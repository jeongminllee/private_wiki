# 한눈에 보기

정보처리기사 필기 과정을 처음 시작하는 사람을 위한 장시간 강의다. 2020년 NCS 기반 개편 이후 소프트웨어 프로젝트의 기획·설계·개발·데이터베이스·프로그래밍·시스템 구축을 넓게 다루는 자격이라는 관점에서 범위를 소개한다.

# 과목 지도

- **소프트웨어 설계**: 요구사항, 화면·애플리케이션 설계와 UML 같은 표현 수단
- **소프트웨어 개발**: 자료구조, 통합 구현, 제품 소프트웨어 패키징과 테스트
- **데이터베이스 구축**: 논리·물리 설계, SQL과 데이터베이스 운영
- **프로그래밍 언어 활용**: C, Java, Python의 문법과 코드 실행, 운영체제·네트워크 기초
- **정보시스템 구축 관리**: 개발 방법론, 프로젝트 관리, 보안과 시스템 구축

# 강의 활용법

긴 강의를 처음부터 받아쓰지 않는다. 먼저 기출 한 회를 풀어 모르는 과목을 표시한 뒤 해당 구간을 듣는다. 개념마다 “정의”, “서로 구분할 기준”, “기출에서 묻는 형태” 세 줄만 남기고 바로 유사 문제를 푼다. 코드와 SQL은 눈으로 이해한 뒤 직접 실행하거나 손으로 결과를 추적한다.

# 시점에 따른 주의

영상에서 언급하는 응시 인원, 합격률, 일정과 세부 시험 운영은 제작 당시 자료다. 시험 일정·응시 자격·출제 기준은 바뀔 수 있으므로 최신 Q-Net 공고를 기준으로 삼는다. 강의는 범위 이해와 개념 설명에 사용하고 행정 정보의 최종 출처로 사용하지 않는다.
