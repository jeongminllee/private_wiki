# 한눈에 보기

NVIDIA Build는 여러 AI 모델과 NIM 추론 API, 에이전트 스킬, 참조 블루프린트를 찾아보고 브라우저에서 시험할 수 있는 개발자 포털이다. 모델 카탈로그뿐 아니라 가속 컴퓨팅, 피지컬 AI와 개발 도구 자료를 함께 제공한다.

# 핵심 내용

- 호스팅된 추론 엔드포인트로 모델의 입력·출력을 빠르게 시험하고 API 예제를 확인할 수 있다.
- 에이전트 스킬과 블루프린트는 검색, 분석, 실행 같은 기능을 조합하는 출발점을 제공한다.
- NIM은 NVIDIA 하드웨어에 최적화된 모델 서빙 단위를 지향한다.
- 포털에는 모델별 카드, 사용 조건과 배포 관련 자료가 함께 연결된다.

# 왜 읽을 만한가

대형 모델을 직접 설치하기 전에 API로 동작과 응답 형식을 확인할 수 있다. 이후 온프레미스 배포를 검토할 때 같은 모델의 서빙 경로와 NVIDIA 생태계 도구를 찾아보기 쉽다.

# 적용 아이디어

- 후보 모델을 같은 소수의 테스트 프롬프트로 비교하고 응답, 지연 시간, 사용 조건을 기록한다.
- B200 환경에 올릴 모델은 포털 데모 결과와 자체 서빙 결과를 분리해 평가한다.
- 블루프린트는 완성품보다 구성 요소와 운영 요구사항을 파악하는 참고 구현으로 사용한다.

# 주의할 점

포털은 계속 갱신되므로 노출 모델과 무료 호출 범위가 바뀔 수 있다. 데모 품질을 실제 배포 성능으로 간주하지 말고 계정 조건, 데이터 처리, 라이선스와 비용을 별도로 확인해야 한다.
