# 확인된 내용

글의 제목은 “What 10 Years of Java Taught Me About Over-Engineering”이고 Pudari Madhavi가 작성했다. 공개된 첫 부분은 복잡성을 지적 능력이나 좋은 아키텍처의 증거로 착각했던 경험을 돌아보며, Java 시스템은 너무 단순해서보다 지나치게 영리하게 설계되어 실패하는 경우가 많다고 주장한다.

과잉 설계는 대개 악의가 아니라 “나중에 확장될 수 있다”, “언젠가 필요할 수 있다”, “유연하게 만들자” 같은 좋은 의도에서 시작된다고 설명한다.
