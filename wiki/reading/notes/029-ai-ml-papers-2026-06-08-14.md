# 한눈에 보기

이 주의 연구는 에이전트가 환경과 전략을 스스로 개선하는 흐름이 강하지만, 동시에 그 주장을 검증하기 위한 더 엄격한 벤치마크와 외부 최적화 기법의 필요성을 보여준다. “모델에게 전부 맡긴다”기보다 모델의 생성 능력과 실행기·탐색 알고리즘·평가기를 조합하는 방향이다.

# 주요 흐름

## 자기 개선과 다중 에이전트

`Economy of Minds`는 여러 에이전트가 역할과 자원을 나누는 상호작용을 탐구한다. `AutoScientists`는 연구 문제 설정, 실험, 검토를 여러 에이전트가 반복하는 구조를 다룬다. `Self-Harness`는 에이전트가 자신의 도구 사용과 제어 구조를 개선하는 방향을 제시한다. 이름은 자율적이지만 실제 품질은 평가 함수, 비용 한도, 실패 복구에 좌우된다.

## 한계를 드러내는 평가

`LiveBrowseComp`는 최신 웹 탐색이 필요한 질문으로 검색 에이전트가 실제 검색보다 사전 지식에 의존하는 문제를 찾으려 한다. AI 리뷰어 연구는 빠른 1차 검토에는 유용하지만 인간 전문가와 다른 오류를 내므로 대체재보다 보완재로 보는 편이 타당하다고 제안한다. HPO 연구는 LLM이 탐색 전략을 설명하고 후보를 만들되 CMA-ES 같은 최적화기가 상태와 수치 탐색을 담당하는 하이브리드 방식을 쓴다.

## 자원 효율

`AutoForge`는 학습과 평가용 환경 생성 비용을 줄이려 하고, `APEX`는 가치가 큰 샘플을 선택해 학습 효율을 높인다. `FP8 is All You Need`와 `DySIB`는 정밀도, 데이터 선택, 계산 배분을 조정해 같은 자원으로 더 나은 결과를 얻는 문제를 다룬다.

# 실무 적용

- “자기 개선” 루프에는 고정된 회귀 과제, 최대 비용, 이전 버전 보존, 롤백 조건을 둔다.
- 검색 에이전트는 답만 평가하지 말고 실제로 최신 출처를 열었는지와 인용 일치 여부를 검사한다.
- 수치 최적화는 LLM의 직관만 쓰지 말고 검증된 탐색 알고리즘과 결합한다.
- AI 리뷰는 놓친 영역을 찾는 두 번째 관점으로 사용하고 최종 책임과 고위험 판정은 사람이 맡는다.

# 주의할 점

자동 연구·자동 개선은 데모에서 실제 운영으로 갈 때 비용과 오류 누적이 급격히 커질 수 있다. 성능 향상뿐 아니라 재현성, 실패율, 평가 누출, 사람의 개입량을 함께 봐야 한다.
