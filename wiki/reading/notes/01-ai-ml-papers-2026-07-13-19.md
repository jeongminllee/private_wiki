# 한눈에 보기

이번 주 논문들은 모델 자체보다 에이전트가 사용하는 컨텍스트와 스킬, 실행 경계를 어떻게 설계하느냐에 초점이 맞춰져 있다. 자기 개선도 가중치 재학습만을 뜻하지 않고 프롬프트, 메모리, 도구와 스캐폴드까지 스스로 갱신하는 문제로 확장된다.

# 핵심 내용

- `Self-Improvements in Modern Agentic Systems`는 에이전트를 기반 모델과 스캐폴드의 결합으로 보고, 두 구성 요소 중 무엇을 어떻게 갱신하는지에 따라 자기 개선 방식을 분류한다.
- `R3-Skill`은 스킬을 문서 검색 문제로만 다루지 않는다. 특정 질의와 스킬의 실행 호환성을 학습하고, 거절된 사례도 학습 신호로 이용한다.
- `Prismata`는 웹 에이전트가 간접 프롬프트 인젝션을 만났을 때 현재 작업에 필요한 최소 권한만 유지하도록 컨텍스트 기반 최소 권한을 적용한다.
- 다른 논문들은 에이전트 실패를 컨텍스트 품질의 문제로 분석하고, VLM이 이미지를 다시 살펴보는 듯한 행동이 실제 재검사인지 검증하며, 생성형 AI의 사이버 보안 활용과 위험을 함께 다룬다.

# 왜 읽을 만한가

에이전트 성능을 모델 교체 문제로만 보지 않고 스킬 선택, 컨텍스트 구성, 권한 통제라는 운영 문제로 바꿔 보게 한다. 특히 실제 에이전트를 만들고 있다면 R3-Skill, Prismata, 컨텍스트 품질 논문부터 읽는 편이 효율적이다.

# 적용 아이디어

- 스킬 검색 평가에 의미 유사도뿐 아니라 실제 실행 성공 여부와 거절 사유를 넣는다.
- 도구 권한을 세션 전체에 고정하지 말고 현재 단계의 목적과 출처에 따라 축소한다.
- 에이전트 회고 시 모델 답변보다 입력 컨텍스트, 선택된 스킬, 도구 결과를 먼저 검사한다.

# 주의할 점
