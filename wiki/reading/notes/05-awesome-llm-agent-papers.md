# 한눈에 보기

LLM 에이전트 연구를 설문, 아키텍처, 계획, 메모리, 도구 사용, 멀티에이전트, 환경, 응용, 평가, 안전의 열 영역으로 나눈 읽기 지도다. 각 논문에 짧은 설명과 발표 정보, 코드 링크를 붙여 탐색 비용을 낮춘다.

# 핵심 내용

- 200편 이상의 논문을 주제별로 분류하고 최신 연구를 계속 보완한다.
- 처음 보는 사람을 위한 핵심 논문 열 편의 시작 목록이 있다.
- `LLM Agents: A Survey`의 보조 자료라 개별 논문과 전체 연구 지형을 오가기 쉽다.
- 안전 영역에는 간접 프롬프트 인젝션처럼 에이전트의 도구 사용과 직접 연결되는 위험도 포함된다.

# 왜 읽을 만한가

처음부터 끝까지 읽는 목록이라기보다 질문이 생겼을 때 관련 연구를 빠르게 찾는 색인으로 가치가 크다. 에이전트 연구의 하위 분야와 대표 평가 자료를 한 화면에서 볼 수 있다.

# 추천 읽기 순서

1. 설문으로 전체 용어와 문제 지형을 잡는다.
2. ReAct와 계획 계열로 기본 실행 루프를 이해한다.
3. 메모리와 도구 사용을 읽어 상태·행동 설계로 확장한다.
4. AgentBench 같은 평가 자료로 성능 주장 검증법을 본다.
5. 간접 프롬프트 인젝션 등 안전 논문으로 운영 경계를 점검한다.

# 주의할 점

큐레이션에 포함됐다는 사실이 논문의 재현성이나 품질을 보증하지는 않는다. 목록의 최신성도 저장소 갱신 시점에 의존하므로 실제 적용 전 원 논문과 코드를 확인해야 한다.
