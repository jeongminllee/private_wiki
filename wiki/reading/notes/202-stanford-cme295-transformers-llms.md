# 강의 구성

Stanford CME 295는 NLP 배경에서 시작해 현대 LLM 시스템까지 아홉 강의로 이어지는 공개 강의다. 각 회차에는 slide와 약 1시간 40~50분 길이의 영상이 있고 중간·기말시험과 해설도 공개되어 있다.

1. tokenization, embedding, RNN·LSTM, attention과 Transformer
2. MHA·MQA·GQA, 위치 embedding, RoPE와 BERT 계열
3. MoE, context length, sampling, prompting과 chain of thought
4. pretraining, quantization, hardware 최적화, SFT와 LoRA
5. reward model, RLHF, PPO 계열과 DPO
6. reasoning model, reasoning을 위한 RL, GRPO와 scaling
7. RAG, function calling, agent와 ReAct
8. LLM-as-a-judge의 장점, 편향과 함정
9. 전체 복습과 최신 동향

# 활용 방법

Transformer를 이미 아는 사람은 3강부터 시작해 학습, 정렬, 추론, 에이전트, 평가 순서로 보는 편이 효율적이다. 개념을 실제로 점검하려면 slide만 읽기보다 공개 시험을 먼저 풀고 해설과 강의를 역순으로 확인하는 방식이 좋다.
