# 확인한 내용

AI, 네트워크, 컴퓨터과학, 알고리즘, 데이터베이스, 디자인 패턴, 영어, 수학, 운영체제, 프로그래밍과 Spring 관련 PDF·EPUB·MOBI 파일을 모은 GitHub 저장소다. CLRS, Kurose의 네트워크 교재, Design Patterns, English Grammar in Use처럼 일반적으로 유료 판매되는 상업 서적도 포함돼 있다.

저장소 소유자는 2025년 3월 8일 아카이브해 현재 읽기 전용이며, 다른 전자책 모음 저장소의 fork다. 확인 가능한 라이선스가 없고 각 책의 배포 권한도 제시되지 않는다.

# 왜 로컬 위키 원천으로 쓰지 않는가

공개 GitHub에 있다는 사실은 책의 저작권이 허용됐다는 뜻이 아니다. 원문을 내려받아 다시 보관하거나 책별 내용을 대량 추출하면 저작권 침해 가능성이 크다. 저장소가 삭제되거나 DMCA 대상이 될 수 있어 장기 보존성과 출처 신뢰성도 낮다.

따라서 여기서는 책 파일이나 다운로드 경로를 복제하지 않고, 저장소의 성격과 위험만 기록한다. 읽고 싶은 책은 출판사 전자책, 도서관, 저자 공개본, OpenStax·공식 공개 강의처럼 권리가 분명한 경로에서 확보하는 편이 안전하다. 공개 라이선스가 확인되는 개별 자료가 있다면 그 공식 URL을 별도 문서로 등록하는 방식이 좋다.
