# 접근 결과

저장된 OKKY 주소는 글 제목과 약 47분의 읽기 시간 등 기본 메타데이터만 노출했다. 일반 웹 요청은 HTTP 403으로 거절됐고, 검색 및 읽기 화면에서도 본문을 확보하지 못했다. 따라서 제목만 보고 LLM의 일반적인 작동 원리를 대신 작성하지 않았다.

# 확인 가능한 정보

- 저장 제목은 `요즘 자주 듣는 LLM, 도대체 어떻게 작동하는 걸까요?`다.
- 글 주소와 작성자 프로필 경로는 식별되지만 실제 문단, 그림, 출처 목록은 확인할 수 없다.
- 긴 설명 글로 보이지만 다루는 범위와 난이도, 저자의 고유한 설명 방식은 본문 없이 판단할 수 없다.

# 막힌 이유

사이트가 자동 요청을 차단하며, 공개 검색 결과에는 본문 캐시가 없다. 로그인 세션이 필요한 브라우저 화면을 우회하거나 보호된 내용을 추정해서 가져오는 것은 적절하지 않다.

# 복구에 필요한 것

사용자가 글 본문을 Markdown이나 텍스트로 내보내거나, 공개적으로 접근 가능한 원문 링크를 제공하면 다시 처리할 수 있다. 그림이 핵심이라면 글의 PDF 또는 스크린샷도 함께 필요하다. 자료가 들어오면 저자의 설명 순서를 보존한 재작성 요약과 핵심 용어 링크를 추가한다.
