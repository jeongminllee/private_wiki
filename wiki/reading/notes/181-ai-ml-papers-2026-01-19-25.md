# 한눈에 보기

이 주의 논문은 LLM을 답변 모델이 아니라 환경을 탐색하고 행동하며 경험으로 개선되는 에이전트로 확장한다. 일반적인 에이전트 프레임워크뿐 아니라 검색, 컴퓨터 사용, 코드베이스, 반도체 커널 생성처럼 구체적인 업무에 맞춘 시스템이 두드러진다.

# 주요 흐름

- **Agentic Reasoning survey**: 계획·도구·검색을 다루는 기초 능력, 피드백·기억을 통한 자기진화, 다중 에이전트 협업을 하나의 지도에 놓는다.
- **Agentic-R**: 문장 유사도만 보지 않고 최종 답변에 실제로 기여하는지를 이용해 다단계 검색기를 학습한다.
- **EvoCUA**: 검증 가능한 합성 과제를 여러 샌드박스에서 실행해 컴퓨터 사용 경험을 만든다.
- **TritorX**: LLM, 린터, JIT 컴파일, PyTorch OpInfo 테스트를 묶어 새로운 ML 가속기용 ATen 커널을 생성한다.
- **Confucius Code Agent**: 큰 코드베이스를 다루기 위한 계층적 기억과 메타 에이전트 구조를 제안한다.
- **UniversalRAG**: 텍스트뿐 아니라 이미지·비디오까지 검색 단위를 확장한다.
- **STEM**: FFN의 일부를 토큰별 임베딩 조회로 바꿔 계산량과 매개변수 용량을 분리한다.

# 해석

자기진화라는 이름이 붙어도 무엇을 학습할지와 성공 여부는 사람이 만든 환경과 검증기가 결정한다. 실제 도입에서는 에이전트의 자율성보다 실행 가능한 테스트, 격리, 비용 상한, 실패 추적을 먼저 봐야 한다.
