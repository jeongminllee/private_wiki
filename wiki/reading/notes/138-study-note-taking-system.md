# 한눈에 보기

노트의 목적을 예쁜 기록이 아니라 다음 복습에서 사고를 빠르게 복원하는 도구로 정의한다. 교재 전체를 옮기기보다 큰 구조를 잡고, 내용을 자기 언어로 설명한 뒤, 마지막에는 틀리기 쉬운 항목만 남긴 작은 공략집으로 줄인다.

# 세 단계

1. 장·절의 관계와 핵심 질문을 먼저 구조화한다.
2. 책을 덮고 원리, 이유와 예시를 자기 문장으로 설명한다.
3. 회상에 실패한 부분, 구분 기준, 공식의 조건과 대표 문제만 요약 노트에 남긴다.

# 실제 복습

노트를 읽기 전에 빈 종이 또는 질문 카드로 먼저 회상한다. 틀린 뒤 원문을 확인하고 노트를 수정한다. 간격을 두고 다시 꺼내며, 알고 있는 설명은 삭제하고 반복해서 틀리는 단서만 남기면 노트가 점점 작아진다.

# 비판적으로 볼 점

영상 설명의 “복습 시간 10분의 1”은 모든 학습자에게 검증된 수치가 아니다. 구조화와 자기 설명도 실제 문제 풀이, retrieval practice와 feedback이 없으면 익숙함만 키울 수 있다. 과목 성격에 따라 diagram, code 실행과 계산 연습을 함께 쓴다.
