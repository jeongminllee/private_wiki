# 한눈에 보기

이번 묶음의 공통 질문은 더 많은 데이터를 넣는 것보다 긴 입력을 구조화하고 여러 구성 요소가 협력하는 규칙을 어떻게 만들 것인가이다. 비디오에는 장면 그래프와 검색 계획이, 에이전트 프로토콜에는 별도의 거버넌스 계층이 필요하다는 논의가 눈에 띈다.

# 핵심 내용

- `Gen4U`는 생성용 비디오 확산 모델의 내부 표현을 별도 파인튜닝 없이 비디오 이해 인코더로 활용할 가능성을 탐색한다.
- `EGAgent`는 매우 긴 비디오를 엔티티 장면 그래프로 정리하고, 계획 에이전트가 시각·음성 검색을 조합해 필요한 구간을 찾는다.
- 에이전트 상호운용 프로토콜 연구는 MCP, A2A, ACP, ANP 등을 비교한다. 연결과 메시지 교환 규칙은 있어도 투표, 이견 처리, 인간에게 넘기는 조건과 감사 같은 거버넌스 기능은 부족하다고 지적한다.
- `Nexus`는 거시·미시 시계열 신호와 문맥을 여러 에이전트가 나누어 해석하고, 도메인 보정 루프로 예측을 다듬는다.

# 왜 읽을 만한가

MCP 같은 프로토콜을 도입하면 협업 문제가 자동으로 해결된다는 오해를 바로잡는다. 통신 규격 위에 책임, 이견, 승인, 감사 정책을 따로 설계해야 한다는 점은 프로덕션 에이전트에 직접 적용할 수 있다.

# 적용 아이디어

- 멀티에이전트 설계 문서에 메시지 형식과 별도로 최종 결정권, 실패 시 승격, 감사 로그 규칙을 적는다.
- 긴 영상이나 로그를 통째로 모델에 넣기 전에 엔티티·시간·관계 구조로 색인한다.
- 여러 예측기의 합의뿐 아니라 도메인 제약을 검사하는 보정 단계를 둔다.

# 주의할 점

주간 큐레이션의 요약만으로 방법 간 우열을 판단하기 어렵다. 특히 벤치마크 수치는 데이터셋, 백본 모델과 비용 조건을 원 논문에서 확인해야 한다.
