# 개요

CMDS는 지식관리 체계가 사람에게뿐 아니라 이를 읽고 수정하는 AI에게도 스스로를 설명해야 한다고 본다. 공식 홈페이지의 현재 v4.9.5는 10,000개 이상 note, 공개 system file 6개, 9개 대분류와 91개 category를 설명한다.

`CLAUDE.md`는 Claude Code 실행 규칙, `AGENTS.md`는 다른 coding agent용 이식 규칙, `CMDS.md`는 철학과 사용자 맥락, Guide는 운영 표준, Head Quarter는 navigation, `DESIGN.md`는 visual language를 맡는다. Precedence 번호로 충돌을 해결하고 shared rule은 include해 중복을 줄인다.

# 지식 lifecycle

`Connect`는 inbox의 idea를 포착하고, `Merge`는 여러 note를 문헌 지식으로 통합한다. `Develop`는 지식을 method·code·product로 적용하고, `Share`는 essay·slide·video 같은 output으로 만든다. Slash command가 각 단계를 encoding한다.
