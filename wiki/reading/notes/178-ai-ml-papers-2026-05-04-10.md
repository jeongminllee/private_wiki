# 한눈에 보기

이 주의 논문은 긴 자연어 chain-of-thought를 모두 생성하지 않고도 추론을 효율화하는 방법, 에이전트와 코드 모델을 더 현실적으로 평가하는 방법, 모바일 환경에서 모델을 가볍게 실행하는 방법에 집중한다.

# 주요 흐름

- **Abstract Chain-of-Thought**: 자연어 추론을 더 짧은 추상 토큰 표현으로 압축해 계산 비용을 줄이려 한다.
- **Answer-level fine-tuning**: 중간 경로 전체보다 최종 답변 분포를 게임 이론적으로 정렬하는 접근을 제안한다.
- **MobileLLM-Flash**: 온디바이스 추론에서 모델 구조와 실행 효율을 함께 최적화한다.
- **ProgramBench**: 컴파일된 바이너리만 보고 프로그램을 재구축하게 해 코드 에이전트의 깊은 이해를 평가한다.
- **Code World Model 보고서**: 코드를 생성하는 단계를 넘어 실행 환경과 결과를 예측하는 모델의 준비 수준을 점검한다.
- **Autorater 연구**: LLM 평가자가 사용하는 rubric의 표현과 수정이 점수에 미치는 영향을 다룬다.

# 읽을 때의 기준

주간 모음은 연구 발견용 색인이다. 각 성능 수치는 서로 다른 모델·데이터·예산에서 나온 결과이므로 한 표에 바로 비교하면 안 된다. 관심 논문은 원문에서 기준선, 계산량, 공개 코드, 평가 오염 가능성을 다시 확인해야 한다.
