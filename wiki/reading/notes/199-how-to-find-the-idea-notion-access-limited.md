# 확인된 정보

URL slug에는 `How to find the idea`가 포함되어 있다. Notion이 반환한 일반 HTML에는 실제 페이지 제목과 본문이 없으며, 검색 색인에도 해당 페이지 내용이 남아 있지 않았다.

# 막힌 이유

2026-07-24 공개 URL과 페이지 ID를 각각 조회했지만 Notion API가 `object_not_found`를 반환했다. 페이지가 삭제되었거나 웹 공개가 해제됐거나 현재 통합에 공유되지 않은 상태로 보인다.

아이디어 발상법에 관한 일반 자료를 대신 넣으면 원문을 복구한 것처럼 보일 수 있어 제목 이상의 내용을 추정하지 않았다.

# 다시 처리하려면

- 다시 공개한 Notion 링크
- 페이지를 PDF·Markdown으로 내보낸 파일
- 본문을 복사한 텍스트나 캡처
