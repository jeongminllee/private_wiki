# 추천 목록

1. `클린 코드`: 이름, 함수, 오류 처리와 테스트를 통해 읽히는 코드를 고민한다.
2. `SICP`: 절차와 데이터 추상화, 재귀, 상태와 해석기를 통해 계산 모델을 배운다.
3. `한 권으로 읽는 컴퓨터 구조와 프로그래밍`: bit, CPU, memory, I/O와 software가 만나는 층을 연결한다.
4. `Head First Design Patterns`: 반복되는 설계 문제와 객체 협력의 trade-off를 사례로 익힌다.
5. `Effective TypeScript`: TypeScript의 type system, inference와 API 설계를 실무적으로 다룬다.

# 읽는 순서

당장 코드 리뷰가 어렵다면 `클린 코드`, 프로그램이 왜 그렇게 동작하는지 궁금하면 컴퓨터 구조 책이나 `SICP`, 변경에 약한 객체 설계를 다룬다면 design pattern으로 간다. TypeScript를 실제로 쓸 때만 마지막 책의 효용이 크다.

# 읽기보다 중요한 것

각 장에서 규칙을 외우기보다 작은 코드에 적용하고 전후 diff, test와 실패 사례를 남긴다. `클린 코드`와 design pattern에는 저자의 시대와 스타일에 따른 의견이 섞여 있으므로 절대 규칙으로 적용하지 않는다. `SICP`는 깊지만 입문자에게 가파르므로 강의와 exercise를 병행한다.
