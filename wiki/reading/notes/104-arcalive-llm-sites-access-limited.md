# 확인된 내용

Notion 항목은 Arca Live의 LLM 관련 게시물을 가리키지만 제목이 `Source: Arcalive`뿐이고 별도 메모가 없다. 저장된 링크를 복원했으나 현재 환경에서는 게시물 본문과 검색 색인을 가져오지 못해 어떤 서비스가 포함됐는지 확인할 수 없었다.

# 막힌 이유

- 커뮤니티 페이지가 자동 접근 환경에서 정상 본문을 반환하지 않는다.
- 검색 결과나 공개 캐시에 원문의 제목과 목록이 남아 있지 않다.
- 무료 체험 서비스 목록은 계정, 국가, 시점에 따라 조건이 자주 바뀌므로 제목만 보고 재구성하면 잘못된 정보를 만들 가능성이 높다.

# 필요한 자료

게시물 본문을 복사한 텍스트, 화면 캡처 또는 접근 가능한 대체 링크가 있으면 목록별로 `서비스 / 용도 / 무료 조건 / 개인정보·결제 주의점 / 확인일`을 정리할 수 있다. 그 전에는 임의의 서비스 목록을 채우지 않는다.
