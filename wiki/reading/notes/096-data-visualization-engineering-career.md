# 한눈에 보기

데이터 시각화 전문가는 주어진 표를 차트로 바꾸는 사람에 머물지 않는다. 데이터 pipeline과 metric을 이해하고, 사용자가 탐색하고 결정할 수 있는 web product를 설계하며, 분석 결과를 이해관계자에게 이야기로 전달하는 교차 역할이다.

# 기업별 쓰임

- **Netflix**: 재무·콘텐츠·광고 지표를 여러 조직이 함께 이해할 내부 data product로 만든다.
- **OpenAI**: supercomputer의 node, network와 rack 상태 및 job 진행을 실시간으로 관찰하는 도구를 만든다.
- **Apple**: 제품·서비스 분석을 interactive visualization과 경영진 dashboard로 전달한다.
- **McKinsey**: 연구 보고서의 데이터를 web·social·영상용 story로 표현한다.
- **Airbnb**: 가격, 가용성, 사용자 참여와 품질을 탐색하는 재사용 가능한 interface를 만든다.

# 공통 역량

SQL·Python/R로 데이터를 수집·정제하고 metric의 의미를 설명할 수 있어야 한다. React/Vue, JavaScript/TypeScript와 D3 같은 기술로 맞춤형 interaction을 구현하며, Tableau·Power BI·Grafana·Plotly 같은 도구도 목적에 맞게 선택한다. UI/UX, accessibility와 시각적 storytelling, product manager·designer·analyst와의 협업이 함께 요구된다.

# 포트폴리오 방향

정적인 dashboard 한 장보다 실제 질문을 해결하는 작은 data application이 좋다. 원자료와 metric 정의, 잘못 해석할 위험, interaction을 택한 이유와 사용자 test를 함께 보여준다. 2025년 채용 공고를 바탕으로 한 글이므로 회사별 현재 opening과 기술 stack은 최신 채용 페이지에서 다시 확인한다.
