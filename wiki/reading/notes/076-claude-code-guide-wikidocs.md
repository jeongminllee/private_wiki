# 한눈에 보기

박재홍의 WikiDocs 가이드는 순서대로 따라 하는 `클래스 101`과 기능을 찾는 `레퍼런스`를 함께 제공한다. 설치와 첫 대화에서 시작하지만 개발자만을 대상으로 하지 않고 이메일, 회의록, Excel, PPT, 연구, 금융, 법무·HR와 의료 문서 활용까지 범위를 넓힌다.

# 주요 구조

- **기초**: 설치, 세션, 모델, 자율권, 안전, 컨텍스트와 `CLAUDE.md`
- **개발**: 탐색, debugging, TDD, refactoring, hook, Git/CI, worktree, skill, MCP와 agent team
- **업무**: 문서·자료 처리, 보고서, 경쟁사 분석, SOP와 브라우저 자동화
- **연구·전문 영역**: 논문, 연구 코드, 재무·법무·의료 자료의 보조 처리
- **레퍼런스**: 설정, 권한, slash command, CLI, plugin, cloud 실행, 보안과 privacy
- **부록**: 창시자 workflow, source 분석과 전체 변경 이력

웹 버전은 공식 문서 변경을 자주 반영하고, 판매되는 PDF/EPUB는 구매 시점의 snapshot이다. 빠르게 변하는 명령과 option에는 변경 이력이 특히 유용하다.

# 활용 방법

처음에는 기초의 권한·컨텍스트와 개발의 작은 bug fix를 직접 해 본다. 이후 반복 업무만 skill이나 hook으로 옮긴다. 비즈니스·법무·의료 예제는 결과 초안을 만드는 방법으로 보고, 사실 검증과 최종 책임을 도구에 넘기지 않는다.

# 주의할 점

범위가 넓어 모든 장의 깊이가 같지는 않다. 자동으로 갱신된 설명도 공식 문서와 실제 버전에서 확인해야 한다. 유출 source 분석 부록은 저작권·보안과 신뢰할 수 없는 재배포 파일 문제를 고려해 읽고 실행 파일을 내려받지 않는다.
