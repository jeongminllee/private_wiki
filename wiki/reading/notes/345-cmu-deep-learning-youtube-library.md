# 자료의 성격

이 링크는 단일 영상이 아니라 CMU `11-685/11-785 Introduction to Deep Learning`의 여러 학기 lecture와 recitation을 공개하는 channel이다. 외부 학습자는 강좌 site의 schedule에서 slide, notebook, reading과 해당 YouTube 영상을 함께 찾을 수 있다.

# 다루는 범위

과정은 Python·PyTorch와 neural network 기초에서 시작해 optimization, CNN, RNN, sequence-to-sequence, CTC, language model, attention·Transformer로 진행한다. 뒤에는 autoencoder·VAE, diffusion, GAN, GNN, reinforcement learning, Hopfield network와 Boltzmann machine까지 이어진다. 학기별 syllabus가 달라 channel upload 순서보다 특정 학기의 course page를 기준으로 보는 편이 낫다.

# 학습 방법

강의를 수동 시청하는 데 그치지 말고 각 lecture의 notebook을 실행하고 핵심 식을 직접 유도한다. 한 학기 schedule을 정해 순서대로 따라가며 assignment는 공개 정책과 academic integrity를 지킨다. 영상 수가 많고 중복 학기가 있으므로 최신 강의가 항상 입문자에게 가장 쉬운 것은 아니다.
