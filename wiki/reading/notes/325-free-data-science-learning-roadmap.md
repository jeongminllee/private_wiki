# 학습 순서

기초는 Python, SQL, 수학·통계다. Python은 문법만 보지 말고 데이터 정리와 자동화에 연결하고, SQL은 실제 표를 join·aggregate하며 익힌다. 확률, 분포, 추정, 가설검정과 선형대수는 모델 결과를 해석할 만큼 다룬다. 글은 Kaggle Learn, SQLBolt, StatQuest, 3Blue1Brown, Google ML Crash Course, fast.ai 같은 무료 경로를 제안한다.

# 포트폴리오 원칙

작은 notebook 수를 늘리기보다 4~6개의 완결된 작업이 낫다. 최소한 데이터 cleaning, EDA·visualization, modeling 또는 applied analytics를 포함하고, end-to-end pipeline, 특정 domain 문제, dashboard·storytelling, API·automation 같은 서로 다른 역량을 보여 준다. README에는 문제, 데이터, 판단 근거, 평가 방법과 한계를 남긴다.

# 데이터와 경험

Kaggle, 정부 open data, World Bank, UCI, Harvard Dataverse와 공개 API에서 데이터를 구할 수 있다. pandas, scikit-learn, Polars, SciPy, Matplotlib, DuckDB 등에서 documentation·test·issue를 개선하는 open-source contribution도 실제 협업 증거가 된다.

# 주의

무료 자료의 양보다 정기적으로 결과물을 완성하고 피드백 받는 과정이 중요하다. 글이 연결한 일부 상업 서적의 무료 PDF는 비공식·저작권 침해 가능성이 있으므로 공식 공개본, 도서관 또는 저자 배포본을 사용한다. 서비스의 무료 범위도 변할 수 있다.
