# 강의 범위

CMU 11-785 Fall 2025는 neural network의 표현력, empirical risk minimization, gradient descent, backpropagation, convergence, optimizer와 regularization에서 시작한다. 이후 CNN, RNN, sequence-to-sequence, CTC와 beam search, language model, attention, Transformer, newer architecture와 LLM으로 확장한다.

# 실습 구조

Homework의 P1은 MLP, CNN, RNN·GRU와 search 같은 핵심 operation을 직접 구현하는 데 가깝고, P2는 phoneme state labeling, face verification, language modeling과 attention 기반 ASR 등 application task를 다룬다. Autograd engine, optimizer, dropout, batch normalization과 ResNet bonus도 제공된다.

Recitation은 Python·OOP, NumPy, PyTorch, tensor operation, data loader·preprocessing, debugging, distributed training, model save·load, W&B와 cloud·Kaggle 환경까지 보완한다. Lecture slide, YouTube 영상, notebook과 optional textbook link가 공개되어 self-study가 가능하다.

# 학습 순서

P1 구현으로 forward·backward와 shape를 이해하고, 작은 dataset에서 gradient check를 한 뒤 P2 application으로 넘어가는 편이 좋다. Kaggle score만 좇지 말고 baseline, ablation, train·validation curve와 error analysis를 남긴다.

과제 제출 system과 일부 recording은 CMU 계정이 필요할 수 있고, 공개 자료를 보는 것과 course credit 취득은 다르다. Semester page는 고정 snapshot이므로 최신 iteration과 혼동하지 않는다.
