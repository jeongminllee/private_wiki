# 한눈에 보기

CodeGraph는 파일 텍스트를 매번 검색하는 대신 코드의 심볼, 호출, 구현, 의존 관계를 로컬 그래프로 만들어 MCP와 CLI로 질의하게 한다. “이 인터페이스의 구현체는 무엇인가”, “이 함수 변경의 영향 범위는 어디인가”처럼 관계를 따라가는 질문을 에이전트가 적은 도구 호출로 풀도록 돕는다.

# 주요 기능

- 저장소를 파싱해 심볼과 관계를 사전 인덱싱한다.
- 파일 감시로 변경을 반영하고, 연결 시점에 현재 파일과 그래프를 대조한다.
- 최신 상태가 아닐 때 staleness 경고를 보여준다.
- MCP 도구와 CLI를 제공해 에이전트와 사람이 같은 그래프를 조회한다.

프로젝트는 자체 평가에서 토큰과 비용, 도구 호출 감소를 보고하지만 README의 수치가 버전에 따라 갱신된다. 공급자 선택 저장소와 설정에서 나온 결과이므로 일반적인 보장으로 읽으면 안 된다.

# 언제 유용한가

모듈이 많고 호출 관계가 얽힌 저장소, 익숙하지 않은 코드베이스의 영향 분석에 가치가 크다. 작은 저장소나 정확한 문자열을 찾는 작업은 `rg`가 더 빠르고 단순할 수 있다. 가장 현실적인 구성은 텍스트 검색, 언어 서버, 그래프 질의를 질문 종류에 따라 병행하는 것이다.

# 평가 방법

대표적인 아키텍처 질문과 변경 과제를 고정하고, 그래프 없이 수행한 경우와 성공률·토큰·시간·잘못된 참조 수를 비교한다. 자동 동기화가 끊긴 직후와 대규모 리네임 뒤에도 답이 맞는지 확인해야 한다.

# 주의할 점

파서가 이해하지 못하는 동적 호출과 메타프로그래밍은 관계가 누락될 수 있다. 오래된 그래프는 자신 있게 틀린 맥락을 제공하므로 갱신 상태가 결과에 포함되어야 한다. 인덱스에 비밀 코드가 담기는 위치와 보존 정책도 확인한다.
