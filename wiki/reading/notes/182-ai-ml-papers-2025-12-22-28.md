# 한눈에 보기

이 주의 연구는 모델이 틀릴 때를 찾아 검색하거나 내부 표현을 수정하는 신뢰성 연구, 토큰을 순차 생성하는 병목을 줄이는 추론 연구, 시간과 공간이 일관된 세계 모델 연구로 나뉜다.

# 주요 흐름

- **QuCo-RAG**: 모델의 말로 표현한 자신감 대신 사전학습 데이터의 통계적 단서를 이용해 검색 시점을 결정한다.
- **H-Neurons**: 환각과 연관된 뉴런을 찾아 발생 근원을 분석하고 개입하려 한다.
- **Model-First Reasoning**: 답을 내기 전에 문제의 구조와 변수를 명시적으로 모델링하게 한다.
- **Jacobi Forcing**: 여러 토큰 후보를 병렬 갱신해 자기회귀 디코딩의 순차 병목을 줄인다.
- **qTTT**: 긴 문맥을 읽을 때 test-time training으로 중요한 신호가 희석되는 문제를 완화한다.
- **WorldPlay**: 과거 프레임의 기하학적 정보를 다시 구성해 장시간의 실시간 상호작용 비디오를 생성한다.
- **4D-RGPT·NEPA**: 시간축을 포함한 장면 이해와 픽셀 대신 표현 공간을 예측하는 시각 학습을 탐색한다.

# 주의

환각 뉴런이나 검색 규칙 하나로 사실성을 보장할 수는 없다. 모델 내부 개입은 과제와 모델이 바뀌면 재검증해야 하며, 세계 모델의 시각적 일관성도 실제 물리 법칙의 정확성과 같지 않다.
