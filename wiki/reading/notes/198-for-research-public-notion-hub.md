# 한눈에 보기

인하대학교 ECE의 김법수(Beopsoo Kim)가 공개한 연구 자료 허브다. 하나의 튜토리얼 본문보다 논문 작성과 연구 운영에 필요한 페이지와 데이터베이스를 모아 둔 목차형 자료실이다.

# 포함된 영역

- **논문 작성 팁**: 연구 문장, 구성, 작성 과정에 관한 자료
- **통계·데이터 사이언스 모음**: 논문 분석에 필요한 방법과 도구
- **Research management template**: 연구 과제와 문헌, 진행 상황을 관리하는 템플릿
- **ChatGPT로 원하는 결과 얻기**: 연구 보조에 생성형 AI를 사용할 때의 프롬프트 자료
- **저널·연구 영향력 지표 가이드**: 저널과 연구 성과 지표를 해석하기 위한 안내
- 주제별로 분리된 여러 Notion 데이터베이스

# 활용 방법

필요한 페이지를 한꺼번에 복제하기보다 현재 연구 단계에 맞춰 사용한다. 문헌 수집, 분석 방법 결정, 초안 작성, 저널 선택을 별도 workflow로 나누고 각 자료의 출처와 갱신일을 확인하는 편이 좋다.

# 확인 범위

공개 최상위 페이지와 하위 자료의 제목은 확인했지만 일부 하위 페이지와 데이터베이스는 외부 workspace 권한 때문에 본문을 읽을 수 없었다. 허브 자체의 구조를 정리했으며 각 하위 자료의 세부 내용을 추정하지 않았다. 원 저자는 공유 시 출처를 반드시 밝히고 홍보·사익에 사용하지 말라고 명시한다.
