# 한눈에 보기

이 GeekNews 글은 박재홍의 `클로드 코드 가이드`를 소개하는 원 게시물이다. 저자는 빠르게 찾는 reference, Claude Code 창시자의 workflow와 실전 사용법을 한곳에 모으고, Claude와 함께 공식 문서 변경을 계속 반영한다고 설명한다.

# 이 항목의 가치

가이드 본문과 별개로 자료가 어떤 목적으로 시작됐는지와 독자 피드백을 볼 수 있다. 초기에 깨진 link가 댓글로 발견되어 수정됐고, 웹 버전의 지속 갱신과 PDF/EPUB snapshot의 차이도 논의됐다. 살아 있는 문서는 자동 갱신만으로 신뢰할 수 있는 것이 아니라 사람이 link와 내용 변화를 계속 확인해야 함을 보여준다.

# 읽을 때

기능을 빠르게 찾을 때는 웹 가이드의 quick reference를 사용하고, 현재 behavior와 security boundary는 Anthropic 공식 문서에서 다시 확인한다. 전자책은 특정 시점의 안정된 읽기본이고 웹 버전은 더 최신일 수 있으므로 서로 역할이 다르다.
