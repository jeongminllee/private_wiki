# 한눈에 보기

영상은 AI 개발자가 모델 실험만 하는 직무가 아니라 데이터 준비, LLM application 구현, backend·deployment와 협업까지 연결하는 역할임을 현직 경험으로 설명한다. 준비도 기술 목록보다 하나의 문제를 끝까지 해결한 증거를 보여주는 방향이 중요하다.

# 준비할 축

- Python, 자료구조·알고리즘과 기본적인 software engineering.
- ML/DL의 학습·평가 원리와 PyTorch 등 한 framework의 실제 사용.
- LLM application이라면 embedding, RAG, evaluation, prompt와 serving의 failure mode.
- Git, API, database, Docker·cloud와 log·monitoring 등 배포 후 운영.
- 문제 정의, 실험 설계, metric 선택과 결과를 이해관계자에게 설명하는 능력.

# 포트폴리오

흔한 notebook 복제보다 실제 사용자를 정하고 baseline, 데이터와 metric, 실패·개선 과정을 남긴다. README에는 architecture, 재현 command, demo, 비용·latency·quality trade-off와 내가 담당한 부분을 명확히 쓴다. 면접에서는 “왜 이 방법인가”와 다른 선택지를 설명할 수 있어야 한다.

# 코딩 테스트와 영상의 한계

지원 회사의 최근 공고와 전형을 기준으로 알고리즘, SQL과 구현 문제의 비중을 확인한다. 영상은 한 사람의 경험이며 2026년 초 모집 과정 홍보가 포함돼 있다. 특정 bootcamp 참여가 취업의 필수 조건이라는 뜻으로 읽지 않는다.
