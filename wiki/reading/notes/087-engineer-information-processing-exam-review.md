# 한눈에 보기

작성자가 2024년 1회 정보처리기사 필기와 실기를 준비하고 합격한 개인 후기다. 준비 기간이 필기 3일, 실기 2일로 매우 짧았으므로 그대로 재현할 공부 계획이라기보다, 어떤 자료와 문제 유형이 실제 시험 적응에 도움이 됐는지 보는 사례다.

# 필기에서 얻을 점

- 시나공 자료로 개념을 훑고 전자문제집 CBT와 Kinz에서 기출을 반복했다.
- 실제 시험에서 본 문제와 유사 유형을 여러 개 만났다고 보고해, 시간 제약이 클수록 기출의 빈출 개념과 오답 분석이 중요하다고 본다.
- CBT 화면과 즉시 채점 방식에 익숙해지고, 애매한 문제는 표시해 마지막에 다시 검토했다.

# 실기에서 얻을 점

후기에서 본 2024년 1회 실기는 총 20문항의 필답형이었고, 작성자의 분류로는 코딩 8문항, SQL 4문항, 보안·네트워크 각 2문항, 운영체제 1문항과 기타 이론 3문항이었다. C pointer, Java overriding·shadowing, Python, SQL, IP 주소, paging, cohesion, design pattern과 test coverage를 복습 대상으로 제시한다.

이 구성은 특정 회차의 체감 분류다. 다음 회차의 비중이나 난이도를 보장하지 않으므로 전체 출제 기준을 먼저 보고, 복원 문제는 실전 형식 점검에 사용한다.

# 추천 학습 흐름

1. 공식 출제 기준으로 범위를 지도처럼 만든다.
2. 필기는 CBT 기출을 풀고 오답이 가리키는 개념만 보충한다.
3. 실기는 답을 보는 데서 끝내지 않고 코드 출력과 SQL을 손으로 써 본다.
4. 복원 문제 한 회를 시간 제한 안에 풀어 약한 영역을 찾는다.
5. 접수일·준비물·시험 방식은 당시 후기가 아니라 최신 Q-Net 공고로 확인한다.
