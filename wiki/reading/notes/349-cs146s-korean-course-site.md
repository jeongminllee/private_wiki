# 강좌 목표

CS146S는 software development가 사람이 처음부터 code를 쓰는 과정에서 `계획 → AI 생성 → 수정 → 반복`으로 바뀌는 흐름을 다룬다. AI coding, automated testing, documentation, vulnerability detection과 deployment를 실제 engineering workflow에 통합하고 실패 패턴을 이해하는 것이 목표다.

한국어판은 원 저자 Mihail Eric의 허가 아래 Team Attention이 reading을 번역한다. Course는 3 units, 주간 lecture·hands-on session·industry guest와 final project로 구성되며 CS111 수준 programming을 prerequisite로, CS221·229를 권장한다.

# 활용

한국어 번역으로 구조를 익힌 뒤 code, product 기능과 용어는 원문 reading에서 대조한다. Tool과 API가 빠르게 바뀌므로 과제의 의도와 현재 실행법을 구분한다. YouTube 한국어 강의처럼 아직 `예정`인 항목은 완료된 자료로 가정하지 않는다.
