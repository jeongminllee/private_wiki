# 한눈에 보기

Linux 입문자가 수많은 배포판 비교에 시간을 쓰기보다 Ubuntu Desktop이나 Fedora Workstation 중 하나로 먼저 시작하라는 글이다. 둘 다 설치 자료, 하드웨어 지원, 사용자 기반이 넓어 Linux의 기본 경험을 만들기 쉽다.

# Ubuntu를 고를 때

- Canonical의 기업 지원과 넓은 소프트웨어·하드웨어 호환성이 있다.
- 6개월 주기 일반판과 장기 지원 LTS를 선택할 수 있다.
- GNOME이 맞지 않으면 KDE를 쓰는 Kubuntu 같은 공식 flavor가 있다.
- 안정적인 장기 사용과 많은 문제 해결 문서를 원할 때 편하다.

# Fedora를 고를 때

- 비교적 순정에 가까운 GNOME과 최신 Linux 구성요소를 빠르게 제공한다.
- Red Hat의 지원을 받으며 RHEL 계열 기술을 미리 접할 수 있다.
- 각 버전 지원 기간은 약 13개월이라 정기 업그레이드가 필요하다.
- Silverblue 같은 atomic desktop은 시스템 변경과 rollback을 더 엄격하게 관리한다.

# 시작 순서

먼저 live USB나 가상머신에서 Wi-Fi, 그래픽, 절전, 오디오, 필수 앱을 확인한다. 배포판을 바꾸는 일은 Linux 사용에 익숙해진 뒤 구체적인 불편이 생겼을 때 해도 늦지 않다.
