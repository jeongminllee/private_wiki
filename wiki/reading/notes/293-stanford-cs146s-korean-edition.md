# 프로젝트

`stanford-cs146s-kr`는 Stanford CS146S `The Modern Software Developer`를 한국어로 옮기는 프로젝트다. 원저자 Mihail Eric이 source attribution을 조건으로 번역을 허가했고, 한국어 site는 `kr.themodernsoftware.dev`에서 제공된다. 비공식 무단 복제라기보다 원저자의 공개 허가를 받은 localization이라는 점이 중요하다.

목표는 모든 reading 자료와 주요 slide의 한국어판을 제공하고, 이후 한국어 YouTube 강의와 Discord community로 확장하는 것이다. Repository는 Vite, React, TypeScript와 Tailwind CSS로 만든 web app이며 curriculum·FAQ content를 source 안에 관리한다.

# 어떻게 활용할까

이 강좌의 가치는 특정 coding agent 사용법 하나보다 AI가 software lifecycle에 들어온 뒤 개발자가 해야 할 일을 curriculum으로 묶는 데 있다. 한국어판으로 개념을 먼저 읽고 원문 링크를 함께 열어 용어, code와 최신 tool behavior를 대조하면 번역에만 의존하는 문제를 줄일 수 있다.

번역은 읽기 장벽을 낮추지만 원본 강좌와 외부 reading은 계속 바뀔 수 있다. 한국어 page의 완료 여부와 update 날짜를 확인하고, 중요한 command·API·제품 정책은 원문을 기준으로 검증한다. Repository README가 밝히는 현재 범위에는 “예정” 항목도 있으므로 slide·영상·community가 모두 완성됐다고 가정하지 않는다.

# 기여 원칙

번역 수정은 단어 치환보다 문맥과 source attribution을 보존해야 한다. AI coding 용어는 첫 등장에 영어를 병기하고, 원문 변경을 추적할 수 있게 source URL이나 revision을 남기는 편이 유지보수에 유리하다. 번역 content의 저작권은 원본 저작권자에게 있다는 안내도 재배포 시 유지해야 한다.
