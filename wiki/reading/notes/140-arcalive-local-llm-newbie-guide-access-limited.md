# 확인된 내용

게시물 제목은 `뉴비에게 도움 되는 글 모음`으로 복원됐으며 로컬 AI 언어모델 채널의 안내 자료로 보인다. 그러나 현재 환경에서는 본문과 연결된 개별 글 목록을 가져오지 못했다.

# 막힌 이유

- Arca Live 게시물이 자동 접근 환경에서 정상 본문을 반환하지 않는다.
- 검색 cache에도 전체 링크 목록과 설명이 남아 있지 않다.
- 2023년 게시물이라 model, quantization, runtime와 GPU별 설치법이 현재와 크게 달라졌을 수 있다.

# 필요한 자료

본문 복사나 캡처가 있으면 링크별 주제와 현재 상태를 확인해 `기초 개념 / hardware·VRAM / model 선택 / quantization / runtime / UI / troubleshooting` 순서의 최신 학습 경로로 다시 만들 수 있다. 그 전에는 오래된 명령을 추정해 넣지 않는다.
