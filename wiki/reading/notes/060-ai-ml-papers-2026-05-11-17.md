# 한 줄 요약

이번 묶음은 모델의 최종 답만 보는 대신 중간 추론을 구조화하고, 제한된 데이터와 하드웨어에서 실행 경로를 다시 설계하며, 정답/오답을 넘어 연속적인 평가 기준을 만들려는 연구 흐름을 보여준다.

# 세 가지 흐름

## 검증 가능한 중간 과정

Agentic Code Reasoning은 코드 실행 없이 분석할 때 전제, 실행 경로와 결론을 준형식적으로 적게 해 패치 동등성, 결함 위치, 코드 질의응답을 개선한다. TCRM은 보상 모델의 토큰별 출력을 최종 보상의 조건부 기댓값으로 해석해 과정 신호를 만든다. RubricEM은 장기 과제를 rubric 단위로 분해해 실행, 평가와 기억의 공통 구조로 쓴다.

## 효율을 위한 실행 경로 재설계

FairyFuse는 삼진 가중치와 융합 AVX-512 커널로 CPU 추론의 메모리 병목을 줄인다. SIRA는 여러 번 검색하는 에이전트 대신 증거 어휘를 보강한 단일 질의와 weighted BM25를 사용한다. 제한된 인간 시연을 다룬 로봇 연구는 행동을 그대로 복제하지 않고 상태 진전 신호를 추론해 더 짧은 경로를 찾는다.

## 평가 기준의 확장

Soohak은 수학자 64명이 만든 439개 연구 수준 문제와 함께 잘못 정의된 문제를 거절하는 능력을 평가한다. EditLens는 인간/AI 이분법 대신 AI 편집의 정도를 연속값으로 추정한다. Transformers are Inherently Succinct는 표현 압축 능력과 그에 따라 커지는 형식 검증 난이도를 함께 분석한다.

# 읽는 방법

주간 글은 논문의 관계를 빠르게 보는 2차 자료다. 성능 수치와 일반화 가능성은 각 원 논문의 데이터, 비교군, 하드웨어와 평가 절차에서 다시 확인한다. 구조화된 추론도 실제 실행 테스트를 완전히 대체하지 않으며, 내재 평가 점수가 사용자 가치와 같다고 볼 수 없다.
