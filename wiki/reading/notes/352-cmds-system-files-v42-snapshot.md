# 자료의 의미

이 URL은 현재도 응답하지만 page title은 `CMDS System Files v4.2 — Knowledge Architecture`다. 현재 공식 `system.cmdspace.work`의 v4.9.5보다 이전 구조를 보여 주는 배포 snapshot이므로 최신 설치 문서가 아니라 변화 이력을 확인하는 자료로 보는 편이 맞다.

# 현재판과의 관계

핵심 철학은 사람과 AI가 같은 vault 규칙을 읽고 역할별 system file과 precedence로 충돌을 해결하는 것이다. 이후 version에서는 공개 핵심 file이 6개로 정리되고 `DESIGN.md`, shared rule 8개와 command·property 수가 공식 문서에 명확히 표시됐다.

# 사용 원칙

구버전의 file 수, command와 template를 현재 규격처럼 복사하지 않는다. 오래된 link에서 발견한 아이디어는 현재 docs와 GitHub revision에서 다시 확인하고, version이 필요한 인용에는 `v4.2 snapshot`임을 명시한다.
