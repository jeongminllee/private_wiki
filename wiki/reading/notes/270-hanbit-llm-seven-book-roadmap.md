# 네 단계

한빛미디어는 LLM 학습 목표를 기초, application 구현, 업무 활용, 서비스 운영으로 나누고 7권을 배치한다.

## 1. 기초

- **쉽고 빠르게 익히는 실전 LLM 2판**: model 선택, prompting, embedding, fine-tuning, RAG와 평가를 폭넓게 훑는 입문서
- **핸즈온 LLM**: pretrained model을 활용해 semantic search, classification, clustering 등 code 중심으로 학습

## 2. Application 만들기

- **러닝 랭체인**: LangChain·LangGraph로 RAG, memory와 agent application을 구현
- **LLM 엔지니어링**: data pipeline, supervised fine-tuning, evaluation, inference와 production lifecycle

## 3. 업무와 생성형 AI

- **핸즈온 생성형 AI**: Transformer, autoencoder와 diffusion을 text·image·audio 실습으로 연결
- **생성형 AI를 위한 프롬프트 엔지니어링**: LLM·diffusion model에 공통으로 적용하는 prompt 원칙과 사례

## 4. 운영과 비용

- **LLM 서비스 설계와 최적화**: model selection, quantization, scaling, serving과 infrastructure cost

# 고르는 방법

전부 순서대로 살 필요는 없다. API application이 목표면 기초 한 권과 application 한 권을, model 학습이 목표면 *핸즈온 LLM*과 *LLM 엔지니어링*을, 이미 service를 운영한다면 마지막 책을 먼저 골라도 된다.

이 목록은 출판사가 자사 도서를 큐레이션한 글이므로 독립적인 품질 순위는 아니다. 목차, sample chapter, code repository, 사용 library version과 독자 수준을 비교하고 한 단계에 한 권만 선택하는 편이 좋다.
