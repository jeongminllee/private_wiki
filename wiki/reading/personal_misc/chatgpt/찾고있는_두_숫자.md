# 찾고있는 두 숫자

### ❓ 질문 (User)
from typing import List

def twoSum(nums : List[int], target : int) -> List[int] :
    ans = 0
    hashtable_dict = {}
    for i in range(len(nums)) :
        value = target - nums[i]

        if hashtable_dict.get(value) is not None and hashtable_dict[value] != i :
            ans += 1

        hashtable_dict[nums[i]] = i

    return ans

N = 9
nums = [5, 12, 7, 10, 9, 1, 2, 3, 11]
target = 13
print(twoSum(nums, target))

### 💡 답변 (Assistant)
이 코드는 두 개의 숫자를 더하여 주어진 `target` 값을 만족하는 경우의 수를 찾는 함수입니다. 주어진 리스트 `nums`에서 두 수를 더하여 `target` 값을 만족하는 경우를 찾아 `ans` 변수에 저장한 후, `ans` 값을 반환합니다.

함수 `twoSum`의 동작을 설명해드리겠습니다:

1. `hashtable_dict`는 딕셔너리로, 숫자와 해당 숫자의 인덱스를 저장하는 용도로 사용됩니다.
2. 반복문을 사용하여 `nums` 리스트를 순회합니다. 리스트의 각 요소에 접근하며 다음을 수행합니다.
   - `value` 변수에는 `target`에서 현재 숫자를 뺀 값이 저장됩니다.
   - `hashtable_dict`에서 `value`를 키로 검색하여, 만약 값이 존재하고, 그 값의 인덱스가 현재 숫자의 인덱스와 다르다면, 두 숫자의 합이 `target`과 일치하므로 `ans` 값을 1 증가시킵니다.
   - 현재 숫자와 그 인덱스를 `hashtable_dict`에 저장합니다.
3. 반복문을 모두 순회한 후, `ans` 값을 반환합니다.

이 코드를 실행하면, 주어진 `target` 값을 만족하는 경우의 수가 `ans` 변수에 저장되고, 이 값을 반환합니다. 주어진 예제에서 `target`가 13이고, `nums` 리스트에서 3과 10을 더하면 13이 되므로 답은 1이 됩니다. 따라서 `1`이 출력됩니다.

프로그램을 실행하면 다음과 같은 결과가 출력될 것입니다:

```
1
```
