### ❓ 질문 (User)
```c
int main() {
    int a=10, b=15;
    printf(“%d”, ++a/5 << b/2 + 1*2);
}
```
작성된 프로그램의 실행 결과를 쓰시오.

### 💡 답변 (Assistant)
===
✅ 문제 분석

제시된 C 코드의 핵심은 **연산자 우선순위와 전위 증가 연산자(++a)** 의 동작을 정확히 이해하는 것입니다.

```c
int a=10, b=15;
printf("%d", ++a/5 << b/2 + 1*2);
```

👉 핵심 포인트

- 전위 증가 연산자: `++a`
- 산술 연산: `/`, `*`, `+`
- 비트 이동 연산: `<<`
- 연산자 우선순위

---

### 📌 1단계 : 전위 증가 연산

```
a = 10
++a → 11
```

---

### 📌 2단계 : 연산자 우선순위 정리

C 언어 연산자 우선순위 (높은 순서 → 낮은 순서)

1️⃣ `++`  
2️⃣ `* /`  
3️⃣ `+ -`  
4️⃣ `<< >>`

즉,

```
++a / 5 << b / 2 + 1 * 2
```

은 다음처럼 계산됩니다.

```
( (++a) / 5 ) << ( (b / 2) + (1 * 2) )
```

---

### 📌 3단계 : 좌변 계산

```
++a = 11
11 / 5 = 2   (정수 나눗셈 → 몫만)
```

👉 좌변 결과 = 2

---

### 📌 4단계 : 우변 계산

```
b = 15

b / 2 = 7      (정수 나눗셈)
1 * 2 = 2
7 + 2 = 9
```

👉 우변 결과 = 9

---

### 📌 5단계 : 비트 이동 연산

```
2 << 9
```

왼쪽 시프트는

```
2 × (2^9)
```

```
2 × 512 = 1024
```

---

🎯 정답  
👉 **1024**

---

📌 정답인 이유 요약

| 단계 | 계산 |
|------|------|
| ++a | 11 |
| 11 / 5 | 2 |
| b / 2 | 7 |
| 1 * 2 | 2 |
| 7 + 2 | 9 |
| 2 << 9 | 1024 |

---

🔎 헷갈릴 수 있는 오답 포인트

❌ `<<`가 `+`보다 우선순위가 높다고 착각  
→ 실제로 `+`가 더 높음

❌ 11 / 5 를 2.2로 계산  
→ C는 정수 나눗셈 → 2

❌ 2 << 9 를 2^9 로 계산  
→ 2 × 2^9 임

---

📚 추가로 공부해야 할 것 (실기 출제 빈도 높음)

1️⃣ C 언어 연산자 우선순위  
2️⃣ 정수 나눗셈  
3️⃣ 비트 시프트 연산  
4️⃣ 전위/후위 증가 연산 차이  

---

🧠 실기시험 포인트 정리

✔ 정수형 연산 → 소수 버림  
✔ `* /` > `+ -` > `<<`  
✔ `a << n` = a × 2ⁿ  
✔ 전위 증가 → 먼저 증가 후 연산  

이 유형은 **연산자 우선순위 + 비트 연산**을 묶어서 자주 출제됩니다. 반드시 정확히 계산하는 연습을 하세요.

### 💡 답변 (Assistant)
===
✅ 문제 분석  

수정된 코드입니다.

```c
int main() {
    int a=10, b=15;
    printf("%d", ++a/5 << b/2-1*2);
}
```

이번 문제의 핵심은 **연산자 우선순위**와 **비트 시프트 연산의 결합 방향(좌결합)** 입니다.

---

🎯 핵심 키워드

- 전위 증가 연산자 `++`
- 정수 나눗셈
- `* /` > `+ -` > `<<`
- 시프트 연산은 좌결합

---

📌 1️⃣ 전위 증가

```
a = 10
++a → 11
```

---

📌 2️⃣ 연산자 우선순위 정리

우선순위 높은 순서:

1. `++`
2. `* /`
3. `+ -`
4. `<<`

따라서 수식은 다음처럼 묶입니다.

```
(++a / 5) << (b / 2 - 1 * 2)
```

---

📌 3️⃣ 좌변 계산

```
++a = 11
11 / 5 = 2   (정수 나눗셈)
```

👉 좌변 = 2

---

📌 4️⃣ 우변 계산

```
b = 15

b / 2 = 7
1 * 2 = 2
7 - 2 = 5
```

👉 우변 = 5

---

📌 5️⃣ 비트 시프트 계산

```
2 << 5
```

왼쪽 시프트는

```
2 × (2^5)
```

```
2 × 32 = 64
```

---

🎯 정답  
👉 **64**

---

📌 정답인 이유 요약

| 단계 | 결과 |
|------|------|
| ++a | 11 |
| 11 / 5 | 2 |
| b / 2 | 7 |
| 1 * 2 | 2 |
| 7 - 2 | 5 |
| 2 << 5 | 64 |

---

🔎 헷갈릴 수 있는 오답 포인트

❌ 11 / 5 = 2.2 로 계산  
→ 정수 나눗셈 → 2

❌ `<<`가 `-`보다 우선한다고 착각  
→ `-`가 더 높음

❌ 2 << 5 를 2^5 로 계산  
→ 2 × 2⁵

3️⃣ 정수 나눗셈 특징  
4️⃣ 전위/후위 증가 차이

🧠 실기시험 포인트 정리

✔ `* /` > `+ -` > `<<`  
✔ 정수형 나눗셈은 몫만  
✔ `a << n = a × 2ⁿ`  
✔ 전위 증가 → 증가 후 연산  

이 문제는 **연산자 우선순위 + 시프트 연산 결합 문제**의 전형적인 유형입니다.
