# 이차방정식 근의 합

> **카테고리**: `Reading - Personal & Misc`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-03-05

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
우선, 주어진 이차방정식  
\[
x^2 + 2x + 3 = 0
\]
의 두 근을 \(a\)와 \(b\)라 하면, 문제에서 구하라는 식은  
\[
\frac{1}{a^2 + 3a + 3} + \frac{1}{b^2 + 3b + 3}
\]
입니다.

**1. 식의 변형**

\(a\)에 대해 \(a^2 + 3a + 3\)을 다음과 같이 변형해 봅니다.  
원래 방정식에서  
\[
a^2 + 2a + 3 = 0
\]
이므로, 이를 이용하면  
\[
a^2 + 3a + 3 = (a^2 + 2a + 3) + a = 0 + a = a.
\]
동일하게 \(b\)에 대해서도 \(b^2 + 3b + 3 = b\)임을 알 수 있습니다.

**2. 식의 단순화**

따라서 원래 식은  
\[
\frac{1}{a} + \frac{1}{b}
\]
가 됩니다.

**3. 분수 합의 계산**

\(\frac{1}{a} + \frac{1}{b}\)는 분자와 분모를 통일하면  
\[
\frac{a+b}{ab}
\]
입니다. 여기서 이차방정식의 근의 관계를 사용하면,
- 근의 합: \(a+b = -\frac{2}{1} = -2\),
- 근의 곱: \(ab = 3\).

그러므로  
\[
\frac{1}{a} + \frac{1}{b} = \frac{a+b}{ab} = \frac{-2}{3}.
\]

**최종 답:**  
\[
-\frac{2}{3}
\]

### 💡 답변 (Assistant)
일반적인 이차방정식  
\[
ax^2 + bx + c = 0
\]
의 두 근을 \( \alpha \)와 \( \beta \)라고 하면, 인수분해를 통해  
\[
ax^2 + bx + c = a(x-\alpha)(x-\beta)
\]
라고 쓸 수 있습니다. 오른쪽을 전개하면

\[
a(x^2 - (\alpha+\beta)x + \alpha\beta) = ax^2 - a(\alpha+\beta)x + a\alpha\beta.
\]

이 식이 원래 식 \(ax^2 + bx + c\)와 같아야 하므로, 계수들을 비교하면  
1. \(x^2\)항의 계수: \(a = a\)  
2. \(x\)항의 계수: \(-a(\alpha+\beta) = b\)  
3. 상수항: \(a\alpha\beta = c\)

따라서  
\[
\alpha+\beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}.
\]

이것이 바로 **비에타의 공식 (Vieta의 공식)** 입니다.

---

이제 주어진 이차방정식  
\[
x^2 + 2x + 3 = 0
\]
에서 \(a = 1\), \(b = 2\), \(c = 3\)이므로,  
\[
\alpha + \beta = -\frac{2}{1} = -2, \quad \alpha\beta = \frac{3}{1} = 3.
\]

이로써 두 근의 합은 \(-2\)이고, 곱은 \(3\)임을 증명할 수 있습니다.

두 근의 합과 두 근의 곱이 어떻게 나오는지 증명해줘

### 💡 답변 (Assistant)
이차방정식의 근을 구하는 근의 공식은  
\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]
입니다. 이를 이용해  
\[
x^2 + 2x + 3 = 0
\]
에서 \(a = 1\), \(b = 2\), \(c = 3\)를 대입하면,

\[
x = \frac{-2 \pm \sqrt{2^2 - 4 \cdot 1 \cdot 3}}{2 \cdot 1} 
= \frac{-2 \pm \sqrt{4 - 12}}{2} 
= \frac{-2 \pm \sqrt{-8}}{2}.
\]

여기서 \(\sqrt{-8} = 2i\sqrt{2}\)이므로, 두 근은

\[
x = \frac{-2 \pm 2i\sqrt{2}}{2} = -1 \pm i\sqrt{2}.
\]

즉,  
\[
a = -1 + i\sqrt{2}, \quad b = -1 - i\sqrt{2}.
\]

이제 두 근의 합을 계산하면

\[
a + b = (-1 + i\sqrt{2}) + (-1 - i\sqrt{2}) = -2,
\]
그리고 두 근의 곱은

\[
ab = (-1 + i\sqrt{2})(-1 - i\sqrt{2}).
\]

두 복소수의 곱은 켤레 복소수 곱이므로,  
\[
ab = (-1)^2 + (\sqrt{2})^2 = 1 + 2 = 3.
\]

따라서 근의 공식을 통해도 두 근의 합은 \(-2\)이고, 곱은 \(3\)임을 확인할 수 있습니다.
