# 이차 방정식 근의 공식

### 💡 답변 (Assistant)
이차 방정식의 근의 공식은 다음과 같습니다.  

### **1. 이차 방정식의 일반적인 형태**  
\[
ax^2 + bx + c = 0
\]
여기서 \( a \), \( b \), \( c \)는 상수이며, \( a \neq 0 \)이어야 합니다.

### **2. 근의 공식**
이차 방정식 \( ax^2 + bx + c = 0 \)의 해(근)는 다음 공식으로 구할 수 있습니다.

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

여기서:
- \( \pm \) 기호는 두 개의 근을 의미합니다.  
- \( b^2 - 4ac \)를 **판별식(Discriminant, \( D \))**이라고 하며, 근의 개수와 성질을 결정합니다.  

### **3. 판별식에 따른 근의 성질**
판별식 \( D = b^2 - 4ac \)의 값에 따라 이차 방정식의 근이 달라집니다.
- **\( D > 0 \)**: 서로 다른 두 개의 실수 근을 가짐.
- **\( D = 0 \)**: 중근(서로 같은 두 개의 실수 근)을 가짐.
- **\( D < 0 \)**: 실수 근이 없으며, 두 개의 서로 다른 허수 근을 가짐.

### **4. 예제**
다음 이차 방정식을 풀어보겠습니다.  
\[
2x^2 - 3x + 1 = 0
\]
여기서 \( a = 2 \), \( b = -3 \), \( c = 1 \)입니다.

#### **1) 판별식 계산**
\[
D = (-3)^2 - 4(2)(1) = 9 - 8 = 1
\]
\( D > 0 \)이므로 서로 다른 두 개의 실수 근을 가집니다.

#### **2) 근의 공식 적용**
\[
x = \frac{-(-3) \pm \sqrt{1}}{2(2)}
\]
\[
x = \frac{3 \pm 1}{4}
\]

#### **3) 두 근 구하기**
\[
x_1 = \frac{3 + 1}{4} = \frac{4}{4} = 1
\]
\[
x_2 = \frac{3 - 1}{4} = \frac{2}{4} = \frac{1}{2}
\]

따라서, 방정식 \( 2x^2 - 3x + 1 = 0 \)의 두 근은 **\( x = 1 \)과 \( x = \frac{1}{2} \)**입니다.

### **1. 이차 방정식의 일반적인 형태**
이차 방정식은 다음과 같이 주어진다.

\[
ax^2 + bx + c = 0
\]

여기서 \( a, b, c \)는 상수이고, \( a \neq 0 \)이다.

---

### **2. 완전제곱식 만들기**
이차 방정식을 풀기 위해 좌변을 **완전제곱식**으로 변형한다.

#### **(1) 양변을 \( a \)로 나누기**
먼저 \( a \)로 나누어 계수를 단순화한다.

\[
x^2 + \frac{b}{a}x + \frac{c}{a} = 0
\]

#### **(2) 상수를 우변으로 이항**
\[
x^2 + \frac{b}{a}x = -\frac{c}{a}
\]

#### **(3) 완전제곱식을 만들기 위해 적절한 수 추가**
좌변을 완전제곱식으로 만들기 위해, **\( \left(\frac{b}{2a}\right)^2 \)**를 좌우 양변에 추가한다.

\[
x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = -\frac{c}{a} + \left(\frac{b}{2a}\right)^2
\]

좌변은 완전제곱식이 되므로 다음과 같이 쓸 수 있다.

\[
\left( x + \frac{b}{2a} \right)^2 = \frac{b^2}{4a^2} - \frac{c}{a}
\]

#### **(4) 우변 통분**
우변을 하나의 분수로 정리하면,

\[
\left( x + \frac{b}{2a} \right)^2 = \frac{b^2 - 4ac}{4a^2}
\]

---

### **3. 양변에 제곱근 적용**
양변의 제곱을 없애기 위해 제곱근을 취한다.

\[
x + \frac{b}{2a} = \pm \sqrt{\frac{b^2 - 4ac}{4a^2}}
\]

분모의 제곱근을 분리하면,

\[
x + \frac{b}{2a} = \pm \frac{\sqrt{b^2 - 4ac}}{2a}
\]

---

### **4. 최종 정리**
\( x \)에 대해 정리하면,

\[
x = -\frac{b}{2a} \pm \frac{\sqrt{b^2 - 4ac}}{2a}
\]

이를 하나로 합치면,

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

---

### **결론**
위 과정을 통해 **이차 방정식의 근의 공식**이 유도되었다.

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

이 공식은 모든 이차 방정식의 해를 구하는 데 사용될 수 있다.
