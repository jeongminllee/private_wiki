# Instructions vs Constraints

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
Which of the following criteria in the rubric are instructions (NOT constraints) - Select all that apply

The response must provide a realistic timeline for how long a new hire would need to learn new systems and start leading projects


The response should use bullet points where appropriate for clarity


The response should explain how these additional skills could help the team achieve its goals


None of the rubrics follow the guidelines.

### 💡 답변 (Assistant)
Based on the given options, **instructions** are guidelines that describe how the response should be presented, rather than placing limits or restrictions (constraints). Here's the breakdown:

### Options:
1. **The response must provide a realistic timeline for how long a new hire would need to learn new systems and start leading projects**  
   - **Constraint**: The use of "must" indicates a requirement that restricts the content.  

2. **The response should use bullet points where appropriate for clarity**  
   - **Instruction**: The use of "should" implies guidance on presentation, not a restriction on content.

3. **The response should explain how these additional skills could help the team achieve its goals**  
   - **Instruction**: Again, "should" suggests guidance rather than a limitation.  

4. **None of the rubrics follow the guidelines**  
   - This is unrelated to the classification of the criteria provided.  

### Correct Answer:
**2 and 3** are instructions, as they provide guidance on how the response should be formatted or what it should include, without imposing strict requirements.
