# 노션 타임 트래킹 캘린더 연동

> **카테고리**: `Reading - Personal & Misc`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
노션(Notion)에서 **타임 트래킹(Time Tracking) 페이지**를 **캘린더(Calendar)** 뷰와 연동하는 방법은 다음과 같은 절차를 따르면 됩니다. 아래는 타임 트래킹 데이터베이스를 캘린더로 시각화하고 연동하는 방법에 대한 안내입니다.

---

## ✅ 1. 기본 개념 정리

- **타임 트래킹 페이지**: 업무 시간, 시작/종료 시간, 소요 시간 등을 기록하는 DB (Database)
- **캘린더 뷰(Calendar View)**: 날짜 속성을 기준으로 한 Notion의 시각화 뷰
- **연동**이란 별도의 기능은 없지만, *하나의 DB 내에서 날짜 속성을 캘린더 뷰로 표현*하거나 *연결된 DB를 활용한 Linked DB*를 이용해 캘린더와 연결할 수 있음

---

## 🛠️ 2. 타임 트래킹 DB에 캘린더용 날짜 속성 추가

타임 트래킹 DB에서 캘린더와 연동하려면 반드시 `Date` 속성이 필요합니다.

### 예시 필드 구성:
| Task | Start Time | End Time | Date | Duration |
|------|------------|----------|------|----------|
| 글 작성 | 10:00 AM   | 12:00 PM | 2025-07-23 | 2시간 |

> **📌 Date 속성 필수:** 캘린더 뷰는 `Date` 속성이 있어야 가능합니다.

---

## 📅 3. 동일 DB에서 캘린더 뷰 추가하기

1. 타임 트래킹 DB 열기
2. 우측 상단 `+ Add a view` 클릭
3. `Calendar` 선택 → 원하는 이름 (예: Time Calendar)
4. `Date` 속성을 캘린더 기준으로 설정
5. 생성 완료

> 이렇게 하면 타임 트래킹 정보가 **캘린더 형식**으로 시각화됩니다.

---

## 🔁 4. 다른 캘린더 DB와 연동하고 싶다면? (Linked Database 사용)

다른 캘린더 DB에 타임 트래킹 내용을 반영하려면 **Linked Database** 기능을 사용하세요.

### 절차:

1. 새 페이지 또는 기존 캘린더 DB에서 `/linked` 입력 → `Create linked database` 선택
2. 타임 트래킹 DB 선택
3. 필터 추가: `Date is not empty`
4. 뷰 추가 → `Calendar` 형식 선택

이렇게 하면 타임 트래킹 DB의 정보를 **다른 페이지에서도 캘린더 형태로 보여줄 수 있습니다.**

---

## ✨ 팁: 자동 Duration 계산하는 방법

- `Formula` 속성 생성 후 아래 식 사용:
```notion
dateBetween(end, start, "minutes") / 60
```
→ 결과는 시간 단위 (예: 1.5시간)

---

## 🧩 Notion 캘린더 연동 외부툴 (선택사항)

- [Notion + Google Calendar Sync](https://notion-calendar.com) (자동 동기화는 외부 툴 필요)
- Zapier, Automate.io 등을 통해 자동화 가능 (예: 캘린더 이벤트 → 노션으로 기록)

## ✅ 요약

| 목적 | 방법 |
|------|------|
| 타임 트래킹 데이터를 캘린더로 보기 | 동일 DB에 캘린더 뷰 추가 |
| 타임 트래킹 DB를 다른 캘린더 페이지에 연동 | Linked Database + Calendar View |
| 시작/종료 시간으로 자동 소요 시간 계산 | Formula 필드로 계산 |
| 구글 캘린더와 연동 | 외부 서비스(Zapier, Notion Calendar 등) 사용 |
