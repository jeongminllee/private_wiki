## 1. 전체 자동화 구조 (권장 아키텍처)

가장 안정적인 구조는 아래 흐름입니다.

```
[책 목록 원본]
   ↓
[정형 데이터(CSV / JSON)]
   ↓
[Python 스크립트]
   ├─ Notion API (DB row 생성)
   ├─ Open Library / Google Books API (메타데이터)
   └─ 이미지 URL 처리(간접 링크)
```

**핵심 원칙**
- 크롤링 ❌ (교보·알라딘 직접 긁기 → 차단/법적 리스크)
- **공식 공개 API만 사용**
- 이미지·URL은 “참조 링크” 방식으로 처리

## 2. 1단계: 노션 데이터베이스 설계 (먼저 해야 할 일)

노션에서 **Database (Table)** 하나 생성 후, 아래 속성들을 정확히 맞추세요.

| 속성명 | Notion 타입 |
|------|-----------|
| title | Title |
| 저자 | Text |
| 카테고리 | Select |
| 중주제 | Text |
| 이미지 | URL |
| 책 URL | URL |

📌 **카테고리 Select 값**은 미리 고정

```
문학
소설

```

## 4. 3단계: 책 메타데이터 & 이미지 – 안전한 방법

### ❌ 피해야 할 방식
- 교보문고 / 알라딘 HTML 크롤링
- 직접 이미지 다운로드 후 업로드

### ✅ 권장 방식 (실무에서 가장 안전)

#### ① Open Library API (1순위)
- 무료
- ISBN 없어도 제목 기반 검색 가능
- 커버 이미지 제공

```
https://openlibrary.org/search.json?title=모비딕
```

커버 이미지 URL:
```
https://covers.openlibrary.org/b/olid/{OLID}-L.jpg
```

#### ② Google Books API (2순위)
- 검색 정확도 높음
- 이미지 링크 제공
- 일일 무료 쿼터 충분

## 5. 4단계: Notion API + Python 자동 등록

### (1) 준비물
- Notion Integration 생성
- Database ID 확보
- Integration Token 발급

### (2) Python 예시 코드 (핵심 구조)

```python
import csv
import requests

NOTION_TOKEN = "secret_xxx"
DATABASE_ID = "xxxx"

headers = {
    "Authorization": f"Bearer {NOTION_TOKEN}",
    "Content-Type": "application/json",
    "Notion-Version": "2022-06-28"
}

def create_page(title, author, category, image_url=None, book_url=None):
    data = {
        "parent": {"database_id": DATABASE_ID},
        "properties": {
            "title": {
                "title": [{"text": {"content": title}}]
            },
            "저자": {
                "rich_text": [{"text": {"content": author or ""}}]
            },
            "카테고리": {
                "select": {"name": category}
            },
            "이미지": {
                "url": image_url
            },
            "책 URL": {
                "url": book_url
            }
        }
    }

    requests.post(
        "https://api.notion.com/v1/pages",
        headers=headers,
        json=data
    )

with open("books.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        create_page(
            row["title"],
            row["author"],
            row["category"]
        )
```

📌 **이 상태로도 100권은 1~2분 내 등록 가능**

## 6. 이미지 & URL 처리 전략 (차단 회피 핵심)

### 이미지
- Notion에 **이미지 파일 업로드 ❌**
- **URL만 저장 ⭕**

추천 소스:
- Open Library cover URL
- Google Books `thumbnail`

### 책 URL
- 구매 링크 ❌
- 정보 페이지 ⭕  
예:
- Google Books 정보 페이지
- Open Library book page

# 📌 전체 작업 로드맵 (우선순위 기준)

## PHASE 0. 목표·제약 조건 명확화 (가장 먼저)
> **실수 방지 단계 – 절대 건너뛰면 안 됨**

### 목적
- 100권을 “한 번에” 등록
- 이후에도 **재사용 가능한 구조** 확보
- 이미지·URL 차단/저작권 리스크 제거

### 제약 조건 확정
- ❌ 교보·알라딘 직접 크롤링 금지
- ⭕ 공개 API(Open Library / Google Books)만 사용
- ⭕ 이미지 = URL 참조 방식
- ⭕ 중주제는 수동 입력

✔️ 이 단계에서 “자동화 범위”를 명확히 정해두는 것이 핵심

## PHASE 1. 노션 데이터베이스 스키마 설계 (최우선)
> **자동화의 80%는 여기서 결정됨**

### 해야 할 일
1. 노션 Database (Table) 생성
2. 속성 타입 고정

### 확정 스키마

| 속성명 | 타입 | 비고 |
|---|---|---|
| title | Title | 필수 |
| 저자 | Text | |
| 카테고리 | Select | **미리 옵션 생성 필수** |
| 중주제 | Text | 수동 입력 |
| 이미지 | URL | 외부 참조 |
| 책 URL | URL | 외부 참조 |

📌 **이 단계에서 스키마 변경 금지**  
→ 이후 단계 전부 이 구조를 기준으로 설계됨

---

## PHASE 2. 원본 도서 데이터 정규화 (중요)
> **자동화 입력값을 “기계가 먹을 수 있는 형태”로 변환**

### 해야 할 일
