# 자바 테이블 나이 오류

> **카테고리**: `CS - Java 프로그래밍`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2026-05-29

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
좋아요. 이 오류는 보통 **테이블에서 선택한 행의 “나이” 값이 비어 있는데, 그 값을 `int`로 변환하려고 해서** 발생합니다.

예를 들어 이런 코드가 있으면 오류가 납니다.

```java
int age = Integer.parseInt(table.getValueAt(row, 3).toString());
```

나이 칸이 비어 있으면 값이 `null`이거나 `""`일 수 있어서 다음 오류가 날 수 있습니다.

```java
NullPointerException
NumberFormatException
```

## 해결 방법 1: null / 빈 문자열 검사 후 처리

```java
int row = table.getSelectedRow();

if (row == -1) {
    return; // 선택된 행이 없으면 종료
}

Object ageObj = table.getValueAt(row, 3); // 3번 컬럼: 나이

int age = 0; // 기본값

if (ageObj != null && !ageObj.toString().trim().isEmpty()) {
    age = Integer.parseInt(ageObj.toString());
}

System.out.println("나이: " + age);
```

핵심은 이 부분입니다.

```java
if (ageObj != null && !ageObj.toString().trim().isEmpty())
```

즉, **나이 데이터가 있을 때만 숫자로 변환**합니다.

---

## 해결 방법 2: 나이가 비어 있으면 문자열 그대로 출력

나이를 꼭 `int`로 바꿀 필요가 없다면 이렇게 하는 게 더 안전합니다.

```java
Object ageObj = table.getValueAt(row, 3);

String age = "";

if (ageObj != null) {
    age = ageObj.toString();
}

System.out.println("나이: " + age);
```

이 방식은 나이가 비어 있어도 오류가 안 납니다.

## 더 깔끔하게 함수로 만들기

반복해서 써야 한다면 함수로 빼는 게 좋습니다.

```java
private String getCellValue(JTable table, int row, int col) {
    Object value = table.getValueAt(row, col);

    if (value == null) {
        return "";
    }

    return value.toString();
}
```

사용:

```java
String empNo = getCellValue(table, row, 0);
String name = getCellValue(table, row, 1);
String dept = getCellValue(table, row, 2);
String age = getCellValue(table, row, 3);
```

## 결론

현재 오류 제거의 핵심은 이것입니다.

```java
Object ageObj = table.getValueAt(row, 3);

if (ageObj != null && !ageObj.toString().trim().isEmpty()) {
    int age = Integer.parseInt(ageObj.toString());
}
```

나이처럼 비어 있을 수 있는 컬럼은 바로 `toString()` 하거나 `Integer.parseInt()` 하지 말고, 반드시 **null 체크 + 빈 문자열 체크**를 먼저 해야 합니다.

### ❓ 질문 (User)
자바에서 테이블 작업 중이야. 데이터가 {사번, 이름, 부서, 나이}인데 어떤 데이터는 나이가 비어있어. 이때 선택을 하니까 오류가 나더라고. 오류 제거하는 방법 알려줘.

### 💡 답변 (Assistant)
오류 원인은 **삭제 자체가 아니라, 삭제 후 JTable의 선택 상태가 해제되면서 `ListSelectionListener`가 다시 실행되기 때문**입니다.

삭제 버튼을 누르면 이 코드가 실행됩니다.

```java
dtm.removeRow(selectRow);
```

그런데 행이 삭제된 직후에는 선택된 행이 없어질 수 있습니다. 이때

```java
jt.getSelectedRow()
```

값이 `-1`이 됩니다.

그런데 선택 이벤트 쪽에서 바로 이렇게 쓰고 있습니다.

```java
txts[i].setText(jt.getValueAt(jt.getSelectedRow(), i).toString());
```

즉 실제로는 이렇게 실행되는 상황입니다.

```java
jt.getValueAt(-1, i)
```

그래서 오류가 납니다.

```java
ArrayIndexOutOfBoundsException: Index -1 out of bounds
```

## 해결 코드

`valueChanged()` 안에서 선택된 행이 없으면 바로 종료하면 됩니다.

```java
jt.getSelectionModel().addListSelectionListener(new ListSelectionListener() {
    @Override
    public void valueChanged(ListSelectionEvent e) {
        if (e.getValueIsAdjusting()) {
            return;
        }

        int selectedRow = jt.getSelectedRow();

        if (selectedRow == -1) {
            return;
        }

        for (int i = 0; i < txts.length; i++) {
            Object value = jt.getValueAt(selectedRow, i);

            if (value == null) {
                txts[i].setText("");
            } else {
                txts[i].setText(value.toString());
            }
        }
    }
});
```

이렇게 바꾸면 삭제 후 선택된 행이 없어져도 오류가 안 납니다.

## 핵심 정리

현재 문제 코드는 이 부분입니다.

```java
jt.getValueAt(jt.getSelectedRow(), i)
```

`getSelectedRow()`가 항상 정상 행 번호라고 생각하면 안 됩니다.

선택된 행이 없으면 JTable은 `-1`을 반환합니다.

그래서 JTable에서 선택된 행을 사용할 때는 항상 이렇게 확인하는 습관을 들이면 좋습니다.

```java
int row = jt.getSelectedRow();

if (row == -1) {
    return;
}
```

최종적으로는 `ListSelectionListener` 부분만 위 코드처럼 고치면 지금 오류는 해결됩니다.
