### 💡 답변 (Assistant)
문제  
Sam과 Quorra는 사이트들이 여러 개 있는 비밀 기지의 지도를 만들려고 합니다. 이 기지는 그리드 월드에 위치하며, 여러 (가상) 사이트들이 (가상) 경로로 서로 연결되어 있습니다. 비록 사이트의 개수(n)는 알고 있지만, 사이트 간의 연결 정보는 매우 부족합니다. 기지 내부에 있었던 여러 프로그램들이 사이트 간의 연결에 대한 일부 정보를 제공할 수 있으며, Sam과 Quorra는 이 정보를 모아 전체 그림을 완성하려고 합니다. 특히, 모든 사이트 간에 경로가 존재하는지, 즉 임의의 두 사이트 사이를 이동할 수 있는지 확인하고자 합니다.

목표는 주어진 연결 정보만으로 모든 사이트가 서로 연결되어 있는지를 결정하는 것입니다. 연결은 양방향이라고 가정합니다. 즉, 사이트 1과 사이트 2 사이에 연결이 있으면, 사이트 1에서 사이트 2로, 사이트 2에서 사이트 1로 이동할 수 있습니다.

입력  
테스트 케이스의 개수가 첫 줄에 주어집니다 (최대 50개). 그 후, 각 줄마다 하나의 테스트 케이스가 주어집니다. 각 테스트 케이스의 첫 번째 숫자는 사이트의 개수 n (최대 100)이며, 사이트들은 0부터 n-1까지 번호가 매겨져 있습니다. 두 번째 숫자는 사이트 간의 연결 개수 k (최대 200)입니다. 그 후, k 쌍의 숫자가 주어지며, 각각은 연결을 나타냅니다. 연결은 중복될 수 있고, 자기 자신으로의 연결(즉, 한 사이트에서 자기 자신으로의 연결)이 있을 수도 있습니다.

출력  
각 테스트 케이스마다 모든 사이트가 서로 연결되어 있는지 확인한 후, 그 결과에 따라 “Connected.” 또는 “Not connected.”를 출력합니다.

출력 형식  
정확한 출력 형식은 제출 시 언어를 Java로 설정하면 확인할 수 있습니다.

### ❓ 질문 (User)
문제
Sam and Quorra are trying to build a map of a secret base in the Grid world that contains a number of (virtual) sites interconnected by (virtual) pathways. Although they know the number of sites (n), their knowledge of interconnections between the sites is sparse. Several different programs that have been inside the base are able to give them some information about the connections between the sites, and Sam and Quorra need to put it together. In particular, they would like to make sure that they have enough information to know how to go from every site to every other site.

Your goal is to help them decide if a specified set of connections is enough to ensure that there is a path from every site to every other site. Assume that the connections are bi-directional, i.e., if we know that there is a connection between site 1 and site 2, then we can go from site 1 to site 2, and vice versa.

입력
The first line in the test data file contains the number of test cases (≤ 50). After that, each line contains a test case. The first number in each test case is the number of sites, n (≤ 100). The sites are numbered from 0 to n − 1. The second number is the number of connections between the sites, k (≤ 200). After that there are k pairs of numbers, one for each connection. The connections might repeat and further, there may be self-connections (i.e., a connection from a site to itself).

출력
For each test case, you are to check whether there is path from every site to every other site, and output “Connected.” or “Not connected.” accordingly.

출력 형식
정확한 출력 형식은 제출에서 언어를 Java로 설정하면 확인할 수 있다.

### 💡 답변 (Assistant)
아래는 DFS를 이용해서 모든 사이트가 연결되어 있는지 확인하는 파이썬 코드 예시입니다. 이 코드는 입력에서 각 테스트 케이스마다 DFS를 수행하여 방문한 그룹의 수가 1개인지 판별합니다.

```python
def dfs(node, group, adj, visited):
    visited[node] = group
    for neighbor in adj[node]:
        if visited[neighbor] == 0:
            dfs(neighbor, group, adj, visited)

# 입력 받기
T = int(input())
for _ in range(T):
    parts = list(map(int, input().split()))
    n, k = parts[0], parts[1]
    
    # 인접 리스트 생성 (각 사이트에 대한 연결 정보)
    adj = [[] for _ in range(n)]
    for i in range(k):
        a = parts[2 + 2*i]
        b = parts[2 + 2*i + 1]
        if a != b:  # 자기 자신으로의 연결은 무시
            adj[a].append(b)
            adj[b].append(a)
    
    # 방문 배열: 0은 미방문, 1부터 그룹 번호 부여
    visited = [0] * n
    group = 0
    for i in range(n):
        if visited[i] == 0:
            group += 1
            dfs(i, group, adj, visited)
    
    # 모든 사이트가 연결되어 있다면 그룹 수는 1이어야 함
    if group == 1:
        print("Connected.")
    else:
        print("Not connected.")
```

### 코드 설명

1. **DFS 함수**:  
   `dfs(node, group, adj, visited)` 함수는 현재 노드 `node`에서 시작하여 연결된 모든 노드를 `group` 번호로 표시합니다. 이미 방문한 노드는 건너뜁니다.

2. **입력 처리**:  
   - 첫 번째 줄에서 테스트 케이스의 수 `T`를 입력받습니다.  
   - 각 테스트 케이스마다 첫 두 숫자는 사이트의 개수 `n`과 연결의 개수 `k`입니다. 그 후 `k`쌍의 연결 정보가 주어집니다.

3. **인접 리스트 생성**:  
   각 사이트의 연결 정보를 저장하기 위해 인접 리스트(`adj`)를 사용합니다.

4. **방문 배열 및 그룹 분류**:  
   방문하지 않은 노드가 있으면 새로운 그룹 번호를 부여하며 DFS를 수행합니다.  
   모든 노드가 같은 그룹 번호(즉, 그룹이 1개)로 표시되면 모든 사이트가 연결되어 있다는 의미입니다.

5. **출력**:  
   그룹의 개수가 1이면 "Connected."를, 그렇지 않으면 "Not connected."를 출력합니다.

이 코드는 제시한 입력 예시에 대해 올바른 결과를 출력할 것입니다.
