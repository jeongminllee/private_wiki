# 구글 스프레드시트 이메일 연동

> **카테고리**: `CS - Java 프로그래밍`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
구글 스프레드 시트에 있는 내용과 구글 메일을 연동하는 Apps Script 코드를 작성해줘. 코드를 단계별로 작성해주고, 주석은 한국어로 작성해줘.

1행에는 칼럼들이 존재해. B1 셀에는 참석 여부에 대한 칼럼, D1에는 이메일 주소에 대한 칼럼이 작성되어 있어.
B2셀부터 모든 B열에 "참석합니다" 라고 답변한 사람들에게 D2 셀부터 존재하는 이메일 주소를 수신인으로 하여 행사 설명에 대한 이메일을 일괄적으로 발송하려고 해.

# 행사 설명 이메일 내용
"2025 Eco Week"에 신청해주셔서 감사합니다.
행사 내용에 대한 브로슈어를 전달 드립니다.
입장코드는 작성해주신 휴대전화 번호로 QR코드를 전달드리겠습니다.
25년 7월, 건강한 모습으로 뵙겠습니다.

### 💡 답변 (Assistant)
아래는 구글 스프레드시트와 구글 메일(Gmail)을 연동하여, 참석 여부가 `"참석합니다"`로 표시된 사람들에게 안내 이메일을 일괄 발송하는 Google Apps Script 코드입니다. **단계별로 설명**과 **한국어 주석**도 함께 제공합니다.

---

## ✅ 1단계: Apps Script 열기
1. 구글 스프레드시트를 엽니다.
2. 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.

---

## ✅ 2단계: 아래 코드를 붙여넣기

```javascript
function sendEcoWeekEmails() {
  // 현재 열려있는 스프레드시트를 가져옵니다.
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // 데이터의 마지막 행을 확인합니다.
  const lastRow = sheet.getLastRow();

  // B열 (참석 여부)과 D열 (이메일 주소)을 2행부터 마지막 행까지 가져옵니다.
  const attendanceData = sheet.getRange(2, 2, lastRow - 1).getValues(); // B열
  const emailData = sheet.getRange(2, 4, lastRow - 1).getValues(); // D열

  // 반복문을 돌면서 "참석합니다"라고 응답한 사람에게만 메일을 발송합니다.
  for (let i = 0; i < attendanceData.length; i++) {
    const response = attendanceData[i][0]; // 참석 여부
    const email = emailData[i][0];         // 이메일 주소

    // 응답이 "참석합니다"이고 이메일 주소가 유효할 경우
    if (response === "참석합니다" && email) {
      // 이메일 제목과 본문 작성
      const subject = "2025 Eco Week 행사 안내드립니다";
      const body = 
        "안녕하세요.\n\n" +
        "\"2025 Eco Week\"에 신청해주셔서 감사합니다.\n" +
        "행사 내용에 대한 브로슈어를 전달 드립니다.\n" +
        "입장코드는 작성해주신 휴대전화 번호로 QR코드를 전달드리겠습니다.\n\n" +
        "25년 7월, 건강한 모습으로 뵙겠습니다.\n\n" +
        "- 2025 Eco Week 운영팀 드림";

      // 메일 발송
      GmailApp.sendEmail(email, subject, body);
    }
  }
}
```

---

## ✅ 3단계: 실행 및 권한 허용
1. 상단 ▶️ 실행 버튼 클릭 (`sendEcoWeekEmails` 함수 선택되어 있어야 함)
2. 처음 실행 시 Google 계정 권한 요청이 나타납니다. **"허용"**을 눌러 승인해 주세요.

## 🔄 참고 팁
- **메일 중복 발송 방지**를 원하면 시트에 "발송 완료" 여부를 저장하는 로직도 추가할 수 있습니다.
- QR코드와 같은 첨부파일은 `MailApp.sendEmail()`의 첨부 옵션으로 추가할 수 있습니다.

### ❓ 질문 (User)

이 내용과 구글 캘린더를 연동하는 Apps Script 코드를 작성해줘.
스프레드 시트에 데이터값은 A2부터 D9까지 존재하고, 1행의 데이터는 모두 칼럼 값이야.
첨부한 데이터 값을 참고하여 정확한 Apps Script 코드를 작성해줘.

# 1, 2 행의 데이터 값 예시
미팅명  미팅 날짜  미팅 시간  목적 및 주요 논의 사항
대외협력팀 미팅  2024-11-13  10:00~11:00  협력 범위 및 후원 형태 논의, 역할 분담

### 💡 답변 (Assistant)
좋습니다. 아래는 구글 스프레드시트의 미팅 일정을 **구글 캘린더에 자동 등록**해주는 Google Apps Script 코드입니다. A2:D9의 데이터를 참고해 정확하게 작동하도록 작성했으며, **한국어 주석**을 포함해 단계별로 설명드릴게요.

## ✅ 1단계: Apps Script 열기

1. 구글 스프레드시트를 열고
2. 상단 메뉴 **[확장 프로그램] → [Apps Script]** 클릭

## ✅ 2단계: 코드 붙여넣기

```javascript
function createMeetingsInCalendar() {
  // 스프레드시트의 활성 시트를 불러옵니다.
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  
  // A2:D9 범위의 데이터를 가져옵니다 (총 8행)
  const dataRange = sheet.getRange("A2:D9").getValues();

  // 캘린더 ID를 지정합니다. 기본 캘린더 사용 시 아래 함수로 가져올 수 있습니다.
  const calendar = CalendarApp.getDefaultCalendar();

  // 각 행을 순회하면서 캘린더 이벤트를 생성합니다.
  for (let i = 0; i < dataRange.length; i++) {
    const row = dataRange[i];

    const title = row[0]; // 미팅명
    const dateStr = row[1]; // 미팅 날짜 (예: "2024-11-13")
    const timeStr = row[2]; // 미팅 시간 (예: "10:00~11:00")
    const description = row[3]; // 목적 및 주요 논의 사항

    // 미팅 시간을 시작과 종료로 나눕니다.
    const [startTimeStr, endTimeStr] = timeStr.split("~");

    // Date 객체로 변환 (주의: 월은 0부터 시작하므로 -1 필요)
    const [year, month, day] = dateStr.split("-").map(Number);
    const [startHour, startMin] = startTimeStr.split(":").map(Number);
    const [endHour, endMin] = endTimeStr.split(":").map(Number);

    const startDate = new Date(year, month - 1, day, startHour, startMin);
    const endDate = new Date(year, month - 1, day, endHour, endMin);

    // 이미 동일한 제목과 시간의 이벤트가 있는지 중복 체크 (선택사항)
    const existingEvents = calendar.getEvents(startDate, endDate, {search: title});
    if (existingEvents.length === 0) {
      // 이벤트 생성
      calendar.createEvent(title, startDate, endDate, {
        description: description
      });
    }
  }
}
```

---

## ✅ 3단계: 실행 및 권한 허용

1. 상단의 ▶️ 실행 버튼 클릭 (`createMeetingsInCalendar` 함수 선택)
2. 처음 실행 시, **Google Calendar 접근 권한**을 요청하면 **허용**합니다.

---

## ✅ 결과

- 스프레드시트 A2:D9에 있는 모든 미팅이 Google Calendar에 자동 등록됩니다.
- 중복 생성 방지를 위해 **같은 시간에 같은 제목이 있는지** 검사 후 등록합니다.

---

### ✅ 참고 확장 기능
- "등록 완료" 여부를 스프레드시트에 체크하고 싶으면 추가 열(E열)에 상태값 저장도 가능합니다.
- 미팅에 **참석자 이메일 초대**를 넣고 싶다면 `calendar.createEvent(title, start, end, {guests: "이메일주소"})` 식으로 확장 가능합니다.
