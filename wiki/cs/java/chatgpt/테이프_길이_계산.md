### ❓ 질문 (User)
문제
Bocchi the Builder has just finished constructing her latest project: a pathway consisting of two rows of white equilateral triangular tiles. However, at the last moment, disaster struck, and she accidentally spilled black paint on some of the tiles! Now, she must purchase warning tape to block off the wet areas. Can you help her determine how many meters of tape she needs?

The first triangle will always point upwards, and any pair of adjacent tiles (that is, tiles that share a common side) will point in opposite directions. Every triangle has a side length of 1 meter.

입력
The first line will consist of one integer, 
$C$, representing the number of columns.

The next two lines will each consist of 
$C$ integers separated by spaces. Each integer represents the colour of a tile in the room, with 1 indicating that the tile is black and 0 indicating that the tile is white.

출력
Output a single integer representing the length of the tape Bocchi must purchase in meters.

제한
 
$1 \le C \le 200\,000$ 
예제 입력 1 
5
1 0 1 0 1
0 0 0 0 0
예제 출력 1 
9

### 💡 답변 (Assistant)
이 문제는 "검은 타일" 주변의 경계선을 계산하여 테이프의 총 길이를 구하는 문제입니다. 문제의 해결을 위해 다음 접근 방식을 사용할 수 있습니다:

### 접근 방식:
1. **입력 처리**:
   - 두 개의 타일 배열을 입력받아 각 행의 데이터를 저장합니다.

2. **경계 계산**:
   - 검은 타일(값이 1인 타일)의 각 변을 살펴보고, 인접한 타일이 흰색(값이 0)인 경우 경계로 간주합니다.
   - 각 타일의 위치와 방향에 따라 이웃 타일을 확인하여 경계를 계산합니다.

3. **결과 출력**:
   - 모든 검은 타일의 경계를 합산하여 결과를 출력합니다.

### 파이썬 코드
```python
def calculate_tape_length(C, top_row, bottom_row):
    # 초기화
    total_tape = 0

    # 각 타일을 순회하며 경계를 계산
    for col in range(C):
        # 위쪽 행 타일
        if top_row[col] == 1:
            # 위쪽 변
            total_tape += 1
            # 왼쪽 변 (첫 번째 열 제외)
            if col == 0 or bottom_row[col - 1] == 0:
                total_tape += 1
            # 오른쪽 변
            if col == C - 1 or bottom_row[col] == 0:
                total_tape += 1

        # 아래쪽 행 타일
        if bottom_row[col] == 1:
            # 아래쪽 변
            total_tape += 1
            # 왼쪽 변 (첫 번째 열 제외)
            if col == 0 or top_row[col] == 0:
                total_tape += 1
            # 오른쪽 변
            if col == C - 1 or top_row[col + 1] == 0:
                total_tape += 1

    return total_tape

# 입력 처리
C = int(input())
top_row = list(map(int, input().split()))
bottom_row = list(map(int, input().split()))

# 결과 계산 및 출력
result = calculate_tape_length(C, top_row, bottom_row)
print(result)
```

			}
		}

				total += 3;
			}
		}
		
		for (int a = 0; a < n-1; a++) {

				total -= 2;
			}
			if (row2[a] == 1 && row2[a+1] == 1) {
				total -= 2;
			}
		}
		
		
		for (int a = 0; a < n; a+= 2) {
			if (row1[a] == 1 && row2[a] == 1) {

			}
		}

### 💡 답변 (Assistant)
아래는 주어진 Java 코드를 Python으로 변환한 버전입니다. 주어진 코드의 논리를 그대로 따라 작성했으며, 입력 및 출력 방식도 Python에 맞게 수정했습니다.

### Python 코드
```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    n = int(data[0])  # 첫 번째 입력: 열의 개수
    
    row1 = list(map(int, data[1:n+1]))  # 첫 번째 행의 타일 정보
    row2 = list(map(int, data[n+1:]))  # 두 번째 행의 타일 정보
    
    total = 0
    
    # 첫 번째 행의 타일 경계 길이
    for a in range(n):
        if row1[a] == 1:
            total += 3
    
    # 두 번째 행의 타일 경계 길이
    for a in range(n):
        if row2[a] == 1:
            total += 3
    
    # 경계 겹침 처리
    for a in range(n - 1):
        if row1[a] == 1 and row2[a + 1] == 1:
            total -= 2
        if row2[a] == 1 and row2[a + 1] == 1:
            total -= 2
    
    # 특정 위치의 경계 겹침 처리
    for a in range(0, n, 2):
        if row1[a] == 1 and row2[a] == 1:
            total -= 2
    
    print(total)

if __name__ == "__main__":
    main()
```

### 코드 설명
1. **입력 처리**:
   - `sys.stdin.read`를 사용하여 한 번에 입력을 읽고, 이를 `split`하여 각 값을 리스트로 저장합니다.
   - 첫 번째 값은 열의 개수 `n`, 그 뒤로는 두 행의 타일 정보입니다.

2. **타일 경계 계산**:
   - 각 행의 모든 타일에 대해 검은 타일(`1`)일 때 기본적으로 3씩 더합니다.

3. **경계 겹침 처리**:
   - **같은 열에서**: 특정 조건에 따라 겹치는 경계 부분(공유되는 경계선)을 `-2`씩 빼줍니다.
   - **대각선 겹침**: 홀수 열에 대해 위쪽 행과 아래쪽 행에서 대각선으로 겹치는 경우를 처리합니다.

4. **출력**:
   - 최종 계산된 `total` 값을 출력합니다.
