### 💡 답변 (Assistant)
네, 'Year' 열을 2011년부터 최근 연도까지 필터링하려면 다음과 같이 할 수 있습니다. 먼저 데이터프레임을 읽은 후 'Year' 열을 조건에 맞게 필터링하고 나서 피벗 테이블을 생성합니다.

```python
import pandas as pd

# 데이터 불러오기
df = pd.read_csv("https://raw.githubusercontent.com/mwaskom/seaborn-data/master/healthexp.csv")

# 'Year' 열을 2011년 이상의 값만 필터링
df_filtered = df[df['Year'] >= 2011]

# 피벗 테이블 생성
df_pivoted = df_filtered.pivot(index='Year', columns='Country', values='Life_Expectancy')

# 결과 출력
print(df_pivoted)
```

이렇게 하면 'Year' 열이 2011년 이상의 값만을 포함하는 데이터프레임을 생성하고, 그 데이터프레임을 기반으로 피벗 테이블을 만들게 됩니다.
