# 최대 유지 날짜 계산

> **카테고리**: `CS - Python 프로그래밍`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
You have a diet plan for the next 
$N$ days (numbered from 
$1$ to 
$N$). During day 
$i$, you need to drink exactly 
$P_i$ mL of milk. Alternatively, you can consume a biscuit instead, as a replacement for milk on that day.

Currently, you only have 
$M$ mL of milk and 
$K$ biscuits. If there is not enough milk to drink on a day and you run out of biscuits, then your diet plan stops.

Determine the maximum number of days you can maintain your diet plan.

입력
The first line consists of three integers 
$N$ 
$M$ 
$K$ (
$1 ≤ N ≤ 100$; 
$0 ≤ M, K ≤ 100$).

The next line consists of 
$N$ integers 
$P_i$ (
$1 ≤ P_i ≤ 100$).

출력
Output a single integer representing the maximum number of days you can maintain your diet plan. 
파이썬 코드로 풀어줘

### 💡 답변 (Assistant)
아래는 주어진 문제를 해결하는 Python 코드입니다. 

이 코드는 각 날짜를 순차적으로 확인하며, 필요한 우유가 있는 경우 우유를 소비하고, 그렇지 않으면 비스킷을 소비하여 최대한 많은 날짜 동안 계획을 유지하려고 합니다. 

```python
def max_days_on_diet(N, M, K, P):
    # N: 총 일수
    # M: 초기 우유 양
    # K: 초기 비스킷 개수
    # P: 매일 필요한 우유량 리스트

    days = 0  # 유지한 날짜 수
    for milk_needed in P:
        if M >= milk_needed:
            # 우유가 충분하면 우유를 소비
            M -= milk_needed
            days += 1
        elif K > 0:
            # 우유가 부족하면 비스킷을 소비
            K -= 1
            days += 1
        else:
            # 우유도 없고 비스킷도 없으면 멈춤
            break

    return days

# 입력 처리
N, M, K = map(int, input().split())  # 첫 번째 줄 입력
P = list(map(int, input().split()))  # 두 번째 줄 입력

# 결과 출력
print(max_days_on_diet(N, M, K, P))
```

### 작동 방식
1. 각 날짜마다 `milk_needed`를 확인합니다.
2. 만약 우유(`M`)가 충분하면 해당 양을 차감하고 날짜 수를 증가시킵니다.
3. 우유가 부족하지만 비스킷(`K`)이 있다면 비스킷을 하나 소비합니다.
4. 우유와 비스킷 둘 다 사용할 수 없으면 반복을 중단합니다.
5. 최종적으로 가능한 최대 날짜를 반환합니다.

### 입력 예시
```
5 10 2
3 8 5 2 4
```

### 출력 예시
```
4
```

### 설명
- 첫째 날: 3mL 소비 (우유 남음: 7)
- 둘째 날: 8mL 소비 (우유 남음: 0)
- 셋째 날: 5mL 필요, 비스킷 소비 (비스킷 남음: 1)
- 넷째 날: 2mL 필요, 비스킷 소비 (비스킷 남음: 0)
- 다섯째 날: 4mL 필요, 우유와 비스킷 모두 부족 -> 중단

따라서 최대 4일 동안 유지할 수 있습니다.
