# 세로로 문자 읽기

> **카테고리**: `CS - Python 프로그래밍`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 문제는 Python에서 2차원 배열처럼 처리하면 쉽게 해결할 수 있습니다. 핵심 아이디어는 **열(column) 기준으로 한 글자씩 세로로 읽되, 해당 행(row)에 문자가 존재할 때만 읽는 것**입니다.

예제와 함께 설명드릴게요.

---

### ✅ 예시 입력
```python
arr = [
    "ABCDE",
    "abc",
    "012345",
    "!@#$%",
    "xyz"
]
```

### ✅ 목표 출력
한 글자씩 세로로 읽어서 이어붙인 결과:
```
Aa0!x
Bb1@y
Cc2#z
D345
E
```
결과적으로 문자열 `"Aa0!xBb1@yCc2#zD345E"` 를 만들어내는 것이 목표입니다.

---

### ✅ 해결 방법
1. 최대 문장 길이를 구합니다.
2. 인덱스를 기준으로 0부터 최대 길이까지 순회하면서,
3. 각 문장의 해당 인덱스 위치에 문자가 있는지 확인하고 결과에 추가합니다.

---

### ✅ 코드 구현
```python
arr = [
    "ABCDE",
    "abc",
    "012345",
    "!@#$%",
    "xyz"
]

result = ''
max_len = max(len(row) for row in arr)

for i in range(max_len):
    for row in arr:
        if i < len(row):  # 현재 인덱스 i에 해당 문자가 존재하는 경우만 추가
            result += row[i]

print(result)
```

---

### ✅ 출력 결과
```
Aa0!xBb1@yCc2#zD345E
```

---

### ✅ 요약
- `zip()`은 길이가 다를 경우 짧은 쪽 기준으로 잘리므로 이 문제에는 적합하지 않음
- 대신 `max_len`을 기준으로 반복하고, 인덱스 체크 후 문자 추가

필요하다면 이걸 함수로 만들어드릴 수도 있어요!
