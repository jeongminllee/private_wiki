## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
요구사항을 정확히 보면:

- 파일 이름 패턴: `ch01.py`, `ch02.py`, `ch03.py` …
- 여러 개를 **순서대로 자동 생성**
- 필요하면 시작 번호 / 개수 조절 가능

아래는 가장 실무적으로 깔끔한 코드다.

---

## ✅ 기본 버전 (연속 파일 생성)

```python
# 생성할 파일 개수
count = 10

# 시작 번호
start = 1

for i in range(start, start + count):
    filename = f"ch{i:02d}.py"  # 01, 02 형식 유지

    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {filename}\n")
    
    print(f"{filename} 생성 완료")
```

---

## ✅ 설명 (핵심 포인트)

- `f"ch{i:02d}.py"`
  → `02d` = 두 자리 숫자 (01, 02, 03 …)

- `open(filename, "w")`
  → 파일 없으면 생성
  → 있으면 덮어쓰기

---

## ✅ 파일 내용까지 템플릿 넣고 싶다면

```python
count = 5
start = 1

template = """\
# {filename}

def main():
    print("{filename} 실행")

if __name__ == "__main__":
    main()
"""

for i in range(start, start + count):
    filename = f"ch{i:02d}.py"

    with open(filename, "w", encoding="utf-8") as f:
        f.write(template.format(filename=filename))

    print(f"{filename} 생성 완료")
```

---

## ✅ 기존 파일 덮어쓰기 방지 버전 (실무 추천)

```python
import os

count = 5
start = 1

for i in range(start, start + count):
    filename = f"ch{i:02d}.py"

    if os.path.exists(filename):
        print(f"{filename} 이미 존재 → 건너뜀")
        continue

    with open(filename, "w", encoding="utf-8") as f:
        f.write(f"# {filename}\n")

    print(f"{filename} 생성 완료")
```
