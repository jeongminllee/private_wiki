# 로봇 이동 시뮬레이션 분석

> **카테고리**: `CS - Python 프로그래밍`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
좋습니다! 주어진 코드는 문제의 요구사항에 따라 **로봇이 벽, 장애물, 방문한 지역을 피해 미리 지정된 방향 순서에 따라 반복 이동한 뒤**, **더 이상 이동할 수 없을 때 위치를 출력**하는 로직입니다. 아래에 각 부분을 단계적으로 나누어 동작을 설명해드릴게요.

---

## ✅ 1. 입력 및 초기화

```python
R, C = map(int, input().split())
arr = [[0] * C for _ in range(R)]
```

- `R, C`: 방의 행과 열 크기입니다. (3 ≤ R, C ≤ 1000)
- `arr`: `R x C` 크기의 방을 나타내는 2차원 배열입니다.
  - 값 `0`: 이동 가능한 공간
  - 값 `1`: 장애물이 있거나 이미 방문한 칸

---

## ✅ 2. 장애물 표시

```python
k = int(input())
for _ in range(k):
    br, bc = map(int, input().split())
    arr[br][bc] = 1
```

- 장애물의 개수 `k`만큼 반복하며 `(br, bc)`에 해당하는 위치를 `1`로 설정하여 **이동 불가능한 지역으로 표시**합니다.

---

## ✅ 3. 로봇 시작 위치 지정

```python
sr, sc = map(int, input().split())
arr[sr][sc] = 1
```

- 로봇의 시작 위치를 `sr, sc`로 받고, 그 위치는 방문한 것으로 간주하여 `1`로 설정합니다.

---

## ✅ 4. 방향 설정

```python
direction = list(map(int, input().split()))
```

- 총 4개의 방향이 입력되며, 각 방향은 다음과 같이 매핑됩니다:
  - 1: 상 (-1, 0)
  - 2: 하 (+1, 0)
  - 3: 좌 (0, -1)
  - 4: 우 (0, +1)

```python
dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]
```

- 위의 `dr`, `dc`는 각 방향 번호(1~4)를 인덱스로 사용할 수 있도록 미리 정의된 **이동 벡터**입니다.

---

## ✅ 5. 로봇 이동 시뮬레이션

```python
r, c = sr, sc

while True:
    moved = False
```

- 현재 로봇의 위치를 `r, c`에 저장하고, 루프를 돌며 이동을 반복합니다.
- `moved`: 이번 루프에서 한 번이라도 이동했는지를 나타냄 (이동하지 못하면 종료 조건)

---

## ✅ 6. 방향 순서대로 이동 시도

```python
for d in direction:
    while True:
        nr, nc = r + dr[d - 1], c + dc[d - 1]
```

- 각 방향 `d`에 대해 **일직선으로 갈 수 있는 만큼 이동**합니다.
- `d - 1`은 방향 인덱스를 0-based로 맞춰주는 역할입니다.

```python
if 0 <= nr < R and 0 <= nc < C and arr[nr][nc] == 0:
    moved = True
    arr[nr][nc] = 1
    r, c = nr, nc
else:
    break
```

- 이동 조건:
  - 방을 벗어나지 않음
  - 장애물 또는 방문했던 지역이 아님
- 조건을 만족하면 이동하고 방문 처리 (`1`)
- 조건을 만족하지 않으면 해당 방향 이동 중단 → 다음 방향으로 전환

---

## ✅ 7. 이동 불가 → 종료

```python
if not moved:
    break
```

- 네 방향 모두에서 **더 이상 이동할 수 없다면 루프를 종료**합니다.

---

## ✅ 8. 결과 출력

```python
print(r, c)
```

- 로봇이 **마지막으로 도달한 위치**를 출력합니다.

---

## 🔄 예제 흐름 예시

입력:
```
3 3
1
1 0
1 1
1 2 3 4
```

방:
```
. . .
x o .
. . .
```

이동 방향 순서: 상 → 하 → 좌 → 우

이동 과정:
1. (1,1) → (0,1) (위)
2. (0,1) → (0,0) (왼쪽)
3. (0,0) → 이동 불가 → 종료

출력: `0 0`

---

## 🔍 요약

- 방향 순서대로 한 방향 끝까지 가고, 막히면 다음 방향으로.
- 한 번이라도 이동하면 다시 첫 방향부터 반복.
- 네 방향 다 이동할 수 없으면 종료.
- **장애물, 방문한 지역, 벽은 모두 통과 불가**로 간주.

이 코드는 시뮬레이션 문제에서 구조적으로도 간단명료하며, 입력 제약(R, C ≤ 1000, k ≤ 1000) 내에서 효율적으로 작동합니다.

---

### ❓ 질문 (User)
문제
해빈이는 로봇을 좋아한다. 로봇을 가지고 놀던 해빈이는 로봇에게 계속해서 명령을 내려 움직이는 대신 이동할 방향을 미리 지정하여 로봇이 알아서 움직이도록 하였다.  이 로봇은 다음과 같은 규칙을 가지고 움직인다.

로봇은 사용자가 지정한 방향을 일직선으로 움직인다.
이동 중 벽이나 방문한 지역, 장애물을 만날 경우 로봇은 사용자가 지정한 다음 방향으로 움직인다.
사용자가 지정한 다음 방향이 없다면 맨 처음 방향으로 돌아가서 위의 과정을 반복한다.
로봇이 움직일 수 없을 경우 동작을 멈춘다. 
* * *

x 0 *

* * *

<초기 상태>

* 1 *

x 0 *

* * *

<1번 째 이동>

2 1 *

x 0 *

* * *

<2번 째 이동>

방 크기가 3* 3이고

장애물이 (1, 0)에 있으며

시작 위치는 (1,1)

해빈이가 지정한 방향이 (상, 하, 좌, 우) 일 때,

로봇의 마지막 위치는 (0, 0)이다.

2 번째 이동이 끝난 후, 로봇은 움직일 수 없으므로 동작을 멈춘다.

로봇은 (1, 1) → (0, 1) → (0, 0)로 이동하였다.

입력으로 방의 크기와 장애물의 개수, 각 장애물들의 위치, 로봇의 시작 위치, 이동 방향의 순서가 주어졌을 때 로봇이 멈추는 위치를 출력하시오. 위치 (0, 0)은 왼쪽 위를 가리키며 방의 크기가 R * C일 때 오른쪽 아래 위치는 (R - 1, C - 1)이 된다. (R은 세로의 크기를 C은 가로의 크기를 말한다.)

입력
첫 번째 줄에는 방의 크기 R, C(3 ≤ R, C ≤ 1,000)가 입력된다. 두 번째 줄에는 장애물의 개수 k(0 ≤ k ≤ 1,000)가 입력된다. 다음 k개의 줄에는 각 장애물 위치 br(0 ≤ br ≤ R – 1), bc(0 ≤ bc ≤ C - 1)가 주어진다. 그 다음 순서대로 로봇의 시작 위치 sr(0 ≤ sr ≤ R – 1), sc(0 ≤ sc ≤ C - 1)와 이동 방향의 순서(총 4개가 입력되는데 1은 위 방향, 2은 아래 방향, 3은 왼쪽 방향, 4는 오른쪽 방향을 나타낸다)가 한 줄씩 입력된다. 로봇의 시작위치에 장애물이 있는 경우는 없다.

출력
로봇의 마지막 위치 r, c를 출력한다.

예제 입력 1 
3 3
1
1 0
1 1
1 2 3 4
예제 출력 1 
0 0

```
# 방 크기
R, C = map(int, input().split())

# 방 세팅
arr = [[0] * C for _ in range(R)]

# 장애물
k = int(input())
for _ in range(k) :
    br, bc = map(int, input().split())
    arr[br][bc] = 1 # 장애물 초기 설정

# 로봇 시작 위치
sr, sc = map(int, input().split())
arr[sr][sc] = 1

# 방향 입력
direction = list(map(int, input().split()))

# 방향 설정
dr = [-1, 1, 0, 0]
dc = [0, 0, -1, 1]

# 로봇 현재 위치
r, c = sr, sc

# 로봇이 더 이상 움직이지 않을 때 까지 반복
while True :
    moved = False   # 이번 턴에 이동 여부 확인

    for d in direction :    # 이동 시도
        while True :
            nr, nc = r + dr[d - 1], c + dc[d - 1]   # 다음 방향 이동 시도

            # 방문 가능한지
            if 0 <= nr < R and 0 <= nc < C and arr[nr][nc] == 0 :
                moved = True
                arr[nr][nc] = 1
                r, c = nr, nc

            # 만약 불가능하면 중단
            else :
                break

    # 만약 한 번도 이동하지 못했다면 종료
    if not moved :
        break

# 최종 위치 출력
print(r, c)
```
