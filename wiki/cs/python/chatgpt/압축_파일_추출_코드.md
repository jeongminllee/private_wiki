### 💡 답변 (Assistant)
아래는 Python을 사용하여 폴더 내의 ZIP 파일을 추출하는 코드 예제입니다. 이 코드는 폴더 구조를 고려하여 작성되었습니다.

```python
import os
import zipfile

# 추출 대상 폴더 경로 설정
main_folder = "메인 폴더"

# main_folder 내의 모든 파일 및 하위 폴더 순회
for root, dirs, files in os.walk(main_folder):
    for file in files:
        if file.endswith(".zip"):
            zip_file_path = os.path.join(root, file)
            extract_folder = os.path.splitext(zip_file_path)[0]  # 확장자를 제외한 이름을 추출

            # 추출 폴더가 존재하지 않으면 생성
            if not os.path.exists(extract_folder):
                os.makedirs(extract_folder)

            # ZIP 파일을 추출
            with zipfile.ZipFile(zip_file_path, 'r') as zip_ref:
                zip_ref.extractall(extract_folder)

            print(f'{zip_file_path} 파일을 추출했습니다.')
```

이 코드는 `main_folder`로 지정된 폴더 내에서 모든 하위 폴더를 순회하면서 확장자가 `.zip`인 파일을 찾고, 각 ZIP 파일을 해당하는 폴더에 추출합니다. 폴더가 존재하지 않으면 폴더를 생성합니다. 추출된 파일은 원래의 ZIP 파일과 동일한 폴더에 저장됩니다.

이 코드를 사용하려면 `main_folder`를 실제 메인 폴더 경로로 변경해야 합니다. 코드를 실행하기 전에 필요한 패키지인 `os`와 `zipfile`를 import하는지 확인하십시오.

이 코드는 주어진 폴더 구조에서 각 하위 폴더를 순회하면서 확장자가 `.zip`인 파일을 찾고, 각 ZIP 파일을 해당하는 폴더에 추출합니다. 추출된 파일은 원래의 ZIP 파일과 동일한 폴더에 저장됩니다.

### 💡 답변 (Assistant)
쓰고 남은 ZIP 파일을 삭제하려면 다음과 같이 코드를 수정할 수 있습니다. 아래 코드는 ZIP 파일 추출 후 해당 ZIP 파일을 삭제합니다.

```python
import os
import zipfile

# 추출 대상 폴더 경로 설정
main_folder = "메인폴더"

# main_folder 내의 모든 폴더 순회
for root, dirs, files in os.walk(main_folder):
    for dir in dirs:
        folder_path = os.path.join(root, dir)
        for subdir_root, _, sub_files in os.walk(folder_path):
            for sub_file in sub_files:
                if sub_file.endswith(".zip"):
                    zip_file_path = os.path.join(subdir_root, sub_file)
                    extract_folder = os.path.splitext(zip_file_path)[0]  # 확장자를 제외한 이름을 추출

                    # 추출 폴더가 존재하지 않으면 생성
                    if not os.path.exists(extract_folder):
                        os.makedirs(extract_folder)

                    # ZIP 파일을 추출
                    with zipfile.ZipFile(zip_file_path, 'r') as zip_ref:
                        zip_ref.extractall(extract_folder)

                    print(f'{zip_file_path} 파일을 추출했습니다.')

                    # 추출이 완료된 후 ZIP 파일 삭제
                    os.remove(zip_file_path)
                    print(f'{zip_file_path} 파일을 삭제했습니다.')
```

이 코드는 ZIP 파일을 추출한 후에 해당 ZIP 파일을 `os.remove()` 함수를 사용하여 삭제합니다. 코드를 실행하면 ZIP 파일이 추출되고 그 후 삭제됩니다.

주의: ZIP 파일 삭제는 반복적으로 실행하면 해당 ZIP 파일이 완전히 삭제되므로 주의해야 합니다.
