# 제거 및 선택 함수

> **카테고리**: `CS - Python 프로그래밍`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
def solution(code):
    return "".join(code.split("1"))[::2] or "EMPTY"
풀이해줘

### 💡 답변 (Assistant)
이 코드는 주어진 문자열 `code`에서 "1"을 제거하고 짝수 번째 문자들만 선택하여 반환하는 함수입니다. "1"을 제거하는 부분은 `"".join(code.split("1"))`를 통해 이루어지고, 그 다음 `[::2]`를 사용하여 짝수 번째 문자를 선택합니다. 마지막으로, 문자열이 비어있다면 "EMPTY"를 반환합니다.

여기서 각 부분을 자세히 설명하겠습니다:

1. `code.split("1")`: 주어진 문자열 `code`를 "1"을 기준으로 분리합니다. 이렇게 하면 "1"이 제거된 문자열의 리스트가 생성됩니다.

2. `"".join(...)`: 분리된 문자열들을 다시 합쳐 하나의 문자열로 만듭니다. "1"이 제거된 문자열이 생성됩니다.

3. `[::2]`: 생성된 문자열에서 짝수 번째 문자만 선택합니다. Python에서 문자열의 인덱스는 0부터 시작하므로, 짝수 번째 문자를 선택하려면 `[::2]`를 사용합니다.

4. `or "EMPTY"`: 위의 단계에서 생성된 문자열이 비어있다면, 즉 모든 "1"이 제거되고 아무 문자도 남지 않았다면 "EMPTY"를 반환합니다.

예를 들어, `solution("Hello1World1")`를 호출하면 "HelloWorld"를 반환하고, `solution("111")`를 호출하면 "EMPTY"를 반환합니다.
