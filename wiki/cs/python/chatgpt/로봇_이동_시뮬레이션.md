## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
로봇
 
시간 제한	메모리 제한	제출	정답	맞힌 사람	정답 비율
1 초	256 MB	3067	1085	909	35.164%
문제
해빈이는 로봇을 좋아한다. 로봇을 가지고 놀던 해빈이는 로봇에게 계속해서 명령을 내려 움직이는 대신 이동할 방향을 미리 지정하여 로봇이 알아서 움직이도록 하였다.  이 로봇은 다음과 같은 규칙을 가지고 움직인다.

로봇은 사용자가 지정한 방향을 일직선으로 움직인다.
이동 중 벽이나 방문한 지역, 장애물을 만날 경우 로봇은 사용자가 지정한 다음 방향으로 움직인다.
사용자가 지정한 다음 방향이 없다면 맨 처음 방향으로 돌아가서 위의 과정을 반복한다.
로봇이 움직일 수 없을 경우 동작을 멈춘다. 
* * *

x 0 *

* * *

<초기 상태>

* 1 *

x 0 *

* * *

<1번 째 이동>

2 1 *

x 0 *

* * *

<2번 째 이동>

방 크기가 3* 3이고

장애물이 (1, 0)에 있으며

시작 위치는 (1,1)

해빈이가 지정한 방향이 (상, 하, 좌, 우) 일 때,

로봇의 마지막 위치는 (0, 0)이다.

2 번째 이동이 끝난 후, 로봇은 움직일 수 없으므로 동작을 멈춘다.

로봇은 (1, 1) → (0, 1) → (0, 0)로 이동하였다.

입력으로 방의 크기와 장애물의 개수, 각 장애물들의 위치, 로봇의 시작 위치, 이동 방향의 순서가 주어졌을 때 로봇이 멈추는 위치를 출력하시오. 위치 (0, 0)은 왼쪽 위를 가리키며 방의 크기가 R * C일 때 오른쪽 아래 위치는 (R - 1, C - 1)이 된다. (R은 세로의 크기를 C은 가로의 크기를 말한다.)

입력
첫 번째 줄에는 방의 크기 R, C(3 ≤ R, C ≤ 1,000)가 입력된다. 두 번째 줄에는 장애물의 개수 k(0 ≤ k ≤ 1,000)가 입력된다. 다음 k개의 줄에는 각 장애물 위치 br(0 ≤ br ≤ R – 1), bc(0 ≤ bc ≤ C - 1)가 주어진다. 그 다음 순서대로 로봇의 시작 위치 sr(0 ≤ sr ≤ R – 1), sc(0 ≤ sc ≤ C - 1)와 이동 방향의 순서(총 4개가 입력되는데 1은 위 방향, 2은 아래 방향, 3은 왼쪽 방향, 4는 오른쪽 방향을 나타낸다)가 한 줄씩 입력된다. 로봇의 시작위치에 장애물이 있는 경우는 없다.

출력
로봇의 마지막 위치 r, c를 출력한다.

예제 입력 1 
3 3
1
1 0
1 1
1 2 3 4
예제 출력 1 
0 0

### 💡 답변 (Assistant)
이 문제는 로봇이 주어진 이동 규칙에 따라 이동을 반복한 뒤, **더 이상 이동할 수 없는 시점에서의 위치**를 출력하는 시뮬레이션 문제입니다.

---

## ✅ 접근 방식 요약

1. **입력 받기**:
   - 방의 크기와 장애물 좌표, 시작 좌표, 방향 순서를 입력 받습니다.
2. **방 상태 표현**:
   - 장애물은 `-1`, 방문한 곳은 `True`로 체크.
3. **로봇 이동**:
   - 지정된 방향 순서에 따라 한 방향으로 끝까지 이동하다가,
   - 이동 불가 시 다음 방향을 시도하고,
   - 모든 방향이 막히면 종료.

---

## ✅ 방향 정의

| 방향 번호 | 의미 | 방향 벡터 (dr, dc) |
|-----------|------|--------------------|
| 1         | 위   | (-1, 0)             |
| 2         | 아래 | (1, 0)              |
| 3         | 왼쪽 | (0, -1)             |
| 4         | 오른쪽 | (0, 1)             |

---

## ✅ 코드 구현

```python
import sys
input = sys.stdin.readline

R, C = map(int, input().split())
K = int(input())

# 방 생성
room = [[0] * C for _ in range(R)]

# 장애물
for _ in range(K):
    br, bc = map(int, input().split())
    room[br][bc] = -1  # 장애물

# 시작 위치
sr, sc = map(int, input().split())

# 방향 순서 (인덱스를 0부터 시작하게 맞춤)
dirs = list(map(int, input().split()))
dirs = [d - 1 for d in dirs]

# 상, 하, 좌, 우
drs = [-1, 1, 0, 0]
dcs = [0, 0, -1, 1]

# 방문 표시
visited = [[False] * C for _ in range(R)]
r, c = sr, sc
visited[r][c] = True

while True:
    moved = False
    for d in dirs:
        nr, nc = r + drs[d], c + dcs[d]
        # 이동 가능한 동안 반복
        while 0 <= nr < R and 0 <= nc < C and not visited[nr][nc] and room[nr][nc] != -1:
            r, c = nr, nc
            visited[r][c] = True
            nr += drs[d]
            nc += dcs[d]
            moved = True
        if moved:
            break  # 새로운 위치에서 다시 방향 반복
    if not moved:
        break

print(r, c)
```
