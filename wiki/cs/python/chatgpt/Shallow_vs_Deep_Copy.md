# Shallow vs Deep Copy

> **카테고리**: `CS - Python 프로그래밍`

파이썬에서 '깊은 복사와 얕은 복사' 에 대해서 공부하고 있는 중이야

### 💡 답변 (Assistant)
깊은 복사와 얕은 복사에 대해 실습해볼 수 있는 파이썬 코드를 작성해줄게요.

### 얕은 복사 (Shallow Copy)
얕은 복사는 객체의 참조만 복사하기 때문에, 복사된 객체는 원본 객체와 같은 객체를 가리키게 됩니다. 즉, 하나의 객체를 여러 이름으로 부르는 것과 같습니다.

### 깊은 복사 (Deep Copy)
깊은 복사는 객체의 참조뿐만 아니라, 객체가 참조하고 있는 모든 객체들까지도 재귀적으로 복사합니다. 따라서 복사된 객체는 원본 객체와는 별개의 객체가 됩니다.

아래는 얕은 복사와 깊은 복사를 실습할 수 있는 예제 코드입니다:

```python
import copy

# 원본 리스트 생성
original_list = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 얕은 복사
shallow_copied_list = copy.copy(original_list)

# 깊은 복사
deep_copied_list = copy.deepcopy(original_list)

print("원본 리스트:")
print(original_list)

print("\n얕은 복사 리스트:")
print(shallow_copied_list)

print("\n깊은 복사 리스트:")
print(deep_copied_list)

# 원본 리스트의 요소 변경
original_list[0][0] = 99

print("\n원본 리스트 수정 후:")
print(original_list)

print("\n얕은 복사 리스트 수정 후:")
print(shallow_copied_list)

print("\n깊은 복사 리스트 수정 후:")
print(deep_copied_list)
```

### 설명
1. `original_list`라는 리스트를 생성합니다.
2. `copy.copy()`를 사용하여 `original_list`의 얕은 복사를 만듭니다.
3. `copy.deepcopy()`를 사용하여 `original_list`의 깊은 복사를 만듭니다.
4. `original_list`의 요소를 변경합니다.
5. 원본 리스트, 얕은 복사 리스트, 깊은 복사 리스트를 출력하여 변경 사항을 확인합니다.

### 실행 결과
```
원본 리스트:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

얕은 복사 리스트:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

깊은 복사 리스트:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

원본 리스트 수정 후:
[[99, 2, 3], [4, 5, 6], [7, 8, 9]]

얕은 복사 리스트 수정 후:
[[99, 2, 3], [4, 5, 6], [7, 8, 9]]

깊은 복사 리스트 수정 후:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

위 결과에서 알 수 있듯이, 원본 리스트를 수정했을 때 얕은 복사 리스트는 영향을 받지만, 깊은 복사 리스트는 영향을 받지 않습니다. 이는 얕은 복사는 같은 객체를 참조하고 있기 때문에 원본 객체의 변경 사항을 그대로 반영하지만, 깊은 복사는 완전히 별개의 객체이기 때문에 영향을 받지 않기 때문입니다.

### ❓ 질문 (User)
그러면 얕은 복사는 참조만 복사하기 때문에 해당의 메모리 주소는 두 변수가 동일한 메모리 주소를 공유할 것이고 깊은 복사는 별개의 객체이기 때문에 아예 새로운 객체라고 봐야 하잖아.
파이썬에서 할당된 메모리 주소를 볼 수 있는 메소드가 있을까?

### 💡 답변 (Assistant)
네, 파이썬에서 객체의 메모리 주소를 확인할 수 있는 메소드가 있습니다. `id()` 함수를 사용하면 객체의 메모리 주소를 확인할 수 있습니다.

아래 예제 코드에서는 얕은 복사와 깊은 복사의 메모리 주소를 확인해 보겠습니다:

```python
import copy

# 원본 리스트 생성
original_list = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 얕은 복사
shallow_copied_list = copy.copy(original_list)

# 깊은 복사
deep_copied_list = copy.deepcopy(original_list)

# 메모리 주소 출력
print("원본 리스트의 메모리 주소:", id(original_list))
print("얕은 복사 리스트의 메모리 주소:", id(shallow_copied_list))
print("깊은 복사 리스트의 메모리 주소:", id(deep_copied_list))

# 원본 리스트의 각 요소들의 메모리 주소 출력
print("\n원본 리스트 요소들의 메모리 주소:")
for i, elem in enumerate(original_list):
    print(f"원본 리스트[{i}]의 메모리 주소:", id(elem))

# 얕은 복사 리스트의 각 요소들의 메모리 주소 출력
print("\n얕은 복사 리스트 요소들의 메모리 주소:")
for i, elem in enumerate(shallow_copied_list):
    print(f"얕은 복사 리스트[{i}]의 메모리 주소:", id(elem))

# 깊은 복사 리스트의 각 요소들의 메모리 주소 출력
print("\n깊은 복사 리스트 요소들의 메모리 주소:")
for i, elem in enumerate(deep_copied_list):
    print(f"깊은 복사 리스트[{i}]의 메모리 주소:", id(elem))
```

### 코드 설명
1. `original_list`라는 리스트를 생성합니다.
2. `copy.copy()`를 사용하여 `original_list`의 얕은 복사를 만듭니다.
3. `copy.deepcopy()`를 사용하여 `original_list`의 깊은 복사를 만듭니다.
4. `id()` 함수를 사용하여 각 리스트와 리스트 내 요소들의 메모리 주소를 출력합니다.

### 예상 결과
원본 리스트와 얕은 복사 리스트의 메모리 주소는 다르지만, 리스트 내 요소들의 메모리 주소는 동일합니다. 반면, 깊은 복사 리스트와 그 요소들의 메모리 주소는 모두 원본과 다릅니다.

```

원본 리스트 요소들의 메모리 주소:
원본 리스트[0]의 메모리 주소: 140246415184896
원본 리스트[1]의 메모리 주소: 140246415185024

얕은 복사 리스트[0]의 메모리 주소: 140246415184896
얕은 복사 리스트[1]의 메모리 주소: 140246415185024
얕은 복사 리스트[2]의 메모리 주소: 140246415185152
```

위의 결과에서 원본 리스트와 얕은 복사 리스트의 요소들이 같은 메모리 주소를 공유하고 있다는 것을 확인할 수 있습니다. 반면 깊은 복사 리스트는 원본 리스트와 완전히 별개의 메모리 주소를 가지고 있습니다.
