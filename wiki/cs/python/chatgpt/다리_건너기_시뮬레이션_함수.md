# 다리 건너기 시뮬레이션 함수

> **카테고리**: `CS - Python 프로그래밍`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
from collections import deque

def solution(bridge_length, weight, truck_weights):
    answer = 0
    bridge = deque([0] * bridge_length)
    truck_weights = deque(truck_weights)
    
    currentWeight = 0
    
    while len(truck_weights) != 0 :
        answer += 1
        
        currentWeight -= bridge.popleft()
        
        if currentWeight + truck_weights[0] <= weight :
            currentWeight += truck_weights[0]
            bridge.append(truck_weights.popleft())
        else :
            bridge.append(0)
            
    answer += bridge_length
            
    return answer

### 💡 답변 (Assistant)
이 코드는 주어진 조건에 따라 트럭이 다리를 건너는데 필요한 시간을 계산하는 Python 함수를 구현한 것입니다. 함수 `solution`은 세 개의 매개변수를 사용합니다:

1. `bridge_length`: 다리의 길이 (트럭이 몇 대까지 동시에 다리를 건널 수 있는지).
2. `weight`: 다리가 버틸 수 있는 최대 하중.
3. `truck_weights`: 다리를 건너려는 트럭들의 무게가 순서대로 담긴 리스트.

코드의 주요 로직은 다음과 같습니다:

1. `answer`를 0으로 초기화하고, `bridge`라는 길이가 `bridge_length`인 데크(deque)를 생성합니다. 데크를 사용하여 다리의 상태를 표현하며, 초기에는 모든 원소가 0으로 초기화되어 있습니다.
2. `truck_weights`도 데크로 변환하여 트럭이 다리에 진입하는 순서대로 처리할 수 있도록 합니다.
3. `currentWeight` 변수를 사용하여 현재 다리 위에 있는 트럭들의 총 무게를 추적합니다.
4. 반복문을 통해 트럭이 다리를 건너는 시뮬레이션을 수행합니다. 다음을 반복합니다:
   - 시간(초)을 1 증가시킵니다.
   - `bridge`의 맨 앞 원소(가장 먼저 다리에서 나가는 트럭의 무게)를 `currentWeight`에서 빼주고, 다리에서 나간 트럭을 데크에서 제거합니다.
   - 다리에 새로운 트럭이 진입 가능한지를 확인합니다. 다리 위에 있는 트럭의 무게와 새로운 트럭의 무게를 합한 값이 `weight` 이하일 경우, 새로운 트럭을 다리에 진입시키고, `currentWeight`와 `bridge`에 추가합니다. 그렇지 않으면 0을 다리에 추가하여 트럭이 진입하지 않도록 합니다.
5. 반복문을 종료하면, 모든 트럭이 다리를 건넜으므로, `answer`에 `bridge_length`를 더해주어 시뮬레이션 종료 시간을 계산합니다.

코드는 주어진 조건에 따라 트럭이 다리를 건너는 과정을 모의하여 걸리는 시간을 계산하는데 사용됩니다.
