# 메시지 읽지 않은 사람

> **카테고리**: `CS - Python 프로그래밍`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 문제는 **메시지를 누가 읽지 않았는지를 추론**하는 시뮬레이션 문제입니다. 조건은 다음과 같습니다:

---

### ✅ 핵심 조건 요약

- A부터 사전 순서대로 총 N명.
- K개의 메시지 중 Q번째 메시지를 **읽지 않은 사람을 추론**.
- "A"는 항상 모든 메시지를 읽음.
- 누군가가 **메시지를 보냈거나 읽었다면**, 그 시점 이전까지의 메시지는 모두 읽었다고 간주.
- 각 메시지마다: 안 읽은 사람 수 `R`, 송신자 `P` 주어짐.

---

## 🧠 접근 전략

우리는 **Q번째 메시지를 기준**으로, 누가 이 메시지를 **읽었을 수도 있고**, **읽지 않았을 수도 있는지**를 추론해야 합니다.

---

### 1. 상태 추적

- `last_action[i]` : i번째 사람이 마지막으로 메시지를 보냈거나 읽은 시점 (인덱스) 기록
- `unread_count[i]`: i번째 메시지를 읽지 않은 사람 수
- 메시지를 보낸 사람은 그 시점까지의 메시지를 모두 읽은 것으로 간주
- 메시지를 읽지 않은 사람은 메시지를 보낸 시점 이후에 아직 읽지 않은 사람

---

## 🧩 풀이 순서 요약

1. N명 구성: A, B, ..., Z 중 N명
2. 각 메시지를 순차적으로 보면서 각 사람의 **최종 읽은 시점** 기록
3. Q번째 메시지를 기준으로, **Q번째 메시지를 읽었을 수도 있는 사람들** 제거
4. 남은 사람이 후보가 됨
5. Q번째 메시지에서 주어진 "읽지 않은 사람 수"와 남은 후보 수가 같다면 그들을 출력

---

## ✅ 코드 구현 (Python)

```python
N, K, Q = map(int, input().split())
messages = []
for _ in range(K):
    r, p = input().split()
    messages.append((int(r), p))

# 사람 목록
people = [chr(ord('A') + i) for i in range(N)]

# 각 사람의 마지막 읽은 시점 (0-based index)
last_read = {person: -1 for person in people}
last_read['A'] = K  # A는 항상 모든 메시지를 읽음

# 각 메시지마다 송신자 기준으로 읽은 시간 갱신
for i in range(K):
    r, sender = messages[i]
    last_read[sender] = i

# Q번째 메시지를 읽지 않았을 가능성이 있는 사람 후보
q_idx = Q - 1
r_q, _ = messages[q_idx]

# Q번째 메시지를 보낸 사람도 읽었음
# A는 항상 읽음

# 후보자 = Q번째 메시지 보낸 시점 이후에도 읽지 않은 사람
candidates = []
for person in people:
    if last_read[person] < q_idx:
        candidates.append(person)

# A는 항상 읽으므로 제외
if 'A' in candidates:
    candidates.remove('A')

# 만약 후보 수 == 읽지 않은 사람 수와 일치하면 출력
if len(candidates) == r_q:
    print(' '.join(candidates))
else:
    print(-1)
```

## ✅ 예제 실행

입력:
```
5 6 4
1 A
2 A
2 A
3 A
3 B
3 A
```

Q = 4번째 메시지를 기준으로
- 읽지 않은 사람 수 = 3
- A는 항상 읽음
- 메시지 0~3까지 송신자는 모두 A (A는 항상 읽음)
- B, C, D, E 중에서 메시지 4 이전에 읽은 적 있는 사람은 B (메시지 4 송신자) → 메시지 4 보냈으니 0~3은 읽은 것
- 따라서 읽지 않았을 가능성 있는 사람: C, D, E

출력:
```
C D E
```

### ❓ 질문 (User)
문제
OAKAK TALK에는 신기한 기능이 있다. 바로 메시지 옆에 아직 안 읽은 사람의 수를 표시해주는 기능이다. 하지만 이 기능은 읽지 않은 사람의 수만 표시해줄 뿐, 메시지를 읽지 않은 사람이 누구인지는 표시해주지 않는다. 따라서 이 기능으로 메시지를 몇 명이 읽었는지는 알 수 있지만, 누가 읽었는지는 알 수 없다. 하지만 특정한 조건을 만족한다면, 우리는 메시지를 읽지 않은 사람을 유추해낼 수 있다.

그 조건은 다음과 같다. N명이 있는 OAKAK TALK방이 있다. 그리고 그 방에는 K개의 메시지가 있다. 각각의 메시지는 해당 메시지의 송신자와 읽지 않은 사람의 수에 대한 정보를 담고 있다. 만약 어떤 시점에 메시지를 읽거나 보냈다면, 그 시점 이전에 수신된 메시지는 모두 읽은 것으로 처리된다.

Q번째 메시지를 읽지 않은 사람을 유추 가능한대로 모두 구해보자! 사람의 이름은 편의상 A, B, C, …, Z라고 하며, N명의 이름은 A부터 사전 순서대로 N개의 알파벳이 부여된다. “나”의 이름은 A이고 “나”는 항상 모든 메시지를 읽는다.

입력
첫째 줄에 OAKAK TALK방에 있는 사람 수 N과 총 메시지의 개수 K, 정보를 알고 싶은 메시지의 번호 Q가 주어진다. (1 ≤ N ≤ 26, 1 ≤ K ≤ 10,000, 1 ≤ Q ≤ K) 둘째 줄부터 K개의 줄에 걸쳐 메시지를 읽지 않은 사람의 수 R과 그 메시지 송신자의 이름 P가 하나의 공백을 사이에 두고 주어진다. 메시지를 읽지 않은 사람의 수는 항상 이전 메시지를 읽지 않은 사람의 수보다 크거나 같고, 모순되는 입력은 없음이 보장된다.

출력
메시지를 읽지 않았을 가능성이 있는 모든 사람의 이름을 사전 순서대로 하나의 공백을 사이에 두고 출력한다. 모든 사람이 메시지를 읽어 출력할 이름이 없는 경우에는 –1을 출력한다.

예제 입력 1 
5 6 4
1 A
2 A
2 A
3 A
3 B
3 A
예제 출력 1 
C D E
