## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
C언어에서
Printf(“%x”, 32)
를 0x20 으로 적어냈는데 틀린거겠지…?

### 💡 답변 (Assistant)
결론부터 정확히 짚자면 **틀린 답입니다.**

### 이유
```c
printf("%x", 32);
```
이 코드는 **정수 32를 16진수 형태로 출력**합니다.

- 32 (10진수) → 16진수로 변환 → `20`
- `%x`는 **"0x" 접두사 없이 순수한 16진수 값만 출력**합니다.

👉 따라서 실제 출력 결과는:
```
20
```

---

### 왜 `0x20`이 틀렸냐?
- `0x20`은 **C에서 사용하는 "16진수 리터럴 표기법"**
- 하지만 `%x`는 **출력 포맷**이라서 `"0x"`를 자동으로 붙이지 않습니다.

---

### 만약 `0x20`으로 출력하고 싶다면
```c
printf("0x%x", 32);
```
이렇게 직접 붙여줘야 합니다.

---

### 정리 (시험 포인트)
| 코드 | 출력 |
|------|------|
| `printf("%x", 32);` | `20` |
| `printf("%#x", 32);` | `0x20` |
| `printf("0x%x", 32);` | `0x20` |

---

이건 시험에서 정말 자주 낚이는 포인트입니다.  
👉 **"%x는 접두사 안 붙는다"** 이거 하나만 확실히 기억해두면 됩니다.

---

## 📌 C언어 포매팅 문제 (106.00)

### 문제 형태
```c
#include <stdio.h>

int main() {
    printf("%d.00", 106);
    return 0;
}
```

---

## ✅ 정답
👉 **106.00**

---

## 🎯 왜 이런 문제가 나오냐
이건 “자료형 + 포맷 문자열 이해” 확인 문제다.

- `%d` → 정수 출력
- 뒤에 `.00` → 그냥 문자열 그대로 붙음

즉 내부적으로는:
```text
"106" + ".00" = "106.00"
```

---

## ❗ 헷갈리는 포인트
많이들 이렇게 착각한다:

- `%f` 써야 106.00 나오는 거 아닌가?
→ ❌ 아님 (그건 float 출력일 때)

여기서는 그냥:
👉 **정수 출력 + 문자열 붙이기**
