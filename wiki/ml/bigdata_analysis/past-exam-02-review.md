# 제2회 빅데이터 분석기사 필기 기출문제 복기 대시보드

이 문서는 빅데이터 분석기사 필기 제2회 기출문제를 1번부터 순차적으로 복기하며 핵심 이론, 함정 선지 분석, 빈출 암기 족보를 정리한 스터디 노트입니다.

## 📌 [01번] 분석 성숙도 평가 항목 구분

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 마스터플랜 $\rightarrow$ 분석 성숙도 vs 준비도
- **핵심 의도**: CMMI 기반 분석 성숙도 평가 3대 부문과 준비도 6대 영역을 명확히 구분하는지 평가.

### 🎯 정답
**③ 법, 제도 (속하지 않음)**

### 📌 정답인 이유
- **분석 성숙도(Maturity) 3대 평가 부문**: **비즈니스**, **조직·역량**, **IT 부문(자원)** (※ '법·제도'는 성숙도 평가 부문에 포함되지 않음)
- **성숙도 발전 4단계**: 도입(Introduction) $\rightarrow$ 활용(Growth) $\rightarrow$ 확산(Expansion) $\rightarrow$ 최적화(Optimization)

### 📚 출제위원 시크릿 족보
- **분석 준비도 6대 진단 축**: 분석 업무 파악, 인력/조직, 분석 기법, 분석 데이터, 분석 문화, IT 인프라
- **준비도 $\times$ 성숙도 4분면**:
  - 준비형: 준비도 $\uparrow$, 성숙도 $\downarrow$
  - 정착형: 준비도 $\downarrow$, 성숙도 $\uparrow$
  - 도입형: 준비도 $\downarrow$, 성숙도 $\downarrow$
  - 확산형: 준비도 $\uparrow$, 성숙도 $\uparrow$

## 📌 [02번] 데이터 거버넌스(Data Governance) 정의

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 체계
- **핵심 의도**: 전사 차원의 데이터 정책, 표준화, 조직 및 책임 체계를 구축하는 프레임워크 정의 파악.

### 🎯 정답
**④ 데이터 거버넌스 (Data Governance)**

### 📌 정답인 이유
- **데이터 거버넌스**: 전사 차원의 모든 데이터에 대해 정책/지침, 표준화 운영 조직 및 책임 등의 표준화된 관리 체계를 수립하고 운영하는 총체적 프레임워크.
- **거버넌스 3대 구성 요소**: **원칙(Principles)**, **조직(Organization)**, **프로세스(Process)**.
- **주요 관리 대상**: 마스터 데이터 관리(MDM), 메타데이터(Data Dictionary), 데이터 품질(Data Quality), 생명주기 관리.

### 🔎 오답 선지 분석
1. **BCP (Business Continuity Planning)**: 재난 시 업무 연속성 유지 계획.
2. **ERP (Enterprise Resource Planning)**: 전사적 자원 관리 시스템.
3. **KPI / MBO**: 핵심 성과 지표 / 목표 관리 경영 방식.

## 📌 [03번] 머신러닝 지도학습 / 비지도학습 구분

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 머신러닝 학습방법 $\rightarrow$ 지도학습/비지도학습 구분
- **핵심 의도**: 정답 레이블(Target/Label) 유무에 따른 분류 및 회귀의 학습 유형 식별.

### 🎯 정답
**② 지도학습 (Supervised Learning)**

### 📌 정답인 이유
- 지도학습은 정답값(Label, Target $Y$)이 존재하는 학습 방식.
- **분류(Classification)**: 범주형 값 예측 (Yes/No, 합격/불합격)
- **회귀(Regression)**: 연속형 수치 예측 (집값, 매출액, 온도)

### 🔎 오답 선지 분석
1. **비지도학습**: 정답 없음, 데이터 내부 구조 탐색 (군집분석, 연관분석, 차원축소 PCA).
2. **강화학습**: 상태(State) $\rightarrow$ 행동(Action) $\rightarrow$ 보상(Reward)을 최대화하는 정책 학습.
3. **준지도학습**: 소량의 라벨 데이터 + 대량의 비라벨 데이터 결합 (의사 라벨링 / Pseudo-labeling).

### 🧠 빅분기 암기 팁
- **“지분회 / 비군연”**: 지도학습 = 분류 + 회귀 / 비지도학습 = 군집 + 연관
- **⚠️ 1타 강사 함정 주의**: **로지스틱 '회귀'는 회귀가 아니라 '분류' 모델!**

## 📌 [04번] AI, 머신러닝, 딥러닝의 관계와 특징

### ✅ 문제 분석
- **출제 파트**: 제1과목 / 제3과목 기초 $\rightarrow$ AI / ML / DL 포함관계 및 모델 특성
- **핵심 의도**: $DL \subset ML \subset AI$ 포함관계와 인공신경망 기반 딥러닝의 핵심 특성(인간 뇌 신경망 모방, Feature 자동 학습) 파악.

### 🎯 정답
**④ 머신러닝: 딥러닝보다 인간의 사고방식과 더 유사한 기술 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **포함관계**: 인공지능(AI) $\supset$ 머신러닝(ML) $\supset$ 딥러닝(DL)
- 딥러닝은 인간 뇌의 뉴런(Neuron)과 시냅스(Synapse) 구조에서 착안한 **인공신경망(ANN)**을 다층으로 쌓은 기술이므로, 머신러닝보다 인간의 정보처리 구조와 더 유사함.

### 🔎 선지 정밀 분석
1. **인공지능(AI)**: 인간의 지능적 행동(학습, 추론, 판단)을 모방하는 소프트웨어 기술.
2. **머신러닝(ML)**: 명시적 프로그래밍 없이(Rule-based X), 데이터로부터 패턴/규칙을 스스로 학습.
3. **딥러닝(DL)**: 다층 신경망 기반으로 대규모 데이터에서 계층적 특성을 자동 추출 및 학습.
4. **머신러닝 vs 딥러닝**: 머신러닝은 수동 특성 공학(Feature Engineering) 비중이 높은 반면, 딥러닝은 Feature를 자동으로 추출함.

### 🧠 빅분기 암기 팁
- **“인 $\rightarrow$ 머 $\rightarrow$ 딥”**: 인공지능 $\supset$ 머신러닝 $\supset$ 딥러닝
- **“딥 = 뇌”**: 딥러닝은 다층 신경망을 통해 인간 뇌 정보처리 구조를 모방.

## 📌 [05번] 개인정보보호법상 동의 없이 처리 가능한 예외 사례

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 법제도 $\rightarrow$ 개인정보보호법 제15조(개인정보의 수집·이용)
- **핵심 의도**: 정보주체의 동의 없이 수집·이용 가능한 법적 예외 요건과 과도한 사생활 침해(상시 모니터링)의 한계 구분.

### 🎯 정답
**③ 회사가 업무 효율성을 높이기 위해 임직원의 업무 처리 내역과 인터넷 접속 기록을 모니터링하는 시스템을 설치하는 경우 (동의 없이 불가 $\rightarrow$ 오답이므로 정답)**

### 📌 정답인 이유
- **개인정보처리자의 정당한 이익 요건**: 처리자의 정당한 이익이 정보주체의 권리보다 명백하게 우선해야 함 ($처리자의 정당한 이익 > 정보주체의 권리$).
- 단순한 '업무 효율성' 목적으로 직원의 인터넷 접속 기록 및 업무 내역을 상시 모니터링하는 것은 사생활 침해 소지가 매우 크므로 동의 없는 처리로 인정되지 않음.

### 🔎 선지 정밀 분석
1. **대학교 주차 관리 목적 차량 소유자 번호 조회**: 정당한 이익 및 시설 관리 목적상 필요한 최소한의 범위 내 처리.
2. **보험 계약 체결을 위한 사고이력/가입여부 수집**: 정보주체와의 **계약 체결 및 이행**을 위한 불가피한 처리.
3. **화재 상황에서 자녀 구조를 위한 부모 연락처 수집**: 급박한 **생명·신체·재산의 이익**을 위한 긴급 처리.

### 📚 출제위원 시크릿 족보
- **개인정보 동의 없는 수집·이용 6대 예외 사유 (개인정보보호법 제15조 제1항)**:
  1. 법률에 특별한 규정이 있거나 법령상 의무 준수를 위해 불가피한 경우
  2. 공공기관이 법령 등에서 정하는 소관 업무를 수행하기 위해 불가피한 경우
  3. 정보주체와의 **계약의 체결 및 이행**을 위하여 불가피하게 필요한 경우
  4. 명백히 정보주체 또는 제3자의 급박한 **생명, 신체, 재산의 이익**을 위하여 필요한 경우
  5. 개인정보처리자의 **정당한 이익**을 달성하려는 경우 (명백하게 정보주체의 권리보다 우선하는 경우에 한함)
  6. 공중위생 등 공공의 안전과 안녕을 위하여 긴급히 필요한 경우

### 🧠 빅분기 암기 팁
- **“법·공·계 / 생·정·공”**:
  - **법**적 의무, **공**공기관 소관업무, **계**약 체결/이행
  - **생**명/신체 긴급보호, **정**당한 이익, **공**공 안전
- **⚠️ 1타 강사 판정 공식**: **"업무 효율화 / 직원 인터넷 감시" $\rightarrow$ 과도한 사생활 침해로 동의 필수!**

## 📌 [06번] 개인정보의 추가적 이용·제공 범위 및 민감정보 규제

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 및 법제도 $\rightarrow$ 당초 수집 목적과의 합리적 관련성 & 민감정보/고유식별정보 처리 제한
- **핵심 의도**: 당초 수집 목적과 합리적으로 관련된 범위 내에서의 추가적 이용·제공 가능 여부 판단 및 민감정보(건강/병력)의 엄격한 처리 규제 식별.

### 🎯 정답
**③ 병원 진료 시 수집한 주민등록번호를 이용해 다른 병원에 병력을 조회하는 경우 (추가 이용 불가 $\rightarrow$ 오답 선지로서 정답)**

### 📌 정답인 이유
- **합리적 관련성의 한계**: 당초 수집 목적과 합리적 관련성이 인정되는 범위에서만 추가 이용이 가능하나, 타 병원 병력 조회는 목적 외이자 정보주체의 권리를 침해.
- **민감정보 규제**: **병력, 질병, 진료기록 등 건강정보는 민감정보**에 해당하여 일반 개인정보보다 훨씬 엄격한 별도 동의/법적 근거가 필수적임.

### 🔎 선지 정밀 분석
1. **LP 음반 카탈로그 고객에게 CD/DVD 음악 카탈로그 발송**: 당초 목적(음악 상품 안내)과 매체 확장 수준의 합리적 관련성 인정 (⭕ 가능).
2. **약국에서 잘못 가져간 의약품 주인에게 연락**: 사고 방지 및 고객 보호 목적의 긴급하고 밀접한 추가 이용 (⭕ 가능).
3. **타 병원 병력 조회**: 주민등록번호(고유식별정보)와 병력(민감정보)이 결합된 과도한 침해로 불가능 (❌ 정답).
4. **기존 상품 안내 DM에 할인쿠폰 동봉 발송**: 기존 홍보 목적에 부합하는 합리적 확장 (⭕ 가능).

### 📚 출제위원 시크릿 족보: [민감정보 vs 고유식별정보]
| 구분 | 정의 및 대상 항목 | 처리 요건 |
| :--- | :--- | :--- |
| **민감정보 (Sensitive Info)** | 사상·신념, 노동조합·정당 가입/탈퇴, 정치적 견해, **건강·병력**, 성생활, 유전정보, 범죄경력자료 | 별도의 명시적 동의 또는 법령 근거 필수 |
| **고유식별정보 (Unique ID)** | **주민등록번호**, 여권번호, 운전면허번호, 외국인등록번호 | 원칙적 금지, 법률/대통령령 구체적 근거 시에만 예외적 허용 |

### 🧠 빅분기 암기 팁
- **“주민은 고유, 병력은 민감”**:
  - **주민등록번호** $\rightarrow$ 고유식별정보 (민감정보 ❌)
  - **병력/질병/진료내역** $\rightarrow$ 민감정보 (건강에 관한 정보 ⭕)
- **고유식별정보 4총사**: **“주·여·운·외”** (주민, 여권, 운전면허, 외국인등록)

## 📌 [07번] 분석 대상(What)과 분석 방법(How)에 따른 4대 과제 발굴 유형

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 과제 발굴 $\rightarrow$ 분석 대상(What) vs 분석 방법(How) 2×2 매트릭스
- **핵심 의도**: 분석 방법(How)은 알고 있으나 분석 대상(What)을 모르는 경우의 과제 발굴 유형 식별.

### 🎯 정답
**③ 통찰 (Insight)**

### 📌 정답인 이유
- **대상(What) 모름(X) + 방법(How) 앎(O)**: 보유한 분석 기술/도구를 활용하여 데이터 속에 숨겨진 새로운 패턴과 비즈니스 시사점을 찾아내는 **통찰(Insight)** 도출.

### 📚 출제위원 시크릿 족보: [과제 발굴 4대 유형 2×2 매트릭스]
| 분석 대상 (What) | 분석 방법 (How) | 과제 발굴 유형 | 핵심 설명 및 예시 |
| :---: | :---: | :---: | :--- |
| **안다 (Known)** | **안다 (Known)** | **최적화 (Optimization)** | 문제와 해결 기법을 모두 알아 프로세스 효율성 및 성과 극대화 |
| **안다 (Known)** | **모른다 (Unknown)** | **솔루션 (Solution)** | 해결해야 할 문제는 명확하나 기법을 몰라 새로운 해법(Solution) 모색 |
| **모른다 (Unknown)** | **안다 (Known)** | **통찰 (Insight)** | 분석 기술은 있으나 대상이 불명확하여 새로운 통찰(Insight) 도출 |
| **모른다 (Unknown)** | **모른다 (Unknown)** | **발견 (Discovery)** | 대상과 방법 모두 모르는 백지 상태에서 탐색적 연구를 통한 과제 발견 |

### 🧠 빅분기 암기 팁
- **“다 알면 최적화, 다 모르면 발견”**:
  - **O / O** $\rightarrow$ 최적화 (Optimization)
  - **X / X** $\rightarrow$ 발견 (Discovery)
- **“문제(대상) 알면 솔루션, 기술(방법) 알면 통찰”**:
  - **대상 O, 방법 X** $\rightarrow$ 해결책 필요 $\rightarrow$ **솔루션 (Solution)**
  - **대상 X, 방법 O** $\rightarrow$ 도구로 새로운 통찰 발굴 $\rightarrow$ **통찰 (Insight)**

## 📌 [08번] 상향식 접근법(Bottom-up) 프로세스 기반 과제 발굴 절차

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 과제 발굴 $\rightarrow$ 상향식 접근법(Bottom-Up)
- **핵심 의도**: 실제 현장 업무 프로세스를 관찰·분석하여 데이터 분석 과제를 도출하는 4단계 순서 파악.

### 🎯 정답
**③ 프로세스 분류 $\rightarrow$ 프로세스 흐름 분석 $\rightarrow$ 분석요건 식별 $\rightarrow$ 분석요건 정의**

### 📌 정답인 이유
- 현업의 큰 업무 단위를 나누고(**분류**), 세부 진행 과정을 추적하여(**흐름 분석**), 분석이 필요한 문제점을 찾아낸 뒤(**식별**), 구체적인 분석 과제로 명문화(**정의**)함.

### 🔎 선지 정밀 분석 & 출제 함정
- **식별 vs 정의 순서 함정**: 무엇을 분석할지 찾아내기(식별) 전에 먼저 정의할 수 없음 $\rightarrow$ 항상 **식별 $\rightarrow$ 정의**.
- **분류 vs 흐름 순서 함정**: 분석할 업무 영역을 먼저 쪼개놓아야(분류) 흐름을 볼 수 있음 $\rightarrow$ 항상 **분류 $\rightarrow$ 흐름**.

### 📚 출제위원 시크릿 족보: [상향식 vs 하향식 접근법 비교]
| 구분 | 하향식 접근법 (Top-Down) | 상향식 접근법 (Bottom-Up) |
| :--- | :--- | :--- |
| **출발점** | 비즈니스 문제 / 전략적 목표 (Problem-driven) | 원천 데이터 / 현업 프로세스 (Data-driven) |
| **주요 절차** | 문제 탐색 $\rightarrow$ 문제 정의 $\rightarrow$ 해결방안 탐색 $\rightarrow$ 타당성 검토 | 프로세스 분류 $\rightarrow$ 흐름 분석 $\rightarrow$ 요건 식별 $\rightarrow$ 요건 정의 |
| **적용 상황** | 해결할 과제가 명확하고 논리적 검증이 필요할 때 | 문제가 불명확하거나 새로운 기회를 탐색할 때 (발견/통찰) |

### 🧠 빅분기 암기 팁
- **“분 $\rightarrow$ 흐 $\rightarrow$ 식 $\rightarrow$ 정”**:
  - **분**류 $\rightarrow$ **흐**름 분석 $\rightarrow$ **식**별 $\rightarrow$ **정**의
- **“찾고(식별) $\rightarrow$ 정한다(정의)”**: 식별이 항상 정의보다 앞선다!

## 📌 [09번] 빅데이터 분석 5단계 생명주기(Lifecycle) 순서

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 분석 방법론 $\rightarrow$ 빅데이터 분석 5단계 생명주기
- **핵심 의도**: 분석 프로젝트의 5단계 표준 흐름(기획 $\rightarrow$ 준비 $\rightarrow$ 분석 $\rightarrow$ 구현 $\rightarrow$ 평가/전개) 및 선후관계 파악.

### 🎯 정답
**④ 분석 기획 $\rightarrow$ 데이터 준비 $\rightarrow$ 데이터 분석 $\rightarrow$ 시스템 구현 $\rightarrow$ 평가 및 전개**

### 📌 정답인 이유
- **빅데이터 분석 5단계 표준 절차**:
  1. **분석 기획 (Planning)**: 비즈니스 이해 및 프로젝트 정의
  2. **데이터 준비 (Preparing)**: 데이터 수집, 정제 및 검증
  3. **데이터 분석 (Analyzing)**: EDA, 피처 엔지니어링, 머신러닝 모델링 및 검증
  4. **시스템 구현 (Developing)**: 모델을 운영 환경 시스템에 탑재 및 통합 테스트
  5. **평가 및 전개 (Deploying)**: 성과 평가, 최종 배포 및 운영 모니터링

### 🔎 오답 선지 및 출제위원 함정 분석
- **가장 악질적인 빈출 함정**: **"데이터 분석"과 "시스템 구현" 순서 뒤집기** (①번 선지).
  - ❌ 시스템 구현 $\rightarrow$ 데이터 분석
  - ⭕ **데이터 분석(모델 생성) $\rightarrow$ 시스템 구현(시스템에 탑재)**
  - *“분석해서 알고리즘/결과가 나와야 시스템에 얹을 수 있다!”*

### 📚 출제위원 시크릿 족보: [3대 분석 방법론 비교]
| 방법론 | 단계별 순서 요약 | 핵심 특징 |
| :--- | :--- | :--- |
| **KDD (5단계)** | 선택 $\rightarrow$ 전처리 $\rightarrow$ 변환 $\rightarrow$ **데이터 마이닝** $\rightarrow$ 평가 | 학술적 데이터마이닝 중심 |
| **CRISP-DM (6단계)** | 비즈니스 이해 $\leftrightarrow$ 데이터 이해 $\rightarrow$ 데이터 준비 $\leftrightarrow$ **모델링** $\rightarrow$ 평가 $\rightarrow$ 전개 | 산업계 표준, 피드백 루프(반복) |
| **빅데이터 분석 (5단계)** | **기획 $\rightarrow$ 준비 $\rightarrow$ 분석 $\rightarrow$ 구현 $\rightarrow$ 평가/전개** | 실무 IT 시스템 배포 관점 통합 |

### 🧠 빅분기 암기 팁
- **“기 · 준 · 분 · 구 · 평”**:
  - **기**획 $\rightarrow$ **준**비 $\rightarrow$ **분**석 $\rightarrow$ **구**현 $\rightarrow$ **평**가/전개
- **“분석(모델링)이 먼저, 구현(시스템)이 나중!”**

## 📌 [10번] 탐색적 데이터 분석(EDA, Exploratory Data Analysis)의 정의

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 탐색 기초 $\rightarrow$ EDA 개념 및 특징
- **핵심 의도**: 벨 연구소의 존 튜키(John Tukey)가 제안한 데이터 탐색·시각화 중심의 분석 철학 파악.

### 🎯 정답
**④ 탐색적 분석 (EDA, Exploratory Data Analysis)**

### 📌 정답인 이유
- **EDA (탐색적 데이터 분석)**: 모델링이나 가설 검정에 앞서, 데이터를 다양한 각도에서 시각화하고 관찰하여 데이터의 구조, 분포, 이상치, 결측치 및 변수 간 관계를 직관적으로 파악하는 분석 기법.
- **핵심 인물**: **John Tukey (존 튜키)** - 박스플롯(Box Plot)의 창안자이자 EDA의 아버지.

### 🔎 선지 정밀 분석
1. **모델링 (Modeling)**: 알고리즘(회귀, 트리, 딥러닝 등)을 적용하여 예측/분류 모형 구축.
2. **정합성 검증**: 데이터 간 논리적 모순, 무결성, 규칙 일치 여부 확인.
3. **시스템 테스트**: 개발된 소프트웨어/시스템이 요구사항에 맞춰 동작하는지 시험.

### 📚 출제위원 시크릿 족보: [EDA vs CDA 비교]
| 구분 | EDA (탐색적 데이터 분석) | CDA (확증적 데이터 분석) |
| :--- | :--- | :--- |
| **목적** | 데이터 탐색, 패턴 발견, 가설 설정 | 사전 설정 가설 검정, 통계적 유의성 확인 |
| **핵심 도구** | 박스플롯, 히스토그램, 산점도, 요약통계량 | $t$-test, ANOVA, 회귀분석, $p$-value 검정 |
| **창안/대표** | John Tukey (존 튜키) | 전통적 추론 통계학 (가설 검정) |

### 🧠 빅분기 암기 팁
- **“튜키는 탐색(EDA)한다”**: **John Tukey $\rightarrow$ EDA (박스플롯 창안자)**
- **“EDA = 탐색 / CDA = 검증”**: 탐색적 분석과 확증적 분석의 차이 식별

## 📌 [11번] 데이터 분석 단계 중 모델링(Modeling)의 정의

### ✅ 문제 분석
- **출제 파트**: 제1과목 / 제3과목 $\rightarrow$ 데이터 분석 세부 절차 $\rightarrow$ 모델링(Modeling)의 역할과 정의
- **핵심 의도**: 통계 모델 및 머신러닝 알고리즘을 적용하여 예측/분류 모형을 구축하는 단계 식별.

### 🎯 정답
**① 모델링 (Modeling)**

### 📌 정답인 이유
- **모델링(Modeling)**: 분석 목적에 적합한 통계적 기법이나 머신러닝 알고리즘을 선택·적용하여 데이터로부터 수학적 모형을 학습하고 생성하는 핵심 단계.
- 문제 지문의 *“통계 모델을 만들거나 기계학습을 이용하여 모델을 만드는 과정”*과 1:1로 정확히 일치함.

### 🔎 선지 정밀 분석
1. **모델링 (Modeling)**: 알고리즘 적용 및 모형 생성 (회귀식 도출, 트리 분할, 가중치 학습 등).
2. **텍스트 분석 (Text Analytics)**: 자연어 비정형 데이터 대상 기법 (형태소 분석, 감성 분석, 토픽 모델링 등).
3. **모델 평가 (Evaluation)**: 생성된 모델의 성능 지표(정확도, F1-Score, ROC-AUC, RMSE 등) 측정.
4. **탐색적 분석 (EDA)**: 모델링 착수 전 데이터 구조/분포/이상치 탐색 및 이해.

### 📚 출제위원 시크릿 족보: [분석 핵심 3단계 흐름]
| 단계 | 핵심 수행 내용 | 대표 활동 |
| :--- | :--- | :--- |
| **1. EDA (탐색)** | 데이터를 들여다보고 이해함 | 분포 확인, 결측치/이상치 정제, 상관분석 |
| **2. Modeling (구축)** | 수학적/통계적 모델을 만듦 | 로지스틱 회귀, 랜덤포레스트, 딥러닝 학습 |
| **3. Evaluation (평가)** | 모델이 얼마나 잘 맞는지 측정함 | Confusion Matrix, ROC-AUC, 교차검증 |

### 🧠 빅분기 암기 팁
- **“탐 $\rightarrow$ 만 $\rightarrow$ 평”**:
  - **탐**색한다 = EDA
  - **만**든다 = 모델링(Modeling)
  - **평**가한다 = 모델 평가(Evaluation)
- **지문 매칭**: *"모델을 만든다 / 학습한다"* $\rightarrow$ **무조건 모델링!**

## 📌 [12번] 반정형 데이터 수집 기술 vs ETL 데이터 통합

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 전환 $\rightarrow$ 정형/반정형 데이터 수집 기술
- **핵심 의도**: 반정형 데이터(JSON, XML, HTML 등)를 직접 수집하는 기술(API, HTTP, 크롤링)과 DW 적재용 데이터 파이프라인(ETL)의 차이점 식별.

### 🎯 정답
**③ ETL (Extract $\rightarrow$ Transform $\rightarrow$ Load)**

### 📌 정답인 이유
- **반정형 데이터 수집 기술**: 웹/외부 시스템으로부터 HTML, JSON, XML, 로그 등을 직접 긁어오거나 가져오는 기술 (Open API, HTTP 통신, 웹 크롤링/스크래핑).
- **ETL의 정체**: 원천 시스템(주로 RDB/로그)에서 데이터를 추출(Extract) $\rightarrow$ 정제·변환(Transform) $\rightarrow$ 데이터웨어하우스/데이터마트에 적재(Load)하는 **데이터 통합 및 가공 프로세스**이므로 직접적인 반정형 데이터 수집 기술로 보기 부적절함.

### 🔎 선지 정밀 분석
1. **Open API (Application Programming Interface)**: 외부 플랫폼에서 제공하는 규격화된 인터페이스로 JSON/XML 반정형 데이터 수집.
2. **HTTP (HyperText Transfer Protocol)**: 웹 기반 클라이언트-서버 통신 프로토콜로 웹 리소스 수집의 기반.
3. **ETL (Extract, Transform, Load)**: 데이터 통합/적재 솔루션 (정형 DW 구축 중심).
4. **Crawling (크롤링)**: 웹 크롤러 봇이 웹페이지를 자동 순회하며 HTML 문서를 수집하는 대표적 반정형 수집 기술.

### 📚 출제위원 시크릿 족보: [데이터 유형별 수집 기술 총정리]
| 데이터 유형 | 데이터 예시 | 대표 수집 기술 / 도구 |
| :--- | :--- | :--- |
| **정형 데이터** | RDB 테이블, 스프레드시트 | **ETL**, **CDC** (Change Data Capture), **Sqoop** (RDB $\leftrightarrow$ Hadoop), DBtoDB |
| **반정형 데이터** | **JSON, XML, HTML, 시스템 로그** | **Open API**, **HTTP**, **Crawling**, **Flume**, **Chukwa**, **Fluentd**, **Logstash** |
| **비정형 데이터** | 이미지, 동영상, 음성, 센서 스트림 | **Kafka**, **Storm**, 센서 네트워크(IoT), 크롤링, 실시간 스트리밍 수집 |

### 🧠 빅분기 암기 팁
- **“API · HTTP · 크롤링 = 웹 수집”**: 웹 상의 반정형 데이터 직접 수집 기술 3총사
- **“ETL = 뽑고(E) $\rightarrow$ 바꾸고(T) $\rightarrow$ 넣는다(L)”**: 데이터 파이프라인/통합 기술!
- **“로그 수집 4형제”**: **플룸(Flume), 척와(Chukwa), 플루언티드(Fluentd), 로그스태시(Logstash)**

## 📌 [13번] 데이터 전처리 영역 구분 (변환 vs 정제 vs 통합)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 기초 $\rightarrow$ 데이터 변환(Transformation)의 정의
- **핵심 의도**: 데이터 정제(Cleansing), 데이터 통합(Integration), 데이터 변환(Transformation), 데이터 축소(Reduction)의 세부 작업 대상 식별.

### 🎯 정답
**① 데이터 유형을 변환하거나 데이터 분석이 용이한 형태로 변환하는 과정**

### 📌 정답인 이유
- **데이터 변환(Transformation)**: 분석 목적에 적합하도록 데이터의 자료형 변경, 정규화(Min-Max), 표준화(Z-Score), 구간화(Binning), 인코딩(One-Hot/Label) 등을 수행하는 과정.
- ②번 선지의 *"결측값 대체/변환, 이상값 제거, 노이즈 교정"*은 대상이 **오류 데이터 처리**이므로 **데이터 정제(Data Cleansing)**에 해당함.

### 🔎 선지 정밀 분석 & 출제위원 함정
1. **데이터 변환 (Transformation)**: 분석 편의를 위한 데이터 형태 및 유형 변환 (⭕ 정답).
2. **데이터 정제 (Cleansing)**: 결측값(대체/삭제), 이상값(처리), 노이즈 제거 (❌ 동사 '변환'이 들어갔더라도 대상이 결측/이상/노이즈이면 무조건 **정제**!).
3. **데이터 통합 (Integration)**: 서로 다른 데이터 소스/테이블을 연계·병합·통합 (❌ 통합).
4. **레거시 시스템 연계**: 구형 시스템 데이터와의 결합 및 통합 (❌ 통합).

### 📚 출제위원 시크릿 족보: [데이터 전처리 4대 핵심 영역]
| 전처리 영역 | 주요 대상 및 핵심 작업 | 대표 기법 / 키워드 |
| :--- | :--- | :--- |
| **1. 정제 (Cleansing)** | 불완전/오류/결측 데이터 처리 | **결측값 대체·삭제**, **이상값 정제**, **노이즈 스무딩** |
| **2. 통합 (Integration)** | 여러 출처의 데이터 결합 | **연계**, **병합(Merge)**, **조인(Join)**, 레거시 연동 |
| **3. 변환 (Transformation)** | 분석에 용이한 형태·값으로 변경 | **정규화**, **표준화**, **원-핫 인코딩**, **로그 변환**, **구간화** |
| **4. 축소 (Reduction)** | 데이터 크기 및 차원 축소 | **주성분분석(PCA)**, **샘플링(Sampling)**, **특성 선택(Feature Selection)** |

### 🧠 빅분기 암기 팁
- **“정결이노 / 통연병 / 변형유 / 축차양”**:
  - **정**제 $\rightarrow$ **결**측, **이**상, **노**이즈
  - **통**합 $\rightarrow$ **연**계, **병**합
  - **변**환 $\rightarrow$ **형**태, **유**형 변경 (스케일링/인코딩)
  - **축**소 $\rightarrow$ **차**원축소(PCA), **양** 축소

## 📌 [14번] 개인정보 비식별화(De-identification) 5대 조치 기법

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 법제도 $\rightarrow$ 개인정보 비식별화 기법
- **핵심 의도**: 개인정보 비식별 조치 가이드라인의 5대 기법(가명처리, 데이터 마스킹, 데이터 삭제, 데이터 범주화, 총계처리)의 정확한 정의 및 차이점 식별.

### 🎯 정답
**① 데이터 마스킹 (설명이 '가명처리'에 해당하므로 잘못 매칭된 선지 $\rightarrow$ 정답)**

### 📌 정답인 이유
- **가명처리(Pseudonymization)**: 개인식별이 가능한 데이터를 식별할 수 없는 **다른 값으로 대체**하는 방식 (예: 홍길동 $\rightarrow$ 사용자001).
- **데이터 마스킹(Data Masking)**: 데이터의 전체 또는 일부를 **공백, 특수문자(*) 등으로 가리는** 방식 (예: 홍길동 $\rightarrow$ 홍*동, 주민번호 $\rightarrow$ 900101-1******).
- ①번 선지는 마스킹이라는 이름을 붙여놓고 '다른 값으로 대체한다'는 가명처리의 정의를 서술하여 명백한 오답 선지임.

### 🔎 선지 정밀 분석: [5대 비식별화 기법]
1. **가명처리 (Pseudonymization)**: 다른 값으로 대체 (휴리스틱 가명화, 암호화, 토큰화).
2. **데이터 삭제 (Suppression / Deletion)**: 식별자 자체를 물리적으로 제거 (식별자 삭제, 부분삭제).
3. **데이터 범주화 (Categorization / Binning)**: 명확한 값을 구간이나 상위 범주 대표값으로 묶음 (예: 31세 $\rightarrow$ 30대, 역삼동 $\rightarrow$ 강남구).
4. **총계처리 (Aggregation)**: 개별 관측값을 합계, 평균 등의 통계 집계값으로 변환 (예: 개인 소득 $\rightarrow$ 부서 평균 소득).
5. **데이터 마스킹 (Masking)**: 식별 필드의 일부를 별표(*), X 등으로 숨김 처리.

### 📚 출제위원 시크릿 족보: [비식별화 5대 기법 핵심 비교표]
| 비식별화 기법 | 핵심 동작 키워드 | 구체적 변환 예시 |
| :--- | :--- | :--- |
| **가명처리** | **다른 값으로 대체 / 치환** | 홍길동 $\rightarrow$ 고객A, 임꺽정 $\rightarrow$ User_07 |
| **데이터 마스킹** | **일부/전체를 가림 (*, X 처리)** | 홍길동 $\rightarrow$ 홍*동, 010-1234-5678 $\rightarrow$ 010-****-5678 |
| **데이터 삭제** | **식별 필드/레코드 제거** | 이름, 주민등록번호 컬럼 자체 삭제 |
| **데이터 범주화** | **구간화 / 범위 / 상위 개념 묶기** | 나이 28세 $\rightarrow$ 20대, 키 178cm $\rightarrow$ 170~180cm |
| **총계처리** | **합계, 평균 등 집계값 대체** | 직원 개별 연봉 $\rightarrow$ 팀 평균 연봉 6,000만원 |

### 🧠 빅분기 암기 팁
- **“가대 / 마가 / 삭삭 / 범구 / 총평”**:
  - **가**명처리 $\rightarrow$ **대**체
  - **마**스킹 $\rightarrow$ **가**림 (*, X)
  - **삭**제 $\rightarrow$ **삭**제
  - **범**주화 $\rightarrow$ **구**간/범주
  - **총**계처리 $\rightarrow$ **평**균/합계
- **⚠️ 최빈출 낚시 주의**: **“가명처리(대체) ↔ 데이터 마스킹(가림)”** 서로 바꿔치기하는 문제 무조건 조심!

## 📌 [15번] 프라이버시 보호 모델 (k-익명성 vs l-다양성 vs t-근접성)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 법제도 $\rightarrow$ 프라이버시 보호 모델
- **핵심 의도**: 동일 준식별자 집합 내 민감한 속성의 다양성을 확보하여 동질성 공격 및 추론을 방어하는 기법(l-diversity) 식별.

### 🎯 정답
**② l-다양성 (l-diversity)**

### 📌 정답인 이유
- **l-다양성(l-diversity)**: $k$-익명성의 치명적 취약점인 **동질성 공격(Homogeneity Attack)**을 보완하기 위해, 하나의 동질 집합(Equivalence Class) 내에 최소 $l$개 이상의 서로 다른 민감한 정보(질병, 소득 등)가 다양하게 분포하도록 강제하는 모델.
- 문제 지문의 *“민감한 정보의 다양성을 높여 추론 가능성을 낮춘다”*와 1:1 완벽 일치.

### 🔎 선지 정밀 분석: [프라이버시 3대 모델 발전사]
1. **k-익명성 (k-anonymity)**: 동일한 준식별자(나이, 성별, 지역 등) 조합을 가진 레코드가 최소 $k$개 이상 존재하도록 하여 개인 식별 방지. (취약점: 동질 집합 내 모든 사람의 질병이 '암'이면 특정인 질병 추론 가능 $\rightarrow$ 동질성 공격 취약).
2. **l-다양성 (l-diversity)**: 각 동질 집합 내 민감 정보가 최소 $l$개 이상 서로 다르게 존재하도록 보장. (취약점: 쏠림 공격 Skewness, 유사성 공격 Similarity).
3. **t-근접성 (t-closeness)**: 동질 집합 내 민감 정보의 분포가 전체 데이터의 민감 정보 분포와 $t$ 이하의 거리(EMD)를 유지하도록 제한.
4. **s-민감성 (s-sensitivity)**: 동질 집합 내 특정 민감 속성의 비율을 $s$ 이하로 제한하는 변형 모델.

### 📚 출제위원 시크릿 족보: [프라이버시 3대 모델 완벽 비교표]
| 프라이버시 모델 | 핵심 규정 및 기준 | 방어 대상 취약점 | 대표 키워드 |
| :--- | :--- | :--- | :--- |
| **$k$-익명성** | 동일 준식별자 그룹 내 **최소 $k$명 이상의 레코드** | 연결 공격 (Linking Attack), 단일 식별 | **개인 식별 방지**, 레코드 수($k$) |
| **$l$-다양성** | 동질 집합 내 **최소 $l$개 이상의 다양한 민감값** | **동질성 공격 (Homogeneity)**, 배경지식 공격 | **민감 정보 다양성 확보** |
| **$t$-근접성** | 집합 내 민감값 분포와 **전체 분포 간 거리 $\le t$** | **쏠림 공격 (Skewness)**, 유사성 공격 | **전체 분포와의 유사성/거리** |

### 🧠 빅분기 암기 팁
- **“K는 사람 수, L은 종류 수, T는 분포 차이”**:
  - **K** $\rightarrow$ 같은 준식별자를 가진 사람이 **$k$명 이상**
  - **L** $\rightarrow$ 민감한 정보의 종류가 **$l$가지 이상**
  - **T** $\rightarrow$ 전체 데이터와의 확률 분포 거리가 **$t$ 이하**

## 📌 [16번] 데이터 품질 관리 특성 (완전성 vs 유일성 vs 일관성)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 $\rightarrow$ 데이터 품질 관리(Data Quality) 기준
- **핵심 의도**: 필수 항목 누락 여부(NULL 허용 여부)를 평가하는 데이터 품질 특성(완전성) 식별.

### 🎯 정답
**① 완전성 (Completeness)**

### 📌 정답인 이유
- **완전성(Completeness)**: 필수적으로 입력되거나 존재해야 하는 데이터 항목에 누락(Missing Value / NULL)이 없이 온전히 저장되어 있는 정도.
- 문제 지문의 *“필수항목에 누락이 없어야 한다 / 고객 ID는 NULL일 수 없다”*는 완전성의 표준 정의와 100% 일치함.

### 🔎 선지 정밀 분석: [데이터 품질 핵심 특성]
1. **완전성 (Completeness)**: 누락(NULL) 없음, 필수 데이터 존재 여부 (⭕ 정답).
2. **유일성 (Uniqueness)**: 데이터 레코드나 식별자가 중복되지 않고 유일하게 존재함 (PK 제약조건).
3. **일관성 (Consistency)**: 서로 다른 시스템이나 테이블 간에 동일한 데이터가 모순 없이 동일한 규칙으로 유지됨.
4. **신뢰성 (Reliability) / 정확성 (Accuracy)**: 데이터가 현실 세계의 실제 참값(Truth)과 일치함.
5. **유효성 (Validity)**: 데이터가 사전에 정의된 도메인(포맷, 길이, 값의 범위)을 충족함.

### 📚 출제위원 시크릿 족보: [데이터 품질 5대 특성 완벽 비교표]
| 품질 특성 | 핵심 질문 | 대표 예시 및 위반 사례 |
| :--- | :--- | :--- |
| **완전성 (Completeness)** | 필수 값이 빠짐없이 들어있는가? | 고객 ID에 **NULL**이 존재하면 완전성 위반 |
| **유일성 (Uniqueness)** | 중복된 데이터가 없는가? | 동일한 주민번호/고객번호가 2건 이상 저장되면 **중복(유일성 위반)** |
| **일관성 (Consistency)** | 시스템 간 모순이 없는가? | A시스템은 회원 성별이 '남', B시스템은 '여'로 불일치 |
| **유효성 (Validity)** | 정의된 형식/범위에 맞는가? | 나이 컬럼에 -5세가 입력되거나, 날짜 컬럼에 2026-13-40 입력 |
| **정확성 (Accuracy)** | 실제 사실과 부합하는가? | 고객의 실제 주소와 DB에 기록된 주소가 다름 |

### 🧠 빅분기 암기 팁
- **“비면 완전성, 겹치면 유일성”**:
  - **NULL / 결측치 / 비어있음** $\rightarrow$ **완전성**
  - **중복 / 복수 레코드 / 겹침** $\rightarrow$ **유일성**
  - **시스템 간 불일치 / 모순** $\rightarrow$ **일관성**
  - **도메인 / 범위 / 형식 오류** $\rightarrow$ **유효성**

## 📌 [17번] 정형 데이터 품질 기준과 소프트웨어 사용성 구분

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 $\rightarrow$ 정형 데이터 품질 기준
- **핵심 의도**: 데이터 품질 관리 기준(완전성, 유효성, 일관성 등)과 소프트웨어 품질 지표(사용성 등)의 혼동 함정 식별.

### 🎯 정답
**② 규정된 조건에서 사용될 때, 사용자에 의해 이해되고, 선호될 수 있게 하는 정도 (소프트웨어 사용성에 해당 $\rightarrow$ 정답)**

### 📌 정답인 이유
- **데이터 품질 기준의 대상**: 데이터 값 자체의 완전성(누락 없음), 유효성(도메인 준수), 일관성(모순 없음), 정확성(참값 일치) 등.
- ②번 선지의 *"사용자에 의해 이해되고 선호되는 정도"*는 ISO 9126 / ISO 25010 등의 **소프트웨어 사용성(Usability)** 정의로, 데이터 자체의 정형 품질 기준에 속하지 않음.

### 🔎 선지 정밀 분석
1. **필수항목 누락 없음**: **완전성 (Completeness)** (⭕ 데이터 품질 기준).
2. **사용자 이해 및 선호도**: **사용성 (Usability)** (❌ 데이터 품질 기준 아님 $\rightarrow$ 정답).
3. **유효 범위 및 도메인 충족**: **유효성 (Validity)** (⭕ 데이터 품질 기준).
4. **구조·값의 일관된 정의 및 일치**: **일관성 (Consistency)** (⭕ 데이터 품질 기준).

### 📚 출제위원 시크릿 족보: [데이터 품질 vs SW 품질 함정 분리]
| 구분 | 데이터 품질 (Data Quality) | 소프트웨어 품질 (Software Quality) |
| :--- | :--- | :--- |
| **평가 대상** | DB 내부의 데이터 레코드, 컬럼, 값 | 시스템, 인터페이스, 프로그램 코드 |
| **주요 기준** | **완전성, 유효성, 일관성, 유일성, 정확성** | **기능성, 신뢰성, 사용성(Usability), 효율성, 유지보수성, 이식성** |

### 🧠 빅분기 암기 팁
- **“도메인 = 유효 / 모순없음 = 일관 / 누락없음 = 완전”**
- **⚠️ 1타 강사 함정 파쇄**: *"사용자가 쓰기 편하다 / 선호한다 / 이해하기 쉽다"* 문장이 나오면 데이터 품질이 아니라 **'소프트웨어 사용성'**이므로 바로 쳐내기!

## 📌 [18번] 데이터 분석 4대 성숙도 단계 (기술 $\rightarrow$ 진단 $\rightarrow$ 예측 $\rightarrow$ 처방)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 분석 개요 $\rightarrow$ 가트너(Gartner) 분석 성숙도 4단계
- **핵심 의도**: 진단 분석(Diagnostic Analytics)의 핵심 질문(“왜 발생했는가?”)과 원인 분석 목적 식별.

### 🎯 정답
**① 왜 발생했는가?**

### 📌 정답인 이유
- **진단 분석 (Diagnostic Analytics)**: 과거에 발생한 현상이나 결과의 **근본적인 원인(Root Cause)**과 상관관계를 규명하기 위한 분석.
- 질문 매칭: *“왜 이런 문제가 발생했는가? (Why did it happen?)”* $\rightarrow$ **진단 분석**.

### 🔎 선지 정밀 분석: [분석 4대 성숙도 질문 매칭]
1. **왜 발생했는가? (Why did it happen?)**: **진단 분석 (Diagnostic)** (⭕ 정답).
2. **사건이 일어날 것인가? (What will happen?)**: **예측 분석 (Predictive)** (❌ 미래 발생 가능성).
3. **어떻게 대응할 것인가? (How should we act / optimize?)**: **처방/규범 분석 (Prescriptive)** (❌ 최적화 및 실행 방안).
4. **무슨 일이 일어났는가? (What happened?)**: **기술 분석 (Descriptive)** (❌ 과거 현상 요약/보고).

### 📚 출제위원 시크릿 족보: [Gartner 4대 분석 성숙도 완벽 비교표]
| 단계 | 분석 유형 | 핵심 질문 | 대표 기법 및 비즈니스 예시 |
| :---: | :--- | :--- | :--- |
| **1단계** | **기술 분석 (Descriptive)** | **무슨 일이 일어났는가?** | 대시보드, 통계 요약, 과거 매출 실적 집계 |
| **2단계** | **진단 분석 (Diagnostic)** | **왜 일어났는가?** | 드릴다운, 원인 분석, 상관분석, 이탈 원인 규명 |
| **3단계** | **예측 분석 (Predictive)** | **앞으로 무슨 일이 일어날까?** | 회귀분석, 머신러닝 분류/예측, 수요 예측 |
| **4단계** | **처방 분석 (Prescriptive)** | **어떻게 해야 하는가? (최적화)** | 시뮬레이션, 의사결정 최적화, 맞춤형 프로모션 추천 |

### 🧠 빅분기 암기 팁
- **“무 · 왜 · 앞 · 어”** (핵심 질문 매칭):
  - **무**슨 일? $\rightarrow$ **기술(Descriptive)**
  - **왜** 일어남? $\rightarrow$ **진단(Diagnostic)**
  - **앞**으로 어찌 됨? $\rightarrow$ **예측(Predictive)**
  - **어**떻게 해야 함? $\rightarrow$ **처방(Prescriptive)**
- **“왜 = 진단 / 어떻게 = 처방”** 1초 컷!

## 📌 [19번] ETL(Extract, Transform, Load)의 상세 특성과 구성 요소

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 적재 $\rightarrow$ ETL 아키텍처 및 세부 기능
- **핵심 의도**: ETL 자체의 프로세스적 성격과 중간 임시 저장 공간인 **스테이징 영역(Staging Area)**의 역할을 명확히 구분하는지 평가.

### 🎯 정답
**④ ETL은 중간 단계에 저장하는 역할을 한다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **ETL의 본질**: 원천 데이터로부터 데이터를 **추출(Extract) $\rightarrow$ 변환(Transform) $\rightarrow$ 적재(Load)**하는 일련의 데이터 처리 프로세스 및 통합 소프트웨어.
- **중간 임시 저장의 주체**: ETL 수행 중 원천 데이터를 정제·변환하기 위해 임시로 거치는 중간 저장 공간은 **스테이징 영역(Staging Area)**이며, ETL 자체가 저장소 역할을 하는 것은 아님.

### 🔎 선지 정밀 분석: [ETL 핵심 기능 및 아키텍처]
1. **DW, Data Mart, ODS 적재**: 다양한 원천(Source)에서 추출·가공 후 목적지 저장소에 적재 (⭕ 올바른 설명).
2. **배치(Batch) vs 실시간(Real-Time) ETL**: 정기적 일괄 적재(Batch) 및 이벤트 발생 즉시 처리(Real-Time/CDC) 지원 (⭕ 올바른 설명).
3. **MPP(Massively Parallel Processing) 지원**: 대용량 데이터를 고속으로 변환·적재하기 위해 다중 노드 병렬 분산 처리 아키텍처 활용 (⭕ 올바른 설명).
4. **중간 저장 역할**: 저장소는 **Staging Area**이며 ETL 프로세스 자체의 정의가 아님 (❌ 오답 선지로서 정답).

### 📚 출제위원 시크릿 족보: [데이터 웨어하우스(DW) 아키텍처 구성 요소]
| 구성 요소 | 핵심 역할 및 기능 |
| :--- | :--- |
| **원천 시스템 (Source)** | 레거시 DB, ERP, 웹 로그, 외부 API 등 원본 데이터 생성처 |
| **ETL 도구** | 원천 데이터를 추출, 클렌징/변환 후 목적지에 밀어 넣는 데이터 파이프라인 |
| **스테이징 영역 (Staging Area)** | ETL 변환 전후 대규모 데이터를 **임시로 보관하는 중간 버퍼 공간** |
| **ODS (Operational Data Store)** | 운영계 시스템의 데이터를 통합하여 실시간/준실시간 조회를 지원하는 저장소 |
| **DW (Data Warehouse)** | 전사적 의사결정 지원을 위해 장기 보관하는 주제 중심적·통합적·시계열적·비휘발성 저장소 |
| **데이터 마트 (Data Mart)** | 특정 부서(마케팅, 재무 등)나 특정 분석 목적을 위해 DW에서 추출한 소규모 저장소 |

### 🧠 빅분기 암기 팁
- **“중간 저장은 Staging Area, 처리 파이프라인은 ETL”**
- **“E(뽑고) $\rightarrow$ T(바꾸고) $\rightarrow$ L(넣는다)”**
- **“DW 4대 특성”**: **주 · 통 · 시 · 비** (주제지향성, 통합성, 시계열성, 비휘발성)

## 📌 [20번] 비정형 데이터(텍스트·음성·이미지·동영상)의 표현 및 저장 특성

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터의 이해 $\rightarrow$ 비정형 데이터의 구조와 특성
- **핵심 의도**: 비정형 멀티미디어 데이터(텍스트, 음성, 이미지, 비디오)의 고유한 표현 방식 및 음성 데이터의 시계열 동적(Dynamic) 신호 특성 파악.

### 🎯 정답
**② 음성 데이터는 정적이므로 $y=f(x)$의 형태 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **음성 데이터의 특성**: 사람의 음성이나 소리는 **시간($t$)의 흐름에 따라 공기의 압력(진폭)이 연속적으로 변하는 아날로그/디지털 파형(Waveform $x(t)$)** 신호임.
- 따라서 음성은 정적(Static) 데이터가 아니라 **동적(Dynamic) 시계열 신호 데이터**이므로, "음성은 정적 데이터"라는 서술은 명백한 오류임.

### 🔎 선지 정밀 분석: [비정형 4대 데이터 표현 방식]
1. **텍스트 데이터**: 단어(Word/Token), 문장(Sentence), 문서(Document), 코퍼스(Corpus) 단위로 표현 (⭕ 올바른 설명).
2. **음성 데이터**: 시간축을 갖는 파형(Waveform), 주파수 스펙트로그램(Spectrogram), MFCC 등으로 표현되는 동적 신호 (❌ 정적으로 표현하여 정답).
3. **이미지 데이터**: 2차원 격자 형태의 픽셀(Pixel)과 Red, Green, Blue 3채널의 색상 강도($0\sim255$)로 표현 (⭕ 올바른 설명).
4. **동영상 데이터**: 시간 순서에 따른 연속적인 이미지 프레임(Frame)과 오디오가 결합된 대용량 멀티미디어로, 주로 스트리밍(Streaming) 방식으로 처리·전송 (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [비정형 데이터 4대 유형 총정리]
| 비정형 데이터 | 핵심 구성 단위 / 표현 형식 | 주요 전처리 / 특징 추출 기법 |
| :--- | :--- | :--- |
| **텍스트 (Text)** | 단어, 문장, BoW, TF-IDF, Word2Vec | 형태소 분석, 불용어 제거, 토큰화, 정규표현식 |
| **음성 (Audio)** | **시간에 따른 파형($x(t)$), 진폭, 주파수** | STFT(단시간 푸리에 변환), **MFCC**, 멜 스펙트로그램 |
| **이미지 (Image)** | **2D 픽셀(Pixel), RGB 3채널 매트릭스** | 리사이징, 정규화, CNN 합성곱 필터링, 데이터 증강 |
| **동영상 (Video)** | **연속 프레임(FPS), 시간축 + 3D 텐서**, 스트리밍 | 프레임 추출, Optical Flow, 3D-CNN, 오디오-비디오 동기화 |

### 🧠 빅분기 암기 팁
- **“단어 = 텍스트 / 파형(시간) = 음성 / 픽셀(RGB) = 이미지 / 프레임(스트리밍) = 동영상”**
- **“음성은 정적(X) $\rightarrow$ 시간에 따라 변하는 동적 신호(O)”** 1초 컷!

## 📌 [21번] 상자그림(Boxplot)의 기본 구성 통계량과 이상치 경계

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 데이터 시각화 $\rightarrow$ 상자그림(Boxplot)의 5수치 요약
- **핵심 의도**: 상자그림(Boxplot)에서 기본적으로 직접 파악할 수 있는 통계량($Q_1, Q_2, Q_3, IQR$, 이상치)과 기본 요소가 아닌 통계량(평균값) 식별.

### 🎯 정답
**③ 평균값 (Mean)**

### 📌 정답인 이유
- **Boxplot의 5수치 요약 (Five-Number Summary)**:
  1. 최솟값 (Minimum - 수염의 하단 경계)
  2. 제1사분위수 ($Q_1$ - 25% 지점, 상자 하단)
  3. **중앙값 / 제2사분위수 ($Q_2$ / Median - 50% 지점, 상자 내부의 실선)**
  4. 제3사분위수 ($Q_3$ - 75% 지점, 상자 상단)
  5. 최댓값 (Maximum - 수염의 상단 경계)
- **평균값(Mean)**은 이상치에 민감한 대표값이므로, 저항성(Resistance)을 갖는 순서 기반 통계량으로 구성된 기본 상자그림에서는 표시되지 않음.

### 🔎 선지 정밀 분석: [Boxplot 확인 가능 지표]
1. **제1사분위수 ($Q_1$)**: 상자의 아랫변 (⭕ 확인 가능).
2. **사분위수 범위 ($IQR$)**: 상자의 세로 길이 ($IQR = Q_3 - Q_1$) (⭕ 확인 가능).
3. **평균값 (Mean)**: 기본 Boxplot 구성 요소 아님 (❌ 확인 불가 $\rightarrow$ 정답).
4. **중앙값 ($Q_2$ / Median)**: 상자 내부를 가로지르는 중간 선 (⭕ 확인 가능).

### 📚 출제위원 시크릿 족보: [IQR 이상치 판별 공식 - 실기/필기 공통 필수]
```
             [ 상위 이상치 (Upper Outlier) : Q3 + 1.5 * IQR 초과 ]
     ──┬──   <-- 최대값 경계 (Upper Whisker : Q3 + 1.5 * IQR 이내의 최대 관측값)
       │
   ┌───┴───┐ <-- 제3사분위수 (Q3, 75%)
   │       │
   │───────│ <-- 중앙값 (Q2, Median, 50%)  ※ 평균(Mean)이 아님!
   │       │
   └───┬───┘ <-- 제1사분위수 (Q1, 25%)
       │
     ──┴──   <-- 최솟값 경계 (Lower Whisker : Q1 - 1.5 * IQR 이내의 최소 관측값)
             [ 하위 이상치 (Lower Outlier) : Q1 - 1.5 * IQR 미만 ]
```
- **사분위수 범위**: $IQR = Q_3 - Q_1$
- **보통 이상치 (Mild Outlier) 판정 기준**:
  - 하한선 (Lower Fence) = $Q_1 - 1.5 \times IQR$ 미만
  - 상한선 (Upper Fence) = $Q_3 + 1.5 \times IQR$ 초과
- **극단 이상치 (Extreme Outlier) 판정 기준**:
  - $Q_1 - 3.0 \times IQR$ 미만 또는 $Q_3 + 3.0 \times IQR$ 초과

### 🧠 빅분기 암기 팁
- **“박스플롯엔 평균 없다! 가운데 선은 중앙값!”**
- **“이상치는 1.5배 IQR!”** (실기 파이썬 전처리 코드 작성 시에도 단골 출제)

## 📌 [22번] 변수 선택(Feature Selection) 래퍼(Wrapper) 기법의 특성

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 차원축소 및 변수 선택 $\rightarrow$ 래퍼(Wrapper) 기법(전진, 후진, 단계적 선택)
- **핵심 의도**: 모델 성능 기반 변수 선택법인 래퍼(Wrapper) 방식의 동작 원리와 데이터 변동에 따른 불안정성(낮은 안정성) 한계 식별.

### 🎯 정답
**② 전진선택법은 변수값의 작은 변동에도 그 결과가 유지되어 안정성이 높다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **래퍼(Wrapper) 기법의 불안정성**: 래퍼 기법은 데이터의 작은 변동이나 노이즈에도 모델의 성능 평가치(AIC, BIC, $R^2$, Accuracy 등)가 민감하게 출렁이며, 이로 인해 선택되는 최적 변수 조합이 크게 바뀔 수 있어 **안정성(Stability)이 낮음**.
- 따라서 "변수값의 작은 변동에도 결과가 유지되어 안정성이 높다"는 서술은 명백한 오류임.

### 🔎 선지 정밀 분석: [래퍼 3대 변수 탐색 방식]
1. **전진선택법 (Forward Selection)**: 독립변수가 없는 공집합 상태($\varnothing$)에서 시작하여 모델 성능을 가장 크게 향상시키는 변수를 하나씩 추가 (⭕ 올바른 설명).
2. **안정성 오류**: 래퍼 방식은 그리디(Greedy) 탐색으로 데이터 변화에 민감하여 안정성이 낮고 과적합 위험이 있음 (❌ 정답).
3. **후진제거법 (Backward Elimination)**: 모든 독립변수를 포함한 상태에서 시작하여 기여도가 가장 낮은 변수를 하나씩 제거 (⭕ 올바른 설명).
4. **단계적 선택법 (Stepwise Selection)**: 전진선택으로 변수를 추가하되, 이미 선택된 변수의 유의성을 재검토하여 불필요해진 변수를 제거하는 추가+제거 결합 방식 (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [변수 선택 3대 접근법 (Filter vs Wrapper vs Embedded)]
| 구분 | 필터 기법 (Filter) | 래퍼 기법 (Wrapper) | 임베디드 기법 (Embedded) |
| :--- | :--- | :--- | :--- |
| **선택 방식** | 모델 학습 전 **통계적 지표**로 평가 | **실제 예측 모델을 반복 학습**시켜 평가 | 모델 자체의 **학습 알고리즘 내부**에서 선택 |
| **대표 알고리즘** | 피어슨 상관계수, 카이제곱 검정, ANOVA F-값, 상호정보량 | **전진선택법, 후진제거법, 단계선택법**, RFE, 유전 알고리즘 | **Lasso (L1 규제)**, Ridge(L2), ElasticNet, 의사결정나무 불순도 중요도 |
| **계산 속도** | **매우 빠름** (Lightweight) | **매우 느림** (반복 모델 학습) | 보통 |
| **특징 및 한계** | 변수 간 상호작용 무시 | 최적 조합 탐색 가능, **과적합 위험 & 낮은 안정성** | 모델 특화 변수 선택 |

### 🧠 빅분기 암기 팁
- **“전진 = 빈손 출발 추가 / 후진 = 풀옵션 출발 제거 / 단계 = 넣다 뺐다”**
- **“필터 = 모델 없이 통계 / 래퍼 = 모델 직접 돌림 / 임베디드 = 모델이 알아서(Lasso)”**
- **“래퍼는 계산량 크고, 데이터 바뀌면 변수 조합 흔들려 안정성 낮음!”**

## 📌 [23번] 차원 축소(Dimensionality Reduction) 4대 기법 비교 (PCA vs MDS vs 요인분석 vs t-SNE)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 차원축소 기법 $\rightarrow$ 주성분분석(PCA)의 원리와 타 기법(MDS, FA, t-SNE) 비교
- **핵심 의도**: PCA에서 주성분($PC_1, PC_2, \dots$)은 설명 분산의 크기(고윳값)에 따라 엄격한 **우선순위(서열)**가 존재한다는 특성 파악.

### 🎯 정답
**① PCA(주성분분석)는 각 주성분 간에 우선순위가 없이 대등하게 차원을 축소한다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **PCA의 주성분 우선순위 원리**:
  - 기존 변수들의 선형 결합으로 직교(Orthogonal, 상관관계=0)하는 새로운 주성분을 만들 때, **데이터의 분산(정보량)을 가장 많이 보존하는 축을 제1주성분($PC_1$)**으로 지정.
  - $PC_1$과 직교하면서 두 번째로 큰 분산을 설명하는 축이 $PC_2$가 됨 ($PC_1 > PC_2 > PC_3 \dots$).
  - 따라서 주성분 간에는 명확한 설명력/분산 크기 서열(우선순위)이 존재하며, 결코 대등하지 않음.

### 🔎 선지 정밀 분석: [차원축소 4대 기법 특성]
1. **PCA (Principal Component Analysis)**: 분산 최대화 선형 변환, 주성분 간 직교 및 명확한 분산 순위 존재 (❌ 대등하다고 서술하여 정답).
2. **다차원 척도법 (MDS, Multi-Dimensional Scaling)**: 객체들 간의 **거리(유사도/비유사도)**를 최대한 보존하면서 저차원(2D/3D) 공간에 기하학적으로 배치 (⭕ 올바른 설명).
3. **요인 분석 (Factor Analysis)**: 변수 간의 상관관계(공분산)를 분석하여 데이터 이면에 숨겨진 소수의 **잠재 요인(Latent Factor)**을 도출 (⭕ 올바른 설명).
4. **t-SNE (t-Distributed Stochastic Neighbor Embedding)**: 고차원에서의 데이터 간 거리 확률 분포를 저차원에서도 유지하도록 하는 **비선형(Non-linear) 지역 이웃 구조 보존 시각화 기법** (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [차원축소 4대 핵심 기법 완벽 비교표]
| 기법 명칭 | 선형/비선형 | 핵심 보존 대상 / 작동 원리 | 주요 활용 목적 |
| :--- | :---: | :--- | :--- |
| **PCA (주성분분석)** | **선형 (Linear)** | **데이터의 전체 분산(Variance) 최대화**, 직교 좌표 변환 | 다중공선성 해소, 데이터 압축, 모델 속도 개선 |
| **MDS (다차원척도법)** | 선형 / 비선형 | 객체 간의 **거리 / 비유사성 (Distance)** 보존 | 지각도(Perceptual Map) 시각화, 브랜드 포지셔닝 |
| **요인 분석 (FA)** | **선형 (Linear)** | 변수 간 상관관계 분석을 통한 **잠재 공통 요인 추출** | 설문 조사 분석, 성격 5요인, 지능 검사 요인 분석 |
| **t-SNE** | **비선형 (Non-linear)** | 데이터 간의 **국소적 이웃 관계 (Local Neighborhood)** 보존 | 고차원 복잡 데이터(이미지/임베딩) 2D/3D 시각화 |

### 🧠 빅분기 암기 팁
- **“PCA = 분산 큰 놈부터 줄 세우기 (PC1 > PC2 > PC3)”**
- **“MDS = 거리 보존 / 요인분석 = 잠재 요인 / t-SNE = 비선형 이웃 시각화”**
- **“주성분은 서로 직교(상관도 0)하며 독립이다!”**

## 📌 [24번] 파생변수(Derived Variable) 생성 기법 및 요약변수와의 구분

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 $\rightarrow$ 파생변수(Derived Variable) 생성 방법
- **핵심 의도**: 기존 원본 데이터를 활용하여 비즈니스 의미를 갖는 새로운 파생변수를 생성하는 표준적인 접근법 식별.

### 🎯 정답
**③ ㄱ, ㄴ, ㄷ**

### 📌 정답인 이유
- **파생변수의 대표적 생성 방식**:
  - **ㄱ. 한 값으로부터 특징 추출 (⭕)**: 원본 데이터 1개의 속성에서 새로운 의미 추출 (예: 구매일시 $\rightarrow$ 요일/시간대, 주민번호 $\rightarrow$ 나이/성별).
  - **ㄴ. 한 레코드 내의 값들 결합 (⭕)**: 같은 행의 여러 컬럼 연산 결합 (예: 총매출 $\div$ 방문횟수 $\rightarrow$ 객단가, 체중 $\div$ 키$^2 \rightarrow$ BMI).
  - **ㄷ. 다른 테이블의 부가 정보 참조 (⭕)**: 외부 테이블 조인을 통한 파생 변수 부착 (예: 우편번호 $\rightarrow$ 해당 지역 평균 소득수준).
- **오답 보기 분석**:
  - **ㄹ. 거래 레코드를 분리한다 (❌)**: 다수의 거래 이력 레코드는 집계하여 **'요약(Aggregation)'**하는 것이지 '분리'하는 것이 아님.
  - **ㅁ. 복잡한 표현방식으로 변환한다 (❌)**: 로그변환, 정규화 등은 **변수 변환(Transformation)** 영역에 해당함.

### 📚 출제위원 시크릿 족보: [요약변수 vs 파생변수 핵심 비교]
| 구분 | 요약변수 (Summary Variable) | 파생변수 (Derived Variable) |
| :--- | :--- | :--- |
| **정의** | 여러 데이터를 수집하여 **종합·집계(통계량)한 변수** | 사용자가 **특정 비즈니스 목적이나 가설을 가지고 새롭게 정의한 변수** |
| **대표 예시** | 기간별 구매금액 합계, 총 방문횟수, 평균 결제액 | 주구매 시간대, 구매 성향 지수, 휴면 가능성 점수, 고객 세분화 등급 |
| **특징** | 대부분의 분석 프로젝트에서 **공통적으로 재사용 가능** | 특정 분석 상황 및 분석가의 주관적 해석에 따라 **특화/주관적일 수 있음** |

### 🧠 빅분기 암기 팁
- **“파생변수 5대 생성법: 추 · 결 · 참 · 피 · 요”**:
  - **추**출: 한 값에서 특징 추출 (날짜 $\rightarrow$ 요일)
  - **결**합: 한 레코드 내 변수 결합 (매출 $\div$ 건수 $\rightarrow$ 건당금액)
  - **참**조: 다른 테이블 정보 참조 조인
  - **피**벗: 시간 종속 데이터 피벗
  - **요**약: 거래 레코드 요약 (분리 ❌)
- **“거래 레코드는 분리(X)가 아니라 요약(O)!”**

## 📌 [25번] 불균형 데이터(Imbalanced Data) 처리 기법 vs 변수 선택 기법

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 / 제3과목 모델링 $\rightarrow$ 불균형 데이터 처리 $\rightarrow$ 리샘플링(Resampling) 기법
- **핵심 의도**: 클래스 불균형 해결을 위한 데이터 샘플링 기법(언더/오버샘플링, SMOTE)과 변수 선택(Feature Selection)의 임베디드 기법을 구별할 수 있는지 평가.

### 🎯 정답
**④ 임베디드(Embedded) 기법 (변수 선택 기법에 해당 $\rightarrow$ 정답)**

### 📌 정답인 이유
- **불균형 데이터(Imbalanced Data) 처리 기법**: 특정 클래스(예: 사기 거래, 암 환자)의 비율이 극도로 적을 때 데이터 분포를 맞추는 **언더샘플링, 오버샘플링, SMOTE, 비용 민감 학습(Cost-Sensitive / Class Weight)** 등.
- **임베디드(Embedded) 기법**: Lasso(L1 규제), Ridge(L2 규제), 의사결정나무처럼 **모델 자체의 학습 알고리즘 내부에서 중요한 변수를 선택**하는 Feature Selection 기법이므로 불균형 처리 기법이 아님.

### 🔎 선지 정밀 분석: [불균형 데이터 3대 리샘플링 기법]
1. **언더샘플링 (Under-sampling)**: 다수 클래스의 데이터를 소수 클래스 크기에 맞추어 무작위/규칙 기반으로 축소 (⭕ 장점: 빠른 학습 / ❌ 단점: 중요한 정보 유실 위험).
2. **오버샘플링 (Over-sampling)**: 소수 클래스의 데이터를 단순 복제하여 증폭 (⭕ 장점: 정보 보존 / ❌ 단점: 특정 데이터 중복으로 인한 **과적합(Overfitting)** 발생).
3. **SMOTE (Synthetic Minority Over-sampling Technique)**: 소수 클래스 데이터 간의 $K$-최근접 이웃(KNN) 선형 보간을 통해 **새로운 가상 합성 샘플을 생성**하여 증폭 (⭕ 장점: 단순 복제 과적합 완화 / ❌ 단점: 노이즈 샘플 증폭 가능).
4. **임베디드 기법**: 변수 선택 기법임 (❌ 불균형 처리와 무관 $\rightarrow$ 정답).

### 📚 출제위원 시크릿 족보: [불균형 데이터 해결 전략 총정리]
| 접근 방식 | 구체적 해결 기법 | 핵심 동작 메커니즘 |
| :--- | :--- | :--- |
| **데이터 레벨 (Resampling)** | **언더샘플링** | 다수 클래스 샘플 삭제 (Random Under, Tomek Links, ENN) |
| | **오버샘플링** | 소수 클래스 샘플 단순 복제 (Random Over) |
| | **합성 오버샘플링 (SMOTE)** | 소수 클래스 이웃 간 가상 샘플 합성 ($x_{new} = x_i + \lambda(x_{knn} - x_i)$) |
| **알고리즘 레벨 (Cost-Sensitive)** | **가중치 조정 (Class Weight)** | 소수 클래스 오분류 시 손실함수에 더 큰 페널티 부여 |
| **평가 지표 레벨** | **지표 변경** | 정확도(Accuracy) 배제 $\rightarrow$ **F1-Score, ROC-AUC, PR-AUC, G-mean** 사용 |

### 🧠 빅분기 암기 팁
- **“언 · 오 · 스 = 불균형 처리 / 필 · 랩 · 임 = 변수 선택”**:
  - **언**더 / **오**버 / **스**모트 $\rightarrow$ 불균형 데이터 처리
  - **필**터 / **랩**퍼 / **임**베디드 $\rightarrow$ 변수 선택 (Feature Selection)
- **“SMOTE = 복제(X) $\rightarrow$ 합성(O)”**

## 📌 [26번] 불균형 데이터 처리 중 오버샘플링(Over-sampling)의 장단점 및 특성

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 불균형 데이터 처리 $\rightarrow$ 오버샘플링(Over-sampling)의 특성과 장단점
- **핵심 의도**: 오버샘플링 적용 시 데이터 크기 증가에 따른 계산량/학습시간 증가 및 과적합(Overfitting) 취약점을 정확히 인지하고 있는지 평가.

### 🎯 정답
**④ 데이터의 크기가 클 때 효과적이며 계산 시간이 감소한다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **오버샘플링의 계산 비용**: 소수 클래스 데이터를 증폭(복제 또는 합성)하므로 전체 훈련 데이터셋의 크기($N$)가 커짐.
- 데이터 수가 증가함에 따라 **계산량과 메모리 소모가 늘어나고 모델 학습 시간이 증가**함. (데이터 크기 축소 및 계산 시간 단축은 **언더샘플링(Under-sampling)**의 장점임).

### 🔎 선지 정밀 분석: [오버샘플링 핵심 특성]
1. **정보 손실 없음**: 다수 클래스 데이터를 삭제하지 않고 그대로 보존하므로 정보 손실(Information Loss)이 발생하지 않음 (⭕ 장점).
2. **과적합(Overfitting) 위험**: 단순 무작위 복제(Random Over-sampling) 시 동일한 소수 샘플을 반복 학습하여 일반화 성능이 저하될 수 있음 (⭕ 단점).
3. **대표 기법**: Random Over-sampling, **SMOTE**, **Borderline-SMOTE**, **ADASYN** 등 (⭕ 올바른 기법군).
4. **계산 시간 감소 오류**: 데이터 증폭으로 계산 시간은 증가함 (❌ 정답).

### 📚 출제위원 시크릿 족보: [Under-sampling vs Over-sampling 핵심 대조표]
| 비교 항목 | 언더샘플링 (Under-sampling) | 오버샘플링 (Over-sampling) |
| :--- | :--- | :--- |
| **조작 방식** | **다수 클래스 샘플을 삭제**하여 축소 | **소수 클래스 샘플을 복제/합성**하여 증폭 |
| **데이터 크기 / 속도** | 전체 데이터 감소 $\rightarrow$ **학습 속도 빠름, 계산량 감소** | 전체 데이터 증가 $\rightarrow$ **학습 속도 느림, 계산량 증가** |
| **치명적 단점** | 유용한 다수 클래스 데이터의 **정보 손실(Loss)** 발생 | 동일 샘플 중복 학습으로 인한 **과적합(Overfitting)** 위험 |
| **적합한 상황** | 전체 데이터가 매우 방대하여 학습 속도가 중요할 때 | 데이터 손실을 감당하기 어려운 소규모 불균형 데이터셋 |

### 🧠 빅분기 암기 팁
- **“언더 = 버린다 (빠름, 정보손실) / 오버 = 늘린다 (느림, 과적합)”**
- **“오버는 늘리니까 당연히 오래 걸린다!”** 1초 컷!

## 📌 [27번] 피어슨 상관계수(Pearson Correlation)의 범위와 해석

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기초통계 및 상관분석 $\rightarrow$ 피어슨 상관계수($r$)의 범위와 선형성 해석
- **핵심 의도**: 상관계수 $r=\pm 1$이 의미하는 바(완전한 선형 관계)와 비선형 관계의 구별, 그리고 $r=0$의 정확한 의미(선형관계 부재) 파악.

### 🎯 정답
**③ -1~+1 사이의 값으로 -1과 +1은 완전한 비선형관계를 의미한다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **피어슨 상관계수($r$)의 범위**: $-1 \le r \le +1$
  - $r = +1$: 모든 점이 양의 기울기를 갖는 하나의 직선 위에 완벽히 위치하는 **완전한 양(+)의 선형관계**.
  - $r = -1$: 모든 점이 음의 기울기를 갖는 하나의 직선 위에 완벽히 위치하는 **완전한 음(-)의 선형관계**.
- 따라서 $\pm 1$을 "완전한 비선형관계"라고 표현한 ③번은 명백한 오류임.

### 🔎 선지 정밀 분석: [상관분석 기초 원리]
1. **산점도(Scatter Plot) 활용**: 두 연속형 변수의 선형성, 방향, 이상치 분포를 시각적으로 확인 (⭕ 올바른 설명).
2. **양(+)과 음(-)의 방향성**: $X$ 증가 시 $Y$ 증가 $\rightarrow$ 양의 상관 / $X$ 증가 시 $Y$ 감소 $\rightarrow$ 음의 상관 (⭕ 올바른 설명).
3. **$\pm 1$ 비선형관계 오류**: 완벽한 선형관계임 (❌ 정답).
4. **피어슨 상관계수**: 모수적(Parametric) 연속형 두 변수 간 선형적 상관 강도를 측정 (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [상관계수 최빈출 함정 2가지]
1. **⚠️ 함정 1: $r = 0$은 '아무 관계가 없다'는 뜻이 아니다!**
   - $r = 0$은 **"두 변수 간에 '선형(직선)' 관계가 없다"**는 뜻이지, 관계 자체가 없다는 뜻이 아님.
   - 예: $Y = X^2$ (2차 함수 포물선)나 원($X^2 + Y^2 = 1$)처럼 **강력한 비선형 관계가 있어도 피어슨 상관계수 $r \approx 0$**이 나옴.
2. **⚠️ 함정 2: 피어슨(Pearson) vs 스피어만(Spearman) 비교**:
   - **피어슨**: 연속형 데이터, **선형적 관계**, 이상치에 민감 (모수적).
   - **스피어만**: 순서형/서열 척도, **단조 증가/감소 관계**, 순위 기반 계산으로 **이상치에 둔감/저항성** (비모수적).

### 🧠 빅분기 암기 팁
- **“피어슨은 직선! $\pm 1$은 완벽한 직선!”**
- **“$r=0$은 선형관계가 없는 것, 비선형 관계는 존재 가능!”** 1초 컷!

## 📌 [28번] 기술통계량 대푯값 - 중앙값(Median)의 계산

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기초 기술통계량 $\rightarrow$ 대푯값(평균, 중앙값, 최빈값) 중 중앙값(Median) 계산
- **핵심 의도**: 짝수 개수의 데이터가 주어졌을 때, 오름차순 정렬 후 중앙의 두 관측값의 산술평균을 정확히 계산할 수 있는지 평가.

### 🎯 정답
**④ 4.5**

### 📌 정답인 이유
1. **1단계: 데이터 오름차순 정렬 (필수!)**:
   - 원본 데이터: $\{1, 2, 5, 4, 7, 10\}$
   - 정렬 후 데이터: $\{1, 2, \mathbf{4}, \mathbf{5}, 7, 10\}$
2. **2단계: 데이터 개수($n$) 확인 및 중앙 위치 식별**:
   - $n = 6$ (짝수)
   - 중앙의 두 값은 $\frac{n}{2} = 3$번째 값($4$)과 $\frac{n}{2}+1 = 4$번째 값($5$)임.
3. **3단계: 중앙값 계산**:
   $$\text{Median} = \frac{4 + 5}{2} = 4.5$$

### 📚 출제위원 시크릿 족보: [중앙값(Median) 계산 표준 공식]
- **데이터 개수 $n$이 홀수(Odd)일 때**:
  $$\text{Median} = X_{\left(\frac{n+1}{2}\right)}$$
  - 예: $\{1, 3, \mathbf{5}, 8, 9\} \rightarrow \text{Median} = 5$
- **데이터 개수 $n$이 짝수(Even)일 때**:
  $$\text{Median} = \frac{X_{\left(\frac{n}{2}\right)} + X_{\left(\frac{n}{2}+1\right)}}{2}$$
  - 예: $\{1, 2, \mathbf{4}, \mathbf{5}, 7, 10\} \rightarrow \frac{4+5}{2} = 4.5$

### 🧠 빅분기 암기 팁
- **“중앙값은 무조건 정렬부터!”** (정렬 안 하고 원본에서 가운데 뽑으면 오답 함정에 빠짐!)
- **“홀수면 정가운데 1개, 짝수면 가운데 2개 평균!”**

## 📌 [29번] 시계열 데이터의 추세(Trend)와 변동성(Volatility) 해석

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 시각화 및 시계열 분석 $\rightarrow$ 시계열 그래프 해석
- **핵심 의도**: 장기적인 평균 진행 방향인 **추세(Trend)**와 기준선 주변의 출렁임 진폭인 **변동성(Volatility)**을 올바르게 구별하여 비즈니스 의미로 해석할 수 있는지 평가.

### 🎯 정답
**④ A회사가 B회사보다 변동성이 높은 사업구조를 가지고 있다**

### 📌 정답인 이유
- **A회사 시계열 패턴**: 장기적으로는 우상향하지만, 매월/분기별 급등락(출렁임) 진폭이 매우 큼 $\rightarrow$ **상승 추세 + 높은 변동성(High Volatility)**.
- **B회사 시계열 패턴**: 장기적으로 완만한 우상향 흐름이며, 진폭의 기복이 작고 안정적임 $\rightarrow$ **상승 추세 + 낮은 변동성(Low Volatility)**.
- 따라서 A회사가 B회사보다 변동성이 높은 사업구조를 갖는다는 ④번 설명이 가장 정확함.

### 🔎 오답 선지 정밀 분석
1. **A회사 완만한 증가 오류**: A회사는 급등·급락을 반복하므로 "완만하게 증가했다"고 볼 수 없음 (❌ 오답).
2. **B회사가 A보다 변동이 크다 오류**: 그래프 진폭상 $\text{변동성}_A > \text{변동성}_B$임 (❌ 오답).
3. **B회사가 낮게 시작 오류**: 시작 시점의 매출은 B회사($\approx 37$)가 A회사($\approx 30$)보다 높았음 (❌ 오답).

### 📚 출제위원 시크릿 족보: [시계열 4대 분해 요인 (Time Series Decomposition)]
| 시계열 구성 요인 | 핵심 의미 | 주요 발생 원인 / 예시 |
| :--- | :--- | :--- |
| **1. 추세 요인 (Trend, $T$)** | 장기간에 걸친 지속적인 상승 또는 하강 경향 | 인구 증가, 경제 성장, 기술 발전 |
| **2. 계절 요인 (Seasonal, $S$)** | **요일, 월, 사계절 등 일정한 고정 주기**로 반복되는 변화 | 여름철 빙과류 매출, 주말 영화관 관객 수 |
| **3. 순환 요인 (Cyclical, $C$)** | 일정하지 않은 주기로 장기간 반복되는 파동 | 3~10년 주기의 경기 변동 (호황/불황) |
| **4. 불규칙 요인 (Irregular, $I$)** | 예측할 수 없는 우연적이고 돌발적인 잡음(Noise) | 천재지변, 파업, 전쟁, 팬데믹 |

### 🧠 빅분기 암기 팁
- **“시계열 4대 요인: 추 · 계 · 순 · 불”**:
  - **추**세(Trend) $\rightarrow$ 장기 방향
  - **계**절(Seasonal) $\rightarrow$ 고정된 주기 반복 (1년/1주일 단위)
  - **순**환(Cyclical) $\rightarrow$ 비고정 장기 경기 파동
  - **불**규칙(Irregular) $\rightarrow$ 돌발 잡음
- **“추세(방향)와 변동성(출렁임)은 별개의 개념!”**

## 📌 [30번] 다변량(Multivariate) 데이터 시각화 기법 비교

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 시각화 $\rightarrow$ 다변량 시각화 기법(평행좌표, 산점도행렬, 체르노프 페이스 등)
- **핵심 의도**: 다수의 연속형 변수를 각각 평행한 세로축으로 나열하고 개별 관측치를 꺾은선으로 연결하는 **평행좌표그래프(Parallel Coordinates Plot)**의 정의 식별.

### 🎯 정답
**② 평행좌표그래프 (Parallel Coordinates Plot)**

### 📌 정답인 이유
- **평행좌표그래프(Parallel Coordinates Plot)**: $p$개의 다차원 변수를 수평으로 나란히 배치된 **평행한 세로 축(Parallel Axes)**으로 표현하고, 각 데이터 행(관측치)의 수치들을 하나의 **연속된 꺾은선(Polyline)**으로 연결하여 변수 간 패턴과 군집을 파악하는 기법.
- 문제 지문의 *“하나의 변수를 하나의 세로축으로 평행하게 배치하고 여러 변수의 값을 선으로 연결”*과 1:1 완벽 일치.

### 🔎 선지 정밀 분석: [다변량 4대 시각화 기법]
1. **산점도 행렬 (Scatter Plot Matrix / SPLOM)**: 여러 변수들 간의 1:1 2차원 산점도를 $N \times N$ 바둑판 격자 형태로 배열하여 변수 쌍별 상관성과 분포를 한눈에 파악.
2. **평행좌표그래프 (Parallel Coordinates Plot)**: 축은 평행하게 나열, 개별 관측치는 선으로 연결 (⭕ 정답).
3. **체르노프 페이스 (Chernoff Faces)**: 다차원 변수의 수치를 사람 얼굴의 생김새(눈 크기, 입 꼬리, 눈썹 각도, 코 길이 등)에 매핑하여 직관적으로 표현하는 기법.
4. **스몰 멀티플즈 (Small Multiples)**: 동일한 척도와 포맷을 가진 작은 서브 차트(패널)들을 격자형으로 반복 배열하여 그룹/범주 간 차이를 쉽게 비교하는 기법.

### 📚 출제위원 시크릿 족보: [다변량 데이터 시각화 핵심 비교표]
| 시각화 기법 | 핵심 표현 원리 | 시험 출제 키워드 |
| :--- | :--- | :--- |
| **평행좌표그래프** | 각 변수를 **평행한 축**으로 배치, 관측치를 **선(Line)**으로 연결 | **평행한 세로축**, 선으로 연결 |
| **산점도 행렬 (SPLOM)** | 모든 변수 쌍의 산점도를 **격자 행렬**로 배열 | **변수 쌍별 2차원 산점도 배열** |
| **체르노프 페이스** | 다변량 수치를 **얼굴 형태(눈/코/입)의 기하학적 특징**에 매핑 | **사람 얼굴 모양**, 20개 내외 변수 |
| **스몰 멀티플즈** | 동일한 유형의 작은 그래프를 **격자형으로 다중 반복 배치** | **작은 그래프 다중 반복 배열** |
| **스타 차트 (방사형)** | 중심점에서 방사형으로 뻗어나가는 축에 값 표시 | **방사형 다각형 / 레이더 차트** |

### 🧠 빅분기 암기 팁
- **“평행좌표 = 평행한 축 + 관측치 선 연결”**
- **“산점도행렬 = 바둑판 쌍 / 체르노프 = 얼굴 / 스몰멀티플즈 = 미니 차트 반복”** 1초 컷!

## 📌 [31번] 확률 표본 추출 4대 기법 (계통표본추출 vs 층화추출 vs 집락추출)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 수집 및 표본추출 $\rightarrow$ 확률적 표본 추출 방법(Probability Sampling)
- **핵심 의도**: 첫 번째 표본을 무작위로 선택한 후 일정한 간격($k=3$)마다 규칙적으로 표본을 추출하는 **계통표본추출(Systematic Sampling)**의 정의 식별.

### 🎯 정답
**③ 계통표본추출 (Systematic Sampling)**

### 📌 정답인 이유
- **계통표본추출(Systematic Sampling)**: 모집단 목록에서 첫 번째 원소를 무작위로 선택한 뒤, 표집 간격 $k = \frac{N}{n}$에 따라 매 $k$번째 원소를 규칙적으로 추출하는 방식 (예: 1번, 4번, 7번, 10번...).
- 문제 지문의 *“첫 번째 선택 후 3개 간격으로 샘플을 추출 (1 $\rightarrow$ 4 $\rightarrow$ 7)”*과 1:1 완벽 일치.

### 🔎 선지 정밀 분석: [확률표본추출 4대 기법]
1. **단순확률표본추출 (Simple Random Sampling, SRS)**: 모집단의 모든 개체가 동일한 확률로 무작위 선택됨 (난수표, 제비뽑기).
2. **층화확률표본추출 (Stratified Sampling)**: 모집단을 상호 배타적인 **'층(Stratum)'(성별, 연령, 지역 등)**으로 나눈 후, 각 층별 크기에 비례/불비례하여 무작위 추출 (**층 내 동질, 층 간 이질**).
3. **계통표본추출 (Systematic Sampling)**: 번호가 매겨진 목록에서 일정한 간격($k$)마다 규칙적 추출 (⭕ 정답).
4. **집락/군집추출 (Cluster Sampling)**: 모집단을 소규모의 **'군집(Cluster)'(학교, 학급, 마을 등)**으로 나눈 후, 무작위로 선택된 군집의 구성원 전체를 전수 조사 (**군집 내 이질, 군집 간 동질**).

### 📚 출제위원 시크릿 족보: [층화추출 vs 집락추출 최빈출 함정 대조]
| 구분 | 층화표본추출 (Stratified) | 집락/군집표본추출 (Cluster) |
| :--- | :--- | :--- |
| **그룹 내부 (내부 구성)** | **동질적 (Homogeneous)** (예: 20대 남성 그룹) | **이질적 (Heterogeneous)** (예: 한 학교/마을 내 다양한 학생/주민) |
| **그룹 간 (그룹 간 비교)** | **이질적 (Heterogeneous)** (20대 vs 50대) | **동질적 (Homogeneous)** (A학교 $\approx$ B학교 $\approx$ C학교) |
| **추출 방식** | **모든 층에서** 표본을 골고루 추출 | **몇 개 군집만 무작위로 골라** 군집 전체를 조사 |

### 🧠 빅분기 암기 팁
- **“계통 = 계단처럼 일정 간격 (매 $k$번째)”**
- **“층화 = 층 내 동질, 층 간 이질 / 모든 층에서 골고루”**
- **“집락 = 군집 내 이질, 군집 간 동질 / 몇 개 군집만 통째로”**
- **⚠️ 계통추출 주의점**: 데이터 목록에 주기성(Periodicity)이 존재하면 심각한 표본 편향(Bias) 발생!

## 📌 [32번] 조건부 확률과 베이즈 정리(Bayes' Theorem) 사후확률 계산

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기초 확률분포 및 추론통계 $\rightarrow$ 조건부 확률과 베이즈 정리(Bayes' Rule)
- **핵심 의도**: 생산 라인별 생산 비율과 불량률이 주어졌을 때, “불량품이 발견되었을 때 A라인 제품일 사후확률 $P(A|D)$”을 정확히 계산할 수 있는지 평가.

### 🎯 정답
**① 0.04 (4%)**

### 📌 정답인 이유: [1타 강사의 3초 컷 '1,000개 가상 생산법']
전체 생산량을 **1,000개**로 가정하면 복잡한 수식 없이 10초 만에 풀립니다:

| 생산 라인 | 생산 점유율 | 1,000개 중 생산량 | 라인별 불량률 | 발생 불량품 수 |
| :---: | :---: | :---: | :---: | :---: |
| **A 라인** | 10% | 100개 | 1% (0.01) | **1개** ($100 \times 0.01$) |
| **B 라인** | 30% | 300개 | 2% (0.02) | **6개** ($300 \times 0.02$) |
| **C 라인** | 60% | 600개 | 3% (0.03) | **18개** ($600 \times 0.03$) |
| **합계** | 100% | 1,000개 | - | **전체 불량 = 25개** |

- **사후확률 $P(A|\text{불량})$ 계산**:
  $$P(A|\text{불량}) = \frac{\text{A라인 불량품 수}}{\text{전체 불량품 수}} = \frac{1}{25} = 0.04 \quad (4\%)$$

### 📚 출제위원 시크릿 족보: [베이즈 공식 정석 유도]
$$P(A|D) = \frac{P(D|A) \cdot P(A)}{P(D)} = \frac{P(D|A) \cdot P(A)}{P(D|A)P(A) + P(D|B)P(B) + P(D|C)P(C)}$$
- **분자 (A라인 불량 결합확률)**: $0.01 \times 0.10 = 0.001$
- **분모 (전체 불량률 $P(D)$)**: $0.001 + (0.02 \times 0.3) + (0.03 \times 0.6) = 0.001 + 0.006 + 0.018 = 0.025$
- **사후확률**: $\frac{0.001}{0.025} = 0.04$

### 🧠 빅분기 암기 팁
- **“베이즈 정리는 1,000개 가정법으로 표 만들기!”**
- **“이미 일어난 사건(불량품)이 분모!”** $\rightarrow \frac{\text{해당 라인 불량}}{\text{전체 불량}}$
- **⚠️ 주의**: $P(D|A) = 0.01$ (A라인의 불량률)과 $P(A|D) = 0.04$ (불량품 중 A라인일 확률)은 완전히 다른 값!

## 📌 [33번] 이산/연속 확률분포의 분류와 베르누이 vs 이항분포 구분

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기초 기술통계 및 확률분포 $\rightarrow$ 이산형 vs 연속형 확률분포의 정의 및 특성
- **핵심 의도**: 단 1회의 성공/실패 시행을 다루는 **베르누이분포(Bernoulli)**와 $n$번 독립 반복 시행의 성공 횟수를 다루는 **이항분포(Binomial)**를 명확히 구분하는지 평가.

### 🎯 정답
**④ 베르누이분포는 성공할 확률이 $p$인 독립 시행을 $n$번 반복했을 때 성공 횟수를 나타내는 분포이다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **베르누이분포 (Bernoulli Distribution)**: 결과가 성공($X=1$) 또는 실패($X=0$) 두 가지만 존재하는 **단 1회($n=1$)의 시행**을 나타내는 이산확률분포.
- **이항분포 (Binomial Distribution)**: 성공 확률이 $p$인 베르누이 시행을 **독립적으로 $n$번 반복**했을 때 나타나는 총 성공 횟수($X \sim B(n, p)$)의 분포.
- 따라서 지문의 설명은 베르누이분포가 아니라 **이항분포**의 정의임.

### 🔎 선지 정밀 분석: [확률분포 4대 체계]
1. **이산확률분포군**: 이항분포, 초기하분포, 포아송분포, 기하분포, 다항분포 등 셀 수 있는 이산 확률변수의 분포 (⭕ 올바른 설명).
2. **연속확률분포군**: 정규분포($Z$), $t$분포, 카이제곱분포($\chi^2$), $F$분포 등 실수 구간에서 정의되는 연속 확률변수의 분포 (⭕ 올바른 설명).
3. **이산균등분포 (Discrete Uniform)**: 표본공간 내 모든 이산 확률변수 값이 발생할 확률이 $P(X=x) = \frac{1}{k}$로 모두 동일한 분포 (예: 공정한 주사위) (⭕ 올바른 설명).
4. **베르누이 정의 오류**: $n$회 반복 시행은 이항분포임 (❌ 정답).

### 📚 출제위원 시크릿 족보: [주요 이산확률분포 핵심 비교표]
| 이산확률분포 | 핵심 특징 및 발생 조건 | 평균 ($E(X)$) | 분산 ($V(X)$) |
| :--- | :--- | :---: | :---: |
| **베르누이분포** | **단 1회의 성공/실패 시행** ($n=1$) | $p$ | $p(1-p)$ |
| **이항분포** | 베르누이 시행을 **독립적으로 $n$회 반복** (복원추출 성격) | $np$ | $np(1-p)$ |
| **포아송분포** | **단위 시간/공간당** 발생하는 희귀 사건의 발생 횟수 | $\lambda$ | $\lambda$ (평균=분산) |
| **초기하분포** | 유한 모집단에서 **비복원추출** 시 성공 횟수 (시행 간 종속) | $n \frac{K}{N}$ | $n \frac{K}{N}\frac{N-K}{N}\frac{N-n}{N-1}$ |
| **기하분포** | 처음으로 성공할 때까지 필요한 **시행 횟수** | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ |

### 🧠 빅분기 암기 팁
- **“베는 한 번(1회), 이는 여러 번($n$회)”**:
  - 베르누이 $\rightarrow$ 1번 시행
  - 이항분포 $\rightarrow$ $n$번 반복
- **“이산형 4총사: 베 · 이 · 포 · 초”** (베르누이, 이항, 포아송, 초기하)
- **“연속형 4총사: 정 · t · 카 · F”** (정규, t, 카이제곱, F)

## 📌 [34번] 이산확률분포 vs 연속확률분포 식별 (정규분포)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기초 기술통계 및 확률분포 $\rightarrow$ 확률변수의 유형별 분포 분류
- **핵심 의도**: 이항분포, 균등분포, 포아송분포 등 이산형 분포 사이에서 대표적인 연속확률분포인 **정규분포(Normal Distribution)**를 식별할 수 있는지 평가.

### 🎯 정답
**③ 정규분포 (Normal Distribution)**

### 📌 정답인 이유
- **정규분포 (Normal Distribution)**: 확률변수가 연속적인 모든 실수 구간($-\infty < X < \infty$)을 가지며, 평균($\mu$)과 분산($\sigma^2$)으로 정의되는 **대표적인 연속확률분포**.
- **이항분포 / 포아송분포**: 성공 횟수나 사건 발생 횟수처럼 셀 수 있는 정수($0, 1, 2, \dots$)를 취하는 **이산확률분포**.
- 따라서 보기 중 정규분포만 연속확률분포임.

### 🔎 선지 정밀 분석: [확률변수 유형 대조]
1. **이항분포 (Binomial)**: $n$번 독립 시행 중 성공 횟수 $\rightarrow$ **이산확률분포**.
2. **균등분포 (Uniform)**: 주사위 눈($1\sim6$)처럼 유한한 이산값을 균등하게 갖는 **이산균등분포**로 출제됨 $\rightarrow$ **이산확률분포**.
3. **정규분포 (Normal)**: 가우스 분포, 좌우 대칭 종 모양 곡선 $\rightarrow$ **연속확률분포 (정답)**.
4. **포아송분포 (Poisson)**: 일정 시간/공간당 희귀 사건 발생 횟수 $\rightarrow$ **이산확률분포**.

### 📚 출제위원 시크릿 족보: [이산형 vs 연속형 3초 컷 분류표]
| 분류 기준 | 이산확률분포 (Discrete) | 연속확률분포 (Continuous) |
| :--- | :--- | :--- |
| **확률변수 특성** | 셀 수 있는 값 (이산 정수: $0, 1, 2 \dots$) | 특정 구간 내 모든 실수 (키, 몸무게, 시간, 온도) |
| **확률 함수** | 확률질량함수 (PMF: $P(X=x)$) | 확률밀도함수 (PDF: $f(x)$, 면적이 확률) |
| **대표 분포군** | **베르누이, 이항, 포아송, 초기하, 기하, 다항** | **정규분포, $t$분포, 카이제곱분포, $F$분포, 지수분포** |

### 🧠 빅분기 암기 팁
- **“정 · t · 카 · F = 무조건 연속형!”**
- **“횟수(성공 횟수, 발생 횟수)를 세면 이산형!”**
- **⚠️ 균등분포 주의점**: 균등분포는 이산균등(주사위)과 연속균등(구간 $[a,b]$) 두 종류가 모두 존재하므로, 선지 구성에서 확실한 연속형(정규분포)을 골라내는 것이 포인트!

## 📌 [35번] 가설검정 및 추론통계 검정 통계량 분포 선택 기준 ($t$분포)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 추론통계 및 가설검정 $\rightarrow$ 모평균 검정 분포 선택 기준
- **핵심 의도**: 모분산($\sigma^2$)을 모르고 표본의 크기가 작은 소표본($n < 30$)인 환경에서 모평균을 추정·검정할 때 사용하는 확률분포 식별.

### 🎯 정답
**③ $t$분포 (Student's $t$-distribution)**

### 📌 정답인 이유
- **모평균 검정 통계량 선택 기준**:
  - 모분산($\sigma^2$)을 알고 있는 경우 $\rightarrow$ **표준정규분포 ($Z$)** 활용 ($Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}$).
  - **모분산($\sigma^2$)을 모르고 표본표준편차($s$)를 사용하는 소표본($n < 30$)** $\rightarrow$ **자유도 $df = n-1$인 $t$분포** 활용 ($t = \frac{\bar{X} - \mu}{s / \sqrt{n}}$).
- $t$분포는 표본 크기가 작을 때 발생하는 불확실성을 반영하여 정규분포보다 양쪽 꼬리가 두껍고(Heavy-tailed), 표본 크기 $n \rightarrow \infty$가 됨에 따라 표준정규분포로 수렴함.

### 🔎 선지 정밀 분석: [추론통계 4대 검정분포 매칭]
1. **$Z$분포 (표준정규분포)**: 모분산을 알거나, 중심극한정리에 의해 표본이 충분히 큰 대표본($n \ge 30$)일 때 활용.
2. **카이제곱분포 ($\chi^2$)**: 단일 집단의 **모분산($\sigma^2$) 검정**, 범주형 데이터의 적합도(Goodness-of-fit) 및 독립성/동질성 검정에 활용.
3. **$t$분포**: **모분산 미지 + 소표본 모평균 검정 / 두 집단 평균 차이 검정** (⭕ 정답).
4. **$F$분포**: 두 집단의 **모분산 비($s_1^2 / s_2^2$) 검정**, 3개 이상 집단의 평균 비교인 **분산분석(ANOVA)**, 다중회귀모형의 유의성 검정에 활용.

### 📚 출제위원 시크릿 족보: [검정 통계량 4대 분포 1초 컷 선택 공식]
| 검정 목적 / 대상 | 모분산 ($\sigma^2$) 인지 여부 | 표본 크기 ($n$) | 사용할 검정 분포 |
| :--- | :---: | :---: | :---: |
| **모평균 ($\mu$) 검정** | **알고 있음 ($\sigma$ 기지)** | 무관 | **$Z$분포 (표준정규분포)** |
| **모평균 ($\mu$) 검정** | **모름 ($\sigma$ 미지)** | **소표본 ($n < 30$)** | **$t$분포 ($df = n-1$)** |
| **모평균 ($\mu$) 검정** | **모름 ($\sigma$ 미지)** | **대표본 ($n \ge 30$)** | **$Z$분포** (중심극한정리 근사) 또는 $t$분포 |
| **단일 모분산 ($\sigma^2$) 검정** | - | - | **카이제곱분포 ($\chi^2$)** |
| **두 모분산 비 ($s_1^2 / s_2^2$) 비교 / ANOVA** | - | - | **$F$분포** |

### 🧠 빅분기 암기 팁
- **“평균 검정인데 모분산 모르면 무조건 t!” (모르면 t!)**
- **“분산 1개 검정 $\rightarrow$ 카이제곱($\chi^2$) / 분산 2개 비교 $\rightarrow$ F”**
- **“자유도 $df = n-1$”** (실기 파이썬 t-test 계산 시 필수!)

## 📌 [36번] 점추정(Point Estimation) - 추정량(Estimator) vs 추정값(Estimate)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 통계적 추론 $\rightarrow$ 점추정의 기본 개념(모수, 추정량, 추정값)
- **핵심 의도**: 모평균($\mu$)을 추정하기 위한 표본 통계량 공식인 **추정량(Estimator)**과 실제 표본을 통해 계산된 구체적인 수치인 **추정값(Estimate)**을 정확히 구분하는지 평가.

### 🎯 정답
**② $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i, \quad \bar{x} = 50$**

### 📌 정답인 이유
- **추정량 (Estimator, 확률변수/공식)**: 미지의 모수를 추정하기 위해 사용되는 표본통계량 자체 ($\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$).
- **추정값 (Estimate, 구체적 수치)**: 표본 관측 데이터를 추정량 공식에 대입하여 계산해 낸 구체적인 실수 값 ($\bar{x} = 50\text{만 원}$).
- 따라서 표본통계량 공식이 '추정량', 실제 계산된 수치 50이 '추정값'으로 올바르게 짝지어진 것은 ②번임.

### 🔎 선지 정밀 분석: [통계적 추론 3대 개념 대조]
1. **①번 선지**: 수치(50)를 추정량, 공식을 추정값으로 거꾸로 매칭하여 오답 (❌).
2. **②번 선지**: 공식($\bar{X}$) $\rightarrow$ 추정량 / 수치($50$) $\rightarrow$ 추정값으로 정확히 매칭 (⭕ 정답).
3. **③번 선지**: 평균값 50을 표본 수 500으로 다시 나누는 무의미한 연산 (❌).
4. **④번 선지**: 모평균 추정 문제인데 표본분산 공식($S^2$)을 제시하여 오답 (❌).

### 📚 출제위원 시크릿 족보: [모수 vs 추정량 vs 추정값 비교표]
| 구분 | 통계적 성격 | 모평균 추정 예시 | 모분산 추정 예시 |
| :--- | :--- | :--- | :--- |
| **모수 (Parameter)** | 모집단의 고정된 미지의 특성값 (상수) | 모평균 $\mu$ | 모분산 $\sigma^2$ |
| **추정량 (Estimator)** | 모수를 추정하는 **표본통계량 / 계산 공식** (확률변수) | 표본평균 $\bar{X} = \frac{1}{n}\sum X_i$ | 표본분산 $S^2 = \frac{1}{n-1}\sum (X_i - \bar{X})^2$ |
| **추정값 (Estimate)** | 실제 표본을 넣어 산출된 **구체적인 실수 값** (상수) | $\bar{x} = 50.0$ | $s^2 = 12.4$ |

### 🧠 빅분기 암기 팁
- **“량은 공식(통계량), 값은 숫자(수치)!”**:
  - 추정**량** $\rightarrow$ 계산 **공식** ($\bar{X}$)
  - 추정**값** $\rightarrow$ 계산된 **값/숫자** ($\bar{x} = 50$)
- **“모수($\mu$) $\rightarrow$ 추정량($\bar{X}$) $\rightarrow$ 추정값($\bar{x}=50$)”** 1초 컷!

## 📌 [37번] 모수의 점추정(Point Estimation) 방법 vs 가설검정(Hypothesis Testing)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 통계적 추론 $\rightarrow$ 점추정 방법(Point Estimation Methods)과 가설검정의 구분
- **핵심 의도**: 모수를 하나의 값으로 추정하는 점추정 방법(적률법, MLE, 최소제곱법) 및 평가 척도(MSE)와 가설검정의 기준인 **유의수준(Significance Level, $\alpha$)**을 구별하는지 평가.

### 🎯 정답
**③ 유의수준 (Significance Level)**

### 📌 정답인 이유
- **유의수준 ($\alpha$)**: **가설검정(Hypothesis Testing)**에서 귀무가설($H_0$)이 참임에도 불구하고 기각할 오류인 **제1종 오류(Type I Error)의 최대 허용 확률**(통상 0.05, 0.01)을 의미함.
- 따라서 유의수준은 가설검정의 기각역을 결정하는 기준이지, 모수를 하나의 값으로 추정하는 **점추정(Point Estimation)**과는 관련이 없음.

### 🔎 선지 정밀 분석: [점추정 핵심 기법 및 평가 지표]
1. **평균제곱오차 (MSE, Mean Squared Error)**: 추정량의 분산과 편향의 제곱의 합($\text{MSE}(\hat{\theta}) = \text{Var}(\hat{\theta}) + [\text{Bias}(\hat{\theta})]^2$)으로, **점추정량의 품질과 우수성을 평가**하는 대표적 척도 (⭕ 점추정 관련).
2. **적률법 (Method of Moments, MOM)**: 표본적률을 모적률과 같다고 놓고 연립방정식을 풀어 모수를 추정하는 **고전적 점추정 기법** (⭕ 점추정 관련).
3. **유의수준 ($\alpha$)**: 가설검정의 제1종 오류 허용 확률 (❌ 점추정과 무관 $\rightarrow$ 정답).
4. **최대가능도추정법 (MLE, Maximum Likelihood Estimation)**: 주어진 표본 데이터가 관측될 결합확률(가능도함수 $L(\theta)$)을 최대화하는 모수를 찾는 **가장 대표적인 점추정 기법** (⭕ 점추정 관련).

### 📚 출제위원 시크릿 족보: [점추정 3대 산출법 vs 4대 평가 조건]
| 구분 | 핵심 내용 및 대표 항목 | 시험 출제 포인트 |
| :--- | :--- | :--- |
| **점추정 3대 산출법** | **적 · 우 · 소**<br>1. **적**률법 (MOM)<br>2. 최대**우**도/가능도법 (MLE)<br>3. 최소**소**제곱법 (LSE/OLS) | 모수 $\theta$를 수치로 직접 산출하는 알고리즘 |
| **좋은 점추정량의 4대 조건** | **불 · 효 · 일 · 충**<br>1. **불편성 (Unbiasedness)**: $E(\hat{\theta}) = \theta$<br>2. **효율성 (Efficiency)**: 분산이 최소<br>3. **일치성 (Consistency)**: $n \to \infty$ 시 $\hat{\theta} \to \theta$<br>4. **충분성 (Sufficiency)**: 모수의 모든 정보 포함 | 우수한 추정량을 선택하는 4대 평가 기준 |

### 🧠 빅분기 암기 팁
- **“점추정 산출 3대장: 적 · 우 · 소 (적률, 최대우도, 최소제곱)”**
- **“좋은 추정량 4대 조건: 불 · 효 · 일 · 충 (불편성, 효율성, 일치성, 충분성)”**
- **“유의수준($\alpha$) / p-value / 기각역 $\rightarrow$ 가설검정 냄새!”** 1초 컷!

## 📌 [38번] $t$분포를 이용한 모평균($\mu$)의 95% 신뢰구간(Confidence Interval) 계산

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 통계적 추론 $\rightarrow$ 모평균의 구간추정(Interval Estimation)
- **핵심 의도**: 모분산을 모르고 표본 크기가 작은 환경($n=16, s=12$)에서 $t$분포 임계값을 이용하여 모평균의 신뢰구간을 정확히 계산할 수 있는지 평가.

### 🎯 정답
**① $12.61 \le \mu \le 25.39$**

### 📌 정답인 이유: [1타 강사의 4단계 신뢰구간 계산 공식]
1. **1단계: 분포 선택 및 기본 데이터 정리**:
   - 표본 크기: $n = 16$ (소표본, $df = 16 - 1 = 15$)
   - 표본평균: $\bar{x} = 19$
   - 표본표준편차: $s = 12$ ($\sigma$ 미지 $\rightarrow$ **$t$분포 사용**)
   - 95% $t$ 임계값: $t_{0.025, 15} = 2.131$
2. **2단계: 표준오차(Standard Error, SE) 계산**:
   $$\text{SE} = \frac{s}{\sqrt{n}} = \frac{12}{\sqrt{16}} = \frac{12}{4} = 3$$
3. **3단계: 오차한계(Margin of Error, ME) 계산**:
   $$\text{ME} = t \times \text{SE} = 2.131 \times 3 = 6.393$$
4. **4단계: 모평균 신뢰구간 산출**:
   $$\bar{x} \pm \text{ME} = 19 \pm 6.393 \implies [12.607, 25.393] \approx [12.61, 25.39]$$

### 📚 출제위원 시크릿 족보: [구간추정 만능 구조 & $Z$ vs $t$ 공식]
$$\text{신뢰구간} = \mathbf{\text{점추정값}} \pm \mathbf{\text{임계값}} \times \mathbf{\text{표준오차}}$$
- **모분산 $\sigma^2$을 알 때 ($Z$ 신뢰구간)**:
  $$\bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \quad (\text{95\%일 때 } z_{0.025} = 1.96, \text{ 99\%일 때 } z_{0.005} = 2.58)$$
- **모분산 $\sigma^2$을 모를 때 ($t$ 신뢰구간, 소표본 $n<30$)**:
  $$\bar{x} \pm t_{\alpha/2, n-1}\frac{s}{\sqrt{n}}$$

### 🧠 빅분기 암기 팁
- **“신뢰구간 = 점추정값 $\pm$ 임계값 $\times$ 표준오차”**
- **“표준오차(SE) = $\frac{s}{\sqrt{n}}$”** (분산이 아니라 표준편차를 $\sqrt{n}$으로 나눈다!)
- **“$SE = 12/4 = 3 \rightarrow ME = 2.131 \times 3 = 6.393 \rightarrow 19 \pm 6.393$”** 5초 컷!

## 📌 [39번] 가설검정 오류(제1종·제2종 오류)와 머신러닝 혼동행렬(Confusion Matrix) 매핑

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 통계적 추론 $\rightarrow$ 가설검정의 오류(Type I & Type II Errors)와 검정력
- **핵심 의도**: 귀무가설($H_0$)의 참/거짓과 기각/채택 결정에 따른 4개 영역(a: 정상, b: 제1종 오류, c: 제2종 오류, d: 검정력)을 정확히 매칭하는지 평가.

### 🎯 정답
**③ (b), (c)**

### 📌 정답인 이유: [가설검정 2×2 의사결정 매트릭스]
| 실제 상황 \ 검정 판단 | $H_0$ 채택 (효과 없음 판정) | $H_0$ 기각 / $H_1$ 채택 (효과 있음 판정) |
| :--- | :---: | :---: |
| **실제 $H_0$ 참 (효과 없음)** | (a) 올바른 결정 ($1 - \alpha$, 신뢰수준) | **(b) 제1종 오류 ($\alpha$, Type I Error, $\text{FP}$)** |
| **실제 $H_0$ 거짓 / $H_1$ 참 (효과 있음)** | **(c) 제2종 오류 ($\beta$, Type II Error, $\text{FN}$)** | (d) 올바른 결정 ($1 - \beta$, 검정력 Power, $\text{TP}$) |

- **(b) 제1종 오류 ($\alpha$)**: 실제로 귀무가설이 참인데, 귀무가설을 잘못 기각함 (**생사람 잡음 / 위양성 FP**).
- **(c) 제2종 오류 ($\beta$)**: 실제로 귀무가설이 거짓인데, 귀무가설을 기각하지 못하고 채택함 (**범인 놓침 / 위음성 FN**).

### 📚 출제위원 시크릿 족보: [가설검정 $\leftrightarrow$ 머신러닝 Confusion Matrix 1:1 완벽 대응표]
| 가설검정 개념 | 혼동행렬 (Confusion Matrix) | 직관적 의미 (암 검진 비유) | 확률 공식 매칭 |
| :--- | :--- | :--- | :--- |
| **신뢰수준 ($1 - \alpha$)** | **TN (True Negative)** | 정상인을 정상으로 판정 | $P(\text{채택} \mid H_0\text{ 참})$ |
| **제1종 오류 ($\alpha$, 유의수준)** | **FP (False Positive)** | **정상인을 암 환자로 오진 (위양성)** | **$\text{FPR} = \frac{\text{FP}}{\text{FP}+\text{TN}}$** |
| **제2종 오류 ($\beta$)** | **FN (False Negative)** | **암 환자를 정상인으로 놓침 (위음성)** | **$\text{FNR} = \frac{\text{FN}}{\text{TP}+\text{FN}}$** |
| **검정력 ($1 - \beta$, Power)** | **TP (True Positive)** | **암 환자를 암으로 정확히 검출** | **$\text{TPR} = \text{Recall} = \text{Sensitivity}$** |

### 🧠 빅분기 암기 팁
- **“1종 오류 = $\alpha$ = FP = 생사람 잡음 (없는데 있다고 기각)”**
- **“2종 오류 = $\beta$ = FN = 범인 놓침 (있는데 없다고 채택)”**
- **“검정력 = $1 - \beta$ = TPR = Recall(재현율) = 민감도(Sensitivity)”**
- **“$\alpha$와 $\beta$는 상충관계(Trade-off) $\rightarrow$ 표본크기 $n$을 키워야 둘 다 줄일 수 있음!”**

## 📌 [40번] 가설검정의 4대 핵심 지표와 의사결정 기준 (p-value vs 유의수준)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 통계적 추론 $\rightarrow$ 가설검정 지표 정의 및 판정 규칙
- **핵심 의도**: 유의수준($\alpha$), 신뢰수준($1-\alpha$), 검정력($1-\beta$)의 정확한 정의와 귀무가설 기각 여부를 결정하는 기준($p$-value와 $\alpha$ 비교)을 평가.

### 🎯 정답
**④ 위험도는 귀무가설의 채택·기각 기준이 되는 값이다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **귀무가설 채택/기각의 실제 기준**: 가설검정에서 귀무가설을 기각할지 여부를 결정하는 기준선은 **유의수준(Significance Level, $\alpha$)** 또는 기각역 임계값(Critical Value)이며, 실제 검정통계량으로부터 계산된 **유의확률($p$-value)**과 비교하여 판정함.
  - $p\text{-value} < \alpha \implies H_0$ 기각 (통계적으로 유의한 차이 있음)
  - $p\text{-value} \ge \alpha \implies H_0$ 기각 실패 / 채택 (통계적으로 유의한 차이 없음)
- 따라서 이를 모호하게 '위험도'라고 정의한 ④번 설명은 통계학적 정의로서 부적절함.

### 🔎 선지 정밀 분석: [가설검정 4대 지표 개념 검증]
1. **유의수준 ($\alpha$)**: 귀무가설($H_0$)이 참일 때 이를 기각하는 **제1종 오류를 범할 최대 허용 한계 확률** (통상 0.05 또는 0.01) (⭕ 올바른 설명).
2. **신뢰수준 ($1 - \alpha$)**: 귀무가설($H_0$)이 참일 때 이를 기각하지 않고 올바르게 유지(채택)할 확률 (95% 또는 99%) (⭕ 올바른 설명).
3. **검정력 ($1 - \beta$)**: 대립가설($H_1$)이 참(귀무가설 거짓)일 때 이를 올바르게 탐지하여 **귀무가설을 제대로 기각할 확률** (⭕ 올바른 설명).
4. **위험도 기준 오류**: 가설검정의 채택/기각 기준은 유의수준($\alpha$) 및 $p$-value임 (❌ 정답).

### 📚 출제위원 시크릿 족보: [가설검정 4대 지표 & $p$-value 판정 3초 컷]
| 지표 명칭 | 기호 및 공식 | 핵심 통계적 의미 |
| :--- | :---: | :--- |
| **유의수준** | $\alpha$ | **제1종 오류의 최대 허용 한계** (FP 허용 기준) |
| **신뢰수준** | $1 - \alpha$ | $H_0$가 참일 때 올바르게 $H_0$를 유지할 확률 (TN 확률) |
| **제2종 오류** | $\beta$ | $H_0$가 거짓임에도 $H_0$를 기각하지 못할 확률 (FN 확률) |
| **검정력 (Power)** | $1 - \beta$ | $H_0$가 거짓일 때 올바르게 $H_0$를 기각할 확률 (TP, Recall) |
| **유의확률 ($p$-value)** | $P(\text{극단 관측} \mid H_0)$ | 귀무가설이 맞다는 전제하에 현재 표본 이상의 극단값이 나올 확률 |

### 🧠 빅분기 암기 팁
- **“$p$값이 $\alpha$보다 작으면 ($p < \alpha$) $\rightarrow$ 귀무가설 쫓아낸다 ($H_0$ 기각, 쌉유의!)”**
- **“$p$값이 $\alpha$보다 크면 ($p \ge \alpha$) $\rightarrow$ 귀무가설 못 쫓아낸다 ($H_0$ 채택)”**
- **“$\alpha$ = 1종 오류 / $1-\alpha$ = 신뢰수준 / $\beta$ = 2종 오류 / $1-\beta$ = 검정력”**

## 📌 [41번] 데이터 분석 성숙도 4대 유형 - 진단 분석(Diagnostic Analytics)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 / 제1과목 분석 기획 $\rightarrow$ 분석 유형 및 방법 $\rightarrow$ Gartner 4대 분석 성숙도 모델
- **핵심 의도**: 과거 데이터를 토대로 “왜 이런 현상이 일어났는지 근본 원인(Root Cause)”을 규명하는 **진단 분석(Diagnostic Analytics)**의 정의 식별.

### 🎯 정답
**② 과거 데이터로 왜 일어났는지 찾고, 주어진 상황의 근본 원인을 파악하는 분석**

### 📌 정답인 이유
- **진단 분석(Diagnostic Analytics)**의 핵심 질문: **“왜 발생했는가? (Why did it happen?)”**
- 과거 및 현재 데이터를 드릴다운(Drill-down), 데이터 마이닝, 인과관계 추정 등을 통해 탐색하여 현상 이면에 숨겨진 **근본 원인(Root Cause)**을 밝혀내는 분석임.

### 🔎 선지 정밀 분석: [분석 성숙도 4단계 매칭]
1. **①번 선지**: 원하는 결과를 달성하기 위한 행동 방향과 최적화 솔루션 제시 $\rightarrow$ **처방 분석 (Prescriptive Analytics)**.
2. **②번 선지**: 왜 일어났는지 근본 원인 파악 $\rightarrow$ **진단 분석 (Diagnostic Analytics, 정답)**.
3. **③번 선지**: 현재 데이터를 통해 미래에 무엇이 일어날지 예측 $\rightarrow$ **예측 분석 (Predictive Analytics)**.
4. **④번 선지**: 과거~현재 데이터로 무슨 일이 일어났는지 요약·설명 $\rightarrow$ **기술 분석 (Descriptive Analytics)**.

### 📚 출제위원 시크릿 족보: [Gartner 4대 분석 성숙도 완벽 비교표]
| 분석 성숙도 단계 | 핵심 질문 (Key Question) | 주요 분석 기법 | 비즈니스 가치 & 난이도 |
| :--- | :--- | :--- | :---: |
| **1. 기술 분석 (Descriptive)** | **무슨 일이 일어났는가?** (What happened?) | BI 대시보드, 기초통계량, 요약 보고서 | 난이도 낮음 / 가치 기초 |
| **2. 진단 분석 (Diagnostic)** | **왜 일어났는가?** (Why did it happen?) | 드릴다운, 상관분석, 다차원 분석, 원인 규명 | 난이도 중간 / 원인 파악 |
| **3. 예측 분석 (Predictive)** | **무슨 일이 일어날 것인가?** (What will happen?) | 머신러닝 회귀/분류, 시계열 예측, 통계 모델링 | 난이도 높음 / 미래 대비 |
| **4. 처방 분석 (Prescriptive)** | **어떻게 대응/행동해야 하는가?** (How can we make it happen?) | 시뮬레이션, 수학적 최적화, 의사결정 추천 엔진 | 난이도 최고 / 최적화 달성 |

### 🧠 빅분기 암기 팁
- **“무 · 왜 · 앞 · 어” 1초 컷!**:
  - **무**슨 일? $\rightarrow$ 기술 분석 (Descriptive)
  - **왜** 일어났나? (원인) $\rightarrow$ **진단 분석 (Diagnostic)**
  - **앞**으로 무슨 일? (미래) $\rightarrow$ 예측 분석 (Predictive)
  - **어**떻게 해야 하나? (행동/대응) $\rightarrow$ 처방 분석 (Prescriptive)

## 📌 [42번] 머신러닝 학습 유형 - 비지도학습(Unsupervised Learning)의 실제 적용 사례

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 머신러닝 기초 $\rightarrow$ 지도학습 vs 비지도학습의 비즈니스 사례 매핑
- **핵심 의도**: 라벨($Y$) 없이 데이터 자체의 분포/패턴을 학습하는 **비지도학습(이상치 탐지, 연관분석, 군집화)**과 정답 수치를 예측하는 **지도학습(회귀)**을 명확히 구분하는지 평가.

### 🎯 정답
**② ㄱ, ㄴ**

### 📌 정답인 이유
- **ㄱ. 신용카드의 비정상적 고액 거래 감지 (⭕ 비지도학습)**:
  - 정상적인 거래 데이터의 패턴/밀도를 학습한 후, 정상 분포에서 크게 벗어난 이상치(Outlier)를 탐지하는 **이상 탐지(Anomaly Detection)** 기법 (Isolation Forest, One-Class SVM, 오토인코더 등 비지도학습 활용).
- **ㄴ. 기저귀를 사면 맥주도 함께 구매하는 패턴 발견 (⭕ 비지도학습)**:
  - 정답 라벨 없이 거래 장바구니 데이터에서 항목 간의 동시 발생 패턴(조건부 연관성)을 찾아내는 **연관 규칙 분석(Association Rule Analysis, Apriori)** $\rightarrow$ 비지도학습.
- **ㄷ. 집 크기에 따른 매매비용 예측 (❌ 지도학습)**:
  - 입력 변수 $X$(집 크기)로부터 연속형 정답 라벨 $Y$(매매비용)를 예측하는 **선형/비선형 회귀(Regression)** $\rightarrow$ 지도학습.

### 📚 출제위원 시크릿 족보: [머신러닝 3대 학습 유형별 실무 비즈니스 사례]
| 학습 유형 | 세부 분석 기법 | 대표적인 비즈니스 활용 사례 | 정답 라벨 ($Y$) 유무 |
| :--- | :--- | :--- | :---: |
| **지도학습 (Supervised)** | **분류 (Classification)** | 스팸 메일 필터링, 질병 유무 판정, 고객 이탈 예측 | 있음 (범주형 라벨) |
| | **회귀 (Regression)** | **집값 예측**, 주가 예측, 매출액 추정, 수요량 예측 | 있음 (연속형 수치) |
| **비지도학습 (Unsupervised)** | **군집화 (Clustering)** | 고객 세분화(Segmentation), 상권 분석 | 없음 ($X$만 존재) |
| | **연관분석 (Association)** | **장바구니 분석 (기저귀 $\leftrightarrow$ 맥주)**, 교차판매 추천 | 없음 |
| | **이상탐지 (Anomaly)** | **신용카드 FDS(이상거래탐지)**, 공장 센서 불량 탐지 | 없음 |
| | **차원축소 (Dimension)** | PCA, t-SNE 고차원 시각화 | 없음 |

### 🧠 빅분기 암기 팁
- **“분류 · 회귀 = 정답 있는 지도학습!”**
- **“군집 · 연관 · 이상탐지 · 차원축소 = 정답 없는 비지도학습!”**
- **“기저귀 $\leftrightarrow$ 맥주 = 연관분석 (비지도) 1초 컷!”**

## 📌 [43번] 지도학습의 유형 식별 - 손글씨 숫자(MNIST) 인식 (분류 vs 다지분류)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 지도학습 모델링 $\rightarrow$ 회귀(Regression) vs 분류(Classification)의 식별
- **핵심 의도**: 손글씨 이미지로부터 숫자($0\sim9$)를 판별하는 문제가 연속 수치 예측(회귀)이 아닌 **범주형 라벨 판별(분류, Classification)**임을 파악하는지 평가.

### 🎯 정답
**② 분류 (Classification)**
*(※ 출제자 의도: 머신러닝 대분류 체계인 '회귀 vs 분류'의 구분을 묻는 문제로, 공단 정답표는 상위 개념인 ② '분류'로 처리됨)*

### 📌 정답인 이유 및 수험생 피드백 (② '분류' vs ③ '다지분류')
- **수험생의 고민 (③ 다지분류를 고른 이유)**:
  - 손글씨 숫자 $0\sim9$는 10개의 클래스 중 하나를 고르는 것이므로, 머신러닝 학술적/실무적으로 **다중/다지 클래스 분류(Multiclass Classification)**가 완벽하게 맞는 서술임 (공부 자체는 100점 만점으로 정확하게 이해한 것임).
- **출제위원의 관점 및 정답이 ② '분류'인 이유**:
  - 선지 구성: ① 회귀, ② 분류, ③ 다지분류, ④ 예측
  - 출제자의 본래 핵심 의도는 **"숫자 $0\sim9$가 나온다고 해서 연속 수치를 예측하는 ① '회귀'로 낚이지 않고, 이미지의 범주(Label)를 맞히는 ② '분류'임을 알아채는가?"**였음.
  - 즉, 대분류(Supervised $\rightarrow$ Classification vs Regression) 수준의 테스크 구분을 묻는 문제였기 때문에 최상위 대표 개념인 **② '분류'**를 정답으로 지정함.
  - $\text{분류(Classification)} \supset \text{이진분류(Binary), 다중/다지분류(Multiclass)}$

### 🔎 선지 정밀 분석
1. **① 회귀 (Regression)**: 집값, 온도, 매출처럼 연속적인 크기(수량)를 가진 실수 값을 예측할 때 사용 (❌ 7이라는 숫자는 크기가 아니라 '7번 범주' 라벨임).
2. **② 분류 (Classification)**: 주어진 입력(이미지)이 어느 범주/클래스에 속하는지 식별하는 기법 (⭕ 공단 정답).
3. **③ 다지분류 (Multiclass Classification)**: 3개 이상의 클래스 중 하나를 선택하는 분류의 하위 유형 (개념적으로 완벽히 맞으나 상위 개념인 ②가 정답 처리됨).
4. **④ 예측 (Prediction)**: 머신러닝 전체를 포괄하는 상위 개념으로 문제에서 요구하는 구체적 분석 유형이 아님 (❌).

### 📚 출제위원 시크릿 족보: [다중분류(Multiclass) vs 다중레이블(Multilabel) 심화]
| 구분 | 다중 클래스 분류 (Multiclass) | 다중 레이블 분류 (Multilabel) |
| :--- | :--- | :--- |
| **정의** | $K \ge 3$개 클래스 중 **오직 1개의 정답만 할당** | 1개 데이터에 **여러 개의 클래스가 동시 할당 가능** |
| **대표 예시** | 손글씨 숫자 ($0\sim9$ 중 하나), 동식물 종 분류 | 이미지 태깅 (한 사진에 [사람, 자동차, 신호등] 동시 존재) |
| **출력 활성화 함수** | **Softmax (소프트맥스)** | **Sigmoid (시그모이드 독립 적용)** |
| **손실 함수** | **Cross-Entropy Loss (다중 교차 엔트로피)** | **Binary Cross-Entropy Loss (이진 교차 엔트로피)** |

### 🧠 빅분기 암기 팁
- **“숫자가 나온다고 회귀가 아니다! $0\sim9$는 범주(Label)이므로 분류!”**
- **“기출 정답표: ② 분류 / 학술 개념: 다지분류(Multiclass)”**
- **“소프트맥스 = 다중분류 / 시그모이드 = 이진분류 or 다중레이블”**

## 📌 [44번] 정답 라벨 없는 유사 데이터 그룹화 - 군집화(Clustering)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 비지도학습 모델링 $\rightarrow$ 군집 분석(Clustering)의 적용
- **핵심 의도**: 정답 라벨($Y$, 예: S/M/L) 없이 학생들의 신체 측정 치수($X$)만 주어졌을 때, 유사한 특성을 가진 그룹으로 묶는 **군집화(Clustering)** 기법 식별.

### 🎯 정답
**② 군집화 (Clustering)**

### 📌 정답인 이유
- **군집화(Clustering)**: 별도의 목표변수(정답 라벨 $Y$)가 없는 데이터셋에서 개체 간의 거리(유클리디안 거리, 맨해튼 거리 등) 및 유사성을 측정하여 **비슷한 특성을 가진 관측치들을 $K$개의 군집(Cluster)으로 묶는 비지도학습**.
- 문제 상황처럼 "신체 치수 데이터만 존재하고, 비슷한 체형끼리 묶어 새로운 사이즈 그룹을 도출"하고자 할 때 가장 적합한 기법임 (K-Means, 계층적 군집화 등).

### 🔎 선지 정밀 분석: [지도 vs 비지도 모델 비교]
1. **① 분류트리 (Classification Tree)**: 사전에 S/M/L 라벨이 부여된 학습 데이터를 기반으로 의사결정나무 규칙을 만드는 **지도학습 분류 모델** (❌ 라벨이 없으므로 적용 불가).
2. **② 군집화 (Clustering)**: 라벨 없는 데이터를 거리 기반으로 유사 그룹화 (⭕ 정답).
3. **③ 회귀분석 (Regression)**: 연속형 수치(예: 옷의 원단 길이, 가격)를 종속변수 $Y$로 두고 예측하는 **지도학습 회귀 모델** (❌ 목표 수치가 없음).
4. **④ 서포트벡터머신 (SVM)**: 사전에 라벨링된 클래스 간 마진(Margin)을 최대화하는 초평면(Hyperplane)을 찾는 **지도학습 분류 모델** (❌).

### 📚 출제위원 시크릿 족보: [문제 지문에서 모델 고르는 3초 공식]
| 지문 조건 / 문제 상황 | 사용할 최적 알고리즘 | 대표적 기법 |
| :--- | :--- | :--- |
| **정답 라벨($Y$) 없음 + 유사 그룹으로 묶기** | **군집화 (Clustering)** | K-Means, 계층적 군집, DBSCAN |
| **정답 라벨($Y$) 없음 + 함께 발생하는 규칙 찾기** | **연관분석 (Association)** | Apriori, FP-Growth |
| **정답 라벨($Y$) 있음 + 범주(합격/불합격, S/M/L) 맞히기** | **분류 (Classification)** | 로지스틱 회귀, 의사결정나무, SVM, 랜덤포레스트 |
| **정답 라벨($Y$) 있음 + 연속형 수치(매출, 가격) 맞히기** | **회귀 (Regression)** | 다중선형회귀, 릿지, 라쏘 |

### 🧠 빅분기 암기 팁
- **“정답(Y) 없이 비슷한 것끼리 묶으면 무조건 군집화(Clustering)!”**
- **“답 없이 묶는다 $\rightarrow$ 군집화 (2번 정답!)”** 1초 컷!

## 📌 [45번] 데이터 분석 모델링 단계의 세부 수행 절차

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 분석 모델링 프로세스 $\rightarrow$ 모델링 세부 4단계 절차
- **핵심 의도**: 모델링 마트 구축, 탐색적 분석(EDA) 및 유의변수 도출, 모델 확정, 모델 성능 평가에 이르는 논리적 선후 관계를 정확히 파악하고 있는지 평가.

### 🎯 정답
**③ ㄱ $\rightarrow$ ㄹ $\rightarrow$ ㄴ $\rightarrow$ ㄷ**
*(모델링 마트 설계 및 구축 $\rightarrow$ 탐색적 분석 및 유의변수 도출 $\rightarrow$ 모델링 모델 확정 $\rightarrow$ 모델링 성능 평가)*

### 📌 정답인 이유: [모델링 4단계의 자연스러운 논리 흐름]
1. **1단계 (ㄱ. 모델링 마트 설계 및 구축)**: 분석 모델에 투입할 분석용 데이터셋(마트)을 전처리·통합하여 먼저 마련해야 함 (**재료 준비**).
2. **2단계 (ㄹ. 탐색적 분석 및 유의변수 도출)**: 구축된 마트 데이터를 EDA로 탐색하고, 목표변수와 상관성이 높은 유의변수를 선별함 (**재료 탐색/선정**).
3. **3단계 (ㄴ. 모델링 모델 확정)**: 선별된 변수를 바탕으로 적합한 알고리즘(회귀, 트리, SVM, 앙상블 등)을 적용하여 최적 모델 구조를 확정함 (**요리 수행**).
4. **4단계 (ㄷ. 모델링 성능 평가)**: 완성된 모델을 검증 데이터(Test)로 평가하여 일반화 성능 지표(Accuracy, F1, RMSE 등)를 측정함 (**맛보기/검증**).

### 🔎 선지 정밀 분석
- **오답 선지 공통 오류**:
  - 데이터 마트(ㄱ)도 구축되지 않았는데 EDA(ㄹ)나 성능 평가(ㄷ)를 먼저 수행하는 것은 불가능함.
  - 모델이 확정(ㄴ)되어야 성능 평가(ㄷ)를 할 수 있으므로, ㄷ이 ㄴ보다 앞서거나 EDA(ㄹ)가 맨 뒤로 가는 순서는 모두 오류임.

### 📚 출제위원 시크릿 족보: [모델링 4단계 세부 산출물 및 주요 활동]
| 단계 | 주요 활동 내용 | 핵심 산출물 |
| :--- | :--- | :--- |
| **1. 마트 구축 (ㄱ)** | 원천 데이터 정제, 결합, 파생변수 생성, 분석 단위(Grain) 통일 | 분석용 모델링 마트 (Modeling Mart) |
| **2. 탐색/변수 도출 (ㄹ)** | 기술통계, 분포/이상치 점검, 상관분석, Feature Selection | 유의변수 정의서, EDA 보고서 |
| **3. 모델 확정 (ㄴ)** | 알고리즘 선정, Train/Validation 분할, 하이퍼파라미터 튜닝 | 확정 분석 모델 (Trained Model) |
| **4. 성능 평가 (ㄷ)** | 테스트셋 검증, 오차 행렬, 과적합 여부 점검 | 모델 평가 보고서, 성능 지표표 |

### 🧠 빅분기 암기 팁
- **“모델링 4단계 = 마 · 탐 · 모 · 평”**:
  - **마**트 구축 (재료 준비)
  - **탐**색적 분석/변수 도출 (재료 점검)
  - **모**델 확정 (요리)
  - **평**가 (맛보기)
- **“마트 만들고(ㄱ) $\rightarrow$ 탐색하고(ㄹ) $\rightarrow$ 모델 짜고(ㄴ) $\rightarrow$ 평가한다(ㄷ)!”** 3초 컷!

## 📌 [46번] 데이터 분할(Train / Validation / Test)과 테스트셋의 역할 및 과적합 오류

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 모델 평가 및 검증 $\rightarrow$ 데이터 분할(Train, Validation, Test)의 역할과 데이터 누수
- **핵심 의도**: 모델 평가용 테스트 데이터(Test Set)를 반복해서 재사용하여 모델을 수정할 때 발생하는 현상(**테스트셋에 대한 과적합 및 데이터 누수**)을 정확히 알고 있는지 평가.

### 🎯 정답
**④ 테스트 데이터를 반복해서 재사용하면 이는 훈련셋의 일부가 되고 모델 과소적합의 원인이 된다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **테스트 데이터(Test Set)의 본래 목적**: 최종 확정된 모델의 **미지의 데이터에 대한 일반화 성능(Generalization Performance)**을 단 1회 객관적으로 측정하기 위한 용도임.
- **테스트 데이터 반복 재사용 시 문제점**: 테스트 결과를 보면서 모델의 구조나 하이퍼파라미터를 지속적으로 수정하면, 테스트셋의 정보가 모델에 간접적으로 반영되는 **데이터 누수(Data Leakage)**가 발생하고, 결국 **테스트셋에 과적합(Overfitting)**되어 실전 배포 시 성능이 폭락함.
- 따라서 이를 "과소적합(Underfitting)"의 원인이라고 설명한 ④번은 명백한 오류임.

### 🔎 선지 정밀 분석: [데이터셋 3총사 역할 대조]
1. **① 학습 데이터 (Train Set)**: 모델 내부의 가중치($W$), 절편($b$), 트리 분할 기준 등 **파라미터(Parameter)를 학습·적합**시키는 데 사용 (⭕ 올바른 설명).
2. **② 분할 비율**: $60:20:20$, $70:15:15$, $50:30:20$ 등 프로젝트 규모와 목적에 맞게 분할하여 활용 (⭕ 올바른 설명).
3. **③ 검증 데이터 (Validation Set)**: 여러 알고리즘 비교, 조기 종료(Early Stopping), **하이퍼파라미터 튜닝(Hyperparameter Tuning)**에 활용 (⭕ 올바른 설명).
4. **④ 과소적합 오류**: 테스트셋 반복 재사용은 과소적합이 아닌 **과적합(Overfitting)**을 유발함 (❌ 정답).

### 📚 출제위원 시크릿 족보: [Train vs Validation vs Test 완벽 비교표]
| 데이터셋 구분 | 실생활 비유 | 학습 대상 | 핵심 수행 작업 |
| :--- | :---: | :--- | :--- |
| **학습 데이터 (Train)** | 교과서 / 문제집 | **파라미터 (Parameter)** | 모델의 가중치/회귀계수 학습 |
| **검증 데이터 (Validation)** | 모의고사 | **하이퍼파라미터 (Hyperparameter)** | 모델 비교/선택, 튜닝, 과적합 감지 |
| **테스트 데이터 (Test)** | 실제 수능 시험 | 없음 (학습/튜닝 절대 불가) | **최종 일반화 성능 1회성 평가** |

### 🧠 빅분기 암기 팁
- **“학 · 튜 · 최” 1초 컷!**:
  - Train $\rightarrow$ **학**습 (파라미터)
  - Validation $\rightarrow$ **튜**닝/모델선택 (하이퍼파라미터)
  - Test $\rightarrow$ **최**종평가 (건드리면 과적합!)
- **“테스트셋을 자꾸 보면 $\rightarrow$ 테스트셋에 과적합(Overfitting)된다!”**

## 📌 [47번] 모델 평가 및 검증 - K-겹 교차검증(K-fold Cross-Validation)의 특성과 Fold 수 결정

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 모델 평가 및 검증 $\rightarrow$ 교차검증(Cross-Validation) 기법
- **핵심 의도**: K-겹 교차검증(K-Fold CV)의 동작 원리와 Fold 수($K$) 변화에 따른 학습 데이터 비율 및 연산량의 상관관계 파악.

### 🎯 정답
**③ 훈련 데이터가 작다면 Fold 개수를 줄이는 것이 좋다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **Fold 수($K$)와 학습 데이터 비율의 관계**:
  - $K$-Fold에서 매 반복마다 모델 학습에 사용되는 데이터 비율은 $\frac{K-1}{K}$임.
  - $K=2$일 때: 학습 데이터 50% ($1/2$)
  - $K=5$일 때: 학습 데이터 80% ($4/5$)
  - $K=10$일 때: 학습 데이터 90% ($9/10$)
- 데이터셋의 크기가 작을 때 $K$를 줄여버리면(예: $K=2$), 매 학습 시 사용 가능한 데이터가 절반으로 줄어들어 심각한 과소적합과 편향(Bias)이 발생함.
- 따라서 **데이터가 적을수록 Fold 수($K$)를 늘려(10-Fold 또는 $K=N$인 LOOCV)** 한 번의 학습에 최대한 많은 데이터를 투입해야 함.

### 🔎 선지 정밀 분석: [교차검증 핵심 비교]
1. **① 홀드아웃 대비 안정성**: 홀드아웃(Hold-out)은 1회성 랜덤 분할에 의한 편향에 취약하나, $K$-Fold는 $K$번 평가 후 평균을 내므로 분할 민감도가 낮고 안정적임 (⭕ 올바른 설명).
2. **② 소규모 데이터셋 활용**: 데이터가 부족하여 Train/Validation/Test로 영구 분할하기 어려울 때 모든 데이터를 검증에 1회씩 활용 가능 (⭕ 올바른 설명).
3. **③ Fold 수 축소 오류**: 데이터가 작을수록 $K$를 늘려야 함 (❌ 정답).
4. **④ 평가 신뢰도 향상**: 단일 분할보다 일반화 성능 추정의 신뢰성과 안정성이 우수함 (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [Hold-out vs K-Fold vs LOOCV 완벽 대조표]
| 검증 기법 | 분할 및 반복 횟수 | 매 반복당 Train 비율 | 장점 | 단점 |
| :--- | :---: | :---: | :--- | :--- |
| **홀드아웃 (Hold-out)** | **단 1회 분할** | 통상 70% ~ 80% | **계산 속도 가장 빠름** | 분할 결과에 따라 평가 결과 요동침 (불안정) |
| **K-겹 교차검증 (K-Fold)** | **$K$회 반복** (통상 5, 10) | **$\frac{K-1}{K}$** ($80\% \sim 90\%$) | **평가 안정성/신뢰성 우수**, 데이터 효율적 | 모델을 $K$번 학습하므로 연산량 $K$배 증가 |
| **LOOCV (Leave-One-Out)** | **$N$회 반복** ($K=N$) | **$\frac{N-1}{N}$** (거의 전수 학습) | **데이터 손실 최소화**, 편향 극소화 | 데이터 $N$개만큼 모델 학습 $\rightarrow$ **계산량 극대화** |

### 🧠 빅분기 암기 팁
- **“데이터 적으면 $K$를 늘려라! (LOOCV $K=N$)”**
- **“$K$가 커지면 $\rightarrow$ 학습 데이터 비율($\frac{K-1}{K}$) 증가 $\rightarrow$ 계산량도 $K$배 증가!”**
- **“홀드아웃 = 1번(빠름, 불안정) / K-Fold = K번(안정적) / LOOCV = N번(느림)”** 1초 컷!

## 📌 [48번] 선형 회귀분석의 오차 기본 가정 - 등분산성(Homoscedasticity) 산점도 해석

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 회귀 분석 $\rightarrow$ 선형 회귀의 기본 가정 및 잔차 진단(Residual Diagnostics)
- **핵심 의도**: 잔차 대 예측값($\hat{y}$) 산점도에서 0을 중심으로 위아래 오차의 퍼짐(분산) 폭이 일정한 직사각형 띠 형태를 보고 **등분산성(Homoscedasticity)**을 판별할 수 있는지 평가.

### 🎯 정답
**② 등분산성 (Homoscedasticity)**

### 📌 정답인 이유
- **등분산성(Homoscedasticity)의 정의**: 회귀모형에서 설명변수 $X$ 또는 예측값 $\hat{y}$의 크기와 상관없이 **오차항(잔차)들의 분산이 항상 일정하다는 가정** ($Var(\epsilon_i) = \sigma^2$).
- 잔차 산점도 그래프에서 가로축 전체에 걸쳐 잔차들의 위아래 퍼짐 폭이 균일하게 평행 띠를 형성하고 있으므로 등분산성 가정을 만족함.

### 🔎 선지 정밀 분석: [회귀분석 4대 오차 가정 진단 도구]
1. **① 독립성 (Independence)**: 오차항끼리 상관관계가 없어야 함 ($Cov(\epsilon_i, \epsilon_j) = 0$). 주로 **더빈-왓슨(Durbin-Watson) 검정**($d \approx 2$)으로 자기상관 여부를 판정 (❌ 그래프의 퍼짐 폭과는 무관).
2. **② 등분산성 (Homoscedasticity)**: 잔차의 분산 일정 $\rightarrow$ 잔차 산점도에서 일정한 폭 유지 (⭕ 정답).
3. **③ 정상성 (Stationarity)**: 시계열 데이터에서 시간 경과에 따라 평균과 분산이 일정한 성질로 회귀분석의 오차 기본가정 명칭이 아님 (❌).
4. **④ 비상관성 (Uncorrelated)**: 설명변수와 오차항 간 무상관성 ($Cov(X_i, \epsilon_i) = 0$).

### 📚 출제위원 시크릿 족보: [선형회귀 오차 4대 기본 가정 완벽 진단표]
| 기본 가정 | 통계적 수식 정의 | 주요 진단 도구 / 판정 그래프 | 위반 시 문제점 / 해결 방안 |
| :--- | :--- | :--- | :--- |
| **1. 선형성 (Linearity)** | $E(Y) = \beta_0 + \beta_1 X$ | 잔차 대 예측값 산점도 (무작위 분포) | 다항회귀, 비선형 변환 (로그/제곱근) |
| **2. 독립성 (Independence)** | $Cov(\epsilon_i, \epsilon_j) = 0$ | **Durbin-Watson 검정** ($0\sim4$, $2$에 가까우면 독립) | 시계열 오차 모형(ARIMA) 적용 |
| **3. 등분산성 (Homoscedasticity)** | **$Var(\epsilon_i) = \sigma^2$ (일정)** | **잔차 산점도의 수직 퍼짐 폭 균일 여부** (깔때기 모양 X) | 종속변수 로그/Box-Cox 변환, WLS(가중최소제곱법) |
| **4. 정규성 (Normality)** | $\epsilon_i \sim N(0, \sigma^2)$ | **Q-Q Plot (직선상 위치)**, Shapiro-Wilk, K-S 검정 | 데이터 변환, 비모수 회귀 |

### 🧠 빅분기 암기 팁
- **“선형회귀 4대 가정 = 선 · 독 · 등 · 정”**:
  - **선**형성: $X-Y$ 직선 관계
  - **독**립성: 오차끼리 무관 (**더빈-왓슨 $d \approx 2$**)
  - **등**분산성: 잔차 퍼짐 폭 일정 (**깔때기 모양이면 이분산!**)
  - **정**규성: 잔차가 정규분포 (**Q-Q Plot 직선**)
- **“잔차 폭이 일정하다 = 등분산!”** 1초 컷!

## 📌 [49번] 회귀모형의 변수 선택 기법 - 후진제거법(Backward Elimination)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 회귀 분석 $\rightarrow$ 회귀 변수 선택(Variable Selection) 기법
- **핵심 의도**: 모든 독립변수를 포함한 풀 모델(Full Model)에서 시작하여 기여도가 가장 낮은 변수를 순차적으로 제거하는 **후진제거법(Backward Elimination)**의 메커니즘 식별.

### 🎯 정답
**④ 후진제거법 (Backward Elimination)**

### 📌 정답인 이유
- **후진제거법(Backward Elimination)**:
  - 1단계: 모든 후보 독립변수($X_1, X_2, \dots, X_p$)를 모형에 전부 포함한 상태에서 회귀분석 수행.
  - 2단계: 유의확률($p$-value)이 가장 크거나 $F$-통계량 감소가 가장 적은 유의하지 않은 변수를 하나씩 제거.
  - 3단계: 모든 남아있는 변수가 지정된 유의수준(예: $\alpha = 0.05$)을 만족할 때까지 제거를 반복함.
- 문제 지문의 *“모든 변수를 적용한 후 통계적 유의성에 따라 하나씩 제거”*와 1:1 완벽 일치.

### 🔎 선지 정밀 분석: [변수 선택 3총사 비교]
1. **① 층화추출법 (Stratified Sampling)**: 표본을 추출하는 표본추출법으로 회귀 변수 선택과 무관 (❌).
2. **② 단계적 방법 (Stepwise Selection)**: 전진선택과 후진제거를 결합하여, 변수를 새로 추가하면서 기존 변수의 유의성을 재평가하여 기준 미달 시 제거를 병행함 (❌).
3. **③ 전진선택법 (Forward Selection)**: 독립변수가 없는 상수항 모형($Y = \beta_0$)에서 시작하여 설명력($R^2$, AIC 등)을 가장 크게 향상시키는 변수를 하나씩 추가함 (❌).
4. **④ 후진제거법 (Backward Elimination)**: 풀 모델에서 하나씩 제거 (⭕ 정답).

### 📚 출제위원 시크릿 족보: [회귀 변수 선택 3대 알고리즘 핵심 비교표]
| 변수 선택 기법 | 시작 상태 (초기 모형) | 진행 방식 | 한 번 들어간/나간 변수 |
| :--- | :--- | :--- | :--- |
| **전진선택법 (Forward)** | **변수 없음** ($Y = \beta_0$) | 설명력이 가장 높은 변수 **하나씩 추가** | **한 번 추가된 변수는 절대 빠지지 않음** |
| **후진제거법 (Backward)** | **모든 변수 포함** (Full Model) | 설명력이 가장 낮은 변수 **하나씩 제거** | **한 번 제거된 변수는 다시 들어가지 못함** |
| **단계적선택법 (Stepwise)** | 변수 없음 (또는 일부) | **추가와 제거를 번갈아 수행** | 들어갔다가도 유의성 떨어지면 **다시 제거 가능** |

### 🧠 빅분기 암기 팁
- **“전진 = 빈손 출발 하나씩 넣기”**
- **“후진 = 풀옵션 출발 하나씩 빼기 (4번 정답!)”**
- **“단계 = 넣었다 뺐다 (가장 널리 쓰임)”** 1초 컷!

## 📌 [50번] 규제 선형회귀 - 라쏘(Lasso) vs 릿지(Ridge) 규제 메커니즘 비교

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 회귀 분석 $\rightarrow$ 규제 선형회귀(Lasso, Ridge, ElasticNet)
- **핵심 의도**: 가중치 절댓값 페널티를 사용하는 **라쏘(Lasso, L1 규제)**와 가중치 제곱 페널티를 사용하는 **릿지(Ridge, L2 규제)**의 손실함수 및 변수 선택 특성을 구별하는지 평가.

### 🎯 정답
**④ L2 norm의 제곱을 나눠 규제항으로 사용한다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **라쏘 회귀 (Lasso Regression)**:
  - 손실함수(비용함수): $J(\theta) = \text{MSE}(\theta) + \alpha \sum_{i=1}^p |\theta_i| = \text{MSE} + \alpha \|\theta\|_1$
  - 가중치 벡터의 **L1 Norm(절댓값의 합)**을 페널티로 부여하여, 덜 중요한 독립변수의 회귀계수를 **정확히 0으로 만들어 변수 선택(Feature Selection)** 효과를 제공함.
- **릿지 회귀 (Ridge Regression)**:
  - 손실함수: $J(\theta) = \text{MSE}(\theta) + \alpha \sum_{i=1}^p \theta_i^2 = \text{MSE} + \alpha \|\theta\|_2^2$
  - 가중치 벡터의 **L2 Norm의 제곱(제곱합)**을 페널티로 부여하여, 계수를 0에 가깝게 축소(Shrinkage)하지만 정확히 0으로 만들지는 못함.
- 따라서 ④번은 라쏘가 아닌 **릿지(Ridge)**의 설명임.

### 🔎 선지 정밀 분석: [라쏘 핵심 특성 검증]
1. **① L1 Norm 페널티**: 가중치의 절댓값 합($\sum |\theta_i|$)을 사용 (⭕ 올바른 설명).
2. **② 손실함수 수식**: $J(\theta) = \text{MSE}(\theta) + \alpha \sum |\theta_i|$ (⭕ 올바른 수식).
3. **③ 규제 선형회귀**: 다중공선성을 완화하고 과적합(Overfitting)을 방지하기 위해 계수 크기를 제한하는 규제 모델 (⭕ 올바른 설명).
4. **④ L2 Norm 제곱 오류**: 릿지(Ridge) 회귀의 규제항임 (❌ 정답).

### 📚 출제위원 시크릿 족보: [Lasso vs Ridge vs ElasticNet 완벽 비교표]
| 비교 항목 | 라쏘 회귀 (Lasso) | 릿지 회귀 (Ridge) | 엘라스틱넷 (ElasticNet) |
| :--- | :---: | :---: | :---: |
| **규제 기법** | **L1 규제 (L1 Norm)** | **L2 규제 (L2 Norm)** | **L1 + L2 혼합 규제** |
| **페널티 수식** | $\alpha \sum_{i=1}^p \|\beta_i\|$ (**절댓값 합**) | $\alpha \sum_{i=1}^p \beta_i^2$ (**제곱합**) | $r \alpha \|\beta\|_1 + \frac{1-r}{2} \alpha \|\beta\|_2^2$ |
| **계수를 0으로 만듦?** | **가능 (정확히 0이 됨)** | 불가능 (0에 가깝게 축소만) | 가능 (0이 됨) |
| **변수 선택 기능** | **있음 (희소 모델, Sparsity)** | 없음 (모든 변수 보존) | 있음 |
| **적합한 데이터 상황** | 소수의 유의미한 변수만 존재할 때 | 다수의 변수가 고르게 기여할 때 | 변수 간 강한 상관관계 존재 시 |

### 🧠 빅분기 암기 팁
- **“라쏘는 L1으로 싹둑 잘라 0으로! (변수 선택)”**
- **“릿지는 L2로 제곱해서 축소만! (0은 안 됨)”**
- **“Lasso = L1 = 절댓값 / Ridge = L2 = 제곱”** 1초 컷!

## 📌 [51번] 범주형 반응변수 회귀모형 - 로지스틱 회귀분석(Logistic Regression)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 분류 및 회귀 모델링 $\rightarrow$ 로지스틱 회귀분석(Logistic Regression)
- **핵심 의도**: 종속변수(반응변수 $Y$)가 연속형이 아닌 **범주형(Categorical / Binary)**일 때 적용하는 대표적인 회귀 기반 분류 모델 식별.

### 🎯 정답
**① 로지스틱회귀분석 (Logistic Regression)**

### 📌 정답인 이유
- **로지스틱 회귀의 본질**: 종속변수가 성공/실패, 합격/불합격, 이탈/유지처럼 **범주형(0 또는 1)**일 때, 사건 발생 확률 $p = P(Y=1|X)$를 **오즈(Odds) 및 로짓(Logit) 변환**을 거쳐 선형결합으로 모델링하는 지도학습 분류 기법.
- **수식 구조**:
  $$\text{Odds} = \frac{p}{1-p}, \quad \text{Logit}(p) = \ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k$$
  $$p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \dots + \beta_k X_k)}} = \sigma(z) \quad (\text{시그모이드 함수})$$
- 따라서 반응변수가 범주형일 때 사용하는 회귀분석은 **로지스틱 회귀분석**임.

### 🔎 선지 정밀 분석: [종속변수 유형별 회귀모형]
1. **① 로지스틱 회귀분석**: 범주형 종속변수($0/1$, 다항, 순서형)에 적용 (⭕ 정답).
2. **② 선형 회귀분석**: 종속변수가 **연속형(Continuous)** 수치일 때 적용 (❌).
3. **③ 규제가 있는 선형 회귀분석**: Lasso, Ridge, ElasticNet 등 연속형 $Y$ 대상 과적합 방지 모델 (❌).
4. **④ 비선형 회귀분석**: 연속형 $Y$와 독립변수 $X$ 간의 관계가 지수, 로그 등 비선형 곡선일 때 적용 (❌).

### 📚 출제위원 시크릿 족보: [반응변수 유형에 따른 회귀모형 총정리]
| 종속변수 ($Y$) 유형 | 대표적 회귀분석 기법 | 예측 대상 / 출력값 |
| :--- | :--- | :--- |
| **연속형 실수 (Continuous)** | **일반 선형회귀 (OLS), 릿지, 라쏘** | 실수 수치값 ($\hat{y} \in (-\infty, \infty)$) |
| **이항 범주형 ($0$ or $1$)** | **이항 로지스틱 회귀 (Binary Logistic)** | 사건 발생 확률 ($p \in [0, 1]$) |
| **다항 범주형 ($K \ge 3$, 무순서)** | **다항 로지스틱 회귀 (Multinomial Logistic)** | 각 클래스별 소속 확률 (Softmax) |
| **순서형 범주형 (상/중/하, 1/2/3등)** | **순서형 로지스틱 회귀 (Ordinal Logistic)** | 누적 확률 (Cumulative Odds) |
| **계수형 데이터 (발생 건수: $0, 1, 2 \dots$)** | **포아송 회귀 (Poisson Regression)** | 단위당 평균 발생 건수 ($\lambda$) |

### 🧠 빅분기 암기 팁
- **“수치 맞히면 선형회귀, 범주(0/1) 맞히면 로지스틱 회귀!”**
- **“오즈(Odds) $\rightarrow$ 로짓(Logit) $\rightarrow$ 시그모이드(Sigmoid) = 로지스틱 회귀”**
- **“로지스틱 회귀는 이름에 회귀가 붙지만 본질은 분류(Classification) 모델!”** 1초 컷!

## 📌 [52번] 인공신경망(ANN)의 구조와 학습 대상 파라미터 - 가중치(Weight)

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 딥러닝 및 인공신경망 $\rightarrow$ 신경망의 구조와 오차역전파(Backpropagation) 학습 메커니즘
- **핵심 의도**: 신경망의 순전파(Forward)와 역전파(Backward) 과정에서 손실함수를 최소화하기 위해 **학습(Training)을 통해 지속적으로 조정·갱신되는 매개변수(가중치 Weight, 편향 Bias)** 식별.

### 🎯 정답
**③ 가중치 (Weight)**

### 📌 정답인 이유
- **인공신경망의 학습 원리**:
  1. 입력 데이터($X$)에 **가중치($W$)**를 곱하고 **편향($b$)**을 더한 가중합($z = \sum w_i x_i + b$)을 구함.
  2. 활성화 함수(Sigmoid, ReLU 등)를 통과시켜 최종 출력($\hat{y}$)을 계산 (**순전파, Forward Propagation**).
  3. 실제 정답($y$)과 예측값($\hat{y}$) 간의 오차(Loss $L$)를 계산.
  4. 경사하강법(Gradient Descent)과 연쇄 법칙(Chain Rule)을 이용해 오차를 거꾸로 전파(**역전파, Backpropagation**)하며 **가중치($w$)와 편향($b$)을 갱신함**:
     $$w_{\text{new}} = w_{\text{old}} - \eta \frac{\partial L}{\partial w}$$
- 따라서 신경망에서 학습을 통해 최종 결정되는 핵심 매개변수는 **가중치(Weight)**임.

### 🔎 선지 정밀 분석: [신경망 핵심 구성 요소]
1. **① 커널값 (Kernel)**: SVM의 커널 함수 또는 CNN의 합성곱 필터(Filter)를 의미하며, 일반 신경망의 기본 학습 파라미터 대표 용어가 아님 (❌).
2. **② 뉴런값 (Neuron / Node)**: 입력을 받아 가중합과 활성화 연산을 수행하는 **신경망의 구조적 기본 단위** (❌ 연산 단위이지 학습되는 파라미터가 아님).
3. **③ 가중치 (Weight)**: 입력 신호의 중요도를 결정하며 역전파로 학습되는 **핵심 파라미터** (⭕ 정답).
4. **④ 오차 (Error / Loss)**: 학습을 통해 최소화해야 할 **목적함수(평가 기준)**이지, 학습으로 정해지는 매개변수가 아님 (❌).

### 📚 출제위원 시크릿 족보: [인공신경망 4대 핵심 파라미터 vs 하이퍼파라미터]
| 구분 | 명칭 | 역할 및 특성 | 결정 주체 |
| :--- | :--- | :--- | :---: |
| **파라미터 (Parameter)** | **가중치 ($W$)** | 입력 신호가 출력에 미치는 영향력 조절 | **데이터 학습(역전파)으로 자동 갱신** |
| | **편향 ($b$)** | 뉴런의 활성화 임계치를 조절하는 상수 | **데이터 학습(역전파)으로 자동 갱신** |
| **하이퍼파라미터 (Hyperparameter)** | **학습률 ($\eta$)** | 가중치를 한 번에 얼마나 갱신할지 결정하는 보폭 | 분석가(사람)가 사전 설정 |
| | **은닉층 수 / 노드 수** | 신경망의 깊이와 너비 (모델 복잡도) | 분석가(사람)가 사전 설정 |
| | **에포크 / 배치 크기** | 전체 데이터 반복 횟수 / 1회 갱신당 샘플 수 | 분석가(사람)가 사전 설정 |

### 🧠 빅분기 암기 팁
- **“순전파(예측) $\rightarrow$ 오차 계산(Loss) $\rightarrow$ 역전파(Backprop) $\rightarrow$ 가중치(Weight) 수정!”**
- **“학습되는 것은 가중치(W)와 편향(b)!”** 1초 컷!

## 📌 [53번] 서포트 벡터 머신(SVM)의 핵심 원리와 장단점

### ✅ 문제 분석
- **출제 파트**: 제3과목 빅데이터 모델링 $\rightarrow$ 분류 및 회귀 모델링 $\rightarrow$ 서포트 벡터 머신(SVM, Support Vector Machine)
- **핵심 의도**: 마진 최대화, 서포트 벡터, 커널 트릭 등 SVM의 핵심 메커니즘과 대용량/비선형 데이터 환경에서의 계산 특성(학습 및 테스트 복잡도)을 평가.

### 🎯 정답
**③ 테스트가 매우 쉽다 ❌ (오답이므로 정답)**

### 📌 정답인 이유
- **SVM의 예측(테스트) 연산 특성**:
  - SVM의 새로운 데이터에 대한 예측 결정 함수는 다음과 같이 서포트 벡터들과의 커널 내적 계산으로 이루어짐:
    $$f(\mathbf{x}) = \text{sign}\left( \sum_{i \in \text{SV}} \alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b \right)$$
  - 비선형 RBF 커널 등을 사용하고 서포트 벡터(SV)의 개수가 많아지면, 새로운 관측치 하나를 분류(테스트)할 때마다 **모든 서포트 벡터와의 거리/커널 계산이 필요하므로 예측 단계의 연산 시간과 메모리 부담이 큼**.
  - 또한 하이퍼파라미터($C, \gamma$) 튜닝 및 커널 선택이 까다롭고 결과 해석이 어려운 블랙박스 모델이므로, "테스트가 매우 쉽다"는 설명은 부적절함.

### 🔎 선지 정밀 분석: [SVM의 핵심 특성 4대 점검]
1. **① 분류와 회귀 모두 적용**: 분류(SVC)와 회귀(SVR) 모두 지원하는 지도학습 모델 (⭕ 올바른 설명).
2. **② 서포트 벡터(Support Vector)**: 결정 경계면(초평면)에 가장 가까이 위치하여 경계선의 위치와 마진을 결정하는 핵심 데이터 포인트 (⭕ 올바른 설명).
3. **③ 테스트 용이성 오류**: 서포트 벡터 개수가 많을수록 테스트 계산 비용이 증가함 (❌ 정답).
4. **④ 차원의 저주 회피 (커널 트릭)**: 실제로 고차원 벡터를 직접 계산하지 않고 커널 함수($K(\mathbf{x}_i, \mathbf{x}_j)$)를 통해 내적만 계산하므로 고차원 공간에서도 효과적으로 작동함 (⭕ 올바른 설명).

### 📚 출제위원 시크릿 족보: [SVM 핵심 개념 & 하이퍼파라미터 총정리]
| 핵심 개념 / 파라미터 | 정의 및 특징 | 시험 출제 포인트 |
| :--- | :--- | :--- |
| **마진 (Margin)** | 결정 초평면과 서포트 벡터 사이의 수직 거리 ($\frac{2}{\|\mathbf{w}\|}$) | **SVM의 목적: 마진의 최대화(Max Margin)** |
| **서포트 벡터 (SV)** | 경계선에 가장 가까운 소수의 데이터 포인트 | **서포트 벡터만으로 결정경계가 완전히 결정됨** |
| **커널 트릭 (Kernel Trick)** | 저차원 비선형 데이터를 고차원 선형 공간으로 매핑 | 고차원 직접 변환 없이 **내적만 계산하여 연산 효율화** |
| **규제 파라미터 $C$** | 이상치 허용 오차(Slack Variable)에 대한 페널티 | **$C \uparrow$ (하드 마진, 과적합 위험) / $C \downarrow$ (소프트 마진, 과소적합 위험)** |
| **RBF 파라미터 $\gamma$ (감마)** | 하나의 데이터가 미치는 영향력의 반경 | **$\gamma \uparrow$ (결정경계 복잡, 과적합 위험) / $\gamma \downarrow$ (결정경계 단순)** |

### 🧠 빅분기 암기 팁
- **“SVM = 서포트 벡터 + 마진 최대화 + 커널 트릭!”**
- **“$C$ 크면 깐깐(하드마진, 과적합) / $C$ 작으면 널널(소프트마진, 과소적합)”**
- **“$\gamma$(감마) 크면 복잡(과적합) / $\gamma$ 작으면 단순(과소적합)”** 1초 컷!
