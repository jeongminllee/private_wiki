## 📌 [01번] 분산 데이터 처리 MapReduce 디자인 패턴 - 조인 패턴(Join Pattern)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 빅데이터 저장 및 처리 $\rightarrow$ MapReduce 디자인 패턴
- **핵심 의도**: 서로 다른 위치에 저장된 두 데이터 세트(회원 마스터 + 주문 로그)를 공통 식별자인 `회원ID`를 키(Key)로 결합하는 분산 처리 디자인 패턴(**조인 패턴, Join Pattern**) 식별.

### 🎯 정답
**② 조인 패턴 (Join Pattern)**

### 📌 정답인 이유: [분산 환경에서의 데이터 결합 원리]
- **조인 패턴(Join Pattern)**:
  - RDBMS의 `JOIN` 연산을 하둡/맵리듀스 분산 환경에서 구현한 대표적인 디자인 패턴.
  - **Map 단계**: 서로 다른 데이터셋에서 공통 조인 키(`회원ID`)를 Key로 설정하여 `(회원ID, Value)` 쌍을 방출함.
  - **Shuffle/Sort 단계**: 동일한 `회원ID`를 가진 레코드들이 단일 Reducer 노드로 자동 그룹화되어 모임.
  - **Reduce 단계**: 모인 서로 다른 데이터셋의 레코드들을 하나의 확장된 레코드로 결합함.
- 문제에서 요구하는 작업은 “두 데이터 세트를 회원ID 키로 하나로 결합하는 것”이므로 **조인 패턴(Join Pattern)**이 정확한 정답임.

### 🔎 선지 정밀 분석: [MapReduce 4대 디자인 패턴]
1. **① 필터링 패턴 (Filtering Pattern)**: 특정 조건(예: 결제금액 $\ge 100$만원)을 만족하는 데이터만 선별/추출하거나 레코드를 제거하는 패턴 (❌).
2. **② 조인 패턴 (Join Pattern)**: 공통 Key를 기준으로 복수의 이종 데이터셋을 하나로 결합하는 패턴 (⭕ 정답).
3. **③ 요약 패턴 (Summarization Pattern)**: 수치 집계(평균, 합계, 개수, 최댓값 등)를 산출하는 통계 요약 패턴 (❌ 연령대별 평균 계산은 결합 이후의 후속 작업임).
4. **④ 메타 패턴 (Meta Pattern)**: 복합적인 비즈니스 로직 처리를 위해 여러 MapReduce 잡(Job)을 파이프라인으로 체이닝하는 상위 패턴 (❌).

### 📚 출제위원 시크릿 족보: [MapReduce 3대 핵심 디자인 패턴 비교]
| 디자인 패턴 | 대표 동작 (동사) | 주요 작업 예시 | SQL 연계 |
| :--- | :--- | :--- | :--- |
| **조인 패턴 (Join Pattern)** | **결합한다 (Merge)** | **회원 테이블 + 주문 로그 테이블 결합** | `JOIN ... ON` |
| **필터링 패턴 (Filtering)** | **거른다 (Filter/Select)** | 상위 10% VIP 추출, 불량 로그 제거 | `WHERE ...` |
| **요약 패턴 (Summarization)** | **집계한다 (Aggregate)** | 연령대별 평균 결제액, 총 매출 합계 | `GROUP BY`, `SUM()`, `AVG()` |

### 🧠 빅분기 암기 팁
- **“두 데이터셋 + 공통 Key로 붙인다 $\rightarrow$ 무조건 조인 패턴(Join Pattern)!”**
- **“필터(Filter) = 거른다 / 서머리(Summary) = 집계한다 / 조인(Join) = 붙인다!”**
- **“'연령대별 평균' 낚시어에 속지 말고 본질인 '데이터 결합 작업'을 볼 것!”** 1초 컷!

## 📌 [02번] 데이터 품질 4대 핵심 요소 - 완전성(Completeness) vs 정확성/정합성/적시성

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 및 품질 관리 $\rightarrow$ 데이터 품질 4대 평가 요소
- **핵심 의도**: 회원 데이터 중 '가입 연령', '요금제 코드' 등 필수 컬럼의 값이 비어 있거나 미입력된 **결측치(Missing Value, NULL, 누락)** 상태를 검증하는 데이터 품질 속성(**완전성, Completeness**) 식별.

### 🎯 정답
**③ 완전성 (Completeness)**

### 📌 정답인 이유: [데이터 품질의 4대 핵심 질문]
- **완전성 (Completeness)**:
  - 데이터베이스의 필수 입력 항목이나 레코드에 누락(결측값, NULL, 빈칸)이 없이 **"있어야 할 필수 데이터가 빠짐없이 채워져 있는가?"**를 평가하는 품질 척도.
  - 문제 지문의 "가입 연령 항목이 비어 있음(9만 건)", "요금제 코드가 아예 입력되지 않음(3만 건)"은 명백한 결측값/누락 현상이므로 **완전성(Completeness)**에 해당함.

### 🔎 선지 정밀 분석: [데이터 품질 4대 요소 완벽 대조]
1. **① 적시성 (Timeliness)**: 데이터가 요구되는 적절한 시점에 최신 상태로 제공/갱신되었는가? (❌ 시간/갱신 지연 문제).
2. **② 정합성 (Consistency)**: 서로 다른 테이블이나 시스템 간에 데이터가 모순 없이 논리적으로 일치하는가? (❌ 시스템 간 불일치 문제).
3. **③ 완전성 (Completeness)**: 필수 데이터가 누락 없이 빠짐없이 존재하는가? (⭕ 결측/NULL 검증 $\rightarrow$ 정답).
4. **④ 정확성 (Accuracy)**: 저장된 값이 실제 사실(현실 세계의 참값)과 일치하는가? (❌ 값은 있으나 틀린 오기입 문제).

### 📚 출제위원 시크릿 족보: [데이터 품질 4총사 1초 판별 질문 공식]
| 품질 요소 | 1타 강사 판별 질문 | 실제 발생 오류 사례 |
| :--- | :--- | :--- |
| **완전성 (Completeness)** | **“값이 빠짐없이 [있는가]?”** | `나이 = NULL` (미입력, 결측치 발생) |
| **정확성 (Accuracy)** | **“저장된 값이 실제와 [맞는가]?”** | 30세인데 `나이 = 300` (오기입, 왜곡된 값) |
| **정합성 (Consistency)** | **“데이터 간 내용이 서로 [같은가]?”** | 고객DB 성별='남' vs CRM 성별='여' (모순, 불일치) |
| **적시성 (Timeliness)** | **“데이터가 제때 갱신되어 [최신인가]?”** | 6개월 전 과거 주소가 여전히 남아있음 (갱신 지연) |

### 🧠 빅분기 암기 팁
- **“있나 $\rightarrow$ 완전성 / 맞나 $\rightarrow$ 정확성 / 같나 $\rightarrow$ 정합성 / 제때인가 $\rightarrow$ 적시성!”**
- **“결측치 / NULL / 빈칸 / 누락 $\rightarrow$ 1초 만에 완전성(Completeness)!”**
- **“값 없음 = 완전성 / 값 틀림 = 정확성!”**

## 📌 [03번] 프라이버시 보호 모델의 진화 - $k$-익명성, $l$-다양성, $t$-근접성, $m$-유일성

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 비식별화 및 법·제도 $\rightarrow$ 프라이버시 보호 모델 4총사
- **핵심 의도**: 개인 식별 방어 기법 중 **$m$-유일성(m-Uniqueness)**의 명칭에 담긴 함정(유일성 $\neq$ 유일하게 존재시킴)을 간파하고, $k$-익명성, $l$-다양성, $t$-근접성의 방어 메커니즘을 정확히 구별하는지 평가.

### 🎯 정답
**① $m$-유일성(m-Uniqueness) ❌ (틀린 설명)**
*(설명: 특정 속성 값이 데이터 집합 내에 유일하게 존재하도록 보장하여 개인정보를 보호한다 $\rightarrow$ 정반대 왜곡)*

### 📌 정답인 이유: [개인정보 보호의 역발상과 $m$-유일성]
- **개인정보 비식별화의 기본 철학**: 데이터 내에서 특정 개인이나 레코드가 **"단 1개로 유일하게 특정(Unique)"될 수 있다면 재식별(Re-identification) 공격에 매우 취약**해짐.
- **$m$-유일성(m-Uniqueness)의 진짜 정의**:
  - 원본 데이터의 특정 속성 조합이 비식별 데이터셋 내에서 **최소 $m$개 이상의 후보군으로 존재**하도록 보장함으로써, 공격자가 외부 지식을 결합하더라도 특정 개인 1명으로 확정할 수 없도록 방어하는 기법.
  - 따라서 ①번의 "특정 속성 값이 유일하게 존재하도록 보장한다"는 개인정보를 노출시키는 정반대의 설명이므로 오답임.

### 🔎 선지 정밀 분석: [프라이버시 4대 모델 핵심 검증]
1. **① $m$-유일성 (m-Uniqueness)**: 재식별 후보군을 최소 $m$개 이상 확보하여 유일 식별을 차단하는 모델임 (❌ 유일하게 1개만 존재시킨다는 설명은 틀림 $\rightarrow$ 정답).
2. **② $t$-근접성 (t-Closeness)**: 동질 집단 내 민감정보의 확률분포가 전체 데이터의 민감정보 분포와 거리 **$t$ 이하로 유사**하도록 유지하여 쏠림/유사성 공격을 방어 (⭕ 옳은 설명).
3. **③ $k$-익명성 (k-Anonymity)**: 동일한 준식별자(QI: 나이, 성별, 지역 등) 조합을 갖는 레코드가 **최소 $k$개 이상** 존재하도록 하여 연결 공격(Linkage)을 방어 (⭕ 옳은 설명).
4. **④ $l$-다양성 (l-Diversity)**: $k$-익명성을 만족하는 동질 집단 내에서 민감정보(질병, 소득 등)의 고유값이 **최소 $l$개 이상의 서로 다른 다양성**을 갖도록 하여 동질성/배경지식 공격을 방어 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [프라이버시 모델의 3단계 계층적 진화와 취약점 방어]
$$\boxed{k\text{-익명성 (사람 수 } k\text{명)} \xrightarrow{\text{동질성 공격 방어}} l\text{-다양성 (민감값 } l\text{종류)} \xrightarrow{\text{쏠림/유사성 방어}} t\text{-근접성 (분포차 } t\text{ 이하)}}$$

| 보호 모델 | 핵심 제약 조건 | 방어하는 주 공격 유형 | 한계점 / 취약 공격 |
| :--- | :--- | :--- | :--- |
| **$k$-익명성** | 동일 준식별자 조합 **최소 $k$명** | **연결 공격 (Linkage Attack)** | **동질성 공격(전원 동일 질병), 배경지식 공격** |
| **$l$-다양성** | 그룹 내 민감정보 **최소 $l$가지** | **동질성 공격, 배경지식 공격** | **쏠림 공격(Skewness), 유사성 공격(비슷한 질병)** |
| **$t$-근접성** | 그룹 분포 ↔ 전체 분포 차이 **$t$ 이하** | **쏠림 공격, 유사성 공격** | 데이터 유용성(Utility) 손실 큼 |
| **$m$-유일성** | 재식별 후보군 **최소 $m$개 보장** | **재식별 공격 (Re-identification)** | - |

### 🧠 빅분기 암기 팁
- **“$k$ = 사람 수 $k$명 / $l$ = 민감정보 $l$종류 / $t$ = 분포 거리 $t$ 이하!”**
- **“$m$-유일성 = '유일하게 만들자(X)'가 아니라 '유일하게 1명으로 못 찍게 하자(O)'!”**
- **“동질성 공격 방어 $\rightarrow l$-다양성 / 쏠림·유사성 공격 방어 $\rightarrow t$-근접성!”** 1초 컷!

## 📌 [04번] 웹 데이터 수집 및 구조 해석 - 파싱(Parsing)과 DOM 트리

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 수집 및 비정형 전처리 $\rightarrow$ 웹 데이터 스크래핑 및 파싱
- **핵심 의도**: 비정형/반정형 HTML 문자열 문서를 태그 단위 구성 요소로 분해하고 문서 객체 모델(DOM) 계층 구조를 문법적으로 해석하는 과정(**파싱, Parsing**) 식별.

### 🎯 정답
**④ 파싱 (Parsing)**

### 📌 정답인 이유: [문자열에서 계층 구조를 만드는 과정]
- **파싱(Parsing / 구문 분석)**:
  - 컴퓨터 과학에서 일련의 문자열이나 소스코드를 정해진 **문법(Grammar) 규칙에 따라 토큰화하고 계층적인 구문 트리(Syntax Tree 또는 DOM Tree)로 변환**하는 핵심 처리 과정.
  - 웹 크롤러가 수집한 원시 HTML 코드는 단순한 문자열에 불과하지만, **HTML Parser**를 통과하면 부모-자식 간의 계층적 **DOM(Document Object Model)** 구조로 재해석되어 원하는 태그의 텍스트(상품명, 가격 등)를 정확하게 추출할 수 있게 됨.

### 🔎 선지 정밀 분석: [웹 데이터 수집/처리 관련 용어 검증]
1. **① 정형 언어 (Formal Language)**: 엄격한 문법 규칙으로 정의된 언어 체계 그 자체를 의미하며, 처리 과정/작업 명칭이 아님 (❌).

## 📌 [07번] 문서 지향 NoSQL 데이터베이스 - MongoDB의 특징(BSON, Auto-Sharding)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 빅데이터 저장 및 관리 $\rightarrow$ NoSQL 데이터베이스 유형 및 특징
- **핵심 의도**: 오픈소스 기반으로 **BSON(Binary JSON)** 포맷의 문서(Document)를 저장하며, 유연한 스키마와 수평 확장(Scale-out)을 위한 **Auto-Sharding**을 지원하는 대표 NoSQL 제품(**MongoDB**) 식별.

### 🎯 정답
**④ MongoDB**

### 📌 정답인 이유: [MongoDB의 3대 핵심 시그니처]
- **MongoDB (몽고DB)**:
  - 대표적인 **문서 지향(Document-oriented) NoSQL 데이터베이스**.
  - **BSON(Binary JSON) 포맷**: JSON 형태의 유연한 비정형/반정형 문서를 바이너리 형태로 직렬화하여 고속 저장 및 인덱싱.
  - **유연한 스키마(Schema-less)**: 사전 고정 스키마 없이 Collection 내 Document마다 서로 다른 필드 구조 허용.
  - **Auto-Sharding**: 대용량 데이터를 다수의 노드/서버에 자동으로 수평 분산 분할(Scale-out)하여 처리 성능 확장.

### 🔎 선지 정밀 분석: [NoSQL 대표 제품군 완벽 대조]
1. **① Redis**: **Key-Value Store** 기반의 초고속 **인메모리(In-Memory)** 데이터베이스 (캐시, 세션 관리, ❌).
2. **② DynamoDB**: AWS가 제공하는 **완전관리형(Managed)** NoSQL 데이터베이스 (Key-Value/Document, ❌).
3. **③ CouchDB**: 문서 지향 NoSQL이나, BSON이 아닌 **표준 JSON 문서 및 HTTP/REST API**를 핵심 아키텍처로 사용함 (❌).
4. **④ MongoDB**: BSON, 유연한 스키마, Auto-Sharding을 갖춘 오픈소스 Document NoSQL (⭕ 정답).

### 📚 출제위원 시크릿 족보: [NoSQL 4대 데이터 모델 및 대표 제품 총정리표]
| NoSQL 데이터 모델 | 데이터 저장 구조 | 대표 제품군 | 핵심 특징 및 시험 키워드 |
| :--- | :--- | :--- | :--- |
| **Document Store** | **JSON / BSON 문서** | **MongoDB**, CouchDB | **BSON, 유연한 스키마, Sharding (MongoDB)** / **JSON+REST (CouchDB)** |
| **Key-Value Store** | **Key $\rightarrow$ Value** | **Redis**, Memcached, DynamoDB | **In-Memory 초고속 캐시/세션 (Redis)** |
| **Column Family** | **Row Key + Column Family** | **HBase**, Cassandra | **HDFS 기반 빅데이터 분산 저장 (HBase)**, 대규모 쓰기 최적화 |
| **Graph Store** | **Node + Edge (관계)** | **Neo4j**, OrientDB | 소셜 네트워크, 추천 시스템, 경로 탐색 |

### 🧠 빅분기 암기 팁
- **“BSON + Document + Sharding $\rightarrow$ 1초 만에 MongoDB!”**
- **“JSON + REST API $\rightarrow$ CouchDB!”**
- **“In-Memory + Key-Value $\rightarrow$ Redis!”**
- **“Hadoop HDFS 연계 컬럼 DB $\rightarrow$ HBase / Node+Edge $\rightarrow$ Neo4j!”**

## 📌 [08번] 하둡 분산 파일 시스템(HDFS) 아키텍처와 네임 노드(NameNode)의 단일 장애점(SPOF)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 빅데이터 저장 기술 $\rightarrow$ HDFS(Hadoop Distributed File System) 아키텍처
- **핵심 의도**: HDFS의 핵심 구성 요소인 마스터 노드(**NameNode**)와 워커 노드(**DataNode**)의 역할 분담, 블록(Block) 분할 및 3중 복제 원리, NameNode의 **단일 장애점(SPOF, Single Point of Failure)** 특성을 정확히 이해하고 있는지 평가.

### 🎯 정답
**③ 메타데이터를 관리하는 네임 노드에 장애가 발생하면 전체 시스템이 정상적으로 동작하지 못한다 ⭕ (옳은 설명)**

### 📌 정답인 이유: [도서관 대출 목록과 서가 배치도 비유]
- **네임 노드 (NameNode = 마스터 / 도서관 검색대 & 배치도)**:
  - 파일 시스템의 네임스페이스(디렉터리 구조, 파일명)와 각 파일이 어떤 블록으로 쪼개져 어느 DataNode에 위치하는지에 대한 **메타데이터(Metadata)를 전담 관리**함.
  - DataNode에 실제 물리 데이터 블록이 온전히 보관되어 있더라도, **NameNode가 다운되면 블록의 위치와 조합 정보를 전혀 알 수 없어 클러스터 전체의 읽기/쓰기가 전면 마비**됨 $\rightarrow$ 전통적 HDFS의 대표적인 **단일 장애점(SPOF)**.

### 🔎 선지 정밀 분석: [오답 원인 정밀 파쇄]
1. **① 블록 하나의 크기를 10MB 이하로 제한한다**: HDFS는 대용량 스트리밍 처리를 위해 일반 OS보다 훨씬 큰 **기본 128MB(구버전 64MB)** 단위의 대형 블록을 사용함 (❌ 10MB 제한은 오답).
   - 💡 **큰 블록 사용 이유**: 블록 크기가 클수록 블록 개수가 줄어들어 **NameNode의 메모리 메타데이터 관리 부담과 탐색 시간(Seek Time)이 대폭 절감**됨.
2. **② 파일을 분할하지 않고 하나의 DataNode에 통째로 저장한다**: 대용량 파일을 수십~수백 개의 **블록(Block)으로 균등 분할하여 여러 DataNode에 분산 저장**함 (❌).
3. **③ NameNode 장애 시 전체 시스템 정상 동작 불가**: NameNode가 독점하는 메타데이터 없이는 파일 복원이 불가능하므로 SPOF에 해당 (⭕ 정답).
4. **④ 블록 단위 중복 저장 때문에 장애 시 복구 불가**: 노드 고장에 대비하여 동일 블록을 기본 3개 노드에 **3중 복제(Replication Factor=3)**하므로, 노드가 죽어도 다른 복제본에서 **자동 무중단 복구**됨 (❌).

### 📚 출제위원 시크릿 족보: [HDFS 3대 핵심 노드 역할 및 아키텍처 비교]
$$\boxed{\text{NameNode (지도/목록 관리, SPOF)} \longleftrightarrow \text{DataNode (실제 블록 보관, 3중 복제)} \longleftrightarrow \text{Secondary NameNode (체크포인트 병합)}}$$

| HDFS 구성 노드 | 비유 | 핵심 역할 및 특징 | 시험 빈출 함정 |
| :--- | :--- | :--- | :--- |
| **네임 노드 (NameNode)** | **도서관 검색대 (배치도)** | 파일명, 디렉터리, 블록 위치 **메타데이터 관리 (SPOF)** | 메모리(RAM)에 메타데이터 상주 |
| **데이터 노드 (DataNode)** | **실제 서가 (책 보관 창고)** | **실제 데이터 블록 물리 저장**, NameNode에 하트비트 보고 | 기본 3중 복제(Rack 인지 복제) |
| **보조 네임 노드 (Secondary NN)**| **배치도 복사 보조원** | `FsImage`와 `EditLog`를 주기적으로 병합(체크포인트) | **🚨 NameNode의 즉시 대체 백업 서버가 아님!** |

### 🧠 빅분기 암기 팁
- **“네임 노드는 지도(메타데이터, SPOF), 데이터 노드는 창고(실제 데이터 3중 복제)!”**
- **“HDFS 블록 크기는 대용량 128MB (10MB 같은 쪼잔한 크기 X)!”**
- **“보조 네임 노드는 로그 병합 비서일 뿐, 예비 반장이 아니다!”** 1초 컷!

## 📌 [09번] 하둡(Hadoop) 에코시스템과 대규모 분산 로그 수집 시스템 - Chukwa(척와)

### ✅ 문제 분석

- **핵심 의도**: 다수의 분산 웹 서버로부터 발생하는 대규모 비정형 **로그 데이터를 실시간/배치로 수집하여 HDFS에 적재**하는 데이터 수집 프레임워크인 **Chukwa(척와)** 식별.

### 🎯 정답
**② Chukwa (척와)**

### 📌 정답인 이유: [하둡 기반 분산 로그 수집 파이프라인]

  - 대규모 분산 서버 클러스터에서 발생하는 시스템 로그, 웹 서버 로그(Access/Error log) 및 모니터링 메트릭을 중앙 집중식으로 수집하여 **HDFS 및 HBase에 저장하고 MapReduce로 분석**할 수 있도록 지원하는 하둡 에코시스템의 대표적 데이터 수집 시스템.

### 📚 출제위원 시크릿 족보: [하둡 에코시스템(Hadoop Ecosystem) 핵심 도구 매칭 총정리]

## 📌 [10번] 분석 과제 발굴의 4가지 유형 - What(대상) vs How(방법) 매트릭스

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 과제 발굴 $\rightarrow$ 분석 대상(What)과 분석 방법(How)의 Known/Unknown 조합
- **핵심 의도**: 분석 대상(What)과 분석 방법(How)의 인지 여부에 따라 도출되는 4대 분석 과제 유형(**최적화 Optimization, 솔루션 Solution, 통찰 Insight, 발견 Discovery**)을 정확히 매핑하는지 평가.

### 🎯 정답
**① ㄱ Optimization / ㄴ Insight / ㄷ Solution / ㄹ Discovery**

### 📌 정답인 이유: [What vs How의 4분면 매트릭스 원리]
- **분석 대상(What)**과 **분석 방법(How)**의 인지 상태에 따른 분류:
  1. **ㄱ. What(Known) + How(Known) $\rightarrow$ 최적화 (Optimization)**: 문제와 해결 방법을 모두 이미 알고 있으므로, 프로세스 효율 극대화 및 성능 튜닝에 집중.
  2. **ㄴ. What(Unknown) + How(Known) $\rightarrow$ 통찰 (Insight)**: 분석 기법(예: 연관분석, 군집분석)은 알고 있으나 어떤 패턴이 나올지 모르므로 데이터로부터 새로운 시사점 발굴.
  3. **ㄷ. What(Known) + How(Unknown) $\rightarrow$ 솔루션 (Solution)**: 해결해야 할 비즈니스 문제(예: 고객 이탈 방지)는 명확하지만 구체적 알고리즘/방법을 모르므로 해결책 모색.
  4. **ㄹ. What(Unknown) + How(Unknown) $\rightarrow$ 발견 (Discovery)**: 대상과 방법 모두 모호한 상태에서 혁신적 기회나 미지의 가치를 탐색적으로 발견.

### 📚 출제위원 시크릿 족보: [분석 과제 4대 유형 매트릭스 완벽 정리]
$$\begin{array}{|c|c|c|}
\hline
\text{분석 방법(How) } \backslash \text{ 분석 대상(What)} & \textbf{Known (기존 대상)} & \textbf{Unknown (신규 대상)} \\
\hline
\textbf{Known (기존 방법)} & \textbf{ㄱ. Optimization (최적화)} & \textbf{ㄴ. Insight (통찰)} \\
\hline
\textbf{Unknown (신규 방법)} & \textbf{ㄷ. Solution (솔루션)} & \textbf{ㄹ. Discovery (발견)} \\
\hline
\end{array}$$

### 🔎 선지 정밀 분석: [Insight vs Solution 헷갈림 방지 비법]
- **Solution (What 알고, How 모름)**: **"문제(What)는 명확하니 해결책(Solution)을 찾자!"**
- **Insight (What 모르고, How 알고)**: **"방법(How)을 돌려보니 새로운 통찰(Insight)이 나왔네!"**

### 🧠 빅분기 암기 팁
- **“둘 다 안다(아·아) $\rightarrow$ 최적화 (Optimization)!”**
- **“문제만 안다(아·몰) $\rightarrow$ 솔루션 (Solution)!”**
- **“방법만 안다(몰·아) $\rightarrow$ 통찰 (Insight)!”**
- **“둘 다 모른다(몰·몰) $\rightarrow$ 발견 (Discovery)!”** 1초 컷!

## 📌 [11번] 데이터 분석 방법론 비교 - KDD 5단계 vs CRISP-DM 6단계 및 평가(Evaluation)의 본질

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 분석 방법론 $\rightarrow$ KDD vs CRISP-DM 비교 분석
- **핵심 의도**: KDD(5단계)와 CRISP-DM(6단계)의 프로세스 진행 특성(순차적 vs 반복·순환적) 및 CRISP-DM **평가(Evaluation)** 단계가 단순 모델 성능 측정을 넘어 **비즈니스 목적 달성 여부까지 포괄**함을 파악하고 있는지 평가.

### 🎯 정답
**③ ㄱ, ㄴ**

### 📌 정답인 이유: [KDD vs CRISP-DM 핵심 비교]
- **ㄱ. KDD 5단계 (⭕ 옳음)**: `Selection(선택) → Preprocessing(전처리) → Transformation(변환) → Data Mining(마이닝) → Interpretation/Evaluation(해석/평가)`.
- **ㄴ. 프로세스 진행 방식 (⭕ 옳음)**: KDD는 비교적 순차적·단계적 파이프라인 형태인 반면, CRISP-DM은 각 단계 간 피드백 루프를 통해 전 단계로 되돌아가는 **반복적·순환적(Iterative) 프로세스**임.
- **ㄷ. CRISP-DM 평가(Evaluation) 단계의 범위 (❌ 틀림)**: 정확도·재현율 등 알고리즘의 기술적 성능뿐만 아니라, **"비즈니스 목표를 실제로 달성했는가?", "프로젝트 프로세스 전반에 누락은 없는가?"**를 종합 평가함 (`기술적 성능만 평가` $\rightarrow$ 오답 함정).
- **ㄹ. 적용 범위 (❌ 틀림)**: CRISP-DM은 **Cross-Industry**(산업 범용) 표준 방법론으로 특정 DB 환경에 한정되지 않음.

### 🔎 선지 정밀 분석: [출제위원의 낚시 키워드 분쇄]
1. **ㄱ. KDD 5단계 순서**: `선 → 전 → 변 → 마 → 평` (⭕ 옳은 설명).
2. **ㄴ. KDD(순차적) vs CRISP-DM(반복·순환적)**: CRISP-DM의 핵심 철학인 피드백 루프 반영 (⭕ 옳은 설명).
3. **ㄷ. 평가 단계는 기술적 성능만 측정한다**: 객관식 단골 오답 한정어(`~만`) 등장, 비즈니스 평가 누락 (❌ 틀린 설명).
4. **ㄹ. CRISP-DM은 특정 DB에 한정된다**: Cross-Industry(범산업) 표준에 위배 (❌ 틀린 설명).

### 📚 출제위원 시크릿 족보: [KDD vs CRISP-DM 2대 분석 방법론 총정리표]
$$\boxed{\text{KDD (5단계): 선} \rightarrow \text{전} \rightarrow \text{변} \rightarrow \text{마} \rightarrow \text{평} \quad \text{vs} \quad \text{CRISP-DM (6단계): 업} \rightarrow \text{데} \rightarrow \text{준} \rightarrow \text{모} \rightarrow \text{평} \rightarrow \text{전}}$$

| 비교 항목 | KDD (Knowledge Discovery in Databases) | CRISP-DM (Cross-Industry Standard Process) |
| :--- | :--- | :--- |
| **추진 목적** | 데이터베이스 내 숨겨진 지식/패턴 발견 | **실제 비즈니스 데이터마이닝 프로젝트 완수** |
| **전체 단계** | **5단계** | **6단계** |
| **시작 단계** | 데이터 선택 (Selection) | **업무 이해 (Business Understanding)** |
| **전처리/준비** | Preprocessing(정제) $\rightarrow$ Transformation(변환) | Data Understanding(이해) $\rightarrow$ Data Preparation(준비) |
| **핵심 모델링** | 데이터 마이닝 (Data Mining) | 모델링 (Modeling) |
| **평가 (Evaluation)** | 패턴 해석 및 평가 (Interpretation/Evaluation) | **모델 성능 평가 + 비즈니스 목표 달성도 종합 평가** |
| **최종 단계** | 평가/해석 단계에서 종료 | **전개 / 실무 배포 (Deployment)** |
| **프로세스 성격** | 비교적 순차적·단계적 파이프라인 | **단계 간 피드백 루프가 활발한 반복적·순환적 구조** |

### 🧠 빅분기 암기 팁
- **“KDD = 선 · 전 · 변 · 마 · 평 (선택 $\rightarrow$ 전처리 $\rightarrow$ 변환 $\rightarrow$ 마이닝 $\rightarrow$ 평가)!”**
- **“CRISP-DM = 업 · 데 · 준 · 모 · 평 · 전 (업무 $\rightarrow$ 데이터 $\rightarrow$ 준비 $\rightarrow$ 모델 $\rightarrow$ 평가 $\rightarrow$ 전개)!”**
- **“CRISP-DM의 평가는 '비즈니스 목표 달성'까지 본다! (~만 나온 선지는 즉시 탈락!)”** 1초 컷!

## 📌 [12번] 빅데이터 분석 기획 프로세스 - 도메인 이슈 도출과 빅데이터 요건 정의서

### 📌 정답인 이유: [문제를 찾는 단계 vs 일정을 짜는 단계]
- **도메인 이슈 도출**:
  - 분석 프로젝트 착수 전, 해당 도메인(업무 현장)의 비즈니스 프로세스와 현황을 분석하여 **"현업에서 해결해야 할 본질적인 문제가 무엇인가?"**를 명확히 정의하고, 빅데이터 분석을 통해 해결할 수 있는 **개선 방향과 기능 요건(빅데이터 요건 정의서)**을 도출하는 첫 단추 단계.
- **선택 오답 분석 (① 프로젝트 계획 수립)**:
  - '분석 수행에 앞서'라는 시점 표현만 보고 프로젝트 계획으로 오인하기 쉬우나, 프로젝트 계획 수립은 도출된 요건을 바탕으로 **일정(WBS), 투입 인력, 예산, 역할 분담(R&R)**을 수립하는 활동임.

### 🔎 선지 정밀 분석: [분석 기획 4단계 핵심 활동 대조]
1. **① 프로젝트 계획 수립**: WBS 작성, 프로젝트 범위·일정·인력·비용 배분 및 리스크 관리 계획 (❌).
2. **② 분석 목표 수립**: 발견된 이슈를 해결하기 위해 구체적인 데이터 분석 목표 및 비즈니스 KPI 설정 (❌).
3. **③ 모델 개발**: 선정된 알고리즘을 바탕으로 학습 데이터를 투입하여 실제 머신러닝/통계 모델을 구현·튜닝 (❌).
4. **④ 도메인 이슈 도출**: 업무 현황 파악 $\rightarrow$ 문제 정의 $\rightarrow$ 개선방향 도출 $\rightarrow$ **빅데이터 요건 정의서 산출** (⭕ 정답).

### 📚 출제위원 시크릿 족보: [분석 기획 4단계 프로세스 및 핵심 산출물]
$$\boxed{\text{1. 도메인 이슈 도출 (요건 정의서)} \longrightarrow \text{2. 분석 목표 수립 (목표/KPI)} \longrightarrow \text{3. 프로젝트 계획 수립 (WBS/일정)} \longrightarrow \text{4. 모델 개발 (분석 모델)}}$$

| 기획 단계 | 핵심 활동 (무엇을 하는가?) | 결정적 출제 키워드 / 대표 산출물 |
| :--- | :--- | :--- |
| **1. 도메인 이슈 도출** | **현업 업무 현황 분석, 해결 문제 정의, 개선사항 발굴** | **업무 현황, 문제 정의, [빅데이터 요건 정의서]** |
| **2. 분석 목표 수립** | 비즈니스 문제를 해결하기 위한 분석 방향 구체화 | 분석 목적, 정량적 KPI, 데이터 요구사항 |
| **3. 프로젝트 계획 수립** | 프로젝트 수행 일정, 투입 리소스 및 위험 관리 | **WBS(작업분할구조도), 일정, 인력, 예산, R&R** |
| **4. 모델 개발** | 데이터 수집/전처리 후 실제 알고리즘 모델링 | 알고리즘 선정, 하이퍼파라미터 튜닝, 검증 |

### 🧠 빅분기 암기 팁
- **“현황 파악 + 문제 정의 + 개선사항 + 요건 정의서 $\rightarrow$ 도메인 이슈 도출!”**
- **“문제를 찾는 건 '도메인 이슈', 일정을 짜는 건 '프로젝트 계획'!”**
- **“도메인 이슈(문제 발견) $\rightarrow$ 목표 수립(KPI) $\rightarrow$ 계획 수립(일정/인력) $\rightarrow$ 모델 개발(알고리즘)!”** 1초 컷!

## 📌 [13번] 빅데이터 분석 과제 우선순위 평가 - ROI 관점의 4V 분할 (3V 투자비용 vs 1V 비즈니스 효과)

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 마스터플랜 $\rightarrow$ 분석 과제 우선순위 평가 및 ROI 관점
- **핵심 의도**: 빅데이터의 4V(Volume, Variety, Velocity, Value)를 투자수익률(**ROI, Return on Investment**) 관점에서 **투자비용 요소(3V)**와 **비즈니스 효과 요소(Value)**로 명확히 분리하여 이해하고 있는지 평가.

### 🎯 정답
**② 투자비용 요소에는 크기(Volume)·다양성(Variety)·속도(Velocity)와 더불어 가치(Value)가 함께 포함된다 ❌ (틀린 설명)**

### 📌 정답인 이유: [투입 비용(Cost) vs 산출 효과(Benefit)]
- **$\text{ROI} \approx \frac{\text{비즈니스 효과(Benefit)}}{\text{투자비용(Cost)}}$ 관점의 4V 분할**:
  - **투자비용 요소 (Cost / 난이도 요인)**: 데이터의 크기(**Volume**), 다양성(**Variety**), 처리 속도(**Velocity**) $\rightarrow$ 데이터 인프라, 전처리, 스트리밍 구축 등으로 인해 **비용과 난이도가 상승**하는 요인 (**3V**).
  - **비즈니스 효과 요소 (Value / 수익 요인)**: 분석을 통해 얻게 되는 매출 증대, 비용 절감, 리스크 감소 등 **기업이 창출하는 실질적 가치 (**Value**)**.
- 따라서 ②번에서 "가치(Value)까지 투자비용 요소에 포함된다"고 설명한 것은 투입과 산출을 뒤섞은 명백한 왜곡 오답임.

### 🔎 선지 정밀 분석: [오답 원인 완벽 파쇄]
1. **① 투자비용 요소는 3V로 설명할 수 있다**: Volume, Variety, Velocity는 인프라 및 구축 비용 상승 요인이므로 참 (⭕ 옳은 설명).
   - 🚨 **수험생 착각**: "빅데이터는 4V인데 왜 3V만 비용이지?"라고 오해하기 쉬우나, ROI 관점에서는 3V(비용) + 1V(효과)로 분리됨.
2. **② 투자비용 요소에 Value가 함께 포함된다**: Value는 산출되는 이익(효과)이므로 비용이 아님 (❌ 틀린 설명 $\rightarrow$ 정답).
3. **③ 비즈니스 효과 요소는 Value로 설명할 수 있다**: 분석 모델의 최종적인 비즈니스 효용을 의미함 (⭕ 옳은 설명).
4. **④ 과제 우선순위를 ROI(비용 대비 효과) 관점에서 비교한다**: 시급성(전략적 중요도)과 난이도(비용/기술)를 종합 고려하여 우선순위 도출 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [빅데이터 4V의 ROI 2대 축 매핑표]
$$\boxed{\text{투자비용 (Cost) } = \textbf{3V (Volume, Variety, Velocity)} \quad \longleftrightarrow \quad \text{비즈니스 효과 (Return) } = \textbf{Value}}$$

| ROI 평가 축 | 해당 4V 요소 | 세부 의미 및 영향 |
| :--- | :--- | :--- |
| **투자비용 (Cost)** | **1. Volume (크기)** | 대용량 저장소, 분산 스토리지(HDFS), 서버 증설 비용 |
| **투자비용 (Cost)** | **2. Variety (다양성)** | 정형/비정형/반정형 데이터 통합 및 복잡한 전처리 비용 |
| **투자비용 (Cost)** | **3. Velocity (속도)** | 실시간 스트리밍(Kafka, Flink), 고성능 인프라 구축 비용 |
| **비즈니스 효과 (Return)** | **4. Value (가치)** | **수익 증대, 고객 이탈 방지, 비용 절감, 신사업 창출** |

### 🧠 빅분기 암기 팁
- **“3V(크기·다양성·속도)에는 돈이 들고(비용), Value(가치)로 돈을 번다(효과)!”**
- **“기본 특성은 4V, ROI 관점 분할은 3V(비용) + 1V(효과)!”**
- **“Value를 비용이라고 우기면 0.1초 만에 오답 탈락!”** 1초 컷!

## 📌 [15번] 빅데이터 분석 마스터플랜(Analysis Master Plan) 수립 - 우선순위 평가와 단계적 구현 로드맵

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 마스터플랜 $\rightarrow$ 분석 마스터플랜의 개념, 평가 기준 및 로드맵
- **핵심 의도**: 분석 마스터플랜이 단순한 단기 과제 계획이 아니라, 전사적 관점에서 과제의 **우선순위(전략적 중요도, ROI, 실행 용이성)**를 평가하고 중장기적인 **단계적 이행 로드맵(업무, 데이터, 기술 수준 고려)**을 수립하는 활동임을 식별.

### 🎯 정답
**④ 중장기적 관점에서 분석 과제를 도출하고, 전략적 중요도·비즈니스 성과·실행 용이성 등을 고려해 우선순위를 평가한 뒤 단계적 이행 계획을 수립한다 ⭕ (가장 올바른 설명)**

### 📌 정답인 이유: [마스터플랜의 2대 핵심 축: 우선순위 평가 + 구현 로드맵]
- **분석 마스터플랜 (Analysis Master Plan)**:
  - 전사 차원의 중장기 비전과 목표 달성을 위해 도출된 다수의 분석 과제를 대상으로 **우선순위를 평가**하고, 이를 바탕으로 실행 가능한 **단계별 구현 로드맵을 체계적으로 수립**하는 종합 실행 계획.
  - **1단계 (우선순위 평가)**: 전략적 중요도(시급성), 비즈니스 성과(ROI), 실행 용이성(기술 난이도)을 종합 평가.
  - **2단계 (단계적 로드맵 수립)**: 업무 내재화 수준, 분석 데이터 범위, 분석 기술 도입 수준을 3차원으로 고려하여 단계별(1단계 $\rightarrow$ 2단계 $\rightarrow$ 3단계) 이행 계획 확정.

### 🔎 선지 정밀 분석: [오답 선지의 함정 키워드 분쇄]
1. **① 투자비용 요소인 3V만으로 우선순위를 결정한다**: 3V(비용) 외에 Value(효과), 전략적 중요도, 실행 용이성을 다각도로 검토함 (`~만` 한정 왜곡, ❌).
2. **② 단기 실행 계획만 의미하고 중장기 로드맵은 포함하지 않는다**: 마스터플랜의 본질인 전사적 중장기 로드맵을 배제하여 틀림 (❌).
3. **③ 단계적 구현 로드맵에서 업무·데이터·기술 적용 수준을 고려하지 않는다**: 업무 영역, 데이터 확보 범위, 기술 성숙도의 3대 축을 필수적으로 고려해야 함 (❌).
4. **④ 중장기 관점 + 우선순위 평가 + 단계적 이행 계획 수립**: 마스터플랜의 표준 정의 (⭕ 정답).

### 📚 출제위원 시크릿 족보: [분석 기획 3총사의 계층적 연계 파이프라인]

## 📌 [16번] AI 모델 자체 설계 시 고려사항 vs 서비스 배포/인프라 환경 구분

### ✅ 문제 분석

### 🎯 정답
**② 사용자에게 결과를 전달하는 네트워크 전송 속도 ❌ (모델 자체 설계 요소 아님)**

### 📌 정답인 이유: [모델(Model)과 시스템 인프라(Infra)의 경계]

  1. **학습 데이터의 양(규모)**: 과소적합을 방지하고 복잡한 패턴을 학습하기 위한 표본 크기.
  2. **학습 데이터의 품질(Quality)**: GIGO(Garbage In, Garbage Out) 원리에 따른 정확성, 완전성, 일관성 확보.

- **네트워크 전송 속도 (Network Latency)**:
  - 모델의 내부 학습 알고리즘이나 예측 정확도와는 무관하며, 완성된 모델을 서빙(Serving)하고 API로 결과를 표출할 때 발생하는 **서비스 배포 및 네트워크 인프라 영역의 고려사항**임.

### 🔎 선지 정밀 분석: [4대 선지 영역별 분류]
1. **① 학습에 사용할 데이터의 양(규모)**: 모델 파라미터 학습 및 일반화 성능에 직결 (⭕ 모델 설계 요소).
2. **② 사용자에게 결과를 전달하는 네트워크 전송 속도**: 서비스 배포 및 통신 인프라 요소 (❌ 모델 설계 요소 아님 $\rightarrow$ 정답).
3. **③ 학습 데이터의 품질 (정확성·완전성 등)**: 모델의 예측 신뢰성을 결정하는 최우선 요소 (⭕ 모델 설계 요소).
4. **④ 문제 유형에 적합한 알고리즘의 성능**: 분류/회귀/군집 등 태스크별 최적 모델 선정 기준 (⭕ 모델 설계 요소).

### 📚 출제위원 시크릿 족보: [AI 모델 라이프사이클 4단계 및 단계별 고려사항]
$$\boxed{\text{1. 데이터 준비 (양/품질)} \longrightarrow \text{2. 모델 설계/학습 (알고리즘)} \longrightarrow \text{3. 모델 평가 (지표)} \longrightarrow \text{4. 서비스 배포 (네트워크/서버)}}$$

| **서비스 운영 및 배포** (4단계) | **모델 서빙, API 연동, 실시간 추론 파이프라인** | **네트워크 전송 속도, 서버 CPU/GPU 인프라, 처리 지연시간(Latency)** |

### 🧠 빅분기 암기 팁
- **“모델 설계 = 데이터(양+품질) + 알고리즘(유형+성능)!”**
- **“네트워크 전송 속도는 모델 설계가 아니라 배포/인프라 환경!”**

## 📌 [17번] 빅데이터 성공적 활용의 3대 구성요소 - 자원(데이터), 기술, 인력 vs 3V 특성

## 📌 [18번] 분석 과제 우선순위 평가 기준 - 난이도(Difficulty) vs 시급성(Urgency) 2대 축

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 분석 마스터플랜 $\rightarrow$ 분석 과제 우선순위 평가 기준 (시급성 $\times$ 난이도)
- **핵심 의도**: 분석 과제를 평가하는 2대 축인 **난이도(얼마나 구현하기 어려운가?)**와 **시급성(얼마나 빨리 수행해야 하는가?)**의 세부 평가 항목을 명확히 구분할 수 있는지 평가.

### 🎯 정답
**④ 전략적 중요도와 목표 가치(KPI) 측면에서 해당 과제를 얼마나 빨리 수행해야 하는지의 정도 ❌ (난이도가 아니라 시급성 기준)**

### 📌 정답인 이유: [어려움(난이도) vs 급함(시급성)]
- **난이도 (Difficulty / 기술적·비용적 구현 제약)**:
  - 분석에 필요한 **데이터의 확보 난이도 및 비용**(①번), 데이터 정제/변환 등 **가공 노력 및 전처리 비용**(②번), 기존 업무 시스템과의 연동 및 **기술 수준과 투자 규모**(③번) 등 과제를 실제로 구현하고 운영하는 데 드는 어려움과 복잡도를 의미함.
- **시급성 (Urgency / 전략적 가치 및 시간적 긴급성)**:
  - 비즈니스 전략적 중요도, 경영 목표 가치(KPI) 달성 및 조기 성과 창출 측면에서 **"해당 과제를 얼마나 서둘러 빨리 착수·수행해야 하는가?"**(④번)를 판단하는 기준임.
- 따라서 ④번은 난이도가 아닌 **시급성**의 대표적인 정의이므로 정답임.

### 🔎 선지 정밀 분석: [오답 원인 정밀 파쇄]
1. **① 분석에 필요한 데이터의 입수 난이도와 확보 비용**: 데이터 확보 관점의 난이도 (⭕ 난이도 기준).
2. **② 데이터를 적합한 형태로 가공하는 노력과 비용**: 데이터 전처리 및 변환 관점의 난이도 (⭕ 난이도 기준).
3. **③ 업무 시스템에 적용·운영하기 위한 기술 수준과 투자 규모**: IT 시스템 연동 및 인프라 구축의 어려움 (⭕ 난이도 기준).
   - 🚨 **수험생 오답 원인**: '투자 규모'라는 표현만 보고 비즈니스 효과로 착각하기 쉬우나, '시스템 구현을 위해 얼마나 많은 기술과 투자가 드는가'라는 구축 난이도 관점임.
4. **④ 전략적 중요도와 목표 가치(KPI) 측면에서 얼마나 빨리 수행해야 하는지**: 시간적 긴급성과 전략적 가치를 나타내는 대표적 시급성 지표 (❌ 시급성 기준 $\rightarrow$ 정답).

### 📚 출제위원 시크릿 족보: [분석 과제 우선순위 2대 평가 축 매핑 총정리]
$$\boxed{\text{분석 과제 우선순위} = \textbf{시급성 (얼마나 빨리?)} \quad \times \quad \textbf{난이도 (얼마나 어렵게?)}}$$

| 평가 축 | 핵심 질문 | 세부 평가 항목 및 출제 키워드 |
| :--- | :--- | :--- |
| **시급성 (Urgency)** | **“얼마나 빨리 해야 하는가?”** | **전략적 중요도, 목표 가치(KPI), 비즈니스 긴급성, 조기 성과 창출** |
| **난이도 (Difficulty)** | **“얼마나 구현하기 어려운가?”** | **데이터 확보 난이도, 데이터 가공 노력/비용, 분석 기술 수준, 시스템 적용/투자 규모** |

### 🧠 빅분기 암기 팁
- **“어려우면 난이도(데이터 확보·가공·기술수준), 급하면 시급성(전략·KPI·빨리수행)!”**
- **“'얼마나 빨리'가 보이면 0.1초 만에 시급성 확정!”** 1초 컷!

## 📌 [19번] 빅데이터 분석 조직 체계 - 집중형 vs 기능형 vs 분산형 3대 조직 구조

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 거버넌스 $\rightarrow$ 분석 조직 및 인력 구성 3대 구조
- **핵심 의도**: 전사 차원의 **별도 분석 전담 조직**을 신설하여 분석 업무를 총괄함으로써 **전문성 축적과 표준화**에는 유리하나, 현업 부서와의 분리로 인해 **업무 우선순위 충돌 및 이원화** 위험이 있는 조직 구조(**집중형 조직 구조**) 식별.

### 🎯 정답
**① 집중형 조직 구조**

### 📌 정답인 이유: [분석 인력을 중앙에 모으는 조직 구조]
- **집중형 조직 구조 (Centralized Organization)**:
  - 전사 분석 업무를 총괄하는 **독립적인 중앙 분석 전담 조직(데이터사이언스 센터, AI연구소 등)**을 두고, 각 현업 부서로부터 분석 과제를 요청받아 전담팀이 직접 수행하는 방식.
  - **장점**: 분석 전문 인력의 집중화로 지식·노하우 축적, 분석 프로세스 및 모델의 전사 표준화, 중복 투자 방지.
  - **단점**: 현업 부서와의 물리적·조직적 분리로 인해 현업 비즈니스 이슈에 대한 신속 대응 곤란, 현업과의 우선순위 마찰 및 업무 이원화 발생.

### 🔎 선지 정밀 분석: [분석 조직 3대 구조 비교]
1. **① 집중형 조직 구조**: 중앙 전담 조직 운영, 전문성/표준화 $\uparrow$, 현업과 충돌/괴리 $\uparrow$ (⭕ 정답).
2. **② 기능형 조직 구조**: 별도 전담 조직 없이 **각 현업 부서가 자체적으로 분석 수행** (업무 이해도 $\uparrow$, 전사 관점/전문성 $\downarrow$, ❌).
3. **③ 분산형 조직 구조**: 전문 분석 인력을 **각 현업 부서에 직접 배치/파견**하여 현업 밀착형 분석 수행 (신속한 현업 대응 $\uparrow$, ❌).
4. **④ 매트릭스형 조직 구조**: 기능 관리자와 프로젝트 관리자 간의 이중 보고 체계를 갖는 일반 조직론 구조 (❌).

### 📚 출제위원 시크릿 족보: [빅데이터 분석 조직 3대 구조 완벽 비교 총정리표]
$$\boxed{\text{집중형 (중앙에 모은다)} \quad \longleftrightarrow \quad \text{기능형 (현업이 직접 한다)} \quad \longleftrightarrow \quad \text{분산형 (전문가를 현업에 배치한다)}}$$

| 분석 조직 구조 | 분석 업무 수행 주체 | 핵심 장점 (출제 시그니처) | 핵심 단점 및 한계점 |
| :--- | :--- | :--- | :--- |
| **집중형 조직 (Centralized)** | **중앙의 별도 분석 전담 조직** | **전문성 축적, 분석 프로세스 표준화, 전사 통합 관리** | **현업 부서와의 괴리, 업무 우선순위 충돌, 이원화** |
| **기능형 조직 (Functional)** | **각 현업 부서 자체 수행** | **현업 업무 이해도 최고, 즉각적 실무 반영** | **전사 관점 부재, 부서 간 중복 투자, 전문 역량 미흡** |
| **분산형 조직 (Distributed)** | **현업 부서에 파견된 분석 인력** | **현업 밀착형 분석, 신속한 현장 피드백 반영** | 전사적 분석 통제 곤란, 인력 관리 복잡 |

### 🧠 빅분기 암기 팁
- **“별도 전담 조직 + 표준화 + 현업과 충돌 $\rightarrow$ 1초 만에 집중형!”**
- **“현업이 알아서 각자 한다 $\rightarrow$ 기능형!”**
- **“전문가를 현업에 파견/배치한다 $\rightarrow$ 분산형!”**
- **“집중=중앙 집중, 기능=현업 자체, 분산=현업 파견!”** 1초 컷!

## 📌 [20번] 빅데이터 저장소 아키텍처 - 데이터 레이크(Data Lake)와 Schema-on-Read

### ✅ 문제 분석
- **출제 파트**: 제1과목 빅데이터 분석 기획 $\rightarrow$ 데이터 저장 및 인프라 $\rightarrow$ 데이터 저장소 4대 아키텍처(Data Lake, DW, DM, ODS)
- **핵심 의도**: 정형/비정형 원천 데이터를 가공 없이 **Raw 상태로 대규모 저장**하고, 읽기 시점에 스키마를 정의하는 **Schema-on-Read** 방식을 사용하며, 거버넌스 부재 시 **데이터 늪(Data Swamp)**으로 변질될 위험이 있는 저장소(**데이터 레이크, Data Lake**) 식별.

### 🎯 정답
**② 데이터 레이크 (Data Lake)**

### 📌 정답인 이유: [데이터 레이크의 3대 핵심 시그니처]
- **데이터 레이크 (Data Lake)**:
  - 정형(RDB 테이블), 반정형(JSON, XML, 로그), 비정형(이미지, 영상, 텍스트) 등 모든 형태의 방대한 데이터를 사전 가공 없이 **원천(Raw) 상태 그대로 대용량 저장**하는 중앙 저장소.
  - **Schema-on-Read**: 데이터를 적재(Write)할 때 고정 스키마를 강제하지 않고, 향후 분석가가 데이터를 조회·분석(Read)하는 시점에 비로소 스키마 구조를 동적으로 적용함.
  - **데이터 늪 (Data Swamp)**: 데이터 카탈로그 및 메타데이터 관리, 거버넌스가 부실할 경우 어떤 데이터가 어디에 존재하는지 알 수 없게 오염되는 데이터 레이크 고유의 관리 실패 위험.

### 🔎 선지 정밀 분석: [4대 데이터 저장소 비교 대조]
1. **① 데이터 웨어하우스 (Data Warehouse)**: 전사 분석 및 의사결정을 위해 정제·통합된 데이터를 사전에 정의된 구조로 저장 (**Schema-on-Write**, ❌).
2. **② 데이터 레이크 (Data Lake)**: 원천 Raw 데이터, 정형/비정형 수용, Schema-on-Read, Data Swamp 위험 (⭕ 정답).
3. **③ 데이터 마트 (Data Mart)**: 데이터 웨어하우스(DW)로부터 **특정 부서나 특정 비즈니스 주제 영역**에 맞게 구축한 소규모 맞춤형 저장소 (❌).
4. **④ 운영 데이터 저장소 (ODS)**: 여러 트랜잭션 시스템의 데이터를 통합하여 **현재/최신의 운영 업무 지원 및 실시간 질의**를 수행하는 저장소 (❌).

### 📚 출제위원 시크릿 족보: [4대 엔터프라이즈 데이터 저장소 완벽 비교표]
$$\boxed{\text{ODS (운영 최신 데이터)} \longrightarrow \text{DW (정제·통합/Schema-on-Write)} \longrightarrow \text{DM (부서별 요약)} \quad \text{vs} \quad \text{Data Lake (Raw/Schema-on-Read)}}$$

| 데이터 저장소 | 주요 저장 형태 | 스키마 적용 시점 | 주요 목적 및 특징 | 1타 강사 시험 키워드 |
| :--- | :--- | :--- | :--- | :--- |
| **데이터 레이크 (Data Lake)** | **정형 + 반정형 + 비정형 (Raw)** | **Schema-on-Read** | 탐색적 빅데이터/ML 분석, 유연한 저장 | **Raw, Schema-on-Read, Data Swamp** |
| **데이터 웨어하우스 (DW)** | 주로 정형 (정제·구조화) | **Schema-on-Write** | 전사적 BI, 정기 보고서, 의사결정 | **주·통·시·비 (주제/통합/시계열/비휘발)** |
| **데이터 마트 (DM)** | 정형 (부서별 주제 중심) | Schema-on-Write | 특정 부서(마케팅/영업) 분석 지원 | **특정 부서, 소규모 DW** |
| **운영 데이터 저장소 (ODS)** | 정형 트랜잭션 데이터 | Schema-on-Write | 운영 시스템 간 최신 데이터 통합 조회 | **현재/최신 운영 업무 지원** |

### 🧠 빅분기 암기 팁
- **“Raw 데이터 + Schema-on-Read + 데이터 늪(Data Swamp) $\rightarrow$ 무조건 데이터 레이크(Data Lake)!”**
- **“정제·통합 + Schema-on-Write + 4대 특성(주·통·시·비) $\rightarrow$ 데이터 웨어하우스(DW)!”**
- **“특정 부서 맞춤형 $\rightarrow$ 데이터 마트(DM) / 최신 운영 업무 $\rightarrow$ ODS!”** 1초 컷!

## 📌 [21번] 기술통계와 중심적률(Central Moment) - 3차 중심적률과 왜도(Skewness)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 가공 및 기술통계 $\rightarrow$ 적률(Moment), 왜도(Skewness), 첨도(Kurtosis)의 수학적 정의
- **핵심 의도**: 중심적률 $\mu_n = E[(X-\mu)^n]$의 각 차수(1차, 2차, 3차, 4차)가 의미하는 대푯값/산포도/형태 통계량을 정확히 매칭할 수 있는지 평가.

### 🎯 정답
**② 왜도 (Skewness)**

### 📌 정답인 이유: [왜도는 3차, 첨도는 4차]
- **$n$차 중심적률 (Central Moment)**:
  $$\mu_n = E\left[(X - \mu)^n\right]$$
- **3차 중심적률 ($\mu_3$)과 왜도 (Skewness)**:
  - $\mu_3 = E\left[(X - \mu)^3\right]$
  - 편차의 3제곱(홀수 거듭제곱)을 취하므로 **부호(양수/음수)가 보존**되어, 분포가 평균을 기준으로 **어느 방향(오른쪽/왼쪽)으로 비대칭하게 치우쳤는지**를 나타냄.
  - 이를 표준편차의 3제곱($\sigma^3$)으로 정규화(표준화)한 것이 **왜도 계수(Skewness)**임:
    $$\text{Skewness} = \frac{\mu_3}{\sigma^3} = \frac{E[(X-\mu)^3]}{\sigma^3}$$
- **선택 오답 분석 (③ 첨도 Kurtosis)**:
  - 첨도는 분포의 뾰족한 정도와 꼬리의 두께를 측정하는 통계량으로, **4차 중심적률($\mu_4$)**을 바탕으로 정의됨 ($\text{Kurtosis} = \frac{\mu_4}{\sigma^4}$).

### 🔎 선지 정밀 분석: [적률 vs 통계량 매칭 대조]
1. **① 최빈값 (Mode)**: 도수분포에서 빈도수가 가장 높은 관측값으로 적률 공식과 직접적 관련 없음 (❌).
2. **② 왜도 (Skewness)**: **3차 중심적률 $\mu_3$** 기반의 비대칭도 측정 지표 (⭕ 정답).
3. **③ 첨도 (Kurtosis)**: **4차 중심적률 $\mu_4$** 기반의 꼬리 두께/뾰족함 지표 (❌ 4차 적률).
4. **④ 평균 (Mean)**: 1차 원천적률($E[X]$)에 해당하며, 1차 중심적률 $E[X-\mu]$은 정의상 **항상 0**임 (❌).

### 📚 출제위원 시크릿 족보: [중심적률 4대 차수 완벽 매핑 공식]
$$\boxed{\textbf{1차 = 0} \quad \longleftrightarrow \quad \textbf{2차 = 분산 (2분)} \quad \longleftrightarrow \quad \textbf{3차 = 왜도 (3왜)} \quad \longleftrightarrow \quad \textbf{4차 = 첨도 (4첨)}}$$

| 차수 ($n$) | 중심적률 공식 ($\mu_n$) | 대응 통계량 | 통계적 의미 및 직관 |
| :---: | :--- | :--- | :--- |
| **1차** | $E[X - \mu]$ | **항상 0** | 평균과의 편차의 총합/평균은 항상 0 |
| **2차** | $E[(X - \mu)^2]$ | **분산 (Variance, $\sigma^2$)** | 데이터가 평균으로부터 흩어진 퍼짐 정도 |
| **3차** | $E[(X - \mu)^3]$ | **왜도 (Skewness)** | **분포의 비대칭 방향 및 치우침 정도 (홀수승 $\rightarrow$ 부호 보존)** |
| **4차** | $E[(X - \mu)^4]$ | **첨도 (Kurtosis)** | **분포의 중심 뾰족함 및 이상치/꼬리 두께 (짝수승 $\rightarrow$ 극단값 강조)** |

### 🧠 빅분기 암기 팁
- **“2분 · 3왜 · 4첨 (2차 분산, 3차 왜도, 4차 첨도)!”**
- **“방향(+/-)이 중요한 왜도는 홀수 3차 / 극단값 크기 보는 첨도는 짝수 4차!”**
- **“1차 중심적률 = 평균이 아니라 항상 0!”** 1초 컷!

## 📌 [22번] 확률 표본추출 기법 - 계통 추출(Systematic Sampling)과 추출 간격 $k$

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 수집 및 표본추출 $\rightarrow$ 확률표본추출 4총사 (단순무작위, 계통, 층화, 군집)
- **핵심 의도**: 모집단($N=10,000$)에서 표본 크기($n=500$)를 추출할 때, 추출 간격 $k = N/n = 20$을 계산하고 첫 시작점 $r$을 무작위 추출한 후 **일정한 간격 $k$마다 순차 추출하는 방법(**계통 추출, Systematic Sampling**)** 식별.

### 🎯 정답
**④ 계통 추출 (Systematic Sampling)**

### 📌 정답인 이유: [처음만 랜덤 + 이후엔 $k$ 간격 규칙 추출]
- **계통 추출 (Systematic Sampling / 계통 표집법)**:
  - 모집단 개체들이 일련번호나 순서대로 정렬되어 있을 때, 추출 간격 $k = \frac{N}{n}$를 구한 뒤 $1 \sim k$ 사이에서 첫 번째 번호($r$)를 무작위(Random)로 하나 뽑고, 이후 $r, r+k, r+2k, r+3k, \dots$ 와 같이 **일정한 $k$ 간격으로 표본을 연속 추출**하는 확률표본추출법.
  - 문제 예시: $N=10,000, n=500 \rightarrow k = 20$, 첫 번호 $r=7 \rightarrow 7, 27, 47, 67, \dots$ 순 추출.
- **핵심 유의점 (단점/한계)**:
  - 모집단 배열에 특정한 **주기성(Periodicity)**이나 계절성이 존재할 경우, 특정 주기와 추출 간격 $k$가 일치하면 **심각한 표본 편향(Sampling Bias)**이 발생할 수 있음.

### 🔎 선지 정밀 분석: [확률표본추출 4총사 비교]
1. **① 군집 추출 (Cluster Sampling)**: 모집단을 여러 군집(Cluster)으로 나눈 뒤 **일부 군집을 무작위 선택하여 해당 군집 내 전수조사** (❌ 집단 단위 추출).
2. **② 단순 무작위 추출 (Simple Random Sampling)**: 모든 개체가 동일한 확률로 추출되도록 **처음부터 끝까지 난수표/컴퓨터 난수로만 추출** (❌ 규칙적 간격 없음).
3. **③ 층화 추출 (Stratified Sampling)**: 모집단을 상호 배타적인 층(Stratum, 예: 성별/연령대)으로 나눈 뒤 **모든 층에서 골고루 표본 추출** (❌).
4. **④ 계통 추출 (Systematic Sampling)**: 시작점 $r$ 1회 난수 추출 후 **일정한 간격 $k=N/n$마다 순차 추출** (⭕ 정답).

### 📚 출제위원 시크릿 족보: [확률표본추출 4총사 핵심 비교 총정리표]
$$\boxed{\textbf{계통 = 처음만 랜덤 + $k$간격} \quad \longleftrightarrow \quad \textbf{단순무작위 = 끝까지 랜덤} \quad \longleftrightarrow \quad \textbf{층화 = 모든 층에서} \quad \longleftrightarrow \quad \textbf{군집 = 일부 군집만}}$$

| 표본추출 방식 | 추출 메커니즘 | 출제 시그니처 키워드 | 주요 장단점 |
| :--- | :--- | :--- | :--- |
| **계통 추출 (Systematic)** | **첫 번째 $r$ 무작위 $\rightarrow$ 이후 $k=N/n$ 간격** | **일정 간격 $k$, $r+k, r+2k$** | **추출 용이 / [주기성 존재 시 편향 위험]** |
| **단순 무작위 (SRS)** | 모든 개체에 $1/N$ 동일 추출 확률 부여 | 완전 난수, 난수표, 복원/비복원 | 표본 프레임 필수, 시간/비용 큼 |
| **층화 추출 (Stratified)** | 층내 동질, 층간 이질 $\rightarrow$ **모든 층에서 추출** | 집단 분할 후 **각 층에서 골고루** | 대표성 최고, 모집단 층 정보 필요 |
| **군집 추출 (Cluster)** | 군집내 이질, 군집간 동질 $\rightarrow$ **일부 군집 선택** | **학교, 지역, 지점 통째로 선택** | 조사 비용/시간 대폭 절감, 표본오차 큼 |

### 🧠 빅분기 암기 팁
- **“일정 간격 $k$마다 건너뛰며 뽑는다 $\rightarrow$ 1초 만에 계통 추출!”**
- **“단순=끝까지 랜덤 / 계통=처음만 랜덤 / 층화=모든 층에서 / 군집=일부 군집 통째로!”**
- **“계통 추출의 시험 단골 오답 함정: 모집단 주기성(Periodicity) 주의!”** 1초 컷!

## 📌 [23번] 데이터 정제 및 이상값(Outlier) - 이상값 발생 원인 vs 표본 오류(Sampling Error)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 및 정제 $\rightarrow$ 이상값(Outlier)의 정의 및 발생 원인
- **핵심 의도**: 개별 데이터의 관측값을 비정상적인 극단값으로 왜곡시키는 **데이터 수준의 오류(측정 오류, 관측 오류, 보고/입력 오류)**와, 표본추출 과정에서 자연스럽게 발생하는 통계적 대표성의 차이인 **표본 오류(Sampling Error)**를 명확히 구분할 수 있는지 평가.

### 🎯 정답
**③ 표본 오류 (Sampling Error) ❌ (이상값의 직접적 발생 원인이 아님)**

### 📌 정답인 이유: [값의 왜곡(이상치) vs 대표성의 차이(표본오차)]
- **이상값 (Outlier)**:
  - 대다수의 정상적인 관측치로부터 비정상적으로 크게 벗어난 극단적인 관측값.
  - **직접적 발생 원인**:
    1. **측정 오류 (Measurement Error)**: 센서·저울 등 측정 장비의 오작동, 캘리브레이션 불량 ($70\text{kg} \rightarrow 700\text{kg}$).
    2. **관측 오류 (Observation Error)**: 사람이 눈으로 확인하고 판독하는 과정에서의 착각·오독 ($18.5^\circ\text{C} \rightarrow 81.5^\circ\text{C}$).
    3. **보고/입력 오류 (Reporting Error)**: 설문 응답자 작성 실수, 데이터 전산 입력 시 오타 및 자릿수 오류 ($1.75\text{m} \rightarrow 175\text{m}$).
- **표본 오류 (Sampling Error)**:
  - 모집단 전체를 전수조사하지 않고 일부 표본만을 무작위 추출했기 때문에 필연적으로 발생하는 **표본통계량($\bar{X}$)과 모집단 모수($\mu$) 사이의 통계적 편차**.
  - 데이터 값 하나하나가 오염되거나 망가진 것이 아니므로 **이상값의 생성 원인이 될 수 없음**.

### 🔎 선지 정밀 분석: [오답 원인 정밀 파쇄]
1. **① 측정 오류 (Measurement Error)**: 계측기 고장 등으로 인한 비정상 극단값 생성 (⭕ 이상값 원인).
2. **② 관측 오류 (Observation Error)**: 관찰자의 주관적 판독 실수로 인한 극단값 생성 (⭕ 이상값 원인).
3. **③ 표본 오류 (Sampling Error)**: 표본과 모집단 간의 통계적 표본오차로 개별 데이터 이상값 원인이 아님 (❌ 비원인 $\rightarrow$ 정답).
4. **④ 보고 오류 (Reporting Error)**: 설문 기재 실수나 데이터 입력 오타로 인한 극단값 생성 (⭕ 이상값 원인).
   - 🚨 **수험생 오답 원인**: '보고 오류'를 이상값 원인이 아니라고 생각하기 쉬우나, 실제 전산 데이터 이상치의 80% 이상이 자릿수 오타 등 보고/입력 오류에서 비롯됨.

### 📚 출제위원 시크릿 족보: [데이터 오류 유형 vs 이상값 관계 총정리표]
$$\boxed{\textbf{측정 · 관측 · 보고 오류} \longrightarrow \text{개별 데이터 값 파손} \longrightarrow \textbf{이상값(Outlier) 발생}}$$
$$\boxed{\textbf{표본 오류(Sampling Error)} \longrightarrow \text{표본과 모수의 통계적 차이} \longrightarrow \textbf{이상값 원인 아님!}}$$

| 오류 유형 | 발생 단계 및 원인 | 데이터 값 손상 여부 | 이상값(Outlier) 유발 여부 |
| :--- | :--- | :---: | :---: |
| **측정 오류 (Measurement)** | 계측 기기 고장, 센서 오작동, 노후화 | ⭕ (값 왜곡) | **⭕ 이상값 직접 발생** |
| **관측 오류 (Observation)** | 관측자의 시각적 오독, 잘못된 측정 기록 | ⭕ (값 왜곡) | **⭕ 이상값 직접 발생** |
| **보고/입력 오류 (Reporting)** | 설문 작성자 허위/실수 기재, 타이핑 오타 | ⭕ (값 왜곡) | **⭕ 이상값 직접 발생** |
| **표본 오류 (Sampling)** | **표본추출에 따른 확률적 대표성 차이** | **❌ (정상 데이터)** | **❌ 이상값 발생 원인 아님** |

### 🧠 빅분기 암기 팁
- **“측·관·보(측정·관측·보고)는 값을 망가뜨려 이상치를 만들고, 표본오차는 대표성의 문제다!”**
- **“이상값 원인이 아닌 것 $\rightarrow$ 0.1초 만에 Sampling Error(표본오차)!”** 1초 컷!

## 📌 [24번] 독립 확률변수의 선형결합 - 합의 분산 $Var(X_1 + X_2)$과 표준편차 $SD(X_1 + X_2)$

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 확률분포 $\rightarrow$ 독립 확률변수의 기댓값과 분산 성질
- **핵심 의도**: 모분산이 $\sigma^2$인 모집단에서 서로 독립적으로 추출된 2개의 확률변수 $X_1, X_2$의 **합의 표준편차($SD(X_1 + X_2)$)**를 계산할 때, 표준편차를 직접 더하는 함정($2\sigma$)에 빠지지 않고 **분산을 먼저 합산한 후 제곱근을 취하는 정석 원리**를 알고 있는지 평가.

### 🎯 정답
**① $\sqrt{2}\sigma$**

### 📌 정답인 이유: [표준편차끼리 더하지 말고, 분산부터 더하고 루트!]
1. **1단계: 독립 확률변수의 분산 합산 (분산 가법성)**
   - 두 확률변수 $X_1, X_2$가 서로 독립($Cov(X_1, X_2)=0$)이므로:
     $$Var(X_1 + X_2) = Var(X_1) + Var(X_2) = \sigma^2 + \sigma^2 = 2\sigma^2$$
2. **2단계: 표준편차 계산 (분산에 제곱근 적용)**
   - 표준편차는 분산의 양의 제곱근이므로:
     $$SD(X_1 + X_2) = \sqrt{Var(X_1 + X_2)} = \sqrt{2\sigma^2} = \sqrt{2}\sigma$$
- **선택 오답 분석 (② $2\sigma$)**:
  - $SD(X_1) + SD(X_2) = \sigma + \sigma = 2\sigma$ 처럼 표준편차를 단순 덧셈한 것으로, 확률변수의 선형결합에서는 **표준편차가 직접 더해지지 않으며 반드시 분산을 거쳐 계산해야 함**.

### 🔎 선지 정밀 분석: [오답 원인 정밀 파쇄]
1. **① $\sqrt{2}\sigma$**: 분산 $2\sigma^2$의 제곱근으로 정확한 표준편차 (⭕ 정답).
2. **② $2\sigma$**: 표준편차를 직접 더한 전형적인 수험생 낚시 함정 (❌ 오답).
3. **③ $\sigma$**: 두 확률변수가 합쳐졌음에도 변동성이 증가하지 않는다고 오인 (❌ 오답).
4. **④ $2\sqrt{\sigma}$**: 분산 $\sigma^2$과 표준편차 $\sigma$의 관계를 혼동한 수학적 오류 (❌ 오답).

### 📚 출제위원 시크릿 족보: [독립 확률변수의 연산별 분산 및 표준편차 총정리표]
$$\boxed{Var(aX + bY) = a^2 Var(X) + b^2 Var(Y) \quad (\text{단, } X, Y \text{는 독립})}$$

| 연산 형태 | 분산 계산 ($Var$) | 최종 분산 | 표준편차 ($SD = \sqrt{Var}$) | 핵심 출제 포인트 |
| :--- | :--- | :---: | :---: | :--- |
| **단일 변수 $X_1$** | $Var(X_1)$ | $\sigma^2$ | $\sigma$ | 기본 모분산과 모표준편차 |
| **합 $X_1 + X_2$** | $Var(X_1) + Var(X_2)$ | **$2\sigma^2$** | **$\sqrt{2}\sigma$** | **분산 더하고 루트 씌움** |
| **차 $X_1 - X_2$** | $1^2Var(X_1) + (-1)^2Var(X_2)$ | **$2\sigma^2$** | **$\sqrt{2}\sigma$** | **🚨 뺄셈도 제곱되어 분산은 더해짐!** |
| **표본평균 $\bar{X} = \frac{X_1+X_2}{2}$** | $(\frac{1}{2})^2Var(X_1) + (\frac{1}{2})^2Var(X_2)$ | **$\frac{\sigma^2}{2}$** | **$\frac{\sigma}{\sqrt{2}}$** | **표본평균의 표준오차($\frac{\sigma}{\sqrt{n}}$)** |

### 🧠 빅분기 암기 팁
- **“독립 확률변수 합/차 $\rightarrow$ 표준편차끼리 더하지 말고, 분산부터 더하고 마지막에 루트!”**
- **“$\sigma^2 + \sigma^2 = 2\sigma^2 \longrightarrow \sqrt{2\sigma^2} = \sqrt{2}\sigma$!”** 1초 컷!
- **“뺄셈($X_1 - X_2$)도 $(-1)^2=1$이 되어 분산은 무조건 더해진다!”**

## 📌 [25번] 이산확률분포의 기댓값과 분산 - 주사위 확률변수의 분산 $Var(X) = E[X^2] - (E[X])^2$

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 확률분포 $\rightarrow$ 이산확률변수의 기댓값과 분산 계산
- **핵심 의도**: 1부터 6까지의 값을 각각 $\frac{1}{6}$의 동일 확률로 갖는 주사위 확률변수 $X$의 분산을 구할 때, 제곱의 기댓값 $E[X^2] = \frac{91}{6}$에서 멈추지 않고 **평균의 제곱 $(E[X])^2 = (\frac{7}{2})^2 = \frac{49}{4}$을 차감하는 정석 분산 공식($\text{제평} - \text{평제}$)**을 적용할 수 있는지 평가.

### 🎯 정답
**④ $\frac{35}{12}$**

### 📌 정답인 이유: [분산 계산 3단계 파이프라인: 제평 - 평제]
1. **1단계: 기댓값(평균, $E[X]$) 계산**
   $$E[X] = \sum_{x=1}^6 x \cdot P(X=x) = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = \frac{7}{2} = 3.5$$
2. **2단계: 제곱의 기댓값($E[X^2]$) 계산**
   $$E[X^2] = \sum_{x=1}^6 x^2 \cdot P(X=x) = \frac{1^2+2^2+3^2+4^2+5^2+6^2}{6} = \frac{1+4+9+16+25+36}{6} = \frac{91}{6}$$
3. **3단계: 분산 공식 대입 ($Var(X) = E[X^2] - (E[X])^2$)**
   $$Var(X) = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{91}{6} - \frac{49}{4} = \frac{182 - 147}{12} = \mathbf{\frac{35}{12}}$$
- **선택 오답 분석 (① $\frac{91}{6}$)**:
  - $E[X^2] = \frac{91}{6}$까지 정확하게 계산했으나, 마지막 단계인 평균의 제곱 차감($-\{E[X]\}^2$)을 누락하여 제곱의 기댓값을 분산으로 착각한 출제위원의 최상급 낚시 함정.

### 🔎 선지 정밀 분석: [오답 함정 분쇄]
1. **① $\frac{91}{6}$**: $E[X^2]$ (제곱의 기댓값만 계산하고 멈춘 오답, ❌).
2. **② $\frac{7}{2}$**: $E[X]$ (기댓값/평균, ❌).
3. **③ $\frac{35}{6}$**: 분모 통분 과정의 연산 실수 유도 오답 (❌).
4. **④ $\frac{35}{12}$**: $Var(X) = \frac{91}{6} - \frac{49}{4} = \frac{35}{12}$ (⭕ 정답).

### 📚 출제위원 시크릿 족보: [이산균등분포 $1 \sim n$ 초고속 1초 컷 공식]
$$\boxed{Var(X) = E[X^2] - (E[X])^2 = \textbf{제평 } - \textbf{ 평제} \quad (\text{일반 공식})}$$
$$\boxed{X \sim \text{Discrete Uniform}(1, n) \Longrightarrow E[X] = \frac{n+1}{2}, \quad Var(X) = \frac{n^2 - 1}{12} \quad (\text{1초 컷 특수 공식})}$$

- **주사위($n=6$) 1초 컷 적용**:
  $$Var(X) = \frac{6^2 - 1}{12} = \frac{36 - 1}{12} = \mathbf{\frac{35}{12}} \quad (\text{암산 가능!})$$

### 🧠 빅분기 암기 팁
- **“분산 = 제평 - 평제 (제곱의 평균 - 평균의 제곱)!”**
- **“$\frac{91}{6}$은 $E[X^2]$일 뿐, 아직 분산이 아니다! $(\frac{7}{2})^2 = \frac{49}{4}$를 반드시 빼라!”**
- **“$1 \sim n$ 주사위 분산 공식: $\frac{n^2-1}{12} = \frac{35}{12}$!”** 1초 컷!

## 📌 [26번] 상관분석 - 피어슨 상관계수(Pearson Correlation)의 특성과 비선형 관계의 한계

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 상관분석 $\rightarrow$ 피어슨 상관계수 vs 스피어만 순위상관계수
- **핵심 의도**: 피어슨 상관계수($r$)가 두 연속형 변수 사이의 **직선적인 선형(Linear) 관계만을 측정**하며, 2차 곡선($Y=X^2$) 등 비선형 관계가 뚜렷하더라도 이를 측정하지 못하는 한계점을 파악하고 있는지 평가.

### 🎯 정답
**① 두 변수 사이에 곡선 형태의 비선형 관계가 존재하더라도 그 관계의 강도를 잘 설명할 수 있다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [피어슨은 '직선(선형)'만 본다!]
- **피어슨 상관계수 (Pearson $r$)**:
  $$r = \frac{Cov(X, Y)}{\sigma_X \sigma_Y} = \frac{\sum (X-\bar{X})(Y-\bar{Y})}{\sqrt{\sum (X-\bar{X})^2 \sum (Y-\bar{Y})^2}} \quad (-1 \le r \le 1)$$
  - 두 연속형 변수 간의 **선형적(Linear) 연관성의 방향($+/-$)과 강도($|r|$)**를 측정하는 모수적 척도.
  - **비선형 관계의 치명적 한계**: $Y = X^2$과 같이 $X$와 $Y$ 사이에 완벽한 비선형 함수 관계가 존재하더라도, $X$가 대칭적으로 분포하면 공분산이 0이 되어 **$r=0$**으로 계산됨. 따라서 "비선형 관계의 강도를 잘 설명할 수 있다"는 설명은 명백한 오류임.
  - **이상값(Outlier) 민감성**: 평균 및 편차의 곱을 직접 사용하므로 이상치 1~2개에 의해 상관계수 값이 왜곡되기 쉬움.

### 🔎 선지 정밀 분석: [오답 선지 완벽 파쇄]
1. **① 비선형 관계도 잘 설명할 수 있다**: 직선(선형) 관계만 측정 가능하며 비선형 곡선 관계는 설명 불가 (❌ 틀린 설명 $\rightarrow$ 정답).
2. **② $-1 \le r \le 1$ 범위이며 절댓값이 클수록 관계가 강하다**: 부호는 관계의 방향(양/음), 절댓값 $|r|$은 선형 관계의 강도 (⭕ 옳은 설명).
3. **③ 이상값(Outlier)의 영향을 크게 받을 수 있다**: 모수적 통계량으로 극단값에 취약 (⭕ 옳은 설명).
4. **④ 두 연속형 변수 사이의 선형 관계의 강도와 방향을 측정한다**: 피어슨 상관계수의 표준 정의 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [상관계수 2대 대표 척도 완벽 비교표]
$$\boxed{\textbf{피어슨 (Pearson) = 선형(직선) + 연속형 + 이상치 취약} \quad \longleftrightarrow \quad \textbf{스피어만 (Spearman) = 단조(순위) + 서열척도 + 이상치 강건}}$$

| 비교 항목 | 피어슨 상관계수 (Pearson $r$) | 스피어만 상관계수 (Spearman $\rho$) |
| :--- | :--- | :--- |
| **측정 대상** | **선형(Linear, 직선)적 연관성** | **단조(Monotonic, 순위)적 연관성** |
| **데이터 유형** | **연속형 척도 (등간/비율 척도)** | **순서형/서열 척도 및 비정규 연속형** |
| **계산 방식** | 실제 데이터 관측값의 공분산/표준편차 | **관측값의 순위(Rank) 간 피어슨 상관계수** |
| **이상값 영향** | **극도로 민감함 (왜곡 위험 $\uparrow$)** | **상대적으로 강건함 (Robust)** |
| **비선형 단조 관계** | 포착 불가 ($Y=X^3$ 등에서 왜곡) | **완벽 포착 ($\rho = 1.0$)** |

### 🧠 빅분기 암기 팁
- **“피어슨 = 직선(선형)만 본다! 곡선/비선형 잘 잡는다는 선지는 0.1초 만에 오답!”**
- **“$r=0$은 선형 관계가 없다는 뜻이지, 아무 관계가 없다는 뜻이 아니다 ($Y=X^2$도 $r=0$)!”**
- **“상관관계 $\neq$ 인과관계 / 부호는 방향, 절댓값은 강도!”** 1초 컷!

## 📌 [27번] 추론통계의 기반 - 중심극한정리(CLT) vs 대수의 법칙(LLN)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 확률분포 $\rightarrow$ 표집분포 및 중심극한정리 (CLT)
- **핵심 의도**: 모집단의 분포 형태와 무관하게 표본의 크기 $n$이 충분히 클 때, **표본평균($\bar{X}$)의 표집분포가 정규분포 $N(\mu, \frac{\sigma^2}{n})$로 근사**한다는 통계학의 핵심 정리(**중심극한정리, Central Limit Theorem**) 식별.

### 🎯 정답
**④ 중심극한정리 (Central Limit Theorem, CLT)**

### 📌 정답인 이유: [표본평균들의 분포 $\rightarrow$ 정규분포 근사]
- **중심극한정리 (Central Limit Theorem)**:
  - 평균이 $\mu$이고 분산이 $\sigma^2$인 임의의 모집단(비대칭, 균등, 이항 등 무관)에서 크기가 $n$인 표본을 독립 추출할 때, $n$이 충분히 크면(통상 $n \ge 30$) **표본평균 $\bar{X}$의 분포는 모평균 $\mu$, 분산 $\frac{\sigma^2}{n}$인 정규분포에 근사함**:
    $$\bar{X} \approx N\left(\mu, \frac{\sigma^2}{n}\right) \quad \Longleftrightarrow \quad Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \approx N(0, 1)$$
  - **표준오차 (Standard Error)**: $SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}$ ($n$이 커질수록 표본평균의 변동성 감소).
- **선택 오답 분석 (② 베이즈 정리 Bayes' Theorem)**:
  - 사전확률(Prior)과 우도(Likelihood)를 결합하여 새로운 데이터 관측 후 사후확률(Posterior)을 갱신하는 조건부 확률 정리로, 표집분포의 정규분포 근사와는 무관함.

### 🔎 선지 정밀 분석: [통계학 4대 핵심 정리 대조]
1. **① 대수의 법칙 (Law of Large Numbers, LLN)**: 표본 크기 $n \to \infty$ 일 때 **표본평균의 '값'($\bar{X}$)이 모평균($\mu$)에 확률적으로 수렴**한다는 법칙 (❌ 분포 형태가 아닌 값의 수렴).
2. **② 베이즈 정리 (Bayes' Theorem)**: $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$ (조건부 확률 갱신, ❌).
3. **③ 체비셰프 부등식/정리 (Chebyshev's Theorem)**: 임의의 확률분포에서 평균으로부터 $k$배 표준편차 범위 내에 데이터가 존재할 최소 확률 $P(|X-\mu| < k\sigma) \ge 1 - \frac{1}{k^2}$ 보장 (❌).
4. **④ 중심극한정리 (Central Limit Theorem)**: 모집단 분포 무관, $n$ 증가 시 **표본평균의 '분포'가 정규분포 근사** (⭕ 정답).

### 📚 출제위원 시크릿 족보: [통계학 4대 정리 완벽 비교표]
$$\boxed{\textbf{대수의 법칙: } \bar{X} \longrightarrow \mu \quad (\text{값의 수렴}) \quad \longleftrightarrow \quad \textbf{중심극한정리: } \bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right) \quad (\text{분포의 정규 근사})}$$

| 통계학 핵심 정리 | 핵심 질문 / 적용 대상 | 출제 시그니처 키워드 | 핵심 수식 |
| :--- | :--- | :--- | :--- |
| **중심극한정리 (CLT)** | **표본평균들의 분포는 어떤 모양인가?** | **모집단 무관, 표본 크기 $n$ 충분, 정규분포 근사** | **$\bar{X} \sim N(\mu, \frac{\sigma^2}{n}), SE = \frac{\sigma}{\sqrt{n}}$** |
| **대수의 법칙 (LLN)** | **표본평균의 값은 어디로 다가가는가?** | **표본수 증가 시 표본평균 $\rightarrow$ 모평균 수렴** | **$\lim_{n \to \infty} P(|\bar{X} - \mu| < \epsilon) = 1$** |
| **베이즈 정리 (Bayes)** | **새로운 증거 하에서 사후확률은 얼마인가?** | **사전확률, 우도, 사후확률, 조건부확률 갱신** | **$P(A\|B) = \frac{P(B\|A)P(A)}{P(B)}$** |
| **체비셰프 부등식** | **평균 $\pm k\sigma$ 안에 최소 몇 %가 있는가?** | **분포 무관, 평균 주변 데이터 최소 비율** | **$P(\|X-\mu\| \ge k\sigma) \le \frac{1}{k^2}$** |

### 🧠 빅분기 암기 팁
- **“평균의 '값'이 모평균으로 가면 대수의 법칙 / 평균들의 '분포'가 정규분포로 가면 중심극한정리!”**
- **“모집단 분포 무관 + $n$이 충분히 크면 + 정규분포 근사 $\rightarrow$ 1초 만에 중심극한정리!”**
- **“표본평균 3총사 공식: $E(\bar{X})=\mu, Var(\bar{X})=\frac{\sigma^2}{n}, SE(\bar{X})=\frac{\sigma}{\sqrt{n}}$!”** 1초 컷!

## 📌 [28번] 탐색적 데이터 분석(EDA) - 상자그림(Box Plot) 해석과 IQR 기반 이상값 판정

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 EDA $\rightarrow$ 상자그림(Box Plot)의 5수치 요약 및 이상값(Outlier) 식별
- **핵심 의도**: 두 질병(A vs B)의 치료 기간 상자그림을 보고 중앙값($Q_2$), 사분위수 범위($IQR = Q_3 - Q_1$), 이상값($\circ$ 마커) 유무 및 비대칭도(왜도 방향)를 정확히 판독할 수 있는지 평가.

### 🎯 정답
**③ B 질병에서는 이상값(Outlier)으로 표시된 관측치가 나타난다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [상자그림 5대 요약 수치 및 이상치 식별법]
- **이상값 마커 판독**:
  - 그래프에서 상자그림의 수염(Whisker) 범위를 벗어난 이상값은 **원형($\circ$) 마커**로 표기됨.
  - **A 질병**: 약 60일 지점에 이상값 마커($\circ$)가 뚜렷이 존재함 ($Q_3 + 1.5 \times IQR \approx 34 + 24 = 58$ 초과).
  - **B 질병**: 상하 수염 내에 모든 관측치가 포함되어 **이상값 마커가 전혀 나타나지 않음**. 따라서 ③번은 틀린 설명임.

### 🔎 선지 정밀 분석: [상자그림 4대 선지 판독]
1. **① B 질병의 치료기간 중앙값이 A 질병보다 크다**: 중앙값 실선 기준 질병 B($\approx 30$) > 질병 A($\approx 24$) (⭕ 옳은 설명).
2. **② A 질병의 IQR이 B 질병의 IQR보다 크다**: 상자 높이($IQR = Q_3 - Q_1$) 기준 질병 A($34-18=16$) > 질병 B($38-26=12$) (⭕ 옳은 설명).
3. **③ B 질병에서 이상값 관측치가 나타난다**: B에는 이상치($\circ$)가 없으므로 거짓 (❌ 틀린 설명 $\rightarrow$ 정답).
4. **④ 두 질병 모두 중앙값이 상자 아래쪽에 치우쳐 오른쪽으로 긴 꼬리를 갖는다**: 중앙값($Q_2$)이 $Q_1$에 가깝고 상단 수염이 길어 양의 왜도(오른쪽 긴 꼬리) 형태 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [상자그림(Box Plot) 5수치 요약 및 이상치 경계 공식]
$$\boxed{IQR = Q_3 - Q_1 \quad \longleftrightarrow \quad \text{정상 범위: } [Q_1 - 1.5 \times IQR, \; Q_3 + 1.5 \times IQR]}$$

```text
               ○  (Upper Outlier: X > Q3 + 1.5*IQR)
             ───── (Upper Whisker: Min(Max(X), Q3 + 1.5*IQR))
             ┌───┐ (Q3, 제3사분위수 = 75%)
             │   │ 
             ├───┤ (Q2, 중앙값 Median = 50%)
             │   │ (상자 높이 = IQR)
             └───┘ (Q1, 제1사분위수 = 25%)
             ───── (Lower Whisker: Max(Min(X), Q1 - 1.5*IQR))
               ○  (Lower Outlier: X < Q1 - 1.5*IQR)
```

| 판독 요소 | 그래프 위치 | 통계적 의미 |
| :--- | :--- | :--- |
| **중앙값 (Median, $Q_2$)** | **상자 내부의 실선** | 데이터 중심 위치 (50 백분위수) |
| **사분위수 범위 (IQR)** | **상자의 세로 높이 ($Q_3 - Q_1$)** | 가운데 50% 데이터의 산포도 |
| **위/아래 수염 (Whisker)** | 상자 밖으로 뻗은 선분의 끝단 | 이상치를 제외한 최대/최소 관측치 |
| **이상값 (Outlier)** | **수염 바깥의 별도 점($\circ$, $*$)** | $1.5 \times IQR$ 경계를 벗어난 극단값 |

### 🧠 빅분기 암기 팁
- **“박스플롯 이상치 $\rightarrow$ 수염 밖 동그라미($\circ$) 위치만 보면 1초 컷!”**
- **“상자 높이 = $IQR = Q_3 - Q_1$ / 중앙값 = 상자 안 실선!”**
- **“이상값 경계 = $[Q_1 - 1.5IQR, \; Q_3 + 1.5IQR]$!”** 1초 컷!

## 📌 [29번] 차원 축소 및 다변량 분석 - SVD(특이값 분해)의 행렬 조건 vs PCA/LDA/ICA/요인분석

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 다변량 분석 및 차원 축소 $\rightarrow$ PCA, LDA, ICA, SVD, 요인분석(FA)의 핵심 원리 비교
- **핵심 의도**: 특이값 분해(**SVD, Singular Value Decomposition**)가 고유값 분해(EVD)와 달리 **$m \times n$ 직사각형 행렬(Rectangular Matrix)에도 얼마든지 적용 가능하다는 강력한 성질**을 정확히 알고 있는지 평가.

### 🎯 정답
**② 특이값 분해(SVD)는 $m \times m$ 정방행렬에만 적용할 수 있으며, 정방행렬이 아닌 데이터에는 사용할 수 없다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [SVD는 직사각형 행렬 분해의 최강자!]
- **특이값 분해 (SVD, Singular Value Decomposition)**:
  $$A_{m \times n} = U_{m \times m} \, \Sigma_{m \times n} \, V^T_{n \times n}$$
  - $U$: $A A^T$의 고유벡터들로 구성된 $m \times m$ 직교행렬 (Left Singular Vectors).
  - $\Sigma$: $m \times n$ 대각행렬 (대각원소는 특이값 $\sigma_i = \sqrt{\lambda_i}$).
  - $V$: $A^T A$의 고유벡터들로 구성된 $n \times n$ 직교행렬 (Right Singular Vectors).
  - **결정적 특징**: $m \ne n$인 **임의의 직사각형 행렬(Rectangular Matrix)**에 대해 항상 유일하게 분해 가능함. 따라서 "정방행렬에만 적용할 수 있다"는 설명은 고유값 분해(EVD)와 혼동한 명백한 거짓임.
- **선택 오답 분석 (① ICA 독립 성분 분석)**:
  - 혼합된 다변량 신호에서 비가우스성(Non-Gaussianity)을 최대화하여 통계적으로 상호 독립적인 원천 신호를 분리하는 기법(칵테일 파티 효과 해결)으로, 지극히 올바른 설명임.

### 🔎 선지 정밀 분석: [차원축소 5대 기법 완벽 파쇄]
1. **① 독립 성분 분석 (ICA)**: 다변량 혼합 신호를 통계적 독립 성분으로 분리 (⭕ 옳은 설명 - 칵테일 파티 문제).
2. **② 특이값 분해 (SVD)**: $m \times n$ 직사각형 행렬 분해 가능하므로 정방행렬 한정은 거짓 (❌ 틀린 설명 $\rightarrow$ 정답).
3. **③ 요인분석 (Factor Analysis)**: 잠재 변수(Latent Factor)를 바탕으로 상관관계가 높은 관측 변수 군집화 (⭕ 옳은 설명).
4. **④ LDA vs PCA 비교**: PCA는 분산 최대화(데이터 표현/비지도), LDA는 클래스 간 분리 최대화(분류력 극대화/지도) (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [차원 축소 5대 대표 기법 비교 총정리표]
$$\boxed{\textbf{SVD: } A_{m \times n} = U \Sigma V^T \quad (\textbf{직사각형 행렬 OK}) \quad \longleftrightarrow \quad \textbf{고유값 분해: } A_{n \times n} = P \Lambda P^{-1} \quad (\textbf{정방행렬 필수})}$$

| 차원 축소 기법 | 학습 유형 | 핵심 메커니즘 / 목적 | 출제 시그니처 키워드 |
| :--- | :---: | :--- | :--- |
| **PCA (주성분 분석)** | **비지도** | **데이터 분산 최대화** (서로 무상관 직교 기저) | **비지도, 데이터 잘 표현, 분산 보존** |
| **LDA (선형 판별 분석)** | **지도** | **클래스 간 분산 $\uparrow$ / 클래스 내 분산 $\downarrow$** | **지도학습, 분류력 최대화, 클래스 분리** |
| **ICA (독립 성분 분석)** | 비지도 | **통계적 독립성 극대화** (비가우스성 최대화) | **독립적 원천 신호, 칵테일 파티 효과** |
| **SVD (특이값 분해)** | 선형대수 | **$m \times n$ 임의 행렬 분해** ($U \Sigma V^T$) | **직사각형 행렬 분해 가능, LSA, 추천시스템** |
| **FA (요인 분석)** | 다변량 | **잠재 요인(Latent Factor) 탐색** | **관찰 불가 잠재변수, 공통 요인 묶기** |

### 🧠 빅분기 암기 팁
- **“SVD = 사각형(직사각형 행렬)도 무조건 OK! 정방행렬만 된다고 하면 0.1초 만에 오답!”**
- **“PCA는 잘 담자(분산 최대화), LDA는 잘 나누자(분류 최대화)!”**
- **“PCA = 비상관 / ICA = 통계적 독립 / FA = 잠재 요인!”** 1초 컷!

## 📌 [30번] 데이터 전처리 및 인코딩 - 원-핫 인코딩(One-Hot Encoding)의 직교성과 의미적 유사성 한계

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 및 변수 변환 $\rightarrow$ 범주형 변수 인코딩 (One-Hot Encoding vs Label Encoding vs Embedding)
- **핵심 의도**: 원-핫 인코딩으로 변환된 서로 다른 범주 벡터들은 **서로 다른 좌표축에 위치하여 내적이 0인 상호 직교(Orthogonal) 관계**를 가지므로, 코사인 유사도가 항상 0이 되어 **범주 간의 의미적 유사성(Semantic Similarity)을 전혀 파악할 수 없다는 본질적 한계**를 알고 있는지 평가.

### 🎯 정답
**② 범주 간 코사인 유사도를 계산하여 범주들 사이의 의미적 유사성을 파악할 수 있다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [원-핫 벡터는 모두 남남(직교)이다!]
- **원-핫 인코딩 (One-Hot Encoding)**:
  - 범주의 총 개수가 $k$개일 때, 각 범주를 해당 위치만 1이고 나머지는 모두 0인 **$k$차원 단위 벡터**로 변환하는 기법.
  - **직교성과 코사인 유사도 0**:
    - 임의의 서로 다른 두 범주 $A=(1, 0, 0), B=(0, 1, 0)$의 내적은 $A \cdot B = 1(0) + 0(1) + 0(0) = 0$.
    - 따라서 코사인 유사도 $\cos \theta = \frac{A \cdot B}{\|A\|\|B\|} = \mathbf{0}$.
    - 모든 서로 다른 범주 쌍 간의 코사인 유사도가 예외 없이 0이 되므로, '고양이-호랑이'와 '고양이-자동차'의 유사도 차이를 전혀 구별할 수 없음.
  - **치명적 단점 (고카디널리티 문제)**:
    - 고유 범주 수가 많을수록 차원이 급격히 팽창하여(차원의 저주), 대부분의 원소가 0으로 채워지는 **희소 벡터(Sparse Vector) 문제 및 메모리 낭비** 발생.

### 🔎 선지 정밀 분석: [오답 선지 완벽 파쇄]
1. **① 생성되는 벡터의 차원은 범주의 총 개수와 동일하다**: $k$개 범주 $\rightarrow$ $k$차원 벡터 생성 (⭕ 옳은 설명).
2. **② 코사인 유사도로 의미적 유사성을 파악할 수 있다**: 모든 내적과 코사인 유사도가 0이므로 의미적 유사성 파악 불가 (❌ 틀린 설명 $\rightarrow$ 정답).
3. **③ 서로 다른 범주를 나타내는 두 벡터의 내적은 항상 0이며 직교한다**: $A \cdot B = 0$ 상호 직교 관계 (⭕ 옳은 설명).
4. **④ 해당 범주 위치만 1이고 나머지는 모두 0으로 채워진다**: One-Hot의 기본 정의 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [범주형 변수 3대 인코딩 기법 완벽 비교표]
$$\boxed{\textbf{원-핫 인코딩} \longrightarrow \text{상호 직교 (내적 0, } \cos\theta=0) \longrightarrow \textbf{의미적 유사성 측정 불가!}}$$
$$\boxed{\textbf{밀집 임베딩(Embedding)} \longrightarrow \text{저차원 연속 공간 투영} \longrightarrow \textbf{의미적 유사성 학습 가능!}}$$

| 인코딩 방식 | 표현 형태 | 차원 수 | 의미적 유사성 표현 | 주요 장단점 및 주의사항 |
| :--- | :--- | :---: | :---: | :--- |
| **원-핫 인코딩 (One-Hot)** | **희소 벡터 (Sparse)** | **범주 개수 $k$** | **❌ 불가 (항상 0)** | **명목형 적합 / 고카디널리티 시 차원 폭발** |
| **레이블 인코딩 (Label)** | 단일 정수 ($0, 1, 2, \dots$) | 1차원 | ❌ 불가 | **🚨 명목형 변수에 가짜 대소 순서 왜곡 위험** |
| **임베딩 (Embedding)** | **밀집 벡터 (Dense)** | 사용자 지정 ($d \ll k$) | **⭕ 가능 (코사인 유사도 활용)** | **딥러닝/NLP 핵심, 단어/범주 간 의미 관계 학습** |

### 🧠 빅분기 암기 팁
- **“원-핫은 전부 남남(직교)이다! 내적 0 $\rightarrow$ 코사인 유사도 0 $\rightarrow$ 의미적 관계 파악 불가!”**
- **“의미적 유사성을 찾는 것은 원-핫이 아니라 '임베딩(Embedding)'이다!”**
- **“레이블 인코딩은 가짜 순서 왜곡 조심, 원-핫은 차원 폭발 조심!”** 1초 컷!

## 📌 [31번] 가설검정의 오류 체계 - 제1종 오류($\alpha$)와 유의수준(Significance Level)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 추론통계 $\rightarrow$ 가설검정의 오류 체계 (제1종 오류 vs 제2종 오류)
- **핵심 의도**: 귀무가설($H_0$)이 실제로 참인데도 이를 잘못 기각하는 오류인 **제1종 오류(Type I Error)**와, 이 제1종 오류를 범할 최대 허용 확률 기준인 **유의수준(Significance Level, $\alpha$)**을 정확히 짝지을 수 있는지 평가.

### 🎯 정답
**① ㉠ 제1종 오류, ㉡ 유의수준**

### 📌 정답인 이유: [참인 귀무가설 기각 = 제1종 오류 = $\alpha$ = 유의수준]
- **제1종 오류 (Type I Error, $\alpha$)**:
  - 귀무가설($H_0$)이 **실제로 참(True)**임에도 불구하고, 표본 오차나 우연에 의해 **귀무가설을 기각하고 대립가설을 채택하는 오류** (무죄인 사람에게 유죄를 선고하는 '위양성, False Positive' 오류).
- **유의수준 (Significance Level, $\alpha$)**:
  - 연구자가 사전에 설정하는 **제1종 오류의 최대 허용 확률** (통상 $\alpha = 0.05$ 또는 $0.01$).
  - 유의수준 $\alpha = 0.05$의 의미: "귀무가설이 참인데도 이를 잘못 기각할 위험을 최대 5%까지만 감수하겠다."
- **신뢰수준 (Confidence Level)**: $1 - \alpha$ ($\alpha=0.05$일 때 신뢰수준은 95%).

### 🔎 선지 정밀 분석: [가설검정 핵심 용어 대조]
1. **① ㉠ 제1종 오류, ㉡ 유의수준**: 참인 $H_0$ 기각 $\rightarrow$ 제1종 오류, 최대 허용 확률 $\rightarrow$ 유의수준 $\alpha$ (⭕ 정답).
2. **② ㉠ 제2종 오류, ㉡ 기각역**: 거짓인 $H_0$ 미기각 오류 및 검정통계량 기각 영역으로 오답 (❌).
3. **③ ㉠ 제1종 오류, ㉡ 기각역**: ㉡은 기각역(Critical Region)이 아닌 확률 척도인 유의수준 (❌).
4. **④ ㉠ 제2종 오류, ㉡ 유의수준**: 제2종 오류의 확률은 $\beta$이며 유의수준은 $\alpha$와 연결됨 (❌).

### 📚 출제위원 시크릿 족보: [가설검정 2대 결정과 2대 오류 완벽 분할표]
$$\boxed{\textbf{제1종 오류}(\alpha) = P(H_0 \text{ 기각} \mid H_0 \text{ 참}) \quad \longleftrightarrow \quad \textbf{유의수준} = \alpha \quad \longleftrightarrow \quad \textbf{신뢰수준} = 1 - \alpha}$$
$$\boxed{\textbf{제2종 오류}(\beta) = P(H_0 \text{ 채택/미기각} \mid H_0 \text{ 거짓}) \quad \longleftrightarrow \quad \textbf{검정력(Power)} = 1 - \beta}$$

| 실제 귀무가설($H_0$) 상태 | 귀무가설($H_0$) 기각 (대립가설 채택) | 귀무가설($H_0$) 채택 (기각하지 않음) |
| :---: | :---: | :---: |
| **$H_0$ 참 (효과 없음/무죄)** | **🚨 제1종 오류 ($\alpha$, 유의수준)** <br> *(생사람 잡기 / 위양성)* | **✅ 올바른 결정 ($1 - \alpha$, 신뢰수준)** |
| **$H_0$ 거짓 (효과 있음/유죄)** | **✅ 올바른 결정 ($1 - \beta$, 검정력)** <br> *(범인 제대로 검거)* | **🚨 제2종 오류 ($\beta$)** <br> *(범인 놓침 / 위음성)* |

### 🧠 빅분기 암기 팁
- **“참·기·1·알 $\rightarrow$ 참인 $H_0$ 기각 = 제1종 오류 = $\alpha$ = 유의수준!”**
- **“거·채·2·베 $\rightarrow$ 거짓인 $H_0$ 채택/미기각 = 제2종 오류 = $\beta$!”**
- **“검정력(Power) = $1 - \beta$ (거짓인 $H_0$를 제대로 기각할 확률)!”** 1초 컷!

## 📌 [32번] 데이터 전처리 및 변환 - 데이터 변환 4대 기법(정규화/표준화/일반화/평활화)과 특성 생성

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 및 정제 $\rightarrow$ 데이터 변환(Transformation) 기법의 유형별 정의
- **핵심 의도**: **평활화(Smoothing)**가 데이터의 잡음(Noise)이나 불규칙한 변동을 줄여 매끄러운 추세를 만드는 기법임을 알고, "기존 변수를 조합해 새 변수를 만든다"는 설명이 **특성 생성(Feature Construction)**에 해당함을 구별할 수 있는지 평가.

### 🎯 정답
**③ 평활화(Smoothing) ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [평활화는 '잡음 완화', 변수 조합은 '특성 생성'!]
- **평활화 (Smoothing)**:
  - 데이터에 존재하는 **잡음(Noise)이나 급격한 불규칙 변동을 제거·완화**하여 전체적인 추세나 패턴을 매끄럽게 드러내는 기법.
  - 대표적 기법: **구간화(Binning), 이동평균(Moving Average), 지수평활법(Exponential Smoothing), 회귀 기반 평활화**.
- **특성 생성 (Feature Construction / Feature Engineering)**:
  - 기존 변수들을 사칙연산, 도메인 지식, 비선형 결합 등으로 조합하여 분석 목적에 부합하는 새로운 파생변수를 생성하는 기법 (예: $\text{BMI} = \text{체중}/\text{키}^2$, $\text{고객당 매출} = \text{매출액}/\text{고객수}$).
  - 선지 ③은 특성 생성에 대한 설명이므로 평활화의 정의로 옳지 않음.

### 🔎 선지 정밀 분석: [데이터 변환 4대 기법 대조]
1. **① 정규화 (Normalization)**: 서로 다른 범위의 데이터를 주로 $[0, 1]$ 구간 등의 일정한 스케일로 압축 변환 ($\frac{x - x_{min}}{x_{max} - x_{min}}$, ⭕ 옳은 설명).
2. **② 일반화 (Generalization)**: 세부적/구체적 데이터를 상위 수준의 개념 계층(Concept Hierarchy)으로 요약 변환 (예: 25세 $\rightarrow$ 20대, 강남구 $\rightarrow$ 서울시, ⭕ 옳은 설명).
3. **③ 평활화 (Smoothing)**: 잡음 제거가 아닌 새 변수 생성을 설명하고 있어 오답 (❌ 틀린 설명 $\rightarrow$ 정답).
4. **④ 표준화 (Standardization)**: 데이터의 평균을 0, 표준편차를 1로 변환하는 $Z$-Score 스케일링 ($Z = \frac{x - \mu}{\sigma}$, ⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [데이터 변환 5대 핵심 기법 완벽 비교표]
$$\boxed{\textbf{평활화 = 울퉁불퉁한 잡음 제거} \quad \longleftrightarrow \quad \textbf{특성 생성 = 기존 변수 조합해 새 변수 창출}}$$

| 변환 기법 | 핵심 메커니즘 | 출제 시그니처 키워드 | 대표 예시/공식 |
| :--- | :--- | :--- | :--- |
| **정규화 (Normalization)** | **데이터 범위를 $[0, 1]$로 통일** | **스케일 범위 맞추기, Min-Max** | **$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$** |
| **표준화 (Standardization)** | **평균 0, 분산 1로 통일** | **Z-score, 표준정규분포화** | **$z = \frac{x - \mu}{\sigma}$** |
| **일반화 (Generalization)** | **구체적 값 $\rightarrow$ 상위 개념화** | **개념 계층(Hierarchy), 추상화** | **구 단위 $\rightarrow$ 시 단위, 일 단위 $\rightarrow$ 연 단위** |
| **평활화 (Smoothing)** | **불규칙 변동 및 잡음(Noise) 완화** | **이동평균, 구간화(Binning), 매끄러움** | **주가 이동평균, 비닝 평균 대체** |
| **특성 생성 (Construction)** | **기존 변수 조합 $\rightarrow$ 새 변수 생성** | **파생변수, 도메인 결합, Feature Eng** | **$\text{BMI} = \text{체중}/\text{키}^2$** |

### 🧠 빅분기 암기 팁
- **“평활화(Smoothing) = 울퉁불퉁한 잡음을 평평하고 매끄럽게!”**
- **“기존 변수 조합 $\rightarrow$ 새 변수 생성은 '특성 생성(Feature Construction)'이다!”**
- **“정규화는 0~1 범위 통일, 표준화는 평균 0/분산 1 통일!”** 1초 컷!

## 📌 [33번] 추론통계 및 가설검정 - 가설검정 5단계의 논리적 수행 절차 (가·유·통·피·결)

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 추론통계 $\rightarrow$ 통계적 가설검정 5단계 절차
- **핵심 의도**: 가설검정의 엄밀한 객관성을 담보하기 위해 **유의수준($\alpha$)을 데이터를 분석하기 전에 사전에 확정**하고, 검정통계량을 계산한 뒤 p-value와 비교하여 최종 판정을 내리는 올바른 논리적 순서를 알고 있는지 평가.

### 🎯 정답
**② ㄴ $\rightarrow$ ㄹ $\rightarrow$ ㄱ $\rightarrow$ ㄷ**

### 📌 정답인 이유: [가설설정 $\rightarrow$ 유의수준 설정 $\rightarrow$ 통계량 계산 $\rightarrow$ p-value 판정]
- **가설검정의 정석 5단계 파이프라인**:
  1. **[ㄴ] 가설 설정**: 연구 가설에 따라 귀무가설($H_0$)과 대립가설($H_1$)을 명확히 정의.
  2. **[ㄹ] 유의수준($\alpha$) 설정**: 제1종 오류의 최대 허용 한계인 $\alpha$(예: 0.05)를 **데이터 관측 전에 사전 확정** (P-hacking 및 연구 편향 방지).
  3. **[ㄱ] 검정통계량 계산**: 표본 데이터로부터 $Z, t, F, \chi^2$ 등의 검정통계량 산출.
  4. **[ㄷ] p-value 계산 및 의사결정**: 계산된 검정통계량의 유의확률(p-value)을 유의수준 $\alpha$와 비교하여 $H_0$ 기각 여부 최종 판정.
- **선택 오답 분석 (④ ㄴ $\rightarrow$ ㄱ $\rightarrow$ ㄹ $\rightarrow$ ㄷ)**:
  - 검정통계량을 먼저 계산한 뒤 사후에 유의수준 $\alpha$를 정하는 것은 분석 결과를 보고 유리한 기준을 꿰맞추는 연구 부정(P-hacking)에 해당하여 통계학적 검정 절차로 절대 용인되지 않음.

### 🔎 선지 정밀 분석: [가설검정 절차 단계별 배치]
- **[ㄴ] 1단계**: 귀무가설 $H_0$ 및 대립가설 $H_1$ 수립 (가장 먼저 수행).
- **[ㄹ] 2단계**: 제1종 오류 허용 확률인 유의수준 $\alpha$ 사전 설정.
- **[ㄱ] 3단계**: 표본 데이터 기반 검정통계량($Z/t$ 값 등) 계산.
- **[ㄷ] 4단계**: p-value 도출 후 $\alpha$와 비교하여 기각/채택 판정 ($p < \alpha \rightarrow H_0$ 기각).
- $\Longrightarrow$ 정답 조합: **② ㄴ $\rightarrow$ ㄹ $\rightarrow$ ㄱ $\rightarrow$ ㄷ**

### 📚 출제위원 시크릿 족보: [가설검정 5단계 및 의사결정 규칙 총정리표]
$$\boxed{\textbf{가설설정}(\text{ㄴ}) \longrightarrow \textbf{유의수준}(\text{ㄹ}) \longrightarrow \textbf{검정통계량}(\text{ㄱ}) \longrightarrow \textbf{p-value 판정}(\text{ㄷ})}$$

| 검정 단계 | 주요 수행 내용 | 핵심 원칙 및 주의사항 |
| :---: | :--- | :--- |
| **1단계: 가설 설정** | $H_0$(차이 없음) vs $H_1$(차이 있음) 설정 | 등호($=$)는 반드시 귀무가설($H_0$)에 포함 |
| **2단계: 유의수준 설정** | **$\alpha = 0.05$ 또는 $0.01$ 사전 확정** | **🚨 반드시 표본 분석 전에 사전에 결정할 것!** |
| **3단계: 검정통계량 산출** | $Z = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}, \quad t = \frac{\bar{X}-\mu_0}{s/\sqrt{n}}$ | 표본 크기 및 모분산 인지 여부에 따라 통계량 선택 |
| **4단계: p-value / 기각역** | 검정통계량 관측 확률(p-value) 계산 | $p\text{-value} < \alpha \Longleftrightarrow \text{검정통계량이 기각역에 속함}$ |
| **5단계: 최종 결론** | **$p < \alpha \rightarrow H_0$ 기각 (대립가설 채택)** <br> $p \ge \alpha \rightarrow H_0$ 기각 실패 | "귀무가설 채택"보다 "귀무가설 기각 실패"가 정확 |

### 🧠 빅분기 암기 팁
- **“가설검정 순서 공식 = 가·유·통·피·결 (가설 $\rightarrow$ 유의수준 $\rightarrow$ 통계량 $\rightarrow$ p-value $\rightarrow$ 결론)!”**
- **“유의수준($\alpha$)은 데이터를 보기 전에 미리 정한다 (사후 조정 불가)!”**
- **“$p < \alpha$ 이면 $H_0$ 기각 (P값이 작으면 귀무가설 퇴출)!”** 1초 컷!

## 📌 [34번] 차원 축소 및 변수 선택 - Filter vs Wrapper vs Embedded 3대 기법 비교

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 다변량 분석 및 변수 선택 $\rightarrow$ 필터(Filter), 래퍼(Wrapper), 임베디드(Embedded) 3총사 비교
- **핵심 의도**: 모델 학습 전 통계량으로 거르는 **Filter**, 변수 부분집합을 바꿔가며 모델을 반복 학습시키는 **Wrapper**, 모델 학습 과정 자체에 변수 선택이 내장된 **Embedded**의 작동 시점 및 계산 비용 차이를 정확히 구별할 수 있는지 평가.

### 🎯 정답
**③ 가 (가만 옳고, 나와 다는 틀림)**

### 📌 정답인 이유: [필-전 / 래-반복 / 임-동시]
- **[가] 필터(Filter) 기법 (⭕ 참)**:
  - 모델을 학습시키지 않고, 상관계수, 카이제곱($\chi^2$), 분산, 상호정보량(Mutual Info) 등 **순수 통계적 척도로 변수를 사전에 독립적으로 선별**하므로 계산 속도가 매우 빠름.
- **[나] 래퍼(Wrapper) 기법 (❌ 거짓)**:
  - 선지에서는 "반복 평가하지 않고 계산비용이 가장 작다"고 서술했으나 정반대임.
  - 전진 선택법(Forward), 후진 제거법(Backward), 단계적 방법(Stepwise), RFE 등 **변수 조합을 바꿔가며 모델을 수없이 반복 학습/평가**하므로 과적합 위험과 계산 비용이 가장 큼.
- **[다] 임베디드(Embedded) 기법 (❌ 거짓)**:
  - 선지에서는 "학습 완료 후 별도 후처리"라고 서술했으나 거짓임.
  - 모델의 목적함수/손실함수 최적화 과정 자체에 변수 선택 알고리즘이 **내장(Embedded)되어 있어, 모델 학습과 변수 선택이 동시에 수행**됨 (예: Lasso $L_1$ 규제, 의사결정나무 불순도 기반 분기).

### 🔎 선지 정밀 분석: [3대 변수 선택 기법 진위 판정]
- **가 (⭕)**: 필터 = 통계량 기반 사전 선별, 모델 비의존, 계산 빠름.
- **나 (❌)**: 래퍼 = 모델 반복 학습 필수, 계산량 최대, 과적합 위험 $\uparrow$.
- **다 (❌)**: 임베디드 = 후처리가 아니라 모델 학습과 '동시'에 변수 선택.
- $\Longrightarrow$ 정답: **③ 가**

### 📚 출제위원 시크릿 족보: [변수 선택 3총사 완벽 비교 총정리표]
$$\boxed{\textbf{필터(Filter)} \longrightarrow \text{학습 전 통계량 선별 (서류전형)}} \quad \longleftrightarrow \quad \boxed{\textbf{래퍼(Wrapper)} \longrightarrow \text{모델 반복 학습 평가 (실기시험)}}$$
$$\boxed{\textbf{임베디드(Embedded)} \longrightarrow \text{학습 과정에서 자동 선별 (Lasso, Decision Tree)}}$$

| 비교 항목 | 필터 기법 (Filter) | 래퍼 기법 (Wrapper) | 임베디드 기법 (Embedded) |
| :--- | :--- | :--- | :--- |
| **선택 시점** | **모델 학습 전 (Pre-processing)** | **모델 반복 학습 중** | **모델 학습과 동시 (In-learning)** |
| **계산 비용** | **매우 낮음 (가장 빠름)** | **매우 높음 (가장 느림)** | 보통 (중간) |
| **모델 의존도** | 없음 (독립적) | 매우 높음 (특정 모델 종속) | 높음 (자체 내장) |
| **대표 알고리즘** | **상관계수, 카이제곱, ANOVA, 분산** | **전진선택, 후진제거, 단계선택, RFE** | **Lasso ($L_1$), Ridge ($L_2$), Tree 기여도** |
| **주요 장단점** | 대용량 고속 처리 / 모델 최적화 한계 | 최적 성능 탐색 / **과적합 및 연산폭발** | 과적합 방지 및 빠름 / 특정 모델 종속 |

### 🧠 빅분기 암기 팁

## 📌 [35번] 기술통계 및 대푯값 - 4대 평균(산술/절사/기하/조화평균)의 특성과 이상값 민감도

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 대푯값 $\rightarrow$ 4대 평균(산술평균, 절사평균, 기하평균, 조화평균)의 정의와 활용
- **핵심 의도**: 절사평균(Trimmed Mean)이 극단값을 잘라내어 **산술평균에 비해 이상값의 영향을 훨씬 덜 받는다(강건하다, Robust)**는 본질적 성질을 알고 있는지, 그리고 기하평균(성장률/복리)과 조화평균(속력/비율)의 적용 맥락을 정확히 매칭할 수 있는지 평가.

### 🎯 정답
**① 절사평균은 산술평균에 비해 이상값의 영향을 더 크게 받는다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [절사평균은 이상값을 잘라내어 영향이 훨씬 작다!]
- **절사평균 (Trimmed Mean)**:
  - 데이터의 양쪽 극단값을 일정 비율(예: 상하위 5%, 10%)씩 **제거(Trim)한 후 남아있는 데이터들의 산술평균을 계산**하는 통계량.
  - **이상값 강건성 (Robustness)**: 극단적인 이상치(Outlier)가 존재할 때 산술평균은 값이 왜곡되지만, 절사평균은 이상값을 사전에 잘라내므로 **산술평균보다 이상값의 영향을 훨씬 덜 받음**. 따라서 "더 크게 받는다"는 설명은 정반대 오류임.
- **선택 오답 분석 (② 산술평균)**:
  - 모든 관측값에 동일한 가중치($1/n$)를 부여하여 단순 합산 후 개수로 나누는 가장 표준적인 대푯값 설명으로 지극히 올바름.

### 🔎 선지 정밀 분석: [4대 평균 기법 완벽 파쇄]
1. **① 절사평균은 이상값 영향을 더 크게 받는다**: 극단값을 잘라내므로 산술평균보다 영향이 훨씬 작음 (❌ 틀린 설명 $\rightarrow$ 정답).
2. **② 산술평균은 모든 관측값에 동일 가중치를 부여하고 합을 개수로 나눈다**: $\bar{X} = \frac{\sum X_i}{n}$ (⭕ 옳은 설명).
3. **③ 기하평균은 성장률이나 수익률 등 비율의 누적 효과를 반영할 때 사용한다**: $G = \sqrt[n]{x_1 x_2 \cdots x_n}$, 곱셈적 누적 (⭕ 옳은 설명).
4. **④ 조화평균은 속도처럼 단위당 비율 데이터의 평균에 적절하다**: $H = \frac{n}{\sum 1/x_i}$, 동일거리 평균속도 계산 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [4대 평균 기법 완벽 비교 총정리표]
$$\boxed{\textbf{산술평균: } \bar{X} = \frac{\sum x_i}{n} \quad (\textbf{이상치 취약}) \quad \longleftrightarrow \quad \textbf{절사평균: } \text{상하위 } p\% \text{ 절사 후 평균} \quad (\textbf{이상치 강건})}$$
$$\boxed{\textbf{기하평균: } G = \sqrt[n]{\prod x_i} \quad (\textbf{성장률·수익률}) \quad \longleftrightarrow \quad \textbf{조화평균: } H = \frac{n}{\sum 1/x_i} \quad (\textbf{평균속도·비율})}$$

| 평균 유형 | 계산 공식 | 최적 적용 상황 | 이상값 영향도 |
| :--- | :--- | :--- | :---: |
| **산술평균 (Arithmetic)** | $\bar{X} = \frac{\sum X_i}{n}$ | 일반적인 대칭형 연속형 데이터 | **매우 큼 (민감)** |
| **절사평균 (Trimmed)** | 상하위 $p\%$ 제거 후 산술평균 | **극단값/이상치가 존재하는 데이터** | **매우 작음 (강건)** |
| **기하평균 (Geometric)** | $G = (X_1 \cdot X_2 \cdots X_n)^{1/n}$ | **성장률, 수익률, 물가상승률, 복리** | 보통 (양수 한정) |
| **조화평균 (Harmonic)** | $H = \frac{n}{\sum (1/X_i)}$ | **동일 거리 왕복 평균속력, 비율(Rate)** | 작음 (양수 한정) |

### 🧠 빅분기 암기 팁
- **“절사평균은 이상치를 잘라내어 영향이 작다(강건하다)!”**
- **“성장은 기하평균 (성장률/수익률/복리) / 속도는 조화평균 (동일거리 평균속력)!”**
- **“3대 평균 크기 관계: 산술 $\ge$ 기하 $\ge$ 조화 (단, 모든 $x_i > 0$)!”** 1초 컷!

## 📌 [36번] 차원 축소 및 다변량 분석 - 차원 축소의 4대 효과와 정보 손실(Information Loss)의 본질

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 다변량 분석 및 차원 축소 $\rightarrow$ 차원 축소의 목적, 장점 및 정보 손실 특성
- **핵심 의도**: 차원 축소가 차원의 저주 완화, 노이즈 제거를 통한 과적합 방지, 고차원 시각화 등 강력한 장점을 가지지만, 고차원 데이터를 저차원으로 압축 투영하는 과정에서 **일부 정보 손실(Information Loss)이 필연적으로 발생**함을 알고 있는지 평가.

### 🎯 정답
**④ 원본 데이터의 정보를 그대로 보존하며, 정보 손실이 전혀 발생하지 않는다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [차원 축소 = 정보 압축 $\rightarrow$ 정보 손실 필연적 발생]
- **차원 축소 (Dimensionality Reduction)**:
  - 수십~수백 개의 고차원 특성 공간에서 핵심적인 정보(분산, 의미 등)를 최대한 보존하면서 차원을 대폭 축소하는 기법.
  - **정보 손실의 필연성**: 예를 들어 100차원 데이터를 10차원 주성분으로 축소할 때, 상위 주성분이 전체 분산의 95%를 설명하더라도 **나머지 5%의 세부 정보는 필연적으로 손실/버려짐**. 따라서 "정보 손실이 전혀 발생하지 않는다"는 설명은 물리적으로 불가능한 절대적 오류임.
- **차원 축소 4대 핵심 이점**:
  1. **차원의 저주(Curse of Dimensionality) 완화**: 데이터 공간 희소성 감소 및 연산 효율성 극대화.
  2. **과적합(Overfitting) 방지**: 불필요한 고차원 잡음(Noise) 및 다중공선성 제거.
  3. **데이터 시각화 (Visualization)**: 2D/3D 공간 투영을 통한 데이터 분포 직관적 파악 (t-SNE, UMAP, PCA).
  4. **저장 공간 및 메모리 절감**.

### 🔎 선지 정밀 분석: [차원 축소 4대 선지 판독]
1. **① 차원의 저주 문제를 완화할 수 있다**: 고차원 희소성 및 계산 복잡도 해결 (⭕ 옳은 설명).
2. **② Noise를 줄여 과적합 방지에 도움이 된다**: 사소한 잡음 축 제거로 일반화 성능 향상 (⭕ 옳은 설명).
3. **③ 2차원·3차원으로 축소하여 시각화할 수 있다**: 고차원 데이터의 2D/3D 산점도 시각화 가능 (⭕ 옳은 설명).
4. **④ 정보 손실이 전혀 발생하지 않는다**: 차원 압축 시 일부 정보 손실 필연적 발생 (❌ 틀린 설명 $\rightarrow$ 정답).

### 📚 출제위원 시크릿 족보: [차원 축소 2대 접근 방식 완벽 비교표]

## 📌 [37번] 기술통계 및 산포도 - 산포도 4대 측정 지표(범위/IQR/분산/변동계수)와 단위(Unit) 체계

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 기술통계 및 데이터 탐색 $\rightarrow$ 산포도(Dispersion) 4대 측정 지표의 수식과 단위 체계
- **핵심 의도**: **사분위수 범위($IQR = Q_3 - Q_1$)**의 정의를 정확히 알고, 범위(Range, 뺄셈), 분산(단위가 제곱됨), 변동계수(CV, 무차원수로서 단위 없음)의 정의와 단위적 특성을 판별할 수 있는지 평가.

### 🎯 정답
**② 사분위수 범위(IQR)는 $Q_3 - Q_1$이다 ⭕ (올바른 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [IQR = 중앙 50%의 산포도]
- **사분위수 범위 (IQR, Interquartile Range)**:
  - $IQR = Q_3 - Q_1$ (제3사분위수 75%와 제1사분위수 25%의 차이).
  - 데이터의 **중앙 50%가 얼마나 퍼져 있는지를 측정**하는 지표로, 양쪽 극단값을 배제하므로 범위(Range)나 분산에 비해 **이상값(Outlier)에 매우 강건(Robust)**함.
- **오답 선지들의 치명적 오류 분석**:
  - **① 범위 (Range)**: 최댓값과 최솟값의 '합'이 아니라 **'차($X_{max} - X_{min}$)'**임.
  - **③ 분산 (Variance)**: 편차를 제곱하여 평균한 값이므로, 단위는 원자료와 동일하지 않고 **원자료 단위의 제곱($\text{cm}^2, \text{kg}^2$)**이 됨 (원자료와 동일한 단위는 표준편차 $SD$).
  - **④ 변동계수 (CV)**: $CV = \frac{s}{\bar{X}}$로 표준편차를 평균으로 나누어 단위가 상쇄되므로, 원자료 단위가 없는 **무차원수(Dimensionless)** 지표임.

### 🔎 선지 정밀 분석: [산포도 4대 선지 완벽 파쇄]
1. **① 범위는 최댓값과 최솟값을 더한 값이다**: 덧셈이 아니라 $Max - Min$ 뺄셈 (❌).
2. **② IQR = $Q_3 - Q_1$**: 사분위수 범위의 정확한 정의 (⭕ 정답).
3. **③ 분산은 원자료와 단위가 동일하다**: 단위가 제곱되므로 거짓 (❌ $\text{cm} \rightarrow \text{cm}^2$).
4. **④ 변동계수는 원자료와 같은 단위를 갖는다**: 분모/분자 단위 약분되어 무단위(무차원) 지표 (❌).

### 📚 출제위원 시크릿 족보: [산포도 4대 측정 지표 및 단위 체계 총정리표]
$$\boxed{\textbf{범위: } Max - Min \quad \longleftrightarrow \quad \textbf{IQR: } Q_3 - Q_1 \quad (\textbf{이상치 강건})}$$
$$\boxed{\textbf{분산: } E[(X-\mu)^2] \quad (\textbf{단위 제곱}) \quad \longleftrightarrow \quad \textbf{변동계수(CV): } \frac{s}{\bar{X}} \quad (\textbf{단위 없음, 상대적 산포})}$$

| 산포도 지표 | 계산 공식 | 측정 의미 | 단위(Unit) | 이상값 민감도 |
| :--- | :--- | :--- | :---: | :---: |
| **범위 (Range)** | $X_{max} - X_{min}$ | 전체 데이터의 최대 너비 | **원자료와 동일** | **매우 취약 (극단치 2개로 결정)** |
| **사분위수 범위 (IQR)** | **$Q_3 - Q_1$** | **가운데 50% 데이터의 산포** | **원자료와 동일** | **매우 강건 (이상치 무관)** |
| **분산 (Variance)** | $\frac{\sum (X_i - \bar{X})^2}{n-1}$ | 편차 제곱의 평균 | **🚨 원자료 단위의 제곱 ($\text{cm}^2$)** | 취약 (편차 제곱 강조) |
| **표준편차 (Std Dev)** | $\sqrt{Variance}$ | 평균 기준 흩어진 정도 | **원자료와 동일 ($\text{cm}$)** | 취약 |
| **변동계수 (CV)** | **$\frac{s}{\bar{X}} \times 100\%$** | **평균 대비 상대적 변동성** | **🚨 단위 없음 (무차원수)** | - |

### 🧠 빅분기 암기 팁
- **“범최빼 (범위 = 최대 - 최소) / 사삼빼일 (IQR = $Q_3 - Q_1$)!”**
- **“분산은 단위 제곱($\text{cm}^2$), 표준편차는 원래 단위($\text{cm}$), 변동계수는 단위 없음(무차원)!”**
- **“평균이나 단위가 다른 두 집단의 산포 비교 $\rightarrow$ 1초 만에 변동계수(CV)!”** 1초 컷!

## 📌 [38번] 데이터 전처리 및 결측치 - 결측값 처리 3대 기법(완전사례/평균대치/다중대치)과 결측 메커니즘

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 데이터 전처리 및 정제 $\rightarrow$ 결측값(Missing Value) 처리 기법 및 결측 메커니즘
- **핵심 의도**: **완전 사례 분석(Complete Case Analysis / Listwise Deletion)**이 결측치가 하나라도 포함된 행(Row)을 전체 삭제하므로 실제 분석에 사용되는 데이터 표본 수가 **대폭 감소**한다는 기본 원리와, 평균 대치의 **분산 과소추정**, 다중 대치의 **불확실성 반영** 원리를 정확히 알고 있는지 평가.

### 🎯 정답
**① 완전 사례 분석은 결측값이 하나라도 있는 관측치를 모두 제외하므로, 분석에 사용되는 데이터의 양이 원자료보다 늘어난다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [완전 사례 분석은 결측 행 삭제 $\rightarrow$ 데이터 수 감소!]
- **완전 사례 분석 (Complete Case Analysis / Listwise Deletion)**:
  - 다변량 데이터셋에서 단 하나의 변수라도 결측치(NaN)를 가진 관측 대상(행)을 모조리 제거하고, **모든 변수가 온전히 관측된 완전한 행만 남겨서 분석**하는 방법.
  - 따라서 분석에 투입되는 표본 크기 $n$은 원자료보다 **필연적으로 감소**함 ($n \downarrow$). "데이터 양이 늘어난다"는 설명은 물리적으로 불가능한 명백한 거짓임.
- **주요 결측치 대치 기법의 핵심 특성**:
  - **평균 대치법 (Mean Imputation)**: 결측치를 해당 변수의 평균값으로 대체하므로 구현이 간단하지만, 결측값들이 모조리 평균점 주변으로 밀집되어 **데이터의 퍼짐(분산, Variance)을 실제보다 작게 과소추정(Underestimation)**하는 심각한 한계가 존재함.
  - **다중 대치법 (Multiple Imputation / MICE)**: 결측값에 대해 확률적 난수/회귀모형을 적용하여 **$M$개의 서로 다른 대치 데이터셋을 생성 $\rightarrow$ 각각 분석 $\rightarrow$ 결과를 통합(Pooling)**함으로써 결측에 따른 통계적 불확실성을 완벽히 반영함.

### 🔎 선지 정밀 분석: [결측값 처리 4대 선지 판독]
1. **① 완전 사례 분석 $\rightarrow$ 데이터 양 증가**: 결측 행 삭제로 표본수 대폭 감소 (❌ 틀린 설명 $\rightarrow$ 정답).
2. **② 완전 사례 분석은 구현이 간단하지만 표본 감소 및 편향 발생 가능**: 삭제로 인한 검정력 저하 및 편향 유발 가능 (⭕ 옳은 설명).
3. **③ 평균 대치법은 분산을 과소추정할 수 있다**: 평균 쏠림 현상으로 분산 축소 왜곡 (⭕ 옳은 설명).
4. **④ 다중 대치법은 여러 데이터셋을 생성·분석 후 통합하여 불확실성을 반영한다**: MICE의 3단계 표준 정의 (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [결측 메커니즘 3대 유형 및 처리 기법 비교표]
$$\boxed{\textbf{완전사례: } \text{결측 행 삭제 } (n \downarrow) \quad \longleftrightarrow \quad \textbf{평균대치: } \text{분산 과소추정} \quad \longleftrightarrow \quad \textbf{다중대치: } \text{불확실성 반영}}$$

| 결측 메커니즘 유형 | 발생 원인 및 정의 | 예시 | 최적 처리 전략 |
| :--- | :--- | :--- | :--- |
| **MCAR (완전 무작위 결측)** | 결측 발생이 **어떤 변수(관측/미관측)와도 무관** | 설문지 우연한 잉크 번짐, 통신 일시 오류 | 완전사례분석, 단순대치 무방 |
| **MAR (조건부 무작위 결측)** | 결측 발생이 **관측된 다른 변수와 통계적 관련** | 여성이 남성보다 체중 응답 누락률 높음 | **회귀 대치, 다중 대치(MICE), KNN** |
| **MNAR (비무작위 결측)** | 결측 발생이 **결측값 자체의 성질과 직접 관련** | **소득이 극단적으로 높은 사람이 소득 누락** | **패턴 모델링, 결측 여부 변수화** |

### 🧠 빅분기 암기 팁
- **“완전 사례 분석은 결측 행을 버리므로 표본수 감소!”**
- **“평균 대치법의 최대 함정 $\rightarrow$ 1초 만에 '분산 과소추정(Underestimate)'!”**
- **“다중 대치법 = 대치 $\rightarrow$ 분석 $\rightarrow$ 결합(Pooling) 3단계로 불확실성 반영!”**
- **“결측 메커니즘 3총사: MCAR(완전무관) $\rightarrow$ MAR(다른변수 관련) $\rightarrow$ MNAR(결측값 자체 관련)!”** 1초 컷!

## 📌 [39번] 차원 축소 및 다변량 분석 - 주성분 분석(PCA)의 전체 분산 vs 요인 분석(FA)의 공통 분산

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 다변량 분석 및 차원 축소 $\rightarrow$ 주성분 분석(PCA)의 분산 설명 특성 vs 요인 분석(FA)
- **핵심 의도**: **PCA(주성분 분석)**가 데이터의 **전체 분산(Total Variance)**을 최대한 보존하도록 주성분을 추출하는 기법이며, "고유분산을 제외하고 공통분산(Common Variance)만을 이용한다"는 설명은 **요인 분석(Factor Analysis)**의 특징임을 구별할 수 있는지 평가.

### 🎯 정답
**③ 변수 고유의 분산은 제외하고 변수들이 공유하는 공통분산만을 이용하여 주성분을 추출한다 ❌ (틀린 설명 $\rightarrow$ 정답)**

### 📌 정답인 이유: [PCA는 '전체 분산', 요인분석은 '공통 분산'!]
- **주성분 분석 (PCA, Principal Component Analysis)**:
  - 원래 변수들의 선형결합($PC_i = a_{i1}X_1 + \cdots + a_{ip}X_p$)을 통해 데이터가 지닌 **전체 분산(Total Variance)을 가장 많이 설명하는 새로운 직교 축(Orthogonal Axes)**을 순차적으로 추출하는 비지도 차원 축소 기법.
  - 고유분산과 공통분산을 인위적으로 분리하지 않고 **전체 분산의 최대화**를 추구함.
- **요인 분석 (Factor Analysis, FA)**:
  - 변수의 총 분산을 **공통분산(Common Variance)과 고유분산(Specific Variance)**으로 엄밀히 분리한 뒤, 오직 **변수들 간의 상관관계를 설명하는 공통분산(잠재요인)만을 추출**함. 따라서 ③은 PCA가 아닌 FA에 대한 설명임.
- **선택 오답 분석 (④ 주성분 간 직교 및 무상관)**:
  - PCA는 첫 번째 주성분($PC_1$)을 분산 최대 방향으로 잡고, 두 번째 주성분($PC_2$)은 $PC_1$과 **수학적으로 직교($PC_1 \perp PC_2$)하면서 남은 분산을 최대로 설명하는 방향**으로 추출하므로, 주성분 간 상관계수는 정확히 0(비상관, Uncorrelated)이 됨 (지극히 올바른 설명).

### 🔎 선지 정밀 분석: [PCA 4대 선지 완벽 판독]
1. **① 주성분은 설명하는 분산의 크기($\lambda_i$)가 큰 순서대로 정렬된다**: $PC_1 \ge PC_2 \ge PC_3 \cdots$ 순 추출 (⭕ 옳은 설명).
2. **② 주성분은 원래 변수들의 선형결합으로 생성된다**: $PC = a_1X_1 + a_2X_2 + \dots$ 특성 추출 (⭕ 옳은 설명).
3. **③ 고유분산을 제외하고 공통분산만 이용한다**: PCA는 전체 분산 이용, 공통분산만 보는 것은 요인분석 (❌ 틀린 설명 $\rightarrow$ 정답).
4. **④ 서로 다른 주성분은 직교하며 상관계수가 0이다**: $Corr(PC_i, PC_j) = 0$ (⭕ 옳은 설명).

### 📚 출제위원 시크릿 족보: [PCA vs 요인분석(FA) vs 독립성분분석(ICA) 3총사 비교표]
$$\boxed{\textbf{PCA: 전체 분산} \text{ 최대화 + 비상관 직교} \quad \longleftrightarrow \quad \textbf{FA: 공통 분산} \text{ 중심 + 잠재 요인 탐색}}$$

| 비교 항목 | 주성분 분석 (PCA) | 요인 분석 (Factor Analysis) | 독립 성분 분석 (ICA) |
| :--- | :--- | :--- | :--- |
| **목적** | **전체 정보(분산) 압축 및 차원 축소** | **변수 간 상관관계 이면의 잠재 요인 규명** | **혼합 신호에서 독립된 원천 신호 분리** |
| **활용 분산** | **전체 분산 (Total Variance)** | **공통 분산 (Common Variance)** | - |
| **성분 간 관계** | **상호 직교 (Orthogonal, 비상관)** | 직교 또는 사각 회전 (상관 허용 가능) | **통계적 독립 (Independent)** |
| **변수 생성** | 원래 변수들의 **선형결합 ($PC = \sum a_i X_i$)** | 잠재요인들의 **선형결합 ($X_i = \sum l_{ij} F_j + e_i$)** | 비가우스성 극대화 분리 |

### 🧠 빅분기 암기 팁
- **“PCA는 전체 분산 압축 / 요인분석(FA)은 공통 분산 잠재요인!”**
- **“PCA 4대 법칙: 선형결합, 분산 크기순 정렬, 상호 직교, 상관계수 0!”**
- **“PCA는 비상관, ICA는 통계적 독립, FA는 잠재 요인!”** 1초 컷!

## 📌 [40번] 차원 축소 및 다변량 분석 - 주성분 분석(PCA)의 제1주성분($PC_1$) 축 방향과 단위벡터 정규화

### ✅ 문제 분석
- **출제 파트**: 제2과목 빅데이터 탐색 $\rightarrow$ 다변량 분석 및 차원 축소 $\rightarrow$ 주성분 분석(PCA)의 제1주성분 축 방향 및 고유벡터 단위벡터화
- **핵심 의도**: 모분산이 동일한 두 변수 $A, B$ ($Var(A)=Var(B)=1$)의 상관계수가 음수($Corr(A, B) = -0.1$)일 때, **분산이 최대가 되는 제1주성분($PC_1$)의 선형결합 방향($A-B$)**과 **계수 벡터의 크기가 1인 단위벡터(Unit Vector)** 조건을 결합하여 정확한 $PC_1$ 수식을 도출할 수 있는지 평가.

### 🎯 정답
**④ $\frac{1}{\sqrt{2}}A - \frac{1}{\sqrt{2}}B$**

### 📌 정답인 이유: [음의 상관계수 $\rightarrow A-B$ 방향 분산 최대 + 단위벡터 정규화]
1. **1단계: 방향별 선형결합 분산 비교**
   - $Var(aA + bB) = a^2 Var(A) + b^2 Var(B) + 2ab Cov(A, B) = a^2 + b^2 + 2ab(-0.1)$
   - **$A + B$ 방향 ($a=\frac{1}{\sqrt{2}}, b=\frac{1}{\sqrt{2}}$)**:
     $$Var\left(\frac{A+B}{\sqrt{2}}\right) = \frac{1}{2}(1) + \frac{1}{2}(1) + 2\left(\frac{1}{2}\right)(-0.1) = 1 - 0.1 = \mathbf{0.9} \quad (\lambda_2, PC_2)$$
   - **$A - B$ 방향 ($a=\frac{1}{\sqrt{2}}, b=-\frac{1}{\sqrt{2}}$)**:
     $$Var\left(\frac{A-B}{\sqrt{2}}\right) = \frac{1}{2}(1) + \frac{1}{2}(1) + 2\left(-\frac{1}{2}\right)(-0.1) = 1 + 0.1 = \mathbf{1.1} \quad (\lambda_1, PC_1)$$
   - $\Longrightarrow$ 분산이 가장 큰 제1주성분($PC_1$)은 분산이 $1.1$인 **$A - B$ 방향**임.
2. **2단계: 고유벡터(계수 벡터)의 단위벡터 정규화 ($\|v\|=1$)**
   - 선지 ③ ($\frac{1}{2}A - \frac{1}{2}B$): 계수 크기가 $\sqrt{(\frac{1}{2})^2 + (-\frac{1}{2})^2} = \sqrt{\frac{1}{2}} = \frac{1}{\sqrt{2}} \ne 1$ (단위벡터 아님, ❌).
   - 선지 ④ ($\frac{1}{\sqrt{2}}A - \frac{1}{\sqrt{2}}B$): 계수 크기가 $\sqrt{(\frac{1}{\sqrt{2}})^2 + (-\frac{1}{\sqrt{2}})^2} = \sqrt{\frac{1}{2} + \frac{1}{2}} = \mathbf{1}$ (정규화된 단위 고유벡터, ⭕ 정답).

### 🔎 선지 정밀 분석: [PCA 제1주성분 선지 판별]
1. **① $\frac{1}{\sqrt{2}}A + \frac{1}{\sqrt{2}}B$**: $A+B$ 방향으로 분산이 $0.9$에 불과하여 제2주성분($PC_2$)에 해당 (❌).
2. **② $\frac{1}{2}A + \frac{1}{2}B$**: 방향도 틀리고 단위벡터도 아님 (❌).
3. **③ $\frac{1}{2}A - \frac{1}{2}B$**: $A-B$ 방향은 맞으나 계수 벡터의 노름이 1이 아님 (❌).
4. **④ $\frac{1}{\sqrt{2}}A - \frac{1}{\sqrt{2}}B$**: 분산 최대(1.1) 방향이며 단위벡터 조건 만족 (⭕ 정답).

### 📚 출제위원 시크릿 족보: [동일 분산 2변수 PCA 3초 컷 공식 총정리]
$$\boxed{\textbf{양의 상관}(r > 0) \Longrightarrow PC_1 = \frac{A + B}{\sqrt{2}}, \quad PC_2 = \frac{A - B}{\sqrt{2}}}$$
$$\boxed{\textbf{음의 상관}(r < 0) \Longrightarrow PC_1 = \frac{A - B}{\sqrt{2}}, \quad PC_2 = \frac{A + B}{\sqrt{2}}}$$

| 상관계수 부호 | 제1주성분 ($PC_1$, 고유값 $\lambda_1$) | 제2주성분 ($PC_2$, 고유값 $\lambda_2$) | 3초 컷 핵심 직관 |
| :---: | :---: | :---: | :--- |
| **양의 상관 ($r > 0$)** | **$PC_1 = \frac{A + B}{\sqrt{2}} \quad (\lambda_1 = 1 + r)$** | $PC_2 = \frac{A - B}{\sqrt{2}} \quad (\lambda_2 = 1 - r)$ | 함께 증가하므로 **더한 축($+$)**이 변동성 최대 |
| **음의 상관 ($r < 0$)** | **$PC_1 = \frac{A - B}{\sqrt{2}} \quad (\lambda_1 = 1 + \|r\|)$** | $PC_2 = \frac{A + B}{\sqrt{2}} \quad (\lambda_2 = 1 - \|r\|)$ | 반대로 움직이므로 **뺀 축($-$)**이 변동성 최대 |

### 🧠 빅분기 암기 팁
- **“같은 분산일 때 PCA 3초 컷: 플러스 상관은 더하고($A+B$), 마이너스 상관은 뺀다($A-B$)!”**
- **“고유벡터 계수는 무조건 제곱합이 1인 단위벡터($\frac{1}{\sqrt{2}}$)여야 한다!”** 1초 컷!

# 🏆 제2과목 빅데이터 탐색 (21번~40번) 1타 강사 족보 맵

| 문항 | 출제 핵심 주제 | 1타 강사 3초 컷 핵심 공식 |
| :---: | :--- | :--- |
| **21번** | 중심적률 4대 차수 | **“1차=0, 2차=분산(2분), 3차=왜도(3왜, 부호/방향), 4차=첨도(4첨, 극단값)!”** |
| **22번** | 확률표본추출 기법 | **“단순=끝까지 랜덤 / 계통=처음만 랜덤+$k$간격 / 층화=모든 층에서 / 군집=일부 군집만!”** |
| **23번** | 이상값 발생 원인 | **“측·관·보는 값을 망쳐서 이상치 유발 / 표본오차는 대표성의 문제!”** |
| **24번** | 독립확률변수 합의 분산 | **“표준편차끼리 더하지 말고, 분산부터 더하고 마지막에 루트($\sqrt{2}\sigma$)!”** |
| **25번** | 이산확률변수 분산 | **“분산 = 제평 - 평제 ($E[X^2] - \{E[X]\}^2$) / 주사위 분산 = $\frac{n^2-1}{12} = \frac{35}{12}$!”** |
| **26번** | 피어슨 상관계수 특성 | **“피어슨=직선(선형)만 본다(비선형 곡선 불가) / $r=0$은 선형관계 없음!”** |
| **27번** | 중심극한정리 vs 대수법칙 | **“표본평균 '값'이 모평균 가면 대수(LLN) / 표본평균 '분포'가 정규분포 가면 중심극한(CLT)!”** |
| **28번** | 상자그림(Box Plot) 판독 | **“박스 안 선=중앙값, 박스 높이=IQR, 수염 밖 점=이상값($Q_1-1.5IQR, Q_3+1.5IQR$)!”** |
| **29번** | 차원 축소 5대 기법 | **“SVD=직사각형 행렬도 OK / 고유값분해=정방행렬만 / PCA=비지도 / LDA=지도!”** |
| **30번** | 범주형 원-핫 인코딩 | **“원-핫은 전부 남남(직교, 내적 0, 코사인 유사도 0) $\rightarrow$ 의미적 유사성 파악 불가!”** |
| **31번** | 가설검정 오류와 유의수준 | **“참·기·1·알 (참인 $H_0$ 기각=1종=알파=유의수준) / 거·채·2·베 (거짓인 $H_0$ 채택=2종=베타)!”** |
| **32번** | 데이터 변환 기법 | **“평활화=잡음 완화(이동평균/비닝) / 특성생성=기존 변수 조합해 새 변수 창출!”** |
| **33번** | 가설검정 5단계 절차 | **“가·유·통·피·결 (가설설정 $\rightarrow$ 유의수준 사전설정 $\rightarrow$ 통계량 $\rightarrow$ p-value $\rightarrow$ 결론)!”** |
| **34번** | 변수 선택 3총사 | **“필·전 (필터=학습 전 서류전형) / 래·반 (래퍼=반복학습 실기시험, 계산량 최대) / 임·동 (임베디드)!”** |
| **35번** | 대푯값 4대 평균 | **“절사평균=이상치 잘라내어 강건 / 성장은 기하평균 / 속도는 조화평균!”** |
| **36번** | 차원 축소와 정보 손실 | **“차원을 버리면 정보도 일부 버려진다 (정보 손실 0%는 절대 불가능)!”** |
| **37번** | 산포도 4대 지표와 단위 | **“범위=최대-최소 / IQR=$Q_3-Q_1$ / 분산=단위제곱($\text{cm}^2$) / 변동계수=단위 없음!”** |
| **38번** | 결측값 처리와 메커니즘 | **“완전사례=표본 감소 / 평균대치=분산 과소추정 / MCAR(완전무관)-MAR(다른변수)-MNAR(자체)!”** |
| **39번** | PCA vs 요인분석(FA) | **“PCA=전체 분산 최대화(비상관 직교) / 요인분석(FA)=공통 분산(잠재 요인)!”** |
| **40번** | PCA 제1주성분 결정 | **“동일 분산 PCA: 플러스 상관 $\rightarrow A+B$ / 마이너스 상관 $\rightarrow A-B$ / 단위벡터 $\frac{1}{\sqrt{2}}$!”** |
