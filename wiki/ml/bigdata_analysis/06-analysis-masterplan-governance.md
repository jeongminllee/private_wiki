# Summary
분석 마스터플랜(Analysis Master Plan)은 발굴된 다수의 분석 과제를 기업의 중장기 전략과 연계하여 우선순위를 평가하고, 단계적 실행 로드맵을 수립하는 종합 계획이다. 이를 안정적으로 뒷받침하기 위해 조직, 프로세스, 인프라, 데이터 품질을 관리하는 **데이터 거버넌스(Data Governance)** 체계가 필수적이다.

---

# Key Ideas

## 1. 분석 과제 우선순위 평가 사분면 (Priority Matrix)

```
        [ 난이도 (Difficulty) ]
        쉬움 (Easy)         어려움 (Hard)
     ┌──────────────────┬──────────────────┐
  높 │    제 1 사분면   │    제 2 사분면   │
  음 │  (최우선 추진)   │  (중장기 전략적) │
시   ├──────────────────┼──────────────────┤
급   │    제 3 사분면   │    제 4 사분면   │
성   │   (단기 개선)    │   (후순위 검토)  │
  낮 └──────────────────┴──────────────────┘
```
- **시급성 기준 (전략적 가치, 비즈니스 영향도)**: 현재 시점에서 얼마나 긴급하고 비즈니스 ROI가 높은가.
- **난이도 기준 (데이터 확보 용이성, 기술적 복잡도)**: 과제 수행에 필요한 비용과 기술 장벽.

## 2. 분석 준비도(Readiness) & 성숙도(Maturity) 진단 4분면
- **준비형 (Ready)**: 준비도는 높으나 성숙도가 낮음 (사전 인프라는 갖추었으나 실제 활용 역량 부족).
- **정착형 (Settled)**: 준비도는 낮으나 성숙도가 높음 (제한된 인프라에서 분석을 효율적으로 적용 중).
- **도입형 (Introductory)**: 준비도와 성숙도가 모두 낮음 (분석 역량 태동 단계).
- **확산형 (Spreading)**: 준비도와 성숙도가 모두 높음 (전사적 데이터 기반 의사결정 체계 완성).
