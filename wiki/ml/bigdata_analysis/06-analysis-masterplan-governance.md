# Summary
분석 마스터플랜(Analysis Master Plan)은 발굴된 다수의 분석 과제를 기업의 중장기 전략과 연계하여 우선순위를 평가하고, 단계적 실행 로드맵을 수립하는 종합 계획이다. 이를 안정적으로 뒷받침하기 위해 조직, 프로세스, 인프라, 데이터 품질을 관리하는 **데이터 거버넌스(Data Governance)** 체계가 필수적이다.

---

# Key Ideas

## 1. 분석 과제 우선순위 평가 사분면 (Priority Matrix)

```
        [ 난이도 (Difficulty) ]
        쉬움 (Easy)         어려움 (Hard)
     ┌──────────────────┬──────────────────┐
  높 │    제 1 사분면   │    제 2 사분면   │
  음 │  (최우선 추진)   │  (중장기 전략적) │
시   ├──────────────────┼──────────────────┤
급   │    제 3 사분면   │    제 4 사분면   │
성   │   (단기 개선)    │   (후순위 검토)  │
  낮 └──────────────────┴──────────────────┘
```
- **시급성 기준 (전략적 가치, 비즈니스 영향도)**: 현재 시점에서 얼마나 긴급하고 비즈니스 ROI가 높은가.
- **난이도 기준 (데이터 확보 용이성, 기술적 복잡도)**: 과제 수행에 필요한 비용과 기술 장벽.

## 2. 분석 준비도(Readiness)와 분석 성숙도(Maturity) 모델

### (1) 분석 준비도 (Readiness) 6대 진단 영역
기업의 분석 수준을 사전에 파악하기 위한 6가지 축:
1. **분석 업무 파악**: 발생 가능한 미래 이슈 사전 감지, 분석 활용 수준, 시뮬레이션 활용
2. **분석 인력 및 조직**: 분석 전문가 확보, 조직 편성, 교육 프로그램
3. **분석 기법**: 업무별 적합한 분석 기법 적용, 최신 분석 기법 도입
4. **분석 데이터**: 데이터 정합성/품질 관리, 비정형 데이터 관리, 외부 데이터 연계
5. **분석 문화**: 데이터 기반의 합리적 의사결정 문화, 경영진의 직관 배제 및 분석 존중
6. **IT 인프라**: 분석 환경 및 전용 도구 구비, 확장성(빅데이터 플랫폼), 시스템 연계

### (2) 분석 성숙도 (Maturity) 평가 체계 (CMMI 기반)
- **3대 평가 부문**:
  1. **비즈니스 부문 (Business)**: 분석의 비즈니스 가치 창출 및 적용 범위
  2. **조직·역량 부문 (Organization/Competency)**: 분석 전문가 및 조직의 역량 수준
  3. **IT 부문 / IT 자원 (IT/Technology)**: 분석 인프라와 지원 시스템 환경
  *(※ '법·제도' 등은 평가 부문에 포함되지 않음)*
- **성숙도 발전 4단계**:
  1. **도입 (Introduction)**: 일부 부서 중심 분석 시작, 과거 실적 조회 수준
  2. **활용 (Growth)**: 전문 부서 도입, 미래 예측 및 시뮬레이션 활용
  3. **확산 (Expansion)**: 전사적 분석 문화 형성, 빅데이터 플랫폼 구축 및 공유
  4. **최적화 (Optimization)**: 실시간 자동화 분석, 비즈니스 모델 혁신 및 외부 생태계 연계

### (3) 준비도 & 성숙도 진단 4분면
```
        [ 분석 성숙도 (Maturity) ]
          낮음                높음
     ┌──────────────────┬──────────────────┐
  높 │    준비형        │      확산형      │
  음 │ (인프라 갖춤,    │ (전사 의사결정   │
준   │  활용 미흡)      │  체계 완성)      │
비   ├──────────────────┼──────────────────┤
도   │    도입형        │      정착형      │
  낮 │ (역량·인프라    │ (제한적 인프라,  │
  음 │  모두 부족)      │  실무 적용 우수) │
     └──────────────────┴──────────────────┘
```
- **준비형 (Ready)**: 준비도 높음, 성숙도 낮음
- **정착형 (Settled)**: 준비도 낮음, 성숙도 높음
- **도입형 (Introductory)**: 준비도 낮음, 성숙도 낮음
- **확산형 (Spreading)**: 준비도 높음, 성숙도 높음

## 3. 데이터 거버넌스 (Data Governance)

### (1) 데이터 거버넌스의 개념
- **정의**: 전사 차원의 모든 데이터에 대해 정책 및 지침, 표준화 운영 조직 및 책임 등의 표준화된 관리 체계를 수립하고 운영하기 위한 총체적 프레임워크.
- **목적**: 데이터의 가용성, 유용성, 통합성, 보안성 및 품질을 확보하여 데이터 분석을 기업 문화로 정착시키고 비즈니스 의사결정의 신뢰도를 극대화.

### (2) 데이터 거버넌스 3대 구성 요소
1. **원칙 (Principles)**: 데이터를 유지 관리하기 위한 가이드라인, 규정 및 보안/품질 지침.
2. **조직 (Organization)**: 데이터 관리자(Data Steward), 데이터 소유권자, 분석가 등의 역할과 책임(R&R) 정의.
3. **프로세스 (Process)**: 데이터의 생성, 수집, 정제, 저장, 모니터링, 폐기까지의 표준 작업 절차.

### (3) 핵심 관리 대상 체계
- **마스터 데이터 관리 (MDM)**: 고객, 상품, 거래처 등 전사 공유 기준 정보 통합 관리.
- **메타데이터 (Metadata)**: 데이터 사전(Data Dictionary), 명명 규칙, 비즈니스/기술 메타정보 관리.
- **데이터 품질 관리 (Data Quality)**: 정합성, 유효성, 완전성 검증 및 오류 데이터 정제.
- **데이터 생명주기 관리 (Data Lifecycle)**: 데이터 저장 주기, 아카이빙 및 법적 규정 준수 폐기.
