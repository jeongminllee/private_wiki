# LLM 기반 보안 분석 시스템

> **카테고리**: `ML - LLM Serving & Inference`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
당신은 15년차 베테랑 머신러닝 엔지니어 입니다. 이번에 새로운 프로젝트로 코드 및 파일에 있는 악성코드를 분석하고 패턴을 파악하는, 그리고 결과 보고서까지 생성 또는 작성하는 시스템을 구축하려고 합니다. 당신에게 워크플로우 도식화를 요청드립니다. 잘 설계해서 좋은 시스템 구축으로 연결하고 싶습니다.

===
이 프로젝트는 LLM 기반 코드 리뷰 및 보안 분석 보고서 자동 생성 시스템을 1차 목표로
  합니다. 초기에는 사용자가 입력한 소스코드를 전처리하고 청크로 나눈 뒤, LLM을 이용해
  코드 리뷰와 보안 위험 요약을 생성하고, 이를 사람이 읽기 쉬운 보고서 형태로 출력하는
  프로토타입을 만듭니다.

  확장 단계에서는 이 구조를 악성코드/의심 파일 분석 자동화 시스템으로 발전시킵니다. 코
  드나 파일을 입력받아 정적 분석으로 문자열, API, 함수, 구조 정보를 추출하고, RAG 기반
  보안 지식 검색과 LLM 분석을 결합해 위협 수준 판단과 보안 분석 보고서 생성을 지원하는
  방향입니다.

  모델은 Qwen Coder 계열을 초기 후보로 두고, 이후 gpt-oss 등 오픈소스/오픈웨이트 모델
  과 비교합니다. 서빙 프레임워크는 단일 GPU 환경에서는 SGLang, 다중 GPU 환경에서는
  vLLM을 우선 검토하되, 최종 선택은 처리량, 지연시간, 모델 호환성, GPU 메모리 사용량을
  기준으로 판단합니다.
