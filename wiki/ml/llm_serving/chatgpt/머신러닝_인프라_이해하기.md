### ❓ 질문 (User)
머신러닝 모델 훈련과 서빙에 필요한 인프라에 대한 높은 이해도가 있으신 분
이 역량에 대해서 공부하고 싶어

### 💡 답변 (Assistant)
머신러닝 모델 훈련과 서빙에 필요한 인프라에 대해 공부하려면 다음 주제들을 체계적으로 이해하는 것이 좋습니다:

### 1. **모델 훈련 인프라**
- **컴퓨팅 자원**: 모델 훈련에는 많은 연산이 필요하므로, CPU보다 GPU, TPU와 같은 병렬 연산이 가능한 자원을 주로 사용합니다. 클라우드 서비스(AWS, GCP, Azure)에서 GPU나 TPU를 쉽게 사용할 수 있습니다.
  - **분산 훈련**: 대규모 데이터셋과 복잡한 모델을 훈련할 때는 여러 기기에서 모델을 훈련하는 분산 학습이 필요합니다. PyTorch, TensorFlow 등의 프레임워크는 분산 학습을 지원합니다.
- **데이터 파이프라인**: 데이터 전처리, 배치 로드, 샘플링 등 훈련에 필요한 데이터 파이프라인을 구축하는 것이 중요합니다. 이 과정에서 빠른 데이터 로드를 위해 캐싱, 샤딩 등을 사용합니다.
- **모델 관리 및 버전 관리**: 모델의 다양한 버전을 저장하고 관리하기 위해 MLflow, DVC(Data Version Control) 등의 도구를 사용할 수 있습니다.

### 2. **모델 서빙 인프라**
- **서빙 도구**: 훈련된 모델을 배포하고 실시간으로 예측을 제공하기 위한 도구가 필요합니다. TensorFlow Serving, TorchServe, Seldon Core 같은 도구를 통해 모델을 서빙할 수 있습니다.
- **컨테이너화**: Docker와 같은 컨테이너 기술을 사용해 모델을 서빙하는 환경을 패키징하고 쉽게 배포할 수 있습니다. 이를 통해 재현 가능한 환경을 구축할 수 있습니다.
- **Kubernetes**: 컨테이너 오케스트레이션을 통해 모델 서빙을 자동화하고 확장할 수 있습니다. 클러스터에서 다양한 노드를 관리하고 부하를 분산하여 모델을 안정적으로 서빙합니다.
  
### 3. **모니터링 및 유지보수**
- **모니터링**: 서빙된 모델의 성능을 지속적으로 모니터링하기 위해 Prometheus, Grafana 같은 도구를 사용할 수 있습니다. 실시간으로 서비스의 응답 속도, 정확도 등을 측정하고 이상 징후를 탐지합니다.
- **A/B 테스트**: 모델 업데이트 시 다양한 모델을 배포하고 실시간으로 비교해 어떤 모델이 더 나은 성능을 보이는지 테스트합니다.

### 4. **MLOps 도구**
- **CI/CD 파이프라인**: 모델을 지속적으로 개발, 배포, 운영하기 위한 자동화된 파이프라인을 구축합니다. GitLab CI/CD, Jenkins 등을 활용할 수 있습니다.
- **Feature Store**: 훈련 및 예측에 필요한 피처를 관리하는 플랫폼으로, 재사용성을 높여줍니다. Tecton, Feast 등이 대표적입니다.

이런 인프라 구성 요소들을 하나씩 학습하고 실습하면서 경험을 쌓는 것이 좋습니다.

### 서적
1. **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" (Aurélien Géron)**
   - 이 책은 머신러닝의 기본적인 개념부터 실전적인 프로젝트를 다룹니다. 특히 모델 훈련과 배포 과정에서 사용할 수 있는 다양한 라이브러리와 툴을 소개합니다.
   - **대상**: 머신러닝의 기본부터 실습까지 체계적으로 배우고 싶은 분들

2. **"Machine Learning Engineering" (Andriy Burkov)**
   - 이 책은 모델 훈련과 서빙에 대한 인프라를 집중적으로 다룹니다. 모델 개발부터 배포, 모니터링, 유지보수까지 전체적인 워크플로우를 설명합니다.
   - **대상**: MLOps에 대해 심도 있게 이해하고 싶은 사람들

3. **"Building Machine Learning Powered Applications" (Emmanuel Ameisen)**
   - 머신러닝 모델을 실서비스에 배포하기 위한 모든 과정을 다루는 실용적인 책입니다. 실제 애플리케이션에서 머신러닝을 어떻게 통합하고 운영할지에 대한 내용을 포함합니다.
   - **대상**: 모델 서빙과 배포 과정에 집중하고 싶은 분들

4. **"Designing Data-Intensive Applications" (Martin Kleppmann)**
   - 이 책은 데이터 파이프라인, 분산 시스템, 데이터베이스와 같은 대규모 데이터 처리를 다루는 필수적인 내용을 다룹니다. 특히 대규모 머신러닝 인프라에서 데이터 흐름을 어떻게 관리할지에 대한 실질적인 아이디어를 얻을 수 있습니다.
   - **대상**: 분산 데이터 시스템과 데이터 엔지니어링의 이해도를 높이고 싶은 분들

### 온라인 자료
1. **Coursera: "MLOps (Machine Learning Operations) Specialization" (DeepLearning.AI)**
   - MLOps에 대한 체계적인 교육 과정으로, 머신러닝 모델의 배포, 자동화, 모니터링, 버전 관리 등의 인프라 구축 과정을 학습할 수 있습니다.
   - [MLOps Specialization on Coursera](https://www.coursera.org/specializations/machine-learning-operations-mlops)

2. **FastAPI 공식 문서**
   - 머신러닝 모델을 API로 서빙할 때 유용한 FastAPI를 다룬 공식 문서입니다. 간단하고 빠르게 모델을 배포하는 방법을 익힐 수 있습니다.
   - [FastAPI Docs](https://fastapi.tiangolo.com/)

3. **TensorFlow Extended (TFX)**
   - TensorFlow를 활용한 MLOps 워크플로우 구축 가이드입니다. 데이터 전처리, 훈련, 서빙까지 전 과정에 걸쳐 실습할 수 있는 자료를 제공합니다.
   - [TensorFlow TFX Guide](https://www.tensorflow.org/tfx)

4. **Kubeflow**
   - Kubernetes 기반의 머신러닝 워크플로우 관리 도구인 Kubeflow를 다룬 공식 자료입니다. 머신러닝 파이프라인을 자동화하고 배포하는 과정을 설명합니다.
   - [Kubeflow Docs](https://www.kubeflow.org/)
