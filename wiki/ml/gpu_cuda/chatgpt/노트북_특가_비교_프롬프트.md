# 노트북 특가 비교 프롬프트

> **카테고리**: `ML - GPU & CUDA 가속`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-12-10

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
한국에서 판매하는 노트북 특가를 비교하고 싶어. 이거 관련해서 어떻게 물어보는게 좋은지 프롬프트를 작성해줘

### 💡 답변 (Assistant)
그냥 “노트북 뭐가 좋아요?” 이렇게만 쓰면 모델이 대충 말만 해줄 확률이 커요.  
**비교 + 한국 쇼핑몰 + 예산/용도** 를 딱 못 박아주는 프롬프트가 좋습니다.  
바로 복붙해서 쓸 수 있는 템플릿이랑 예시 둘 다 만들어 줄게요.

---

## 1. 템플릿용 프롬프트 (네가 조건만 채워 넣으면 되는 버전)

```text
너는 한국 온라인 쇼핑몰(쿠팡, 11번가, G마켓, 네이버 쇼핑 등)의 노트북 가격과 스펙에 밝은 쇼핑 컨설턴트야. 

아래 조건에 맞는 노트북 “특가 상품”을 여러 개 찾아서 **비교 분석**해줘.

[내 조건]
- 예산: 최대 ______원
- 주요 사용 용도: (예: 웹서핑/문서, 코딩, 영상 편집, 게임, 딥러닝/AI 등)
- 선호 브랜드: (예: 상관 없음 / 삼성 / LG / 레노버 / ASUS / MSI …)
- 화면 크기: (예: 14인치 이하 / 15.6인치 / 16인치 이상 등)
- 무게: (예: 1.4kg 이하 선호 / 2kg까지 괜찮음 등)
- OS: (윈도우 포함 선호 / OS 상관 없음 / 프리도스 OK 등)
- 기타 필수 조건: (예: RAM 최소 16GB, SSD 512GB 이상, 독립 GPU 필요 등)
- 거주 국가/언어: 한국, 한글 키보드 선호

[요청사항]
1. **반드시 웹 검색을 사용해서**, 한국에서 실제로 구매 가능한 상품만 찾아줘.
2. 가능하다면 **최근 7~14일 내 가격 기준 또는 특가/할인 상품** 위주로 골라줘.
3. 최소 3~5개 정도의 후보를 제시하고, 아래 형식의 **비교 표**를 만들어줘.

   - 브랜드/모델명
   - 주요 스펙(CPU, RAM, SSD, GPU, 화면 크기/무게)
   - 대략적인 가격(원)과 판매처
   - 장점
   - 단점
   - 이런 사람에게 추천 (예: 대학생, 개발자, 영상 편집자, 게이머 등)

4. 마지막에 **내 조건 기준에서 1순위 / 2순위 / 3순위 추천 이유**를 간단히 정리해줘.
5. 너무 오래된 정보일 수 있으면, 반드시 “가격은 변동될 수 있음”을 언급해줘.
6. 답변은 한국어로 해줘.
```

이걸 그대로 붙여넣고, 빈칸만 채우면 됩니다.

## 2. 실제로 채워 넣은 예시 프롬프트 (바로 써도 됨)

예를 들어 네 상황이 이렇다고 해보자:

- 예산: 120만 원
- 용도: 코딩 + 가벼운 딥러닝 실험 + 넷플릭스/유튜브
- 화면: 14~15.6인치
- 무게: 1.6kg 이하
- 기타: RAM 16GB 이상, SSD 512GB 이상, NVIDIA GPU까진 있으면 좋고 없어도 됨

그럼 이렇게 쓸 수 있어요:

```text
너는 한국 온라인 쇼핑몰(쿠팡, 11번가, G마켓, 네이버 쇼핑 등)의 노트북 가격과 스펙에 밝은 쇼핑 컨설턴트야. 

아래 조건에 맞는 노트북 “특가 상품”을 여러 개 찾아서 비교 분석해줘.

[내 조건]
- 예산: 최대 1,200,000원
- 주요 사용 용도: 코딩, 가벼운 딥러닝 실험, 넷플릭스/유튜브 시청
- 선호 브랜드: 크게 상관 없지만, as 생각하면 삼성/엘지 우선, 그 외 가성비 모델도 괜찮음
- 화면 크기: 14~15.6인치
- 무게: 1.6kg 이하 선호
- OS: 윈도우 포함이면 좋지만, 프리도스여도 상관 없음
- 기타 필수 조건: RAM 최소 16GB, SSD 최소 512GB, NVIDIA GPU는 있으면 좋고 필수는 아님
- 거주 국가/언어: 한국, 한글 키보드 선호

[요청사항]
1. 반드시 웹 검색을 사용해서, 한국에서 실제로 구매 가능한 상품만 찾아줘.
2. 가능하다면 최근 7~14일 내 가격 기준 또는 특가/할인 상품 위주로 골라줘.
3. 최소 3~5개 정도의 후보를 제시하고, 아래 형식의 비교 표를 만들어줘.

   - 브랜드/모델명
   - 주요 스펙(CPU, RAM, SSD, GPU, 화면 크기/무게)
   - 대략적인 가격(원)과 판매처
   - 장점
   - 단점
   - 이런 사람에게 추천

4. 마지막에 내 조건 기준에서 1순위 / 2순위 / 3순위 추천 이유를 간단히 정리해줘.
5. 가격은 수시로 변동될 수 있으니 그 점도 같이 언급해줘.
6. 답변은 한국어로 해줘.
```

## 3. 초간단 버전 (귀찮을 때 쓰는 최소 프롬프트)

조금 귀찮을 때는 이렇게 짧게도 가능해요:

```text
한국에서 구매 가능한 노트북 특가를 비교하고 싶어.

- 예산: 최대 ______원
- 용도: ______
- 화면/무게: ______
- 최소 스펙: ______

웹 검색을 사용해서 실제 판매 중인 제품 중 3~5개만 골라서,
브랜드/모델명, 핵심 스펙, 가격, 장단점, 추천 이유를 표로 정리하고
내 조건에 가장 잘 맞는 1순위를 골라줘.
```

---

원하면 네 실제 조건(예산, 용도, 선호 브랜드 등) 말해주면  
위 템플릿에 맞춰서 **완전히 커스터마이징된 프롬프트**도 바로 만들어 줄게!
