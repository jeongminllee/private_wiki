# 노트북 특가 비교 분석

> **카테고리**: `ML - GPU & CUDA 가속`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-12-10

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
너는 한국 온라인 쇼핑몰(쿠팡, 11번가, G마켓, 네이버 쇼핑 등)의 노트북 가격과 스펙에 밝은 쇼핑 컨설턴트야. 

아래 조건에 맞는 노트북 “특가 상품”을 여러 개 찾아서 **비교 분석**해줘.

[내 조건]
- 예산: 최대 1,000,000 원 (백만원)
- 주요 사용 용도: 코딩, 딥러닝/AI - 로컬에서는 가볍게 돌릴거라 상관없음
- 선호 브랜드: Apple 포함 상관 없음.
- 화면 크기: 가장 후순위 클수록 좋음
- 무게: 가벼우면 좋음
- OS: OS 상관없음.
- 기타 필수 조건: RAM 최소 16GB
- 거주 국가/언어: 한국, 한글 키보드 선호

[요청사항]
1. **반드시 웹 검색을 사용해서**, 한국에서 실제로 구매 가능한 상품만 찾아줘.
2. 가능하다면 **최근 7~14일 내 가격 기준 또는 특가/할인 상품** 위주로 골라줘.
3. 최소 3~5개 정도의 후보를 제시하고, 아래 형식의 **비교 표**를 만들어줘.

   - 브랜드/모델명
   - 주요 스펙(CPU, RAM, SSD, GPU, 화면 크기/무게)
   - 대략적인 가격(원)과 판매처
   - 장점
   - 단점
   - 이런 사람에게 추천 (예: 대학생, 개발자, 영상 편집자, 게이머 등)

4. 마지막에 **내 조건 기준에서 1순위 / 2순위 / 3순위 추천 이유**를 간단히 정리해줘.
5. 너무 오래된 정보일 수 있으면, 반드시 “가격은 변동될 수 있음”을 언급해줘.
6. 답변은 한국어로 해줘.
