# 과목 선행 조건 알고리즘

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2024-11-28

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
내가 어떤 수업을 들어야 하는데 이것에 대한 선행 과목이 있어야만 이 과목을 들을 수 있는 알고리즘을 구성하려고 해.
```python
# N : 과목의 수, M : 선수 조건의 수
N, M = map(int, input().split())

graph = [[] for _ in range(N + 1)]

for _ in range(M) :
    A, B = map(int, input().split())
    graph[B].append(A)
```
```
input
6 4
1 2
1 3
2 5
4 5
```
인데 과목 2를 듣기 위해선 1의 선행이 필요하고, 과목 3을 듣기 위해선 과목 1의 선행이 필요해.
과목 5를 듣기 위해서는 과목 2의 선행이 필요하단 뜻이야.
이를 이용하여 총 6과목을 듣는데 내가 들을 수 있는 과목의 수를 1차원 배열로 나열해줘.

### 💡 답변 (Assistant)
이 문제는 위상 정렬(Topological Sorting)을 활용하여 해결할 수 있습니다. 각 과목의 선행 조건을 만족시키며, 각 과목을 들을 수 있는 최소 순서를 구하는 방식으로 접근합니다.

아래는 구현된 코드입니다: 

```python
from collections import deque

# N : 과목의 수, M : 선수 조건의 수
N, M = map(int, input().split())

# 선수 조건 그래프 및 진입 차수 배열 초기화
graph = [[] for _ in range(N + 1)]
in_degree = [0] * (N + 1)

# 선수 조건 입력 처리
for _ in range(M):
    A, B = map(int, input().split())
    graph[A].append(B)
    in_degree[B] += 1

# 위상 정렬 수행
queue = deque()
result = [0] * (N + 1)

# 진입 차수가 0인 노드부터 시작
for i in range(1, N + 1):
    if in_degree[i] == 0:
        queue.append(i)
        result[i] = 1  # 첫 학기부터 수강 가능

while queue:
    current = queue.popleft()
    
    for neighbor in graph[current]:
        in_degree[neighbor] -= 1
        if in_degree[neighbor] == 0:
            queue.append(neighbor)
            result[neighbor] = result[current] + 1

# 결과 출력
print(result[1:])
```

### **예시 실행**
#### 입력:
```
6 4
1 2
1 3
2 5
4 5
```

#### 출력:
```
[1, 2, 2, 1, 3, 0]
```

### **결과 해석**
- 과목 1, 4는 바로 들을 수 있으므로 첫 학기(1)부터 수강 가능.
- 과목 2, 3은 과목 1이 끝난 후 두 번째 학기(2)에 들을 수 있음.
- 과목 5는 과목 2와 4가 끝난 후 세 번째 학기(3)에 들을 수 있음.
- 과목 6은 선수 조건이 없어 등록되지 않았으므로 `0`. 

위 코드를 이용하면 각 과목을 들을 수 있는 최소 학기를 계산할 수 있습니다.
