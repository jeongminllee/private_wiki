### ❓ 질문 (User)
```
INF = 1 << 32

def compare(a, b) :
    return b if a < b else a

def main() :
    N = int(input())
    days = [(0, 0)] # 1-based indexing을 위한 더미 데이터

    max_happy = -1
    min_happy = INF
    max_fatigue = -1
    min_fatigue = INF

    # 각 날짜별 행복도와 피로도 입력
    for _ in range(N) :
        u, v = map(int, input().split())
        days.append((u, v))

    # youth 배열 계산 (앞에서부터)
    youth = [(0, 0)]
    for i in range(1, N + 1) :
        if days[i][0] != 0 and days[i][0] < min_happy :
            min_happy = days[i][0]
        if days[i][1] != 0 and days[i][1] > max_fatigue :
            max_fatigue = days[i][1]
        youth.append((min_happy, max_fatigue))

    # old 배열 계산 (뒤에서부터)
    old = [(0, 0)] * (N + 1)

    for i in range(N, 0, -1) :
        if days[i][0] != 0 and days[i][0] > max_happy :
            max_happy = days[i][0]
        if days[i][1] != 0 and days[i][1] < min_fatigue :
            min_fatigue = days[i][1]

        old[i] = (max_happy, min_fatigue)

    # 최적의 K 찾기
    cnt = -1
    for k in range(N - 1, -1, -1) : # k는 젊은 날
        youth_happy = youth[k][0]
        youth_fatigue = youth[k][1]
        old_happy = old[k+1][0]
        old_fatigue = old[k+1][1]


        if youth_happy > old_happy and youth_fatigue < old_fatigue :
            cnt = compare(cnt, k)

    print(cnt)

main()
```

## 1. 상수 및 헬퍼 함수

### INF 상수
```python
INF = 1 << 32
```
- `INF`는 \(2^{32}\)를 의미합니다. 이후 최소값을 갱신할 때 “충분히 큰 값”의 초기값으로 사용됩니다.

### compare 함수
```python
def compare(a, b):
    return b if a < b else a
```
- 두 값 `a`와 `b`를 비교하여, 더 큰 값을 반환합니다.
- 즉, `compare(a, b)`는 사실상 `max(a, b)`와 동일하게 동작합니다.
- 코드에서는 여러 후보 중 가장 큰 \(k\) 값을 선택하기 위해 사용됩니다.

## 2. 입력 및 데이터 준비

### 입력 받기
```python
N = int(input())
days = [(0, 0)]  # 1-based 인덱싱을 위한 더미 데이터
```
- 먼저, 날짜의 개수 \(N\)을 입력받습니다.
- `days` 리스트의 첫 번째 원소로 `(0, 0)`을 넣어 1부터 시작하는 인덱싱을 쉽게 합니다.

### 날짜별 행복도와 피로도 저장
```python
for _ in range(N):
    u, v = map(int, input().split())
    days.append((u, v))
```
- 각 날짜에 대해 행복도 `u`와 피로도 `v`를 입력받아, `days` 리스트에 저장합니다.

## 3. “청춘(young)” 배열 계산 (앞에서부터 누적)

```python
max_happy = -1
min_happy = INF
max_fatigue = -1
min_fatigue = INF

youth = [(0, 0)]
for i in range(1, N + 1):
    if days[i][0] != 0 and days[i][0] < min_happy:
        min_happy = days[i][0]
    if days[i][1] != 0 and days[i][1] > max_fatigue:
        max_fatigue = days[i][1]
    youth.append((min_happy, max_fatigue))
```
- **목적:** 날짜 1부터 \(i\)일까지의 구간에 대해,  
  - **행복도:** 유효한(0이 아닌) 값들 중 **최소** 행복도  
  - **피로도:** 유효한(0이 아닌) 값들 중 **최대** 피로도를 저장합니다.
- `min_happy`와 `max_fatigue`는 각각 청춘 구간 내에서 “최소 행복도”와 “최대 피로도”를 기록합니다.
- 결과적으로, `youth[i]`는 날짜 1부터 \(i\)까지의 구간에서의 `(최소 행복도, 최대 피로도)`를 의미합니다.

> **참고:**  
> 여기서 0인 값은 업데이트 대상에서 제외됩니다. 즉, 행복도나 피로도가 0인 날은 “유효한 값”으로 취급하지 않는 것으로 보입니다.

## 4. “노년(old)” 배열 계산 (뒤에서부터 누적)

```python
old = [(0, 0)] * (N + 1)

for i in range(N, 0, -1):
    if days[i][0] != 0 and days[i][0] > max_happy:
        max_happy = days[i][0]
    if days[i][1] != 0 and days[i][1] < min_fatigue:
        min_fatigue = days[i][1]
    old[i] = (max_happy, min_fatigue)
```
- **목적:** 날짜 \(i\)부터 \(N\)일까지의 구간에 대해,  
  - **행복도:** 유효한 값들 중 **최대** 행복도  
  - **피로도:** 유효한 값들 중 **최소** 피로도를 기록합니다.
- 변수 `max_happy`와 `min_fatigue`는 뒤쪽 구간에서의 “최대 행복도”와 “최소 피로도”를 저장합니다.
- 결과적으로, `old[i]`는 날짜 \(i\)부터 \(N\)까지의 구간에서의 `(최대 행복도, 최소 피로도)`를 의미합니다.

> **주의:**  
> 역시 0인 값은 제외하여 업데이트합니다.

## 5. 최적의 \(K\) (분할 지점) 찾기

```python
cnt = -1
for k in range(N - 1, -1, -1):  # k는 청춘(young) 구간의 날 수
    youth_happy = youth[k][0]
    youth_fatigue = youth[k][1]
    old_happy = old[k+1][0]
    old_fatigue = old[k+1][1]

    if youth_happy > old_happy and youth_fatigue < old_fatigue:
        cnt = compare(cnt, k)

print(cnt)
```
- **분할의 의미:**  
  날짜들을 두 구간으로 나눕니다.  
  - **청춘 구간:** 날짜 1부터 \(k\)까지  
  - **노년 구간:** 날짜 \(k+1\)부터 \(N\)까지

- **조건:**  
  - `youth_happy > old_happy`: 청춘 구간의 **최소 행복도**가 노년 구간의 **최대 행복도**보다 커야 함  
  - `youth_fatigue < old_fatigue`: 청춘 구간의 **최대 피로도**가 노년 구간의 **최소 피로도**보다 작아야 함

- **의미 해석:**  
  이 조건은 “모든 청춘 날들은 (유효한 값 기준) 노년 날들보다 행복도가 더 높고 피로도가 더 낮다”는 것을 보장합니다.

- **\(K\) 선택:**  
  - 조건을 만족하는 \(k\)가 여러 개 있을 경우, `compare(cnt, k)`를 통해 가장 큰 \(k\) (즉, 가능한 청춘 구간의 날 수가 최대인 경우)를 선택합니다.
  - 만약 조건을 만족하는 \(k\)가 하나도 없으면, 초기값인 \(-1\)이 출력됩니다.

---

## 6. 전체적인 동작 요약

1. **입력 처리:** \(N\)일 동안의 행복도와 피로도 데이터를 입력받습니다.
2. **청춘 구간 누적 정보 (앞쪽):**  
   - 날짜 1부터 \(i\)까지의 구간에서의 유효한 행복도의 **최소값**과 피로도의 **최대값**을 `youth` 배열에 저장합니다.
3. **노년 구간 누적 정보 (뒤쪽):**  
   - 날짜 \(i\)부터 \(N\)까지의 구간에서의 유효한 행복도의 **최대값**과 피로도의 **최소값**을 `old` 배열에 저장합니다.
4. **최적 분할점 \(K\) 찾기:**  
   - \(K\)를 0부터 \(N-1\)까지의 값 중에서,  
     - 청춘 구간(날짜 1~\(K\))의 최소 행복도가 노년 구간(날짜 \(K+1\)~\(N\))의 최대 행복도보다 크고,  
     - 청춘 구간의 최대 피로도가 노년 구간의 최소 피로도보다 작은 경우를 만족하는 값 중 **가장 큰 \(K\)**를 선택합니다.
5. **출력:**  
   - 조건을 만족하는 최적의 \(K\) 값을 출력하며, 없으면 \(-1\)을 출력합니다.

## 5. 최적의 분할점 \( k \) 찾기


  - `youth_happy > old_happy`: 청춘 구간의 **최소 행복도**가 노년 구간의 **최대 행복도**보다 **크아야** 합니다.  
    → 이는 모든 청춘 날들이 노년 날들보다 행복도가 높아야 함을 의미합니다.
  - `youth_fatigue < old_fatigue`: 청춘 구간의 **최대 피로도**가 노년 구간의 **최소 피로도**보다 **작아야** 합니다.  
    → 이는 청춘 날들이 노년 날들보다 피로도가 낮아야 함을 의미합니다.

- **동작:**  
  - \( k \)를 \( N-1 \)부터 0까지 (역순) 순회하면서 위 조건을 만족하는지 검사합니다.
  - 조건을 만족하면, `cnt`를 현재까지의 최대 \( k \) 값으로 갱신합니다.
  - 만약 어떤 \( k \)도 조건을 만족하지 않으면 `cnt`는 초기값 \(-1\)로 남습니다.

> **주의:**  
> - \( k = N \)인 경우에는 노년 구간이 없으므로 고려하지 않고, \( k \)는 \( N-1 \) 이하의 값만을 검사합니다.  
> - 0 값은 업데이트에 사용되지 않으므로, 실제 비교는 유효한(0이 아닌) 데이터에 대해서만 이뤄집니다.

---

## 6. 최종 출력

```python
    print(cnt)
```
- 조건을 만족하는 최적의 \( k \) (젊은 날의 최대 개수)를 출력합니다.
- 만약 조건에 맞는 \( k \)가 하나도 없다면 \(-1\)이 출력됩니다.

---

## 전체적인 요약

1. **입력:**  
   - \( N \)일 동안의 행복도와 피로도 데이터를 입력받고, 1-based 인덱스로 관리합니다.
2. **청춘 배열 계산 (앞에서부터):**  
   - 날짜 1일부터 \( i \)일까지의 구간에 대해, 유효한 행복도 중 **최소값**과 유효한 피로도 중 **최대값**을 기록합니다.
3. **노년 배열 계산 (뒤에서부터):**  
   - 날짜 \( i \)부터 \( N \)일까지의 구간에 대해, 유효한 행복도 중 **최대값**과 유효한 피로도 중 **최소값**을 기록합니다.
4. **분할점 \( k \) 탐색:**  
   - 날짜 1부터 \( k \)까지를 청춘, \( k+1 \)부터 \( N \)까지를 노년으로 보았을 때,  
     - 청춘의 최소 행복도가 노년의 최대 행복도보다 크고,  
     - 청춘의 최대 피로도가 노년의 최소 피로도보다 작아야 합니다.
   - 이러한 조건을 만족하는 \( k \)들 중 최대값을 찾습니다.
5. **출력:**  
   - 조건을 만족하는 최적의 \( k \)를 출력하며, 없다면 \(-1\)을 출력합니다.

---

이 코드의 핵심은 입력된 데이터를 기반으로 양 구간(청춘과 노년)의 **경계**를 누적 집계한 후, 두 구간 간의 “행복도”와 “피로도”의 상대적 우열 관계를 비교하여 올바른 분할점을 찾는 데 있습니다.
