# 그래프 경로 추론

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
N = int(input())
graph = [[0] * 58 for _ in range(58)]
X = 0
for _ in range(N) :
    left, right = input().split(' => ')
    if left == right :
        continue
    P = ord(left) - 65
    Q = ord(right) - 65
    if graph[P][Q] == 0 :
        graph[P][Q] = 1
        X += 1

for k in range(58) :
    for i in range(58) :
        for j in range(58):
            if i != j and not graph[i][j] and graph[i][k] and graph[k][j] :
                graph[i][j] = 1
                X += 1

print(X)
for i in range(58) :
    for j in range(58) :
        if i == j :
            continue
        if graph[i][j] :
            print(f'{chr(i + 65)} => {chr(j + 65)}')
```

### 💡 답변 (Assistant)
이 코드는 **그래프의 경로 추론 문제**를 해결하는 코드로, 특정 관계들(연결)을 입력받아 **추론 가능한 새로운 관계를 계산**하는 기능을 수행합니다. 주어진 코드는 **플로이드-워셜 알고리즘**을 활용하여 **모든 정점 쌍 간의 관계를 탐색**합니다.

---

### **코드 분석**

#### 1. **입력 및 초기화**
```python
N = int(input())  # 관계의 개수 입력
graph = [[0] * 58 for _ in range(58)]  # 58x58 2차원 배열 초기화 (알파벳 대문자 A-Z 기준, 26 + 여유 공간)
X = 0  # 총 관계 개수 카운트
```

- `N`: 입력받는 관계의 수.
- `graph`: 2차원 배열로, `graph[i][j]`가 `1`이면 정점 `i`에서 정점 `j`로 가는 관계가 존재함을 의미.
  - 배열 크기를 58로 설정한 이유는 알파벳 대문자 ASCII 코드(65~90)를 기준으로 인덱스를 매핑하기 위해.

---

#### 2. **초기 관계 입력**
```python
for _ in range(N):
    left, right = input().split(' => ')  # 관계 입력받기
    if left == right:
        continue  # 자기 자신으로 가는 관계는 무시
    P = ord(left) - 65  # 왼쪽 문자 ASCII 코드 기반 인덱스
    Q = ord(right) - 65  # 오른쪽 문자 ASCII 코드 기반 인덱스
    if graph[P][Q] == 0:  # 새로운 관계라면
        graph[P][Q] = 1
        X += 1  # 관계 수 증가
```

- 입력받은 `left => right` 관계를 `graph`에 기록.
- ASCII 코드의 범위가 `A`~`Z`로 제한되므로 `ord(left) - 65`와 같은 변환을 수행.
- 동일한 관계가 여러 번 입력되더라도 중복 카운트하지 않음.

---

#### 3. **경로 추론 (플로이드-워셜 알고리즘)**
```python
for k in range(58):  # 중간 정점
    for i in range(58):  # 시작 정점
        for j in range(58):  # 도착 정점
            if i != j and not graph[i][j] and graph[i][k] and graph[k][j]: 
                graph[i][j] = 1
                X += 1  # 새로 추가된 관계 카운트
```

- 플로이드-워셜 알고리즘:
  - `graph[i][j]`가 `0`이고 `graph[i][k]`와 `graph[k][j]`가 `1`이면 새로운 간접 관계 `i -> j`를 추론.
  - 모든 정점 쌍에 대해 중간 정점 `k`를 경유하는 가능성을 확인하여 관계를 확장.
- 조건 `i != j`는 자기 자신으로 가는 관계는 무시하기 위해 추가.

---

#### 4. **결과 출력**
```python
print(X)  # 총 관계 개수 출력
for i in range(58):
    for j in range(58):
        if i == j:  # 자기 자신으로 가는 관계는 제외
            continue
        if graph[i][j]:  # 관계가 존재하면 출력
            print(f'{chr(i + 65)} => {chr(j + 65)}')
```

- `X`: 총 관계의 수 출력.
- 모든 관계를 탐색하며 `graph[i][j] == 1`인 경우 알파벳 문자로 변환하여 `A => B` 형식으로 출력.

---

### **작동 원리**

1. 입력받은 관계로 초기 그래프를 설정.
2. 플로이드-워셜 알고리즘을 통해 모든 간접 관계를 추론.
3. 최종적으로 모든 관계의 개수와 관계 목록을 출력.

---

### **입출력 예시**

#### 입력:
```
4
A => B
B => C
C => D
E => F
```

#### 처리 과정:
1. 초기 관계:
   ```
   A -> B
   B -> C
   C -> D
   E -> F
   ```
2. 간접 관계 추론:
   ```
   A -> C (A -> B -> C)
   A -> D (A -> B -> C -> D)
   B -> D (B -> C -> D)
   ```

#### 출력:
```
7
A => B
A => C
A => D
B => C
B => D
C => D
E => F
```

- 관계 수: `7`.
- 관계 목록: 위와 같음.

---

### **코드의 특징**
- 효율적인 관계 추론 알고리즘(Floyd-Warshall)을 사용.
- 모든 관계를 완전 탐색하여 추론 가능한 관계를 누락 없이 계산.
