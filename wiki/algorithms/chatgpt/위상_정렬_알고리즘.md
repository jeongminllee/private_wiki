### **위상 정렬 (Topological Sorting)**

위상 정렬(Topological Sorting)은 **방향성을 가진 그래프(DAG, Directed Acyclic Graph)에서 정점들을 선형적으로 정렬하는 알고리즘**이야. 즉, 방향 그래프에서 **선행 관계(Dependency)가 있는 작업들을 순서대로 정렬할 때 유용**하지.

---

## **📌 위상 정렬의 특징**
1. **DAG(Directed Acyclic Graph, 방향 비순환 그래프)에서만 수행 가능**  
   - 순환이 존재하면 위상 정렬을 수행할 수 없어.
2. **선행 조건이 있는 작업을 정렬하는 데 유용**  
   - 예를 들면, 선수 과목이 있는 강의 수강 순서 정하기, 소프트웨어 빌드 순서 정하기 등이 있어.
3. **위상 정렬의 결과는 유일하지 않을 수도 있음**  
   - 여러 가지 위상 정렬 결과가 존재할 수 있어.

---

## **📌 위상 정렬 알고리즘**
위상 정렬을 수행하는 대표적인 알고리즘은 **Kahn's Algorithm (큐를 이용한 방법)**과 **DFS를 이용한 방법** 두 가지가 있어.

### **🔹 1. Kahn's Algorithm (진입 차수 기반)**
> **진입 차수(Indegree):** 특정 노드로 들어오는 간선의 개수  
> **진입 차수가 0인 노드부터 제거하면서 정렬**

#### **💡 동작 과정**
1. 그래프의 모든 정점에 대해 **진입 차수(Indegree)를 계산**한다.
2. 진입 차수가 0인 노드를 **큐(Queue)에 삽입**한다.
3. 큐에서 노드를 하나씩 꺼내면서, 해당 노드와 연결된 간선을 제거한다.
4. 간선을 제거한 후, 진입 차수가 0이 된 노드를 다시 큐에 삽입한다.
5. 모든 노드를 방문할 때까지 반복한다.

#### **⏳ 시간 복잡도**
- **O(V + E)** (V: 노드 수, E: 간선 수)

#### **📝 Python 코드 (Kahn's Algorithm)**
```python
from collections import deque

def topological_sort_kahn(graph, indegree, N):
    result = []  # 위상 정렬 결과를 저장할 리스트
    queue = deque()

    # 진입 차수가 0인 노드를 큐에 삽입
    for i in range(N):
        if indegree[i] == 0:
            queue.append(i)

    while queue:
        node = queue.popleft()
        result.append(node)

        # 해당 노드와 연결된 간선 제거
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)

    # DAG가 아니면 (사이클이 있으면) 위상 정렬이 불가능
    if len(result) != N:
        return "Cycle detected, topological sort not possible"

    return result
```

### **🔹 2. DFS를 이용한 방법**
> **역순으로 방문하여 정렬**

#### **💡 동작 과정**
1. 각 노드를 방문하면서 **DFS 탐색**을 수행한다.
2. 더 이상 방문할 노드가 없으면 **현재 노드를 스택(Stack)에 삽입**한다.
3. 모든 노드에 대해 DFS가 끝나면, **스택에서 노드를 하나씩 꺼내면서 정렬 결과를 만든다.**

#### **⏳ 시간 복잡도**
- **O(V + E)**

#### **📝 Python 코드 (DFS 기반)**
```python
def topological_sort_dfs(graph, N):
    visited = [False] * N
    stack = []

    def dfs(node):
        visited[node] = True
        for neighbor in graph[node]:
            if not visited[neighbor]:
                dfs(neighbor)
        stack.append(node)  # 탐색이 끝난 노드를 스택에 삽입

    for i in range(N):
        if not visited[i]:
            dfs(i)

    return stack[::-1]  # 스택에서 꺼내는 순서가 위상 정렬 결과
```

## **📌 위상 정렬 예제**
> **예제 그래프**
```
0 → 1 → 3
↓    ↓
2 → 4
```
**입력 데이터 (인접 리스트 형태)**
```python
graph = {0: [1, 2], 1: [3, 4], 2: [4], 3: [], 4: []}
indegree = [0, 1, 1, 1, 2]  # 진입 차수
N = 5  # 노드 개수
```
**출력**
```
위상 정렬 결과: [0, 1, 2, 3, 4] (or 다른 순서 가능)
```

## **📌 위상 정렬 활용 예시**
1. **작업 스케줄링**  
   - 프로젝트의 작업 간 선후 관계가 있을 때 실행 순서를 정하는 데 사용
2. **컴파일 순서 결정**  
   - 여러 개의 모듈이 존재할 때, 특정 모듈이 다른 모듈을 의존할 경우 빌드 순서를 정할 수 있음
3. **과목 수강 순서 정하기**  
   - 선수 과목이 있는 경우, 어떤 과목부터 들어야 하는지 정할 수 있음
4. **데이터 처리 파이프라인 구성**  
   - 데이터의 흐름이 선형적이어야 할 경우, 순서를 정하는 데 사용

## **📌 위상 정렬 정리**
| 알고리즘 | 자료구조 | 시간 복잡도 | 특징 |
|----------|--------|------------|------------|
| Kahn's Algorithm | 큐(Queue) | O(V + E) | 진입 차수를 기반으로 수행 |
| DFS 기반 | 스택(Stack) | O(V + E) | 역순으로 정렬 |

위상 정렬은 **DAG(방향 비순환 그래프)에서만 적용 가능**하며, **작업 스케줄링, 컴파일 순서, 데이터 처리** 등 다양한 분야에서 사용돼.
