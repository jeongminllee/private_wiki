# 업무 역량 및 커리큘럼

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
수행 업무

초거대 언어모델 개발
- 한국어 언어 모델 Tuning
- 한국어 언어 모델 벤치마크 구축
- 한국어 언어 모델 Inference 엔진 최적화

심층문서이해 기술 개발 
- 영어 Chemical 도메인의 언어 모델을 위한 데이터 처리 및 모델 튜닝

강화학습 기반 언어모델 개발
- 강화학습 기반 언어모델 개발 관련 데이터 처리 및 모델 튜닝

테이블이해 기술(TableMRC) 개발
- 테이블 구조 이해를 위한 언어모델 (Pre-trained Langauge Model) 구현
- 한국어 모델 Tuning 및 Inference 엔진 최적화

이 업무에 필요한 역량을 알려줘. 그리고 그 역량을 개발할 커리큘럼을 작성해줘

### 💡 답변 (Assistant)
이 업무에서 필요한 주요 역량은 다음과 같습니다.

### 필요한 역량

1. **자연어 처리(NLP) 및 언어 모델 이해**
   - 한국어와 영어 모델을 포함한 언어 모델의 작동 원리와 트랜스포머 모델에 대한 깊이 있는 이해가 필요합니다.
   - 전처리 및 데이터 처리 파이프라인을 구성할 수 있는 능력과 한국어 및 Chemical 도메인 데이터 특성을 이해해야 합니다.

2. **머신러닝 및 딥러닝 모델 튜닝**
   - 한국어 및 영어 언어 모델을 최적화하는 하이퍼파라미터 튜닝 및 퍼포먼스 향상 기법이 필요합니다.

3. **강화학습 및 실험 설계**
   - 강화학습 알고리즘의 원리와 언어 모델에 적용할 수 있는 기술을 알아야 합니다.
   - 관련 데이터를 이해하고 강화학습에 맞는 실험 설계 및 구현 능력이 필요합니다.

4. **모델 서빙 및 인프라 최적화**
   - Inference 엔진의 최적화 방법 및 서빙 인프라에 대한 경험이 필요합니다.

5. **테이블 구조 이해 및 TableMRC**
   - 테이블 구조를 이해하고 이를 언어 모델이 처리할 수 있는 형태로 변환할 수 있는 역량이 필요합니다.
   - 언어모델의 구조적 이해를 바탕으로 테이블에서 질의 응답을 처리하는 기술에 대한 이해가 중요합니다.

### 커리큘럼

#### 1. 자연어 처리(NLP) 및 언어 모델 이해 (4주)
   - **Week 1**: NLP 기본기 다지기 (토큰화, 임베딩, 전처리) 및 한국어 처리의 특수성 이해
   - **Week 2**: 트랜스포머 모델 기초 및 언어 모델의 작동 방식 이해
   - **Week 3**: 한국어와 영어 도메인 데이터 전처리 및 텍스트 데이터 파이프라인 구축 실습
   - **Week 4**: Chemical 도메인 데이터 탐색과 전처리

#### 2. 머신러닝 및 딥러닝 모델 튜닝 (3주)
   - **Week 5**: 언어 모델 하이퍼파라미터 튜닝 기초와 성능 평가
   - **Week 6**: 최적화 알고리즘 및 GPU 최적화 실습
   - **Week 7**: 한국어 모델 최적화 사례 및 벤치마크 구축

#### 3. 강화학습 및 실험 설계 (4주)
   - **Week 8**: 강화학습 기초 (Policy Gradient, Q-Learning 등)
   - **Week 9**: 강화학습 언어 모델에의 적용 기법 이해
   - **Week 10**: 강화학습 관련 데이터 생성 및 전처리 방법 실습
   - **Week 11**: 강화학습 기반 실험 설계 및 평가 실습

#### 4. 모델 서빙 및 인프라 최적화 (3주)
   - **Week 12**: Inference 엔진 작동 원리 및 최적화 기법 이해
   - **Week 13**: 모델 서빙 인프라 구축 (GPU 활용, Flask/FastAPI 기반 API 구성)
   - **Week 14**: 최적화 기법 실습 및 성능 평가

#### 5. 테이블 구조 이해 및 TableMRC (3주)
   - **Week 15**: TableMRC 및 구조적 언어 모델 이해
   - **Week 16**: 테이블 구조 데이터 전처리 및 모델 적용
   - **Week 17**: 한국어 모델 튜닝과 Inference 최적화

### 💡 답변 (Assistant)
이후에도 실무 적용을 위한 심화 학습 및 프로젝트 실습 단계가 필요합니다. 아래는 이러한 심화 학습과 실무형 프로젝트 수행 과정을 포함한 커리큘럼의 마지막 부분입니다.

---

#### 6. 심화 실무 프로젝트 및 응용 (4주)
   - **Week 18**: 한국어 언어 모델 튜닝 프로젝트
     - 한국어 데이터셋을 수집, 전처리하고 모델에 학습 및 튜닝 적용
     - 한국어 벤치마크를 구축하여 결과 평가 및 개선 사항 도출
   - **Week 19**: Chemical 도메인 언어 모델 프로젝트
     - Chemical 도메인 텍스트를 활용해 언어 모델을 튜닝하고, 적합한 벤치마크 설계
     - Chemical 도메인에서 중요한 개념 및 키워드 추출 및 처리 방법 고도화
   - **Week 20**: 강화학습 기반 언어 모델 프로젝트
     - 강화학습 기반 언어 모델을 위한 데이터 생성 및 튜닝, 실험 설계 및 최적화
     - 다양한 강화학습 알고리즘을 적용하고 모델 성능 비교 평가
   - **Week 21**: TableMRC 프로젝트
     - 다양한 테이블 구조 데이터를 수집하고 전처리하여 TableMRC 모델 훈련
     - 질의응답 성능 평가 및 최적화 작업 수행

#### 7. 모델 배포 및 모니터링 (2주)
   - **Week 22**: 모델 배포 환경 구축 및 최적화
     - GPU 및 클라우드 인프라 환경에서의 모델 서빙
     - 배포된 모델의 실시간 모니터링과 성능 지표 수집
   - **Week 23**: 엔드투엔드 파이프라인 구축
     - 배포한 모델의 유지 보수 및 피드백 루프 구현
     - 지속적인 모델 성능 개선을 위한 파이프라인 설계 및 자동화

### 💡 답변 (Assistant)
작성된 커리큘럼을 실질적으로 학습하기 위해 단계별로 학습 리소스를 활용하고, 프로젝트를 수행하면서 지식을 확장할 수 있습니다. 주요 방법은 다음과 같습니다.

### 1. 자연어 처리(NLP) 및 언어 모델 이해
   - **온라인 강의**: 
     - [Coursera의 “Natural Language Processing Specialization”](https://www.coursera.org/specializations/natural-language-processing)
     - [Fast.ai의 “Natural Language Processing with Transformers”](https://www.fast.ai/)
   - **교재 및 자료**:
     - “딥러닝을 활용한 자연어 처리” (책)
     - 한국어 NLP: [한국어 NLP 데이터 및 오픈소스 모음](https://github.com/kh-kim/nlp_with_transformers_in_korean)
   - **연습**: 한국어 텍스트 데이터 전처리 및 탐색, 실습으로 진행

### 2. 머신러닝 및 딥러닝 모델 튜닝
   - **온라인 강의**:
     - [Udacity의 “Deep Learning Specialization”](https://www.udacity.com/) - 딥러닝과 최적화 기술 이해
     - [Hugging Face의 튜토리얼](https://huggingface.co/transformers/) - 트랜스포머 튜닝
   - **실습 프로젝트**:  
     - [Kaggle 노트북](https://www.kaggle.com/) 활용해 텍스트 분류나 언어 모델 튜닝
     - 하이퍼파라미터 튜닝을 위한 실습 코드 작성 및 평가

### 3. 강화학습 및 실험 설계
   - **강의 및 튜토리얼**:
     - [Spinning Up in Deep RL by OpenAI](https://spinningup.openai.com/) - 강화학습 기본기
     - [강화학습 입문 (한빛미디어 출판)](https://www.hanbit.co.kr/)
   - **실습 프로젝트**:
     - OpenAI Gym을 활용해 간단한 강화학습 알고리즘 실습
     - 언어 모델에 맞춘 강화학습 적용을 위해 데이터 구성 및 성능 평가

### 4. 모델 서빙 및 인프라 최적화
   - **온라인 강의**:
     - [Deploying Machine Learning Models (Coursera)](https://www.coursera.org/) - 서빙 및 최적화
     - [AWS, Google Cloud 튜토리얼](https://aws.amazon.com/) - 클라우드 기반 모델 서빙 실습
   - **실습**:
     - Flask/FastAPI로 API 구축, Docker로 컨테이너화 실습
     - Inference 최적화 기법 적용, 성능 지표 측정

### 5. 테이블 구조 이해 및 TableMRC
   - **논문 및 튜토리얼**:
     - “TAPAS: Weakly Supervised Table Parsing” 논문 리뷰 및 실습 ([논문 링크](https://arxiv.org/abs/2004.02349))
     - TableQA 실습: [TAble-MRC 리포지토리](https://github.com/facebookresearch/TAPAS) 활용
   - **실습 프로젝트**:
     - 테이블 구조 데이터를 수집하고 TableQA 모델 구축 실습
     - TableMRC를 위한 모델 튜닝 및 질의응답 평가

### 6. 실무 프로젝트 수행
   - **프로젝트**: 자체 프로젝트나 오픈소스 프로젝트 참여
   - **Kaggle이나 GitHub에서 관련 프로젝트 진행**:
     - 프로젝트 수행을 통해 피드백 받기, 코드 공유, 협업 경험

### 7. 배포 및 모니터링
   - **DevOps와 MLOps 학습**:
     - DevOps for Data Science (Pluralsight) - MLOps 기초 및 자동화
     - [Seldon Core](https://www.seldon.io/)나 [Kubeflow](https://www.kubeflow.org/) 학습
   - **실습**:
     - 간단한 MLOps 파이프라인을 구축하고 자동화된 배포 실습

이 과정을 반복적으로 연습하고, 실무 프로젝트로 적용할 때 적합한 자료와 툴을 활용하면 이 커리큘럼을 충실히 따라가며 기술 역량을 높일 수 있습니다.

### 💡 답변 (Assistant)
요구 및 우대 역량을 충족하기 위한 커리큘럼은 각 역량에 맞춘 단계별 학습 과정으로 구성할 수 있습니다. 이를 통해 실무에서 바로 적용할 수 있는 기술적 준비를 할 수 있습니다.

---

### 1. **Linux와 Python 기초 및 활용** (2주)
   - **필수 기술**: Linux 명령어 및 Python 코딩
   - **목표**: 환경 설정과 스크립트 작성, 서버 관리 등 기본적 Linux 명령어에 익숙해지고 Python을 중급 이상으로 다룰 수 있도록 학습
   - **학습 경로**:
     - **Week 1**: Linux 기본 명령어 (파일/폴더 조작, 서버 관리, 네트워크 설정)
     - **Week 2**: Python 중급 실습 (함수형 프로그래밍, 객체지향 프로그래밍, 예외 처리)
   - **리소스**:
     - Linux 강의: [The Linux Command Line](https://www.udemy.com/course/the-linux-command-line-bootcamp/) (Udemy)
     - Python 강의: [Intermediate Python](https://www.coursera.org/) - 함수형/객체지향 및 실무적 Python 활용법

### 2. **Hugging Face 언어 모델 활용 및 튜닝** (3주)
   - **필수 기술**: Hugging Face 라이브러리의 언어 모델 로드, 트레이닝 및 튜닝 방법
   - **목표**: Hugging Face 모델 구조 이해와 모델 튜닝 능력 습득, 한국어 데이터셋을 사용한 튜닝 경험
   - **학습 경로**:
     - **Week 3**: Hugging Face Transformers 기본 사용법 (모델 로딩, 토크나이징)
     - **Week 4**: Fine-tuning 실습 (한국어 데이터셋을 사용한 튜닝 예제 실습)
     - **Week 5**: 튜닝된 모델 평가와 성능 비교, 벤치마크 도구 활용법
   - **리소스**:
     - Hugging Face 튜토리얼: [Transformers 공식 튜토리얼](https://huggingface.co/course/chapter1)
     - 한국어 데이터셋 활용 예제: [KLUE 데이터셋](https://klue-benchmark.com/)

### 3. **Multi-GPU Model-Parallelism** (2주)
   - **필수 기술**: Multi-GPU 설정과 병렬 모델 학습
   - **목표**: 대규모 데이터 학습을 위해 여러 GPU를 활용하여 모델을 병렬로 학습하고 최적화하는 방법 습득
   - **학습 경로**:
     - **Week 6**: PyTorch 기반 Multi-GPU 설정 및 DDP(Distributed Data Parallel) 활용 실습
     - **Week 7**: 모델 병렬화와 성능 최적화 실습, 병렬 학습의 성능 이슈 해결
   - **리소스**:
     - [PyTorch Distributed Training 튜토리얼](https://pytorch.org/tutorials/intermediate/ddp_tutorial.html)
     - AWS 또는 GCP 환경에서 Multi-GPU 연습 환경 구축

### 4. **딥러닝 모델 학습 경험 (PyTorch or JAX)** (3주)
   - **필수 기술**: PyTorch 및 JAX 기반 딥러닝 모델 구조 설계와 학습
   - **목표**: PyTorch/JAX로 언어 모델을 학습하고, 최적화할 수 있는 능력 함양
   - **학습 경로**:
     - **Week 8**: PyTorch 모델 구성 및 실습 (RNN, CNN, 트랜스포머 모델 등)
     - **Week 9**: JAX 기본기 다지기 및 언어 모델 적용 (모델 구조 정의, 데이터 로딩, 학습 과정 설계)
