# DFS Tree Diameter Calculation

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2024-11-27

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 코드는 **트리의 지름**을 찾는 알고리즘으로, **깊이 우선 탐색(DFS)**를 두 번 수행하여 트리의 지름(가장 먼 두 노드 간의 거리)을 계산합니다. 주요 단계와 동작 방식을 다음과 같이 설명할 수 있습니다:

---

### 1. **트리의 지름 정의**
- 트리의 지름은 트리에서 **가장 먼 두 노드 사이의 거리**입니다.
- 이를 구하기 위해 트리의 구조를 그래프로 표현하고 DFS를 활용합니다.

---

### 2. **DFS 함수 설명**

#### 입력:
- `n`: 트리의 총 노드 개수.
- `e`: DFS를 시작할 노드.
- `flag`: 반환 값을 결정하는 플래그.  
  - `True`: 가장 먼 노드의 **인덱스** 반환.
  - `False`: 가장 먼 노드까지의 **거리** 반환.

#### 동작:
1. **거리 초기화**:
   - `distance` 배열은 각 노드의 방문 여부와 해당 노드까지의 거리를 저장합니다.
   - 초기값은 `-1`로 설정하여 방문하지 않았음을 나타냅니다.

2. **DFS를 위한 스택**:
   - 스택을 이용해 DFS를 수행합니다.
   - 초기에는 시작 노드 `e`와 초기 거리 `0`이 스택에 들어갑니다.

3. **스택을 이용한 탐색**:
   - 스택이 빌 때까지 현재 노드와 거리를 꺼내서 탐색합니다.
   - 탐색 중 현재 노드와 연결된 모든 인접 노드에 대해:
     - 방문하지 않은 노드라면, 스택에 해당 노드와 누적 거리를 추가합니다.

4. **결과 반환**:
   - `flag == True`: 가장 먼 노드의 **인덱스**를 반환.
   - `flag == False`: 가장 먼 노드까지의 **거리**를 반환.

---

### 3. **트리의 입력 처리**
- 트리는 **인접 리스트**로 표현됩니다:
  - 각 노드는 `(인접 노드, 간선 가중치)` 형태로 연결 정보를 저장합니다.
  - 양방향 연결이므로, 입력 데이터를 통해 양방향으로 인접 리스트를 생성합니다.

---

### 4. **트리의 지름 계산 과정**
1. **첫 번째 DFS**:
   - 루트 노드(`1`)에서 시작하여 가장 먼 노드(`A`)를 찾습니다.
   - `dfs(n, 1, True)` 호출:
     - `flag == True`이므로 루트 노드에서 가장 먼 노드의 **인덱스**를 반환합니다.

2. **두 번째 DFS**:
   - 가장 먼 노드(`A`)에서 다시 DFS를 수행하여 그로부터 가장 먼 노드(`B`)까지의 거리를 구합니다.
   - `dfs(n, A, False)` 호출:
     - `flag == False`이므로 가장 먼 노드까지의 **거리**를 반환합니다.

3. **결과 출력**:
   - 두 번째 DFS의 결과가 트리의 지름입니다.

---

### 5. **예제 실행**

#### 입력 예제:
```
5
1 2 3
2 3 4
3 4 5
3 5 2
```

#### 과정:
1. 그래프 표현:
   ```
   1 -3-> 2 -4-> 3 -5-> 4
               \-2-> 5
   ```

2. 첫 번째 DFS (`dfs(n, 1, True)`):
   - 노드 `1`에서 시작하여 가장 먼 노드 `4`를 반환.

3. 두 번째 DFS (`dfs(n, 4, False)`):
   - 노드 `4`에서 시작하여 가장 먼 노드까지의 거리 `12`를 계산.

#### 출력:
```
12
```

---

### 6. **시간 복잡도**
- 각 DFS는 한 번의 트리 탐색을 수행하며, 모든 노드를 한 번씩 방문하므로 **O(N)**.
- DFS를 두 번 수행하므로 전체 복잡도는 **O(N)**.

---

이 코드의 핵심 아이디어는 **가장 먼 노드에서 다시 DFS를 수행하면 트리의 지름이 계산된다**는 점입니다.

---

### ❓ 질문 (User)
```
# 깊이 우선 탐색(DFS)을 사용하여 트리의 지름을 찾는 함수
# n: 노드의 총 개수, e: 시작 노드, flag: 최대 거리 노드 찾기 여부를 결정하는 플래그
def dfs(n, e, flag) :
    # 모든 노드의 거리를 -1로 초기화 (방문하지 않은 상태)
    distance = [-1] * (n + 1)
    
    # 스택에 시작 노드와 초기 거리(0) 추가
    stack = [(e, 0)]
    
    # 스택이 빌 때까지 탐색 진행
    while stack :
        # 현재 노드와 현재까지의 거리를 스택에서 pop
        e, d = stack.pop()
        
        # 현재 노드의 거리 갱신
        distance[e] = d
        
        # 현재 노드와 연결된 모드 인접 노드 탐색
        for node, weight in graph[e] :
            # 아직 방문하지 않은 노드인 경우
            if distance[node] == -1 :
                # 스택에 인접 노드와 거리 추가 (현재 거리 + 간선 가중치)
                stack.append((node, d + weight))
    
    # flag가 True일 경우: 가장 먼 노드의 인덱스 반환
    if flag :
        x = 0
        for i in range(1, n + 1) :
            # 현재까지 가장 먼 노드 찾기
            if distance[x] < distance[i] :
                x = i
        return x
    
    # flag가 False일 경우: 최대 거리 반환
    return max(distance)

# 트리의 노드 개수 입력
n = int(input())

# 그래프를 인접 리스트로 초기화
graph = [[] for _ in range(n + 1)]

# 트리의 간선 정보 입력 (부모-자식-가중치)
for _ in range(1, n) :
    parent, child, weight = map(int, input().split())
    # 양방향 그래프로 간선 추가
    graph[parent].append((child, weight))
    graph[child].append((parent, weight))

# 트리의 지름 계산
# 1. 첫 번째 DFS로 트리에서 가장 먼 노드 찾기
# 2. 그 노드에서 다시 DFS를 수행하여 트리의 지름 계산
print(dfs(n, dfs(n, 1, True), False))
```
