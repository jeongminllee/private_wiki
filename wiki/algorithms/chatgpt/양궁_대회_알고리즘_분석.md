## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 코드는 라이언( lion )과 어피치( apeach )가 참여하는 양궁대회 문제에서, 라이언이 최대 점수 차이로 승리할 수 있도록 화살을 분배하는 최적의 경우를 찾기 위한 깊이 우선 탐색(DFS) 알고리즘을 구현한 예제입니다. 이 문제는 주어진 화살 개수(n)와 어피치의 과녁 당 화살 배분(info)을 바탕으로 라이언이 특정 점수를 얻기 위해 필요한 최소 화살 수를 계산하고, 여러 경우의 수 중 최대 점수 차이를 내는 배분을 선택하는 문제로 구성되어 있습니다. 아래 각 함수와 알고리즘의 동작 원리를 상세히 분석해보겠습니다.

---

## 함수별 분석

### 1. `calcPoint(apeach, lion)`
- **역할:**  
  라이언과 어피치의 화살 배분 정보를 받아 각 선수의 총 점수를 계산하고, 그 차이(라이언 점수 - 어피치 점수)를 반환합니다.

- **세부 과정:**  
  - **반복문 (for i in range(11)):**  
    11개의 점수 구간(10점부터 0점까지)에 대해 순회합니다.
    
  - **조건 검사:**  
    - 만약 어피치와 라이언 모두 해당 구간에 화살이 없으면(`apeach[i] == lion[i] == 0`), 그 구간은 무시합니다.
    
    - 만약 어피치의 화살 수가 라이언보다 많거나 같으면(`apeach[i] >= lion[i]`), 어피치가 그 구간의 점수(10-i 점)를 획득합니다.
    
    - 그렇지 않으면(`lion[i] > apeach[i]`), 라이언이 해당 구간의 점수를 획득합니다.
    
  - **최종 반환:**  
    라이언 점수에서 어피치 점수를 뺀 값을 반환합니다. (즉, 라이언이 이겼을 경우 양수, 졌을 경우 음수 또는 0)

### 2. `DFS(idx, n, apeach, lion)`
- **역할:**  
  깊이 우선 탐색(DFS)을 통해 11개의 점수 구간에 대해 라이언의 화살 배분 경우의 수를 탐색합니다. 매 단계마다 해당 점수 구간에서 어피치를 이기기 위한 최소 화살 수(`apeach[점수구간] + 1`)를 투입하거나, 투입하지 않는 선택지를 재귀적으로 탐색합니다.

- **매개변수 설명:**  
  - `idx`: 현재 고려 중인 점수 구간의 순서 (0부터 시작하여 10까지).  
    단, 코드 내부에서는 실제 인덱스 계산 시 `10 - idx`로 변환되어 사용되므로, 실제 고려하는 점수는 높은 점수(10점)부터 낮은 점수(0점) 순입니다.
    
  - `n`: 남은 화살의 개수.
  - `apeach`: 어피치가 각 구간에 맞춘 화살의 개수를 저장한 리스트.
  - `lion`: 현재까지 라이언이 할당한 화살 배분을 기록한 리스트.

- **구현 상세:**  
  1. **남은 화살 초과 처리:**  
     - 만약 `n < 0`이면, 현재 배분 방법은 유효하지 않으므로 바로 리턴합니다.
  
  2. **기저 조건 (idx > 10):**  
     - 모든 11구간(인덱스 0~10)을 처리한 경우, `calcPoint`를 호출해 현재 배분으로 인한 점수 차이(diff)를 계산합니다.
     - 만약 diff가 0 이하이면(즉, 라이언이 승리하지 못하면) 해당 경우를 버립니다.
     - diff가 현재까지의 최대 점수 차이(`point`)보다 크다면, 전역 변수 `point`와 `answer`를 갱신합니다.
       - **남은 화살 처리:**  
         만약 재귀 종료시 아직 남은 화살이 있다면 `answer[10]` (0점 구간)에 추가하여 모든 화살을 소진하는 방식으로 처리합니다.
  
  3. **재귀 탐색 (두 가지 선택지):**  
     - **첫 번째 선택 (해당 구간 승리):**  
       현재 고려하는 점수 구간(`10-idx`)에서 라이언이 어피치를 이기기 위해서는, 어피치가 맞춘 화살의 개수보다 1만 더 많이 쏘아야 합니다.  
       따라서, `lion[10-idx] = apeach[10-idx] + 1`로 설정한 후, 남은 화살 수를 빼고 다음 구간(idx+1)으로 재귀 호출합니다.
     
     - **두 번째 선택 (해당 구간 포기):**  
       현재 구간에 아무런 화살도 넣지 않고(`lion[10-idx] = 0`), 다음 구간으로 넘어가 재귀 호출합니다.

### 3. `solution(n, info)`
- **역할:**  
  주어진 총 화살 개수 `n`과 어피치의 화살 배분 리스트 `info`를 바탕으로, 라이언이 승리할 수 있는 최적의 화살 분배 방식(`answer`)을 찾아 반환합니다.

- **구현 상세:**  
  - 전역 변수 `answer`를 `[-1]`로 초기화합니다. 이는 라이언이 승리할 수 있는 배분이 없을 경우 -1을 반환하기 위함입니다.
  - 전역 변수 `point`를 0으로 초기화하여 현재까지 발견한 최대 점수 차이를 기록합니다.
  - DFS 함수(`DFS(0, n, info, [0 for _ in range(11)])`)를 호출하여 탐색을 시작합니다.
  - DFS를 통해 갱신된 `answer`를 반환합니다.

## 알고리즘의 핵심 아이디어 및 문제 풀이 맥락

- **문제 배경:**  
  이 문제는 보통 "양궁대회" 또는 "양궁" 문제로 알려져 있으며, 두 선수 간의 점수 승부를 위해 각 점수 구간에 할당할 화살을 결정해야 하는 문제입니다. 어피치는 이미 특정 방식으로 화살을 맞춘 상태이며, 라이언은 이를 이기기 위해 특정 구간에 필요한 최소 화살 수(어피치의 수 + 1)를 할당할 수 있습니다.

- **탐색 전략:**  
  DFS를 사용하여 11개의 점수 구간 각각에 대해 "이기는 경우"와 "포기하는 경우"의 두 가지 경우의 수를 모두 탐색합니다.  
  이 때, 중요한 점은 모든 가능한 배분을 고려하면서도 남은 화살의 수가 음수가 되지 않도록 관리하고, 모든 화살을 사용하여 최종 배분을 완성하는 것입니다.
  
- **최적 해 선택:**  
  DFS 종료 시 라이언이 승리하는 경우(diff > 0)를 체크하고, 그 중에서 최대 점수 차이를 내는 경우를 기록합니다.  
  만약 여러 경우가 동일한 최대 차이를 낸다면, 문제 조건에 따라 우선순위를 부여할 수 있으나 코드에서는 단순히 처음 발견한 큰 점수 차이가 나오면 그 배분을 채택하게 됩니다.
  
- **남은 화살 처리:**  
  DFS의 기저 조건에서 남은 화살이 남았을 경우(예: n이 0보다 크면), 0점 구간에 추가하여 모든 화살을 사용하도록 만듭니다.

## 결론

이 코드는 양궁대회 문제에서 라이언의 최적 화살 분배 방법을 찾기 위한 전형적인 DFS(깊이 우선 탐색) 접근법을 보여줍니다.  
- `calcPoint` 함수로 두 선수의 점수를 계산하고,  
- `DFS` 함수로 모든 가능한 경우를 탐색하며 (각 구간에서 승리할 것인지, 포기할 것인지의 두 가지 경우),  
- `solution` 함수에서 초기 조건을 세팅 후 DFS를 호출하여 최종 배분 방법을 반환합니다.

이러한 구조 덕분에 주어진 화살 개수와 어피치의 배분 정보가 있을 때, 라이언이 이길 수 있는 최대 점수 차이를 구현할 수 있는 최적의 배분을 찾을 수 있습니다.

### ❓ 질문 (User)
```
def calcPoint(apeach, lion) :
    apeach_score = 0
    lion_score = 0
    for i in range(11) :
        if apeach[i] == lion[i] == 0 :
            continue
        if apeach[i] >= lion[i] :
            apeach_score += 10 - i
        else :
            lion_score += 10 - i
    return lion_score - apeach_score

def DFS(idx, n, apeach, lion) :
    global answer, point
    if n < 0 :
        return 
    
    if idx > 10 :
        diff = calcPoint(apeach, lion)
        if diff <= 0 :
            return
        if diff > point :
            point = diff
            answer = [lion[i] for i in range(11)]
            answer[10] += n
        return
    
    lion[10-idx] = apeach[10-idx] + 1
    DFS(idx + 1, n-lion[10-idx], apeach, lion)
    lion[10 - idx] = 0
    DFS(idx+1, n , apeach, lion)


def solution(n, info):
    global answer, point
    answer = [-1]
    point = 0
    DFS(0, n, info, [0 for _ in range(11)])
    return answer
```
