# BFS and Wall Placement

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
from collections import deque
from copy import deepcopy

# 상하좌우 이동을 위한 방향 벡터
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]


def bfs():
    global answer
    q = deque()
    maps = deepcopy(arr)  # 원본 배열을 변경하지 않기 위해 깊은 복사

    # 초기 바이러스 위치를 큐에 삽입
    for i in range(N):
        for j in range(M):
            if maps[i][j] == 2:
                q.append((i, j))

    # BFS로 바이러스 확산
    while q:
        x, y = q.popleft()
        for d in range(4):  # 4방향 탐색
            nx, ny = x + dx[d], y + dy[d]

            # 맵 범위 내이고 빈 칸인 경우
            if 0 <= nx < N and 0 <= ny < M and maps[nx][ny] == 0:
                maps[nx][ny] = 2  # 바이러스 확산
                q.append((nx, ny))

    # 안전 영역(0) 개수 세기
    cnt_0 = 0
    for i in range(N):
        cnt_0 += maps[i].count(0)

    # 최대 안전 영역 크기 갱신
    answer = max(answer, cnt_0)


def makeWall(cnt=0):
    if cnt == 3:  # 벽 3개를 모두 세웠으면
        bfs()  # 바이러스 확산 시뮬레이션 실행
        return
    for i in range(N):
        for j in range(M):
            if arr[i][j] == 0:  # 빈 칸인 경우
                arr[i][j] = 1  # 벽 세우기
                makeWall(cnt + 1)  # 재귀적으로 다음 벽 세우기
                arr[i][j] = 0  # 백트래킹: 벽 다시 제거


# 입력 받기
N, M = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(N)]
answer = 0

# 모든 가능한 벽 조합 시도
makeWall()

# 결과 출력
print(answer)
```
이 코드에 대해서 분석해주고 시간복잡도와 공간복잡도에 대해서 설명해줘

### 💡 답변 (Assistant)
이 코드는 BFS를 이용하여 바이러스 확산을 시뮬레이션하고, 벽을 세워 최대한 많은 안전 영역(빈 칸)을 확보하는 문제를 해결하는 프로그램입니다. 주로 백트래킹과 BFS를 사용하여 모든 경우의 수를 탐색합니다.

### 코드 분석

1. **상하좌우 이동을 위한 방향 벡터 정의:**
   ```python
   dx = [-1, 1, 0, 0]
   dy = [0, 0, -1, 1]
   ```

2. **BFS 함수 정의:**
   - 이 함수는 바이러스의 확산을 시뮬레이션합니다.
   - 초기 바이러스 위치를 큐에 넣고, BFS로 바이러스를 확산시킵니다.
   - 바이러스가 확산된 후 남아 있는 안전 영역의 크기를 계산하여 최대값을 갱신합니다.

3. **벽 세우기 함수 정의:**
   - `makeWall(cnt=0)` 함수는 재귀적으로 벽을 세웁니다.
   - 벽이 3개 세워지면 BFS를 호출하여 바이러스 확산을 시뮬레이션합니다.
   - 모든 경우의 수를 시도하기 위해 백트래킹을 사용하여 벽을 세우고 제거합니다.

4. **입력 받기 및 초기화:**
   - 사용자로부터 맵의 크기(N, M)와 맵의 정보를 입력 받습니다.
   - 초기 최대 안전 영역 크기를 저장할 변수를 0으로 초기화합니다.

5. **벽 세우기 시도 및 결과 출력:**
   - 모든 가능한 벽 조합을 시도하여 최대 안전 영역 크기를 구합니다.
   - 최종 결과를 출력합니다.

### 시간 복잡도

벽을 세우는 모든 경우의 수를 시도하고, 각 경우마다 BFS를 실행하기 때문에 시간 복잡도는 다음과 같이 분석할 수 있습니다:

1. **벽 세우기:**
   - 벽 3개를 세우는 모든 조합을 시도합니다.
   - 맵의 크기가 N x M일 때, 벽 3개를 세우는 경우의 수는 대략적으로 O((N * M)^3)입니다.

2. **BFS:**
   - BFS의 시간 복잡도는 맵의 크기에 비례합니다.
   - 맵의 모든 칸을 한번씩 방문하기 때문에 O(N * M)입니다.

종합적으로, 시간 복잡도는 대략 O((N * M)^3 * N * M) = O(N^4 * M^4)입니다. 이는 매우 큰 값이 될 수 있으며, 입력 크기가 커질수록 실행 시간이 급격히 증가합니다.

### 공간 복잡도

1. **맵 저장 공간:**
   - 맵을 저장하는 데 O(N * M)의 공간이 필요합니다.

2. **큐를 위한 공간:**
   - BFS 과정에서 사용할 큐의 최대 크기는 O(N * M)입니다.

3. **재귀 호출 스택:**
   - 벽을 세우는 재귀 호출의 깊이는 최대 3입니다.
   - 따라서 재귀 호출로 인한 추가적인 공간은 O(3)입니다.

종합적으로, 공간 복잡도는 O(N * M)입니다.

### 결론

이 프로그램은 모든 가능한 벽 조합을 시도하여 최대 안전 영역을 구하는 문제를 해결합니다. 시간 복잡도는 입력 크기가 커질수록 매우 커지므로, 최적화가 필요한 경우에는 더 효율적인 알고리즘을 고려해야 할 수 있습니다. 공간 복잡도는 맵의 크기에 비례하며, 비교적 적은 메모리 사용량을 가집니다.
