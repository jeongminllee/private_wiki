## ✅ 1. 디버깅 목적에 맞게 숫자 변경

파이썬은 `print(Solution().reverseBits(00000010100101000001111010011100))`처럼 **0으로 시작하는 숫자 리터럴**을 허용하지 않습니다.  
이진수는 `0b` 접두사를 붙여 표현해야 하므로, 아래처럼 수정해야 합니다:

```python
print(Solution().reverseBits(0b00000010100101000001111010011100))
```

---

## ✅ 2. 디버깅용 `print()` 삽입

다음은 각 반복에서 `res`와 `n`의 상태를 비트로 출력해보는 예입니다.

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0

        for i in range(32):
            res = res << 1
            res += n & 1
            print(f"[{i+1:2}] n bit: {n & 1} | res: {format(res, '032b')} | n: {format(n, '032b')}")
            n >>= 1

        return res

# 테스트
n = 0b00000010100101000001111010011100
result = Solution().reverseBits(n)
print(f"Result in decimal: {result}")
print(f"Result in binary : {format(result, '032b')}")
```

## ✅ 출력 예시

이 코드를 실행하면 다음과 같은 정보를 얻을 수 있습니다:

- 현재 몇 번째 반복인지 (`i`)
- 현재 `n`의 마지막 비트 (`n & 1`)
- 현재 `res` 값이 어떻게 변화하고 있는지 (`format(res, '032b')`로 32비트 이진 문자열로 출력)
- `n` 값도 이진수로 출력

---

## ✅ 디버깅 시 핵심 포인트

- `res <<= 1` : 왼쪽으로 한 칸 이동 (기존 결과의 자리를 확보)
- `res += n & 1` : `n`의 마지막 비트를 `res`에 추가
- `n >>= 1` : `n`의 다음 비트를 위해 오른쪽으로 한 칸 이동

## 🧩 문제 설명

**32비트 부호 없는 정수 `n`이 주어졌을 때, 그 비트 순서를 반대로 바꿔서 반환하라.**

예를 들어:

- 입력:  
  `00000010100101000001111010011100`  
- 출력:  
  `00111001011110000010100101000000`

이 숫자는 각각 10진수로 표현하면:

```text
입력:  43261596
출력: 964176192
```

---

## ✅ 핵심 아이디어

우리는 `n`의 **오른쪽 끝 비트부터 하나씩 뽑아서**, 결과값 `res`의 **왼쪽부터 채워넣는** 작업을 32번 반복해야 합니다.

1. 결과값 `res`를 0으로 초기화
2. 반복문을 32번 돌면서:
   - `res`를 왼쪽으로 1비트 쉬프트해서 빈 공간 확보
   - `n`의 마지막 비트 (`n & 1`)를 `res`에 추가
   - `n`을 오른쪽으로 1비트 쉬프트해서 다음 비트 준비

---

## ✅ 파이썬 코드

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0
        for _ in range(32):
            res <<= 1         # 결과값을 왼쪽으로 쉬프트
            res |= n & 1      # n의 마지막 비트를 res에 추가
            n >>= 1           # n을 오른쪽으로 쉬프트해서 다음 비트로
        return res
```

---

## ✅ 예제 실행

입력:

```python
n = 0b00000010100101000001111010011100
```

실행:

```python
result = Solution().reverseBits(n)
print(result)                     # 964176192
print(format(result, '032b'))     # 00111001011110000010100101000000
```

---

## ✅ 시간 복잡도

- 반복문 32회 → **O(1)**  
- 항상 고정된 비트 수(32비트)이므로 입력 크기에 비례하지 않음

---

## ✨ 보충 설명

- `res <<= 1` : `res`의 비트를 왼쪽으로 한 칸 이동해서 공간 확보
- `res |= n & 1` : `n`의 가장 오른쪽 비트를 가져와서 `res`의 가장 오른쪽에 추가
- `n >>= 1` : `n`의 다음 비트를 뽑기 위해 오른쪽으로 이동

## 🧩 문제 설명

> **Given** a 32-bit unsigned integer `n`, **reverse its bits** and return the result as an unsigned integer.

즉, `n`의 이진 표현에서 **비트 순서를 거꾸로 바꿔서** 정수로 다시 리턴해야 합니다.

예시:

```
입력:  00000010100101000001111010011100 (10진수로 43261596)
출력:  00111001011110000010100101000000 (10진수로 964176192)
```

---

## 🧠 핵심 아이디어

- 비트를 1비트씩 꺼내서 결과에 **역순으로** 밀어넣는 방식
- 총 32비트이므로, **32번** 반복하며 처리

---

## ✅ 파이썬 풀이

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0
        for _ in range(32):
            res <<= 1          # 결과값을 왼쪽으로 한 칸 이동
            res |= (n & 1)     # n의 마지막 비트를 결과값의 마지막에 추가
            n >>= 1            # n을 오른쪽으로 한 칸 이동
        return res
```

---

## 🔍 예제 설명

입력값:  
```
n = 0b00000010100101000001111010011100
   = 43261596
```

1. `res = 0`에서 시작
2. n의 마지막 비트(`n & 1`)를 꺼내서 res의 맨 뒤에 추가
3. res를 한 칸 왼쪽으로 밀고, n은 한 칸 오른쪽으로 밀기
4. 이걸 32번 반복

결과는:
```
res = 0b00111001011110000010100101000000
     = 964176192
```

## 🔧 `n & 1`의 의미

`&`는 **비트 AND 연산자**입니다.

즉, `n & 1`은:

> n의 **가장 오른쪽 비트(least significant bit)** 가 **1인지 0인지** 확인하는 표현입니다.

---

### ✅ 예시 1: n = 13 (이진수: `1101`)

```text
n     = 1101
1     = 0001
--------------
n & 1 = 0001 (== 1)
```

→ 결과: **1**  
→ 이는 `n`의 **마지막 비트가 1**이라는 뜻입니다.

---

### ✅ 예시 2: n = 8 (이진수: `1000`)

```text
n     = 1000
1     = 0001
--------------
n & 1 = 0000 (== 0)
```

→ 결과: **0**  
→ 이는 `n`의 **마지막 비트가 0**이라는 뜻입니다.

---

## 🔄 왜 이걸 쓰나요?

`n & 1`을 통해:

- `n`의 **맨 끝 비트**가 1이면 → `1` (즉, 홀수)
- `n`의 **맨 끝 비트**가 0이면 → `0` (즉, 짝수)

---

## 🧠 잘못된 이해: `n == 1`이면 True?

`n & 1`은 `n == 1`일 때만 1이 나오는 게 아니라,
**`n`의 마지막 비트가 1이면 언제든 1이 나옵니다.**

즉,

| n (10진수) | n (2진수) | `n & 1` 결과 | 의미       |
|------------|-----------|--------------|------------|
| 1          | `0001`    | 1            | 마지막 비트 1 |
| 3          | `0011`    | 1            | 마지막 비트 1 |
| 7          | `0111`    | 1            | 마지막 비트 1 |
| 2          | `0010`    | 0            | 마지막 비트 0 |
| 8          | `1000`    | 0            | 마지막 비트 0 |

---

## 🔍 요약

| 표현       | 의미                              |
|------------|-----------------------------------|
| `n & 1`    | `n`의 마지막 비트가 1인지 검사     |
| `== 1`     | 정확히 `n`이 1일 때만 True         |
| `n & 1 == 1` | `n`이 홀수인지 검사 (마지막 비트가 1인지) |
| `n & 1 == 0` | `n`이 짝수인지 검사 (마지막 비트가 0인지) |

## 🔹 `<<` : **왼쪽 시프트 (Left Shift)**

> `n << k` : `n`의 **비트들을 왼쪽으로 k칸 밀고**, **오른쪽 빈 자리는 0으로 채운다**.

### 🧪 예시

```python
n = 5        # 이진수: 0000 0101
n << 1       #       => 0000 1010
```

- 10진수 결과: `5 << 1` → `10`
- 왼쪽으로 1칸 밀면, 값은 **2배**가 됩니다.

📌 **패턴**
```text
n << k  →  n × 2^k
```

---

## 🔹 `>>` : **오른쪽 시프트 (Right Shift)**

> `n >> k` : `n`의 **비트들을 오른쪽으로 k칸 밀고**, **왼쪽 빈 자리는 0으로 채운다 (부호 없는 정수일 경우)**.

### 🧪 예시

```python
n = 5        # 이진수: 0000 0101
n >> 1       #       => 0000 0010
```

- 10진수 결과: `5 >> 1` → `2`
- 오른쪽으로 1칸 밀면, 값은 **반으로 나눈 몫**이 됩니다.

📌 **패턴**
```text
n >> k  →  n // 2^k
```

---

## 🔸 표로 비교해 보기

| 표현       | 비트 예시 (`n = 0000 0101`) | 결과 비트 | 결과 값 | 의미           |
|------------|------------------------------|------------|-----------|----------------|
| `n << 1`   | `0000 0101` → `0000 1010`     | 10         | 2배        |
| `n << 2`   | `0000 0101` → `0001 0100`     | 20         | 4배        |
| `n >> 1`   | `0000 0101` → `0000 0010`     | 2          | //2        |
| `n >> 2`   | `0000 0101` → `0000 0001`     | 1          | //4        |

  하지만 LeetCode 190번은 **부호 없는 정수**가 전제이므로 걱정할 필요는 없습니다.
