## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
좋다, 이 코드는 꽤 “시스템적으로 잘 짜인” 모바일 베이스(4륜) 제어 코드야. 단순 코드 설명이 아니라 **실행 흐름 + 데이터 흐름 중심으로 도식화** 해줄게.

---

# 📌 전체 구조 (Top-Level Flow)

```
[전역 설정]
 ├─ 모터 ID 정의 (FL, FR, BL, BR)
 ├─ 통신 설정 (Serial1, Protocol 2.0)
 ├─ SyncWrite 구조체 준비
 └─ 속도 데이터 버퍼(sw_data)

        ↓

[setup()]
 ├─ 시리얼 시작
 ├─ Dynamixel 통신 초기화
 ├─ 모터 탐색 (FindMobileBaseServos)
 ├─ 각 모터 설정
 │    ├─ Torque OFF
 │    ├─ Drive Mode 설정 (좌: 정방향 / 우: 역방향)
 │    ├─ Operating Mode 설정
 │    └─ Torque ON
 └─ SyncWrite 구조 초기화

        ↓

[loop()]  ← 반복 실행
 ├─ 속도 설정 (앞 바퀴 전진)
 ├─ syncWrite 실행
 ├─ delay
 ├─ 속도 설정 (앞 바퀴 후진)
 ├─ syncWrite 실행
 ├─ delay
 ├─ 정지
 ├─ 뒤 바퀴 전진
 ├─ 뒤 바퀴 후진
 └─ 정지
```

---

# 🔧 setup() 상세 도식

```
[setup 시작]

   ↓
Serial.begin()

   ↓
dxl.begin()
dxl.setProtocol()

   ↓
[모터 탐색 루프]
while (!FindMobileBaseServos())
    반복

   ↓
[모터 초기화 루프]
for each motor ID:
    Torque OFF
    Drive Mode 설정
        좌측 → NORMAL
        우측 → REVERSE
    Operating Mode 설정
    Torque ON

   ↓
[SyncWrite 초기화]
 ├─ 주소 설정 (104)
 ├─ 데이터 크기 (4 bytes)
 ├─ 모터 리스트 등록
 └─ velocity = 0 초기화

[setup 종료]
```

# 🔁 loop() 동작 시퀀스 (핵심)

이 부분이 실제 “로봇 움직임 시나리오”야.

```
(1) 앞바퀴 전진
SetVelocity(FL+, FR+, BL=0, BR=0)
 → syncWrite

(2) 앞바퀴 후진
SetVelocity(FL-, FR-, BL=0, BR=0)
 → syncWrite

(3) 전체 정지
SetVelocity(0,0,0,0)

(4) 뒷바퀴 전진
SetVelocity(0,0, BL+, BR+)

(5) 뒷바퀴 후진
SetVelocity(0,0, BL-, BR-)

(6) 정지
SetVelocity(0,0,0,0)
```

👉 즉,
- 앞 바퀴만 움직임
- 뒤 바퀴만 움직임  
→ 테스트용 시퀀스

# ⚙️ 핵심 데이터 흐름 (진짜 중요)

## 1. 속도 설정 함수

```
SetMobileGoalVelocityForSyncWrite(...)
   ↓
sw_data[i].goal_velocity 에 값 저장
   ↓
sw_infos.is_info_changed = true
```

---

## 2. syncWrite 동작

```
dxl.syncWrite(&sw_infos)
   ↓
sw_data 배열에 있는 값들을
   ↓
모든 모터(ID 1~4)에 동시에 전송
```

👉 핵심:
- **병렬 제어 (동기화)**
- 각각 write 안 하고 한 번에 보냄

---

# 🔍 FindMobileBaseServos() 도식

```
Broadcast Ping
   ↓
응답 받은 ID 리스트 확보

   ↓
필요한 ID들과 비교
   ├─ 모두 존재 → true
   └─ 하나라도 없음 → false + 에러 출력
```

👉 역할:
- 모터 연결 확인 (하드웨어 체크)

# 🔥 이 코드의 핵심 포인트 (시험/실무 관점)

### 1. SyncWrite 사용
- 여러 모터를 **동시에 제어**
- 로봇에서 필수

---

### 2. Drive Mode 분리
```
좌측: NORMAL
우측: REVERSE
```
👉 이유:
- 바퀴 방향이 반대라서

---

### 3. 구조체 기반 데이터 전송
```
sw_data_t
```
👉 low-level 제어 느낌 (임베디드 특징)

---

### 4. 안전한 초기화 순서
```
Torque OFF → 설정 → Torque ON
```
