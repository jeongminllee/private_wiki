### 💡 답변 (Assistant)
"트라이(Trie)"는 문자열을 저장하고 검색하는 데 효율적인 **트리(Tree) 구조**의 자료구조야. 특히 **문자열 탐색이 빠른 자동완성, 사전(Dictionary), 접두사 검색(Prefix Search)** 같은 기능을 구현할 때 많이 사용돼.

---

### 🔹 **트라이(Trie)의 개념**
트라이는 각 노드가 하나의 문자(character)를 저장하는 **트리 형태의 자료구조**야. 문자열을 저장할 때, **공통된 접두사(prefix)를 공유하도록 구성**되기 때문에 효율적인 검색이 가능해.

예를 들어, 다음 단어들이 있다고 해보자.

- "cat"
- "cap"
- "can"
- "dog"

이걸 트라이로 표현하면 이렇게 돼:

```
(root)
 ├── c
 │   ├── a
 │   │   ├── t (end)
 │   │   ├── p (end)
 │   │   ├── n (end)
 ├── d
     ├── o
         ├── g (end)
```

각 단어의 끝을 표시하기 위해 특별한 `end` 표시를 추가할 수도 있어.

---

### 🔹 **트라이(Trie)의 주요 연산**
1. **삽입(Insert)**
   - 문자열을 하나씩 노드에 추가해 가면서 저장.
   - 중복되는 접두사는 공유하여 메모리를 절약.

2. **검색(Search)**
   - 루트에서 시작해 한 글자씩 따라가며 단어가 존재하는지 확인.

3. **삭제(Delete)**
   - 단어의 마지막 노드를 찾아 제거하고, 필요하면 부모 노드도 정리.

4. **접두사 검색(Prefix Search)**
   - 특정 접두사로 시작하는 모든 단어를 빠르게 찾을 수 있음.
   - 예를 들어, "ca"로 시작하는 단어를 찾으면 ["cat", "cap", "can"]을 쉽게 검색 가능.

---

### 🔹 **트라이(Trie)의 시간복잡도**
트라이의 핵심 강점은 **검색 속도가 O(N)** 이라는 점이야. 여기서 N은 찾고자 하는 문자열의 길이야.

- **삽입(Insert):** O(N)
- **검색(Search):** O(N)
- **삭제(Delete):** O(N)

일반적인 해시맵(HashMap)은 O(1)에 가깝지만, 해시 충돌이 발생할 경우 성능이 저하될 수 있어. 반면, **트라이는 해시 충돌 없이 일정한 성능을 보장**하는 특징이 있어.

---

### 🔹 **트라이(Trie)의 활용 예시**
1. **자동완성(Auto-complete)**
   - 키보드 입력 시, 트라이를 사용하면 접두사 검색을 통해 추천 단어를 빠르게 찾을 수 있어.

2. **사전(Dictionary) 구현**
   - 단어를 효율적으로 저장하고 검색하는 데 활용됨.

3. **검색 엔진에서 키워드 검색**
   - 특정 키워드가 포함된 문서를 빠르게 찾는 데 사용됨.

4. **IP 주소 라우팅**
   - 트라이 구조를 활용해 IP 주소를 계층적으로 저장하고 검색.

---

### 🔹 **트라이(Trie) 코드 예제 (Python)**
```python
class TrieNode:
    def __init__(self):
        self.children = {}  # 자식 노드 (문자별 저장)
        self.is_end = False  # 단어의 끝 여부

class Trie:
    def __init__(self):
        self.root = TrieNode()  # 루트 노드 초기화

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True  # 단어 끝 표시

    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end  # 단어가 존재하는지 확인

    def starts_with(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True  # 접두사가 존재하는지 확인

# 사용 예시
trie = Trie()
trie.insert("cat")
trie.insert("cap")
trie.insert("dog")

print(trie.search("cat"))  # True
print(trie.search("can"))  # False
print(trie.starts_with("ca"))  # True (cat, cap 존재)
```

---

### 🔹 **트라이 vs 해시맵(HashMap)**
|  | Trie | HashMap |
|---|---|---|
| **속도** | O(N) (문자열 길이에 비례) | O(1) (평균적) |
| **메모리 사용** | 더 큼 (노드 저장 필요) | 더 적음 |
| **접두사 검색** | O(N) (빠름) | O(N) (느림) |
| **정렬된 결과** | 가능 | 불가능 |

**👉 결론:**  
- **해시맵**: 특정 문자열의 존재 여부만 확인할 때 유리.
- **트라이**: **접두사 검색, 자동완성, 정렬된 결과가 필요할 때** 유리.

---

트라이는 **검색 속도가 빠르고, 접두사 검색이 가능하며, 자동완성 기능을 구현할 수 있는 강력한 자료구조**야! 😊
