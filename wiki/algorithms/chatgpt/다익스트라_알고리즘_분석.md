# 다익스트라 알고리즘 분석

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
from collections import defaultdict
import heapq

def dijkstra(start, edges) :
    distances = [float('inf')] * (N + 1)
    distances[start] = 0
    q = []
    heapq.heappush(q, [start, distances[start]])

    while q :
        current_node, current_distance = heapq.heappop(q)

        if distances[current_node] < current_distance :
            continue

        for adj, weight in edges[current_node] :
            dist = current_distance + weight

            if dist < distances[adj] :
                distances[adj] = dist
                heapq.heappush(q, [adj, dist])

    return distances


N, M, X = map(int, input().split())
edges = defaultdict(list)
r_edges = defaultdict(list)

for _ in range(M) :
    A, B, T = map(int, input().split())
    edges[A].append((B, T))
    r_edges[B].append((A, T))

to_x = dijkstra(X, edges)
from_x = dijkstra(X, r_edges)

ans = 0
for i in range(1, N + 1) :
    ans = max(ans, to_x[i] + from_x[i])

print(ans)
```
이 코드를 보고 분석해줘

### 💡 답변 (Assistant)
이 코드는 **다익스트라 알고리즘**을 활용해 **단방향 그래프**에서 최단 경로를 계산한 뒤, 특정 노드 \( X \)를 기준으로 **왕복 최단 시간**을 구하는 문제를 해결합니다.

---

### 1. **코드의 목적**
- 특정 노드 \( X \)에서 다른 노드까지의 왕복 시간을 계산한 후, **최대 왕복 시간**을 찾습니다.
- 주어진 조건:  
  \( N \): 노드의 수  
  \( M \): 간선의 수  
  \( X \): 기준이 되는 노드

---

### 2. **사용된 개념**
1. **다익스트라 알고리즘**  
   - 우선순위 큐 (`heapq`)를 사용하여 최단 경로를 계산합니다.
   - `edges`와 `r_edges`를 통해 **단방향 간선**을 저장합니다.

2. **그래프 구조**  
   - `edges`: **정방향 간선**을 저장 (출발 → 도착).  
   - `r_edges`: **역방향 간선**을 저장 (도착 → 출발).  

3. **왕복 시간 계산**  
   - \( X \)에서 다른 노드로 가는 시간 (`to_x`)  
   - 다른 노드에서 \( X \)로 오는 시간 (`from_x`)  
   - 두 값을 더해서 왕복 시간을 계산합니다.

---

### 3. **코드 흐름 분석**

1. **입력 처리**
   ```python
   N, M, X = map(int, input().split())
   edges = defaultdict(list)
   r_edges = defaultdict(list)

   for _ in range(M):
       A, B, T = map(int, input().split())
       edges[A].append((B, T))  # 정방향 간선
       r_edges[B].append((A, T))  # 역방향 간선
   ```
   - \( N \): 노드 개수  
   - \( M \): 간선 개수  
   - \( X \): 기준 노드  
   - `edges`에는 정방향 간선을 저장합니다.  
   - `r_edges`에는 역방향 간선을 저장합니다.  

2. **다익스트라 함수** (`dijkstra`)
   ```python
   def dijkstra(start, edges):
       distances = [float('inf')] * (N + 1)
       distances[start] = 0
       q = []
       heapq.heappush(q, [start, distances[start]])

       while q:
           current_node, current_distance = heapq.heappop(q)

           if distances[current_node] < current_distance:
               continue

           for adj, weight in edges[current_node]:
               dist = current_distance + weight

               if dist < distances[adj]:
                   distances[adj] = dist
                   heapq.heappush(q, [adj, dist])

       return distances
   ```
   - **거리 배열** `distances`를 초기화하고, **우선순위 큐**를 통해 최단 경로를 계산합니다.
   - 각 노드에서 인접한 노드를 탐색하며 최단 거리 업데이트 (`dist`).

3. **정방향 및 역방향 다익스트라 실행**
   ```python
   to_x = dijkstra(X, edges)  # 다른 노드 → X로 가는 최단 경로
   from_x = dijkstra(X, r_edges)  # X → 다른 노드로 가는 최단 경로
   ```

4. **최대 왕복 시간 계산**
   ```python
   ans = 0
   for i in range(1, N + 1):
       ans = max(ans, to_x[i] + from_x[i])
   print(ans)
   ```
   - 각 노드 \( i \)에서 \( X \)까지 왕복 시간 = `to_x[i]` + `from_x[i]`.
   - 최대 왕복 시간을 `ans`에 저장하고 출력합니다.

---

### 5. **시간 복잡도**
- **다익스트라 알고리즘**의 시간 복잡도: \( O(E \log V) \)  
   (\( E \): 간선 수, \( V \): 노드 수)  
- 정방향 다익스트라와 역방향 다익스트라를 각각 수행하므로:  
  \( O(2 \cdot E \log V) \) ≈ \( O(E \log V) \)

---

### 6. **핵심 포인트**
1. **정방향**과 **역방향** 그래프를 구분해서 최단 경로를 계산합니다.
2. **우선순위 큐**를 사용해 다익스트라의 효율성을 높였습니다.
3. 왕복 최단 경로를 계산하여 **최대 왕복 시간**을 구합니다.
