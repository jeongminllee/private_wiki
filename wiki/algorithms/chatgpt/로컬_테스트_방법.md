# 로컬 테스트 방법

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
        dummy = ListNode(-501)
        curr1 = dummy
        length = right - left + 1

        for _ in range(left) :
            curr1 = curr1.next

        curr2 = curr1
        stack = []

        for _ in range(length) :
            stack.append(curr1.val)
            curr1 = curr1.next

        while stack :
            v = stack.pop()
            curr2.val = v
            curr2 = curr2.next

        curr2 = curr2.next

        return dummy.next
```
Input: head = [1,2,3,4,5], left = 2, right = 4
Output: [1,4,3,2,5]

테스트 케이스 1번을 로컬에서 테스트 해보고 싶은데, 입력을 어떻게 해야될지 모르겠어.

### 💡 답변 (Assistant)
이 문제를 **로컬에서 테스트**하려면, LeetCode가 내부적으로 해주던 두 가지를 직접 구현해야 합니다.

1. `ListNode` 클래스 정의  
2. **파이썬 리스트 ↔ 연결 리스트 변환 코드**

아래 순서대로 하면 바로 실행할 수 있습니다.

---

## 1. ListNode 클래스 정의

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

---

## 2. 파이썬 리스트 → 연결 리스트 변환 함수

```python
def build_linked_list(values):
    dummy = ListNode(0)
    curr = dummy
    for v in values:
        curr.next = ListNode(v)
        curr = curr.next
    return dummy.next
```

---

## 3. 연결 리스트 → 파이썬 리스트 변환 함수 (출력 확인용)

```python
def linked_list_to_list(head):
    result = []
    curr = head
    while curr:
        result.append(curr.val)
        curr = curr.next
    return result
```

---

## 4. 당신이 작성한 Solution 코드 (그대로 사용)

⚠️ **중요:** 현재 코드에는 `dummy.next = head`가 빠져 있어서
정상 동작하지 않습니다. 테스트를 위해 **이 한 줄은 반드시 추가**해야 합니다.

```python
class Solution:
    def reverseBetween(self, head, left, right):
        dummy = ListNode(-501)
        dummy.next = head      # ← 반드시 필요
        curr1 = dummy
        length = right - left + 1

        for _ in range(left):
            curr1 = curr1.next

        curr2 = curr1
        stack = []

        for _ in range(length):
            stack.append(curr1.val)
            curr1 = curr1.next

        while stack:
            curr2.val = stack.pop()
            curr2 = curr2.next

        return dummy.next
```

---

## 5. 테스트 코드 (질문에서 준 테스트 케이스)

```python
# 입력
head = build_linked_list([1, 2, 3, 4, 5])
left = 2
right = 4

# 실행
sol = Solution()
result = sol.reverseBetween(head, left, right)

# 출력 확인
print(linked_list_to_list(result))
```

### 실행 결과
```
[1, 4, 3, 2, 5]
```

## 핵심 요약

- LeetCode의 `head = [1,2,3,4,5]` 는 **실제로는 연결 리스트**
- 로컬 테스트 시에는  
  **리스트 → 연결 리스트 → 함수 실행 → 다시 리스트로 변환**
- `dummy.next = head` 누락은 **치명적인 버그 포인트**

---

원하시면  
- 이 풀이의 **시간/공간 복잡도 평가**
- **포인터로 직접 뒤집는 정석 풀이와 비교**
- 지금 코드에서 발생할 수 있는 **잠재적 오류 케이스**

까지 이어서 같이 정리해 드리겠습니다.

---

### ❓ 질문 (User)
AttributeError: 'NoneType' object has no attribute 'next'

### 💡 답변 (Assistant)
이 에러는 **원인이 명확한 런타임 오류**입니다.  
결론부터 말하면, **포인터를 이동시키는 위치 계산이 잘못되어 `curr1`이 `None`이 된 상태에서 `.next`에 접근**하고 있습니다.

---

## 에러 메시지 해석

```
AttributeError: 'NoneType' object has no attribute 'next'
```

의미:
- 어떤 변수가 `None`
- 그런데 그 변수에 대해 `.next`를 호출함

즉, **연결 리스트의 끝을 넘어갔다는 뜻**입니다.

---

## 문제 원인 ①: for 루프 횟수 오류 (핵심)

```python
for _ in range(left):
    curr1 = curr1.next
```

이 코드는 **left번째 노드가 아니라 `left+1`번째 노드 위치**로 이동합니다.

### 올바른 목표
- `curr1`은 **left 이전 노드**를 가리켜야 함
- 따라서 이동 횟수는 `left - 1`

### 수정
```python
for _ in range(left - 1):
    curr1 = curr1.next
```

---

## 문제 원인 ②: dummy.next 설정이 없으면 즉시 터짐

만약 이 줄이 없다면:

```python
dummy.next = head
```

첫 번째 `curr1 = curr1.next`에서 바로 `None`이 됩니다.

✔ 이 줄은 **필수**입니다.

---

## 수정된 전체 코드 (에러 해결 버전)

```python
class Solution:
    def reverseBetween(self, head, left, right):
        dummy = ListNode(-501)
        dummy.next = head

        curr1 = dummy
        length = right - left + 1

        # 🔴 핵심 수정: left → left - 1
        for _ in range(left - 1):
            curr1 = curr1.next

        curr2 = curr1
        stack = []

        for _ in range(length):
            stack.append(curr1.val)
            curr1 = curr1.next

        while stack:
            curr2.val = stack.pop()
            curr2 = curr2.next

        return dummy.next
```

---

## 왜 이런 에러가 자주 발생하나?

연결 리스트 문제에서 **가장 흔한 3대 실수**

1. dummy.next = head 누락
2. `left` / `right` 위치 오프바이원(off-by-one)
3. 끝 노드 이후 접근 (`None.next`)

이번 경우는 **2번이 직접 원인**, 1번이 있으면 더 빨리 터졌을 상황입니다.
