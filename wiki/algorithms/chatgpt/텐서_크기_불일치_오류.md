# 텐서 크기 불일치 오류

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-08-30

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
해당 에러는 “배치 차원 다음(보통 seq_len)에서 두 텐서의 길이가 다르다”는 뜻입니다. 값이 **127 vs 511**인 걸 보면, 한쪽은 `max_length=128`에서 1칸(shift) 빠진 **127**, 다른 쪽은 `max_length=512`에서 1칸 빠진 **511**로 계산되고 있을 가능성이 높아요. 즉 **입력/라벨/마스크 중 하나의 길이 설정이 다르게 되어** loss 계산 또는 마스킹에서 충돌이 납니다.

# 가장 흔한 원인 (체크 리스트)
1) **입력과 라벨 max_length 불일치**  
   - 예: `input_ids`는 512로 토크나이즈, `labels`는 128로 토크나이즈 → shift 후 511 vs 127.  
   - **해결**: 입력과 라벨의 길이를 **항상 동일**하게 만들고, 라벨에서 학습하지 않을 위치는 `-100`으로 패딩.

2) **잘못된 collator 사용**  
   - `DataCollatorWithPadding`만 쓰고 라벨을 직접 만들었는데, **라벨을 동일 길이로 pad(-100)** 하지 않음.  
   - **해결(카우zalLM)**: `DataCollatorForLanguageModeling(tokenizer, mlm=False)` 사용(라벨=입력 복사, pad 정렬).  
   - **해결(seq2seq)**: `DataCollatorForSeq2Seq(tokenizer, model=model, padding=True)` 사용.

3) **tokenizer 설정 불일치**  
   - `padding_side`(left/right)나 `pad_token` 미설정(특히 LLaMA류)로 인해 마스크/라벨 길이 어긋남.  
   - **해결**:  
     ```python
     tokenizer.padding_side = "right"
     if tokenizer.pad_token is None:
         tokenizer.pad_token = tokenizer.eos_token
     ```

4) **수동 shift 시 마스크도 같이 안 밀어줌**  
   - 직접 `logits[..., :-1, :]`와 `labels[..., 1:]`를 썼다면, **attention_mask도 `[..., 1:]`로 맞춰야** 합니다.

# 바로 하는 3줄 디버그
Trainer/데이터로더에서 배치 하나 뽑아 **shape**부터 확인하세요.
```python
batch = next(iter(trainer.get_train_dataloader()))
print("input_ids:", batch["input_ids"].shape)
print("labels:", batch["labels"].shape)
print("attention_mask:", batch["attention_mask"].shape)
```
여기서 `[:, 1]` 차원이 서로 같아야 합니다(보통 모두 `B x L`).

# 안전한 전처리/Collator 예시

## 1) Causal LM (GPT류)
```python
tokenizer.padding_side = "right"
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

def preprocess(ex):
    tok = tokenizer(ex["text"], truncation=True, max_length=512, add_special_tokens=False)
    tok["labels"] = tok["input_ids"].copy()   # 길이 완전 동일
    return tok

from transformers import DataCollatorForLanguageModeling
collator = DataCollatorForLanguageModeling(tokenizer=tokenizer, mlm=False)
```

### 프롬프트-응답만 학습시키는 경우(프롬프트 무시):
```python
def preprocess(ex):
    p = tokenizer(ex["prompt"], max_length=384, truncation=True, add_special_tokens=False)["input_ids"]
    r = tokenizer(ex["response"], max_length=128, truncation=True, add_special_tokens=False)["input_ids"]
    input_ids = p + r + [tokenizer.eos_token_id]
    labels    = [-100]*len(p) + r + [tokenizer.eos_token_id]   # 길이 == input_ids
    attn      = [1]*len(input_ids)
    return {"input_ids": input_ids, "labels": labels, "attention_mask": attn}
# collator는 위와 동일(MLM=False). pad 시 labels는 -100으로 채워짐 → 길이 일치 보장
```

## 2) Seq2Seq (Encoder–Decoder)
```python
from transformers import DataCollatorForSeq2Seq
def preprocess(ex):
    X = tokenizer(ex["src"],  max_length=512, truncation=True)
    Y = tokenizer(ex["tgt"],  max_length=128, truncation=True)
    X["labels"] = Y["input_ids"]                 # Teacher forcing: decoder len = labels len
    return X

collator = DataCollatorForSeq2Seq(tokenizer, model=model, padding=True)
```

## 3) 직접 collator 쓰는 경우(길이 강제 일치)
```python
import torch
from torch.nn.utils.rnn import pad_sequence

def collate(batch):
    ids  = [torch.tensor(x["input_ids"]) for x in batch]
    mask = [torch.tensor(x["attention_mask"]) for x in batch]
    labs = [torch.tensor(x.get("labels", x["input_ids"])) for x in batch]

    ids  = pad_sequence(ids,  batch_first=True, padding_value=tokenizer.pad_token_id)
    mask = pad_sequence(mask, batch_first=True, padding_value=0)
    labs = pad_sequence(labs, batch_first=True, padding_value=-100)

    assert ids.shape[1] == labs.shape[1], f"{ids.shape} vs {labs.shape}"
    return {"input_ids": ids, "attention_mask": mask, "labels": labs}
```

# 수동 shift를 쓴다면(참고)
```python
# logits: [B, L, V], labels: [B, L]
shift_logits = logits[..., :-1, :].contiguous()
shift_labels = labels[..., 1:].contiguous()
shift_mask   = attention_mask[..., 1:].contiguous()  # 👈 마스크도 같이!
loss = F.cross_entropy(
    shift_logits.view(-1, shift_logits.size(-1)),
    shift_labels.view(-1),
    ignore_index=-100,
    reduction="none"
)
loss = (loss * shift_mask.reshape(-1)).sum() / shift_mask.sum()
```

---

위 순서대로 점검하면 거의 잡힙니다. 요약하면 **“입력/라벨/마스크의 seq_len을 통일하고, pad를 -100/0/`pad_token_id`로 일관되게”**가 핵심입니다. 필요하시면 현재 사용 중인 토크나이저/전처리/콜레이터 코드 조각을 붙여주시면, 제가 거기에 맞춰 정확히 수정해 드릴게요.
