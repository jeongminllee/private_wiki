# 코딩테스트 환경 설정

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
안녕? 지금부터 코딩테스트 환경을 설정하기 위해서 날 좀 도와줬으면 좋겠어. 
python, pytest 를 활용하면 된다고 알고 있어서 그거 위주로 작성하자.
내가 정답 판정을 받게 txt 파일을 준비해두었고, 출력이 한줄씩 나열되어 있으며, 이를 여러번 반복해야돼.

### 💡 답변 (Assistant)
좋아. 추천 구조는 이렇게 잡으면 돼.

```text
project/
├─ solution.py
├─ tests/
│  ├─ test_solution.py
│  └─ cases/
│     ├─ 01.in.txt
│     ├─ 01.out.txt
│     ├─ 02.in.txt
│     ├─ 02.out.txt
│     └─ ...
```

`solution.py`

```python
import sys


def solve():
    input = sys.stdin.readline

    # 여기에 풀이 코드 작성
    n = int(input())
    print(n)


if __name__ == "__main__":
    solve()
```

`tests/test_solution.py`

```python
import subprocess
from pathlib import Path


BASE_DIR = Path(__file__).parent
CASE_DIR = BASE_DIR / "cases"


def normalize(text: str) -> str:
    """
    줄 끝 공백, 마지막 개행 차이를 무시하기 위한 정규화
    """
    return "\n".join(line.rstrip() for line in text.strip().splitlines())


def get_test_cases():
    input_files = sorted(CASE_DIR.glob("*.in.txt"))

    cases = []
    for input_file in input_files:
        output_file = input_file.with_name(
            input_file.name.replace(".in.txt", ".out.txt")
        )

        if output_file.exists():
            cases.append((input_file, output_file))

    return cases


def test_solution():
    for input_file, output_file in get_test_cases():
        input_data = input_file.read_text(encoding="utf-8")
        expected = output_file.read_text(encoding="utf-8")

        result = subprocess.run(
            ["python", "solution.py"],
            input=input_data,
            text=True,
            capture_output=True,
            timeout=2,
        )

        actual = result.stdout

        assert normalize(actual) == normalize(expected), (
            f"\n실패 케이스: {input_file.name}"
            f"\n\n[기대 출력]\n{expected}"
            f"\n\n[실제 출력]\n{actual}"
            f"\n\n[에러 출력]\n{result.stderr}"
        )
```

실행은 프로젝트 루트에서:

```bash
pytest -v
```

예시 파일은 이렇게 준비하면 돼.

`tests/cases/01.in.txt`

```text
3
```

`tests/cases/01.out.txt`

```text
3
```

핵심은 이거야.

```python
result = subprocess.run(
    ["python", "solution.py"],
    input=input_data,
    text=True,
    capture_output=True,
)
```

이 부분이 실제 백준/프로그래머스처럼 `stdin`으로 입력을 넣고, `stdout`으로 나온 출력을 받아서 정답 파일과 비교해주는 역할을 해.

여러 테스트를 한 번에 돌리고 싶으면 `01.in.txt / 01.out.txt`, `02.in.txt / 02.out.txt`처럼 계속 추가하면 된다.

좋아. 코딩테스트용 “입력 파일 → 내 풀이 실행 → 기대 출력과 비교” 환경을 Python + pytest 중심으로 잡으면 아주 깔끔하게 만들 수 있어. 먼저 가장 기본 구조부터 제안하고, 여러 테스트 파일을 반복 실행할 수 있게 확장해볼게.

### 💡 답변 (Assistant)
결론부터 정확히 짚자면 👉 **네, 지금 상태는 “정답이 아니다”가 맞아.**

`pytest`에서


이게 떴다는 건 이 코드가 실패했다는 뜻이야:

```python
assert normalize(actual) == normalize(expected)
```

즉,

- 네 코드 출력 (`actual`)
- 정답 파일 (`expected`)

이 둘이 **한 글자라도 다르면 실패**야.

## 🔍 근데 여기서 중요한 포인트 (실무적으로 중요함)

단순히 “틀렸다”가 아니라 **왜 틀렸는지**를 봐야 한다.

네가 작성한 코드에는 이미 디버깅용 메시지가 들어있어:

```python
f"\n실패 케이스: {input_file.name}"
f"\n\n[기대 출력]\n{expected}"
f"\n\n[실제 출력]\n{actual}"
f"\n\n[에러 출력]\n{result.stderr}"
```

👉 그래서 pytest 출력 아래쪽 보면 이런 형태 나올 거야:

```
실패 케이스: 01.in.txt

[기대 출력]
...

[실제 출력]
...

[에러 출력]
...
```

이걸 반드시 확인해야 한다.

## 🚨 자주 터지는 원인 (거의 90% 여기서 걸림)

```

```


→ 이건 그냥 런타임 에러

### 💡 답변 (Assistant)
맞아, 그 증상이라면 **`solution.py` 안에서 입력/출력 상태가 누적되고 있을 가능성**이 커.

하지만 네가 표시한 이 부분 자체는 매 반복마다 새로 실행돼:

```python
result = subprocess.run(
    ["python", "solution.py"],
    input=input_data,
    text=True,
    capture_output=True,
    timeout=2,
)
```

즉, `01.in.txt`, `02.in.txt`마다 **새 Python 프로세스**로 `solution.py`를 다시 실행한다. 그래서 일반적으로는 갱신 문제가 생기지 않아야 해.

문제는 보통 여기 중 하나야.

## 1. `solution.py`가 파일 입력을 직접 읽고 있을 가능성

`solution.py` 안에 이런 코드가 있으면 안 돼:

```python
sys.stdin = open("tests/cases/01.in.txt")
```

또는

```python
f = open("01.in.txt")
```

이러면 pytest가 넣어준 `input=input_data`를 무시하고 계속 01번 파일만 읽을 수 있어.

`solution.py`는 반드시 이렇게만 읽어야 해:

```python
import sys

def solve():
    input = sys.stdin.readline

    # 풀이 코드
    n = int(input())
    print(n)

if __name__ == "__main__":
    solve()
```

## 2. 실행 위치 문제

`["python", "solution.py"]`는 현재 pytest를 실행한 위치 기준으로 `solution.py`를 찾는다.

더 안전하게 이렇게 바꿔줘:

```python
PROJECT_ROOT = BASE_DIR.parent
SOLUTION_PATH = PROJECT_ROOT / "solution.py"
```

그리고 subprocess 부분을 이렇게 수정:

```python
result = subprocess.run(
    ["python", str(SOLUTION_PATH)],
    input=input_data,
    text=True,
    capture_output=True,
    timeout=2,
    cwd=PROJECT_ROOT,
)
```

전체 핵심 수정본:


### 💡 답변 (Assistant)
`collected 1 item`은 정상일 가능성이 커.

pytest 기준에서 **item = 테스트 함수 개수**야.  
지금 파일에는 테스트 함수가 이것 하나뿐이지?

```python
def test_solution():
    ...
```

그래서 `collected 1 item`으로 나와.

다만 그 함수 안에서:

```python
for input_file, output_file in get_test_cases():
```

여러 케이스를 반복 실행하고 있는 구조라서, 실제로는 01, 02, 03…이 다 돌아갈 수 있어.

즉 현재 구조는:

```text
pytest item 1개
└─ test_solution()
   ├─ 01.in.txt 검사
   ├─ 02.in.txt 검사
   ├─ 03.in.txt 검사
   └─ ...
```

케이스별로 pytest item을 따로 보고 싶으면 `parametrize`를 쓰면 돼.

```python
import subprocess
from pathlib import Path
import pytest


BASE_DIR = Path(__file__).parent
PROJECT_ROOT = BASE_DIR.parent
CASE_DIR = BASE_DIR / "cases"
SOLUTION_PATH = PROJECT_ROOT / "solution.py"


def normalize(text: str) -> str:
    return "\n".join(line.rstrip() for line in text.strip().splitlines())


def get_test_cases():
    input_files = sorted(CASE_DIR.glob("*.in.txt"))

    cases = []
    for input_file in input_files:
        output_file = input_file.with_name(
            input_file.name.replace(".in.txt", ".out.txt")
        )

        if output_file.exists():
            cases.append((input_file, output_file))

    return cases


@pytest.mark.parametrize("input_file, output_file", get_test_cases())
def test_solution(input_file, output_file):
    input_data = input_file.read_text(encoding="utf-8")
    expected = output_file.read_text(encoding="utf-8")

    result = subprocess.run(
        ["python", str(SOLUTION_PATH)],
        input=input_data,
        text=True,
        capture_output=True,
        timeout=2,
        cwd=PROJECT_ROOT,
    )

    actual = result.stdout

    assert normalize(actual) == normalize(expected), (
        f"\n실패 케이스: {input_file.name}"
        f"\n\n[입력]\n{input_data}"
        f"\n\n[기대 출력]\n{expected}"
        f"\n\n[실제 출력]\n{actual}"
        f"\n\n[에러 출력]\n{result.stderr}"
    )
```

그러면 예를 들어 케이스가 3개면:

```text
collected 3 items
```

처럼 나와.

지금 상황 정리하면:

```text
collected 1 item = 테스트 함수 1개라서 정상
케이스별 item 표시 원함 = pytest.mark.parametrize 사용
```

### 💡 답변 (Assistant)
이 에러는 `parametrize`에 지정한 인자 이름과 `test_solution()` 함수 매개변수 이름이 안 맞아서 난 거야.

아마 이런 상태일 가능성이 커:

```python
@pytest.mark.parametrize("input_file, output_file", get_test_cases())
def test_solution():
    ...
```

위처럼 데코레이터에는 `input_file`이 있는데, 함수에는 인자가 없어서 pytest가 에러를 낸 거야.

이렇게 고쳐줘:

```python
@pytest.mark.parametrize("input_file, output_file", get_test_cases())
def test_solution(input_file, output_file):
    input_data = input_file.read_text(encoding="utf-8")
    expected = output_file.read_text(encoding="utf-8")

    result = subprocess.run(
        ["python", str(SOLUTION_PATH)],
        input=input_data,
        text=True,
        capture_output=True,
        timeout=2,
        cwd=PROJECT_ROOT,
    )

    actual = result.stdout

    assert normalize(actual) == normalize(expected), (
        f"\n실패 케이스: {input_file.name}"
        f"\n\n[입력]\n{input_data}"
        f"\n\n[기대 출력]\n{expected}"
        f"\n\n[실제 출력]\n{actual}"
        f"\n\n[에러 출력]\n{result.stderr}"
    )
```

핵심은 이 둘이 정확히 일치해야 해:

```python
@pytest.mark.parametrize("input_file, output_file", ...)
def test_solution(input_file, output_file):
```

즉,

```text
parametrize 이름: input_file, output_file
함수 인자 이름: input_file, output_file
```

이렇게 맞춰야 정상적으로 `collected N items`가 나올 거야.

## 첫 번째 코드 기준 추천 수정 방향

큰 틀은 유지하고 이렇게 고치면 됩니다.

```python
import heapq


class Road:
    def __init__(self, left_id, right_id, length, st_pos):
        self.left_id = left_id
        self.right_id = right_id
        self.length = length
        self.st_pos = st_pos

    def __lt__(self, other):
        if self.length == other.length:
            return self.st_pos < other.st_pos
        return self.length > other.length


def main():
    Q = int(input())

    N = M = 0
    lamp_pos = []
    left_lamp = []
    right_lamp = []
    left_heap = []
    right_heap = []
    distance_heap = []

    def get_max_distance():
        while distance_heap:
            road = distance_heap[0]

            if (
                lamp_pos[road.left_id] == road.st_pos
                and lamp_pos[road.right_id] == road.st_pos + road.length
            ):
                return road

            heapq.heappop(distance_heap)

        return None

    for _ in range(Q):
        query = list(map(int, input().split()))
        cmd = query[0]

        if cmd == 100:
            _, N, M, *lamp_pos = query
            lamp_pos = [-1] + lamp_pos

            left_lamp = [-1] + [-1] + [idx for idx in range(1, M)]
            right_lamp = [-1] + [idx + 1 for idx in range(1, M)] + [-1]

            left_heap = []
            right_heap = []
            distance_heap = []

            for idx in range(1, len(lamp_pos)):
                heapq.heappush(left_heap, (lamp_pos[idx], idx))
                heapq.heappush(right_heap, (-lamp_pos[idx], idx))

                if idx > 1:
                    heapq.heappush(
                        distance_heap,
                        Road(
                            idx - 1,
                            idx,
                            lamp_pos[idx] - lamp_pos[idx - 1],
                            lamp_pos[idx - 1],
                        ),
                    )

        elif cmd == 200:
            max_distance = get_max_distance()
            heapq.heappop(distance_heap)

            left_id = max_distance.left_id
            right_id = max_distance.right_id

            new_lamp_id = len(lamp_pos)
            new_lamp_pos = max_distance.st_pos + (max_distance.length + 1) // 2

            lamp_pos.append(new_lamp_pos)

            right_lamp[left_id] = new_lamp_id
            left_lamp[right_id] = new_lamp_id

            left_lamp.append(left_id)
            right_lamp.append(right_id)

            heapq.heappush(left_heap, (new_lamp_pos, new_lamp_id))
            heapq.heappush(right_heap, (-new_lamp_pos, new_lamp_id))

            heapq.heappush(
                distance_heap,
                Road(left_id, new_lamp_id, new_lamp_pos - lamp_pos[left_id], lamp_pos[left_id]),
            )
            heapq.heappush(
                distance_heap,
                Road(new_lamp_id, right_id, lamp_pos[right_id] - new_lamp_pos, new_lamp_pos),
            )

        elif cmd == 300:
            _, D = query
            lamp_pos[D] = -1

            left_id = left_lamp[D]
            right_id = right_lamp[D]

            if left_id != -1:
                right_lamp[left_id] = right_id
            if right_id != -1:
                left_lamp[right_id] = left_id

            if left_id != -1 and right_id != -1:
                heapq.heappush(
                    distance_heap,
                    Road(
                        left_id,
                        right_id,
                        lamp_pos[right_id] - lamp_pos[left_id],
                        lamp_pos[left_id],
                    ),
                )

        elif cmd == 400:
            min_pos = 0
            max_pos = N + 1

            while left_heap:
                pos, lamp_id = left_heap[0]
                if lamp_pos[lamp_id] == pos:
                    min_pos = pos
                    break
                heapq.heappop(left_heap)

            while right_heap:
                neg_pos, lamp_id = right_heap[0]
                if lamp_pos[lamp_id] == -neg_pos:
                    max_pos = -neg_pos
                    break
                heapq.heappop(right_heap)

            max_distance = get_max_distance()

            answer = max(
                2 * (min_pos - 1),
                2 * (N - max_pos),
                max_distance.length,
            )

            print(answer)


if __name__ == "__main__":
    main()
```

## 더 공부해야 할 점

지금 이 문제에서 핵심은 문법보다 **자료구조 유지 전략**입니다.

공부 우선순위는 이 순서가 좋습니다.

1. **heapq와 우선순위 큐**
   - Python `heapq`는 기본이 최소 힙
   - 최대 힙처럼 쓰려면 음수 또는 `__lt__` 커스터마이징 사용
   - 삭제된 데이터를 바로 제거하지 않고 나중에 제거하는 lazy deletion 이해 필요

2. **Lazy Deletion**
   - 현재 코드의 `get_max_distance()`가 바로 이 방식입니다.
   - heap 안에는 이미 삭제되었거나 무효가 된 구간이 남아 있고, 꺼낼 때 현재 상태와 비교해서 버립니다.

3. **이중 연결 리스트를 배열로 구현하기**
   - `left_lamp[id]`
   - `right_lamp[id]`
   - 삭제/삽입 시 양쪽 링크 갱신  
   이 문제에서 진짜 중요한 구조입니다.

4. **구간 관리**
   - 가로등 추가 = 기존 구간 하나 삭제 + 새 구간 두 개 추가
   - 가로등 삭제 = 양옆 구간 합쳐서 새 구간 하나 추가

5. **정수 올림 나눗셈**
   - `ceil(a / 2)` 대신 `(a + 1) // 2`
   - `ceil((L_i + L_j) / 2)` 대신 `(L_i + L_j + 1) // 2`

요약하면, 첫 번째 코드는 **아이디어는 맞고**, 고쳐야 할 핵심은 `Optional`, 전역 상태 정리, `main()` 구조화, heap 초기화 안정성입니다.
