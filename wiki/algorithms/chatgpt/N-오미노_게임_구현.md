# N-오미노 게임 구현

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
N-오미노는 이차원 평면 위에 N개의 정사각형이 연결된 도형이다. 1-오미노는 1*1 크기의 정사각형이다. 그래서 n-노미노는 n - 1오미노에 1-오미노, 즉 1*1짜리 정사각형을 추가 한 것과 같다. 단, 두 N-오미노가 합동이면 같다고 가정한다.

아래에는 가능한 5가지 4-오미노가 있다.

images-73.png

아래에는 전체 108가지의 7-오미노 중 일부가 있다.

images-74.png

철수와 동수는 변수 X, R, C가 정해진 상태에서 아래의 절차대로 게임을 진행하려고 한다.

1.철수는 가능한 X-오미노 중에서 하나를 고른다.                                    

2.동수는 여러 가지 X-오미노를 이용해서 넘치지도 부족하지도 않게 R*C 판을 채운다. 단, 철수가 고른 X-오미노를 적어도 한개를 이용해야 하며 X-오미노를 뒤집거나 회전하여 이용해도 된다. 동수가 위의 조건을 만족하면서 판을 채우면 동수는 승리하고 판을 채우지 못하면 패배한다.

X, R, C가 주어질때 철수가 무조건 이길지 동수가 무조건 이길지 판별하라.

입력
입력의 첫째 줄에는 테스트케이스의 수 T가 주어진다

다음 T개의 줄에서는 각각 X, R, C가 차례대로 주어진다.

T = 64., 1 ≤ X, R, C ≤ 4

출력
각각의 테스트케이스에 대하여 "Case #x:y"를 출력한다. 이때 x는 테스트케이스 번호(1부터 시작한다). 철수가 선택했을때 무조건 이기는 X-오미노가 하나라도 있으면 y는 RICHARD이고 하나도 없으면 y는 GABRIEL이다.

예제 입력 1 
4
2 2 2
2 1 3
4 4 1
3 2 3
예제 출력 1 
Case #1: GABRIEL
Case #2: RICHARD
Case #3: RICHARD
Case #4: GABRIEL
힌트
Case #1에서는 철수는 선택할 수 있는 2-오미노가 하나 밖에 없다--1*2짜리 직사각형. 2*2판은 1*2 직사각형 두개로 무조건 채울수 있으므로 동수 승!

Case #2에서도 철수는 선택할 수 있는 2-오미노가 하나 밖에 없다--1*2짜리 직사각형. 하지만 동수가 그 2-오미노를 어느것에 놓더라도 1*1이 하나 남으므로 철수 승!

Case #3에서 철수가 이길수 있는 방법은 2*2짜리 4-오미노를 선택하는 것이다. 1*4판에다가 2*2정사각형은 절대 넣을 수 없으므로 철수 승!

Case #4에서는 1*3짜리 3-오미노 또는 L모양으로 생긴 3-오미노를 선택해야 한다. 두 경우 모두 동수가 2*3판에 하나를 놓고 똑같은 모양 하나를 더 넣으면 되므로 동수 승!

### 💡 답변 (Assistant)
아래는 Python 코드로 구현한 예시입니다.

```python
def solve():
    import sys
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    T = int(input_data[0])
    results = []
    idx = 1
    for t in range(1, T + 1):
        X = int(input_data[idx]); idx += 1
        R = int(input_data[idx]); idx += 1
        C = int(input_data[idx]); idx += 1

        # R과 C 중 작은 값을 R로 설정
        if R > C:
            R, C = C, R

        answer = "GABRIEL"
        # 전체 칸 수가 X로 나누어떨어져야 함
        if (R * C) % X != 0:
            answer = "RICHARD"
        # X가 7 이상이면 구멍이 있는 도형을 만들 수 있으므로 항상 Richard 승리
        elif X >= 7:
            answer = "RICHARD"
        elif X == 1:
            answer = "GABRIEL"
        elif X == 2:
            answer = "GABRIEL"
        elif X == 3:
            # 3-오미노의 경우 최소한 2 이상의 폭이 필요
            if R < 2:
                answer = "RICHARD"
        elif X == 4:
            # 4-오미노는 최소한 3 이상의 폭이 있어야 함
            if R < 3:
                answer = "RICHARD"

        results.append(f"Case #{t}: {answer}")

    sys.stdout.write("\n".join(results))


if __name__ == '__main__':
    solve()
```

---

### 코드 설명

1. **입력 처리**:  
   `sys.stdin.read()`를 사용해 입력 전체를 읽고 공백 기준으로 나눕니다. 첫 번째 값은 테스트 케이스의 수 T입니다.

2. **문제 조건에 따른 처리**:  
   - 전체 칸 수가 X로 나누어 떨어지지 않으면 tiling이 불가능하므로 `RICHARD`를 출력합니다.
   - X가 7 이상이면 구멍이 있는 도형을 만들 수 있어 tiling이 어려우므로 `RICHARD`를 출력합니다.
   - X가 1 또는 2인 경우는 tiling이 항상 가능하므로 `GABRIEL`입니다.
   - X가 3인 경우, 최소 한쪽의 길이가 2 이상이어야 tiling이 가능합니다.
   - X가 4인 경우, 최소 한쪽의 길이가 3 이상이어야 tiling이 가능합니다.

3. **출력**:  
   각 케이스마다 “Case #x: y” 형식으로 결과를 출력합니다.

이 코드는 문제의 조건에 따라 철수가(=Richard) 무조건 이길 수 있는 경우와 동수가(=Gabriel) 이길 수 있는 경우를 올바르게 판별합니다.

### 각 조건에 대한 분석

1. **x == 1인 경우:**
   ```python
   if x == 1:
       return ('GABRIEL')
   ```
   - **분석:**  
     1-오미노는 단순한 1×1 정사각형입니다. 어떤 보드든(칸의 수가 맞으면) 채울 수 있으므로 항상 Gabriel(동수)이 이깁니다.

2. **x == 2인 경우:**
   ```python
   elif x == 2 and r * c % x == 0:
       return ('GABRIEL')
   ```
   - **분석:**  
     2-오미노는 1×2 또는 2×1 모양의 직사각형입니다.  
     - **보드 채우기 조건:**  
       보드의 총 칸 수가 2로 나누어 떨어져야 합니다. (짝수여야 함)  
     - 만약 보드의 칸 수가 2의 배수라면, Gabriel은 항상 채울 수 있습니다.
     - **주의:**  
       만약 보드의 칸 수가 2의 배수가 아니라면 else 절로 넘어가서 `RICHARD`를 반환하게 됩니다.

3. **x == 3인 경우:**
   ```python
   elif x == 3 and r * c % x == 0 and (r >= 2 and c >= 2):
       return ('GABRIEL')
   ```
   - **분석:**  
     3-오미노에는 직선형(1×3)과 L자 모양이 있습니다.
     - **면적 조건:**  
       보드의 총 칸 수가 3의 배수여야 합니다.
     - **최소 보드 크기 조건:**  
       최소한 양쪽 모두 2 이상의 크기가 필요합니다.  
       이유: 만약 보드의 한 변이 1이면 L자 모양 오미노는 회전해도 들어가지 않으므로 tiling이 불가능해집니다.
     - 두 조건이 모두 만족해야 Gabriel이 이길 수 있습니다.

4. **x == 4인 경우:**
   ```python
   elif x == 4 and r * c % x == 0 and (r >= 3 and c >= 3):
       return ('GABRIEL')
   ```
   - **분석:**  
     4-오미노에는 여러 모양(직선, L자, T자, S자 등)이 존재합니다.
     - **면적 조건:**  
       보드의 총 칸 수가 4의 배수여야 합니다.
     - **최소 보드 크기 조건:**  
       어떤 4-오미노들은 보드의 한 변이 2이면 들어가지 않는 경우가 있으므로 최소 3 이상의 크기가 필요합니다.
     - 조건들이 만족되면 Gabriel이 보드를 채울 수 있다고 판단합니다.

5. **그 외의 경우:**
   ```python
   else:
       return ('RICHARD')
   ```
   - **분석:**  
     위의 모든 경우에 해당하지 않으면 tiling이 불가능한 조건으로 판단하여 Richard(철수)가 승리하는 경우입니다.

### 요약

- **기본 아이디어:**  
  오미노의 크기(x)에 따라 보드를 채울 수 있는 최소 조건(면적이 x의 배수, 보드의 최소 크기)이 다릅니다.  
  각 경우에 대해 조건을 체크하여 tiling이 가능한지 여부를 판단합니다.

- **코드의 한계:**  
  이 코드는 문제의 입력 제약 조건 (1 ≤ X, R, C ≤ 4)에 맞춰져 있으므로 X가 5 이상인 경우는 고려하지 않습니다.  
  문제의 전체 버전에서는 추가적인 조건 검사가 필요하지만, 여기서는 소규모 입력에 한정되어 있습니다.

---

이와 같이, 각 조건문은 “이 오미노로 판을 채울 수 있으면 Gabriel, 아니면 Richard”의 논리에 따라 구성되어 있습니다. 각 오미노 크기에 맞는 최소 보드 크기와 총 칸 수의 조건을 만족하는지 여부로 결과를 반환하게 됩니다.
