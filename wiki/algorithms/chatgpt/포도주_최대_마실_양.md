# 포도주 최대 마실 양

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
1. 포도주 잔을 선택하면 그 잔에 들어있는 포도주는 모두 마셔야하고, 마신 후에는 원위치
2. 연속으로 놓여있는 3잔을 모두 마실 수는 없다.
[0, 6, 10, 13, 9, 8, 1]
내가 최대로 마실 수 있는 양을 구하는 파이썬 코드 작성해줘

### 💡 답변 (Assistant)
주어진 조건에 맞춰 최대로 마실 수 있는 양을 구하는 파이썬 코드를 작성해볼게요. 주어진 규칙에 따라 최대로 마실 수 있는 포도주의 양을 계산하는 함수를 만들어 보겠습니다.

```python
def max_wine_amount(wine):
    n = len(wine)
    if n == 0:
        return 0
    if n == 1:
        return wine[0]

    dp = [0] * n
    dp[0] = wine[0]
    dp[1] = wine[0] + wine[1]

    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + wine[i], dp[i - 3] + wine[i - 1] + wine[i])

    return max(dp[-1], dp[-2])

wines = [0, 6, 10, 13, 9, 8, 1]
result = max_wine_amount(wines)
print("최대로 마실 수 있는 양:", result)
```

이 코드는 주어진 포도주 잔 배열에서 최대로 마실 수 있는 양을 계산합니다. 주어진 규칙에 따라 한 번에 최대로 마실 수 있는 양을 계산하여 반환합니다. 위의 예시 코드를 실행하면 최대로 마실 수 있는 양이 출력될 거에요.
