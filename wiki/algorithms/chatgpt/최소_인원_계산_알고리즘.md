### 💡 답변 (Assistant)
이 문제는 "처음에 집 안에 최소 몇 명이 있었어야 지금까지 관찰한 입출입 이벤트들이 가능했는가?"를 묻는 문제예요.

---

## 🔍 문제 이해 (예시 기준)

예제 입력:
```
1
3
3 5
3 4
1 0
```

- 테스트 케이스 1개
- 입출입 이벤트 3개
  1. 3명 입장, 5명 퇴장
  2. 3명 입장, 4명 퇴장
  3. 1명 입장, 0명 퇴장

---

## 💡 핵심 아이디어

- 사람 수는 음수가 될 수 없어요.
- 어떤 시점에서 퇴장하는 인원이 현재 인원보다 많으면, "처음에 그만큼 더 있었어야 한다"는 뜻이에요.
- 입장 전에 퇴장이 일어나는 게 아니라, **입장이 먼저, 퇴장이 나중**이라는 순서를 잘 지켜야 해요.

---

## ✅ 풀이 전략

1. 현재 집 안에 있는 사람 수 (`current`)와
2. 필요한 최소 시작 인원 수 (`min_start`)를 0으로 설정.
3. 각 이벤트마다:
   - 먼저 `P1`명을 입장시킴 → `current += P1`
   - 그다음 `P2`명을 퇴장시킴
     - 만약 `current >= P2`면 → 그냥 `current -= P2`
     - 만약 `current < P2`면 → 부족한 인원만큼 처음부터 있었어야 함 → `min_start += (P2 - current)`, 그리고 `current = 0`
4. 모든 이벤트가 끝나면 `min_start`가 답.

---

## 🧑‍💻 파이썬 코드 (한글 주석 포함)

```python
T = int(input())  # 테스트 케이스 수 입력

for _ in range(T):
    M = int(input())  # 입출입 이벤트 개수
    current = 0       # 현재 집 안에 있는 사람 수
    min_start = 0     # 처음에 있어야 했던 최소 인원

    for _ in range(M):
        P1, P2 = map(int, input().split())  # P1명 입장, P2명 퇴장

        current += P1  # 입장한 사람 더하기

        if current >= P2:
            current -= P2  # 퇴장할 수 있는 만큼 퇴장
        else:
            # 퇴장 인원이 부족하면, 처음부터 그만큼 더 있었어야 함
            min_start += (P2 - current)
            current = 0  # 전부 나가고 0명 남음

    print(min_start)
```

### 💡 답변 (Assistant)
이 문제는 **지뢰 찾기에서 닫힌 칸 중 지뢰가 있을 수 있는 최대 개수**를 구하는 문제입니다.

---

## ✅ 문제 핵심 요약

- 보드의 테두리는 모두 열려 있으며 숫자가 쓰여 있음.
- 나머지 안쪽은 모두 닫혀 있으며, `'#'`로 표시됨.
- 숫자 칸은 주변 8칸에 지뢰가 몇 개 있는지를 나타냄.
- 조건을 만족하면서 닫힌 칸에 **최대한 많은 지뢰**를 넣는 것이 목표.

---

## 💡 풀이 아이디어

1. **입력 파싱**: NxN 보드 생성
2. **모든 닫힌 칸(`'#'`)에 일단 지뢰가 있다고 가정**하고, 그게 가능한지 확인
3. 테두리에 있는 숫자 칸에서 지뢰 개수를 만족하지 못하면 → 그 가정은 틀린 것
4. **최대한 많이 지뢰를 넣되, 조건을 위반하지 않도록 제한**해야 함.

이를 위해 **완전탐색**이나 **제약을 만족하는 최대 지뢰 수 계산**으로 접근할 수 있는데, 이 문제는 단순하게 해결 가능:

---

## ✅ 단계별 풀이 전략

### 1. `'#'` 칸마다 지뢰 있다고 가정

- 모든 `'#'`를 `'*'`로 가정하고,
- 테두리 숫자 칸들의 주위에 있는 `'*'` 개수를 세어봄
- 숫자보다 많으면 → 위배 → 해당 위치에 `'*'` 제거

이 과정을 반복해서 가능한 지뢰 위치만 남기고, 그 수를 세면 됨.

---

## 🧑‍💻 Python 코드 (한글 주석 포함)

```python
# 8방향 탐색을 위한 델타
dx = [-1, -1, -1,  0, 0, 1, 1, 1]
dy = [-1,  0,  1, -1, 1,-1, 0, 1]

# 입력 받기
N = int(input())
board = [list(input()) for _ in range(N)]

# 모든 '#'을 지뢰(*)로 가정한 새 보드 생성
mine_board = [row[:] for row in board]
for i in range(N):
    for j in range(N):
        if board[i][j] == '#':
            mine_board[i][j] = '*'

# 숫자 칸 기준으로 조건 위배하는 곳은 '*' 제거
for i in range(N):
    for j in range(N):
        if board[i][j].isdigit():
            target = int(board[i][j])
            count = 0
            # 8방향 탐색
            for d in range(8):
                ni, nj = i + dx[d], j + dy[d]
                if 0 <= ni < N and 0 <= nj < N and mine_board[ni][nj] == '*':
                    count += 1
            # 조건 위배 시, 주변 '*' 중 일부 제거
            if count > target:
                for d in range(8):
                    ni, nj = i + dx[d], j + dy[d]
                    if 0 <= ni < N and 0 <= nj < N and mine_board[ni][nj] == '*':
                        mine_board[ni][nj] = '.'
                        count -= 1
                        if count == target:
                            break

# 최종 지뢰 개수 세기
result = sum(row.count('*') for row in mine_board)
print(result)
```
