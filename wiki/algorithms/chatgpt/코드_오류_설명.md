# 코드 오류 설명

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-12-12

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = {}
        cols = {}
        boxes = {}

        for i in range(9) :
            for j in range(9) :
                curr = board[i][j]
                if curr == "." :
                    continue

                if curr in rows or curr in cols or curr in boxes :
                    return False
                
                rows[i].add(curr)
                cols[j].add(curr)
                boxes[(i//3, j//3)].add(curr)

        return True
```

이 코드가 오류가 나는 이유를 설명해줘.

### 💡 답변 (Assistant)
오류가 나는 이유는 **자료구조를 “선언만” 해놓고 초기화/인덱싱을 잘못했기 때문**입니다. 지금 코드에는 크게 2가지 치명적인 문제가 있습니다.

## 1) `rows`, `cols`, `boxes`는 dict인데, `in` 검사 방식이 잘못됨
```python
if curr in rows or curr in cols or curr in boxes:
```
- `rows`는 `{}`(dict)이고, `curr`는 `"5"` 같은 문자열입니다.
- 파이썬에서 `x in dict` 는 **dict의 “키”에 x가 있는지**를 검사합니다.
- 그런데 `rows`의 키는 `i`(0~8)가 되어야 하므로, `"5" in rows` 는 항상 False에 가깝고, **중복 검사가 의도대로 동작하지 않습니다.**

즉, 여기서 검사해야 하는 건
- `curr in rows[i]`
- `curr in cols[j]`
- `curr in boxes[(i//3, j//3)]`
처럼 **각 위치의 set 내부**입니다.

## 2) `rows[i].add(curr)`에서 바로 터짐 (KeyError 또는 AttributeError)
```python
rows[i].add(curr)
```
- `rows`는 빈 dict `{}`이고, 아직 `rows[i]`라는 키가 없습니다.
- 그래서 `rows[i]` 접근 순간 **KeyError** 가 납니다.  
  (만약 `rows[i]`가 우연히 다른 타입으로 들어갔어도 `.add`가 없으면 AttributeError가 납니다.)

마찬가지로 `cols[j]`, `boxes[(i//3, j//3)]`도 **각 키에 대해 set을 미리 만들어줘야** 합니다.

---

### 한 줄 요약
- `curr in rows` 는 “값 중복”이 아니라 “키 존재” 검사라 로직이 틀렸고,
- `rows[i]`/`cols[j]`/`boxes[key]`에 들어갈 set을 **미리 생성하지 않아서** `rows[i].add()`에서 에러가 납니다.

원하면, 이 코드를 최소 수정으로 올바르게 동작하게 고친 버전도 바로 제공해드릴게요.

### 💡 답변 (Assistant)
`KeyError: 0`는 **`rows[i]`라는 키(0)가 아직 `rows` 딕셔너리에 없는데 접근했기 때문**입니다.

지금 코드 흐름을 보면 첫 칸에서 바로 이렇게 됩니다.

- 시작: `rows = {}`
- 첫 반복: `i = 0, j = 0`
- 검사 줄에서 `rows[i]`를 읽으려 함 → `rows[0]`이 없음 → **KeyError: 0**

즉, `rows`, `cols`, `boxes`를 “딕셔너리로 선언만” 했고, **각 키에 대응하는 set을 생성하지 않았습니다.**

---

## 해결 방법 1) `setdefault`로 필요할 때 초기화
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows, cols, boxes = {}, {}, {}

        for i in range(9):
            for j in range(9):
                curr = board[i][j]
                if curr == ".":
                    continue

                rows.setdefault(i, set())
                cols.setdefault(j, set())
                boxes.setdefault((i//3, j//3), set())

                if curr in rows[i] or curr in cols[j] or curr in boxes[(i//3, j//3)]:
                    return False

                rows[i].add(curr)
                cols[j].add(curr)
                boxes[(i//3, j//3)].add(curr)

        return True
```

## 해결 방법 2) `defaultdict(set)` 사용 (가장 깔끔)
```python
from collections import defaultdict

class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = defaultdict(set)
        cols = defaultdict(set)
        boxes = defaultdict(set)

        for i in range(9):
            for j in range(9):
                curr = board[i][j]
                if curr == ".":
                    continue

                b = (i//3, j//3)
                if curr in rows[i] or curr in cols[j] or curr in boxes[b]:
                    return False

                rows[i].add(curr)
                cols[j].add(curr)
                boxes[b].add(curr)

        return True
```

원리만 정리하면: **dict는 없는 키에 접근하면 KeyError가 나므로, 접근 전에 해당 키에 set을 만들어둬야** 합니다.

### ❓ 질문 (User)
아 그래서 defaultdict를 쓰는거구나. defaultdict 이 라이브러리에는 기본적이로 setdefault 가 내장되어 있어서 이런 오류가 발생하지 않는거지?

### 💡 답변 (Assistant)
거의 맞게 이해하셨는데, 표현을 조금만 정교하게 하면 더 정확합니다.

- `defaultdict`에는 **`setdefault`가 “내장되어 있어서”** 동작하는 게 아닙니다.  
- `defaultdict`는 **없는 키를 `dict[key]`로 읽는 순간**, 내부적으로 **`default_factory`(예: `set`)를 호출해서 값을 자동 생성**하고 그 값을 저장한 뒤 반환합니다.

즉:

### `defaultdict(set)`에서 일어나는 일
```python
rows = defaultdict(set)
rows[0]          # 0이 없으면 set()을 만들어 rows[0]에 넣고, 그 set을 반환
rows[0].add('5') # 이제 정상 동작
```

### `setdefault`는 일반 dict의 메서드
`setdefault`는 `defaultdict` 전용 기능이 아니라 **일반 `dict`에도 있는 메서드**입니다.

```python
rows = {}
rows.setdefault(0, set()).add('5')  # 0이 없으면 set()을 넣고 그 set 반환
```

### 차이 한 줄 요약
- `defaultdict`: **“접근할 때 자동 생성”** (읽기/쓰기 모두에서 편리)
- `setdefault`: **“명시적으로 한 번 초기화”** (일반 dict에서도 가능)

원하시면, `defaultdict` 없이도 (성능/가독성 좋은) `rows = [set() for _ in range(9)]` 같은 리스트 방식으로도 깔끔하게 구현할 수 있습니다.
