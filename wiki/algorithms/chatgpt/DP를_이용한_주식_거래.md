# DP를 이용한 주식 거래

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-03-28

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 코드는 최대 k번의 거래를 통해 주식 매매에서 얻을 수 있는 최대 이익을 구하는 동적 계획법(DP) 접근법입니다. 코드의 주요 아이디어와 각 부분을 자세히 분석하면 다음과 같습니다.

---

### 1. DP 배열의 초기화

```python
dp = [[1000, 0] for _ in range(k + 1)]
```

- **목적:** 각 거래 횟수(0부터 k까지)에 대해 두 개의 상태 값을 저장하기 위함입니다.
- **dp[i][0]:** i번째 거래를 “진입”할 때의 최소 비용(또는 효과적으로 주식을 산 가격)을 추적합니다.  
  - 초기값이 1000인 이유는, 문제의 가격 범위나 제한에 따라 충분히 큰 값(실제 무한대 대신 사용)으로 설정한 것입니다.
- **dp[i][1]:** i번의 거래까지 완료했을 때의 최대 이익을 저장합니다.
  - 초기값은 0으로 시작합니다.

---

### 2. 가격 리스트를 순회하며 DP 업데이트

```python
for price in prices:
    for i in range(1, k + 1):
        dp[i][0] = min(dp[i][0], price - dp[i-1][1])
        dp[i][1] = max(dp[i][1], price - dp[i][0])
```

- **외부 루프:** 각 날짜의 주식 가격을 순회합니다.
- **내부 루프:** 1번 거래부터 k번 거래까지 진행하면서 다음과 같이 상태를 갱신합니다.

#### a. dp[i][0] 업데이트

```python
dp[i][0] = min(dp[i][0], price - dp[i-1][1])
```

- **의미:** 
  - 이전 거래(`i-1`)에서 얻은 이익(`dp[i-1][1]`)을 고려하여 현재 가격에서 “주식을 산 효과적인 가격”을 업데이트합니다.
  - `price - dp[i-1][1]`는 만약 이전 거래까지의 이익을 재투자한다고 가정했을 때, 현재 주식을 사는 순수 비용(실제 가격에서 이전 이익을 뺀 값)을 의미합니다.
  - 이를 통해 가능한 최소의 “순 비용”을 저장하게 됩니다.

#### b. dp[i][1] 업데이트

```python
dp[i][1] = max(dp[i][1], price - dp[i][0])
```

- **의미:**
  - 현재 주식을 팔았을 때의 이익을 계산합니다. 즉, 현재 가격에서 해당 거래의 최소 순 비용(`dp[i][0]`)을 빼서 거래를 마감했을 때의 이익을 산출합니다.
  - 최대 이익을 기록하기 위해 기존의 `dp[i][1]`과 비교하여 큰 값으로 갱신합니다.

---

### 3. 최종 반환

```python
return dp[k][1]
```

- **의미:** 최대 k번의 거래를 완료했을 때의 최대 이익을 반환합니다.

---

### 전체적인 아이디어

- **DP 접근법:**  
  각 거래 단계마다 "매수(구매)"와 "매도(판매)"의 상태를 동시에 추적하여, 이전 거래의 이익을 다음 거래의 비용 계산에 반영하는 방식입니다.
  
- **거래의 의미:**  
  - `dp[i][0]`은 i번째 거래를 시작하기 위해 필요한 최소 비용(이전에 얻은 이익을 차감한 가격)이며,  
  - `dp[i][1]`은 i번째 거래를 완료했을 때의 최대 이익입니다.
  
- **효율성:**  
  이중 루프를 통해 모든 가격에 대해 모든 거래 단계를 고려하므로, 시간 복잡도는 O(k * n)이 됩니다. 이는 k와 n의 크기에 따라 적절한 성능을 보여줄 수 있습니다.

---

### 결론

이 코드는 주어진 가격 배열과 최대 거래 횟수 k에 대해, 각 거래마다 최적의 매수/매도 전략을 동적 계획법으로 구현하여 최대 이익을 계산하는 방법을 보여줍니다. 각 단계에서 이전 거래의 이익을 활용해 비용과 이익을 업데이트함으로써, 전체 거래 과정에서 이익을 극대화하는 전략을 세우는 구조입니다.

### ❓ 질문 (User)
```
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        dp = [[1000, 0] for _ in range(k + 1)]
        for price in prices :
            for i in range(1, k + 1) :
                dp[i][0] = min(dp[i][0], price - dp[i-1][1])
                dp[i][1] = max(dp[i][1], price - dp[i][0])

        return dp[k][1]
```
