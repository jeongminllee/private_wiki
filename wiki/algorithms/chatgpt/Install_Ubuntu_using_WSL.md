# Install Ubuntu using WSL

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
vscode 에 있는 wsl 을 활용해서 우분투를 설치해줘

### 💡 답변 (Assistant)
VSCode에서 WSL(Windows Subsystem for Linux)을 활용하여 우분투를 설치하고 설정하는 방법을 안내해드리겠습니다. WSL은 Windows 환경에서 Linux 배포판을 실행할 수 있게 해주는 기술입니다. 아래의 단계를 따라 진행해보세요:

**1. Windows 기능 켜기/끄기 설정:**

- 시작 메뉴에서 "Windows 기능 켜기/끄기"를 검색하여 실행합니다.
- 나타나는 창에서 "Windows Subsystem for Linux" 옵션을 체크하고 확인을 클릭합니다.
- 시스템을 재부팅할 것을 요구하면 재부팅합니다.

**2. WSL2 설치 및 활성화:**

- WSL2를 설치하기 위해, Windows Terminal 혹은 PowerShell을 관리자 권한으로 실행합니다.
- 다음 명령어를 입력하여 WSL2를 기본 버전으로 설정합니다.
  ```bash
  wsl --set-default-version 2
  ```

**3. 우분투 배포판 설치:**

- VSCode를 열고 "Extensions" 아이콘을 클릭하여 확장 기능을 검색합니다.
- "Remote - WSL" 확장을 찾아 설치합니다.
- 설치가 완료되면 VSCode를 다시 시작합니다.

**4. 우분투 배포판 선택 및 설치:**

- VSCode에서 왼쪽 하단의 "Remote Explorer" 아이콘을 클릭합니다.
- "WSL Targets" 섹션에서 "Connect to WSL..."을 클릭합니다.
- 나열된 WSL 배포판 중 원하는 배포판(예: Ubuntu)을 선택하여 연결합니다.
- 선택한 배포판이 실행되면서 VSCode에서 작업 환경이 열립니다.

이제 VSCode를 통해 WSL을 사용하여 우분투를 실행하고 관리할 수 있습니다. 이 환경에서 터미널을 사용하여 Linux 명령어를 실행하거나, 개발 작업을 진행할 수 있습니다.

### ❓ 질문 (User)
vs code 코드 내에 있는 extension에서 wsl 을 써도 똑같이 하면 될까?

### 💡 답변 (Assistant)
네, 맞습니다! VSCode의 확장 기능 중에서 "Remote - WSL" 확장을 사용하면 VSCode 내에서 간편하게 WSL(Windows Subsystem for Linux)을 활용할 수 있습니다. 이를 통해 코드 작업을 진행하면서 마치 로컬 환경에서처럼 Linux 환경을 사용할 수 있습니다.

아래는 "Remote - WSL" 확장을 통해 VSCode에서 WSL을 사용하는 방법을 간략히 설명한 것입니다:

1. **VSCode 설치 및 확장 설치:**

   - VSCode를 설치하고 실행합니다.
   - 좌측 사이드바에서 "Extensions" 아이콘을 클릭하여 확장 기능을 검색합니다.
   - "Remote - WSL"을 검색하여 설치합니다.

2. **WSL과 연결:**

   - 설치가 완료되면, 왼쪽 하단에 위치한 "><" 아이콘(또는 "Remote Explorer" 아이콘)을 클릭합니다.
   - "WSL Targets" 섹션에서 "Connect to WSL..."을 선택합니다.
   - 이제 사용 가능한 WSL 배포판 목록이 표시됩니다.
   - 원하는 WSL 배포판(예: Ubuntu)을 선택하여 연결합니다.

3. **WSL 환경에서 코드 작업:**

   - 선택한 WSL 배포판이 실행되면 VSCode 환경이 그 안에서 열립니다.
   - 이제 마치 Linux 환경에서 작업하듯이 터미널을 통해 명령어를 실행하거나 코드를 작성할 수 있습니다.
   - 파일 탐색기 등을 통해 코드 파일을 열고 편집할 수 있습니다.

이렇게 하면 VSCode 내에서 WSL을 활용하여 Linux 환경을 사용할 수 있으며, 코드 작업과 개발을 원활하게 수행할 수 있습니다.

### ❓ 질문 (User)
conda create -n [가상환경이름] python=3.8 을 하면 python 3.8.16 같이 최신버전으로 설치되던데 우분투에서는 대체되는 명령어를 쓰면 똑같이 될까?

### 💡 답변 (Assistant)
네, 우분투에서도 Conda를 사용하여 가상 환경을 생성하고 특정 버전의 Python을 설치할 수 있습니다. Conda는 다양한 플랫폼에서 동일한 방식으로 작동하므로 Windows와 우분투에서 거의 동일한 명령어를 사용할 수 있습니다.

다만, Conda 명령어는 환경에 따라 설치되는 버전이 달라질 수 있습니다. 가장 정확한 결과를 얻으려면 Conda 명령어를 사용하여 원하는 버전을 직접 지정하는 것이 좋습니다.

우분투에서 Conda를 사용하여 특정 버전의 Python 가상 환경을 생성하려면 다음과 같은 명령어를 사용할 수 있습니다:

```bash
conda create -n 가상환경이름 python=3.8
```

여기서 `가상환경이름`에는 원하는 가상 환경의 이름을 넣어주시면 됩니다. 이 명령어는 Conda를 통해 Python 3.8 버전을 설치한 가상 환경을 생성합니다.

주의: Conda의 패키지 저장소가 최신 버전으로 업데이트되지 않았을 수도 있으므로, 항상 최신 버전을 가져오지 않을 수 있습니다. 필요한 버전이 제대로 설치되었는지 확인하는 것이 중요합니다.

### ❓ 질문 (User)
종합하면 vs code extensions 에서 wsl 을 설치하고 Ubuntu 설치 후 conda ~~~ 하면 되는거네? 혹시 아나콘다 같은 패키지를 설치할 필요는 없을까?

### 💡 답변 (Assistant)
네, 맞습니다. 아래는 전체적인 과정을 요약한 것입니다:

1. **VSCode Extensions 설치:**
   - VSCode를 열고 "Extensions" 아이콘을 클릭하여 확장 기능을 검색합니다.
   - "Remote - WSL" 확장을 설치합니다.

2. **WSL을 통한 Ubuntu 설치 및 연결:**
   - "Remote Explorer" 아이콘을 클릭하고 "WSL Targets" 섹션에서 "Connect to WSL..."을 선택합니다.
   - Ubuntu 배포판을 선택하여 연결합니다.

3. **Conda를 통한 가상 환경 생성:**
   - 터미널에서 `conda create -n 가상환경이름 python=3.8` 명령어를 실행하여 가상 환경을 생성합니다.

4. **가상 환경 활성화 및 작업:**
   - `conda activate 가상환경이름` 명령어를 실행하여 생성한 가상 환경을 활성화합니다.
   - 이제 가상 환경에서 필요한 패키지 설치 및 작업을 진행합니다.

**아나콘다(Anaconda) 설치 여부:**
- Conda를 사용하려면 아나콘다를 설치할 필요가 없습니다. Conda는 아나콘다 배포판의 일부이지만 별도로 설치해서 사용할 수도 있습니다.
- WSL 내에서 가상 환경을 생성하고 패키지를 관리하는 데 Conda를 사용하는 것이 편리할 수 있습니다.
- 만약 아나콘다 배포판 전체를 설치하고 싶다면, WSL 내에서도 설치가 가능합니다.

따라서 가상 환경을 만든 후에 필요한 패키지를 Conda로 설치하면 됩니다. 이렇게 하면 VSCode의 WSL 환경에서 Ubuntu에서 Conda를 사용하여 Python 환경을 구성하고 관리할 수 있습니다.

### ❓ 질문 (User)
혹시 기본적으로 base 환경에는 영향을 안주지?

### 💡 답변 (Assistant)
기본적으로 Conda의 가상 환경은 서로 독립적으로 관리되며, 하나의 가상 환경을 수정하거나 패키지를 설치하더라도 다른 가상 환경이나 기본(base) 환경에는 영향을 주지 않습니다.

Conda는 각 가상 환경을 분리된 공간에 설치하고 관리하기 때문에, 가상 환경 간의 충돌이나 영향을 최소화할 수 있습니다. 따라서 한 가상 환경에서 패키지를 설치하거나 수정하더라도 다른 가상 환경이나 기본 환경에는 영향을 미치지 않습니다.

그러나 기본(base) 환경을 수정하면 시스템 전체에 영향을 줄 수 있으므로, Conda를 사용할 때는 가상 환경을 사용하여 패키지를 설치하고 관리하는 것이 좋습니다. 이렇게 하면 개발 환경을 더욱 격리시켜 유지할 수 있습니다.
