### 문제 요약

- **입력**:  
  - 구슬의 종류 \(N\) (\(3 \leq N \le 5\))  
  - 각 종류별 구슬 개수 (각 개수는 1 이상 10 이하, 총합은 35 이하)

- **목표**:  
  - 주어진 모든 구슬을 사용하여, 구슬의 색이 \(N\)가지 있는 직선 목걸이를 만든다.
  - **제약 조건**: 임의의 연속된 3개의 구슬는 모두 다른 색이어야 한다.
    - 예를 들어, 연속된 3개 구슬 중에 같은 색이 2개 이상 있다면 안 됨.

- **예시**:  
  - 예제: 1번 구슬 2개, 2번 구슬 1개, 3번 구슬 1개 (색을 각각 초록, 파랑, 빨강으로 가정)  
    - 목걸이의 양 끝에 초록(1번)이 위치해야 하므로 가능한 경우는 두 가지:  
      - 초록–빨강–파랑–초록  
      - 초록–파랑–빨강–초록

---

### 문제의 특성 및 관찰

1. **연속 3개 구슬 조건의 함의**:
   - 임의의 3개의 연속 구슬가 모두 다르려면, 당연히 **인접한 2개의 구슬도 서로 달라야 한다.**
   - 즉, 같은 색의 구슬이 연속해서 나타나는 것은 삼연속 조건 위배의 원인이 됨.

2. **구슬의 배치**:
   - 구슬은 구분되는 개체가 아니라 색깔별로 개수가 정해진 “동질적”인 아이템이므로, 순서에 따른 배치 경우의 수를 구하는 문제이다.
   - 단, 동일 색끼리는 구분하지 않으므로 순열에서 중복을 제외한 경우의 수를 세야 한다.

3. **문제 규모**:
   - 최대 5종류, 각 종류 최대 10개, 총합 최대 35개.
   - 상태의 크기가 크지 않으므로 **DP(동적 계획법)** 또는 **백트래킹 + 메모이제이션**으로 해결 가능하다.

---

### 접근 방법

#### 1. 상태 정의

- **DP의 상태**:  
  현재 남은 각 색깔의 구슬 개수와 **직전 2개의 구슬 색**으로 상태를 정의한다.
  
  - 예: `dp(rem0, rem1, ..., rem{N-1}, last2, last1)`
    - `rem_i`: 아직 배치하지 않은 i번 구슬의 남은 개수.
    - `last2, last1`: 마지막에 배치한 두 구슬의 색 (순서가 있음).

#### 2. 점화식(Transition)

- **다음 구슬 선택**:
  - 현재 상태에서 다음에 올 구슬의 색 \(x\)를 고를 때,
  - 조건: 남은 개수가 있어야 하고, **\(x\)가 `last2`와 `last1` 모두와 달라야 한다.**  
    (즉, \((last2, last1, x)\)가 모두 다른 색이어야 함.)
  
- **점화식**:
  - 남은 구슬이 모두 0이면, valid한 하나의 배치를 완성한 것이므로 1을 반환.
  - 그 외의 경우, 각 가능한 \(x\)에 대해  
    \[
    \text{ways} += \text{dp}(\text{new remaining counts}, last1, x)
    \]
    (여기서 new remaining counts는 \(x\)의 개수를 1 감소시킨 상태)

#### 3. 초기 상태 설정

- **초기 2개 구슬 선택**:
  - 전체 구슬의 총 개수가 3 이상이므로, 목걸이의 시작은 2개 이상의 구슬부터 시작한다.
  - 첫 두 구슬은 아직 triple 조건이 발동하지 않지만, 최종 배치에서는 인접한 구슬이 같으면 안 되므로 서로 다른 색이어야 한다.
  - 따라서, 가능한 모든 **순서 있는 서로 다른 색**의 두 구슬 \((i, j)\) (i ≠ j)로 시작하고, 각 구슬의 개수를 1씩 감소시킨 후 DP를 시작한다.

#### 4. 예시 분석 (예제 3: 1번 구슬 2개, 2번 구슬 1개, 3번 구슬 1개)

- 초기 가능한 2개 구슬 선택:  
  가능한 ordered pair: (1,2), (1,3), (2,1), (2,3), (3,1), (3,2)
  
- 실제 valid한 배치가 되는 것은 (1,2)와 (1,3) 선택 후에 남은 구슬을 채워나갔을 때이다.
  - 예:  
    - (1,2) → 남은: 1번: 1, 2번: 0, 3번: 1  
    - 다음 구슬은 조건에 의해 `x` ≠ 1 (last2)와 `x` ≠ 2 (last1) → \(x\) = 3 만 선택 가능.  
    - 이후 마지막 자리에 남은 1번을 채우면 valid한 배치가 된다.
  - 다른 경우에서는 triple 조건을 만족시키지 못해 경우의 수가 0이 나온다.

#### 5. 메모이제이션

- **메모이제이션**:
  - 위의 상태 `(rem0, rem1, ..., rem{N-1}, last2, last1)`를 튜플 등으로 표현하여, 이미 계산한 상태에 대해서는 결과를 재사용.
  - 전체 상태의 수는 각 색깔의 개수가 최대 10 (즉, 0~10)이고, 색 종류가 최대 5이므로 \(11^5 \times 5 \times 5\) 정도의 상태가 나오지만, 실제로는 총합이 35 이하이므로 훨씬 적을 것이다.

---

### 결론

- **알고리즘 개요**:
  1. 모든 가능한 서로 다른 색의 두 구슬을 시작으로 초기 상태를 만든다.
  2. 상태 `(남은 구슬 개수, 마지막 두 구슬의 색)`를 이용한 재귀/DP를 수행하며, 다음 구슬을 고를 때 triple 조건 (마지막 2개와 새 구슬이 모두 다른)을 만족하는지 체크한다.
  3. 모든 구슬을 사용하면 1가지 valid 배치로 카운트한다.
  4. 메모이제이션을 사용하여 중복 계산을 피한다.
  5. 가능한 배치의 총 수를 출력한다.

이와 같이 문제를 해결할 수 있다.

### 💡 답변 (Assistant)
다음은 위의 아이디어를 바탕으로 작성한 파이썬 코드입니다.

```python
import sys
from functools import lru_cache

def main():
    input = sys.stdin.readline
    N = int(input().strip())
    beads = [int(input().strip()) for _ in range(N)]
    
    # dp 함수의 상태: (remaining_counts, last2, last1)
    # remaining_counts: 각 색깔 구슬의 남은 개수를 튜플로 표현
    @lru_cache(maxsize=None)
    def dp(rem, last2, last1):
        # rem은 각 색깔 구슬의 남은 개수를 나타내는 튜플
        if sum(rem) == 0:
            return 1
        ways = 0
        for color in range(N):
            if rem[color] > 0:
                # 새로 추가할 구슬 color가 last2, last1와 모두 달라야 한다.
                if color != last2 and color != last1:
                    new_rem = list(rem)
                    new_rem[color] -= 1
                    ways += dp(tuple(new_rem), last1, color)
        return ways

    res = 0
    # 초기 상태: 첫 두 구슬은 반드시 서로 다른 색이어야 함.
    for i in range(N):
        if beads[i] > 0:
            for j in range(N):
                if i != j and beads[j] > 0:
                    new_rem = list(beads)
                    new_rem[i] -= 1
                    new_rem[j] -= 1
                    res += dp(tuple(new_rem), i, j)
    print(res)

if __name__ == '__main__':
    main()
```

---

### 코드 설명

1. **입력 받기**:  
   - 첫 줄에 구슬 종류의 수 `N`을 입력받고, 이어서 각 구슬의 개수를 `beads` 리스트에 저장합니다.

2. **DP 함수 정의 (`dp`)**:  
   - 상태는 `(rem, last2, last1)`로, `rem`은 남은 구슬 개수를 튜플로 표현합니다.
   - 만약 모든 구슬을 사용했다면 (`sum(rem)==0`) 1을 반환합니다.
   - 그렇지 않으면, 가능한 모든 색깔에 대해 남은 구슬이 0보다 많고, 해당 색깔이 `last2`와 `last1`과 다르면 해당 구슬을 선택하고 재귀적으로 호출합니다.

3. **초기 상태 설정**:  
   - 첫 두 구슬은 반드시 서로 다른 색이어야 하므로, 가능한 `(i, j)` 쌍 (i ≠ j)로 시작한 후 남은 구슬의 개수를 업데이트하여 `dp` 함수를 호출합니다.
   - 모든 초기 상태에 대해 결과를 합산합니다.

4. **결과 출력**:  
   - 최종 경우의 수 `res`를 출력합니다.

이 코드로 문제에서 요구하는 조건에 맞게 목걸이를 만들 수 있는 경우의 수를 구할 수 있습니다.
