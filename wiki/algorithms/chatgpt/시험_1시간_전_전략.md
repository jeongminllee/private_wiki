## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
시험 1시간 전이야 지금까지 공부한거 요약해서 1시간 동안 공부할 내용으로 정리해줘

### 💡 답변 (Assistant)

# 🚨 1시간 최종 점검 루틴 (합격용)

## ⏱️ 0~10분: “무조건 맞춰야 하는 개념” 워밍업

### ✅ 테스트 기법 (최빈출)
- 화이트박스 vs 블랙박스
- 커버리지

✔ 핵심 암기
- 내부 구조 → 화이트박스  
- 외부 명세 → 블랙박스  

✔ 커버리지 정리
- 문장 커버리지
- 분기(결정) 커버리지
- 조건 커버리지
- 조건/결정 커버리지

👉 특히 **조건 vs 결정 차이** 다시 확인

---

### ✅ 접근통제 모델 (100% 나온다)
- MAC → 중앙 통제 (군대)
- DAC → 소유자 권한
- RBAC → 역할 기반

👉 문제 보면 바로 매칭 가능해야 함

---

### ✅ 암호화 & 인증
- AES → 대칭키 (표준)
- RSA → 공개키
- OAuth → 토큰 기반 인증 (SNS 로그인)
- JWT → 토큰
- SSO → 한 번 로그인

---

## ⏱️ 10~25분: “헷갈리기 쉬운 개념 정리”

### ✅ 네트워크
- 서브넷 계산
- 패킷 교환

✔ 연결형 → 가상회선
✔ 비연결형 → 데이터그램

👉 문제 패턴 그대로 외워라

---

### ✅ 보안 공격
- 세션 하이재킹
- XSS / SQL Injection

✔ 핵심 키워드
- “세션 가로채기” → 하이재킹
- “스크립트 삽입” → XSS

---

### ✅ 디자인 패턴 (자주 나오는 것만)
- Adapter → 인터페이스 변환
- Singleton → 하나만 생성
- Factory → 객체 생성 캡슐화

👉 길게 생각하지 말고 “키워드 매칭”

---

## ⏱️ 25~40분: “코딩/자료구조 빠르게 정리”

### ✅ 연결 리스트
- 삽입 / 삭제 흐름
- 포인터 이동

✔ 시험 핵심
- prev → curr → next 흐름

---

### ✅ 스택 / 큐
- LIFO / FIFO
- DFS → 스택
- BFS → 큐

---

### ✅ 정렬
- 버블 / 선택 / 삽입 (기본 개념만)
👉 시간 복잡도까지는 보통 안 물음

---

### ✅ 트리
- 이진트리 순회
  - 전위 / 중위 / 후위

👉 순서만 정확히 기억

---

## ⏱️ 40~55분: “실수 방지 구간 (이게 진짜 중요)”

### 🚨 자주 틀리는 것 TOP

1. 조건 vs 결정 커버리지
2. MAC / DAC / RBAC 구분
3. OAuth vs SSO vs JWT
4. 가상회선 vs 데이터그램
5. 하이재킹 vs 스니핑

👉 여기서 틀리면 합격/불합격 갈림

---

## ⏱️ 55~60분: “마인드셋 정리”

✔ 모르면 찍지 말고 키워드 찾기  
✔ 문제에서 “정의 문장” 찾기  
✔ 아는 문제 100% 맞추기  

---

# 🧠 마지막 핵심 압축 (이거만 보고 들어가도 됨)

✔ 내부 → 화이트박스  
✔ 외부 → 블랙박스  

✔ 중앙통제 → MAC  
✔ 역할 → RBAC  
✔ 소유자 → DAC  

✔ 토큰 로그인 → OAuth  
✔ 한 번 로그인 → SSO  

✔ 연결형 → 가상회선  
✔ 비연결형 → 데이터그램  

✔ 세션 가로채기 → 하이재킹  

✔ 인터페이스 변환 → Adapter  

---

# 🔥 시험 직전 전략 (진짜 중요)

- **서술형 → 키워드 중심으로**
- **코드 문제 → 실행 흐름만 따라가기**
- **모르는 문제 → 제거법으로 최소 50% 확률 확보**
