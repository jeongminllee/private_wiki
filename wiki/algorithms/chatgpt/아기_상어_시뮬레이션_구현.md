## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```python
# 0 : 빈칸
# 1 ~ 6 : 물고기의 크기
# 9 : 아기 상어의 위치
# 처음 아기 상어의 크기 2
# 상하좌우 인접한 한 칸씩 이동
# 아기 상어는 자기보다 큰 물고기가 있는 칸은 지나갈 수 없고, 나머지는 지나갈 수 있음.
# 자기보다 작은 물고기만 먹을 수 있음.
# => 크기가 같으면 먹을 순 없지만, 지나갈 순 있음.

# 먹을 수 있으면 그 물고기 먹으러 간다.
# 먹을 수 있는게 여러 마리면 그 중 가장 가까운 물고기를 먹으러 간다.
# 거리가 같으면, 가장 위에 있는 물고기, 가장 왼쪽의 물고기

# 이동은 1초가 걸리고 먹는데는 시간이 걸리지 않는다.

# 자신의 크기와 같은 수의 물고기를 먹으면 크기가 1 증가한다.
```
위 주석만 보고 파이썬 코드를 구현해줘

### 💡 답변 (Assistant)
아래는 주어진 조건에 따라 Python으로 구현한 아기 상어 시뮬레이션 코드입니다. BFS(너비 우선 탐색)를 사용하여 가장 가까운 물고기를 찾고, 조건에 따라 아기 상어를 이동시키고 크기를 증가시키는 로직을 구현했습니다.

---

### 💡 답변 (Assistant)
위 코드는 다음의 주요 단계를 포함합니다:
1. **BFS로 먹을 물고기 탐색**: 아기 상어가 이동 가능한 범위를 탐색하며 가장 가까운 먹을 수 있는 물고기를 찾습니다.
2. **조건에 따른 정렬**: 거리, 위쪽, 왼쪽 순으로 우선순위를 부여하여 가장 적합한 물고기를 선택합니다.
3. **물고기 섭취 및 크기 증가**: 먹은 물고기 수에 따라 상어의 크기를 증가시킵니다.
4. **시뮬레이션 종료 조건**: 먹을 수 있는 물고기가 없으면 종료합니다.

예제 보드에서 아기 상어가 물고기를 모두 먹는 데 걸리는 시간을 출력합니다. 필요에 따라 보드를 수정하여 다른 테스트를 진행할 수 있습니다.

### 💡 답변 (Assistant)
아기 상어 시뮬레이션 코드를 다음과 같은 단계로 쪼개어 설명할 수 있습니다:

---

### 1. **초기 설정**
- **보드와 상어 위치 초기화**  
  - 입력받은 `board`에서 아기 상어의 초기 위치(값이 9인 곳)를 찾습니다.  
  - 아기 상어의 위치를 기록한 후, 그 위치를 빈칸(0)으로 설정합니다.

- **상어의 초기 상태**  
  - 상어의 초기 크기는 `2`, 먹은 물고기 수는 `0`으로 시작합니다.
  - 전체 시뮬레이션의 경과 시간을 저장할 변수 `time`을 초기화합니다.

---

### 2. **BFS(너비 우선 탐색)로 물고기 탐색**
- **탐색 시작**  
  - 현재 상어 위치에서 BFS를 수행하여 상어가 도달할 수 있는 모든 칸을 탐색합니다.
  - BFS는 `queue`를 사용해 (x, y, 이동 거리)를 관리합니다.
  - `visited` 배열로 이미 방문한 칸을 기록하여 중복 방문을 방지합니다.

- **이동 가능 조건**  
  - 상어보다 크기가 큰 물고기가 있는 칸은 이동할 수 없습니다.
  - 빈칸(0)과 상어 크기와 같은 물고기가 있는 칸은 지나갈 수만 있습니다.
  - 상어보다 작은 물고기가 있는 칸은 **먹을 수 있는 대상**이 됩니다.

- **먹을 물고기 선택**  
  - BFS로 먹을 수 있는 물고기를 모두 찾은 후, 조건에 따라 우선순위를 정합니다:
    1. **거리**가 가장 가까운 물고기 우선.
    2. 거리가 같다면 **위쪽**에 있는 물고기 우선.
    3. 위쪽도 같다면 **왼쪽**에 있는 물고기 우선.

---

### 3. **물고기 먹기 및 이동**
- **물고기 섭취**  
  - 선택된 물고기로 상어를 이동시키고, 물고기를 먹습니다.
  - 먹은 물고기 수를 1 증가시키고, 먹은 칸을 빈칸(0)으로 바꿉니다.

- **상어 크기 증가 조건**  
  - 먹은 물고기 수가 현재 상어 크기와 같아지면 상어의 크기를 1 증가시킵니다.
  - 먹은 물고기 수를 다시 0으로 초기화합니다.

- **시간 경과 추가**  
  - 물고기를 먹으러 가는 데 걸린 거리(시간)를 `time`에 더합니다.

---

### 4. **종료 조건**
- **먹을 물고기 없음**  
  - BFS 결과 먹을 물고기가 없으면 시뮬레이션을 종료합니다.
  - 이때까지 누적된 `time`이 결과가 됩니다.

---

### 5. **결과 출력**
- 시뮬레이션 종료 후, `time` 값을 출력하여 아기 상어가 물고기를 모두 먹는 데 걸린 시간을 반환합니다.

---

### **동작 예시**
#### 입력 보드
```plaintext
4 3 2 1 0
0 0 0 0 0
0 0 9 0 0
0 0 0 0 0
1 2 3 4 5
```
1. **아기 상어 시작 위치**: (2, 2), 크기 2
2. **첫 번째 이동**: 가장 가까운 물고기 (4, 0)로 이동 (거리: 4초)
3. **두 번째 이동**: (3, 0)로 이동 (거리: 1초)
4. **상어 크기 증가**: 먹은 물고기 2마리 → 크기 3
5. ... (반복)

#### 결과
```
시간: 16초
```
