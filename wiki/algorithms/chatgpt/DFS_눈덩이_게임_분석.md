# DFS 눈덩이 게임 분석

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-06-14

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
# 굴린다 : +1 칸 이동, 눈덩이 크기 + a
# 던진다 : +2 칸 이동, (눈덩이 크기 // 2) + a

def dfs(size, time, idx) :
    global snowball

    if time > M :
        return

    else :
        snowball = max(snowball, size)

    if idx <= N - 1 :
        dfs(size + arr[idx + 1], time + 1, idx + 1)

    if idx <= N - 2 :
        dfs((size // 2) + arr[idx + 2], time + 1, idx + 2)

# N, M : 앞마당의 길이, 대회의 시간
N, M = map(int, input().split())

# 눈덩이 크기 a 총 길이 N + 1
arr = [1] + list(map(int, input().split()))

snowball = 0
dfs(1, 0, 0)
print(snowball)
```

이 코드를 분석해줘

### 💡 답변 (Assistant)
이 코드는 **눈덩이 굴리기 게임**을 시뮬레이션하는 **DFS(깊이 우선 탐색)** 기반의 백트래킹 알고리즘입니다. 주어진 조건 아래에서 눈덩이의 최대 크기를 계산합니다.

---

### 🔧 **문제 설정**

- 눈덩이는 처음에 **크기 1**, **위치 0**에서 시작.
- 앞마당은 총 **N + 1칸**(0부터 N까지).
- 눈밭에는 각 칸마다 `arr[i]`만큼 눈이 있어 굴리거나 던질 때 눈덩이에 더해짐.
- 총 사용 가능한 시간은 `M`초이며, **매 초마다 다음과 같은 두 가지 선택지 중 하나를 선택할 수 있음**:
  - `굴린다`: +1칸 이동, 시간 +1초, 눈덩이 크기 += `arr[idx + 1]`
  - `던진다`: +2칸 이동, 시간 +1초, 눈덩이 크기 = (현재 크기 // 2) + `arr[idx + 2]`

---

### 🧠 **코드 구성 설명**

#### 📌 입력 처리
```python
N, M = map(int, input().split())
arr = [1] + list(map(int, input().split()))
```

- `N`: 앞마당 길이 (칸 수는 `N + 1`)
- `M`: 대회 제한 시간
- `arr`: 눈덩이 크기 정보. `arr[0]`을 `1`로 설정해 시작점 처리 (`idx=0`일 때 눈덩이 초기 크기와 맞춤)

#### 📌 DFS 함수
```python
def dfs(size, time, idx):
    global snowball

    if time > M:
        return

    snowball = max(snowball, size)

    if idx <= N - 1:
        dfs(size + arr[idx + 1], time + 1, idx + 1)

    if idx <= N - 2:
        dfs((size // 2) + arr[idx + 2], time + 1, idx + 2)
```

- `size`: 현재 눈덩이 크기
- `time`: 현재 사용한 시간
- `idx`: 현재 위치 (칸 인덱스)
- `snowball`: 도달한 최대 눈덩이 크기 (전역변수)

**로직 요약**:

1. 시간이 초과되면 리턴
2. 그렇지 않으면 `snowball` 최대값 갱신
3. 가능한 경우:
   - 굴리기 (`+1칸`): 다음 칸으로 이동, 시간 +1, 눈덩이 크기 증가
   - 던지기 (`+2칸`): 다다음 칸으로 이동, 시간 +1, 눈덩이 크기 절반 + 새 칸 눈 추가

#### 📌 DFS 실행
```python
snowball = 0
dfs(1, 0, 0)
print(snowball)
```

- 눈덩이 크기 1, 시간 0, 위치 0에서 시작

---

### ✅ 예제 시나리오

입력:
```
3 2
2 3 1 4
```
→ `arr = [1, 2, 3, 1, 4]`

가능한 경로 예시:
- 굴리기-굴리기
- 굴리기-던지기
- 던지기-굴리기
- 던지기-던지기

각각의 눈덩이 크기를 계산해 `snowball`에 가장 큰 값을 저장

---

### 📌 시간 복잡도

- DFS로 모든 경로 탐색: 최대 `2^M` 가지
- M(최대 시간)이 작으면 완전 탐색 가능 (M ≤ 10~15 정도는 가능)

---

이 코드는 시간 제한 안에서 눈덩이의 크기를 최대화하는 모든 경로를 탐색하며, **최대 눈덩이 크기**를 출력하는 **백트래킹 기반의 완전 탐색** 구현입니다.

10 5
1 3 4 5 6 7 8 10 12 14

이 데이터를 예시로 설명해줘

### 💡 답변 (Assistant)
좋습니다. 주어진 입력값:

```
10 5
1 3 4 5 6 7 8 10 12 14
```

### 📌 입력 의미

- `N = 10`: 앞마당의 길이는 10칸 (`arr[0]` ~ `arr[10]` → 총 11칸)
- `M = 5`: 대회에서 사용할 수 있는 최대 시간 (5초)
- 눈의 양 배열: `arr[1]` ~ `arr[10]`까지 각 칸에 있는 눈의 양  
  → 따라서 전체 `arr` = `[1, 1, 3, 4, 5, 6, 7, 8, 10, 12, 14]`  
  (※ `arr[0] = 1`로 시작 지점의 눈덩이 크기를 맞추기 위해 임의 설정)

---

### ⛳ 게임 시작

- **초기 상태**: 눈덩이 크기 `1`, 시간 `0`, 위치 `0`
- **가능한 선택**: 각 초마다
  - `굴리기`: `+1`칸 이동, 눈덩이 크기 `+ arr[idx+1]`, 시간 +1
  - `던지기`: `+2`칸 이동, 눈덩이 크기 `= (size // 2) + arr[idx+2]`, 시간 +1

---

### 🧭 경로 탐색 예시

#### 첫 번째 단계 (시간: 0초, 위치: 0, 크기: 1)

- `굴리기`: 이동 → idx 1, 크기 = 1 + arr[1] = 1 + 1 = **2**, 시간: 1
- `던지기`: 이동 → idx 2, 크기 = (1 // 2) + arr[2] = 0 + 3 = **3**, 시간: 1

---

### 예시 경로 1: `굴리기 → 굴리기 → 굴리기 → 굴리기 → 굴리기`

- t=0: idx=0, size=1  
- t=1: idx=1, size=2 (arr[1]=1)  
- t=2: idx=2, size=2+3=5  
- t=3: idx=3, size=5+4=9  
- t=4: idx=4, size=9+5=14  
- t=5: idx=5, size=14+6=20  
→ 총 시간 5초 소모, 도달한 눈덩이 크기: **20**

---

### 예시 경로 2: `던지기 → 굴리기 → 던지기 → 굴리기 → 굴리기`

- t=0: idx=0, size=1  
- t=1: 던지기 → idx=2, size=0+3=3  
- t=2: 굴리기 → idx=3, size=3+4=7  
- t=3: 던지기 → idx=5, size=7//2=3 + 6 = 9  
- t=4: 굴리기 → idx=6, size=9+7=16  
- t=5: 굴리기 → idx=7, size=16+8=24  
→ 도달한 눈덩이 크기: **24**

---

### 예시 경로 3: `던지기 → 던지기 → 던지기 → 굴리기 → 굴리기`

- t=0: idx=0, size=1  
- t=1: 던지기 → idx=2, size=3  
- t=2: 던지기 → idx=4, size=3//2=1 + 5 = 6  
- t=3: 던지기 → idx=6, size=6//2=3 + 7 = 10  
- t=4: 굴리기 → idx=7, size=10+8=18  
- t=5: 굴리기 → idx=8, size=18+10 = **28**

→ 눈덩이 크기: **28**

---

### 🔚 최종 결과

이러한 방식으로 **모든 가능한 경로를 DFS로 탐색**한 뒤,  
도달 가능한 **가장 큰 눈덩이 크기**를 `snowball`에 저장하게 됩니다.

즉, 최종 출력은:

```python
print(snowball)  # → 가장 큰 눈덩이 크기 출력
```

위의 예시 중 `28`이 가장 클 수도 있지만, 모든 경로를 탐색해야 진짜 최댓값을 알 수 있습니다.  
DFS는 이를 백트래킹 방식으로 완전 탐색하며, 시간 내 가능한 최대값을 찾아냅니다.
