### 💡 답변 (Assistant)
응. 다만 **맥북 프로 2018 15인치에서 외장 모니터를 일반 USB-C/Thunderbolt → HDMI·DisplayPort 방식으로 직접 연결한 상태라면, Radeon 외장 그래픽을 끄는 것은 사실상 불가능해.**

정확히 말하면 네가 말한 “외장 GPU”는 외부 장치인 eGPU가 아니라, 맥북 내부에 들어 있는 **AMD Radeon 독립 GPU(dGPU)**야.

## 왜 끌 수 없나

이 모델은 외부 디스플레이 출력 경로가 Radeon GPU에 연결돼 있어. 그래서 macOS의 **자동 그래픽 전환**을 켜 두더라도 외장 모니터를 연결하는 순간 Radeon GPU가 활성화되고, 모니터를 분리할 때까지 유지된다. Apple도 외장 디스플레이 연결 시 고성능 GPU를 계속 사용한다고 명시하고 있어. citeturn706720view0

따라서 다음 방법들은 해결책이 되지 않아.

- 시스템 설정에서 `자동 그래픽 전환` 켜기
- `gfxCardStatus`로 Integrated Only 강제하기
- 맥북 덮개를 닫고 클램셸 모드로 사용하기
- USB-C 포트를 좌우로 바꾸기
- HDMI 대신 DisplayPort로 바꾸기

`gfxCardStatus`로 Intel GPU만 강제하면 외장 모니터가 꺼지거나 전환 자체가 거부될 가능성이 크다. 소프트웨어 설정 문제가 아니라 디스플레이 출력 배선 구조의 문제이기 때문이야.

## Radeon을 피할 수 있는 실질적인 방법

유일하게 현실적인 우회 방법은 **DisplayLink 방식의 USB 그래픽 어댑터 또는 도킹스테이션**을 사용하는 거야.

연결 구조는 다음과 같아.

```text
맥북 USB 포트
    ↓
DisplayLink 칩 내장 어댑터/독
    ↓
HDMI 또는 DisplayPort
    ↓
외장 모니터
```

DisplayLink는 모니터를 GPU에 직접 연결하는 대신 화면 데이터를 소프트웨어로 캡처한 후 USB로 전달한다. 따라서 일반 HDMI·DP 직결 때문에 Radeon GPU가 강제로 켜지는 상황은 피할 수 있다. DisplayLink 측에서도 이를 GPU에 직접 연결되지 않은 가상 디스플레이 방식으로 설명하고 있다. citeturn706720view1

다만 단점이 있어.

- DisplayLink Manager 설치 필요
- macOS의 `화면 및 시스템 오디오 녹화` 권한 필요
- 약간의 CPU 사용량과 입력 지연 발생 가능
- 고주사율·그래픽 작업에는 부적합
- Netflix, Disney+, Amazon Prime 등 일부 DRM 영상이 검은 화면으로 나올 수 있음 citeturn706720view3
- 반드시 **“DisplayLink 지원”이라고 명시된 제품**이어야 함

코딩, 웹브라우징, 문서 작업, 터미널, 일반적인 60Hz 모니터 사용이라면 비교적 잘 맞는 방식이야. 최신 DisplayLink Manager도 Intel Mac과 현재 macOS 버전을 계속 지원하고 있지만, 사용하는 macOS 버전에 맞는 드라이버를 선택해야 한다. citeturn706720view2

## 돈을 들이지 않고 발열을 줄이는 방법

Radeon 자체를 끌 수는 없지만 소비전력과 발열을 조금 줄일 수는 있어.

1. 모니터 주사율을 **60Hz**로 설정한다.
2. 4K 모니터라면 과도한 HiDPI 배율 대신 기본 또는 낮은 해상도를 시험한다.
3. 외장 모니터 하나만 사용하고 불필요한 디스플레이 확장은 피한다.
4. 브라우저 탭, 영상 재생, Electron 앱처럼 GPU를 자주 사용하는 프로그램을 줄인다.
5. 맥북 후면을 받침대로 들어 올려 흡·배기 공간을 확보한다.
6. 내부 팬과 방열판에 먼지가 쌓였다면 청소하고, 오래된 제품이라면 서멀 상태도 점검한다.

핵심은 이거야.

> **현재 어댑터로 모니터를 직접 연결하면서 Radeon만 끄는 것은 불가능하고, Radeon을 피하려면 DisplayLink 장비가 필요하다.**

다만 DisplayLink 장비 비용과 불편까지 고려하면, 우선은 **60Hz 설정 + 해상도 조정 + 냉각 개선**부터 적용하는 게 가장 경제적이야.

## 내장 화면만 사용할 때 강제하는 방법

외장 모니터를 먼저 분리하고 터미널에서 다음을 실행할 수 있어.

```bash
sudo pmset -a gpuswitch 0
```

설정값 확인:

```bash
pmset -g | grep gpuswitch
```

`gpuswitch 0`으로 나오면 Intel UHD Graphics 630 우선 모드로 설정된 것이다. 일반적으로 알려진 값은 다음과 같다.

```text
0: 내장 Intel GPU 우선
1: Radeon GPU 고정
2: 자동 그래픽 전환
```

원래 상태로 복구하려면:

```bash
sudo pmset -a gpuswitch 2
```

다만 이 값들은 Apple이 일반 사용자용으로 공식 문서화한 설정은 아니며, macOS 버전에 따라 제대로 적용되지 않을 수 있다. 실제 2018년형 사례에서도 `gpuswitch 0`을 설정했지만 외장 모니터는 여전히 Radeon에 연결된 것으로 표시됐다. 즉, 이 명령은 **그래픽 전환 정책을 바꾸는 것이지 Radeon의 전원을 물리적으로 차단하는 명령이 아니다.** citeturn108727view2

## gfxCardStatus도 동일한 한계가 있다

`gfxCardStatus`에는 `Integrated Only` 기능이 있어서 Intel GPU를 강제로 선택할 수 있다. citeturn108727view1

하지만 외장 모니터가 Radeon 출력 경로를 사용하므로 다음 중 하나가 발생한다.

- Integrated Only 선택이 거부됨
- 다시 Discrete GPU로 전환됨
- 외장 모니터가 검은 화면이 됨
- 메뉴에는 Intel로 표시돼도 Radeon이 외장 출력을 계속 담당함

## 하지 않는 게 좋은 방법

인터넷에는 AMD 관련 커널 확장 파일을 삭제하거나 이동하는 방법, NVRAM 변수를 조작하는 방법, SIP를 끄는 방법도 나온다. 하지만 2018년형 A1990에서는 다음 위험이 있다.

- 부팅 실패
- 로그인 이후 검은 화면
- 잠자기·깨우기 오류
- macOS 업데이트 실패
- 외장 모니터 완전 사용 불가
- 복구 모드에서 원상복구해야 하는 상황

특히 오래된 **2011년형 GPU 고장 우회법은 2018년형에 그대로 적용되지 않는다.** 실제 2018년형 사례에서도 구형 모델용 비활성화 절차는 적용할 수 없었다고 보고됐다. citeturn108727view2

따라서 현재 목적이 **외장 모니터는 계속 쓰면서 Radeon만 끄는 것**이라면 결론은 다음과 같아.

> USB-C/DisplayPort/HDMI 직결 상태에서는 불가능하다.  
> `pmset`이나 `gfxCardStatus`로 강제해도 Radeon의 외장 디스플레이 출력까지 끌 수는 없다.

Radeon을 실제로 사용하지 않으면서 외장 모니터를 유지하려면 GPU 직접 출력이 아닌 **DisplayLink USB 어댑터·도킹스테이션** 방식으로 연결해야 한다.
