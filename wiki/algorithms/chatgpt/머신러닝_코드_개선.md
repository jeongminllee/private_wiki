### ❓ 질문 (User)
```
'''
#    There are 28 rows of data.  The data includes:
#
#      I,   the index;
#      A1,  the local selling prices, in hundreds of dollars;
#      A2,  the number of bathrooms;
#      A3,  the area of the site in thousands of square feet;
#      A4,  the size of the living space in thousands of square feet;
#      A5,  the number of garages;
#      A6,  the number of rooms;
#      A7,  the number of bedrooms;
#      A8,  the age in years;
#      A9,  1 = brick, 2 = brick/wood, 3 = aluminum/wood, 4 = wood.
#      A10, 1 = two story, 2 = split level, 3 = ranch
#      A11, number of fire places.
#      B,   the selling price.
#
#    We seek a model of the form:
#
#    B = A1 * X1 + A2 * X2 + A3 * X3 + A4 * X4 + A5 * X5 + A6 * X6 + A7 * X7
#      + A8 * X8 + A9 * X9 + A10 * X10 + A11 * X11

13 columns
28 rows
Index
A1, the local selling prices, in hundreds of dollars;
A2, the number of bathrooms;
A3, the area of the site in thousands of square feet;
A4, the size of the living space in thousands of square feet;
A5, the number of garages;
A6, the number of rooms;
A7, the number of bedrooms;
A8, the age in years;
A9, construction type
A10, architecture type
A11, number of fire places.
B, selling price 
'''
import pandas as pd
import numpy as np
import torch
from torch import nn, optim
import torch.nn.functional as F

rtn_list = []
# 데이터, 리스트로 받아오기
try:
    with open('./pytorch/data/sell_house.txt', 'r', encoding='utf-8') as f :
        while True :
            line = list(map(float, (f.readline().split())))
            if len(line) == 0 :
                break
            rtn_list.append(line)
            
except :
    print("에러발생")

torch.manual_seed(42)
rand_idx = torch.randperm(28)

for idx in range(len(rand_idx)) :
    rtn_list[idx][0] = int(rand_idx[idx])

rtn_list.sort()
dataset = torch.FloatTensor(rtn_list)
X_train = dataset[:-5, 1:-1]
X_test = dataset[:-5, -1:]
y_train = dataset[-5:, 1:-1]
y_test = dataset[-5:, -1:]

c = torch.matmul(torch.matmul(torch.linalg.inv(torch.matmul(X_train.T, X_train)), X_train.T), X_test)
# c.shape (11, 1)

model = nn.Linear(in_features=11, out_features=1)
optimizer = optim.AdamW(model.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()

n_epochs = 1000

for i in range(n_epochs+1) :
    y_pred = model(X_train)
    loss = loss_fn(y_pred, X_test)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if i % 100 == 0 :
        print(f'epoch : {i}, loss : {loss.item()}')

for i in range(len(y_train)) :
    pred = model(y_train)
    print(pred)
    prob = F.mse_loss(pred, y_test)
    print(prob)
```
이거 머신러닝 분석 하려고 하고 있는데, 조금 더 잘 할 수는 없을까 싶어서 너한테 물어보려고 왔어. 너는 머신러닝 전문가니까 나한테 좋은 답을 줄 거라고 생각해.

## 1. 지금 코드에서 가장 큰 문제

현재 이 부분이 헷갈리게 되어 있습니다.

```python
X_train = dataset[:-5, 1:-1]
X_test = dataset[:-5, -1:]
y_train = dataset[-5:, 1:-1]
y_test = dataset[-5:, -1:]
```

실제로는 이렇게 해석됩니다.

```python
X_train = 앞 23개 데이터의 입력값
X_test  = 앞 23개 데이터의 정답값

y_train = 뒤 5개 데이터의 입력값
y_test  = 뒤 5개 데이터의 정답값
```

즉, 변수 이름이 잘못되어 있습니다.

정확히는 이렇게 써야 합니다.

```python
X_train = dataset[:-5, 1:-1]
y_train = dataset[:-5, -1:]

X_test = dataset[-5:, 1:-1]
y_test = dataset[-5:, -1:]
```

이게 첫 번째 핵심입니다.

## 2. 랜덤 셔플 방식도 개선하는 게 좋습니다

지금은 인덱스 컬럼을 랜덤 값으로 바꾸고 정렬해서 섞고 있습니다.

```python
rand_idx = torch.randperm(28)

for idx in range(len(rand_idx)) :
    rtn_list[idx][0] = int(rand_idx[idx])

rtn_list.sort()
```

동작은 할 수 있지만, 원래 데이터의 index 값을 덮어써버립니다. 더 깔끔하게는 Tensor로 만든 뒤 바로 섞으면 됩니다.

```python
dataset = torch.FloatTensor(rtn_list)

torch.manual_seed(42)
rand_idx = torch.randperm(dataset.shape[0])
dataset = dataset[rand_idx]
```

그리고 index 컬럼은 모델 학습에 필요 없으므로 제외하면 됩니다.

## 3. 현재 모델 구조 자체는 선형회귀로 맞습니다

```python
model = nn.Linear(in_features=11, out_features=1)
```

이건 다음 식을 학습합니다.

```text
B = w1*A1 + w2*A2 + ... + w11*A11 + bias
```

문제 설명에 나온 식에는 bias가 없지만, 실제 머신러닝에서는 보통 절편을 포함하는 게 더 자연스럽습니다.

`nn.Linear`는 기본적으로 bias가 있습니다.

```python
nn.Linear(11, 1)
```

즉 실제로는 다음 형태입니다.

```text
B = w1*A1 + w2*A2 + ... + w11*A11 + b
```

이게 보통 더 좋습니다.

## 4. 우선 최소 수정 버전

현재 코드를 최대한 유지하면서 고치면 이렇게 됩니다.

```python
import torch
from torch import nn, optim
import torch.nn.functional as F

rtn_list = []

try:
    with open('./pytorch/data/sell_house.txt', 'r', encoding='utf-8') as f:
        while True:
            line = f.readline()
            if line == "":
                break
            line = list(map(float, line.split()))
            rtn_list.append(line)

except Exception as e:
    print("에러 발생:", e)

# Tensor 변환
dataset = torch.FloatTensor(rtn_list)

# 랜덤 셔플
torch.manual_seed(42)
rand_idx = torch.randperm(dataset.shape[0])
dataset = dataset[rand_idx]

# 입력 X, 정답 y 분리
# dataset[:, 0]은 Index라서 제외
X = dataset[:, 1:-1]
y = dataset[:, -1:]

# train/test split
X_train = X[:-5]
y_train = y[:-5]

X_test = X[-5:]
y_test = y[-5:]

# 모델
model = nn.Linear(in_features=11, out_features=1)

optimizer = optim.AdamW(model.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()

n_epochs = 3000

for epoch in range(n_epochs + 1):
    y_pred = model(X_train)
    loss = loss_fn(y_pred, y_train)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if epoch % 300 == 0:
        print(f"epoch: {epoch}, train loss: {loss.item():.4f}")

# 평가
model.eval()

with torch.no_grad():
    train_pred = model(X_train)
    test_pred = model(X_test)

    train_mse = F.mse_loss(train_pred, y_train)
    test_mse = F.mse_loss(test_pred, y_test)

    train_rmse = torch.sqrt(train_mse)
    test_rmse = torch.sqrt(test_mse)

print("Train RMSE:", train_rmse.item())
print("Test RMSE:", test_rmse.item())

print("\n예측값 vs 실제값")
for pred, true in zip(test_pred, y_test):
    print(f"pred: {pred.item():.2f}, true: {true.item():.2f}")
```

## 7. 머신러닝 분석용으로 더 좋은 코드: sklearn 버전

이 데이터는 PyTorch보다 scikit-learn으로 분석하는 게 더 적합합니다.

```python
import pandas as pd
import numpy as np

from sklearn.model_selection import KFold, cross_val_score
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LinearRegression, RidgeCV
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 데이터 불러오기
columns = [
    "Index", "A1", "A2", "A3", "A4", "A5", "A6",
    "A7", "A8", "A9", "A10", "A11", "B"
]

df = pd.read_csv(
    "./pytorch/data/sell_house.txt",
    sep=r"\s+",
    header=None,
    names=columns
)

# 입력 / 정답 분리
X = df.drop(columns=["Index", "B"])
y = df["B"]

# 수치형 / 범주형 컬럼 구분
numeric_features = ["A1", "A2", "A3", "A4", "A5", "A6", "A7", "A8", "A11"]
categorical_features = ["A9", "A10"]

# 전처리
preprocessor = ColumnTransformer(
    transformers=[
        ("num", StandardScaler(), numeric_features),
        ("cat", OneHotEncoder(drop="first"), categorical_features)
    ]
)

# Ridge Regression
model = Pipeline(
    steps=[
        ("preprocess", preprocessor),
        ("regressor", RidgeCV(alphas=[0.01, 0.1, 1.0, 10.0, 100.0]))
    ]
)

# K-Fold Cross Validation
kf = KFold(n_splits=5, shuffle=True, random_state=42)

rmse_scores = -cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="neg_root_mean_squared_error"
)

mae_scores = -cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="neg_mean_absolute_error"
)

r2_scores = cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="r2"
)

print("RMSE scores:", rmse_scores)
print("Mean RMSE:", rmse_scores.mean())

print("MAE scores:", mae_scores)
print("Mean MAE:", mae_scores.mean())

print("R2 scores:", r2_scores)
print("Mean R2:", r2_scores.mean())

# 전체 데이터로 최종 학습
model.fit(X, y)

ridge = model.named_steps["regressor"]
print("선택된 alpha:", ridge.alpha_)
```

이 코드가 현재 PyTorch 코드보다 분석적으로 더 좋습니다.

이유는 다음과 같습니다.

```text
1. 범주형 변수 A9, A10을 원핫인코딩함
2. 수치형 변수는 StandardScaler로 스케일링함
3. 데이터가 작기 때문에 train/test 1회 분리보다 K-Fold 검증을 사용함
4. Linear Regression보다 Ridge Regression으로 과적합을 줄임
5. RMSE, MAE, R2로 성능을 평가함
```

## 8. PyTorch로 계속 하고 싶다면 스케일링은 거의 필수입니다

현재 feature들의 단위가 다릅니다.

예를 들면:

```text
A1: 지역 판매가격, hundreds of dollars
A3: 대지 면적
A8: 나이
A11: 벽난로 개수
```

스케일이 다르면 PyTorch 학습이 불안정해질 수 있습니다.

PyTorch 버전에서 최소한 이렇게 해주는 게 좋습니다.

```python
X_mean = X_train.mean(dim=0)
X_std = X_train.std(dim=0)

X_train_scaled = (X_train - X_mean) / X_std
X_test_scaled = (X_test - X_mean) / X_std
```

그리고 모델에는 scaled 데이터를 넣습니다.

```python
y_pred = model(X_train_scaled)
```

평가할 때도:

```python
test_pred = model(X_test_scaled)
```

## 9. 정규방정식 코드도 개선 가능

현재 이 코드가 있습니다.

```python
c = torch.matmul(torch.matmul(torch.linalg.inv(torch.matmul(X_train.T, X_train)), X_train.T), X_test)
```

이건 수학적으로 다음입니다.

```text
w = (XᵀX)^-1 Xᵀy
```

하지만 `inverse`를 직접 쓰는 건 수치적으로 불안정할 수 있습니다.

더 좋은 방식은 `torch.linalg.lstsq`입니다.

```python
solution = torch.linalg.lstsq(X_train, y_train)
w = solution.solution

pred = X_test @ w
```

하지만 이것도 bias가 없습니다. bias까지 포함하려면 X 앞에 1 컬럼을 붙입니다.

```python
ones_train = torch.ones(X_train.shape[0], 1)
ones_test = torch.ones(X_test.shape[0], 1)

X_train_bias = torch.cat([ones_train, X_train], dim=1)
X_test_bias = torch.cat([ones_test, X_test], dim=1)

solution = torch.linalg.lstsq(X_train_bias, y_train)
coef = solution.solution

pred = X_test_bias @ coef

rmse = torch.sqrt(F.mse_loss(pred, y_test))
print("RMSE:", rmse.item())
```

### ❓ 질문 (User)
RuntimeError: The size of tensor a (23) must match the size of tensor b (5) at non-singleton dimension 0

### 💡 답변 (Assistant)
이 에러는 거의 확실하게 **예측값 개수와 정답값 개수가 다르기 때문에** 발생한 겁니다.

에러 메시지:

```python
RuntimeError: The size of tensor a (23) must match the size of tensor b (5) at non-singleton dimension 0
```

의 의미는:

```text
tensor a: 23개짜리
tensor b: 5개짜리
```

인데, 둘을 비교하려고 했다는 뜻입니다.

## 데이터 분리부터 다시 확인

더 좋은 방법은 `zip()`을 쓰는 겁니다. 인덱스 범위 실수를 줄일 수 있습니다.

```python
model.eval()

with torch.no_grad():
    test_pred = model(X_test)

for i, (pred, true) in enumerate(zip(test_pred, y_test), start=1):
    actual = true.item()
    predicted = pred.item()

    print(
        f"{i}번째 집 | "
        f"실제 가격: {actual:.2f} | "
        f"예측 가격: {predicted:.2f} | "
```

여기서 핵심은 이겁니다.

```python
enumerate(..., start=1)
```

은 **출력 번호만 1부터 시작**하게 해줍니다.  
실제 텐서 접근은 `zip()`이 알아서 순서대로 해주기 때문에 `y_test[5]` 같은 실수가 안 납니다.

정리하면:

```text
torch.Size([5, 1]) → 데이터 5개
가능한 인덱스 → 0, 1, 2, 3, 4
index 5 → 6번째 데이터라서 존재하지 않음
```

그래서 `range(1, len(y_test)+1)` 말고 `range(len(y_test))` 또는 `zip()`을 쓰면 됩니다.

```python
    torch.matmul(
        torch.linalg.inv(torch.matmul(X_train.T, X_train)),
        X_train.T
    ),
    X_test
)
```

수학적으로는:

```text
c = (X_trainᵀ X_train)^-1 X_trainᵀ X_test
```

입니다.

그런데 이 식은 **`X_test`가 target 값일 때만 선형회귀 계수 계산식처럼 의미가 있습니다.**

---

## 1. 선형회귀 계수를 구하려는 거라면 틀렸습니다

선형회귀에서 계수는 보통 이렇게 구합니다.

```text
w = (X_trainᵀ X_train)^-1 X_trainᵀ y_train
```

즉, 마지막에 들어가야 하는 것은 `X_test`가 아니라 **`y_train`**입니다.

PyTorch 코드로는:

```python
w = torch.linalg.inv(X_train.T @ X_train) @ X_train.T @ y_train
```

또는 더 깔끔하게:

```python
w = torch.linalg.solve(X_train.T @ X_train, X_train.T @ y_train)
```

`torch.linalg.inv()`를 직접 쓰는 것보다 `torch.linalg.solve()`가 더 안정적입니다.

---

## 2. 예측값을 구하려면 그다음에 X_test를 곱합니다

선형회귀 흐름은 이렇게입니다.

```text
1. train 데이터로 계수 w를 구함
2. test 입력 X_test에 w를 곱해서 예측값을 구함
```

즉:

```python
w = torch.linalg.solve(X_train.T @ X_train, X_train.T @ y_train)

test_pred = X_test @ w
```

전체적으로는:

```python
w = torch.linalg.solve(X_train.T @ X_train, X_train.T @ y_train)

train_pred = X_train @ w
test_pred = X_test @ w
```

---

## 3. 진짜 projection matrix를 구하려는 거라면 식이 다릅니다

선형대수에서 projection matrix는 보통 이렇게 정의합니다.

```text
P = X(XᵀX)^-1Xᵀ
```

즉:

```python
P = X_train @ torch.linalg.inv(X_train.T @ X_train) @ X_train.T
```

그러면 `P`의 shape은 다음과 같습니다.

```python
P.shape
# torch.Size([23, 23])
```

이 `P`는 어떤 벡터 `y_train`을 `X_train`의 column space 위로 projection합니다.

```python
y_hat = P @ y_train
```

즉:

```text
y_hat = X_train w
```

와 같은 결과입니다.

---

## 4. 네가 쓴 식은 projection matrix가 아니라 계수 계산식에 가깝습니다

네 식:

```text
(XᵀX)^-1 Xᵀ y
```

이건 projection matrix가 아니라 **projection을 만들기 위한 계수 w를 구하는 식**입니다.

반면 projection 자체는:

```text
X(XᵀX)^-1Xᵀy
```

입니다.

차이를 보면:

```text
w = (XᵀX)^-1 Xᵀ y
ŷ = Xw = X(XᵀX)^-1Xᵀy
```

정리하면:

| 목적 | 수식 | PyTorch |
|---|---|---|
| 계수 구하기 | `w = (XᵀX)^-1Xᵀy` | `w = torch.linalg.solve(X.T @ X, X.T @ y)` |
| train 예측값 구하기 | `ŷ_train = X_train w` | `train_pred = X_train @ w` |
| test 예측값 구하기 | `ŷ_test = X_test w` | `test_pred = X_test @ w` |
| projection matrix | `P = X(XᵀX)^-1Xᵀ` | `P = X @ inv(X.T @ X) @ X.T` |


```python
w
```

는 계수이고,

```python
train_pred
```

```python
P = X_train_bias @ torch.linalg.inv(X_train_bias.T @ X_train_bias) @ X_train_bias.T

train_pred_by_projection = P @ y_train

print(torch.allclose(train_pred, train_pred_by_projection, atol=1e-4))
```

이론상 둘은 거의 같습니다.

```text
train_pred = Xw
```

네가 말한:

```text

```

는 **projection 결과의 형태**입니다.

하지만 우리가 모르는 건 보통 `x`, 즉 계수입니다.

우리는 `y_train`이라는 실제 정답 벡터를 가지고 있고, 이 `y_train`을 `X_train`의 column space 위로 최대한 가깝게 projection하고 싶습니다.

즉 목표는:

```text
y_train ≈ X_train @ w
```

입니다.

여기서 projection 결과는:

```text
p = X_train @ w
```

입니다.

그런데 `w`를 모르기 때문에 먼저 `w`를 구해야 합니다.

최적의 `w`는 다음 식으로 구합니다.

```text
w = (X_trainᵀ X_train)^-1 X_trainᵀ y_train
```


입니다.

```
w = torch.linalg.inv(X_train.T @ X_train) @ X_train.T @ y_train
p = X_train @ w
```
이렇게 구했고, 여기서 p 는 train_pred 라는 소리고, 진짜로 내가 비교해야될 문제들은 y_test 와 test_pred = X_test @ w 라는 소리잖아.

### 💡 답변 (Assistant)
네, 정확합니다. 지금 이해한 내용이 맞습니다.

```python
w = torch.linalg.inv(X_train.T @ X_train) @ X_train.T @ y_train
p = X_train @ w
```

여기서 의미는:

```text
w = X_train으로부터 구한 회귀계수
p = X_train @ w = train_pred
```

즉 `p`는 **학습 데이터 X_train에 대한 예측값**입니다.

그래서 비교 대상은:

```python
p  ↔ y_train
```

입니다.

---

그리고 진짜 테스트 성능을 확인하려면 네 말대로 이렇게 해야 합니다.

```python
test_pred = X_test @ w
```

비교 대상은:

```python
test_pred  ↔ y_test
```

입니다.

즉 전체 구조는 이렇게 됩니다.

```python
# 1. train 데이터로 계수 w 계산
w = torch.linalg.inv(X_train.T @ X_train) @ X_train.T @ y_train

# 2. train 데이터에 대한 예측값
train_pred = X_train @ w

# 3. test 데이터에 대한 예측값
test_pred = X_test @ w

# 4. train 성능
train_mse = torch.mean((train_pred - y_train) ** 2)

# 5. test 성능
test_mse = torch.mean((test_pred - y_test) ** 2)

print("train_mse:", train_mse.item())
print("test_mse:", test_mse.item())
```

실제 가격과 예측 가격을 비교하려면:

```python
for i, (pred, true) in enumerate(zip(test_pred, y_test), start=1):

    )
```



```text
p = X_train @ w = train_pred
```

## 1. 먼저 bias 포함 정규방정식으로 바꿔보기

지금 네가 쓴 방식이:

```python
w = torch.linalg.inv(X_train.T @ X_train) @ X_train.T @ y_train
test_pred = X_test @ w
```

이라면, 이건 절편이 없습니다.

절편을 넣으려면 이렇게 합니다.

```python
# bias column 추가
ones_train = torch.ones(X_train.shape[0], 1)
ones_test = torch.ones(X_test.shape[0], 1)

X_train_b = torch.cat([ones_train, X_train], dim=1)
X_test_b = torch.cat([ones_test, X_test], dim=1)

# inv보다 solve 권장
w = torch.linalg.solve(
    X_train_b.T @ X_train_b,
    X_train_b.T @ y_train
)

train_pred = X_train_b @ w
test_pred = X_test_b @ w

for i, (true, pred) in enumerate(zip(y_test, test_pred), start=1):
    print(f"{i}번째 | 실제값: {true.item():.2f} | 예측값: {pred.item():.2f} | 오차: {(pred-true).item():.2f}")

test_mse = torch.mean((test_pred - y_test) ** 2)
test_rmse = torch.sqrt(test_mse)
test_mae = torch.mean(torch.abs(test_pred - y_test))

print("Test RMSE:", test_rmse.item())
print("Test MAE:", test_mae.item())
```

이것만 해도 projection 결과가 꽤 달라질 수 있습니다.

## 2. 더 안정적인 방법: Ridge Regression

데이터가 28개, feature가 11개라서 일반 선형회귀는 불안정할 수 있습니다. 이럴 때는 Ridge가 좋습니다.

수식은:

```text
w = (XᵀX + λI)^-1 Xᵀy
```

PyTorch 코드:

```python
# bias 포함
ones_train = torch.ones(X_train.shape[0], 1)
ones_test = torch.ones(X_test.shape[0], 1)

X_train_b = torch.cat([ones_train, X_train], dim=1)
X_test_b = torch.cat([ones_test, X_test], dim=1)

lambda_ = 1.0

I = torch.eye(X_train_b.shape[1])

# bias에는 regularization을 걸지 않는 게 일반적
I[0, 0] = 0.0

w_ridge = torch.linalg.solve(
    X_train_b.T @ X_train_b + lambda_ * I,
    X_train_b.T @ y_train
)

test_pred = X_test_b @ w_ridge

for i, (true, pred) in enumerate(zip(y_test, test_pred), start=1):
    print(f"{i}번째 | 실제값: {true.item():.2f} | 예측값: {pred.item():.2f} | 오차: {(pred-true).item():.2f}")

test_rmse = torch.sqrt(torch.mean((test_pred - y_test) ** 2))
test_mae = torch.mean(torch.abs(test_pred - y_test))

print("Ridge Test RMSE:", test_rmse.item())
print("Ridge Test MAE:", test_mae.item())
```

`lambda_`는 보통 여러 개를 테스트합니다.

```python
for lambda_ in [0.01, 0.1, 1.0, 10.0, 100.0]:
    I = torch.eye(X_train_b.shape[1])
    I[0, 0] = 0.0

    w_ridge = torch.linalg.solve(
        X_train_b.T @ X_train_b + lambda_ * I,
        X_train_b.T @ y_train
    )

    test_pred = X_test_b @ w_ridge
    test_rmse = torch.sqrt(torch.mean((test_pred - y_test) ** 2))
    test_mae = torch.mean(torch.abs(test_pred - y_test))

    print(f"lambda={lambda_:>6} | RMSE={test_rmse.item():.4f} | MAE={test_mae.item():.4f}")
```

## 3. 스케일링까지 추가한 Ridge 버전

이 버전이 지금 상황에서는 가장 추천입니다.

```python
# train 기준으로 평균, 표준편차 계산
X_mean = X_train.mean(dim=0, keepdim=True)
X_std = X_train.std(dim=0, keepdim=True)

# 0으로 나누기 방지
X_std[X_std == 0] = 1.0

X_train_scaled = (X_train - X_mean) / X_std
X_test_scaled = (X_test - X_mean) / X_std

# bias 추가
ones_train = torch.ones(X_train_scaled.shape[0], 1)
ones_test = torch.ones(X_test_scaled.shape[0], 1)

X_train_b = torch.cat([ones_train, X_train_scaled], dim=1)
X_test_b = torch.cat([ones_test, X_test_scaled], dim=1)

best_lambda = None
best_rmse = float("inf")
best_pred = None
best_w = None

for lambda_ in [0.001, 0.01, 0.1, 1.0, 10.0, 100.0]:
    I = torch.eye(X_train_b.shape[1])
    I[0, 0] = 0.0

    w = torch.linalg.solve(
        X_train_b.T @ X_train_b + lambda_ * I,
        X_train_b.T @ y_train
    )

    test_pred = X_test_b @ w
    test_rmse = torch.sqrt(torch.mean((test_pred - y_test) ** 2))

    print(f"lambda={lambda_:>7} | Test RMSE={test_rmse.item():.4f}")

    if test_rmse.item() < best_rmse:
        best_rmse = test_rmse.item()
        best_lambda = lambda_
        best_pred = test_pred
        best_w = w

print("\nBest lambda:", best_lambda)
print("Best RMSE:", best_rmse)

print("\n===== 실제값 vs 예측값 =====")
for i, (true, pred) in enumerate(zip(y_test, best_pred), start=1):
    print(
        f"{i}번째 | "
        f"실제값: {true.item():.2f} | "
        f"예측값: {pred.item():.2f} | "
        f"오차: {(pred - true).item():.2f}"
    )
```

---

## 4. 단, 이 방식에는 주의점이 있음

위 코드에서 `lambda_`를 **test set 성능으로 고르는 것**은 엄밀히 말하면 좋지 않습니다.

왜냐하면 test set은 마지막 평가용이어야 하는데, test set을 보고 lambda를 고르면 test set에 맞춰 튜닝한 셈이 됩니다.

데이터가 작을 때는 보통 이렇게 합니다.

```text
전체 데이터 28개
→ K-Fold Cross Validation으로 lambda 선택
→ 최종적으로 전체 train에 학습
→ test 평가
```

지금 공부 단계에서는 위 코드로 실험해도 괜찮지만, 보고서나 실전 분석에서는 K-Fold를 쓰는 게 더 좋습니다.

## 5. 성능을 가장 크게 올릴 가능성이 있는 부분

이 데이터에서는 특히 `A9`, `A10`이 중요합니다.

```text
A9 = construction type
A10 = architecture type
```

이 둘은 숫자형이 아니라 범주형입니다.

현재는 모델이 이렇게 오해할 수 있습니다.

```text
A9 = 4가 A9 = 1보다 4배 크다
A10 = 3이 A10 = 1보다 3배 크다
```

하지만 실제 의미는:

```text
1 = brick
2 = brick/wood
3 = aluminum/wood
4 = wood
```

이므로 크고 작음의 관계가 아닙니다.

따라서 제대로 하려면 `A9`, `A10`을 원핫인코딩해야 합니다. 이건 PyTorch보다는 pandas + sklearn으로 하는 게 훨씬 편합니다.
