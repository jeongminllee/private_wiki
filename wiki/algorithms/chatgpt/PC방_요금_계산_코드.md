### ❓ 질문 (User)
문제
현성이는 요즘 LINEAR 2라는 온라인 게임에 빠져있다. PC방에 가서 게임을 즐기는데, 자주 가는 PC방의 요금체계는 다음과 같다. 일반 요금으로 시간당 1000원 씩을 받으며, 야간 정액을 끊으면 5000원만 내고 밤 10시부터 다음날 아침 8시까지 사용할 수 있다. 이 PC방에서는 1시간에서 1분이라도 넘으면 새로운 1시간에 대한 요금을 부과한다. 그리고 이미 일반 요금으로 사용을 하다가 야간 정액을 쓰게 되면 일반 요금을 미리 계산을 하고 야간 정액을 쓸 수 있다. 즉, 일반 요금을 쓰다가 야간 정액을 쓰고 다시 일반 요금을 쓰게 되면 두 개의 일반 요금을 각각 따로 계산이 된다.

현성이가 게임을 시작하는 시각과 게임을 하는 시간을 입력으로 받으면 현성이가 최소로 지불해야 하는 PC방 이용 요금을 계산하는 프로그램을 작성하시오. 현성이는 한 번 게임을 시작하면 게임을 하는 시간 동안 계속 게임을 한다고 하자.

입력
입력의 첫 줄에는 테스트 케이스의 개수 T (1 ≤ T ≤ 10)가 주어진다. 각 테스트 케이스는 한 줄에 HH:MM D가 주어지며 HH와 MM사이에는 :(콜론)이 있고, MM과 D사이에는 한 칸의 공백이 주어진다. HH:MM은 현성이가 게임을 시작하는 시각을 나타내며 HH시 MM분부터 시작함을 의미한다. D는 현성이가 게임을 하는 시간을 분으로 나타내며 정수로 주어진다. HH:MM은 00:00부터 23:59까지의 시각으로 표시되며 모두 2자리로 표시된다(숫자가 한 자리일 때에는 앞에 0이 붙어서 주어진다.). 사람 체력의 한계상 D는 3일 동안의 시간까지만 입력된다. (1 ≤ D ≤ 4320)

출력
각 테스트 케이스에 대해서 현성이가 지불해야 하는 최소의 PC방 이용 요금을 한 줄에 하나씩 출력한다(단위 원은 생략).

예제 입력 1 
4
14:30 180
19:28 242
23:25 580
21:10 765
예제 출력 1 
3000
5000
7000
8000

### 💡 답변 (Assistant)
아래는 문제의 조건에 맞게 최소 비용을 구하는 파이썬 코드입니다. 

문제의 핵심은 PC방 이용 시간을 연속 구간으로 나누어, 각 구간에 대해 일반 요금(1시간당 1000원, “1시간 넘으면 새 1시간 요금”)과 “야간 정액” (밤10시부터 다음날 08시까지 5000원)을 선택할 수 있는데, 이미 일반 요금 구간과 야간 정액 구간이 분리되어 계산된다는 점입니다. 

아래 코드는 시작 시각과 이용 시간(분)을 절대 분 단위(예, 00:00을 0분으로 하여)로 변환한 후, 재귀/메모이제이션(dp)로 “현재 시각부터 종료시각까지 최소 비용”을 구하는 방식입니다.  
 
특히, 
- 일반 요금 구간은 “구간 길이(분)에 대해 \(1000 \times \lceil\frac{사용분}{60}\rceil\)” 이며, 구간의 끝나는 ‘중요한’ 시각은  
  - 시작 시각에서 60분씩 더한 시각(즉, 구간내 비용이 바뀌는 시점)
  - 또는 야간 정액이 시작되는(혹은 종료되는) 고정 시각(22:00, 08:00)
  - 그리고 세션 종료 시각  
  를 후보로 고려합니다.
- 만약 현재 시각이 야간 시간(22:00~08:00) 내라면, “야간 정액”을 바로 사용할 수 있는데, 이 경우 정액은 5000원으로 (사용시간이 짧더라도) 해당 야간 구간의 끝(즉, 22:00에 시작하면 다음날 08:00, 이미 야간 중이면 그 날 08:00)까지 커버합니다.

아래 전체 코드를 보시기 바랍니다.

---

```python
def solve():
    import sys, math
    data = sys.stdin.read().splitlines()
    if not data:
        return
    T = int(data[0].strip())
    out_lines = []
    line_index = 1
    for _ in range(T):
        # 입력 형식: "HH:MM D"
        time_str, d_str = data[line_index].split()
        line_index += 1
        D = int(d_str)
        HH, MM = map(int, time_str.split(":"))
        # 시작 시각을 0분부터의 절대 분으로 계산 (예: 00:00 → 0, 14:30 → 14*60+30)
        start = HH * 60 + MM
        end = start + D   # 세션 종료 시각(절대 분)
        
        memo = {}  # dp 메모이제이션
        
        # 현재 시각 x(절대 분)가 야간 요금 적용 시간에 해당하는지?
        # 야간 시간은 밤10시(22:00, 1320분)부터 자정 그리고 자정부터 아침 08:00(480분)까지.
        def is_night(x):
            r = x % 1440
            return (r >= 1320 or r < 480)
        
        # x가 야간 구간에 있다면, 야간 정액은 “밤10시부터 다음날 아침 08시까지” (또는
        # 자정 이후라면 당일 08:00까지) 커버합니다.
        def night_end(x):
            r = x % 1440
            if r >= 1320:
                return (x // 1440 + 1) * 1440 + 480
            elif r < 480:
                return (x // 1440) * 1440 + 480
            else:
                # 이 함수는 x가 야간 구간일 때만 호출됩니다.
                return x
        
        # f(x): 현재 절대 시각 x부터 세션 종료(end)까지의 최소 비용
        def f(x):
            if x >= end:
                return 0
            if x in memo:
                return memo[x]
            best = float('inf')
            # 일반 요금 옵션:
            # x부터 어떤 y까지 일반 요금을 쓰면 비용은 1000 * ceil((y-x)/60)
            # 단, 구간이 길어질수록 비용이 동일한 "계단" 구간이 있으므로, 
            # 구간의 끝 후보는
            #   1. x에서 60분씩 더한 시각 (즉, x+k*60)
            #   2. 세션 종료 시각 end
            #   3. 야간 정액 전환을 위해 중요한 시각 (밤10:00, 아침 08:00)
            # 를 고려합니다.
            cand = set()
            # (1) x+k*60 (x+k*60 <= end)
            max_k = (end - x) // 60
            for k in range(1, max_k + 1):
                cand.add(x + k * 60)
            # (2) 세션 종료 시각
            cand.add(end)
            # (3) x와 end 사이에 위치한 밤 10시(22:00)나 아침 08:00(08:00) 시각
            #    전환 시각은 절대 시각으로 d*1440+480, d*1440+1320 (d: day) 입니다.
            start_day = (x // 1440) - 1
            end_day = (end // 1440) + 1
            for d in range(start_day, end_day + 1):
                for boundary in (d * 1440 + 480, d * 1440 + 1320):
                    if x < boundary <= end:
                        cand.add(boundary)
            # 각 후보 y에 대해 구간 [x, y]를 일반 요금으로 처리하는 비용 + f(y)를 고려
            for y in sorted(cand):
                seg = y - x
                cost_seg = 1000 * ((seg + 59) // 60)  # ceil(seg/60)와 같음.
                candidate = cost_seg + f(y)
                if candidate < best:
                    best = candidate

            # 야간 정액 옵션: 
            # 만약 현재 x가 야간 시간대라면, 5000원을 내면
            #   - 세션 종료(end)가 야간 구간의 끝(N)보다 이전이면 5000원으로 끝내고,
            #   - 아니면 5000원 + f(N) (N: night_end(x))
            # 를 고려할 수 있습니다.
            if is_night(x):
                N = night_end(x)
                if end <= N:
                    candidate = 5000
                else:
                    candidate = 5000 + f(N)
                if candidate < best:
                    best = candidate

            memo[x] = best
            return best
        
        ans = f(start)
        out_lines.append(str(ans))
    sys.stdout.write("\n".join(out_lines))
    
if __name__ == '__main__':
    solve()
```

### 코드 설명

1. **입력 처리 및 절대 시간 계산**  
   시작 시각 `"HH:MM"`을 분 단위 정수로 바꾸고, 이용 시간 D(분)을 더해 종료 시각(`end`)를 구합니다.

2. **is_night(x) 함수**  
   주어진 절대 시각 x의 분 값(x % 1440)을 보고, 밤10시(1320분) 이후 또는 08:00(480분) 이전이면 야간 시간대로 판단합니다.

3. **night_end(x) 함수**  
   x가 야간 시간에 있다면, 야간 정액이 커버하는 끝 시각을 반환합니다.
   - x가 22:00~자정에 있으면 다음날 08:00,
   - 자정~08:00에 있으면 당일 08:00을 반환합니다.

4. **dp 함수 f(x)**  
   현재 x부터 종료 시각까지 최소 비용을 구하는 재귀 함수입니다.  
   일반 요금 구간으로 처리할 때는, x에서 시작해 “구간의 끝 후보” (x+k*60, 세션 종료, 혹은 밤/아침 시각)를 고려합니다.  
   또한, x가 야간 구간이면 야간 정액 옵션(5000원 + 이후 비용)을 고려합니다.

5. **메모이제이션**  
   이미 계산한 x에 대해서는 memo 사전을 이용해 중복 계산을 방지합니다.

6. **출력**  
   각 테스트 케이스에 대해 최소 비용을 출력합니다.

### ❓ 질문 (User)
```
def solve():
    ans = 0
    time, spd = sys.stdin.readline().strip().split()
    spd = int(spd)

    h, m = map(int, time.split(":"))
    h = (h + 2) % 24

    while spd > 0:
        if h <= 4 and spd > 300:
            spd -= (600 - (h * 60 + m))
            h = 10
            m = 0
            ans += 5000
        else:
            h = (h + 1) % 24
            spd -= 60
            ans += 1000
    print(ans)


if __name__ == '__main__':
    T = int(input())
    for _ in range(T) :
        solve()
```

### 💡 답변 (Assistant)
이 풀이에서는 문제의 “야간 정액”과 “일반 요금”의 요금체계를 아주 간단한 그리디(탐욕) 방식으로 해결할 수 있도록 **시간을 2시간 이동시키는 트릭**을 사용합니다. 즉, 입력받은 시작 시각에 2시간을 더한 뒤 모듈로 24를 취합니다.

아래에 그 핵심 아이디어와 코드 작동 방식을 자세히 설명합니다.

---

### 1. 시간 이동(shift)로 야간 구간을 쉽게 처리

- 원래 문제에서 **야간 정액**은 밤 10시(22:00)부터 다음날 아침 8시(08:00)까지 사용할 수 있습니다.
- 그런데 이 구간은 자정을 넘어가므로 계산하기 번거롭습니다.
- 따라서, 코드에서는  
  ```python
  h, m = map(int, time.split(":"))
  h = (h + 2) % 24
  ```  
  와 같이 시작 시각에 2시간을 더합니다.
- 이 결과, 원래 **야간 구간(22:00 ~ 08:00)**은 이동 후 **0:00 ~ 10:00** 구간이 됩니다.
  - 예를 들어, 원래 22:00은 (22+2)%24 = 0:00,  
    08:00은 (8+2)%24 = 10:00이 되어,  
    계산하기 쉬운 연속구간이 됩니다.

---

### 2. 그리디하게 시간 진행 시뮬레이션

- 남은 게임 시간(분 단위)을 `spd`에 저장하고, 전체 비용을 `ans`에 누적합니다.
- while 루프를 돌면서 남은 시간 `spd`가 0보다 클 때까지 다음 두 방식 중 하나를 선택합니다.

#### (1) 야간 정액 사용 조건

```python
if h <= 4 and spd > 300:
```

- **`h <= 4` 조건**:  
  이동된 시간으로 보면, 야간 정액 사용 가능 구간은 **0:00 ~ 10:00**인데,  
  그중에서도 “야간 정액”을 쓰기에 유리한 시점은 초반부, 즉 원래 22:00~02:00에 해당하는 구간입니다.  
  (이동 후 0:00 ~ 4:00에 해당)
  
- **`spd > 300` 조건**:  
  일반 요금은 1시간(60분)마다 1000원인데, 300분(5시간) 동안이면 5000원이 됩니다.  
  즉, 남은 시간이 300분을 초과한다면 (즉, 5시간이 넘는다면) 일반 요금으로 계산하면 5000원 이상이 나오게 되므로  
  야간 정액(5000원)을 쓰는 것이 이득입니다.

- 만약 두 조건이 모두 만족되면,  
  ```python
  spd -= (600 - (h * 60 + m))
  h = 10
  m = 0
  ans += 5000
  ```
  를 수행합니다.
  - **(600 - (h*60+m))**: 현재 이동된 시간에서 10:00(600분)까지 남은 분 수를 계산합니다.  
    (10:00 이동된 시간는 원래 08:00에 해당합니다.)
  - 즉, 야간 정액은 남은 시간 중 **10:00(이동된 시간)**까지의 사용을 커버하므로,  
    그 시간만큼 `spd`에서 빼고, 시간을 10:00(이동된)으로 맞춥니다.
  - 비용은 5000원을 추가합니다.

#### (2) 일반 요금 처리

- 위 조건을 만족하지 않는 경우, 1시간 단위로 일반 요금을 적용합니다.
- 즉,
  ```python
  else:
      h = (h + 1) % 24
      spd -= 60
      ans += 1000
  ```
  를 통해 60분(1시간)마다 1000원을 청구하면서 진행합니다.
- **주의:** 분 단위가 60분 미만이어도 1시간으로 취급하는 문제 규칙을 단순하게  
  “한 시간씩 빼면서” 계산하는 방식으로 구현한 것입니다.

---

### 3. 왜 이 방식이 가능한가?

- **시간 이동의 효과:**  
  문제의 야간 정액 구간(22:00~08:00)을 이동 후 0:00~10:00으로 만들면  
  자정을 넘는 복잡한 처리를 단순한 연속 구간(0분부터 600분까지)으로 계산할 수 있게 됩니다.
  
- **그리디한 선택:**  
  코드에서는 현재 시간이 이동 후 0~4시(즉, 원래 22:00~02:00)이고 남은 시간이 300분 이상이면  
  무조건 야간 정액을 쓰도록 합니다.  
  이는 “남은 시간이 5시간(300분)을 넘으면 일반 요금으로는 5000원 이상이 될 것”이라는  
  합리적인 판단에 기반한 것입니다.
  
- **시간 시뮬레이션의 단순화:**  
  남은 시간을 60분씩 줄이면서 계산하다가, 야간 구간에 진입하면 한 번에  
  야간 정액이 적용되는 시간을 계산해 빼므로, 복잡한 분 단위의 요금계산 문제를  
  단순하게 "한 시간씩 또는 한 구간씩" 진행하는 방식으로 해결할 수 있습니다.

이러한 이유로, 이 코드는 문제에서 요구하는 최소 비용 계산을 올바르게 수행할 수 있는 것입니다.
