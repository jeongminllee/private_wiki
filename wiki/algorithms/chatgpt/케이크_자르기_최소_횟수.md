## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
각 변의 길이가 X$X$, Y$Y$, Z$Z$인 직육면체 모양의 케이크가 있다. 케이크 속 어딘가에 단위 크기(1×1×1$1 \times 1 \times 1$)의 건포도가 하나 들어 있다. 건포도는 케이크를 단위 크기의 격자 공간으로 간주했을 때, 격자 공간의 어떤 한 곳에 위치한다. 당신은 건포도 알레르기가 있어서 케이크를 먹기 전에 케이크를 잘라 미리 건포도의 위치를 특정하기로 했다. 케이크를 자르는 규칙은 다음과 같다:
* 자를 때는 x$x$축, y$y$축, z$z$축 중 한 축과 평행한 평면으로만 자를 수 있으며, 자르기로 한 평면 전체를 자른다.
* 자른 조각의 위치를 재배치하는 것은 금지된다.
* 자른 결과가 단위 크기로 나눠질 수 있어야만 자를 수 있다.
위와 같은 방법으로 케이크를 0$0$번 이상 자른 후, 잘린 케이크 조각들의 모든 표면을 관찰할 수 있다. 이때 특정 칸이 건포도에 해당하는 칸인지는 해당 칸의 한 면만 노출되더라도 확인할 수 있다.
당신은 케이크를 가급적 온전한 상태에 가깝게 두면서 건포도의 위치를 특정하고 싶기 때문에 케이크를 자르는 횟수를 최소화하고자 한다. 최선의 전략을 사용했을 때, 최악의 경우에도 자르기 몇 번이면 건포도의 위치를 특정할 수 있는지 그 최소 횟수를 구하라.
입력
첫 번째 줄에 정수 X$X$, Y$Y$, Z$Z$가 공백으로 구분되어 주어진다. (1≤X,Y,Z≤100000$1\leq X, Y, Z \leq 100\,000$)
출력
첫 번째 줄에 최선의 전략을 사용했을 때, 최악의 경우에도 자르기 몇 번이면 건포도의 위치를 특정할 수 있는지 그 최소 횟수를 구하라.
예제 입력 1 복사


Copy
1 1 1
예제 출력 1 복사


Copy
0
케이크의 크기가 1×1×1$1 \times 1 \times 1$이기 때문에, 건포도가 위치하는 칸이 유일하게 정해질 수 있고 자르기를 수행하지 않더라도 건포도의 위치를 특정할 수 있다.
예제 입력 2 복사


Copy
3 3 5
예제 출력 2 복사


Copy
1

### 💡 답변 (Assistant)
이 문제는 케이크를 자르면서 건포도의 위치를 정확하게 특정하는 최소 자르기 횟수를 구하는 문제입니다. 자르기 횟수를 최소화하려면, 각 축에 대해 건포도의 위치를 구별할 수 있도록 해야 합니다.

### 문제 분석

1. **직육면체 모양의 케이크**:
   - 케이크의 크기는 `X * Y * Z`이며, 각 변의 길이는 `X`, `Y`, `Z`입니다.
   - 건포도는 `(x, y, z)` 형태로 케이크의 3D 격자 공간에 위치합니다.

2. **자르기 규칙**:
   - x축, y축, z축 중 하나의 축에 평행한 평면으로만 자를 수 있습니다.
   - 자른 후 케이크가 단위 크기로 나눠져야 하므로 자르기 전에 각 축에 대해 1씩 나누어 떨어져야 합니다.

3. **문제의 목표**:
   - 최소 자르기 횟수로 건포도의 정확한 위치를 구별할 수 있도록 해야 합니다.

### 해결 전략

우리는 자를 때마다 각 축을 기준으로 자르는 방식으로 최소 횟수를 구할 수 있습니다. 각 축을 자르는 횟수는 `X - 1`, `Y - 1`, `Z - 1`로 나타낼 수 있습니다. 하지만 중요한 점은, 자르기가 필요한 축이 몇 개인지에 대한 판단입니다.

#### 주요 아이디어:
- 각 축에 대해 "얼마나 자를 필요가 있는지"를 파악하는 문제입니다.
- 자를 수 있는 최솟값을 구하는 방법은 각 축에서 "건포도의 위치가 몇 번째 칸에 있는지"를 구별할 수 있도록 최소 자르기 횟수를 결정하는 것입니다.

### 해결 과정:

1. **X, Y, Z에 대해 건포도의 위치를 구별하기**:
   - X, Y, Z가 1인 경우 자를 필요가 없으므로 0번 자르기.
   - 그렇지 않으면 각 축에 대해 건포도의 위치를 정확하게 파악할 수 있도록 최소 자르기 횟수를 구합니다.

2. **최소 자르기 횟수**:
   - 건포도가 하나의 칸에 정확히 위치한다면, 각 축에 대해 자르는 횟수를 구별할 수 있어야 합니다.
   - 최악의 경우에는 건포도가 `(x, y, z)` 위치에 있을 때까지 자르기를 최소화하는 방법을 찾아야 합니다.

### 알고리즘:

- 각 축에 대해 `X > 1`, `Y > 1`, `Z > 1`인 경우 자르는 횟수를 최소화하려면 가장 적은 수로 건포도의 위치를 구별할 수 있도록 해야 합니다.
  
### 코드 구현:

```python
def min_cuts(x, y, z):
    cuts = 0
    if x > 1:
        cuts += 1
    if y > 1:
        cuts += 1
    if z > 1:
        cuts += 1
    return cuts

# 입력 받기
X, Y, Z = map(int, input().split())

# 결과 출력
print(min_cuts(X, Y, Z))
```

### 설명:

- 각 축에 대해 `X`, `Y`, `Z`가 1보다 큰 경우만 자르기 필요하므로, 각 축에 대해 자르기 필요 여부를 체크합니다.
- 각 축에 대해 자르는 횟수를 더하여 최악의 경우에 건포도를 정확하게 구별할 수 있는 최소 자르기 횟수를 계산합니다.

### 예시 실행:

**입력 1**:
```
1 1 1
```

**출력 1**:
```
0
```
케이크가 이미 1×1×1 크기이므로 자를 필요가 없습니다.

**입력 2**:
```
3 3 5
```

**출력 2**:
```
1
```
x, y, z 축 중 하나에서만 자르면 건포도의 위치를 확실히 알 수 있습니다.

### 시간 복잡도:
이 문제의 시간 복잡도는 `O(1)`로, 주어진 `X`, `Y`, `Z` 값에 대해 상수 시간 내에 결과를 계산할 수 있습니다.
