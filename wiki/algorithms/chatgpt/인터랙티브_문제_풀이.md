# 인터랙티브 문제 풀이

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 문제는 “인터랙티브(interactive)” 문제로, 컴퓨터와 상호작용하면서 해결해야 하는 문제입니다.

### 문제 요약
- **상황:** \(n^2\)명의 심사위원들이 각자 서로 다른 정수가 적힌 복권(또는 로트)을 뽑았습니다. 이 복권들은 \(n \times n\) 정사각형 형태로 탁자 위에 놓여 있습니다.
- **목표:** 복권 중에서 가장 큰 숫자가 적힌 복권을 찾는 것입니다.
- **제한:** 전체 \(n^2 + 100\)번 이하의 질의(queries)를 통해 답을 찾아야 합니다.
- **인터랙션 방식:** 
  - 여러분은 탁자를 직접 볼 수 없으므로, 좌표를 지정하여 복권에 적힌 숫자를 요청해야 합니다.
  - 질의 형식은 `? x y`로, \(1 \leq x,y \leq 1000\)인 좌표를 입력합니다.
  - 만약 좌표가 복권 배열의 범위를 벗어나면, "ArrayIndexOutOfBoundsException"이라는 문자열이 응답됩니다.
  - 범위 내의 좌표를 요청하면 그 자리의 복권에 적힌 정수(1부터 \(10^9\) 사이의 값)가 응답됩니다.
  - 목표 복권(가장 큰 숫자)을 찾으면 `! v`의 형식으로 출력하여 종료합니다.

### 문제 풀이 전략
- **사각형의 크기:** \(n\)의 값은 1에서 100 사이이며, 문제를 풀기 전에 정확한 \(n\)을 알 수 없으므로, 질의를 통해 배열의 범위를 파악해야 할 수도 있습니다.
- **질의 제한:** \(n^2 + 100\)번의 질의 안에 최대값을 찾는 전략을 짜야 합니다.
- **접근 방법:** 
  - 처음에는 좌표가 배열 내부인지 확인하기 위해 몇몇 좌표에 대해 질의를 진행할 수 있습니다.
  - 이후에는 배열 내부의 값을 비교하면서 최대값을 찾기 위한 탐색 알고리즘(예를 들어, 전체를 탐색하거나, 특정 패턴을 이용해 효율적으로 검색)을 구현할 수 있습니다.

### 예제 설명
예제에서는 여러 질의를 통해 몇몇 좌표의 값을 알아내고, 결국 가장 큰 값인 123456이 포함된 복권을 찾았습니다. 

1. 예제 질의들 (`? 1 1`, `? 4 5` 등)을 통해 각 위치의 값을 확인합니다.
2. 배열 범위를 벗어난 좌표를 질의했을 때 "ArrayIndexOutOfBoundsException" 응답을 받아서, 배열의 크기를 유추할 수 있습니다.
3. 모든 정보를 바탕으로 가장 큰 값인 123456이 어디에 있는지 결정하고, 최종적으로 `! 123456`을 출력합니다.

이 문제는 단순히 최대값을 찾는 것처럼 보이지만, 인터랙션 방식과 제한된 질의 횟수를 고려하여 어떻게 효율적으로 정보를 수집할 것인지가 관건입니다.

### 💡 답변 (Assistant)
아래는 문제에서 설명한 인터랙티브 프로토콜에 맞춰 파이썬으로 작성한 예시 코드입니다. 이 코드는 먼저 배열의 크기 \(n\)을 찾은 뒤, 모든 좌표를 순회하며 최대값을 찾아 출력합니다.

```python
import sys

def query(x, y):
    """좌표 (x, y)에 대해 질의하고, 응답을 반환합니다.
    만약 좌표가 범위를 벗어나면 None을 반환합니다.
    """
    print(f"? {x} {y}")
    sys.stdout.flush()
    response = input().strip()
    if response == "ArrayIndexOutOfBoundsException":
        return None
    return int(response)

def main():
    # 1. 배열의 크기 n 찾기.
    # 배열은 (1,1)부터 (n,n)까지이므로, x좌표를 1부터 증가시키며 탐색합니다.
    n = 0
    while True:
        res = query(n + 1, 1)
        if res is None:
            break
        n += 1

    # 2. 배열 전체를 탐색하며 최대값을 찾습니다.
    max_value = -1
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            value = query(i, j)
            # value가 None이면, 예상치 못한 오류지만 그냥 continue
            if value is None:
                continue
            if value > max_value:
                max_value = value

    # 3. 최대값을 찾았으므로 출력합니다.
    print(f"! {max_value}")
    sys.stdout.flush()

if __name__ == '__main__':
    main()
```

### 코드 설명
1. **`query` 함수:**  
   - 좌표 \((x, y)\)를 질의하고, 결과를 읽어 반환합니다.
   - 만약 "ArrayIndexOutOfBoundsException"을 받으면 `None`을 반환합니다.

2. **배열 크기 \(n\) 탐색:**  
   - \((1,1)\), \((2,1)\), ... 순으로 질의하여, 유효한 숫자를 받는 동안 \(n\)을 증가시킵니다.
   - 처음으로 "ArrayIndexOutOfBoundsException"을 받으면 그 이전이 배열의 마지막 행임을 알 수 있습니다.

3. **최대값 탐색:**  
   - \(1 \leq i, j \leq n\) 범위의 모든 좌표를 질의하면서 최대값을 갱신합니다.

4. **최종 답 출력:**  
   - 최대값을 찾으면 `! 최대값`의 형식으로 출력하여 인터랙션을 종료합니다.

이 코드는 단순한 완전탐색 방식이므로, \(n \le 100\)인 조건 하에서 충분히 질의 제한 내에 문제를 해결할 수 있습니다.

### 💡 답변 (Assistant)
이 에러는 `input()` 호출 시 빈 문자열이 반환되어, 이를 정수로 변환하려고 할 때 발생합니다. 보통 인터랙티브 문제에서 표준 입력/출력이 제대로 flush되지 않거나, interactor가 예상치 못한 응답을 보낼 때 이런 문제가 발생할 수 있습니다.

다음은 몇 가지 해결 방법과 개선된 코드 예시입니다.

---

### 1. 해결 방법
- **출력 후 버퍼 플러시 확인:**  
  `print()` 후에 반드시 `sys.stdout.flush()`를 호출해서 출력 버퍼가 비워지도록 합니다.

- **입력 검증 추가:**  
  입력 받은 문자열이 빈 문자열이 아닌지 확인하고, 빈 문자열이라면 예외 처리하거나 재시도할 수 있습니다.

- **try/except 사용:**  
  변환 과정에서 발생할 수 있는 `ValueError`를 처리해서 디버깅 메시지를 출력하거나, 예외 상황에 대처할 수 있습니다.

---

### 2. 개선된 코드 예시

아래 코드는 위의 점들을 반영하여, 입력을 받을 때 빈 문자열이나 변환 오류가 발생하는 경우에 대한 처리를 추가한 코드입니다.

```python
import sys

def query(x, y):
    """
    좌표 (x, y)에 대해 질의하고, 응답을 정수 또는 None으로 반환합니다.
    만약 좌표가 범위를 벗어나면 "ArrayIndexOutOfBoundsException" 문자열을 받고 None을 반환합니다.
    """
    print(f"? {x} {y}")
    sys.stdout.flush()
    response = input().strip()

    # 빈 문자열이나 예기치 않은 응답 처리
    if not response:
        sys.stderr.write("Error: 빈 입력이 감지되었습니다.\n")
        return None

    if response == "ArrayIndexOutOfBoundsException":
        return None

    try:
        return int(response)
    except ValueError:
        sys.stderr.write(f"Error: 정수 변환 실패, 받은 응답: '{response}'\n")
        return None

def main():
    # 1. 배열의 크기 n 찾기
    n = 0
    while True:
        res = query(n + 1, 1)
        if res is None:
            break
        n += 1

    # n이 0이면 문제가 있는 상황이므로 종료 처리
    if n == 0:
        sys.stderr.write("오류: 배열의 크기를 확인할 수 없습니다.\n")
        return

    # 2. 배열 전체 탐색하며 최대값 찾기
    max_value = -1
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            value = query(i, j)
            if value is None:
                continue
            if value > max_value:
                max_value = value

    # 3. 최대값 출력
    print(f"! {max_value}")
    sys.stdout.flush()

if __name__ == '__main__':
    main()
```

---

### 코드 설명
- **입력 검증:**  
  - `if not response:` 부분에서 빈 문자열 입력을 감지하면 에러 메시지를 출력하고 `None`을 반환합니다.
  - `try/except`를 사용하여 `int()` 변환 중 오류가 발생하면 에러 메시지를 출력합니다.

- **출력 플러시:**  
  모든 `print()` 후에 `sys.stdout.flush()`를 호출하여 즉시 출력되도록 했습니다.

이렇게 하면, 만약 interactor에서 빈 응답이나 예상치 못한 응답이 온다면, 해당 문제를 디버깅하기 쉽고, 프로그램이 갑자기 중단되지 않도록 할 수 있습니다.

---

### 1. 초기 변수 설정

```python
ans, n = 0, 100
```

- **ans**: 지금까지 발견한 값들 중 최대값을 저장합니다. 초기값은 0으로 설정합니다.
- **n**: 배열의 크기 \(n \times n\)에서 \(n\)을 의미합니다. 처음엔 최대값 100으로 가정하지만, 이후 실제 \(n\)을 알아내면 갱신됩니다.

---

### 2. 첫 번째 for문 – 배열의 첫 열을 이용해 \(n\) 결정하기

```python
for i in range(100):
    print(f"? {i + 1} 1")
    s = input()
    if s == "ArrayIndexOutOfBoundsException":
        n = i
        break
    else:
        ans = max(ans, int(s))
```

- **목적**: 배열의 크기를 모르는 상황에서 첫 번째 열(행 번호 \(1\)부터 \(100\)까지, \(y=1\))에 대해 질의를 진행합니다.
- **동작 과정**:
  - `print(f"? {i + 1} 1")`: \((i+1, 1)\) 좌표에 있는 복권의 값을 요청합니다.
  - `s = input()`: 인터랙터로부터 응답을 받습니다.
  - **범위 확인**: 만약 응답이 `"ArrayIndexOutOfBoundsException"`이면,
    - 이는 \((i+1, 1)\) 좌표가 배열 범위를 벗어났다는 의미이므로, 배열의 크기는 \(n = i\)임을 알 수 있습니다.
    - `break`로 반복문을 종료합니다.
  - **유효한 값이면**: 응답이 정수 문자열이면, 이를 정수로 변환한 후 현재까지의 최대값과 비교하여 **ans**를 갱신합니다.
- **효과**: 이 과정을 통해 첫 열의 각 좌표에 있는 값들을 확인하면서, 배열이 유효한 좌표인지도 판단하고 동시에 최대값 후보를 갱신합니다.

---

### 3. 두 번째 for문 – 전체 배열 탐색

```python
for y in range(2, n + 1):
    for x in range(1, n + 1):
        print(f"? {x} {y}")
        ans = max(ans, int(input()))
```

- **목적**: 첫 번째 열( \(y=1\) ) 이외의 나머지 행들(\(y=2\)부터 \(n\))에 대해 모든 열(\(x=1\)부터 \(n\))의 값을 질의합니다.
- **동작 과정**:
  - 바깥 루프는 행 번호 \(y\)가 \(2\)부터 \(n\)까지 진행합니다.
  - 안쪽 루프는 각 행에 대해 열 번호 \(x\)가 \(1\)부터 \(n\)까지 진행합니다.
  - 각 좌표 \((x,y)\)에 대해 `print(f"? {x} {y}")`로 질의하고, `input()`을 통해 받은 값을 정수로 변환하여 현재 최대값 **ans**와 비교 후 갱신합니다.
- **특징**:
  - 첫 번째 열은 이미 처리했으므로, \(y=2\)부터 시작합니다.
  - 실제 \(n\)을 이전 단계에서 결정했으므로, 여기서는 추가 범위 검사가 필요 없습니다.

---

### 4. 최종 답 출력

```python
print(f'! {ans}')
```

- **목적**: 이제까지의 질의를 통해 찾은 최대값 **ans**를 인터랙터에 최종 답으로 제출합니다.
- **동작 과정**:
  - `print(f'! {ans}')`로 정답을 출력하면, 인터랙션이 종료됩니다.

### 추가 분석

- **전체 질의 횟수**:
  - 첫 번째 for문: 최대 100번 (실제 \(n\)이 작으면 반복문은 중단됩니다).
  - 두 번째 for문: \((n - 1) \times n\)번.
  - 전체 질의 횟수는 \(n + (n - 1)n = n^2 + 1\)번 이하가 되어 문제 제한 \(n^2 + 100\) 내에 충분합니다.
  
- **효율성**:
  - 모든 좌표를 직접 탐색하는 완전 탐색 방식입니다.
  - \(n\)의 최댓값이 100이므로, 최대 10,000번 정도의 질의로 충분히 해결 가능합니다.
  
- **예외 처리**:
  - 첫 번째 루프에서 "ArrayIndexOutOfBoundsException" 응답을 이용해 배열의 실제 크기를 판단합니다.
  - 두 번째 루프에서는 이미 \(n\)을 알고 있기 때문에 범위 오류에 대한 처리가 필요 없습니다.

이와 같이 코드는 인터랙션의 특성을 이용하여 배열의 크기를 동적으로 파악한 후, 전체 배열을 순회하며 최대값을 찾아내는 방식으로 구현되어 있습니다.

---

### ❓ 질문 (User)
```
ans, n = 0, 100
for i in range(100):
    print(f"? {i + 1} 1")
    s = input()
    if s == "ArrayIndexOutOfBoundsException":
        n = i
        break
    else:
        ans = max(ans, int(s))

for y in range(2, n + 1):
    for x in range(1, n + 1):
        print(f"? {x} {y}")
        ans = max(ans, int(input()))

print(f'! {ans}')
```
