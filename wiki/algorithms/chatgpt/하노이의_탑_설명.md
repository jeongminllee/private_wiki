하노이의 탑(Tower of Hanoi)은  
재귀(recursion) 개념을 설명할 때 자주 사용되는 **고전 퍼즐 문제**입니다.  

---

## 1. 문제 개요  
- **목표**: 세 개의 기둥(막대)과 서로 크기가 다른 N개의 원반이 있을 때,  
  모든 원반을 **첫 번째 기둥 → 세 번째 기둥**으로 옮기기  
- **규칙**:
  1. 한 번에 **하나의 원반**만 옮길 수 있음
  2. 큰 원반은 **작은 원반 위에 놓을 수 없음**
  3. 기둥은 세 개(출발, 보조, 도착)

---

## 2. 예시 (N=3)  
초기 상태:  
```
A: 3 2 1
B:
C:
```
목표 상태:  
```
A:
B:
C: 3 2 1
```

이동 과정 (총 7번 이동):
1. A → C (1)
2. A → B (2)
3. C → B (1)
4. A → C (3)
5. B → A (1)
6. B → C (2)
7. A → C (1)

---

## 3. 원리 (재귀적 접근)
하노이의 탑 문제는 **“작은 문제로 쪼개는 방식”**으로 해결됩니다.

- **N개의 원반을 옮기는 과정**:
  1. **위의 N-1개 원반**을 보조 기둥으로 옮김
  2. **가장 큰 원반(맨 아래)**을 목표 기둥으로 옮김
  3. **보조 기둥의 N-1개 원반**을 목표 기둥으로 옮김

---

## 4. 최소 이동 횟수 공식
- N개의 원반을 옮길 때 최소 이동 횟수:
\[
\text{이동 횟수} = 2^N - 1
\]
예:
- N=3 → \(2^3 - 1 = 7\) 번
- N=4 → \(2^4 - 1 = 15\) 번

---

## 5. Python 예시 코드
```python
def hanoi(n, start, end, aux):
    if n == 1:
        print(f"{start} → {end}")
        return
    hanoi(n-1, start, aux, end)  # N-1개를 보조 기둥으로
    print(f"{start} → {end}")    # 가장 큰 원반 이동
    hanoi(n-1, aux, end, start)  # N-1개를 목표 기둥으로

# 실행 예시
hanoi(3, 'A', 'C', 'B')
```

출력:
```
A → C
A → B
C → B
A → C
B → A
B → C
A → C
```

## 6. 핵심 포인트
- 재귀의 대표적인 예시 (문제를 자기 자신보다 작은 문제로 분할)
- 이동 횟수는 지수적으로 증가 → N이 커지면 현실적으로 불가능
- 알고리즘 학습, 수학적 귀납법 증명 연습에 많이 사용됨

## 1. 문제를 쪼갤 수 있는 이유
하노이의 탑 원리는 **“큰 문제 → 작은 문제로 분할”**에서 나옵니다.

- N개의 원반이 있다고 가정
- 맨 아래 원반(가장 큰 원반)은 절대 다른 원반 위로 못 올라감
- 따라서 **가장 큰 원반을 옮기려면 위에 있는 N-1개를 먼저 비워야 함**

즉, N개를 옮기는 문제 =  
1️⃣ N-1개 원반을 **보조 기둥**으로 옮기기  
2️⃣ 가장 큰 원반을 **목표 기둥**으로 옮기기  
3️⃣ N-1개 원반을 **목표 기둥**으로 옮기기  

---

## 2. 재귀적 구조
예를 들어 N=3일 때를 보면:

```
[3, 2, 1] (A) → (C)
```

- **Step 1**: [2, 1] (N-1=2개)을 B로 옮김  
  → 이 자체가 “N=2 하노이 문제”
- **Step 2**: 원반 3을 C로 옮김
- **Step 3**: B의 [2, 1]을 C로 옮김  
  → 다시 “N=2 하노이 문제”

즉, **"N 하노이 문제" 안에 또 N-1 하노이 문제가 들어있음**  
→ 이게 재귀 호출의 형태입니다.

---

## 3. 최소 이동 횟수 공식 유도
재귀적 정의:
- \( M(N) \) = N개의 원반 최소 이동 횟수
- 위 원리에 따라:
  \[
  M(N) = M(N-1) + 1 + M(N-1)
  \]
  \[
  M(N) = 2 \times M(N-1) + 1
  \]

기저 조건:
- \( M(1) = 1 \) (원반이 하나면 바로 옮기면 끝)

점화식 풀기:
\[
M(N) = 2^N - 1
\]

---

## 4. 왜 재귀가 필연적인가?
- 하노이의 탑은 **큰 원반이 이동하려면 그 위가 완전히 비워져야 함** → 이 과정에서 동일한 규칙이 계속 반복됨.
- 결국 **자기 자신보다 작은 버전의 같은 문제**를 계속 풀어야 함 → 재귀가 가장 자연스러운 해결법.

---

## 5. 시각적 이해 (N=3)
```
A: 3 2 1
B:
C:
```
1. (N-1=2) A → B  
2. (1) A → C  
3. (N-1=2) B → C  

각 N-1 옮김도 같은 방식으로 반복.

---

📌 **정리**  
하노이의 탑 원리는  
> **큰 문제를 ‘N-1개의 하노이 문제’로 쪼개고, 마지막 1개의 원반을 옮긴 뒤, 다시 N-1개의 하노이 문제를 푸는 과정의 반복**  
입니다.  
그 결과 이동 횟수는 \( 2^N - 1 \)이고, 재귀적 구조가 본질이 됩니다.
