# 계단 수 계산 방법

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
45656이란 수를 보자.
이 수는 인접한 모든 자리의 차이가 1이다. 이런 수를 계단 수라고 한다.
N이 주어질 때, 길이가 N인 계단 수가 총 몇 개 있는지 구해보자. 0으로 시작하는 수는 계단수가 아니다.
입력
첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 100보다 작거나 같은 자연수이다.
출력
첫째 줄에 정답을 1,000,000,000으로 나눈 나머지를 출력한다.

### 💡 답변 (Assistant)
계단 수는 인접한 모든 자리의 차이가 1인 수를 말합니다. 예를 들어, 45656이라는 수는 인접한 모든 자리의 차이가 1이기 때문에 계단 수에 해당됩니다. 우리는 주어진 길이 \( N \)에 대해 몇 개의 계단 수가 존재하는지 계산해야 합니다.

### 접근 방법

동적 계획법(DP, Dynamic Programming)을 사용하여 문제를 해결할 수 있습니다. DP 테이블을 사용해 문제를 단계별로 나누어 해결해봅시다.

#### DP 테이블 정의
- \( dp[n][d] \): 길이가 \( n \)이고 마지막 자리가 \( d \)인 계단 수의 개수

#### 초기 상태
- \( dp[1][d] = 1 \) for \( d \) in 1 to 9: 길이가 1인 계단 수는 각 숫자 자체로 1개씩 존재합니다. (0은 제외)

#### 상태 전이
- \( dp[n][d] \):
  - \( d > 0 \)일 때 \( dp[n][d] = dp[n-1][d-1] \) (마지막 자리가 \( d \)이고 그 전 자리가 \( d-1 \)인 경우)
  - \( d < 9 \)일 때 \( dp[n][d] += dp[n-1][d+1] \) (마지막 자리가 \( d \)이고 그 전 자리가 \( d+1 \)인 경우)

#### 최종 결과
- \( \sum_{d=0}^9 dp[N][d] \): 길이가 \( N \)인 모든 계단 수의 합

마지막으로, 결과를 \( 1,000,000,000 \)으로 나눈 나머지를 출력합니다.

### 구현 코드

```python
MOD = 1000000000

def count_stepping_numbers(N):
    dp = [[0] * 10 for _ in range(N + 1)]
    
    # Initialize base cases
    for d in range(1, 10):
        dp[1][d] = 1
    
    # Fill DP table
    for n in range(2, N + 1):
        for d in range(10):
            if d > 0:
                dp[n][d] += dp[n-1][d-1]
            if d < 9:
                dp[n][d] += dp[n-1][d+1]
            dp[n][d] %= MOD
    
    # Sum up all dp[N][d] for d from 0 to 9
    result = sum(dp[N]) % MOD
    return result

# Read input
N = int(input().strip())
print(count_stepping_numbers(N))
```

### 코드 설명
1. **초기화**: \( dp[1][1] \)부터 \( dp[1][9] \)까지를 1로 설정합니다.
2. **DP 테이블 채우기**: 2부터 \( N \)까지 모든 길이에 대해 \( dp \) 테이블을 업데이트 합니다. 각 자릿수 \( d \)에 대해 가능한 이전 자릿수의 값을 더해줍니다.
3. **결과 계산**: \( dp[N] \)의 모든 값을 더하여 결과를 구하고, \( 1,000,000,000 \)으로 나눈 나머지를 출력합니다.

이 접근법을 통해 문제를 효과적으로 해결할 수 있습니다.
