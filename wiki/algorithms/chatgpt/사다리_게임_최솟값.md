## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 문제는 **백트래킹(완전 탐색)**과 **시뮬레이션**이 결합된 형태입니다. 목표는 "모든 i번 세로선에서 출발해서 i번 세로선으로 끝나는" 상태를 만드는 것이며, **추가할 수 있는 가로선의 수가 최대 3개**라는 제약이 있습니다.

---

## ✅ 핵심 아이디어

1. **시뮬레이션 함수**  
   현재 사다리 상태로 각 세로선이 자기 자신으로 도착하는지 시뮬레이션합니다.

2. **백트래킹 함수 (DFS)**  
   추가할 수 있는 가로선을 0개부터 3개까지 시도해보며 가능한 경우를 탐색합니다.

3. **가로선 제약 조건 확인**
   - 한 위치에는 이미 가로선이 없어야 함
   - 바로 옆에도 가로선이 없어야 함 (겹치거나 연속 안됨)

---

## ✅ Python 코드

```python
import sys
input = sys.stdin.readline

N, M, H = map(int, input().split())

ladder = [[0]*N for _ in range(H)]

# 초기 가로선 세팅
for _ in range(M):
    a, b = map(int, input().split())
    ladder[a-1][b-1] = 1  # 오른쪽으로 이동
    ladder[a-1][b] = -1   # 왼쪽에서 온 것 표시

# 사다리 시뮬레이션
def check():
    for start in range(N):
        k = start
        for i in range(H):
            if ladder[i][k] == 1:
                k += 1
            elif ladder[i][k] == -1:
                k -= 1
        if k != start:
            return False
    return True

answer = 4  # 최댓값은 3이므로 초기값은 4로 둠

def dfs(depth, x, y):
    global answer
    if depth >= answer:
        return
    if check():
        answer = depth
        return
    if depth == 3:
        return

    for i in range(x, H):
        k = y if i == x else 0
        for j in range(k, N-1):
            if ladder[i][j] == 0 and ladder[i][j+1] == 0:
                # 가로선 설치
                ladder[i][j] = 1
                ladder[i][j+1] = -1
                dfs(depth+1, i, j+2)  # 인접 회피
                # 가로선 제거 (백트래킹)
                ladder[i][j] = 0
                ladder[i][j+1] = 0

dfs(0, 0, 0)
print(answer if answer <= 3 else -1)
```

### ❓ 질문 (User)

초록선은 세로선을 나타내고, 초록선과 점선이 교차하는 점은 가로선을 놓을 수 있는 점이다. 가로선은 인접한 두 세로선을 연결해야 한다. 단, 두 가로선이 연속하거나 서로 접하면 안 된다. 또, 가로선은 점선 위에 있어야 한다.

## 📌 1. 입력 및 초기 사다리 설정

```python
N, M, H = map(int, input().split())
ladder = [[0] * N for _ in range(H)]
```

- `N`: 세로선 개수
- `M`: 기존에 주어진 가로선 개수
- `H`: 가로선을 놓을 수 있는 위치 개수 (행)
- `ladder[h][n]`:  
  - `0` → 아무것도 없음  
  - `1` → 현재 위치에서 오른쪽으로 이동  
  - `-1` → 현재 위치는 왼쪽에서 온 선

```python
for _ in range(M):
    a, b = map(int, input().split())
    ladder[a-1][b-1] = 1    # 오른쪽으로 이동
    ladder[a-1][b] = -1     # 왼쪽에서 온 것
```

- 입력은 `a`행, `b`열에 가로선을 추가하라는 의미 → 실제로는 (a-1, b-1)과 (a-1, b) 사이
- 사다리 상태에 양방향 정보를 저장

---

## 📌 2. 사다리 결과 검증 함수 `check()`

```python
def check():
    for start in range(N):
        k = start
        for i in range(H):
            if ladder[i][k] == 1:
                k += 1
            elif ladder[i][k] == -1:
                k -= 1
        if k != start:
            return False
    return True
```

- 각 세로선 `start`에 대해 아래로 내려가며 가로선을 따라 이동
- 마지막 위치 `k`가 자기 자신이면 OK
- 하나라도 실패하면 `False` 반환

---

## 📌 3. 백트래킹 탐색 함수 `dfs()`

```python
def dfs(depth, x, y):
    global res
    if depth >= res:
        return
    if check():
        res = depth
        return
    if depth == 3:
        return
```

- `depth`: 지금까지 추가한 가로선 개수
- `x`, `y`: 탐색 시작 위치 (중복 탐색 방지)
- `res`: 현재까지 찾은 최솟값

### 🔍 가로선 추가 루프

```python
    for i in range(x, H):
        k = y if i == x else 0
        for j in range(k, N - 1):
            if ladder[i][j] == 0 and ladder[i][j+1] == 0:
                ladder[i][j] = 1
                ladder[i][j+1] = -1
                dfs(depth+1, i, j+2)  # 인접 가로선 회피
                ladder[i][j+1] = 0
                ladder[i][j] = 0
```

- `(i, j)`에서 가로선을 놓을 수 있는 경우:
  - 해당 위치와 바로 오른쪽이 비어 있어야 함
- `dfs(depth + 1, i, j+2)`:
  - 같은 행에서는 인접 가로선을 피하기 위해 `j+2`부터
- 백트래킹 구조이므로 **추가 후 복구**도 필수

## 📌 4. 실행 및 출력

```python
res = 4  # 최대 3까지만 유효, 그 이상은 -1 처리
dfs(0, 0, 0)
print(res if res <= 3 else -1)
```

- 탐색을 시작하면서, 결과 저장 변수 `res`는 초기값 4로 설정
- 탐색 결과가 `res <= 3`이면 정답, 아니면 `-1`

---

## ✅ 예시 흐름 (예제 입력 2: `2 1 3`, 입력: `1 1`)

- 초기 상태:
  ```
  N = 2, M = 1, H = 3
  ladder[0][0] = 1, ladder[0][1] = -1
  ```

- 결과: 1번 세로선은 2번으로 감 → 실패
- 추가로 1개의 가로선만 더 추가해도 i → i 가능
- 출력: `1`

## 🧠 요약: 이 코드는...

| 구성 요소 | 설명 |
|-----------|------|
| 완전탐색 + 백트래킹 | 최대 깊이 3까지 조합 탐색 |
| 시뮬레이션 | 현재 사다리 구조에서 결과 i → i 검증 |
| 조건 검사 | 인접한 가로선 없는 위치만 선택 |
| 최적화 | `res`보다 크거나 같은 경우 가지치기 |

---

필요하다면 이 구조를 기반으로 **애니메이션 시뮬레이션**이나 **조작 가능한 인터랙티브 데모**로 확장도 가능합니다.

### ❓ 질문 (User)
```
N, M, H = map(int, input().split())

ladder = [[0] * N for _ in range(H)]

# 초기 가로선 세팅
for _ in range(M) :
    a, b = map(int, input().split())
    ladder[a-1][b-1] = 1    # 오른쪽으로 이동
    ladder[a-1][b] = -1     # 왼쪽에서 온 것 표시

# 사다리 시뮬레이션
def check() :
    for start in range(N) :
        k = start
        for i in range(H) :
            if ladder[i][k] == 1 :
                k += 1
            elif ladder[i][k] == -1 :
                k -= 1
        if k != start :
            return False
    return True

def dfs(depth, x, y) :
    global res
    if depth >= res :
        return
    if check() :
        res = depth
        return
    if depth == 3 :
        return

    for i in range(x, H) :
        k = y if i == x else 0
        for j in range(k, N - 1) :
            if ladder[i][j] == 0 and ladder[i][j+1] == 0 :
                # 가로선 설치
                ladder[i][j] = 1
                ladder[i][j+1] = -1
                dfs(depth+1, i, j+2)    # 인접 회피
                # 가로선 제거 (백트래킹)
                ladder[i][j+1] = 0
                ladder[i][j] = 0

res = 4 # 최댓값은 3이므로 초기값은 4로 둠

dfs(0,0,0)
print(res if res <= 3 else -1)
```
