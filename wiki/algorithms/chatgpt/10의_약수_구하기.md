# 10의 약수 구하기

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
아래는 **파이썬을 사용해 10의 모든 약수를 구하는 코드**입니다:

```python
n = 10

divisors = []

for i in range(1, n + 1):
    if n % i == 0:
        divisors.append(i)

print(f"{n}의 약수: {divisors}")
```

### 실행 결과:
```
10의 약수: [1, 2, 5, 10]
```

### 설명:
- `n % i == 0` 은 `i`가 `n`을 나누어 떨어지게 하는지를 확인합니다.
- 나누어 떨어지면 약수이므로 리스트에 추가합니다.

원하시면 리스트 컴프리헨션으로도 간단히 작성할 수 있어요:

```python
n = 10
divisors = [i for i in range(1, n + 1) if n % i == 0]
print(divisors)
```

필요하면 입력값을 사용자로부터 받는 방식도 알려드릴게요.

### ❓ 질문 (User)
파이썬 코드를 활용하여 10의 모든 약수를 구하는 코드를 알려줘

### 💡 답변 (Assistant)
네, 있습니다. 현재 코드의 시간 복잡도는 **O(n)**입니다. 하지만 약수는 대칭적으로 존재하기 때문에, **O(√n)**으로 줄일 수 있습니다.

### 개선된 코드 (시간 복잡도 O(√n)):

```python
import math

n = 10
divisors = set()

for i in range(1, int(math.sqrt(n)) + 1):
    if n % i == 0:
        divisors.add(i)
        divisors.add(n // i)  # i와 짝을 이루는 약수

print(f"{n}의 약수: {sorted(divisors)}")
```

### 실행 결과:
```
10의 약수: [1, 2, 5, 10]
```

### 시간 복잡도 분석:
- `i`를 `1`부터 `√n`까지만 반복하므로 반복 횟수는 약 `√n`번.
- 약수 한 쌍을 한 번에 추가하므로 중복 없이 모든 약수를 빠르게 구함.

이 코드는 `n`이 클수록 성능 차이가 확실히 납니다.  
예를 들어 `n = 10**6`일 때, 기존 방식은 백만 번 반복하지만 개선된 방식은 약 1000번만 반복합니다.

필요하다면 리스트가 아닌 **정렬된 출력**, **입력값 받기**, **약수의 개수/합 계산** 등도 확장 가능합니다.
