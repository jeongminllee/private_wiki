# 벨만-포드 알고리즘 설명

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
벨만 - 포드 알고리즘을 알려줘

### 💡 답변 (Assistant)
벨만-포드(Bellman-Ford) 알고리즘은 **가중치 그래프에서 하나의 시작 정점으로부터 다른 모든 정점까지의 최단 경로를 찾는 알고리즘**입니다. 다익스트라 알고리즘과 달리, **가중치가 음수인 간선**이 있어도 처리할 수 있는 것이 특징입니다.  

### 주요 특징
1. **음수 가중치 지원**: 벨만-포드는 음수 가중치가 있는 그래프에서도 동작합니다.
2. **음수 사이클 검출**: 음수 사이클이 존재하면 경로 비용이 계속 감소하므로, 이를 탐지할 수 있습니다.
3. 시간 복잡도: \(O(V \cdot E)\)  
   - \(V\): 정점의 개수
   - \(E\): 간선의 개수

---

### 알고리즘 과정
1. **초기화**:
   - 시작 정점의 거리를 0으로 설정하고, 나머지 정점들의 거리를 무한대(\(\infty\))로 초기화합니다.

2. **완화(Relaxation)**:
   - 그래프의 모든 간선을 최대 \(V-1\)번 반복해서 확인하며 거리를 갱신합니다.
   - 각 간선을 따라 이동했을 때 더 짧은 경로가 발견되면 거리 값을 업데이트합니다.

3. **음수 사이클 탐지**:
   - 모든 간선을 한 번 더 확인하여, 거리 갱신이 발생하면 음수 사이클이 존재한다고 판단합니다.

---

### 의사 코드 (Pseudo-code)
```text
function BellmanFord(graph, source):
    # Step 1: 초기화
    distance = [∞] * number_of_vertices
    distance[source] = 0
    
    # Step 2: 모든 간선 완화 반복 (V-1번)
    for i from 1 to |V| - 1:
        for each edge (u, v, weight) in graph.edges:
            if distance[u] + weight < distance[v]:
                distance[v] = distance[u] + weight
    
    # Step 3: 음수 사이클 검사
    for each edge (u, v, weight) in graph.edges:
        if distance[u] + weight < distance[v]:
            return "음수 사이클 존재"
    
    return distance
```

### Python 구현 예제
```python
class Graph:
    def __init__(self, vertices):
        self.V = vertices  # 정점의 수
        self.edges = []    # 간선 목록

    def add_edge(self, u, v, weight):
        self.edges.append((u, v, weight))

    def bellman_ford(self, source):
        # Step 1: 초기화
        distance = [float('inf')] * self.V
        distance[source] = 0

        # Step 2: 완화 반복
        for _ in range(self.V - 1):
            for u, v, weight in self.edges:
                if distance[u] != float('inf') and distance[u] + weight < distance[v]:
                    distance[v] = distance[u] + weight

        # Step 3: 음수 사이클 검사
        for u, v, weight in self.edges:
            if distance[u] != float('inf') and distance[u] + weight < distance[v]:
                print("음수 사이클이 존재합니다.")
                return None

        return distance

# 예제 사용
graph = Graph(5)
graph.add_edge(0, 1, -1)
graph.add_edge(0, 2, 4)
graph.add_edge(1, 2, 3)
graph.add_edge(1, 3, 2)
graph.add_edge(1, 4, 2)
graph.add_edge(3, 2, 5)
graph.add_edge(3, 1, 1)
graph.add_edge(4, 3, -3)

result = graph.bellman_ford(0)
if result:
    print("최단 거리:", result)
```

### 예제 설명
- 그래프의 정점과 간선이 주어지면, 벨만-포드 알고리즘이 시작 정점으로부터 다른 모든 정점까지의 최단 경로를 계산합니다.
- 만약 음수 사이클이 존재한다면 이를 탐지하고 메시지를 출력합니다.

---

### 장단점
#### 장점:
- 음수 가중치가 있는 그래프를 처리 가능.
- 음수 사이클 탐지가 가능.
  
#### 단점:
- 시간 복잡도가 높아 큰 그래프에서는 비효율적.
- 양의 가중치만 있는 경우 다익스트라 알고리즘이 더 효율적.
