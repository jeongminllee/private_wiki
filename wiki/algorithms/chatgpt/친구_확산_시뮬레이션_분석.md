# 친구 확산 시뮬레이션 분석

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-02-27

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 코드는 사람들 사이의 친구 관계가 하루하루 확산되어 결국 모든 사람이 서로 친구가 되는(즉, 완전 그래프가 되는) 과정을 시뮬레이션합니다. 주요 흐름은 다음과 같습니다.

---

### 1. 초기 설정
- **입력 처리:**  
  - `N, M = map(int, input().split())`를 통해 사람 수 \(N\)과 초기 친구 관계의 개수 \(M\)을 입력받습니다.
- **친구 관계 저장:**  
  - `friends` 리스트를 \(N+1\) 길이의 집합(set) 배열로 생성하여, 각 인덱스 \(i\)에는 \(i\)번 사람의 친구들의 번호를 저장합니다. (1번부터 \(N\)번까지 사용)

- **초기 친구 추가:**  
  - 다음 반복문에서 \(M\)개의 줄에 걸쳐 두 사람 \(A\)와 \(B\)의 친구 관계를 입력받고, 서로의 친구 집합에 추가합니다.

---

### 2. 친구 확산 시뮬레이션
- **일수와 기록 초기화:**  
  - `days = 0`: 전체 과정에서 소요된 일수를 세기 위한 변수  
  - `daily_new_friends = []`: 매일 새로 형성된 친구 관계의 수를 기록하는 리스트

- **무한 루프:**  
  - 매 반복마다 현재까지 형성된 친구 관계의 총 개수를 계산합니다.  
    - 각 사람의 친구 수를 합산하여 `new_count`에 저장합니다.
  - **종료 조건:**  
    - 모든 사람이 서로 친구인 상태라면, 각 사람이 \(N-1\)명의 친구를 가지게 되므로 \( \text{new_count} = N \times (N-1) \)가 됩니다.  
    - 이 조건이 만족되면 루프를 종료합니다.

- **새로운 친구 찾기:**  
  - 각 사람마다 현재 친구들의 친구(즉, "친구의 친구")를 확인합니다.
  - 만약 친구의 친구가 자신이 아니고, 이미 친구 목록에 없는 경우 새로운 친구 관계로 간주합니다.
  - 중복 추가를 방지하기 위해, (작은 번호, 큰 번호) 형태의 튜플로 저장하여 집합 `new_friend`에 추가합니다.

- **새 친구 관계 업데이트:**  
  - 새로 찾은 친구 관계 쌍에 대해, 양쪽 사람의 친구 집합에 서로 추가합니다.
  - 그날 형성된 새로운 친구 관계의 개수를 `daily_new_friends` 리스트에 기록하고, `days`를 1 증가시킵니다.

---

### 3. 결과 출력
- **최종 출력:**  
  - 전체 과정에 걸린 일수(`days`)를 출력합니다.
  - 이어서 매일 형성된 새 친구 관계의 수를 한 줄씩 출력합니다.

---

### 요약
- **목적:**  
  초기 친구 관계를 바탕으로, 매일 “친구의 친구”를 통해 새로운 친구 관계가 형성되어 최종적으로 모든 사람이 서로 친구가 되는 시점을 찾는 시뮬레이션.
- **알고리즘:**  
  각 반복(일)에 대해 모든 사람을 대상으로 친구의 친구를 확인하고, 새로 형성된 친구 관계를 업데이트하며, 전체 친구 관계 수가 완전 그래프 상태에 도달할 때까지 진행.
- **출력:**  
  전체 소요된 일수와 매일 형성된 친구 관계의 개수를 출력.

이와 같이 코드는 점진적으로 친구 네트워크를 확장하며, 언제 모든 사람이 서로 친구가 되는지, 그리고 매일 몇 개의 새 친구 관계가 생기는지를 계산합니다.

---

### ❓ 질문 (User)
```
def sol_3098() :
    N, M = map(int, input().split())
    friends = [set() for _ in range(N + 1)]

    # 초기 친구 관계 설정
    for _ in range(M) :
        A, B = map(int, input().split())
        friends[A].add(B)
        friends[B].add(A)

    days = 0
    daily_new_friends = []


    while True :
        new_count = 0
        for i in range(1, N + 1) :
            new_count += len(friends[i])

        if new_count == N * (N - 1) :
            break

        new_friend = set()

        # 각 사람에 대해 친구의 친구를 탐색
        for person in range(1, N + 1) :
            for friend in friends[person] : # 현재 친구 목록
                for f_of_f in friends[friend] : # 친구의 친구 목록
                    if f_of_f != person and f_of_f not in friends[person] : # 새로운 친구라면 추가
                        if person <= f_of_f :
                            new_friend.add((person, f_of_f))
                        else :
                            new_friend.add((f_of_f, person))

        for a, b in new_friend :
            friends[a].add(b)
            friends[b].add(a)

        days += 1
        daily_new_friends.append(len(new_friend))    # 친구 관계는 양방향이므로 // 2

    # 결과 출력
    print(days)
    for cnt in daily_new_friends :
        print(cnt)
```
