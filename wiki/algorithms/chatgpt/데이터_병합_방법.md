원하시면 직접 병합된 파일을 저장할 수 있도록, 아래 단계를 안내드릴게요:

1. 각 CSV 파일에서 앞의 8줄을 건너뛰고 데이터를 불러옵니다.
2. `"기기"` 열을 추가하여 각각 `"모바일"` 또는 `"PC"`라고 표시합니다.
3. 두 데이터프레임을 `pd.concat`으로 합쳐 하나의 파일로 만듭니다.
4. 병합된 데이터를 `to_csv("combined_shopping_insight.csv", index=False)`로 저장합니다.

위의 방식으로 직접 처리하시거나, 다시 분석 도구가 가능할 때 요청해 주시면 파일을 바로 드릴 수 있습니다.

# 기기별 유입량 합계 계산

# 냉장고

    aggregated["냉장고"],
    labels=aggregated.index,
    autopct="%1.1f%%",
    startangle=90,
    colors=colors
)
axes[0].set_title("냉장고 유입 비율 (PC vs 모바일)")

# 무선청소기
axes[1].pie(
    aggregated["무선청소기"],
    labels=aggregated.index,
    autopct="%1.1f%%",
    startangle=90,
    colors=colors
)
axes[1].set_title("무선청소기 유입 비율 (PC vs 모바일)")

### 냉장고와 무선청소기 PC, 모바일 비율 계산 및 파이 그래프 그리기 방법 (Python)

```python
import pandas as pd
import matplotlib.pyplot as plt

# 데이터 불러오기
df = pd.read_csv("Mearged_PC_And_Mobile_Data.csv")

# 기기별 총 합계 계산
grouped = df.groupby('기기').sum()

# 냉장고와 무선청소기 데이터
fridge_data = grouped['냉장고']
vacuum_data = grouped['무선청소기']

# 비율 계산
fridge_ratio = fridge_data / fridge_data.sum()
vacuum_ratio = vacuum_data / vacuum_data.sum()

# 파이 그래프 그리기
fig, axes = plt.subplots(1, 2, figsize=(12, 6))

axes[0].pie(fridge_ratio, labels=fridge_ratio.index, autopct='%1.1f%%', startangle=90, colors=['#66b3ff','#ff9999'])
axes[0].set_title('냉장고 PC vs 모바일 비율')

axes[1].pie(vacuum_ratio, labels=vacuum_ratio.index, autopct='%1.1f%%', startangle=90, colors=['#99ff99','#ffcc99'])
axes[1].set_title('무선청소기 PC vs 모바일 비율')

plt.show()
```
