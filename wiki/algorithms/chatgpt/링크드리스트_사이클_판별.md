# 1. Floyd’s Cycle-Finding Algorithm (가장 유명)
### (일명 Tortoise and Hare)

- **핵심 아이디어**  
  서로 다른 속도로 이동하는 두 포인터를 사용  
  → slow: 1칸, fast: 2칸 이동  
  → 사이클이 있으면 반드시 만남

- **시간/공간 복잡도**
  - Time: \(O(n)\)
  - Space: \(O(1)\)

- **이론적 배경**
  - 순환 구조에서 서로 다른 속도의 포인터는 결국 같은 위치에서 만나게 된다는 **주기성(periodicity)** 기반 증명

- **참고 (사실상 “원전”)**
  - Donald Knuth가 1969년에 Floyd에게 귀속시켜 소개  
  - 하지만 실제 Floyd 논문에는 직접 등장하지 않는 것으로 알려짐 (folk theorem 성격) citeturn0search10

---

### 핵심 동작 요약
```
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    
    if slow == fast:
        cycle exists
```

→ fast가 끝(null)에 도달하면 cycle 없음  
→ slow와 fast가 만나면 cycle 존재 citeturn0search0

# 2. Brent’s Algorithm (논문 기반, 더 수학적/최적화된 방법)

### 📄 논문
- **Richard P. Brent**
- *“An improved Monte Carlo factorization algorithm”*
- BIT Numerical Mathematics (1970s)

---

### 특징
- Floyd보다 **평균적으로 약 36% 빠름** citeturn0search10
- “2의 거듭제곱 단위로 탐색 범위 확장”
- 비교 횟수를 줄이는 방식

---

### 핵심 아이디어
- 일정 구간 길이를 \(2^k\) 단위로 늘리면서
- 한 포인터 기준으로 반복 탐색

---

### 간단 구조
```
power = lam = 1
tortoise = x0
hare = f(x0)

while tortoise != hare:
    if power == lam:
        tortoise = hare
        power *= 2
        lam = 0
    hare = f(hare)
    lam += 1
```

---

# 3. Hash-based 방법 (논문보다는 실용적 baseline)

- 방문한 노드를 set/hash에 저장
- 중복 방문 → cycle

### 특징
- Time: \(O(n)\)
- Space: \(O(n)\)

---

# 📚 정리 (논문/이론 기준 비교)

| 알고리즘 | 제안자 | 핵심 아이디어 | 공간 |
|----------|--------|--------------|------|
| Floyd | (Knuth → Floyd attribution) | 두 포인터 속도 차이 | O(1) |
| Brent | Richard Brent | power-of-two 탐색 | O(1) |
| Hash 방식 | - | 방문 기록 저장 | O(n) |
