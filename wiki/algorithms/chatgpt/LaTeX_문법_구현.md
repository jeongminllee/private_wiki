# 1) LaTeX 문서(MWE: Minimal Working Example)
다음 파일로 저장해서 `pdflatex`로 컴파일하면 번호와 함께 수식이 예쁘게 출력됩니다.

```tex
\documentclass[a4paper,12pt]{article}
\usepackage{amsmath, amssymb}
\usepackage{enumitem}
\setlist[itemize]{noitemsep, topsep=2pt}
\setlist[enumerate]{noitemsep, topsep=6pt}

\begin{document}

주어진 식을 여러 방식으로 변형하여 표현:

\begin{enumerate}
  \item 분자와 분모를 $h$로 곱합니다:
  \[
    \frac{\sqrt{\,4 + h - 2\,}\ \cdot h}{h}
  \]

  \item (형식적 조작) 분자의 $h$를 루트 안으로 넣습니다:
  \[
    \frac{\sqrt{\,h(4 + h - 2)\,}}{h}
  \]
  % 주의: 일반적으로는 $a\sqrt{b}=\sqrt{a^2 b}$ 이므로
  % 엄밀히는 \frac{\sqrt{\,h^2(4+h-2)\,}}{h} 가 규칙과 맞습니다.

  \item 루트 안의 식을 정리합니다:
  \[
    \frac{\sqrt{\,h(h + 2)\,}}{h}
  \]

  \item 지수 표기(음수 지수/분수 지수)로 표현:
  \[
    (4 + h - 2)^{\frac{1}{2}} \cdot h^{-1}
  \]
\end{enumerate}

\end{document}
```

# 2) Markdown/MathJax에서 바로 쓰는 버전
노션/깃헙/블로그 등 MathJax가 켜진 환경에서 그대로 붙여넣어 렌더링할 수 있어요.

- 분자와 분모를 \(h\)로 곱합니다:
  $$
  \frac{\sqrt{4 + h - 2}\cdot h}{h}
  $$

- (형식적 조작) 분자의 \(h\)를 루트 안으로 넣습니다:
  $$
  \frac{\sqrt{h(4 + h - 2)}}{h}
  $$

- 루트 안의 식을 정리합니다:
  $$
  \frac{\sqrt{h(h + 2)}}{h}
  $$

- 지수 표기로:
  $$
  (4 + h - 2)^{\frac{1}{2}}\cdot h^{-1}
  $$

# 3) 여기서 사용된 LaTeX 문법 치트시트
- 분수: `\frac{분자}{분모}` → \(\frac{a}{b}\)
- 제곱근: `\sqrt{식}` (선 굵히기 등은 불필요) → \(\sqrt{x}\)
- 곱점: `\cdot` → \(a\cdot b\) (생략 가능하나 명료함 위해 사용)
- 지수(위 첨자): `x^{1/2}`, `h^{-1}` → \(x^{1/2},\ h^{-1}\)
- 중괄호 `{}`: 그룹화(여러 기호/식을 하나의 단위로 묶음)
- 괄호: 그냥 `( )` 사용. 자동 크기 조절은 `\left( \right)` 형태
- 인라인/디스플레이:
  - 인라인: `$ ... $` → 문장 속 수식 \(a+b\)
  - 디스플레이: `\[ ... \]` 또는 `$$ ... $$` → 중앙 정렬 큰 수식
- 정렬된 다줄 수식: `align`/`align*` 환경(= 맞춤선 `&` 사용)

필요하시면 위 표현을 **`align*`**으로 정렬해 한 번에 보여주는 버전도 만들어 드릴게요!

# 평문 수식(LaTeX 제거)
1) \((\sqrt{4 + h − 2} · h) / h\)  
2) \(\sqrt{h(4 + h − 2)} / h\)  
3) \(\sqrt{h(h + 2)} / h\)  
4) \((4 + h − 2)^{1/2} · h^{−1}\)

# 문장형 읽기
1) “루트(4 + h − 2) 곱하기 h를 h로 나눈다.”  
2) “루트(h(4 + h − 2))를 h로 나눈다.”  
3) “루트(h(h + 2))를 h로 나눈다.”  
4) “(4 + h − 2)의 1/2제곱에 h의 −1제곱을 곱한다.”

원하시면 특정 플랫폼(노션/워드/파워포인트/한글 등)에 맞춘 표기나, 한 줄짜리/여러 줄짜리 버전으로도 변환해 드릴게요.
