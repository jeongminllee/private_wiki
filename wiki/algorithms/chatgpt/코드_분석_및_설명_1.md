# 코드 분석 및 설명

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
from collections import deque

T = int(input())

for _ in range(T) :
    N, K = map(int, input().split())
    D = [0] + list(map(int, input().split()))

    dp = [0 for _ in range(N + 1)]
    edges_to_fr = [[] for _ in range(N + 1)]
    edges_fr_to = [[] for _ in range(N + 1)]
    incoming = [0 for _ in range(N + 1)]

    for _ in range(K) :
        x, y = map(int, input().split())
        edges_to_fr[y].append(x)
        edges_fr_to[x].append(y)
        incoming[y] += 1

    w = int(input())

    q = deque()

    for i in range(1, N + 1) :
        if incoming[i] == 0 :
            q.append(i)

    while q :
        to = q.popleft()
        frs = edges_to_fr[to]

        if len(frs) == 0:
            dp[to] = D[to]

        else :
            mx_local = 0

            for fr in frs :
                mx_local = max(mx_local, dp[fr])
            dp[to] = D[to] + mx_local

        tos = edges_fr_to[to]
        for to in tos :
            incoming[to] -= 1
            if incoming[to] == 0 :
                q.append(to)

    print(dp[w])
```
이 코드를 분석해줘

### 💡 답변 (Assistant)
이 코드는 위상 정렬(Topological Sorting)과 동적 프로그래밍(Dynamic Programming)을 활용하여 문제를 해결하는 알고리즘입니다. 주어진 그래프에서 특정 노드 \( w \)까지의 경로에서 최대 비용을 구하는 역할을 합니다. 코드를 단계별로 분석하겠습니다.

---

### 1. **입력 데이터 처리**
```python
T = int(input())  # 테스트 케이스 수
```
- 입력받는 `T`는 테스트 케이스의 수입니다.
- 각 테스트 케이스는 그래프와 목표 노드 \( w \)가 주어집니다.

---

### 2. **테스트 케이스 반복 처리**
```python
for _ in range(T):
    N, K = map(int, input().split())  # N: 노드 수, K: 간선 수
    D = [0] + list(map(int, input().split()))  # 각 노드의 고유 비용
```
- \( N \): 그래프의 노드 수
- \( K \): 그래프의 간선 수
- \( D \): 각 노드의 고유 비용 (1번 노드부터 시작하므로 \( D[0] \)는 더미 값)

---

### 3. **그래프 표현**
```python
dp = [0 for _ in range(N + 1)]  # 각 노드까지의 최대 비용 저장
edges_to_fr = [[] for _ in range(N + 1)]  # 역방향 간선 리스트
edges_fr_to = [[] for _ in range(N + 1)]  # 정방향 간선 리스트
incoming = [0 for _ in range(N + 1)]  # 각 노드의 진입 차수
```
- `dp`: 각 노드까지의 최대 비용을 저장하는 DP 테이블
- `edges_to_fr`: 역방향 간선 (현재 노드로 들어오는 노드 리스트)
- `edges_fr_to`: 정방향 간선 (현재 노드에서 나가는 노드 리스트)
- `incoming`: 각 노드의 진입 차수를 기록

---

### 4. **그래프 구성**
```python
for _ in range(K):
    x, y = map(int, input().split())
    edges_to_fr[y].append(x)  # y로 들어오는 간선의 시작 노드 x
    edges_fr_to[x].append(y)  # x에서 나가는 간선의 끝 노드 y
    incoming[y] += 1          # y의 진입 차수 증가
```
- \( x \to y \): 간선 정보를 기반으로 그래프 구성
- `edges_to_fr`: 노드 \( y \)로 들어오는 노드 \( x \)를 기록
- `edges_fr_to`: 노드 \( x \)에서 나가는 노드 \( y \)를 기록
- `incoming`: 노드 \( y \)의 진입 차수를 증가

---

### 5. **목표 노드 입력**
```python
w = int(input())  # 목표 노드
```
- 결과를 계산할 목표 노드 \( w \)

---

### 6. **위상 정렬 준비**
```python
q = deque()
for i in range(1, N + 1):
    if incoming[i] == 0:  # 진입 차수가 0인 노드
        q.append(i)
```
- 진입 차수가 0인 노드를 큐에 추가
- 진입 차수가 0인 노드는 그래프에서 시작점 역할을 함

---

### 7. **위상 정렬 및 DP 계산**
```python
while q:
    to = q.popleft()  # 현재 노드
    frs = edges_to_fr[to]  # 현재 노드로 들어오는 노드 리스트

    if len(frs) == 0:  # 시작 노드인 경우
        dp[to] = D[to]
    else:
        mx_local = 0
        for fr in frs:
            mx_local = max(mx_local, dp[fr])  # 이전 노드들 중 최대 비용 선택
        dp[to] = D[to] + mx_local  # 현재 노드 비용 추가

    tos = edges_fr_to[to]  # 현재 노드에서 나가는 노드 리스트
    for to in tos:
        incoming[to] -= 1  # 다음 노드의 진입 차수 감소
        if incoming[to] == 0:  # 진입 차수가 0이 되면 큐에 추가
            q.append(to)
```
- 큐를 사용해 위상 정렬을 진행하며, 현재 노드 \( to \)까지의 최대 비용을 계산
- 진입 차수가 0이 된 노드를 큐에 추가하여 진행
- DP 값 업데이트:
  - 시작 노드: \( dp[to] = D[to] \)
  - 일반 노드: \( dp[to] = D[to] + \max(dp[fr]) \), 여기서 \( fr \)은 \( to \)로 들어오는 노드들

---

### 8. **결과 출력**
```python
print(dp[w])
```
- 목표 노드 \( w \)까지의 최대 비용 출력

### 요약
이 코드는 위상 정렬을 사용하여 DAG(Directed Acyclic Graph)에서 특정 노드까지의 최대 비용을 계산합니다. \( O(N + K) \)의 시간 복잡도를 가지며, \( T \)개의 테스트 케이스를 독립적으로 처리합니다. 

사용 사례로는 건물 건설 순서 및 비용 계산 문제(Warcraft 문제) 등이 있습니다.

### 💡 답변 (Assistant)
**Warcraft 문제**는 ACM ICPC(국제 대학생 프로그래밍 대회)와 같은 알고리즘 대회에서 자주 등장하는 유명한 그래프 문제 중 하나입니다. 이 문제는 건설 순서와 각 건물의 건설 비용을 고려하여 특정 건물을 짓는 데 필요한 최소 시간을 계산하는 문제입니다.

---

### **문제 설명**
1. **건물 간의 의존성**
   - \( N \)개의 건물이 있고, 각 건물 \( i \)는 짓는 데 필요한 시간이 \( D[i] \)라고 주어집니다.
   - 일부 건물은 다른 건물이 완성된 후에만 지을 수 있습니다. 이러한 의존성을 간선으로 표현합니다.

2. **그래프 구조**
   - 건물 간의 의존 관계는 방향 그래프(Directed Acyclic Graph, DAG)로 표현됩니다.
   - 예를 들어, 건물 1을 지어야만 건물 3을 지을 수 있다면, 간선 \( 1 \to 3 \)이 존재합니다.

3. **목표**
   - 특정 건물 \( W \)를 짓는 데 걸리는 최소 시간을 계산합니다.
   - 이때, 건물 \( W \)를 짓기 위해 의존하는 모든 건물도 완성해야 합니다.

### **예제**

```
4       # 목표 건물 W = 4

5 3     # 두 번째 테스트 케이스: 5개의 건물과 3개의 간선
10 20 1 5 8    # 각 건물의 건설 시간
1 2

```

### **해결 방법**
이 문제는 위상 정렬과 동적 프로그래밍(DP)을 통해 해결할 수 있습니다.

1. **그래프 구성**
   - 각 건물의 의존성을 간선으로 표현하여 방향 그래프를 만듭니다.
   - \( edges\_to\_fr \): 현재 노드로 들어오는 간선
   - \( edges\_fr\_to \): 현재 노드에서 나가는 간선
   - \( incoming \): 각 노드의 진입 차수

2. **위상 정렬**
   - 진입 차수가 0인 노드를 큐에 넣고, 의존 관계를 따라 순차적으로 처리합니다.

3. **DP 계산**
   - 각 노드 \( i \)까지 걸리는 최소 시간을 \( dp[i] \)로 정의합니다.
   - 시작 노드는 \( dp[i] = D[i] \)로 초기화합니다.
   - 다른 노드는 \( dp[i] = D[i] + \max(dp[fr]) \), 여기서 \( fr \)은 \( i \)로 들어오는 노드들입니다.

4. **목표 노드 출력**
   - 목표 노드 \( W \)의 \( dp[W] \) 값을 출력합니다.

### **알고리즘 동작**
위 예제를 단계별로 풀어보면 다음과 같습니다:

#### 첫 번째 테스트 케이스
1. \( N = 5 \), \( K = 4 \), \( D = [10, 1, 10, 10, 10] \)
2. 그래프:
   ```
   1 → 2 → 4
   1 → 3 → 5
   ```
3. 위상 정렬:
   - 진입 차수가 0인 노드부터 시작: 1 → 2 → 3 → 4 → 5
4. DP 계산:
   - \( dp[1] = 10 \)
   - \( dp[2] = dp[1] + D[2] = 10 + 1 = 11 \)
   - \( dp[3] = dp[1] + D[3] = 10 + 10 = 20 \)
   - \( dp[4] = dp[2] + D[4] = 11 + 10 = 21 \)
   - \( dp[5] = dp[3] + D[5] = 20 + 10 = 30 \)
5. 결과:
   - \( dp[4] = 21 \)

#### 두 번째 테스트 케이스
1. \( dp[1] = 10 \), \( dp[2] = dp[1] + D[2] = 30 \), \( dp[3] = dp[2] + D[3] = 31 \), \( dp[5] = dp[3] + D[5] = 38 \)
