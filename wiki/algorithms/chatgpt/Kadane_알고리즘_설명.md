### 💡 답변 (Assistant)
Kadane 알고리즘은 **연속 부분합(continuous subarray sum) 문제를 O(n) 시간에 푸는 대표적인 알고리즘**이에요.  
LeetCode 53번 *Maximum Subarray* 문제의 핵심 풀이로도 유명하죠.  

---

## 1. 문제 정의
> 정수 배열 `nums`가 주어졌을 때, **연속된 부분 배열의 합 중 최댓값**을 구하는 문제

예:
```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
연속 부분합 최댓값 = 6  (부분 배열: [4, -1, 2, 1])
```

---

## 2. 핵심 아이디어
- 배열을 왼쪽부터 순회하면서,  
  현재 위치까지의 **최대 연속 부분합**을 갱신해 나간다.
- **현재 원소를 포함하는 것이 이득인지, 새로 시작하는 것이 이득인지**를 매 순간 비교한다.

즉, 인덱스 `i`에서:
```
현재 위치까지 최대합 = max(nums[i], 현재위치까지 최대합 + nums[i])
전체 최대합 = max(전체 최대합, 현재 위치까지 최대합)
```

---

## 3. 동작 예시

`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`

| i | nums[i] | 현재까지의 최대합 (cur_sum) | 전체 최대합 (max_sum) |
|---|---------|---------------------------|-----------------------|
| 0 | -2      | -2                        | -2                    |
| 1 | 1       | max(1, -2+1) = 1          | 1                     |
| 2 | -3      | max(-3, 1-3) = -2          | 1                     |
| 3 | 4       | max(4, -2+4) = 4           | 4                     |
| 4 | -1      | max(-1, 4-1) = 3           | 4                     |
| 5 | 2       | max(2, 3+2) = 5            | 5                     |
| 6 | 1       | max(1, 5+1) = 6            | 6                     |
| 7 | -5      | max(-5, 6-5) = 1           | 6                     |
| 8 | 4       | max(4, 1+4) = 5            | 6                     |

결과: **6**

---

## 4. 파이썬 구현
```python
def kadane(nums):
    cur_sum = max_sum = nums[0]
    for num in nums[1:]:
        cur_sum = max(num, cur_sum + num)  # 새로 시작 vs 이어가기
        max_sum = max(max_sum, cur_sum)    # 최대값 갱신
    return max_sum

# 예시
print(kadane([-2,1,-3,4,-1,2,1,-5,4]))  # 6
```

---

## 5. 시간/공간 복잡도
- **시간 복잡도**: O(n) → 한 번 순회
- **공간 복잡도**: O(1) → 추가 배열 없이 변수 2개만 사용

---

## 6. 확장 & 응용
- **부분 배열의 시작/끝 인덱스까지** 추적 가능  
- 2D 배열 최대 부분합(동적 프로그래밍 + Kadane)  
- 주식 거래, 게임 점수 분석, 신호 처리 등에서 사용

# 1) 핵심 관찰: “끝점이 i인 최적해”만 알면 된다
연속 부분합의 최댓값을 구하려면, 인덱스 `i`에서 **i로 끝나는** 연속 부분배열 중 최대합 `best_end[i]`만 알고 가면 됩니다.  
이건 다음의 최적 부분구조에서 바로 나와요:

```
best_end[i] = max( nums[i], best_end[i-1] + nums[i] )
```

- 선택 A: `i`에서 **새로 시작** (그냥 `nums[i]`)
- 선택 B: `i-1`에서 끝난 최적해에 `nums[i]`를 **이어붙임** (`best_end[i-1] + nums[i]`)

여기서 직관이 뚜렷합니다:  
이전까지의 최적 끝합 `best_end[i-1]`가 **음수**라면, 그걸 이어붙이는 순간 합이 **깎이므로** `nums[i]` 하나로 새로 시작하는 게 이득이죠.  
반대로 `best_end[i-1]`가 **양수**면, 붙여서 더 커집니다.

이렇게 각 i에서 “새로 시작 vs 이어가기” 두 가지만 비교하면, 전체 최댓값 `answer`는 순회 중 매번 `answer = max(answer, best_end[i])`로 갱신하면 끝.

# 2) 불변식과 귀납적 정당화 (왜 항상 맞는가)
반복문이 i까지 진행됐다고 하자. 불변식은 두 가지예요.

1) `cur_sum = best_end[i]`  
   즉, **i로 끝나는** 연속 부분배열 중 최대합이 `cur_sum`에 들어있다.  
   - i에서의 선택은 위 공식 `max(nums[i], cur_sum + nums[i])`로 정확히 표현됨.
2) `max_sum`에는 **0..i 구간 전체에서의 최대 연속 부분합**이 들어있다.  
   - 매 스텝에서 `max_sum = max(max_sum, cur_sum)`로 유지.

초기(i=0)에는 둘 다 자명(한 원소짜리). i→i+1로 진행할 때, 1) 공식으로 `cur_sum` 갱신, 2) 그 값을 `max_sum`에 반영.  
따라서 귀납적으로 모든 i에서 참 → 마지막에 `max_sum`이 정답.

# 3) 프리픽스 합 관점: Kadane의 다른 얼굴
프리픽스 합 `P[k] = nums[0]+...+nums[k-1]`를 쓰면,  
어떤 연속 부분합 `nums[l..r]`의 합은 `P[r+1] - P[l]`입니다.  
따라서 r까지 봤을 때의 최댓값은
```
max_{0<=l<=r} (P[r+1] - P[l]) = P[r+1] - min_prefix_so_far
```
여기서 `min_prefix_so_far = min(P[0..r])`.  
즉, 오른쪽으로 스캔하면서
- 현재 `P[r+1]`에서 지금까지의 **가장 작은 프리픽스**를 빼면 “r에서 끝나는 최댓값”
- 그걸 전역 최대와 비교
- 그리고 `min_prefix_so_far` 갱신

이 방식이 **Kadane과 완전히 동치**예요. Kadane의 `cur_sum`은 사실상 `P[r+1] - min_prefix_so_far`를 즉석에서 계산하는 것과 같습니다.  
이 관점을 알면, “왜 음수 누적합은 버리나?”가 더 선명해요. 음수 누적합은 “최솟값 프리픽스” 역할을 못 하고 오히려 발목을 잡으니까요.

# 4) 자주 헷갈리는 포인트 & 엣지 케이스
- **모두 음수일 때**: 정답은 가장 덜 음수(가장 큰) 하나.  
  → 구현에서 `cur_sum = max_sum = nums[0]`로 시작해야 하는 이유. (0으로 시작하면 오답)
- **빈 부분배열 허용 버전**: 합이 음수면 0을 택하도록 하면 정답이 0이 될 수 있음(문제 정의가 그런 경우).  
  → 이땐 초기값을 0으로 두고, 음수면 리셋.
- **인덱스까지 추적하고 싶을 때**:  
  `cur_sum`이 `nums[i]`로 갈아타는 순간 임시 시작점 `temp_start = i`로 바꾸고,  
  `cur_sum > max_sum`가 될 때 전역 `[best_l, best_r] = [temp_start, i]`로 갱신.
- **정확히 왜 “음수면 리셋”인가?**  
  `best_end[i-1] < 0`이면 `best_end[i-1] + nums[i] < nums[i]`.  
  이어붙이면 손해이므로 버리고 새로 시작하는 게 최적.

# 5) 다른 방법들과 비교 (왜 Kadane이 깔끔한가)
- **분할정복**: O(n log n)로 풀 수 있지만 구현이 더 복잡하고 느림.
- **브루트포스/이중 루프**: O(n²) 또는 O(n³) → 실전 불가.
- **프리픽스 최소값 유지법**: 논리는 깔끔하지만, 결국 Kadane과 같은 한 바퀴 O(n), O(1) 메모리.

# 6) 확장 직관
- **2D 최대 부분합**: 행 구간을 고정해 열 합을 압축한 뒤, 매번 Kadane을 돌림(전형적인 O(n³) 알고리즘).
- **제약 있는 변형**(길이 제한, 합 ≥ T 등): 기본 아이디어(끝점 최적해/프리픽스 최소값)를 토대로 조건만 덧붙여 변형 가능.
