### ❓ 질문 (User)
문제
이번 가을학기에 '문제 해결' 강의를 신청한 학생들은 텀 프로젝트를 수행해야 한다. 프로젝트 팀원 수에는 제한이 없다. 심지어 모든 학생들이 동일한 팀의 팀원인 경우와 같이 한 팀만 있을 수도 있다. 프로젝트 팀을 구성하기 위해, 모든 학생들은 프로젝트를 함께하고 싶은 학생을 선택해야 한다. (단, 단 한 명만 선택할 수 있다.) 혼자 하고 싶어하는 학생은 자기 자신을 선택하는 것도 가능하다.

학생들이(s1, s2, ..., sr)이라 할 때, r=1이고 s1이 s1을 선택하는 경우나, s1이 s2를 선택하고, s2가 s3를 선택하고,..., sr-1이 sr을 선택하고, sr이 s1을 선택하는 경우에만 한 팀이 될 수 있다.

예를 들어, 한 반에 7명의 학생이 있다고 하자. 학생들을 1번부터 7번으로 표현할 때, 선택의 결과는 다음과 같다.

1	2	3	4	5	6	7
3	1	3	7	3	4	6
위의 결과를 통해 (3)과 (4, 7, 6)이 팀을 이룰 수 있다. 1, 2, 5는 어느 팀에도 속하지 않는다.

주어진 선택의 결과를 보고 어느 프로젝트 팀에도 속하지 않는 학생들의 수를 계산하는 프로그램을 작성하라.

입력
첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스의 첫 줄에는 학생의 수가 정수 n (2 ≤ n ≤ 100,000)으로 주어진다. 각 테스트 케이스의 둘째 줄에는 선택된 학생들의 번호가 주어진다. (모든 학생들은 1부터 n까지 번호가 부여된다.)

출력
각 테스트 케이스마다 한 줄에 출력하고, 각 줄에는 프로젝트 팀에 속하지 못한 학생들의 수를 나타내면 된다.

예제 입력 1 
2
7
3 1 3 7 3 4 6
8
1 2 3 4 5 6 7 8
예제 출력 1 
3
0

이 문제를 파이썬 코드로 구현할 꺼야. 내가 요청하기 전까지는 코드를 보여주면 안 돼. 
나는 이 문제를 DFS 재귀 순환을 통하여 풀려고 해. 그 이유는 DFS를 활용할 경우, 자기 자신이 되는 경우를 포함한 순환이 이루어질 경우 그 팀이 결성된다는 걸 확인할 수 있기 때문이야. 이러한 특성을 이용해서 문제를 해결하려고 해.

### 💡 답변 (Assistant)
DFS 재귀를 사용해서 사이클(팀)을 찾으려면 아래와 같은 접근법을 고려해 보세요:

1. **그래프 구성 이해**  
   - 각 학생은 딱 한 명을 선택하므로, 학생들을 노드로 하고 선택한 학생으로 향하는 단방향 간선이 있는 그래프로 볼 수 있어요.  
   - 이 그래프는 각 노드에서 한 개의 간선만 나오기 때문에, 결국 각 노드는 자기 자신 또는 다른 노드와 연결되어 “사이클(팀)”을 이루게 됩니다.

2. **방문 관리 배열 두 개 사용하기**  
   - **visited 배열:** DFS 도중 해당 노드를 방문했음을 기록합니다.  
   - **finished 배열:** DFS 재귀의 처리가 완전히 끝났음을 표시합니다.  
   - DFS 도중, 만약 방문한 노드 중에서 아직 finished되지 않은 노드를 다시 만난다면, 이는 현재 재귀 경로 내에 사이클이 존재함을 의미합니다.

3. **DFS 재귀 호출 시 현재 경로 기록하기**  
   - DFS 호출 시, 현재 경로에 있는 노드들을 기록하거나, 각 노드가 경로 내에서 몇 번째 방문되었는지 인덱스를 저장해보세요.  
   - 사이클이 발견되면, 해당 노드가 경로에서 처음 등장한 위치부터 현재까지의 노드들이 사이클(팀)에 속하게 됩니다.

4. **사이클 발견 처리**  
   - DFS 중에, 만약 다음에 방문할 노드가 이미 visited 되어있고, finished되지 않았다면(즉, 현재 DFS 경로에 있다면),  
     - 그 노드가 처음 나타난 위치부터 현재까지의 모든 노드들이 사이클(팀)을 이루게 됩니다.  
     - 이때, 사이클에 포함된 노드 수를 기록하거나 전역 변수에 누적해 두세요.

5. **DFS 종료 시 finished 처리**  
   - DFS의 끝부분(재귀에서 돌아올 때)에서 해당 노드를 finished 처리해 주세요.  
   - 이렇게 하면 나중에 다른 DFS 호출에서 이미 처리된 노드를 다시 처리하지 않아도 됩니다.

6. **최종 결과 계산**  
   - 전체 학생 수에서 사이클(팀)에 속한 학생 수를 빼면, 어떤 팀에도 속하지 못한 학생들의 수를 얻을 수 있습니다.

### 💡 답변 (Assistant)
아래는 DFS 재귀를 사용해서 문제를 해결하는 파이썬 코드 예시입니다. 이 코드는 각 노드(학생)를 방문하며, DFS 재귀 호출 도중 “사이클(팀)”에 속하는 노드를 찾아서 그 개수를 센 후, 전체 학생 수에서 빼는 방식으로 팀에 속하지 않는 학생들의 수를 구합니다.

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

def dfs(v):
    global cycle_count
    visited[v] = True
    next_v = selections[v]
    # 아직 방문하지 않은 학생이면 DFS 재귀 호출
    if not visited[next_v]:
        dfs(next_v)
    # 이미 방문한 학생인데, 아직 DFS 처리가 끝나지 않았다면 사이클(팀)을 발견한 것임
    elif not finished[next_v]:
        temp = next_v
        # 사이클에 포함되는 학생들을 센다.
        while temp != v:
            cycle_count += 1
            temp = selections[temp]
        cycle_count += 1  # 현재 v도 사이클에 포함
    finished[v] = True  # DFS 처리를 완료

T = int(input())
for _ in range(T):
    n = int(input())
    # 학생 번호를 1부터 n까지 사용하므로 인덱스 맞추기 위해 앞에 더미 값을 추가
    selections = [0] + list(map(int, input().split()))
    visited = [False] * (n + 1)
    finished = [False] * (n + 1)
    cycle_count = 0

    for i in range(1, n + 1):
        if not visited[i]:
            dfs(i)

    # 팀에 속한 학생 수는 cycle_count, 나머지가 팀에 속하지 않는 학생들
    print(n - cycle_count)
```

### 코드 설명
1. **입력 처리 및 재귀 한계 증가**  
   - `sys.setrecursionlimit(10**6)`을 사용해 재귀 호출 한계를 늘려줍니다.
   - 입력은 `sys.stdin.readline`으로 받습니다.

2. **DFS 함수 (`dfs`)**  
   - `visited` 배열로 해당 학생을 방문했음을 기록합니다.
   - `finished` 배열은 DFS 호출이 완료된(재귀에서 빠져나온) 학생들을 표시합니다.
   - 만약 다음 학생(`next_v`)이 이미 방문되었으나 아직 DFS 처리가 끝나지 않았다면(즉, 현재 경로 내에 있다면) 사이클을 발견한 것이므로, while문을 통해 사이클에 속하는 노드들을 셉니다.

3. **메인 루프**  
   - 각 테스트 케이스마다 모든 학생에 대해 DFS를 호출하여 사이클(팀)에 포함된 학생 수를 구합니다.
   - 마지막에 전체 학생 수 `n`에서 사이클(팀)에 속한 학생 수를 빼면 팀에 속하지 않는 학생들의 수가 됩니다.

### 💡 답변 (Assistant)
아래는 재귀 대신 스택을 활용하여 DFS 방식으로 사이클(팀)을 찾는 파이썬 코드 예시입니다.

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n = int(input())
    # 학생 번호를 1부터 사용하므로, 인덱스 맞추기 위해 앞에 0을 추가
    selections = [0] + list(map(int, input().split()))
    
    visited = [False] * (n + 1)
    finished = [False] * (n + 1)
    cycle_count = 0

    for i in range(1, n + 1):
        if visited[i]:
            continue
        # 각 DFS마다 현재 경로(스택)를 기록
        stack = []
        cur = i
        while True:
            visited[cur] = True
            stack.append(cur)
            nxt = selections[cur]
            # 아직 방문하지 않았다면 계속 진행
            if not visited[nxt]:
                cur = nxt
                continue
            # 방문한 적은 있지만, DFS 처리가 끝나지 않은 경우 => 현재 경로에 있으므로 사이클 발견
            if not finished[nxt]:
                # 스택에서 nxt가 처음 등장한 인덱스를 찾고, 그 이후의 노드들이 사이클에 속함
                idx = stack.index(nxt)
                cycle_count += len(stack) - idx
            # 더 이상 진행할 수 없으므로 탈출
            break
        # 현재 DFS 경로에 있는 모든 노드에 대해 finished 처리
        for node in stack:
            finished[node] = True

    # 전체 학생 수에서 사이클에 속한 학생 수를 빼면 팀에 속하지 않는 학생 수가 됨
    print(n - cycle_count)
```

### 코드 설명
1. **입력 처리 및 준비**  
   - 각 테스트 케이스마다 학생의 수 `n`과 선택 결과를 입력받습니다.  
   - 학생 번호를 1부터 사용하므로, 인덱스 맞춤을 위해 selections 리스트의 0번 인덱스는 더미 값입니다.

2. **방문 관리**  
   - `visited`: DFS 도중 해당 학생을 방문했음을 기록합니다.  
   - `finished`: DFS의 처리가 완전히 끝난(해당 경로에서 더 이상 사용되지 않는) 학생들을 표시합니다.

3. **반복문과 스택을 활용한 DFS**  
   - 아직 방문하지 않은 각 학생 `i`에 대해 DFS를 시작합니다.  
   - `stack`에는 현재 DFS 경로의 노드들을 저장합니다.  
   - 현재 노드 `cur`에서 selections[cur]로 이동하면서, 방문하지 않은 경우 계속 진행합니다.
   - 만약 이미 방문한 노드지만 `finished`되지 않은 노드를 만난다면, 이는 현재 경로에 포함된 노드이므로 사이클이 형성된 것입니다.
   - 스택 내에서 해당 노드(`nxt`)가 처음 나타난 인덱스를 찾아, 그 인덱스 이후의 노드들이 사이클에 속하는 것으로 계산합니다.

4. **마무리 처리**  
   - DFS 경로에 포함된 모든 노드를 `finished` 처리하여, 이후 중복으로 처리되지 않도록 합니다.
   - 최종적으로 전체 학생 수에서 사이클(팀)에 속한 학생 수를 빼서 팀에 속하지 않는 학생들의 수를 출력합니다.

이와 같이 재귀 대신 스택을 사용하여 DFS를 구현할 수 있습니다.
