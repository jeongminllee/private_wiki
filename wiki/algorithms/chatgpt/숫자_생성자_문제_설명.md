### ❓ 질문 (User)
문제
현재 칠판에 합이 총 N인 숫자들이 적혀 있다. 종영이는 칠판에 적힌 모든 숫자의 합을 적으라고 선생님께 명령받았다. 하지만, 당당하게 N을 쓴 종영이는, N을 씀으로써 숫자들의 합이 늘어나서 혼이 나고 말았다. 결국 종영이는 어이가 없어 때려치고 이 일을 당신에게 부탁하기로 했다. 종영이를 대신하여 이 문제를 해결하자.

즉 N에 대해서 N+(X의 각 자리 숫자의 합) = X를 만족하는 X 중 가장 작은 X를 구하면 된다. 한번은 너무 쉬우니까 T번 해결하여 선생님의 공격에 미리 대비하도록 하자.

입력
첫 줄에 T가 주어진다. (1 ≤ T ≤ 106)

T개의 줄에 걸쳐 각 문제의 N이 주어진다. (1 ≤ N ≤ 109)

출력
공백으로 구분해, 순서대로 문제의 답을 출력한다. 만족하는 답이 없으면 -1을 출력한다.

예제 입력 1 
3
9
10
99
예제 출력 1 
10 -1 100

### 💡 답변 (Assistant)
이 문제는 **숫자 생성자 문제**의 변형으로, 각 숫자와 그 숫자의 각 자리 숫자의 합을 사용하여 새로운 숫자를 생성하는 문제입니다. 목표는 주어진 \( N \)에 대해 다음 식을 만족하는 가장 작은 \( X \)를 찾는 것입니다.

\[
N + (\text{X의 각 자리 숫자의 합}) = X
\]

이를 다시 정리하면,
\[
N = X - (\text{X의 각 자리 숫자의 합})
\]
즉, \( X \)에서 \( X \)의 각 자리 숫자의 합을 뺀 값이 \( N \)이 되어야 합니다.

---

### **문제의 해결 과정**
#### 1. \( N \)의 값이 주어진다.
- \( N = 9, 10, 99 \) 등의 값이 주어진다고 가정합니다.

#### 2. \( X \)를 찾아야 한다.
- \( X \)는 \( N + 1 \) 이상의 값이 될 수 있습니다. 왜냐하면:
  - \( X = N + \) (\( X \)의 각 자리 숫자의 합)이므로, \( X \)의 최소값은 \( N+1 \) 이상입니다.

#### 3. 탐색 범위
- \( X \)를 찾을 때, 가능한 탐색 범위를 설정해야 합니다.
  - 최소 \( X \): \( N + 1 \) 이상.
  - 최대 \( X \): \( N + 100 \) 정도로 제한할 수 있습니다. \( X \)의 각 자리 숫자의 합은 최대 \( \text{X의 자릿수} \times 9 \)이기 때문에, \( N + 100 \) 이상으로는 확장되지 않습니다.

#### 4. 계산 과정
- \( X \)의 각 자리 숫자의 합을 계산하고, 조건을 만족하는지 확인합니다.
  - 조건: \( N + (\text{X의 각 자리 숫자의 합}) = X \)
  - 이를 만족하면, \( X \)가 답이 됩니다.

#### 5. 답이 없는 경우
- \( X \)를 찾을 수 없으면, -1을 출력합니다.

---

### **예제 설명**

#### 예제 입력:
\[
T = 3, \quad N = \{9, 10, 99\}
\]

1. \( N = 9 \):
   - \( X = 10 \)일 때, \( 9 + (\text{10의 각 자리 숫자의 합: 1}) = 10 \)이므로 답은 \( 10 \).

2. \( N = 10 \):
   - \( X \)를 찾아보면, \( 10 + (\text{X의 각 자리 숫자의 합}) \neq X \)가 성립하여 어떤 \( X \)도 만족하지 않음. 따라서 답은 \( -1 \).

3. \( N = 99 \):
   - \( X = 100 \)일 때, \( 99 + (\text{100의 각 자리 숫자의 합: 1}) = 100 \)이므로 답은 \( 100 \).

#### 예제 출력:
\[
10 \, -1 \, 100
\]

---

### **문제를 이해하는 핵심 포인트**
- \( X \)는 \( N \)보다 큰 숫자여야 하며, \( N + (\text{X의 각 자리 숫자의 합}) = X \)를 만족해야 합니다.
- 각 자리 숫자의 합을 계산하여 \( X \)와 비교하는 작업을 여러 번 반복합니다.
- \( T \)가 매우 크기 때문에, 효율적인 계산 방법이 필요합니다.

#include <iostream>
using namespace std;

int mod(int n) {
    int r = 999999999;
    int x = 0;
    while (r) {
        if (9<(n/r))
            return -1;
        x = (x+n/r)*10;
        n %= r;
        r /= 10;
    }
    return x;
}

int test() {
    int n;
    scanf("%d",&n);
    if (n%9) return -1;
    return mod(n);
}

int main() {
    int t;
    cin >> t;
    while(t--)
        printf("%d ",test());
}

### 💡 답변 (Assistant)
C++ 코드를 파이썬으로 변환하였습니다. 아래는 변환된 코드입니다:

```python
def mod(n):
    r = 999999999
    x = 0
    while r:
        if 9 < (n // r):
            return -1
        x = (x + n // r) * 10
        n %= r
        r //= 10
    return x

def test():
    n = int(input())
    if n % 9 != 0:
        return -1
    return mod(n)

def main():
    t = int(input())
    results = []
    for _ in range(t):
        results.append(test())
    print(" ".join(map(str, results)))

if __name__ == "__main__":
    main()
```

### 주요 변환 사항
1. **`cin`과 `scanf`** → **`input`**:
   - C++에서 입력을 받는 부분을 파이썬의 `input` 함수로 대체했습니다.

2. **`printf`** → **`print`**:
   - C++의 출력 방식을 파이썬의 문자열 포맷 및 출력 방식으로 변경했습니다.

3. **반복 구조**:
   - `while(t--)` 같은 반복문을 명시적인 `for` 반복문으로 대체했습니다.

4. **`mod` 함수**:
   - 그대로 동작하도록 변환하였습니다.

위 코드를 실행하면 C++ 코드와 동일한 로직으로 결과를 얻을 수 있습니다.

### **코드 구조**
1. **`mod` 함수**  
   이 함수는 입력된 숫자 \( n \)을 사용하여 특정 조건에 따라 값을 계산합니다.
   - **입력**: 정수 \( n \)
   - **동작**:
     - \( r \)은 999,999,999로 초기화됩니다.
     - \( n \)을 \( r \)로 나누어 몫과 나머지를 계산하며 반복적으로 갱신합니다.
     - 각 자리의 값이 9를 초과하는 경우 함수는 `-1`을 반환합니다.
   - **반환값**: 계산된 \( x \) 또는 조건 불만족 시 `-1`.

   #### 주요 로직:
   ```python
   while r:
       if 9 < (n // r):
           return -1
       x = (x + n // r) * 10
       n %= r
       r //= 10
   return x
   ```
   - \( r \)이 10씩 감소하면서 \( n \)의 자리 값을 처리합니다.
   - 자리값의 합이 9를 초과하면 `-1`을 반환합니다.

2. **`test` 함수**  
   특정 입력 \( n \)에 대해 검사를 수행하며, 조건에 따라 `mod` 함수를 호출합니다.
   - **입력**: 사용자로부터 입력받은 정수 \( n \)
   - **동작**:
     - \( n \)이 9의 배수가 아니면 `-1`을 반환합니다.
     - \( n \)이 9의 배수라면 `mod(n)`의 결과를 반환합니다.
   - **반환값**: `-1` 또는 `mod`의 결과.

3. **`main` 함수**  
   여러 테스트 케이스에 대해 결과를 처리하는 메인 루프입니다.
   - **입력**: \( t \)개의 테스트 케이스.
   - **동작**:
     - 사용자로부터 테스트 케이스의 개수와 각 \( n \) 값을 입력받습니다.
     - 각 \( n \) 값에 대해 `test`를 호출하여 결과를 계산하고 저장합니다.
   - **출력**: 결과를 공백으로 구분하여 출력합니다.

---

### **동작 과정**
1. 사용자로부터 테스트 케이스 개수 (\( t \))와 \( t \)개의 \( n \) 값을 입력받습니다.
2. 각 \( n \)에 대해:
   - 9의 배수인지 확인합니다. 아니라면 바로 `-1` 반환.
   - 9의 배수라면 `mod`를 통해 결과를 계산.
3. 모든 결과를 출력합니다.

### **장점**
1. **효율적인 입력/출력 처리**:

2. **조건 분기 최소화**:
