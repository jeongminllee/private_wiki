문제
군인인 성현이는 전역 후에 새 집으로 이사를 갔다. 주변 이웃과 친하게 지내고 싶은 마음에 이웃집에 떡을 돌리기로 했다. 떡은 한번에 하나씩만 들고 갈 수 있다. 집들 사이에는 총 M개의 양방향 도로가 있다. 귀찮은 성현이는 하루에 X보다 먼 거리를 걷지 않고 거리가 가까운 집부터 방문한다. 또 잠은 꼭 본인 집에서 자야 하므로 왕복할 수 없는 거리는 다음날 가기로 다짐한다. N-1개의 이웃집 모두에게 떡을 돌리기 위해서는 최소 며칠이 소요될 것인가.

집의 번호는 0번부터 N-1번까지 차례대로 붙어있다.

입력
첫째줄에 N, M, X, Y가 공백으로 구분되어 입력된다. (2 ≤ N ≤ 1,000, 1 ≤ M ≤ 100,000, 1 ≤ X ≤ 10,000,000, 0 ≤ Y < N)

단, A집과 B집을 연결하는 도로는 유일하다.

### 💡 답변 (Assistant)
힌트:  
1. **왕복 거리 계산:**  
   - 다익스트라로 구한 각 집까지의 거리는 **편도** 거리입니다.  
   - 문제에서는 떡을 배달할 때 **집에서 출발해 해당 집에 도착한 후 반드시 집으로 돌아와야** 하므로, 한 집에 대한 실제 이동 거리는 `2 * (편도 거리)`가 됩니다.

2. **그리디하게 배달 계획 세우기:**  
   - “거리가 가까운 집부터 방문”한다는 조건에 따라, 모든 이웃집(본인 집 제외)의 편도 거리를 오름차순으로 정렬하세요.
   - 각 집의 왕복 거리를 순서대로 확인하면서, **하루에 걷는 누적 이동 거리**가 **X**를 초과하지 않도록 합니다.
   - 즉, 현재 날의 누적 이동 거리에 다음 집의 왕복 거리를 더했을 때 **X 이하라면 같은 날에 배달**할 수 있고, 만약 초과한다면 **새로운 날을 시작**해야 합니다.

3. **불가능한 경우 체크:**  
   - 만약 어떤 집의 왕복 거리가 **단독으로** 하루의 한도 X보다 크다면, 그 집은 어떤 날에도 방문할 수 없으므로 **-1**을 출력해야 합니다.

이러한 접근법으로, “집에 갔다가 그 자리에서 다시 나가는” 조건(즉, 매 배달마다 항상 집에서 출발하는)을 자연스럽게 처리할 수 있습니다.

아래는 힌트를 반영하여 완성한 파이썬 코드 예시입니다.  
이 코드는 먼저 다익스트라 알고리즘을 통해 Y번 집(내 집)에서 다른 모든 집까지의 최단 거리를 구한 뒤, 각 집에 대해 **왕복 거리(2×편도 거리)** 를 계산하여 오름차순으로 정렬합니다.  
그 후 하루에 걷는 누적 거리가 X를 넘지 않도록 그리디하게 배달 일정을 세웁니다. 만약 어떤 집의 왕복 거리가 하루 한도 X보다 크거나, 도달 불가능한 집이 있다면 -1을 출력합니다.

```python
import heapq
import sys
input = sys.stdin.readline
INF = float('inf')

def dijkstra(start, edges, N):
    # distances[node]: start에서 node까지의 최단 거리
    distances = [INF] * N
    distances[start] = 0
    # 우선순위 큐에는 (현재까지의 거리, 노드) 튜플을 넣는다.
    q = [(0, start)]
    
    while q:
        dist, node = heapq.heappop(q)
        # 이미 더 짧은 경로가 존재한다면 무시
        if distances[node] < dist:
            continue
        
        for nxt_node, nxt_dist in edges[node]:
            new_dist = dist + nxt_dist
            if new_dist < distances[nxt_node]:
                distances[nxt_node] = new_dist
                heapq.heappush(q, (new_dist, nxt_node))
    return distances

def main():
    # 입력: N: 집의 개수, M: 도로 개수, X: 하루 이동 한도, Y: 내 집 번호
    N, M, X, Y = map(int, input().split())
    edges = [[] for _ in range(N)]
    for _ in range(M):
        A, B, C = map(int, input().split())
        edges[A].append((B, C))
        edges[B].append((A, C))
    
    # Y번 집에서 각 집까지 최단 거리 계산
    distances = dijkstra(Y, edges, N)
    
    trips = []
    for i in range(N):
        if i == Y:
            continue  # 내 집은 제외
        if distances[i] == INF:
            print(-1)
            return
        trips.append(2 * distances[i])  # 왕복 거리
    
    trips.sort()  # 가까운 집부터 처리
    
    days = 0
    daily_sum = 0
    for trip in trips:
        # 하루 이동 한도보다 혼자 왕복 거리가 더 크다면 배달 불가능
        if trip > X:
            print(-1)
            return
        # 현재 날짜에 더 가도 한도를 넘지 않으면 같은 날 배달
        if daily_sum + trip <= X:
            daily_sum += trip
        else:
            # 한도를 넘는다면 하루를 마치고 다음 날 시작
            days += 1
            daily_sum = trip
    
    # 남은 누적 이동 거리가 있다면 마지막 날 추가
    if daily_sum > 0:
        days += 1
    
    print(days)

if __name__ == '__main__':
    main()
```

### 코드 설명

1. **다익스트라 함수 `dijkstra`:**  
   - 시작점 `start`에서 모든 노드까지의 최단 거리를 계산합니다.
   - 우선순위 큐에는 `(현재까지의 거리, 노드)` 순으로 저장하여 거리가 짧은 노드부터 처리합니다.

2. **메인 로직:**
   - 입력을 받아 양방향 도로 정보를 `edges`에 저장합니다.
   - Y번 집에서 각 집까지의 최단 거리를 구한 후, 내 집을 제외한 모든 집의 왕복 거리(2×편도 거리)를 계산합니다.
   - 만약 도달 불가능한 집이 있으면 -1을 출력합니다.
   - 왕복 거리를 오름차순으로 정렬한 후, 하루 이동 한도 X 내에서 가능한 만큼 배달하고, 한도를 넘으면 다음 날로 넘어갑니다.
   - 각 배달마다 집에서 출발해 배달 후 집으로 돌아오는 것을 고려하므로 매번 누적 거리 계산에 왕복 거리를 더해줍니다.

### 1. 다익스트라 알고리즘의 우선순위 큐 튜플 순서 오류

- **문제점:**  
  다익스트라 알고리즘에서 우선순위 큐(heapq)를 사용할 때, 튜플의 첫 번째 요소가 비교 기준이 됩니다.  
  작성하신 코드에서는  
  ```python
  heapq.heappush(q, (start, 0))
  ```
  와 같이 `(노드, 거리)` 순서로 튜플을 넣고,  
  ```python
  node, distance = heapq.heappop(q)
  ```
  로 꺼내고 있습니다.  
  이 경우, 우선순위 큐는 **노드 번호**를 기준으로 정렬하므로, 거리가 짧은 순서로 탐색되지 않습니다.

- **개선 방법:**  
  튜플의 순서를 `(거리, 노드)`로 바꿔야 합니다. 예를 들어,
  ```python
  heapq.heappush(q, (0, start))
  ```
  로 시작하고,  
  ```python
  distance, node = heapq.heappop(q)
  ```
  와 같이 꺼내도록 수정합니다.

### 2. 자기 집(Y번 집)을 배달 대상에 포함한 문제

- **문제점:**  
  문제에서는 **내 집(Y번 집)은 배달 대상이 아니다**.  
  다익스트라 알고리즘 결과에는 내 집의 거리가 0으로 포함되는데, 이를 그대로 정렬 및 계산하면 내 집도 배달 대상에 포함되어 잘못된 결과가 나옵니다.

- **개선 방법:**  
  다익스트라 결과에서 Y번 집(거리가 0인 항목)을 제거한 후, 나머지 집들에 대해 왕복 거리를 계산해야 합니다.

### 3. 왕복 거리 및 하루 배달 스케줄 계산 로직의 조건 오류

- **문제점 1 – 왕복 거리 계산:**  
  각 집까지의 편도 거리를 구한 후, 배달은 **집에서 출발해 해당 집에 도착한 후 다시 집으로 돌아와야** 하므로 실제 이동 거리는 `2 * (편도 거리)`입니다.  
  코드에서는 이 부분은 고려하셨지만, 앞서 언급한 자기 집 제외 문제와 결합하면 혼란이 생깁니다.

- **문제점 2 – 배달 스케줄 로직:**  
  코드에서는 다음과 같이 진행하고 있습니다.
  ```python
  for i in range(len(distances)):
      if distances[i] * 2 > X:
          day = -1
          break

      cost += distances[i] * 2
      if i <= len(distances)-2 and X > cost + distances[i+1] * 2:
          continue
      else:
          day += 1
          cost = 0
  ```
  이 로직에서:
  - **조건 비교 오류:**  
    `"X > cost + distances[i+1] * 2"` 조건에서, 만약 **누적 거리 + 다음 집의 왕복 거리가 정확히 X와 같은 경우**에도 같은 날 배달이 가능한데, 조건에 `>` (보다 큰 경우)만 체크하고 있어 잘못 처리될 수 있습니다.
  - **로직 복잡성:**  
    매 반복마다 다음 집을 미리 확인하는 방식은 코드 가독성을 떨어뜨리며, 경계 조건(마지막 집 처리 등)에서 실수가 발생할 가능성이 높습니다.

- **개선 방법:**  
  보다 단순한 그리디 방식으로 작성하는 것이 좋습니다. 예를 들어,
  - `cost` 변수에 현재 날에 걸어간 누적 거리를 저장하고,
  - 각 집의 왕복 거리(`trip`)를 순서대로 더해가면서, 만약 `cost + trip`이 하루 한도 `X`를 초과하면, **하루를 종료하고** 새로운 날을 시작하도록 합니다.
  
  즉, 로직은 다음과 같이 구성할 수 있습니다.
  ```python
  for trip in trips:  # trips는 내 집을 제외한 각 집의 왕복 거리(오름차순 정렬)
      if trip > X:  # 한 집의 왕복 거리가 하루 한도를 넘으면 배달 불가능
          day = -1
          break
      if cost + trip > X:
          day += 1
          cost = trip
      else:
          cost += trip
  if cost > 0:
      day += 1
  ```
  이 방식은 각 날에 가능한 한 많은 집에 배달하면서, 하루 한도를 넘지 않는 가장 간단한 방법입니다.

### 종합 정리

1. **우선순위 큐에 넣는 튜플 순서를 `(0, start)`로 수정하고, pop 시에도 `(distance, node)`로 받아야 합니다.**
2. **다익스트라 결과에서 내 집(Y번 집, 거리 0)은 배달 대상에서 제외해야 합니다.**
3. **각 집에 대해 배달 시 왕복 거리는 `2 * (편도 거리)`임을 고려하고, 하루 한도 `X` 내에서 누적 거리를 더해가며, 초과하는 경우 새로운 날로 넘기는 단순 그리디 로직을 사용합니다.**
4. **조건 비교 시 `>=` 조건 등을 주의하여 경계값 처리를 올바르게 해야 합니다.**

이러한 점들을 보완하여 코드를 수정하면 문제의 의도에 맞는 올바른 해법을 구현할 수 있습니다.

```python
import heapq
import sys
input = sys.stdin.readline
INF = float('inf')

def dijkstra(start, edges, N):
    # distances[node]: start에서 node까지의 최단 거리
    distances = [INF] * N
    distances[start] = 0
    # 우선순위 큐에는 (현재까지의 거리, 노드) 튜플을 넣는다.
    q = [(0, start)]
    
    while q:
        dist, node = heapq.heappop(q)
        # 이미 더 짧은 경로가 존재한다면 무시
        if distances[node] < dist:
            continue
        
        for nxt_node, nxt_dist in edges[node]:
            new_dist = dist + nxt_dist
            if new_dist < distances[nxt_node]:
                distances[nxt_node] = new_dist
                heapq.heappush(q, (new_dist, nxt_node))
    return distances

def main():
    # 입력: N: 집의 개수, M: 도로 개수, X: 하루 이동 한도, Y: 내 집 번호
    N, M, X, Y = map(int, input().split())
    edges = [[] for _ in range(N)]
    for _ in range(M):
        A, B, C = map(int, input().split())
        edges[A].append((B, C))
        edges[B].append((A, C))
    
    # Y번 집에서 각 집까지 최단 거리 계산
    distances = dijkstra(Y, edges, N)
    
    trips = []
    for i in range(N):
        if i == Y:
            continue  # 내 집은 제외
        if distances[i] == INF:
            print(-1)
            return
        trips.append(2 * distances[i])  # 왕복 거리
    
    trips.sort()  # 가까운 집부터 처리
    
    days = 0
    daily_sum = 0
    for trip in trips:
        # 하루 이동 한도보다 혼자 왕복 거리가 더 크다면 배달 불가능
        if trip > X:
            print(-1)
            return
        # 현재 날짜에 더 가도 한도를 넘지 않으면 같은 날 배달
        if daily_sum + trip <= X:
            daily_sum += trip
        else:
            # 한도를 넘는다면 하루를 마치고 다음 날 시작
            days += 1
            daily_sum = trip
    
    # 남은 누적 이동 거리가 있다면 마지막 날 추가
    if daily_sum > 0:
        days += 1
    
    print(days)

if __name__ == '__main__':
    main()
```

## 2. 다익스트라 알고리즘 구현

```python
def dijkstra(start, edges, N):
    # distances[node]: start에서 node까지의 최단 거리
    distances = [INF] * N
    distances[start] = 0
    # 우선순위 큐에는 (현재까지의 거리, 노드) 튜플을 넣는다.
    q = [(0, start)]
    
    while q:
        dist, node = heapq.heappop(q)
        # 이미 더 짧은 경로가 존재한다면 무시
        if distances[node] < dist:
            continue
        
        for nxt_node, nxt_dist in edges[node]:
            new_dist = dist + nxt_dist
            if new_dist < distances[nxt_node]:
                distances[nxt_node] = new_dist
                heapq.heappush(q, (new_dist, nxt_node))
    return distances
```

### 주요 포인트

- **초기화:**
  - `distances` 리스트는 시작 노드(`start`)로부터 각 노드까지의 최단 거리를 저장합니다.
  - 모든 노드는 초기값을 무한대(`INF`)로 설정한 후, 시작 노드의 거리는 `0`으로 설정합니다.
  
- **우선순위 큐 초기화:**
  - `q = [(0, start)]`  
    - `(현재까지의 거리, 노드)` 형태의 튜플을 사용합니다.
    - 시작 노드부터 탐색하기 위해 `(0, start)`를 큐에 넣습니다.

- **메인 루프 (`while q:`):**
  - **`heapq.heappop(q)`**로 가장 짧은 거리의 노드를 꺼냅니다.
  - **이미 처리된 경로 확인:**  
    - `if distances[node] < dist:` 조건을 사용하여, 현재 꺼낸 경로보다 이미 더 짧은 경로가 기록되어 있다면 해당 경로는 무시합니다.
  
- **인접 노드 탐색:**
  - 현재 노드의 모든 인접 노드에 대해,  
    - `new_dist = dist + nxt_dist`를 계산합니다.
    - 만약 `new_dist`가 현재 저장된 `distances[nxt_node]`보다 작다면,  
      - `distances[nxt_node]`를 업데이트하고,
      - 새로운 경로 정보를 `(new_dist, nxt_node)` 형태로 우선순위 큐에 추가합니다.

- **리턴 값:**
  - `distances` 리스트를 반환하여, 시작 노드에서 각 노드까지의 최단 거리를 제공합니다.

## 3. 메인 함수 및 문제 해결 로직

```python
def main():
    # 입력: N: 집의 개수, M: 도로 개수, X: 하루 이동 한도, Y: 내 집 번호
    N, M, X, Y = map(int, input().split())
    edges = [[] for _ in range(N)]
    for _ in range(M):
        A, B, C = map(int, input().split())
        edges[A].append((B, C))
        edges[B].append((A, C))
```

### 입력 처리 및 그래프 구성

- **입력:**  
  - `N`: 전체 집의 개수  
  - `M`: 양방향 도로의 개수  
  - `X`: 하루에 걸을 수 있는 최대 이동 거리 (피로도 제한)  
  - `Y`: 내 집의 번호

- **그래프 구성 (`edges` 리스트):**
  - 각 인덱스 `i`는 집 `i`를 의미하며, 해당 집에서 갈 수 있는 인접 집과 그 사이의 거리 정보를 튜플 형태로 저장합니다.
  - 양방향이므로 입력된 도로 `(A, B, C)`에 대해, `edges[A]`와 `edges[B]` 모두에 정보를 추가합니다.

### 다익스트라 호출 및 배달 대상 집 선정

```python
    # Y번 집에서 각 집까지 최단 거리 계산
    distances = dijkstra(Y, edges, N)
    
    trips = []
    for i in range(N):

            return
        trips.append(2 * distances[i])  # 왕복 거리
    
    trips.sort()  # 가까운 집부터 처리
```

- **최단 거리 계산:**
  - `dijkstra(Y, edges, N)`를 호출하여, 내 집(Y번 집)에서 다른 모든 집까지의 최단 거리를 구합니다.

- **배달 대상 선정:**
  - 내 집(`i == Y`)은 배달 대상에서 제외합니다.
  - 만약 어떤 집에 도달할 수 없다면(`distances[i] == INF`), 문제의 조건에 따라 `-1`을 출력하고 종료합니다.
  - **왕복 거리 계산:**  
    - 각 집에 대해, 편도 거리 `distances[i]`에 2를 곱하여 왕복 거리를 계산한 후 `trips` 리스트에 추가합니다.
    - **예:** 집까지 5의 거리가 있다면 왕복은 10이 됩니다.

- **정렬:**
  - `trips.sort()`를 호출하여, 가까운 집부터 (즉, 왕복 거리가 작은 순서대로) 배달 계획을 세울 수 있도록 정렬합니다.

### 하루 배달 스케줄 계산

```python
    days = 0
    daily_sum = 0
    for trip in trips:
        # 하루 이동 한도보다 혼자 왕복 거리가 더 크다면 배달 불가능
        if trip > X:
            print(-1)
            return
        # 현재 날짜에 더 가도 한도를 넘지 않으면 같은 날 배달

        else:

```

- **변수 설명:**
  - `days`: 배달에 필요한 총 일수를 저장하는 변수입니다.
  - `daily_sum`: 현재 날에 누적해서 걸은 왕복 거리를 저장합니다.

- **루프를 통한 배달 스케줄 계산:**
  - 각 배달 대상 집의 왕복 거리 `trip`에 대해 순회합니다.
  - **단일 배달 불가능 조건:**  
    - 만약 한 집의 왕복 거리가 하루 이동 한도 `X`보다 크다면, 해당 집은 어떤 날에도 배달이 불가능하므로 `-1`을 출력하고 종료합니다.
  
  - **하루 내 배달 가능 여부 체크:**
    - `if daily_sum + trip <= X:`  
      - 현재까지 걸은 거리(`daily_sum`)에 다음 집의 왕복 거리를 더했을 때 하루 한도 `X` 이하이면, 같은 날 배달이 가능합니다.  
      - 이 경우 `daily_sum`에 해당 `trip`을 추가합니다.
  
    - **새로운 날 시작:**  
      - 그렇지 않다면 (즉, `daily_sum + trip > X`인 경우),  
        - 현재 날은 더 이상 배달할 수 없으므로, `days`를 1 증가시켜 하루를 마감합니다.
        - 그리고 `daily_sum`을 현재 `trip` 값으로 초기화하여 새로운 날의 첫 배달로 설정합니다.
  
- **최종 처리:**
  - 루프가 끝난 후, `daily_sum`이 0보다 크다는 것은 마지막 날에 배달한 집이 있다는 의미이므로, 마지막 날을 추가합니다.
  - 최종적으로 `days`에 필요한 총 배달 일수를 출력합니다.
