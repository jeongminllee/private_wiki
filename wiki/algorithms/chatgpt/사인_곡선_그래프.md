### 💡 답변 (Assistant)
좋습니다! 요청하신 그래프는 **제품별(냉장고, 무선청소기)**로 **PC와 모바일 접속 비율**을 보여주는 **파이그래프**입니다.  
우선, 아래 예시는 다음과 같은 데이터 구조를 가정합니다:

### 🔢 가정한 데이터 예시

| 제품       | PC   | 모바일 |
|------------|------|--------|
| 냉장고     | 1200 | 1800   |
| 무선청소기 | 800  | 2200   |

이 데이터를 기준으로 파이그래프 두 개를 나란히 출력해 보겠습니다.

---

### ✅ 전체 코드

```python
# Install and import necessary libraries
!pip install /mnt/data/koreanize_matplotlib-0.1.1-py3-none-any.whl
import matplotlib.pyplot as plt
import koreanize_matplotlib  # For Korean character support

# 데이터 정의
labels = ['PC', '모바일']
refrigerator = [1200, 1800]
vacuum = [800, 2200]

# 파이 차트 설정
fig, axs = plt.subplots(1, 2, figsize=(12, 6))

# 냉장고 파이 차트
axs[0].pie(refrigerator, labels=labels, autopct='%1.1f%%', startangle=90, colors=['skyblue', 'lightcoral'])
axs[0].set_title('냉장고 - PC/모바일 비율')

# 무선청소기 파이 차트
axs[1].pie(vacuum, labels=labels, autopct='%1.1f%%', startangle=90, colors=['skyblue', 'lightcoral'])
axs[1].set_title('무선청소기 - PC/모바일 비율')

plt.tight_layout()
plt.show()
```

---

### 📌 설명
- `autopct='%1.1f%%'`는 퍼센트를 소수점 1자리로 표시합니다.
- `colors=['skyblue', 'lightcoral']`은 PC는 파랑, 모바일은 붉은색 계열로 구분합니다.
- `figsize=(12, 6)`은 가로로 나란히 두 개의 파이차트를 배치하는 설정입니다.
