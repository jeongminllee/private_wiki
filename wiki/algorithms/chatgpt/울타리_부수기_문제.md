문제
준규는 화원을 운영중이다. 준규는 엄청난 가치를 지닌 대마꽃를 M개의 행과 N개의 열을 가진 토지에 경작하는데 진욱이가 자꾸 훔쳐가서 고민에 빠졌다. 준규는 진욱이가 훔쳐가지 못하게 꽃 주변을 울타리로 둘러쌓다. 하지만 시간이 지나면서 울타리 몇개가 부서졌다. 진욱이는 이때를 틈타 다시 꽃을 훔지려고 한다.

아래 보이는 그림은 11행 12열의 화원을 나타낸다. 0은 울타리가 없거나 꽃이 심어져 있는 부분을 나타내고 1은 울타리가 있는 곳을 나타낸다. 화원에 들어 오려면 노란색 부분부터 들어와야 한다.



진욱이가 꽃을 훔치러 화원에 들어왔다. 울타리를 요리조리 피해서 들어가는데 이때 상, 하, 좌, 우로 밖에 이동할 수 없다. 진욱이는 파괴적 성향을 지니고 있기 때문에 울타리로 가로막혀 더이상 안으로 접근할 수 없을 때 울타리를 부순다.  진욱이가 되도록 적은 수의 울타리를 부수면서 안으로 들어갈때, 최대한 많이 울타리를 부순 횟수와 , 그때 얻을 수 있는 꽃의 수를 구하여라.

입력
첫째 줄에 테스트 케이스의 수 T (≤ 10) 가 주어진다. 같은 줄에 주어지는 여러개의 정수는 공백으로 구분된다.

각각의 테스트 케이스의 첫째 줄에는 두개의 정수 R, C가 주어진다 (5 ≤ R, C ≤ 1 000)

R은 화원의 행을 나타내고 C는 열의 수를 나타낸다.

두 번째 줄부터 R+1번째 줄까지 화원의 정보가 주어진다. 화원은 꽃이 심어질 수 있는 부분인 0 과 울타리가 설치된 1로 이루어져 있다.

화원에는 적어도 하나 이상의 꽃이 심어지는 부분이 있다고 가정한다.

힌트
진욱이는 되도록이면 울타리를 부수지 않고 안으로 들어간다.울타리를 부수지 않고 절대로 안으로 들어 갈 수 없을때만 울타리를 부순다.

```
from collections import deque
import heapq

INF = 1<<32

di = [-1, 1, 0, 0]
dj = [0, 0, -1, 1]

def bfs(si, sj, arr) :
    R, C = len(arr), len(arr[0])
    q = []
    q.append((0, si, sj))   # broken_cnt, si, sj
    v = [[INF for _ in range(C)] for _ in range(R)]
    v[si][sj] = 0
    flowers = 0
    res = INF
    while q :
        cnt, ci, cj = heapq.heappop(q)



        for d in range(4) :
            ni, nj = ci + di[d], cj + dj[d]
            if 0<=ni<R and 0<=nj<C :
                if v[ni][nj] > v[ci][cj] + 1 :
                    if arr[ni][nj] == 0:
                        v[ni][nj] = v[ci][cj] + 1
                        flowers = v[ni][nj]
                        heapq.heappush(q, (cnt, ni, nj))

                    else :
                        v[ni][nj] = 0
                        flowers = v[ni][nj]
                        heapq.heappush(q, (cnt+1, ni, nj))
    return res, flowers

# 현재 내가 고려 안한것 : 우선순위를 고려안함
# 우선순위 : 가장 적게 부수면서, 가장 많이 부쉈을 때 채취한 꽃의 개수
# 가장 적게 부숨, 가장 많이 부쉈을 때의 채취한 꽃의 개수

def main() :
    R, C = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(R)]

    start = []
    for i in range(R) :
        for j in range(C) :
            if (i == 0 or j == 0) and arr[i][j] == 0 :
                start.append((i, j))

    for si, sj in start :
        cnt, flowers = bfs(si, sj, arr)

    print(cnt, flowers)
if __name__ == "__main__" :
    T = int(input())
    for _ in range(T) :
        main()
```

## 1. 문제 자체를 어떻게 모델링할지

핵심은 이렇게 볼 수 있어:

- 바깥(“노란색 부분”)에서 시작해서,
- 어떤 꽃(0 칸)에 도착할 때까지
  - **최소 몇 개의 울타리(1)를 부숴야 하는지**를 계산할 수 있다.
- 각 꽃마다 "그 꽃까지 가기 위해 깨야 하는 울타리의 최소 개수"가 생김.
- 그 값들 중에서
  1. **가장 많이 부숴야 하는 울타리 수(= 최댓값)**를 찾고,
  2. 그만큼이나 울타리를 부숴야 도달할 수 있는 꽃의 개수(= 그 최댓값을 가지는 꽃의 개수)를 세면 됨.

즉, 각 0칸에 대해  
> “바깥에서 이 칸까지 올 때 부숴야 하는 **1의 최소 개수**”  

를 구하는 문제 → **0-1 BFS / 다익스트라 한 번**으로 끝나는 유형이야.

문제 설명의  
> “되도록이면 울타리를 부수지 않고 … 절대로 안으로 들어갈 수 없을 때만 울타리를 부순다”  

는 사실상 “**경로 상에서 부숴야 하는 울타리 개수를 최소화한다**”라는 말이야.  
우리는 그 “최소 개수”를 각 칸마다 구한 다음, 그 값 중에서 최대를 보는 것.

## 2. 지금 코드에서 잘 잡은 부분 / 부족한 부분

### 👍 잘 잡은 부분

1. **(i, j) 인접 4방향 이동**  
   `di`, `dj`로 상하좌우 보는 구조는 그대로 쓰면 돼.

2. **우선순위 큐를 쓰려는 시도**  
   `(부순 울타리 개수, 위치)`를 기준으로 우선순위 탐색을 하고 싶었던 것 같고, 이 자체는 올바른 방향(다익스트라/0-1 BFS 아이디어) 이야.

3. **바깥에서 시작하는 아이디어를 떠올림**  
   시작점을 가장자리에서 잡으려 한 것 역시 방향은 맞아.

## 3. 지금 코드에서 잘못되었거나 부족한 점

### (1) “거리/상태” 정의가 잘못 잡혀 있음

```python
v = [[INF for _ in range(C)] for _ in range(R)]
v[si][sj] = 0
...
if v[ni][nj] > v[ci][cj] + 1:
    if arr[ni][nj] == 0:
        v[ni][nj] = v[ci][cj] + 1
        flowers = v[ni][nj]
        heapq.heappush(q, (cnt, ni, nj))
    else:
        v[ni][nj] = 0
        flowers = v[ni][nj]
        heapq.heappush(q, (cnt+1, ni, nj))
```

- `v`가 지금 “뭘 저장하는지”가 애매함.  
  - 걸음 수?  
  - 부순 울타리 수?  
  - 둘 다 아닌 애매한 값이 됨.
- 문제에서 **우리가 최소화해야 할 값은 “부순 울타리 개수”**야.
  - 즉, `v[i][j]`는 **(i, j)에 도달할 때 부순 울타리 최소 개수**가 되어야 함.
- 현재 코드에서는
  - 0으로 가는 경우 `v[ni][nj] = v[ci][cj] + 1`
  - 1로 가는 경우 `v[ni][nj] = 0`
  로 되어 있어서 완전히 반대로 돼 있고, 의미도 맞지 않아.

👉 수정 방향  
- 상태는 간단히:
  ```python
  dist[i][j] = 이 칸에 도달하기 위해 부순 울타리 최소 개수
  ```
- 우선순위 큐에 넣는 값도:
  ```python
  (현재까지 부순 울타리 수, i, j)
  ```

---

### (2) “꽃의 개수(flowers)”를 BFS 안에서 세는 구조

```python
flowers = v[ni][nj]
...
return res, flowers
```

- 꽃 개수는 **경로 하나를 탐색하면서 누적해서 세는 개념이 아님**.
- 해야 할 일은:
  1. 전체 격자에 대해 `dist`를 한 번 다 구해놓고,
  2. 그 중에서  
     - `max_break = max(dist[i][j])` (단, arr[i][j] == 0 인 칸만)
     - `count = max_break를 가진 꽃(0 칸)의 개수`
- 지금처럼 BFS 돌면서 `flowers` 변수를 계속 덮어쓰는 방식으로는 절대 제대로 된 값을 얻을 수 없음.

👉 수정 방향  
- BFS / 0-1 BFS는 **“각 칸의 최소 울타리 파괴 수”**만 계산.
- 꽃 개수 세기와 "최대값 찾기"는 **BFS가 다 끝난 뒤에 한 번에**.

---

### (3) 시작점 / 바깥 처리 방식

```python
for i in range(R) :
    for j in range(C) :
        if (i == 0 or j == 0) and arr[i][j] == 0 :
            start.append((i, j))
```

문제점:

1. **아래·오른쪽 경계는 안 보고 있음**  
   - 지금은 `i == 0 or j == 0`이라서 **위쪽 행 + 왼쪽 열만** 시작점으로 삼음.
   - 하지만 바깥에서 들어올 수 있는 경계는  
     `i == 0 or i == R-1 or j == 0 or j == C-1`  
     모두 고려해야 해.

2. **경계가 전부 1인 경우를 처리 못함**
   - 실제로는 **경계가 다 1이어도**, 진욱이는 첫 칸에서 울타리를 깨고 들어갈 수 있음.
   - 지금 구조는 “경계에 0이 없는 경우”엔 `start`가 비어서 BFS 자체를 못 돔.

👉 전형적인 해결 패턴  
- 격자 바깥을 하나의 큰 영역이라고 보고,  
  **바깥을 0으로 채운 테두리 한 겹을 둘러주는 방식 (padding)** 으로 많이 처리해.
  - 예: (R+2) x (C+2) 크기의 배열을 만들고,
  - 바깥 테두리(0번째, R+1번째 행/열)를 전부 0으로 두고,
  - 그 안에 원래 배열을 1~R, 1~C에 복사.
- 그러면
  - “바깥에서 아무 곳이나 들어간다” = padding 한 격자의 (0, 0) 쪽 0들에서 시작.
  - 바깥에서 경계 1을 깨고 들어가는 것도 자연스럽게 **0 → 1로 이동(비용 1)** 로 모델링됨.

---

### (4) BFS를 여러 번 도는 구조

```python
for si, sj in start :
    cnt, flowers = bfs(si, sj, arr)
```

- 이건 “각 시작점에서 별도의 BFS/Dijkstra를 돌리겠다”는 구조인데,
  - 이 문제는 **“바깥 전체”를 하나의 시작점(또는 다중 시작점)** 으로 보고
  - **한 번만** 최단거리(최소 울타리 파괴 수)를 구하면 됨.
- 아무리 많은 경계 0이 있어도,
  - `dist` 배열의 초기값을 그 모든 시작점에 `0`으로 두고
  - **0-1 BFS / Dijkstra를 딱 한 번** 돌리는 게 정석.

👉 수정 방향  
- `bfs()` 함수는 "시작점 여러 개"를 한 번에 받거나,
- 아예 padding + `(0,0)` 같은 바깥 노드에서 시작하는 형태로 바꾸기.

---

### (5) 우선순위(“가장 적게 부수면서”)를 코드에 어떻게 반영할지

너가 주석에 적은 것처럼:

```python
# 현재 내가 고려 안한것 : 우선순위를 고려안함
# 우선순위 : 가장 적게 부수면서, 가장 많이 부쉈을 때 채취한 꽃의 개수
```

여기서 약간 헷갈린 것 같은데,

- **경로를 고를 때의 우선순위는 단 하나**야:  
  > "부순 울타리 개수가 최소인 경로"
- "꽃을 많이 채취"는 **경로 레벨에서의 우선순위가 아니라**,  
  **모든 칸에 대한 `최소 울타리 파괴 수`를 다 구해놓고 난 뒤**  
  그 중에서 최대값을 가지는 칸의 개수를 세는 문제야.

즉,

1. 탐색(0-1 BFS/다익스트라)에서는  
   👉 **“부순 1의 개수”만을 비용으로** 잡고 최소화.
2. 탐색이 끝난 후  
   👉 `max_break = max(dist[i][j])` (0 칸들만 대상)  
   👉 `answer_cnt = dist[i][j] == max_break 인 0 칸 개수`  

이 두 단계를 명확하게 분리하는 게 포인트.

## 4. 구현 힌트 (간략 버전)

정답 코드는 나중에 원할 때 달라고 했으니까, 지금은 **구조 힌트만** 적을게.

1. **격자 패딩**  
   - (R+2) x (C+2) 배열 만들고,
   - 바깥을 전부 0, 안쪽에 입력 배열 0/1 복사.

2. **0-1 BFS / 다익스트라**  
   - `dist`를 INF로 채움.
   - 시작점은 바깥(예: (0,0) 혹은 전체 바깥 0 영역)에서 `dist = 0`.
   - 큐에 `(0, si, sj)` 넣고 시작.
   - 4방향으로 이동:
     - 다음 칸이 0이면 `cost = 0`
     - 다음 칸이 1이면 `cost = 1`
   - `new_cost = cur_cost + cost` 가 `dist[ni][nj]` 보다 작으면 갱신하고 큐에 넣기.
     - cost가 0이면 deque의 왼쪽에, 1이면 오른쪽에 넣는 **0-1 BFS** 쓰면 더 빠름.
     - 아니면 그냥 우선순위 큐 다익스트라.

3. **정답 계산**  
   - 다시 원래 R x C 구간만 돌아 보면서
     - `arr[i][j] == 0`인 칸에 대해
       - `max_break = max(max_break, dist[i+1][j+1])`
   - 한 번 더 돌면서
       - `dist[i+1][j+1] == max_break`인 0 칸을 세기.

## 5. 요약하면, 네 코드 기준으로 고쳐야 할 핵심들

- `v`는 “이 칸까지 올 때 부순 울타리 최소 개수”로 정의해야 함.
- 0칸/1칸 이동 시 업데이트 로직을 그 정의에 맞게 바꿔야 함.
- BFS 안에서 꽃 개수를 직접 세지 말고, 탐색 끝난 뒤 `dist`를 기반으로 계산.
- 시작점은 위/왼쪽만이 아니라 전체 바깥(혹은 패딩한 바깥 0들)이어야 함.
- 여러 번 BFS를 돌 필요 없이, **한 번의 0-1 BFS / 다익스트라**로 전체 dist를 구하면 됨.

원하면 다음 단계에서:

- 패딩 없이 구현하는 버전,
- 패딩 사용하는 버전,
- 0-1 BFS vs `heapq` 다익스트라 두 가지 스타일 중 하나를 골라서

실제 AC 코드까지 같이 만들어 줄게.

---

### ❓ 질문 (User)
AC 코드 구현해줘.

### 💡 답변 (Assistant)
바로 AC 나는 파이썬 코드로 줄게. (0-1 BFS + 패딩 방식)

아이디어 한 줄 정리만 먼저 말하면:

> 바깥을 0으로 패딩한 뒤, 바깥 (0,0)에서 시작해서  
> 0으로 갈 때 비용 0, 1(울타리)로 갈 때 비용 1인 **0-1 BFS**로  
> 각 칸까지 “부순 울타리 최소 개수”를 구하고,  
> 원래 격자의 0 칸들 중 그 값의 최댓값과 그 개수를 출력.

---

## 코드

```python
import sys
from collections import deque

input = sys.stdin.readline
INF = 10 ** 9

# 상, 하, 좌, 우
di = (-1, 1, 0, 0)
dj = (0, 0, -1, 1)

def solve():
    T = int(input())
    out_lines = []

    for _ in range(T):
        R, C = map(int, input().split())

        # 패딩된 격자: (R+2) x (C+2)
        # 바깥은 모두 0으로 두고, 안쪽에 입력 복사
        PR, PC = R + 2, C + 2
        garden = [[0] * PC for _ in range(PR)]
        for i in range(1, R + 1):
            row = list(map(int, input().split()))
            garden[i][1:C + 1] = row

        # dist[i][j] = (i, j)에 도달하기 위해 부순 울타리(1)의 최소 개수
        dist = [[INF] * PC for _ in range(PR)]
        dq = deque()
        dist[0][0] = 0
        dq.append((0, 0))

        # 0-1 BFS
        while dq:
            i, j = dq.popleft()
            cur = dist[i][j]

            for k in range(4):
                ni = i + di[k]
                nj = j + dj[k]
                if 0 <= ni < PR and 0 <= nj < PC:
                    # 0으로 이동: 비용 0, 1으로 이동: 비용 1 (울타리 하나 부숨)
                    cost = 1 if garden[ni][nj] == 1 else 0
                    nd = cur + cost
                    if nd < dist[ni][nj]:
                        dist[ni][nj] = nd
                        if cost == 0:
                            dq.appendleft((ni, nj))
                        else:
                            dq.append((ni, nj))

        # 원래 격자의 0(꽃) 칸들에 대해
        # dist의 최댓값과 그 개수를 구한다.
        max_break = -1
        cnt = 0
        for i in range(1, R + 1):
            g_row = garden[i]
            d_row = dist[i]
            for j in range(1, C + 1):
                if g_row[j] == 0:  # 꽃(0) 칸
                    d = d_row[j]
                    if d > max_break:
                        max_break = d
                        cnt = 1
                    elif d == max_break:
                        cnt += 1

        out_lines.append(f"{max_break} {cnt}")

    print("\n".join(out_lines))


if __name__ == "__main__":
    solve()
```

### 짧게 다시 정리

- 격자 바깥을 한 겹 0으로 둘러싸서, **“바깥 전체”를 하나의 연결 영역**으로 만든다.
- 바깥 (0,0)에서 시작해서
  - 0으로 가면 비용 0
  - 1(울타리)로 가면 비용 1
  로 0-1 BFS.
- 이렇게 얻은 `dist[i][j]`는 “그 칸까지 가기 위해 부순 울타리의 최소 개수”.
- 원래 R×C 영역 안에서 0인 칸들만 골라
  - 그 중 `dist`의 최대값 = 답 1
  - 그 최대값을 갖는 꽃 칸 개수 = 답 2

이 코드 그대로 제출하면 될 거야. 필요하면 내가 주석 더 빡세게 달아준 버전도 만들어 줄게.

## 2. 코드에서 짚어볼 / 개선하면 좋은 부분들

### (1) `distances[0][0] = 0` 위치

```python
def bfs(si, sj, arr) :
    ...
    distances[0][0] = 0
```

- 인자로 `si, sj`를 받는데, 실제로는 항상 `(0, 0)`에서만 시작하고 있어.
- **선택지**
  1. 아예 인자를 없애고 `bfs(arr)`로 고정
  2. 혹은 `distances[si][sj] = 0`으로 써서 진짜 시작점 인자를 활용

지금도 문제는 없지만, “겉보기와 실제 동작이 다름”이라 나중에 헷갈릴 수 있음.

---

### (2) `global distances` 사용

```python
def main() :
    global distances
    ...
    distances = [[INF for _ in range(C+2)] for _ in range(R+2)]

```

- `bfs()` 안에서 `distances`를 **재할당**하지 않고,  
  `distances[ni][nj] = nd` 처럼 **원소만 수정**하니까 `global` 선언 없이도 동작은 해.
- 그래도 전역 변수 의존은 디버깅/재활용에 조금 불리해.


지금처럼 써도 AC는 되지만, 구조적으로는 위 방식이 더 깔끔.

### (3) `INF` 값

```python
INF = 1<<32
```

- 최대로 부술 수 있는 울타리 수는  
  최악의 경우 격자 전체가 1이라도 `R*C ≤ 10^6`.
- `1<<32`(약 4.29e9)는 훨씬 더 크니까 문제는 전혀 없음.
- 그냥 보통은 `INF = 10**9` 같은 값 많이 씀. 완전 취향 차이.

---

### (4) 입력 처리 & 패딩

```python
arr = [[0 for _ in range(C+2)] for _ in range(R+2)]

for i in range(1, R+1) :
    arr[i] = [0] + list(map(int, input().split())) + [0]
```

- `arr[0]`와 `arr[R+1]`는 전부 0인 상태 유지 → **윗줄, 아랫줄 바깥** 패딩.
- `arr[i][0]`와 `arr[i][C+1]`도 0으로 세팅 → **왼쪽, 오른쪽 바깥** 패딩.
- 그 결과:
  - 전체 (R+2)x(C+2) 격자의 테두리는 모두 0
  - 원래 입력은 (1..R, 1..C)에만 들어 있음
- 이 구조 덕분에 `(0,0)`에서 시작해서 **바깥 영역 전체**를  
  비용 0으로 자유롭게 돌아다닐 수 있게 됨. 완전 의도대로 잘 구현됨.

### (5) 시간 복잡도

- 상태 수: (R+2) * (C+2) ≤ 1,002 * 1,002 ≈ 1e6
- 각 상태에서 최대 4방향 → 약 4e6 간선
- 0-1 BFS는 O(정점 + 간선) → 대략 5e6 단위 → 파이썬으로도 충분히 가능

테스트 케이스 T ≤ 10 → 최악에도 충분히 통과 가능한 수준.

## 3. 코드 상세 해설

이제 네가 짠 코드 그대로, 흐름 따라가면서 설명해볼게.

### 전역/상수 정의

```python
from collections import deque

INF = 1<<32

di = [-1, 1, 0, 0]
dj = [0, 0, -1, 1]
```

- `deque` : 0-1 BFS에서 cost=0인 이동을 `appendleft`, cost=1인 이동을 `append` 하기 위해 사용.
- `INF` : 아직 방문하지 않은 칸의 초기값으로 사용.
- `di`, `dj` : 상하좌우 이동을 위한 델타 배열.

---

### bfs 함수: 0-1 BFS 핵심

```python
def bfs(si, sj, arr) :
    R, C = len(arr), len(arr[0])
    q = deque()
    q.append((si, sj))

    distances[0][0] = 0
```

- `R, C` : 패딩된 격자의 크기 (R+2, C+2)
- 큐 시작점은 `(si, sj)`인데, 실제로는 `(0, 0)`을 넘겨줌.
- `distances[0][0] = 0` : 바깥 한 점의 비용을 0으로 초기화.

```python
    while q :
        ci, cj = q.popleft()
        curr = distances[ci][cj]
```

- 큐에서 현재 위치 `(ci, cj)`를 꺼내고,
- 그 칸까지의 최소 울타리 파괴 수를 `curr`에 저장.

```python
        for d in range(4) :
            ni, nj = ci + di[d], cj + dj[d]
            if 0<=ni<R and 0<=nj<C :
                cost = 1 if arr[ni][nj] == 1 else 0
                nd = curr + cost
                if distances[ni][nj] > nd :
                    distances[ni][nj] = nd
                    if cost == 0 :
                        q.appendleft((ni, nj))
                    else :
                        q.append((ni, nj))
```

- 네 방향으로 인접 칸 `(ni, nj)`을 확인.
- 격자 범위 안이면:
  - 그 칸이 울타리(1)이면 → `cost = 1` (울타리 하나 부숨)
  - 꽃/빈칸(0)이면 → `cost = 0` (울타리 추가 파괴 없음)
- `nd = curr + cost` : 현재까지 부순 울타리 수 + 이번에 더 부순 수
- `distances[ni][nj] > nd` 이면:
  - 더 적게 부수고 도달하는 경로를 찾은 것이므로 갱신
  - 비용 0 이동은 `appendleft` → 같은 레벨에서 우선 탐색
  - 비용 1 이동은 `append` → 나중에 탐색

이게 바로 **0-1 BFS 정석 패턴**이야.

---

### main 함수: 입력 + 패딩 + 결과 계산

```python
def main() :
    global distances
    R, C = map(int, input().split())
    arr = [[0 for _ in range(C+2)] for _ in range(R+2)]

    for i in range(1, R+1) :
        arr[i] = [0] + list(map(int, input().split())) + [0]

    distances = [[INF for _ in range(C+2)] for _ in range(R+2)]

    bfs(0, 0, arr)
```

1. `R, C` 입력.
2. `arr`를 `(R+2) x (C+2)` 크기로 만들고, 전부 0으로 초기화.
3. `1..R` 행에 대해
   - 양 끝에 0을 붙여서 `[0] + 입력 + [0]` 형태로 넣음.
   - 이로써 좌우 테두리가 0으로 패딩.
4. `distances`를 동일 크기 `(R+2) x (C+2)`로 만들고, 전부 `INF`로 채움.
5. `bfs(0, 0, arr)` : 바깥의 한 점 (0,0)에서 시작해서 전체 0-1 BFS 수행.

---

### 정답 계산 파트

```python
    broken = -1
    cnt = 0
    for i in range(1, R+1) :
        for j in range(1, C+1) :
            if arr[i][j] == 0 :
                if distances[i][j] > broken :
                    broken = distances[i][j]

```

- 이제는 원래 격자 (1..R, 1..C)만 확인.
- 그 중에서:
  - 꽃/빈칸(0)인 칸만 대상으로 삼음.
  - `distances[i][j]`는 해당 칸까지 오기 위해 부순 울타리 최소 개수.
- `broken` = 지금까지 본 꽃 칸 중 **최대** 울타리 파괴 수.
- `cnt` = 그 `broken` 값을 가진 꽃 칸의 개수.

즉,  
> “꼭 그렇게까지 해서 들어가는 가장 안쪽 꽃들은 울타리를 몇 개나 부수고 들어가야 하고, 그런 꽃이 몇 송이나 되냐?”  
를 정확히 계산하는 부분.

- 큰 틀: **0-1 BFS + 패딩**으로 “각 꽃까지의 최소 울타리 파괴 횟수”를 구하고,
- 그 중 최댓값과 그 최댓값을 갖는 꽃의 개수를 세는 구조 → **정답 로직 OK**.

원하면 이걸 기준으로
- global 없이 함수형으로 리팩터링한 버전,
- 주석 빡세게 단 “에디토리얼용 코드” 버전

### ❓ 질문 (User)

### 💡 답변 (Assistant)
아래는 **global 없이 함수형으로 리팩토링**한 버전이고,  
각 단계마다 **왜 이렇게 했는지까지** 보이도록 주석을 꽤 빡세게 달아놨어.

```python
import sys
from collections import deque

input = sys.stdin.readline

# 충분히 큰 값으로 "아직 도달하지 못함"을 표현
# 실제로 부술 수 있는 울타리 수의 최댓값은 R*C(<= 10^6) 정도이므로 10^9면 넉넉하다.
INF = 10 ** 9

# 상, 하, 좌, 우 방향 벡터
di = [-1, 1, 0, 0]
dj = [0, 0, -1, 1]


def bfs_01(arr, dist, si, sj):
    """
    0-1 BFS 를 이용하여,
    패딩된 격자 arr 상에서 (si, sj)에서 시작했을 때

    dist[i][j] = (si, sj)에서 (i, j)에 도달하기 위해
                 최소로 부숴야 하는 울타리(1)의 개수

    를 모두 구해주는 함수.

    - arr : 패딩된 격자 (0/1 값이 들어 있음)
    - dist: 같은 크기의 2차원 배열, 초기에는 전부 INF로 채워져 있어야 함
    - (si, sj): 시작 좌표 (우리는 바깥의 (0, 0)에서 시작)
    """

    R = len(arr)      # 패딩까지 포함된 행 수 (원래 R + 2)
    C = len(arr[0])   # 패딩까지 포함된 열 수 (원래 C + 2)

    dq = deque()

    # 시작점의 비용(부순 울타리 수)은 0
    dist[si][sj] = 0
    dq.append((si, sj))

    # 0-1 BFS 시작
    while dq:
        ci, cj = dq.popleft()
        curr_cost = dist[ci][cj]

        # 네 방향으로 인접한 칸을 확인
        for k in range(4):
            ni = ci + di[k]
            nj = cj + dj[k]

            # 격자 범위를 벗어나면 제외
            if not (0 <= ni < R and 0 <= nj < C):
                continue

            # 다음 칸이 울타리(1)이면, 그 칸으로 갈 때 울타리 하나를 부숴야 하므로 cost = 1
            # 다음 칸이 꽃/빈칸(0)이면, 울타리 추가 파괴 없이 cost = 0
            if arr[ni][nj] == 1:
                move_cost = 1
            else:
                move_cost = 0

            next_cost = curr_cost + move_cost

            # 더 적은 비용(더 적게 울타리를 부수고)으로 (ni, nj)에 도달할 수 있다면 갱신
            if next_cost < dist[ni][nj]:
                dist[ni][nj] = next_cost

                # 0-1 BFS 핵심:
                #   - 간선 가중치가 0이면 덱의 왼쪽에 넣어서 "우선 탐색"
                #   - 간선 가중치가 1이면 덱의 오른쪽에 넣어서 "나중 탐색"
                if move_cost == 0:
                    dq.appendleft((ni, nj))
                else:
                    dq.append((ni, nj))


def solve_one_case(R, C, raw_grid):
    """
    단일 테스트 케이스를 처리하는 함수.

    R, C : 원래 격자의 행, 열 크기
    raw_grid : R x C 크기의 2차원 리스트 (0: 꽃/빈칸, 1: 울타리)

    반환값:
      (max_break, count)
      - max_break : 어떤 꽃 칸에 도달하기 위해
                    최소로 부숴야 하는 울타리 수의 최댓값
      - count     : 그 최댓값 max_break를 가지는 꽃 칸의 개수
    """

    # 1. 격자 패딩
    #    바깥을 0으로 둘러싸서, "밖에서 들어오는 것"을 자연스럽게 모델링한다.
    #
    #    패딩 후 크기: (R + 2) x (C + 2)
    #    - arr[0][*]    : 전부 0 (위 바깥)
    #    - arr[R+1][*]  : 전부 0 (아래 바깥)
    #    - arr[*][0]    : 전부 0 (왼쪽 바깥)
    #    - arr[*][C+1]  : 전부 0 (오른쪽 바깥)
    #
    #    실제 입력으로 받은 원래 격자는 arr[1..R][1..C] 에 들어간다.
    arr = [[0] * (C + 2) for _ in range(R + 2)]

    for i in range(1, R + 1):
        # raw_grid는 0 ~ R-1 인덱스이므로 i-1 행을 가져와서
        # 양 옆에 0을 붙여 패딩한다.
        arr[i][1:C + 1] = raw_grid[i - 1]

    # 2. dist 배열 준비
    #    dist[i][j] = arr 상에서 (0, 0) 에서 (i, j)로 올 때
    #                 최소로 부숴야 하는 울타리(1)의 개수
    dist = [[INF] * (C + 2) for _ in range(R + 2)]

    # 3. 0-1 BFS 실행 (시작점은 바깥의 (0, 0))
    bfs_01(arr, dist, 0, 0)

    # 4. 원래 격자(1..R, 1..C) 안에서 꽃(0) 칸만 보면서
    #    dist 값을 확인해 최댓값과 그 개수를 구한다.
    max_break = -1
    count = 0

    for i in range(1, R + 1):
        for j in range(1, C + 1):
            # 꽃이 심어질 수 있는 칸(0)인 경우만 고려
            if arr[i][j] == 0:
                d = dist[i][j]
                # 아직 도달 못하는 칸이라면 d == INF 일 수 있음
                # 문제 조건상 "적어도 하나 이상의 꽃" + 바깥과의 연결을 고려하면
                # 보통 INF는 등장하지 않아야 하지만,
                # 안전하게 사용하려면 필요시 추가 체크도 가능하다.
                if d > max_break:
                    max_break = d
                    count = 1
                elif d == max_break:
                    count += 1

    return max_break, count


def main():
    T = int(input().strip())
    answers = []

    for _ in range(T):
        # 각 테스트 케이스마다 R, C 입력
        R, C = map(int, input().split())

        # R줄에 걸쳐 격자 정보 입력 (0 또는 1)
        raw_grid = [list(map(int, input().split())) for _ in range(R)]

        max_break, count = solve_one_case(R, C, raw_grid)
        answers.append(f"{max_break} {count}")

    # 모든 테스트 케이스 결과 출력
    print("\n".join(answers))


if __name__ == "__main__":
    main()
```

### 정리해 보면

- `bfs_01` : **0-1 BFS 전용 함수**  
  → `arr`와 `dist`를 인자로 받아, 출발점에서의 최소 울타리 파괴 수를 전부 채움.
- `solve_one_case` : **단일 테스트 케이스 처리**  
  - 패딩된 격자 구성  
  - `dist` 초기화  
  - 0-1 BFS 호출  
  - 원래 격자 부분만 돌면서 `max_break`, `count` 계산
- `main` : 테스트 케이스 수 T만큼 `solve_one_case` 호출해서 답을 모아서 출력.

이제 완전히 함수형 구조라 `global`에 의존하지 않고,  
각 함수 역할도 잘 나뉘어 있어서 나중에 다른 문제 풀 때 0-1 BFS 템플릿으로도 재활용하기 좋을 거야.
