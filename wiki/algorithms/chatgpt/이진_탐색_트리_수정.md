### ❓ 질문 (User)
문제
이진 탐색 트리는 모든 노드가 많아야 2개의 자식 노드를 가지고 있는 트리이고, 각 노드에는 수가 하나씩 쓰여있다. 만약 어떤 노드에 쓰여 있는 수가 X라면, 그 노드의 왼쪽 서브트리에는 X보다 작은 수, 오른쪽 서브트리에는 X보다 큰 수만 저장되어 있어야 한다.

1보다 크거나 같고, N보다 작거나 같은 수 N개가 한 번씩 등장하는 수열이 입력으로 주어진다. 이 수열을 이용해서 이진 탐색 트리를 만들려고 한다. 이제 배열의 첫 번째 수를 루트 노드로 놓고, 다른 나머지 수들을 순서대로 삽입하면서 이진 탐색 트리를 만들려고 한다. 즉, 첫 번째 수를 제외한 모든 수에 대해서 insert(X,root)를 실행하는 것과 같다. 그 함수는 다음과 같다. 

이진 탐색 트리에 삽입하는 함수는 다음과 같다.

insert(number X, node N)
    카운터 C값을 1 증가시킨다
    if X가 노드 N에 있는 수보다 작다면
        if N의 왼쪽 자식이 없다면
            X를 포함하는 새 노드를 만든 뒤, N의 왼쪽 자식으로 만든다
        else
            insert(X, N의 왼쪽 자식)
    else (X가 노드 N에 있는 수보다 크다면)
        if N의 오른쪽 자식이 없다면
            X를 포함하는 새 노드를 만든 뒤, N의 오른쪽 자식으로 만들기
        else
            insert(X, N의 오른쪽 자식)
각 수를 삽입한 후에 C의 값을 출력하는 프로그램을 작성하시오. 카운터 C의 값은 0으로 초기화되어 있다.

입력
첫째 줄에 수열의 크기 N이 주어진다. (1 ≤ N ≤ 300,000)

다음 N개의 줄에는 수열의 수가 차례대로 주어진다. 수는 구간 [1, N]에 포함된 정수이고, 중복되지 않는다.

출력
N개의 줄에 각 수가 트리에 삽입된 후에 카운터 C값을 한 줄에 하나씩 출력한다.

```
class Node :
    def __init__(self):
        self.root = 0
        self.left = None
        self.right = None

def insert(number, node, cnt=0) :
    cnt += 1
    if number < node.root :
        if node.left is None :
            node.left = number
        else :
            insert(number, node.left)

    else :
        if node.right is None :
            node.right = number
        else :
            insert(number, node.right)

    return cnt

def main() :
    N = int(input())
    for _ in range(N) :
        X = int(input())
        node = Node()
        cnt = insert(X, node)

    print(cnt)



if __name__ == "__main__" :
    main()
```

## 1. Node 설계/사용이 잘못된 부분

### (1) Node가 값을 안 들고 있음

```python
class Node :
    def __init__(self):
        self.root = 0
        self.left = None
        self.right = None
```

- 각 노드는 “자기 값”을 가져야 하는데, `root`라는 이름으로 **항상 0**으로 초기화되어 있음.
- 보통은 이렇게 설계해야 함:

```python
class Node:
    def __init__(self, val):
        self.val = val        # 이 노드에 저장된 값
        self.left = None
        self.right = None
```

지금 상태로는 모든 노드가 값 0을 가지고 있으니, 비교 로직이 완전히 깨짐.

---

### (2) left/right에 `Node`가 아니라 `int`를 넣고 있음

```python
if number < node.root :
    if node.left is None :
        node.left = number
    else :
        insert(number, node.left)
```

- `node.left`에는 **Node 객체**가 들어가야 하는데, 지금은 그냥 `number`라는 **정수**를 넣고 있음.
- 다음 재귀 호출에서 `insert(number, node.left)`를 하면, 이제 `node`가 숫자라서 `node.root`를 읽는 순간 `AttributeError`가 터짐.

수정 예:

```python
if number < node.val:
    if node.left is None:
        node.left = Node(number)
    else:
        cnt += insert(number, node.left)
```

오른쪽도 동일하게 `Node(number)`를 만들어야 함.

---

### (3) 매 삽입마다 트리를 새로 만들고 있음

```python
def main() :
    N = int(input())
    for _ in range(N) :
        X = int(input())
        node = Node()
        cnt = insert(X, node)
```

- 문제에서는 **하나의 트리**를 만들어서 처음 수는 루트로 놓고, 나머지 수들을 순서대로 넣으라고 되어 있음.
- 그런데 지금은 `for` 루프 안에서 `node = Node()`로 **매번 새로운 트리**를 만듦 → 이전에 삽입한 내용이 완전히 사라짐.

의도대로라면:

```python
def main():
    N = int(input())
    nums = [int(input()) for _ in range(N)]

    root = Node(nums[0])   # 첫 번째 수를 루트로
    C = 0
    print(C)               # 첫 번째 수는 insert를 안 하니까 0

    for x in nums[1:]:
        C += insert(x, root)   # 삽입하면서 방문 노드 수를 더함
        print(C)
```

---

### (4) `cnt`가 “전역 카운터 C”와 의미가 다름

문제의 C는:

> insert 함수가 호출될 때마다, 함수 시작에서 **C를 1 증가**  
> → 전체 삽입 과정에서 몇 번 방문했는지 **누적**하는 전역 카운터

그런데 현재 코드는:

```python
def insert(number, node, cnt=0) :
    cnt += 1
    ...
    return cnt
```

- `cnt`를 매 호출마다 기본값 0으로 시작하고 있음 → 전역 누적이 아니라 “이번 insert에서 몇 번 증가했는가”만 계산.
- 재귀 호출에서도 `cnt` 리턴값을 받지 않고 있어서, 재귀 깊이만큼 카운트도 안 됨:

```python
else :
    insert(number, node.left)  # 반환값을 버리고 있음
```

- 의도대로라면:
  - 방법 1: 진짜 전역 변수 C를 쓰고, insert 안에서 `global C` 하고 `C += 1`.
  - 방법 2: insert가 “이번 삽입에서 방문한 노드 수”를 리턴하고, `C`는 바깥에서 누적.

예시 (방법 2, while로 iterative):

```python
def insert(number, node):
    cnt = 0
    cur = node
    while True:
        cnt += 1  # 이 노드를 한 번 방문
        if number < cur.val:
            if cur.left is None:
                cur.left = Node(number)
                break
            cur = cur.left
        else:
            if cur.right is None:
                cur.right = Node(number)
                break
            cur = cur.right
    return cnt
```

그리고 바깥에서:

```python
C += insert(x, root)
print(C)
```

---

### (5) `print(cnt)` 위치/의미

```python
print(cnt)
```

- `main`의 `for` 루프 밖에서 한 번만 출력하고 있음 → 마지막 삽입의 카운트만 출력.
- 문제는 **각 수를 삽입한 뒤 C의 값을 한 줄에 하나씩** 출력해야 함.
- 구조는:

```python
print(0)           # 첫 번째 숫자 삽입 직후
for 나머지 숫자:
    C += insert(...)
    print(C)
```

처럼 매 삽입 후 바로 출력해야 함.

## 2. 알고리즘/성능 측면에서의 큰 문제

위에 말한 것들은 “코드가 돌아가기 위한” 버그들이고, 그걸 다 고쳐도 **이 방식 자체가 시간 초과/재귀 깊이 문제를 낼 가능성이 매우 큼**.

- N ≤ 300,000
- 입력이 `1, 2, 3, 4, ..., N` 같은 **정렬된 상태**일 때,
  - 일반적인 이진 탐색 트리 삽입은 “한쪽으로만” 자라서 **최악 O(N^2)** 연산이 됨.
  - 방문 노드 수도 합치면 대략 `1 + 2 + ... + N ≈ N²/2` 수준.
- 파이썬에서 재귀로 구현하면 깊이 300,000까지 내려가야 해서 `RecursionError`가 나거나 매우 느려짐.

그래서 BOJ 원문 기준 정답들은 보통:

- 실제 BST를 만들지 않고,
- 값의 범위가 1..N인 걸 이용해서
  - “가장 가까운 작은 값/큰 값의 깊이 + 1”로 현재 노드 깊이를 구한 다음
  - 세그먼트 트리/펜윅트리(Fenwick)로 깊이 정보를 관리하면서  
    **O(N log N)**에 전체 C를 계산하는 방식으로 풀어.

그래도 일단 “네 코드 스타일을 유지하면서 논리적으로 맞는 BST 삽입 코드”를 원한다면, 이런 식이 최소한의 수정 버전이야 (성능은 별도로):

```python
import sys
input = sys.stdin.readline

class Node:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None

def insert(number, root):
    cnt = 0
    cur = root
    while True:
        cnt += 1  # 이 노드 방문
        if number < cur.val:
            if cur.left is None:
                cur.left = Node(number)
                break
            cur = cur.left
        else:  # number > cur.val (문제에서 중복 없음)
            if cur.right is None:
                cur.right = Node(number)
                break
            cur = cur.right
    return cnt

def main():
    N = int(input())
    nums = [int(input()) for _ in range(N)]

    root = Node(nums[0])
    C = 0
    print(C)  # 첫 노드는 insert 안 쓰니까 0

    for x in nums[1:]:
        C += insert(x, root)
        print(C)

if __name__ == "__main__":
    main()
```

이렇게 하면:

- 구조/의미는 문제 요구에 맞게 돌아감.
- 다만, **최악 케이스에서는 시간 초과 가능성이 크다**는 점은 꼭 알고 있어야 해.

## 정리

**수정/개선해야 할 핵심 포인트**

1. `Node`는 값을 인자로 받아서 `self.val`에 저장해야 함 (`root=0` X).
2. `left`/`right`에는 `Node` 객체를 넣어야지 `int`를 넣으면 안 됨.
3. 트리를 매번 새로 만들지 말고, 첫 번째 값으로 루트를 만든 후 계속 재사용해야 함.
4. `cnt`는 “이번 삽입에서 방문한 노드 수”를 리턴하고, 전체 카운터 `C`는 바깥에서 누적해야 함.
5. 매 삽입 후 `C`를 바로바로 출력해야 함 (N줄 출력).
6. (중요) 이 방식은 최악 O(N^2)이라서, 실제 제출용으로는 세그트리/Fenwick 기반 O(N log N) 풀이를 고민해야 함.

원하면, 다음 단계로는 이 문제의 **세그먼트 트리 / Fenwick 트리 기반 정답 코드**도 같이 짜 줄게.

## 1. 핵심 아이디어 정리

값이 1..N인 **서로 다른 수열**이니까, “값” 자체를 인덱스로 쓰는 게 가능해.

### 1) 깊이(Depth)로 생각하기

각 원소 X를 BST에 삽입할 때,

- 그 원소의 **깊이(depth)** = 그 원소를 찾기 위해 방문하는 노드 수와 동일  
  → 그리고 문제의 C는 “각 삽입에서 방문한 노드 수의 누적 합”  
  → 즉,  
  \[
  C_k = \sum_{i=1}^{k} \text{depth}(A_i)
  \]
  이라고 볼 수 있음.

예제 1) 1,2,3,4

- depth(1)=0
- depth(2)=1
- depth(3)=2
- depth(4)=3  
  ⇒ 누적합: 0, 1, 3, 6 (예제 출력 그대로)

### 2) 새로 들어오는 값 X의 깊이는?

이미 어떤 값들이 들어와서 BST가 만들어져 있다고 하자.  
이 상태에서 값 X를 넣으면,

- X보다 작은 값 중 **이미 들어온 애들** 중 하나가 왼쪽 체인에 있을 수 있고,
- X보다 큰 값 중 **이미 들어온 애들** 중 하나가 오른쪽 체인에 있을 수 있음.

중요한 사실 (이 문제의 핵심):

> X의 부모는,  
> 현재까지 삽입된 값들 중  
> “X보다 작은 값들 중 가장 큰 값” 또는  
> “X보다 큰 값들 중 가장 작은 값”  
> 둘 중 **깊이가 더 큰 쪽**이 된다.

그래서

- pred = 현재까지 삽입된 값 중 **X보다 작은 값 중 가장 큰 값**
- succ = 현재까지 삽입된 값 중 **X보다 큰 값 중 가장 작은 값**

이라고 두면,

\[
\text{depth}(X) = \max(\text{depth(pred)}, \ \text{depth(succ)}) + 1
\]

- pred가 없으면 depth(pred) = -1 로 취급
- succ가 없으면 depth(succ) = -1 로 취급  
- 둘 다 없으면 depth(X) = 0 (루트)

이렇게 하면 **루트도 같은 공식으로 처리** 가능.

## 2. 세그먼트 트리로 필요한 연산 구현

우리가 계속 해야 하는 일:

1. 어떤 값 X가 삽입되면, “X가 들어왔다”는 것을 기록.
2. 다음 삽입 때
   - pred = (현재까지 삽입된 값 중) X보다 작은 값 중 가장 큰 값
   - succ = (현재까지 삽입된 값 중) X보다 큰 값 중 가장 작은 값  
   을 찾아야 함.

값의 범위가 [1, N] 이므로, 인덱스 1..N에 대해

- “이 인덱스의 값이 삽입되었는지 여부”를 0/1로 관리할 수 있음.

여기서 세그먼트 트리를 하나 만들어서,  
각 구간에 대해

- 그 구간 안에서 **가장 왼쪽에 있는 삽입된 값의 인덱스 (leftmost)**
- 그 구간 안에서 **가장 오른쪽에 있는 삽입된 값의 인덱스 (rightmost)**

를 저장하면,

- `query(1, X-1)` → 구간 [1, X-1]에서 오른쪽 끝에 있는 삽입된 값 → pred
- `query(X+1, N)` → 구간 [X+1, N]에서 왼쪽 끝에 있는 삽입된 값 → succ

을 O(log N)에 구할 수 있음.

### 세그트리 노드 정보

각 노드에 `(leftmost, rightmost)` 두 값을 저장:

- 아무것도 없는 구간: `leftmost = INF`, `rightmost = 0` 같은 식으로 sentinel 사용

병합(merge) 규칙:

```text
(left1, right1) + (left2, right2) -> (left, right)

left  = left1 != INF ? left1 : left2
right = right2 != 0   ? right2 : right1
```

즉,

- 왼쪽 자식에서 “제일 왼쪽 원소”가 있으면 그걸 쓰고, 없으면 오른쪽 자식의 leftmost
- 오른쪽 자식에서 “제일 오른쪽 원소”가 있으면 그걸 쓰고, 없으면 왼쪽 자식의 rightmost

## 3. 전체 알고리즘

1. 입력 수열 A[1..N]을 그대로 받음.
2. `depth[1..N]` 배열 준비 (각 값의 깊이 저장).
3. 세그트리 초기화: 모두 “비어 있음”.
4. C = 0 (누적 카운터)
5. 각 X에 대해 아래를 반복:

   ```text
   pred = [1, X-1] 구간에서 가장 오른쪽에 있는 삽입된 값 (없으면 0)
   succ = [X+1, N] 구간에서 가장 왼쪽에 있는 삽입된 값 (없으면 INF)

   dpred = pred != 0   ? depth[pred] : -1
   dsucc = succ != INF ? depth[succ] : -1

   depth[X] = max(dpred, dsucc) + 1

   C += depth[X]
   출력(C)

   세그트리에 X 위치를 "삽입됨"으로 업데이트
   ```

- 첫 번째 원소의 경우 pred/ succ 둘 다 없으므로 depth = 0, C = 0 → 예제와 일치.

## 4. 파이썬 코드 (세그트리 풀이)

Python 기준으로 세그트리 + 빠른 입출력까지 포함한 코드야:

```python
import sys
input = sys.stdin.readline

INF = 10**9

def build_seg_tree(n):
    # leftmost[i], rightmost[i] 를 저장하는 세그트리
    size = 4 * n
    leftmost = [INF] * size
    rightmost = [0] * size
    return leftmost, rightmost

def update(node, start, end, idx, leftmost, rightmost):
    # idx 위치가 삽입되었음을 표시 (leaf: left=right=idx)
    if start == end:
        leftmost[node] = idx
        rightmost[node] = idx
        return
    mid = (start + end) // 2
    if idx <= mid:
        update(node * 2, start, mid, idx, leftmost, rightmost)
    else:
        update(node * 2 + 1, mid + 1, end, idx, leftmost, rightmost)

    # 자식 정보 병합
    l1, r1 = leftmost[node * 2],     rightmost[node * 2]
    l2, r2 = leftmost[node * 2 + 1], rightmost[node * 2 + 1]

    leftmost[node]  = l1 if l1 != INF else l2
    rightmost[node] = r2 if r2 != 0   else r1

def query(node, start, end, l, r, leftmost, rightmost):
    # 구간 [l, r] 안의 (leftmost, rightmost) 반환
    if r < start or end < l:
        # 공집합
        return INF, 0
    if l <= start and end <= r:
        return leftmost[node], rightmost[node]

    mid = (start + end) // 2
    l1, r1 = query(node * 2, start, mid, l, r, leftmost, rightmost)
    l2, r2 = query(node * 2 + 1, mid + 1, end, l, r, leftmost, rightmost)

    # 병합
    left  = l1 if l1 != INF else l2
    right = r2 if r2 != 0   else r1
    return left, right

def main():
    N = int(input())
    nums = [int(input()) for _ in range(N)]

    leftmost, rightmost = build_seg_tree(N)
    depth = [0] * (N + 2)  # 값이 1..N이므로 여유 있게

    C = 0
    out_lines = []

    for x in nums:
        # 이전에 삽입된 값들 중, X보다 작은 것들 / 큰 것들 중에서
        # 가장 가까운 값을 세그트리에서 찾는다.

        # 1) predecessor: [1, x-1]에서 가장 오른쪽 값
        if x > 1:
            _, pred = query(1, 1, N, 1, x - 1, leftmost, rightmost)
        else:
            pred = 0  # 없다는 표시

        # 2) successor: [x+1, N]에서 가장 왼쪽 값
        if x < N:
            succ, _ = query(1, 1, N, x + 1, N, leftmost, rightmost)
        else:
            succ = INF  # 없다는 표시

        # 깊이 계산
        dpred = depth[pred] if pred != 0   else -1
        dsucc = depth[succ] if succ != INF else -1

        depth[x] = max(dpred, dsucc) + 1

        C += depth[x]
        out_lines.append(str(C))

        # X를 삽입했다고 세그트리에 기록
        update(1, 1, N, x, leftmost, rightmost)

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    main()
```

### 복잡도

- 세그트리 연산 한 번에 O(log N)
- N개의 수에 대해
  - 두 번의 query (pred / succ)
  - 한 번의 update  
  ⇒ 전체 시간 복잡도: **O(N log N)**  
- N ≤ 300,000에서 충분히 통과 가능한 수준.

---

원하면,
- 이걸 Fenwick 트리(펜윅) + “k번째 원소 찾기” 트릭으로 바꾸는 버전이나,
- 파이썬에서 조금 더 빠르게 돌리기 위한 미세 튜닝(함수 지역 변수 캐싱 등)도 같이 손봐줄게.

### ❓ 질문 (User)
```
#include <iostream>
#include <vector>
#include <algorithm>
#include <map>

using namespace std;
// 바이너리 트리 만들면서 체크되는 노드가 몇 개인가를 계산하면됨

int n;
long long C;
map<int,int>m; // 숫자, 뎁스

void init()
{
  cin >> n;
  C = 0;

  // root 만들기
  int num;
  cin >> num;
  m.insert({num, 1});
  cout << 0 << '\n';
  C = 0;
}

void calc(int num)
{
  map<int,int>::iterator iter;
  iter = m.upper_bound(num);

  int height = 0;
  
  // num이 가장 큰 경우
  if(iter == m.end()) {
    C += (--iter)->second;
    cout << C << '\n';
    height = iter->second + 1;
  }
  // num이 가장 작은 경우
  else if(iter == m.begin()) {
    C += iter->second; // upper_bound 이므로 다음 값 가리킴
    cout << C << '\n';
    height = iter->second + 1;
  }
  // 중간인 경우
  else {
    // upper가 가리키는 곳 왼쪽 자식으로 붙을지
    // upper의 왼쪽 자식의 오른쪽 자식으로 붙을지 모름
    // 더 깊은 쪽으로 붙음
    int upperHeight = iter->second;
    iter--;
    int tmpHeight = iter->second;
    height = max(upperHeight, tmpHeight);

    C += height; // 붙을 노드의 height만큼 카운트되는 것과 동일
    cout << C << '\n';
    height++;
  }

  m.insert({num, height}); // +1된 뎁스 추가
}

int main() {
  ios_base :: sync_with_stdio(false);
  cin.tie(NULL);
  cout.tie(NULL);
  
  init();

  int num;
  for(int i = 1; i < n; i++) {
    cin >> num;
    calc(num);
  }
}
```
이 코드를 파이썬 코드로 구현해줘.

### 💡 답변 (Assistant)
아까 C++ 코드 그대로 따라가면서, 파이썬 버전으로 옮겨볼게.  
`std::map<int,int>`는 **정렬된 키 + 각 키의 depth 저장** 구조라서, 파이썬에서는

- 정렬된 키 리스트 `keys`
- 각 값의 깊이를 저장하는 딕셔너리 `depth`

+ `bisect` 모듈로 `upper_bound` 를 흉내 내면 돼.

> ⚠️ 주의: `bisect.insort`는 O(N)이라 최악엔 O(N²)까지 갈 수 있어.  
> BOJ용 최적 코드로는 아까 얘기한 세그트리 풀이가 더 안전하고,  
> 이 코드는 “C++ map 로직을 파이썬으로 그대로 옮긴 버전”이라고 생각하면 돼.

```python
import sys
import bisect

input = sys.stdin.readline

def main():
    n = int(input())
    nums = [int(input()) for _ in range(n)]

    # C++: map<int,int> m;  // 값 -> 깊이
    keys = []        # 정렬된 값들 (map의 key 순서)
    depth = {}       # 값 -> 깊이
    C = 0

    # init(): 첫 번째 수를 root로 사용
    root = nums[0]
    keys.append(root)
    depth[root] = 1  # C++에서 root 깊이를 1로 둔 것과 동일
    print(0)         # 루트 삽입 후 카운터 C는 0

    # 나머지 값들 처리 (calc)
    out_lines = []

    for num in nums[1:]:
        # upper_bound(num)와 동일: num보다 큰 첫 번째 원소의 인덱스
        idx = bisect.bisect_right(keys, num)

        # num이 현재까지의 값 중 가장 큰 경우
        if idx == len(keys):
            # --iter: 가장 큰 값
            pred = keys[-1]
            C += depth[pred]
            out_lines.append(str(C))
            h = depth[pred] + 1

        # num이 가장 작은 경우
        elif idx == 0:
            # upper_bound 결과가 begin()이므로, 그 값이 바로 succ
            succ = keys[0]
            C += depth[succ]
            out_lines.append(str(C))
            h = depth[succ] + 1

        # 중간에 들어가는 경우
        else:
            succ = keys[idx]       # upper가 가리키는 값
            pred = keys[idx - 1]   # upper의 왼쪽 값

            upperHeight = depth[succ]
            tmpHeight = depth[pred]
            base = max(upperHeight, tmpHeight)

            C += base
            out_lines.append(str(C))
            h = base + 1

        # map.insert({num, height});
        depth[num] = h
        bisect.insort(keys, num)

    # 이미 루트에 대해 한 줄 출력했으니 그 뒤부터 출력
    if out_lines:
        sys.stdout.write("\n".join(out_lines) + "\n")


if __name__ == "__main__":
    main()
```

- C++ `upper_bound`, `m.begin()`, `m.end()` 로직을  
  각각 `bisect_right`, `idx == 0`, `idx == len(keys)`로 그대로 대응시킨 버전이야.
- 동작 원리는 C++ 코드와 동일하게,
  - 가장 가까운 왼쪽/오른쪽 값의 깊이 중 큰 값 + 1 을 새 노드 깊이로 쓰고,
  - 그 깊이만큼 C에 더해서 출력하는 구조.
