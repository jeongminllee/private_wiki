### ❓ 질문 (User)
문제
Hearing that the latest fashion trend was cows with two spots on their hides, Farmer John has purchased an entire herd of two-spot cows. Unfortunately, fashion trends tend to change quickly, and the most popular current fashion is cows with only one spot!

FJ wants to make his herd more fashionable by painting each of his cows in such a way that merges their two spots into one. The hide of a cow is represented by an N by M (1 <= N,M <= 50) grid of characters like this:

................
..XXXX....XXX...
...XXXX....XX...
.XXXX......XXX..
........XXXXX...
.........XXX....
Here, each 'X' denotes part of a spot. Two 'X's belong to the same spot if they are vertically or horizontally adjacent (diagonally adjacent does not count), so the figure above has exactly two spots. All of the cows in FJ's herd have exactly two spots.

FJ wants to use as little paint as possible to merge the two spots into one. In the example above, he can do this by painting only three additional characters with 'X's (the new characters are marked with '*'s below to make them easier to see).

................
..XXXX....XXX...
...XXXX*...XX...
.XXXX..**..XXX..
........XXXXX...
.........XXX....
Please help FJ determine the minimum number of new 'X's he must paint in order to merge two spots into one large spot.

입력
Line 1: Two space-separated integers, N and M.
Lines 2..1+N: Each line contains a length-M string of 'X's and '.'s specifying one row of the cow hide pattern.
출력
Line 1: The minimum number of new 'X's that must be added to the input pattern in order to obtain one single spot.
예제 입력 1 
6 16
................
..XXXX....XXX...
...XXXX....XX...
.XXXX......XXX..
........XXXXX...
.........XXX....
예제 출력 1 
3
힌트
Input Details
The pattern in the input shows a cow hide with two distinct spots, labeled 1 and 2 below:

................
..1111....222...
...1111....22...
.1111......222..
........22222...
.........222....
Output Details
Three 'X's suffice to join the two spots into one:

### 💡 답변 (Assistant)
이 코드는 농부 John이 소 가죽의 두 개의 'X'로 된 점들을 하나로 합치기 위해 최소한의 'X'를 추가해야 하는 문제를 해결합니다.  

---

### **문제 해결 접근 방식**
1. **두 개의 점(spot) 찾기**  
   - `find_spots` 함수에서 **BFS(너비 우선 탐색)** 을 사용해 'X'로 이루어진 점(spot)의 개수를 찾습니다.
   - 각 'X'는 상하좌우로 연결된 경우 같은 점에 속한다고 판단합니다.
   - 두 개의 점이 존재한다고 가정했기 때문에, 두 개의 점을 각각 리스트에 저장합니다.

2. **최소 거리 찾기**  
   - `min_paint_needed` 함수에서 두 개의 점을 하나로 합치는 최소한의 'X' 개수를 찾습니다.
   - 각각의 점에 속한 'X' 좌표를 비교하며 **맨해튼 거리(Manhattan Distance)** 를 사용합니다.  
     \[
     거리 = |x_1 - x_2| + |y_1 - y_2| - 1
     \]
     위 식에서 `-1`을 하는 이유는 두 개의 점을 연결하기 위한 최소한의 'X' 개수를 구해야 하기 때문입니다.

3. **출력**  
   - 최소한의 'X'를 추가해야 하는 개수를 출력합니다.

---

### **코드 상세 설명**
#### **1. 두 개의 점 찾기**
```python
def find_spots(grid, N, M):
    visited = [[False] * M for _ in range(N)]
    spots = []
```
- `visited`: 방문 여부를 저장하는 2차원 리스트 (`False`로 초기화)
- `spots`: 두 개의 점을 저장하는 리스트

##### **BFS로 'X' 영역 탐색**
```python
def bfs(x, y):
    queue = deque([(x, y)])
    visited[x][y] = True
    spot = [(x, y)]
```
- `bfs(x, y)`: 특정 위치 `(x, y)`에서 BFS 탐색을 시작하여 연결된 'X'들을 찾아 하나의 점으로 저장합니다.
- `queue`: BFS 탐색을 위한 큐  
- `visited[x][y] = True`: 방문한 위치 표시  
- `spot`: 현재 점(spot)에 속하는 'X' 좌표를 저장하는 리스트  

##### **BFS 탐색 과정**
```python
while queue:
    cx, cy = queue.popleft()
    for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
        nx, ny = cx + dx, cy + dy
        if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny] and grid[nx][ny] == 'X':
            visited[nx][ny] = True
            queue.append((nx, ny))
            spot.append((nx, ny))
```
- 큐에서 좌표 `(cx, cy)`를 하나 꺼내서 상하좌우(`dx, dy`)로 이동하며 연결된 'X'를 찾습니다.
- 방문하지 않았고, 'X'가 있는 좌표라면:
  - `visited`를 `True`로 표시
  - 큐에 추가해서 BFS를 계속 진행
  - 현재 점(spot)에 포함시킴  

##### **결과 저장**
```python
return spot
```
- 탐색이 끝나면 해당 점의 모든 'X' 좌표 리스트를 반환합니다.

##### **모든 'X' 찾기**
```python
for i in range(N):
    for j in range(M):
        if grid[i][j] == 'X' and not visited[i][j]:
            spots.append(bfs(i, j))
```
- 모든 좌표를 순회하면서 방문하지 않은 'X'를 찾으면 `bfs()`를 실행하여 해당 점을 찾아 `spots` 리스트에 추가합니다.

#### **2. 최소한의 'X' 추가하기**
```python
def min_paint_needed(grid, N, M):
    spots = find_spots(grid, N, M)
    if len(spots) != 2:
        return 0  # 이미 하나의 spot으로 연결되어 있음
```
- `spots` 리스트에 저장된 점이 2개가 아닐 경우, 이미 하나로 연결되어 있으므로 `0`을 반환합니다.

##### **두 개의 점 연결하기**
```python
spot1, spot2 = spots
min_dist = float('inf')
```
- `spot1`, `spot2`에 각 점의 좌표 리스트 저장  
- `min_dist`를 무한대 값으로 초기화

##### **맨해튼 거리 계산**
```python
for x1, y1 in spot1:
    for x2, y2 in spot2:
        dist = abs(x1 - x2) + abs(y1 - y2) - 1
        min_dist = min(min_dist, dist)
```
- `spot1`의 모든 좌표 `(x1, y1)`와 `spot2`의 모든 좌표 `(x2, y2)`를 비교하여 **맨해튼 거리**를 계산
- `-1`을 빼는 이유: 맨해튼 거리는 두 점 간 이동하는 칸 수이므로, 실제로 'X'를 추가해야 하는 개수는 `거리 - 1`
- `min_dist` 값을 갱신하여 최소한의 'X' 개수를 찾음

---

#### **3. 실행 및 결과 출력**
```python
# 입력 처리
N, M = map(int, input().split())
grid = [list(input().strip()) for _ in range(N)]

# 결과 출력
print(min_paint_needed(grid, N, M))
```
- `N, M`을 입력받고 `grid`를 저장
- `min_paint_needed(grid, N, M)`를 실행하여 최소한의 'X' 개수를 출력

### **시간 복잡도 분석**
1. `find_spots`: `O(NM)` (모든 셀을 한 번씩 탐색)
2. `min_paint_needed`: `O(S1 * S2)` (`S1`과 `S2`는 각각 두 개의 점에 속하는 'X' 개수, 최악의 경우 `50 * 50 = 2500`)
3. 전체 시간 복잡도는 **O(NM + S1 * S2)**  
   - `N, M ≤ 50`이므로 `2500 + 2500 = 5000` 정도로 충분히 계산 가능
