### 💡 답변 (Assistant)
현재 세션에서는 `koreanize_matplotlib` 패키지가 설치되어 있지 않아 바로 사용할 수 없습니다. 하지만 아래 명령어를 사용하면 로컬 환경이나 Jupyter Notebook에서 설치 후 한글 폰트를 적용할 수 있습니다:

```bash
pip install koreanize-matplotlib
```

설치 후, 코드 상단에 아래 코드를 추가하면 한글이 정상적으로 표시됩니다:

```python
import koreanize_matplotlib
```

이제 한글이 깨지지 않는 파이그래프를 그리기 위한 전체 예제 코드는 다음과 같습니다:

```python
import matplotlib.pyplot as plt
import koreanize_matplotlib

companies = ["넷플릭스", "브로드컴", "스노우플레이크"]
revenues = [85, 93, 7.1]
colors = ["red", "darkred", "skyblue"]

total_revenue = sum(revenues)
revenue_ratios = [r / total_revenue for r in revenues]

plt.figure(figsize=(8, 6))
plt.pie(revenue_ratios, labels=companies, autopct='%1.1f%%', colors=colors, startangle=140)
plt.title("2023년 3분기 매출 비율")
plt.axis('equal')
plt.show()
```

필요하시면 PNG나 PDF로 저장하는 방법도 안내드릴 수 있어요.
