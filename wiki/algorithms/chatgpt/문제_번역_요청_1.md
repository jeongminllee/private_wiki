# 문제 번역

무한한 2차원 평면이 삼각형 영역들로 타일링(테셀레이션) 되어 있다. 이 테셀레이션은 다음과 같이 정의된다.

먼저, **오일러 공식**을 기억하자:

\[
e^{ix} = \cos(x) + i\sin(x)
\]

(여기서 \(x\)는 실수이다.)

---

## 1단계: 기본 격자 생성

모든 정수 \(x, y\)에 대해, 복소평면 위에 다음 위치에 정점을 찍는다:

\[
x + y \cdot e^{\pi i / 3}
\]

---

## 2단계: 삼각형 생성

위에서 만든 정점들 중에서,

- 변의 길이가 1인 **정삼각형을 이루는 세 정점**을 찾는다.
- 해당 세 정점을 연결하여 삼각형의 변을 그린다.
- 그리고 각 삼각형의 **중심에도 정점 하나를 추가**하고,
- 중심에서 세 꼭짓점으로 선을 연결한다.

---

## 문제 정의

총 \(N\)개의 점이 주어진다.  
각 점은 어떤 삼각형 영역 내부에 있으며 (**꼭짓점이나 변 위에는 없음**).

---

## 거리 정의

두 점 사이의 거리는 다음과 같이 정의된다:

- 한 점에서 다른 점으로 이동할 때,
- **정점을 지나지 않으면서**
- **경로가 교차하는 "변(edge)"의 최소 개수**

---

## 목표

모든 점 쌍 \(\frac{N(N-1)}{2}\)에 대해 거리의 합을 구하라.

---

## 입력 형식

- 첫 줄: 테스트 케이스 개수 \(T\) ( \(T \ge 1\) )
- 각 테스트 케이스:

  - 첫 줄: 점의 개수 \(N\) ( \(2 \le N \le 2 \times 10^5\) )

  - 다음 \(N\)줄:
    - 세 정수 \(x, y, z\)
    - \((0 \le x, y < 10^6,\ 0 \le z < 12)\)

각 점은 다음 위치를 의미한다:

\[
x + y \cdot e^{\pi i / 3} + \epsilon \cdot e^{(1 + 2z)\pi i / 12}
\]

- 여기서 \(\epsilon\)은 아주 작은 양수이다.
- 즉, 점은 격자 정점 근처에서 특정 방향으로 살짝 이동한 위치이다.

---

## 출력 형식

각 테스트 케이스마다  
모든 점 쌍 거리의 합을 출력하라.

## 예시 설명 (두 번째 테스트)

- 각 정점 \(x + y e^{\pi i/3}\)는 좌표 \((x,y)\)로 표시된다.
- 범위 \(x, y \in [-1, 2]\) 내 정점들을 표시함
- 삼각형 중심들도 정점으로 포함됨

- \((0,0,0)\)이 포함된 영역 → 초록색
- \((1,1,7)\)이 포함된 영역 → 파란색

- 두 영역 사이를 이동하는 경로 중  
  **3개의 변을 가로지르는 경로**가 존재 → 거리 = 3

## 핵심 요약 (중요)

이 문제는 사실상:

👉 **삼각형 기반 그래프에서의 최단 거리 (edge crossing 수)**  
👉 **모든 쌍 거리 합**

을 구하는 문제이다.

---

## 다음 단계 (추천)

이 문제는 단순 번역 수준이 아니라 다음 개념이 필요하다:

- 삼각 격자 → **좌표 변환 (cube coordinate / axial coordinate)**
- 각 점 → **삼각형 셀로 매핑**
- 거리 → **그래프 거리 (L1-like metric 변형)**
- 전체 합 → **prefix sum / coordinate compression / counting**
