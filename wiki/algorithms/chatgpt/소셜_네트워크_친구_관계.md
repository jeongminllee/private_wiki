### ❓ 질문 (User)
문제
소셜 네트워크는 이제 우리 삶의 일부가 되어버렸다. 이러한 소셜 네트워크를 분석하는 김동규 석사과정은 흥미로운 현상을 발견했다. 바로 친구 관계의 수가 급속도로 증가한다는 것이다.

예로부터 우리의 조상님들은 "친구의 친구는 나의 친구"라고 했다. 사람들은 매일 조상님들의 말씀을 따르기 위해서 자신의 친구의 친구 목록을 확인하고, 이를 모두 자신의 친구로 추가한다. 친구 관계는 상대방이 수락을 해야 되고, 총 1일이 걸린다.

예를 들어, A와 B가 친구라면, A는 B가 어제 또는 그 이전에 만든 친구만 볼 수 있다.

모든 친구관계는 대칭이다. 즉, A와 B의 친구라면, B도 A의 친구이다.

김동규가 분석하는 소셜 네트워크에서는 한 번 친구 관계가 맺어졌으면, 이것을 깰 수 없다.

사람의 수와 지금 친구 관계가 주어졌을 때, 모든 사람이 서로 친구가 되는데 걸리는데 며칠이 걸리는지 구하는 프로그램을 작성하시오. 또한, 매일 매일 새로운 친구 관계가 얼마나 생기는지 구해서 출력하시오.

입력
첫째 줄에 사람의 수 N과 처음 친구 관계의 수 M이 주어진다. (1 ≤ N ≤ 50, 1 ≤ M ≤ N*(N-1)/2)

둘째 줄부터 M개의 줄에는 두 정수 A와 B가 주어진다. (1 ≤ A ≤ N, 1 ≤ B ≤ N, A < B). 이것은 A와 B가 친구라는 것을 의미한다. 항상 모든 사람이 서로 친구가 될 수 있는 경우만 입력으로 주어진다.

출력
첫째 줄에 모든 사람이 서로 친구가 되는데 며칠이 걸리는지 출력한다. 이 값을 K라고 하자.

다음 K개의 줄에는 몇 명의 새로운 친구 관계가 생기는지, 첫째날부터, K번째 날까지 한 줄에 하나씩 출력한다.

3 2
1 2
2 3

1
1

예제 출력 2

3

### 💡 답변 (Assistant)
이 문제는 소셜 네트워크에서 "친구의 친구는 나의 친구"라는 규칙에 따라 친구 관계가 확산되는 과정을 시뮬레이션하는 문제입니다. 초기에는 일부 사람들 간에만 친구 관계가 형성되어 있고, 이후 매일 아래와 같은 과정을 통해 새로운 친구 관계가 만들어집니다.

---

### 문제의 주요 내용 및 규칙

1. **초기 상태**
   - 사람의 수 \(N\)와 초기 친구 관계의 수 \(M\)이 주어집니다.
   - 이후 \(M\)개의 줄에 걸쳐, 두 정수 \(A\)와 \(B\)가 주어지며 이는 \(A\)와 \(B\)가 친구임을 의미합니다.
   
2. **친구 관계 확장 규칙**
   - **친구의 친구 확인:** 매일 각 사람은 자신이 가진 친구 목록에서, (어제 혹은 그 이전에 형성된) 친구 관계를 통해 "친구의 친구" 목록을 확인합니다.
   - **새로운 친구 관계 형성:** 만약 친구의 친구 중 아직 친구가 아닌 사람이 있다면, 그 사람과 친구 관계를 맺습니다. 단, 이 과정은 상대방의 승인을 받아야 하므로 실제 친구 관계가 형성되기까지 1일이 걸립니다.
   - **대칭 관계:** 친구 관계는 대칭적입니다. 즉, 만약 A와 B가 친구가 되면, B와 A도 친구가 됩니다.
   - **한 번 형성된 친구 관계는 취소되지 않음:** 이미 형성된 친구 관계는 이후에 바뀌거나 제거되지 않습니다.

3. **시뮬레이션 과정**
   - **매일 진행:** 초기 상태를 바탕으로 매일 "친구의 친구" 규칙을 적용해 아직 친구가 아닌 사람들 간에 새로운 친구 관계를 추가합니다.
   - **시간 지연:** 각 날에 만들어진 새로운 친구 관계는 다음 날부터 다른 사람들에게 보이게 됩니다.
   - **종료 조건:** 모든 사람이 서로 친구가 되어 (즉, 완전 그래프가 형성될 때까지) 이 과정을 반복합니다.

4. **출력**
   - **첫 줄:** 모든 사람이 서로 친구가 될 때까지 걸린 일 수 \(K\)를 출력합니다.
   - **이후 \(K\)줄:** 각 날마다 형성된 새로운 친구 관계의 개수를 첫 날부터 순서대로 출력합니다.

### 예시를 통한 이해

#### 예제 입력 1
```
3 2
1 2
2 3
```
- **초기 상태:** 친구 관계는 \(1\text{-}2\)와 \(2\text{-}3\)입니다.
- **첫째 날:** 
  - 사람 1은 친구인 2의 친구인 3을 확인하고, 3과 친구가 됩니다.
  - 이로써 \(1\text{-}3\)의 친구 관계가 새로 형성됩니다.
- **결과:** 하루 만에 모든 사람(1, 2, 3)이 서로 친구가 되었으므로, 출력은
  ```
  1
  1
  ```

#### 예제 입력 2
```
5 4
1 2
2 3
3 4
4 5
```
- **초기 상태:** \(1\text{-}2\), \(2\text{-}3\), \(3\text{-}4\), \(4\text{-}5\)의 친구 관계가 존재합니다.
- **첫째 날:** 
  - 여러 사람이 각자의 친구의 친구를 확인해, 예를 들어 \(1\)은 \(2\)의 친구인 \(3\)과 친구가 되고, 그 외에도 \(2\)와 \(3\), \(3\)와 \(5\) 등이 친구가 됩니다.
  - 이 날 총 3개의 새로운 친구 관계가 형성됩니다.
- **둘째 날:**
  - 첫날 형성된 친구 관계까지 포함해 전체 네트워크를 보고, 남은 친구 관계 (예: \(1\text{-}4\), \(1\text{-}5\), \(2\text{-}5\))를 모두 채워넣어 3개의 새로운 친구 관계가 형성됩니다.
- **결과:** 전체가 완성되기까지 2일 걸리며, 각 날 형성된 친구 관계 수는 3, 3이므로 출력은
  ```
  2
  3
  3
  ```

#### 예제 입력 3
```
5 4
1 2
1 3
1 4
1 5
```
- **초기 상태:** 1이 중심인 스타형 구조로, 1은 모두와 친구지만 나머지 사람들끼리는 친구가 아닙니다.
- **첫째 날:**
  - 1을 통해 나머지 사람들 간의 친구 관계가 모두 형성됩니다.
  - 나머지 4명 사이의 친구 관계는 \(\binom{4}{2} = 6\)개가 형성됩니다.
- **결과:** 하루 만에 완전한 친구 네트워크가 완성되어 출력은
  ```
  1
  6
  ```

### 💡 답변 (Assistant)
다음은 해당 문제를 해결하는 Python 코드입니다.  

- `friends` 리스트를 사용하여 각 사람의 친구 목록을 관리합니다.  
- 매일 새로운 친구 관계를 생성하면서, 모든 사람이 친구가 될 때까지 반복합니다.  
- 매일 생성된 친구 관계의 수를 기록하여 출력합니다.  

```python
from collections import deque

def social_network_days(N, M, connections):
    # 친구 관계를 저장할 리스트 (1-based index)
    friends = [set() for _ in range(N + 1)]
    
    # 초기 친구 관계 설정
    for A, B in connections:
        friends[A].add(B)
        friends[B].add(A)
    
    days = 0
    daily_new_friends = []

    # BFS 기반으로 친구 관계 확장
    while True:
        new_friends = [set() for _ in range(N + 1)]
        new_count = 0
        
        # 각 사람에 대해 친구의 친구를 탐색
        for person in range(1, N + 1):
            for friend in friends[person]:  # 현재 친구 목록
                for f_of_f in friends[friend]:  # 친구의 친구 목록
                    if f_of_f != person and f_of_f not in friends[person]:  # 새로운 친구라면 추가
                        new_friends[person].add(f_of_f)
                        new_count += 1
        
        if new_count == 0:  # 더 이상 새로운 친구가 없으면 종료
            break
        
        # 새로운 친구 관계 업데이트
        for person in range(1, N + 1):
            friends[person].update(new_friends[person])
        
        days += 1
        daily_new_friends.append(new_count // 2)  # 친구 관계는 양방향이므로 // 2

    # 결과 출력
    print(days)
    for count in daily_new_friends:
        print(count)

# 입력 처리
N, M = map(int, input().split())
connections = [tuple(map(int, input().split())) for _ in range(M)]

# 실행
social_network_days(N, M, connections)
```

### 코드 설명
1. **데이터 구조**
   - `friends`: 각 사람이 친구로 맺어진 사람들의 집합(set)을 저장하는 리스트.
   - `new_friends`: 매일 새로 생긴 친구 관계를 임시 저장하는 리스트.

2. **초기 친구 관계 저장**
   - `connections`를 받아 각 사람의 친구 목록을 `set`으로 저장.

3. **친구 관계 확장 과정 (BFS 기반)**
   - `friends[person]`을 확인하며 친구의 친구(`f_of_f`)를 찾음.
   - 아직 친구가 아닌 경우 새로운 친구 목록에 추가.
   - 매일 `new_friends`를 `friends`에 업데이트.
   - 더 이상 새로운 친구 관계가 없을 때 종료.

4. **출력**
   - 모든 사람이 친구가 되는데 걸리는 일 수 `days` 출력.
   - 매일 새로 생긴 친구 관계의 수 출력.

### 💡 답변 (Assistant)
다음은 위 문제를 파이썬으로 구현한 코드입니다.  
코드의 주요 아이디어는, 매일 어제까지 만들어진 친구 관계(즉, “visible” 그래프)를 이용해서 아직 친구가 아닌 두 사람이 공통 친구가 있는지 확인하여 새로운 친구 관계를 형성하는 것입니다. 새로운 친구 관계는 다음 날부터 반영됩니다.

```python
def main():
    import sys
    input = sys.stdin.readline
    
    n, m = map(int, input().split())
    
    # 각 사람별로 친구 목록을 저장 (1부터 n까지)
    visible = {i: set() for i in range(1, n+1)}
    for _ in range(m):
        a, b = map(int, input().split())
        visible[a].add(b)
        visible[b].add(a)
    
    # 전체 완전 그래프의 간선 수
    complete_edges = n * (n - 1) // 2
    # 현재 간선 수 (양쪽에 저장되어 있으므로, 실제 간선 수는 sum(deg)//2)
    current_edges = m
    
    days = []  # 각 날에 추가된 친구 관계 수 기록
    
    # 하루 단위로 진행: 이전 날까지의 친구 관계(visible)를 기반으로 새 친구 관계를 구함.
    while current_edges < complete_edges:
        # 현재 visible 상태를 복사(새로운 친구 관계는 당일에 사용하면 안됨)
        old_visible = {u: visible[u].copy() for u in visible}
        new_edges = set()  # (u, v) 형태로 u < v인 새로운 친구 관계
        
        # 모든 가능한 두 사람 (u, v)를 확인
        for u in range(1, n):
            for v in range(u + 1, n + 1):
                # 이미 친구이면 넘어감
                if v in old_visible[u]:
                    continue
                # 두 사람의 친구 목록에서 공통 친구가 있으면 새 친구 관계 형성
                if old_visible[u].intersection(old_visible[v]):
                    new_edges.add((u, v))
        
        # 하루에 추가된 새 친구 관계 수
        new_count = len(new_edges)
        days.append(new_count)
        current_edges += new_count
        
        # visible 그래프에 새 친구 관계 추가 (양쪽에 모두 추가)
        for u, v in new_edges:
            visible[u].add(v)
            visible[v].add(u)
    
    # 결과 출력
    print(len(days))
    for count in days:
        print(count)

if __name__ == '__main__':
    main()
```

### 코드 설명

1. **입력 및 초기화**  
   - 사람의 수 `n`과 초기 친구 관계의 수 `m`을 입력받고, 각 사람별 친구 목록을 `visible` 딕셔너리로 초기화합니다.
   - 초기 친구 관계들을 `visible`에 추가합니다.

2. **시뮬레이션 루프**  
   - 전체 친구 관계의 개수가 완전 그래프의 간선 수(`n*(n-1)/2`)에 도달할 때까지 반복합니다.
   - 매일, 현재까지 만들어진 친구 관계(`old_visible`)를 기반으로 아직 친구가 아닌 두 사람이 공통 친구가 있는지 확인합니다.
   - 공통 친구가 있다면, 두 사람 사이에 새 친구 관계가 형성됩니다.
   - 당일 형성된 모든 새 친구 관계의 수를 기록하고, 내일부터 사용하기 위해 `visible`에 업데이트합니다.

3. **출력**  
   - 전체 걸린 일수와 매일 형성된 친구 관계의 개수를 출력합니다.

이 코드로 문제에서 제시한 예제들을 포함한 다양한 케이스를 해결할 수 있습니다.
