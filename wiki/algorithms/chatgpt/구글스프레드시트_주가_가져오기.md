# 구글스프레드시트 주가 가져오기

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-05-20

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
구글 파이낸스에서 구글 스프레드 시트의 시트이름에 적힌 {티커}에 따라 일자별 종가를 가져와서 스프레드 시트에 저장하고 싶어. {티커}에 따라 A1 셀부터는 날짜, 종가 칼럼이 필요해. 2행부터는 칼럼에 따라서 일자별 종가 정보를 가져오는 Apps Script 코드를 생성해주고, 주석은 한국어로 작성해줘.
최근 1년간의 종가 데이터가 필요해

### 💡 답변 (Assistant)
다음은 **구글 스프레드시트의 시트 이름을 티커로 간주**하고, 해당 티커의 **최근 1년간 일자별 종가(Date, Close Price)** 데이터를 `A1`부터 자동으로 입력해주는 **Google Apps Script 코드**입니다.

---

### ✅ 스크립트 설명
- 시트 이름이 티커(`GOOGL`, `AAPL` 등)로 되어 있다고 가정합니다.
- `=GOOGLEFINANCE()` 함수는 직접 날짜별 주가를 가져올 수 있지만, 앱스 스크립트로 처리하면 다중 시트 자동화가 가능하다는 장점이 있습니다.

---

### ✅ Google Apps Script 코드
```javascript
function importStockPriceFromTicker() {
  // 현재 활성화된 시트를 가져옵니다 (시트 이름은 티커라고 가정)
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var ticker = sheet.getName();  // 예: "AAPL"

  // 오늘 날짜와 1년 전 날짜를 계산
  var today = new Date();
  var oneYearAgo = new Date();
  oneYearAgo.setFullYear(today.getFullYear() - 1);

  // GOOGLEFINANCE 함수를 사용해 일자별 종가를 가져옵니다
  // =GOOGLEFINANCE("AAPL", "close", DATE(2024,5,20), DATE(2025,5,20), "DAILY")
  var formula = `=GOOGLEFINANCE("${ticker}", "close", DATE(${oneYearAgo.getFullYear()}, ${oneYearAgo.getMonth()+1}, ${oneYearAgo.getDate()}), DATE(${today.getFullYear()}, ${today.getMonth()+1}, ${today.getDate()}), "DAILY")`;

  // 시트 초기화 후, A1 셀부터 수식 입력
  sheet.clear();  // 기존 내용 제거
  sheet.getRange("A1").setFormula(formula);
}
```

---

### ✅ 사용 방법
1. 구글 스프레드시트를 열고, **시트 이름을 티커 이름(예: `TSLA`, `MSFT`)**으로 설정하세요.
2. `확장 프로그램 > Apps Script` 메뉴로 이동한 후, 위 코드를 붙여넣고 저장하세요.
3. `▶ 실행` 버튼을 누르면 A1 셀에 수식이 자동으로 입력되어, **최근 1년간 날짜별 종가**가 자동 채워집니다.

---

### 🔁 여러 티커에 대해 반복 실행하려면?
다중 시트의 각 시트마다 적용하고 싶다면 아래처럼 `getSheets()`로 반복할 수도 있습니다:

```javascript
function importAllTickers() {
  var sheets = SpreadsheetApp.getActiveSpreadsheet().getSheets();
  var today = new Date();
  var oneYearAgo = new Date();
  oneYearAgo.setFullYear(today.getFullYear() - 1);

  sheets.forEach(function(sheet) {
    var ticker = sheet.getName();
    var formula = `=GOOGLEFINANCE("${ticker}", "close", DATE(${oneYearAgo.getFullYear()}, ${oneYearAgo.getMonth()+1}, ${oneYearAgo.getDate()}), DATE(${today.getFullYear()}, ${today.getMonth()+1}, ${today.getDate()}), "DAILY")`;
    sheet.clear();
    sheet.getRange("A1").setFormula(formula);
  });
}
```

필요에 따라 위 두 함수를 선택해 사용하면 됩니다.  
추가적으로 날짜나 출력 형식 정렬이 필요하면 말씀해 주세요!

### ❓ 질문 (User)
B3 셀부터 일자별 종가 가격이 있어. 2025.05.19일까지의 일자별 종가값을 꺾은선 그래프로 그려주는 Apps Script 코드를 작성해줘.

### 💡 답변 (Assistant)
아래는 Google Apps Script를 이용해 **현재 시트의 `B3` 셀부터 시작되는 일자별 종가 데이터를 기준으로 꺾은선 그래프(Line Chart)를 생성하는 코드**입니다. 그래프는 시트의 오른쪽 영역에 삽입됩니다.

---

### ✅ 전제 조건  
- `A3:A` 범위에는 날짜  
- `B3:B` 범위에는 종가(close price)  
- 헤더는 `A1:A2`, `B1:B2`에 있을 수 있으므로, `A3:B`에서부터 시작  
- 기준일은 `2025-05-19`까지

---

### ✅ Apps Script 코드
```javascript
function drawClosePriceChart() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  // 데이터의 끝을 찾기 위해 B열의 마지막 행을 탐색
  var lastRow = sheet.getRange("B3:B").getValues().filter(String).length + 2; // +2 because starting from row 3

  // 날짜와 종가 데이터를 가져오기 (A3:B{lastRow})
  var dataRange = sheet.getRange("A3:B" + lastRow);

  // 시트에 있는 기존 차트 제거 (선택사항)
  var charts = sheet.getCharts();
  for (var i = 0; i < charts.length; i++) {
    sheet.removeChart(charts[i]);
  }

  // 꺾은선 그래프 생성
  var chart = sheet.newChart()
    .setChartType(Charts.ChartType.LINE)
    .addRange(dataRange)
    .setPosition(2, 5, 0, 0) // 그래프 위치: 행 2, 열 E (5)
    .setOption('title', '최근 1년간 종가 추이')
    .setOption('hAxis', { title: '날짜' })
    .setOption('vAxis', { title: '종가 (원화 또는 USD)' })
    .setOption('legend', { position: 'none' })
    .build();

  sheet.insertChart(chart);
}
```

---

### ✅ 사용 방법
1. 스프레드시트에서 `확장 프로그램 > Apps Script`를 엽니다.
2. 위 코드를 붙여넣고 저장한 뒤 `drawClosePriceChart()` 함수 실행.
3. 현재 활성 시트에서 꺾은선 그래프가 자동 삽입됩니다.

### 📌 참고
- `2025-05-19`까지의 데이터만 필터링하고 싶다면, 날짜 필터 조건을 추가해줄 수도 있습니다.
- 예를 들어 `A열의 날짜`를 파싱해서 비교하거나, 시트 내에서 `FILTER()` 함수로 미리 범위를 조정한 뒤 해당 범위로 차트를 그릴 수 있습니다.
