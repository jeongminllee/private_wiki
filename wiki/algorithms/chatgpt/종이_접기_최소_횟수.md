문제
W×H 크기의 종이가 있다. 지금 현정이가 필요한 종이의 크기는 넓이가 A인 종이이다. 따라서, 종이를 접어서 넓이가 A인 종이를 만들려고 한다.

종이는 직선을 기준으로 접어야하며, 다음과 같은 두 가지 조건을 지켜야 한다.

종이를 접는 기준선은 직사각형의 한 변과 평행해야 한다.
종이를 접은 후에도 W와 H는 정수가 되어야 한다.
예를 들어, 5×3 크기의 종이가 있는 경우에, 너비를 기준으로 4가 되는 선으로 종이를 접으면 4×3 크기의 종이를 접게 된다. 이제, 높이를 기준으로 1이 되는 선을 기준으로 종이를 접어서 5×2 크기의 직사각형을 만들 수 있다.

W, H, A가 주어졌을 때, 넓이가 A가 되게 접을 수 있는지 없는지 구하고, 접을 수 있는 경우에는 접어야 하는 횟수의 최솟값을 구하는 프로그램을 작성하시오.

입력
첫째 줄에 W, H, A가 주어진다. (1 ≤ W, H ≤ 1,000,000,000, 1 ≤ A ≤ 100,000)

출력
W×H 크기의 종이를 접어서 넓이가 A가 되게 만들 수 있으면 접는 횟수의 최솟값을, 만들 수 없으면 -1을 출력한다.

### 💡 답변 (Assistant)
문제를 풀기 위해서는 “접기”라는 연산이 한 변의 길이를 어떻게 줄일 수 있는지를 먼저 이해해야 합니다.

예를 들어, 한 변의 길이가 \(L\)인 직사각형에서, 종이를 한 번 접을 때는 직선 (접는 기준선)을 \(L\)의 어느 정수 위치 \(x\) (단, \(1\le x\le L-1\))에 놓고 접게 됩니다. 이때 접은 후의 “폭”은 두 부분 중 큰 쪽의 길이가 됩니다. 즉
\[
L\to L'=\max(x,L-x)
\]
인데, 이때 \(x\)를 어떻게 선택하느냐에 따라 \(L'\)는
\[
\lceil L/2\rceil\le L'\le L-1
\]
의 임의의 정수값을 만들 수 있음을 알 수 있습니다.

즉, 한 변에 대해 “접기” 연산은 \(L\)을 임의의 정수 \(t\)로 줄이는 것이 가능하며, 단 조건은 \(t\ge \lceil L/2\rceil\)를 만족해야 합니다. 여러 번 접으면 최대로 많이 줄일 수 있는 값은 “최적으로 많이 줄였을 때” \(L\)이 \(\lceil L/2\rceil\)가 되고, 다시 접으면 \(\lceil \lceil L/2\rceil/2\rceil\) … 이런 식입니다.

따라서, 한 변 \(L\)에서 목표값 \(t\) (\(t\le L\))를 만들기 위해 필요한 “최소 접기 횟수”는, \(k\)번 접었을 때 “최소로 만들 수 있는 값” 
\[
f(L,k)=\underbrace{\lceil\lceil\cdots\lceil}_{k\text{번}} L/2\rceil\cdots/2\rceil
\]
가 \(t\) 이하가 되는 최소 \(k\)와 같습니다. (접은 후에는 그 변에 대해 \(f(L,k)\) 이상 \(L\) 사이의 모든 정수가 만들 수 있으므로.) 실제로 우리는
- 만약 \(t = L\)이면 접지 않아도 되므로 0회.
- \(t < L\)인 경우, \(L\)에서 “최적으로 많이 줄였을 때” \(f(L,k)\)가 \(t\) 이하가 되는 최소 \(k\)가 바로 필요한 최소 접기 횟수입니다.

종이 전체는 \(W\times H\) 크기에서 시작하며, 우리의 목표는 넓이가 \(A\)인 종이를 만드는 것입니다. 최종 직사각형의 두 변은 \(w\)와 \(h\) (양의 정수)여야 하고 \(w\times h=A\)여야 합니다. 또한, 종이를 접는 연산은 두 변에 대해 독립적으로 적용할 수 있으므로, \(W\)에서 \(w\)를, \(H\)에서 \(h\)를 만드는 데 필요한 접기 횟수를 각각 구한 후 합하면 됩니다.

다만 최종 \(w,h\)가 원래 종이의 방향에 맞게 들어가야 하므로
- \(w\le W\)이고 \(h\le H\)
- 또는 (종이 회전이 가능하다고 볼 수 있으므로) \(w\le H\)이고 \(h\le W\)
인 경우만 고려하면 됩니다.

A의 최댓값이 \(10^5\)이므로 \(A\)의 약수(즉, 가능한 \(w,h\) 후보)는 충분히 작게 반복할 수 있습니다.

아래는 위 아이디어를 파이썬 코드로 구현한 예입니다.

---

```python
import math
import sys

def min_folds_needed(L, target):
    """
    L에서 target까지 줄이기 위해 필요한 최소 접기 횟수를 구한다.
    한 번 접으면 최대로 많이 줄일 수 있는 값은 ceil(L/2)이다.
    target이 L보다 클 수는 없으므로, 만약 target > L이면 매우 큰 값을 반환한다.
    """
    if target > L:
        return float('inf')
    folds = 0
    current = L
    # current가 target보다 작거나 같아질 때까지 최적으로 접었을 때의 값으로 갱신한다.
    while current > target:
        current = (current + 1) // 2  # ceil(current/2)
        folds += 1
    return folds

def solve():
    import sys
    data = sys.stdin.read().split()
    if not data:
        return
    W = int(data[0])
    H = int(data[1])
    A = int(data[2])
    
    # 만약 A가 원래 종이의 넓이보다 크면 접어서 A를 만들 수 없다.
    if A > W * H:
        print(-1)
        return
    
    # 원래 종이의 넓이가 이미 A라면 접을 필요가 없다.
    if A == W * H:
        print(0)
        return
    
    best = float('inf')
    found = False
    # A의 약수 쌍 (w, h)를 모두 찾는다.
    for d in range(1, int(math.isqrt(A)) + 1):
        if A % d != 0:
            continue
        e = A // d
        # 후보 1: 최종 크기가 (d, e)가 되어야 하는 경우.
        if d <= W and e <= H:
            folds_w = min_folds_needed(W, d)
            folds_h = min_folds_needed(H, e)
            candidate = folds_w + folds_h
            if candidate < best:
                best = candidate
                found = True
        # 후보 2: (e, d)인 경우 (d와 e가 다르면 회전한 경우)
        if d != e:
            if e <= W and d <= H:
                folds_w = min_folds_needed(W, e)
                folds_h = min_folds_needed(H, d)
                candidate = folds_w + folds_h
                if candidate < best:
                    best = candidate
                    found = True
                    
    if found:
        print(best)
    else:
        print(-1)

if __name__ == '__main__':
    solve()
```

### 코드 설명

1. **min_folds_needed(L, target)**  
   - \(L\)에서 시작해서, 한 번 접을 때마다 최적으로 (즉, 최대한 줄일 수 있도록) 접으면 \( \lceil L/2 \rceil \)가 된다.
   - 이 과정을 반복하면서, 접은 후의 “최소값”이 target 이하가 되는 최소 접기 횟수를 구합니다.

2. **solve() 함수**  
   - 입력을 읽고, \(W \times H\)에서 만들 수 있는 최종 직사각형의 두 변이 \(w\)와 \(h\) (\(w\times h=A\))가 되는 모든 약수 쌍을 찾습니다.
   - 각 후보에 대해 \(W\)에서 \(w\) (또는 \(h\))를, \(H\)에서 \(h\) (또는 \(w\))를 만들기 위한 최소 접기 횟수를 구하고 합한 값을 후보 답으로 취합니다.
   - 가능한 후보가 없으면 -1을 출력합니다.

이 코드는 문제의 조건에 맞게 최소 접기 횟수를 계산합니다.

### 💡 답변 (Assistant)
`math.isqrt`는 파이썬의 `math` 모듈에 있는 함수 중 하나로, **정수의 제곱근**(integer square root)을 구하는 함수입니다.  
즉, 주어진 비음수 정수 \(n\)에 대해, \(x = \texttt{math.isqrt}(n)\)를 호출하면 \(x\)는 \(x^2 \le n\)을 만족하는 가장 큰 정수 \(x\)가 됩니다.

### 주요 특징

- **정확성**:  
  일반적인 제곱근 함수(`math.sqrt`)는 부동소수점(float) 결과를 반환합니다. 반면, `math.isqrt`는 정수 연산을 사용하여 정확하게 정수 제곱근을 계산합니다.  
  예를 들어, `math.isqrt(10)`의 결과는 \(3\)이 됩니다. (왜냐하면 \(3^2 = 9 \le 10\)이고, \(4^2 = 16 > 10\) 이기 때문입니다.)

- **입력 조건**:  
  입력은 음이 아닌 정수여야 합니다. 만약 음수 값을 넣으면 `ValueError`가 발생합니다.

- **효율성**:  
  내부적으로 정수 산술 연산을 사용하기 때문에 매우 큰 정수에 대해서도 빠르게 결과를 계산할 수 있습니다.

### 예제 코드

```python
import math

# 예제 1: 10의 정수 제곱근
n = 10
result = math.isqrt(n)
print(result)  # 출력: 3

# 예제 2: 16의 정수 제곱근
n = 16
result = math.isqrt(n)
print(result)  # 출력: 4

# 예제 3: 27의 정수 제곱근
n = 27
result = math.isqrt(n)
print(result)  # 출력: 5 (5^2=25, 6^2=36 > 27)
```

### 사용 용도

- **정수 연산**:  
  정확한 정수 결과가 필요한 경우, 예를 들어 알고리즘 문제에서 제곱근을 이용해 범위를 조정할 때 유용합니다.

- **성능**:  
  부동소수점 연산보다 정수 연산을 선호할 때 사용할 수 있습니다.

요약하면, `math.isqrt`는 파이썬에서 정수의 제곱근을 안전하고 빠르게 계산할 수 있는 함수입니다.

```python
import math
import sys

def min_folds_needed(L, target):
    """
    L에서 target 길이 이하로 줄이기 위해 필요한 최소 접기 횟수를 구하는 함수입니다.

    설명:
    - 종이 한 변의 초기 길이가 L일 때, 한 번 접으면 최대로 줄일 수 있는 길이는 ceil(L/2)입니다.
      (예: L이 5라면, 접은 후 최소 길이는 ceil(5/2)=3)
    - 이 함수는 "최적으로" 접었을 때 몇 번 접어야 target 이하의 길이를 만들 수 있는지 계산합니다.
    - 만약 target이 L보다 크면 접을 필요가 없으므로, 아주 큰 값(inf)을 반환하여 후보에서 배제할 수 있도록 합니다.
    
    매개변수:
    - L: 현재의 변의 길이 (정수)
    - target: 최종적으로 원하는 길이 (정수)
    
    반환값:
    - L에서 target 이하의 길이를 만들기 위해 필요한 최소 접기 횟수 (정수)
    """
    if target > L:
        return float('inf')
    folds = 0
    current = L
    # current가 target보다 작거나 같아질 때까지, 매 접을 때마다 최대로 줄일 수 있는 방법(즉, ceil(current/2))을 적용합니다.
    while current > target:
        current = (current + 1) // 2  # ceil(current/2)를 정수 나눗셈으로 구현. 
                                    # (current+1)//2는 current가 홀수일 때 올림 효과를 냅니다.
        folds += 1
    return folds
```

### min_folds_needed 함수 설명

- **목적**:  
  종이의 한 변을 접어서 최종 길이가 `target` 이하가 되도록 만들 때, "최적"으로 접었을 경우(한 번 접을 때마다 가능한 한 많이 줄이는 경우)에 필요한 접기 횟수를 구합니다.
  
- **핵심 로직**:  
  - 현재 길이 `current`를 `L`로 시작합니다.
  - while 루프를 통해 `current`가 `target`보다 큰 동안 접기를 수행합니다.
  - 한 번 접을 때마다 가능한 최소 길이인 `(current+1)//2`로 줄입니다.
  - 접을 때마다 `folds` 값을 1씩 증가시키며, 최종적으로 접은 횟수를 반환합니다.
  
- **예시**:  
  예를 들어, `L=5`이고 `target=3`인 경우,
  - 초기 `current = 5`.
  - 첫 번째 접기: `current = (5+1)//2 = 3`. 이때 접은 횟수 `folds = 1`.
  - `current`가 이제 target(3) 이하이므로 루프를 종료하고, 결과 1을 반환합니다.

```python
def solve():
    import sys
    data = sys.stdin.read().split()
    if not data:
        return
    W = int(data[0])
    H = int(data[1])
    A = int(data[2])
    
    # 만약 A가 원래 종이의 넓이보다 크면, 접어서 만들 수 없는 경우이므로 -1 출력.
    if A > W * H:
        print(-1)
        return
    
    # 만약 원래 종이의 넓이와 A가 같다면 접을 필요가 없으므로 0을 출력.
    if A == W * H:
        print(0)
        return
    
    best = float('inf')
    found = False
    # A의 약수 쌍 (w, h)를 모두 찾습니다.
    # 약수 쌍은 최종 직사각형의 두 변의 길이를 의미하며, w * h == A를 만족해야 합니다.
    for d in range(1, int(math.isqrt(A)) + 1):
        if A % d != 0:
            continue
        e = A // d
        # 후보 1: 최종 종이 크기를 (d, e)로 만들 경우.
        if d <= W and e <= H:
            # W에서 d를, H에서 e를 만들기 위해 필요한 접기 횟수를 구합니다.
            folds_w = min_folds_needed(W, d)
            folds_h = min_folds_needed(H, e)
            candidate = folds_w + folds_h
            if candidate < best:
                best = candidate
                found = True
        # 후보 2: (e, d)인 경우 (종이를 90도 회전한 경우)
        if d != e:
            if e <= W and d <= H:
                folds_w = min_folds_needed(W, e)
                folds_h = min_folds_needed(H, d)
                candidate = folds_w + folds_h
                if candidate < best:
                    best = candidate
                    found = True
                    
    if found:
        print(best)
    else:
        print(-1)

if __name__ == '__main__':
    solve()
```

### solve 함수 설명

1. **입력 처리**  
   - `sys.stdin.read()`를 사용해 전체 입력을 읽고, 공백을 기준으로 나눈 후 `data` 리스트에 저장합니다.
   - `data`의 첫 세 개 항목을 각각 `W`, `H`, `A`로 변환합니다.
     - `W`, `H`: 원래 종이의 가로와 세로 길이.
     - `A`: 최종적으로 만들어야 하는 종이의 넓이.

2. **기본 조건 검사**  
   - 만약 `A`가 원래 종이의 넓이 `W * H`보다 크다면, 종이를 접어서 넓이를 늘릴 수 없으므로 바로 `-1`을 출력합니다.
   - 만약 `A`가 `W * H`와 같다면 이미 목표 넓이를 만족하므로 접을 필요가 없어서 `0`을 출력합니다.

3. **최종 직사각형의 후보 결정**  
   - 최종 종이의 크기는 가로 `w`와 세로 `h` (양의 정수)이며, 이들의 곱이 `A`여야 합니다.
   - `A`의 약수들을 이용하여 `(w, h)` 쌍, 즉 `w * h = A`인 모든 경우를 탐색합니다.
   - 반복문 `for d in range(1, int(math.isqrt(A)) + 1):`를 사용하여,  
     - `d`가 `A`의 약수인 경우 `e = A // d`로 대응하는 다른 약수를 구합니다.
     - 이 때, 두 가지 후보(종이 방향 고려)를 확인합니다.
     
   - **후보 1: (w, h) = (d, e)**  
     - 이 경우, 원래 종이의 가로 `W`에서 최종 가로 `d`를, 세로 `H`에서 최종 세로 `e`를 만들 수 있어야 하므로 조건 `d <= W and e <= H`를 확인합니다.
     - 조건을 만족한다면,  
       - `W`에서 `d`를 만들기 위해 필요한 접기 횟수를 `folds_w`에,
       - `H`에서 `e`를 만들기 위해 필요한 접기 횟수를 `folds_h`에 저장합니다.
     - 두 값을 더한 값이 현재 후보가 됩니다.
     
   - **후보 2: (w, h) = (e, d)**  
     - 종이 회전을 고려하여, 만약 `e <= W and d <= H`인 경우에도 동일하게 접기 횟수를 계산합니다.
     - 단, `d != e`인 경우에만 검사하는데, 이는 `d == e`일 경우 두 후보가 동일해지기 때문입니다.
     
   - 두 경우 모두 가능한 후보라면, 최종 접기 횟수의 최솟값을 `best`에 저장하고 `found` 플래그를 True로 설정합니다.

4. **최종 결과 출력**  
   - 후보를 하나라도 찾았다면 `best`에 저장된 최소 접기 횟수를 출력합니다.
   - 만약 어떤 후보도 만족하지 못하면 (즉, `found`가 False이면) `-1`을 출력합니다.

### 추가 설명

- **왜 math.isqrt를 사용하는가?**  
  `for d in range(1, int(math.isqrt(A)) + 1):` 부분에서는 `A`의 약수를 찾기 위해 \( \sqrt{A} \)까지만 검사합니다.  
  `math.isqrt(A)`는 A의 정수 제곱근을 계산합니다. 이렇게 하면 불필요한 반복을 줄여 효율적으로 약수 쌍을 구할 수 있습니다.

- **접기 연산과 정수 조건**  
  문제의 조건 중 하나는 "접은 후에도 W와 H는 정수가 되어야 한다"입니다.  
  이 때문에 한 번 접을 때마다 `(current + 1) // 2`로 계산하는데, 이는 올림 효과를 내면서 정수 결과를 보장합니다.

- **종이의 회전 고려**  
  후보를 두 가지 경우로 나눈 이유는, 최종 직사각형의 두 변 `(w, h)`에 대해 원래 종이의 가로와 세로가 반드시 일치할 필요가 없기 때문입니다.  
  즉, `(w, h)`가 `(d, e)`가 될 수도 있고, `(e, d)`가 될 수도 있습니다.  
  이 두 경우 모두 조건(`w <= W and h <= H` 혹은 `w <= H and h <= W`)을 만족해야 합니다.

\section{문제 설명}

$W \times H$ 크기의 종이가 주어집니다. 현정이가 필요한 종이의 크기는 넓이가 $A$인 종이입니다.
따라서 종이를 접어서 넓이가 $A$인 종이를 만들려고 합니다. 단, 종이를 접을 때 다음 두 조건을 만족해야 합니다:
\begin{enumerate}
    \item 접는 기준선은 직사각형의 한 변과 평행해야 합니다.
    \item 접은 후에도 가로 $W$와 세로 $H$는 정수여야 합니다.
\end{enumerate}

예를 들어, $5 \times 3$ 크기의 종이가 있을 때, 너비를 기준으로 $4$가 되는 선으로 접으면 $4 \times 3$ 크기의 종이가 되고,
또 다른 예로 높이를 기준으로 $1$이 되는 선으로 접으면 $5 \times 2$ 크기의 직사각형을 만들 수 있습니다.

\section{문제 접근 및 풀이 아이디어}

문제를 해결하기 위해, 종이를 접어서 한 변의 길이를 어떻게 줄일 수 있는지 이해해야 합니다.

\subsection*{한 변을 접는 과정}

한 변의 길이가 $L$인 직사각형에서, 접는 기준선을 길이의 $x$ ($1 \le x \le L-1$) 위치에 두면, 접은 후의 길이는 두 부분 중
큰 값인
\[
L' = \max(x,\, L - x)
\]
가 됩니다. 이때 가능한 최소 길이는 접는 기준선을 중앙에 가깝게 두었을 때로,
\[
\lceil L/2 \rceil
\]
임을 알 수 있습니다.

즉, 한 변에 대해 여러 번 접으면, 최적으로 길이를 줄였을 때의 값은
\[
f(L,k)=\underbrace{\lceil\lceil\cdots\lceil}_{k \text{번}} \frac{L}{2}\rceil\cdots/2\rceil
\]
가 되고, 원하는 최종 길이 $t$를 얻기 위해 필요한 최소 접기 횟수는
\[
f(L,k) \le t
\]
를 만족하는 최소 $k$와 같습니다.

\subsection*{전체 문제 접근}

종이 전체는 $W \times H$ 크기에서 시작하며, 최종적으로 원하는 직사각형은 가로와 세로를 각각 $w$, $h$라 할 때
\[
w \times h = A
\]
를 만족해야 합니다. 따라서 $A$의 모든 약수 쌍 $(w,h)$를 고려하여,
\begin{itemize}
    \item $W$에서 최종 가로 길이 $w$를 만들기 위한 접기 횟수,
    \item $H$에서 최종 세로 길이 $h$를 만들기 위한 접기 횟수,
\end{itemize}
를 각각 계산한 후, 두 값의 합이 최소가 되는 경우를 찾으면 됩니다.

또한, 종이의 회전이 가능하므로 $(w,h)$와 $(h,w)$ 두 경우 모두 고려해야 합니다.

\section{파이썬 코드 구현}

아래는 위의 아이디어를 구현한 파이썬 코드입니다.

\begin{lstlisting}[caption={종이 접기 문제 풀이 파이썬 코드}]
import math
import sys

def min_folds_needed(L, target):
    """
    L에서 target까지 줄이기 위해 필요한 최소 접기 횟수를 구한다.
    한 번 접으면 최대로 줄일 수 있는 길이는 ceil(L/2)이다.
    """
    if target > L:
        return float('inf')
    folds = 0
    current = L
    while current > target:
        current = (current + 1) // 2  # ceil(current/2)
        folds += 1
    return folds

def solve():
    data = sys.stdin.read().split()
    if not data:
        return
    W = int(data[0])
    H = int(data[1])
    A = int(data[2])
    
    # A가 원래 종이 넓이보다 크면 불가능.
    if A > W * H:
        print(-1)
        return
    
    # 원래 넓이가 A와 같다면 접을 필요가 없음.
    if A == W * H:
        print(0)
        return
    
    best = float('inf')
    found = False
    # A의 약수 쌍 (w, h)를 모두 찾는다.
    for d in range(1, int(math.isqrt(A)) + 1):
        if A % d != 0:
            continue
        e = A // d
        # 후보 1: (w, h) = (d, e)
        if d <= W and e <= H:
            folds_w = min_folds_needed(W, d)
            folds_h = min_folds_needed(H, e)
            candidate = folds_w + folds_h
            if candidate < best:
                best = candidate
                found = True
        # 후보 2: (w, h) = (e, d) (회전한 경우)
        if d != e:
            if e <= W and d <= H:
                folds_w = min_folds_needed(W, e)
                folds_h = min_folds_needed(H, d)
                candidate = folds_w + folds_h
                if candidate < best:
                    best = candidate
                    found = True
                    
    print(best if found else -1)

if __name__ == '__main__':
    solve()
\end{lstlisting}

\section{코드 설명}

\subsection*{min\_folds\_needed 함수}
\begin{itemize}
    \item \textbf{목적:} 한 변의 길이 $L$을, 한 번 접을 때마다 가능한 최대로 줄여서 목표 길이 $t$에 도달하는 데 필요한 최소 접기 횟수를 구한다.
    \item \textbf{로직:} 
    \begin{itemize}
        \item 초기 길이 $L$에서 시작하여, 매 접기마다 길이를 $(L+1) // 2$ (즉, $\lceil L/2 \rceil$)로 줄인다.
        \item $current > t$인 동안 반복하며, 접은 횟수를 센다.
    \end{itemize}
\end{itemize}

\subsection*{solve 함수}
\begin{enumerate}
    \item 입력으로 $W$, $H$, $A$를 읽는다.
    \item 만약 $A > W \times H$이면, 접어서 넓이를 늘릴 수 없으므로 \texttt{-1}을 출력한다.
    \item $A = W \times H$이면 이미 목표이므로 \texttt{0}을 출력한다.
    \item $A$의 약수 쌍 $(w, h)$ (즉, $w \times h = A$)를 모두 탐색한다.
    \begin{itemize}
        \item \textbf{후보 1:} $(w, h) = (d, e)$인 경우, $W \ge d$ 및 $H \ge e$이어야 한다.
        \item \textbf{후보 2:} 회전을 고려하여 $(w, h) = (e, d)$인 경우, $W \ge e$ 및 $H \ge d$이어야 한다.
    \end{itemize}
    \item 각 경우마다 \texttt{min\_folds\_needed} 함수를 사용해 필요한 접기 횟수를 계산하고, 그 합이 최소가 되는 값을 찾는다.
    \item 가능한 후보가 없으면 \texttt{-1}을, 있으면 최소 접기 횟수를 출력한다.
\end{enumerate}

최종 넓이 $A$에 대해 가능한 모든 약수 쌍을 고려하여, 각 경우에 필요한 최소 접기 횟수를 구했습니다.
