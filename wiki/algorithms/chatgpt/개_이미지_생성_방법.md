# 개 이미지 생성 방법

### ❓ 질문 (User)
사람 얼굴로 닮은 개 얼굴 만들기


process 1
사람얼굴로 닮은 개를 찾아낸다

process 2 
닮은 개의 이미지를 생성해낸다

process3 
어플리케이션을 제작한다


process 1 진행과정

10가지 동물을 target으로 하기로함.

A. 사람과 개의 얼굴의 KeyPoint를 분석하고 품종 도출하기

	A-1 직접 특징점 분석하기 

		A-1-1 CVAT로 개 얼굴의 KeyPoint를 찍는다 -> X (귀찮)

		A-1-2 개얼굴의 KeyPoint를 오토라벨링한다 -> O 
			->기존의 개 얼굴 KeyPoint 라벨링은 귀,눈,코만 학습되어있음(dog face모델사진)
			-> controlnet의 dwpose를 개조하면 개 얼굴도 라벨링을 할 수 음 하지만 사람얼굴형으로됨(컨트롤넷사진)
				A-2 결과 -> 예상대로 너무 사람얼굴형으로 뭉개져 종간 구분이 안됨(결과사진과 성범씨가한분석사진과설명추가)

 	A-2 언어모델(llama,GPT)에게 추론 부탁하기
		
		A-2-1 프롬프트로 직접 질문해본다 
			-> 사람 얼굴의 특징점중 가장 도드라지는 부분에 우리의 target별 특징점을 mapping한 결과와 매칭(GPT가도출한알고리즘사진)
		
		A-2-2 개 얼굴의 KeyPoint를 잘 학습된 언어모델에게 물어본다 ->X
			-> 결과 GPT4는 없다고 하고 Llama2는 대답을 해주나 할루시네이션 현상이 있으므로 
			타당성이 떨어져 사용불가(대답을해주는라마와, 말을번복하는라마사진)

	대안 1. 
		A-2-1의 알고리즘 사용 

	대안 2. 다른 분석을 더 해보던가(강호용선생님: 리그레이션해보세용) , 다른방법 탐구

B. 개 품종별 얼굴 감정추출과 사람 얼굴 감정 추출 유사도 분석
	-> 탐구중

C. 이미지에서 떠오르는 느낌을 CLIP분석 
	-> 탐구중인데 디퓨전 내부 clip의 기능이 꽤 강해서 
	-> 언어모델을 통한 묘사 디퓨전 프롬프트 입력도 생각중

A+B+C의 결과를 종합분석 하려고 했었음 




process2 진행과정

GAN으로 진행하려고 GAN 모델을 찾아보던 중 

특징점을 활용하여 생성하는 GAN 모델을 탐구하다

ControlNet이라는 도구가 있는 Stable Diffusion을 발견해 (스테이블 디퓨전사진)

5일간 하이퍼 파라미터와 성능 TEST를 했음. (성능테스트 했던것들 사진)

도중에 controlnet의 강도가 높을수록 개 얼굴 생성이 잘 안 됨을 느끼고 학습을 계획함 (머리털붙은 생성사진이나 깨진사진)

현재 target 종의 이미지를 종당 50~100여장 정도 학습(700장가량 V100 200epoch 5분정도 걸림)(걸리는 시간 찍어 올리것습니다,,)

(학습과정사진도 ..)

모델의 생성정도를 보면서 학습 방향을 조절 할 예정



process3 진행과정

웹 어플리케이션을 제작할 예정

초기에는 gradio로 모델을 띄우고 성능 TEST를 하고 

구동에 너무 오래걸리거나 프로젝트 시간이 남으면 서버에 띄워 gradio로 배포할 예정

시간이 더 남으면 다른 python웹프레임워크와 JS프레임워크로 예쁘게 꾸며 볼 예정  

-> 발표를위해 8월 31일 test 모델 배포해볼예정이였으나.. 다른 해결할 상황이 많아져서 미룸





역할분담 누구누구누구누구

-> 알아서 잘 나눠봅시다

### 💡 답변 (Assistant)
물론, 여러 프로세스와 역할분담을 도식화해보겠습니다.

### 프로세스 1: 사람 얼굴로 닮은 개 얼굴 만들기
1. **사람얼굴로 닮은 개 찾기**
    - A-1: 사람과 개의 얼굴 KeyPoint 분석
        - A-1-1: CVAT로 개 얼굴 KeyPoint 직접 찍기
        - A-1-2: 개 얼굴 KeyPoint를 오토라벨링하기 (controlnet 수정)
    - A-2: 언어모델 (llama, GPT)을 활용한 추론
        - A-2-1: 프롬프트로 직접 질문하여 알고리즘 도출
        - A-2-2: 다른 학습된 언어모델에게 물어보기 (Llama2)
    - 대안 1: A-2-1의 알고리즘 사용
    - 대안 2: 다른 분석 방법 시도

2. **개 품종별 얼굴 감정추출과 사람 얼굴 감정 추출 유사도 분석**
    - 탐구 중

3. **이미지에서 떠오르는 느낌을 CLIP 분석**
    - 탐구 중, 언어모델과 디퓨전 프롬프트 사용 고려

4. **A+B+C의 결과를 종합분석**

### 프로세스 2: 닮은 개의 이미지 생성
1. **GAN 모델 탐구**
    - 특징점 활용한 생성 모델 탐구
    - Stable Diffusion의 ControlNet 도구 발견

2. **하이퍼파라미터 튜닝 및 성능 테스트**
    - ControlNet의 강도 조절과 학습 계획 수립
    - Target 종 별 이미지 학습

### 프로세스 3: 어플리케이션 제작
1. **웹 어플리케이션 개발**
    - 초기에는 gradio를 사용하여 모델 띄우기
    - 성능 테스트 진행

2. **서버 배포**
    - 성능이나 속도 문제가 발생하면 서버에 배포 고려
    - 다른 Python 웹프레임워크 및 JS 프레임워크 사용 검토

### 역할분담
- 프로세스 1과 관련된 역할:
    - A-1-2: 개 얼굴 KeyPoint 오토라벨링 담당
    - A-2-1: 언어모델 프롬프트로 질문하여 알고리즘 도출
    - 대안 1: A-2-1의 알고리즘 채택
- 프로세스 2와 관련된 역할:
    - GAN 모델 탐구 및 학습
    - 하이퍼파라미터 튜닝 및 성능 테스트 수행
- 프로세스 3과 관련된 역할:
    - 웹 어플리케이션 개발 및 gradio를 통한 모델 띄우기
    - 서버 배포 및 확장적인 개발

이러한 프로세스와 역할을 토대로 팀원들 간의 업무 분담을 조정할 수 있을 것입니다.

강아지 품종 별로 얼굴만 보고 구분할 수 있어?

### 💡 답변 (Assistant)
강아지의 품종을 얼굴만 보고 정확하게 구분하는 것은 어렵습니다. 몇몇 품종은 특정 특징들이 뚜렷해서 상대적으로 더 쉽게 식별할 수 있지만, 대부분의 품종은 비슷한 특징들을 가지고 있어서 시각적으로 얼굴만 보고서 정확하게 판단하기 어렵습니다.

품종 구분에 도움이 되는 몇 가지 특징은 다음과 같습니다:

1. **크기**: 강아지의 크기는 품종을 구분하는데 중요한 특징 중 하나입니다. 작은 강아지와 대형 강아지는 시각적으로 구분하기 쉽습니다.

2. **털**: 품종마다 털의 길이, 색상, 패턴이 다를 수 있습니다. 털의 특징은 품종을 구분하는데 도움이 될 수 있습니다.

3. **얼굴 형태**: 강아지의 얼굴 형태는 품종마다 다를 수 있습니다. 예를 들어, 불독은 다른 품종에 비해 주먹 같은 얼굴 형태를 가지고 있습니다.

4. **귀 모양**: 강아지의 귀 모양도 품종에 따라 다를 수 있습니다. 일부 품종은 귀가 짧고 평평하며, 다른 품종은 길고 특이한 귀 모양을 가지고 있을 수 있습니다.

5. **눈 모양과 색상**: 눈의 모양과 색상도 품종을 식별하는 데 도움이 될 수 있습니다.

그러나 이러한 특징들은 절대적인 규칙이 아니며, 혼합된 품종인 경우에는 훨씬 더 어려울 수 있습니다. 따라서 정확한 품종 식별을 위해서는 강아지의 품종 인증서나 DNA 테스트와 같은 공식적인 방법을 사용해야 합니다.

### 💡 답변 (Assistant)
주어진 "Scale of Points"는 강아지의 외모와 구조를 평가하기 위한 지표입니다. 이러한 점수 체계는 강아지의 특정 품종에 대한 표준을 설정하고, 전시나 경쟁에서 평가할 때 사용됩니다. 주어진 점수 체계를 간략히 설명하겠습니다:

**머리 (Head):** 25점
- Skull (두개골): 5점
- Ears (귀): 10점
- Eyes (눈): 5점
- Muzzle (머즐, 입부분): 5점

**몸통 (Body):** 35점
- Neck (목): 5점
- Chest and shoulders (가슴과 어깨): 15점
- Back, loin and ribs (등, 허리, 갈비): 15점

**움직임과 다리 (Running Gear):** 30점
- Forelegs (전다리): 10점
- Hips, thighs and hind legs (엉덩이, 허벅지, 뒷다리): 10점
- Feet (발): 10점

**털과 꼬리 (Coat and Stern):** 10점
- Coat (털): 5점
- Stern (꼬리): 5점

이러한 각 부분은 해당 부위의 특징과 품질을 평가하고 강아지의 외모와 구조를 정량화하는 데 사용됩니다. 각 항목에 할당된 점수를 합산하여 총점 100점 중에서 개체의 외모와 품질을 평가하게 됩니다. 이러한 점수 체계는 강아지 품종 표준을 유지하고 개체 간의 평가를 일관되게 하기 위해 사용됩니다.
