# 최대 이익 알고리즘 설명

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 코드는 주식 거래 문제(예, LeetCode의 "Best Time to Buy and Sell Stock II")에서 최대 이익을 구하는 알고리즘입니다. 주요 아이디어는 가격이 상승하는 구간마다 이익을 누적하여 전체 이익을 구하는 것입니다.

### 알고리즘 설명

1. **초기 설정**  
   - `current` 변수는 리스트의 첫 번째 가격으로 초기화됩니다.
   - `res` 변수는 총 이익을 저장하는 변수로 0으로 초기화됩니다.

2. **가격 리스트 순회**  
   - 리스트의 각 가격을 순회하면서 이전 가격(`current`)과 비교합니다.
   - 만약 **현재 가격이 이전 가격보다 높다면**, 상승 구간이므로 그 차이(`price - current`)를 이익(`res`)에 추가합니다.
   - 매 반복마다 `current`를 현재의 `price`로 업데이트하여 다음 가격과의 비교에 사용합니다.

3. **최종 결과 반환**  
   - 반복이 끝나면 누적된 이익(`res`)을 반환합니다.

### 핵심 아이디어

- **연속된 상승 구간 활용:**  
  매번 가격이 상승할 때마다 이익을 누적함으로써, 여러 번 거래를 수행하는 것과 동일한 효과를 냅니다. 예를 들어, 가격이 [1, 3, 2, 5]라면, 1→3에서 2의 이익을 보고, 2→5에서 3의 이익을 보는 식으로 총 5의 이익을 얻게 됩니다.

- **최적의 거래 전략:**  
  이 알고리즘은 "낮을 때 사고 높을 때 판다"라는 단순 전략을 사용하여, 주어진 가격 리스트에서 가능한 모든 이익 기회를 잡아 최대 이익을 계산합니다.

이와 같이, 코드 전체적으로 리스트의 각 구간을 확인하여 상승하는 부분에서만 차익을 계산함으로써 최대 이익을 효율적으로 구하는 방법을 사용하고 있습니다.

---

### ❓ 질문 (User)
```
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        current = prices[0]
        res = 0

        for price in prices :
            if current < price :
                res += price - current
            current = price
            

        return res
```
이 코드의 알고리즘을 설명해줘

### 💡 답변 (Assistant)
이 알고리즘은 **탐욕 알고리즘 (Greedy Algorithm)** 으로 분류할 수 있습니다.

### 이유

- **로컬 최적해 선택:**  
  각 단계에서 이전 가격과 비교하여 가격이 상승한 경우 바로 이익을 계산합니다. 이는 전체적인 최대 이익을 보장하기 위해 각 순간마다 최적이라고 판단되는 선택(즉, 가격 상승분을 즉시 수익으로 반영)을 하는 방식입니다.

- **국소적 결정이 전역 해에 기여:**  
  매번 인접한 가격 차이를 누적함으로써, 전체 기간 동안의 최적의 거래 전략(여러 번의 매매)을 구현합니다. 이는 한 번의 전역적 최적해 계산 대신, 국소적으로 최적이라고 생각되는 선택들을 모아서 전체적인 최적해를 구하는 탐욕 알고리즘의 전형적인 접근법입니다.

이처럼, 이 알고리즘은 매 순간 "지금 이익을 취하자"라는 단순하지만 효과적인 결정을 통해 전체 문제의 최적해를 도출하는 탐욕 알고리즘의 한 예라고 할 수 있습니다.
