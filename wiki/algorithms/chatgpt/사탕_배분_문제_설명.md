## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
n명의 아이들이 한 줄로 서 있습니다. 각 아이에게는 정수 배열 ratings에 나타난 등급이 할당되어 있습니다.

아이들에게 사탕을 줄 때 다음 조건을 만족해야 합니다:

- 각 아이는 최소 한 개의 사탕을 받아야 합니다.
- 등급이 높은 아이는 이웃한 아이보다 더 많은 사탕을 받아야 합니다.

아이들에게 줄 사탕의 최소 총 개수를 구하는 문제입니다.

**예제 1:**

- 입력: ratings = [1, 0, 2]
- 출력: 5  
  설명: 첫 번째, 두 번째, 세 번째 아이에게 각각 2, 1, 2개의 사탕을 줄 수 있습니다.

**예제 2:**

- 입력: ratings = [1, 2, 2]
- 출력: 4  
  설명: 첫 번째, 두 번째, 세 번째 아이에게 각각 1, 2, 1개의 사탕을 줄 수 있습니다.  
  세 번째 아이는 위의 조건을 만족하기 때문에 1개의 사탕만 받습니다.

---

### ❓ 질문 (User)
There are n children standing in a line. Each child is assigned a rating value given in the integer array ratings.

You are giving candies to these children subjected to the following requirements:

Each child must have at least one candy.
Children with a higher rating get more candies than their neighbors.
Return the minimum number of candies you need to have to distribute the candies to the children.

 

Example 1:

Input: ratings = [1,0,2]
Output: 5
Explanation: You can allocate to the first, second and third child with 2, 1, 2 candies respectively.
Example 2:

Input: ratings = [1,2,2]
Output: 4
Explanation: You can allocate to the first, second and third child with 1, 2, 1 candies respectively.
The third child gets 1 candy because it satisfies the above two conditions.
 

Constraints:

n == ratings.length
1 <= n <= 2 * 104
0 <= ratings[i] <= 2 * 104

이 문제를 한국어로 번역해줘

### 💡 답변 (Assistant)
이 문제는 그리디(greedy) 알고리즘을 사용하여 해결할 수 있습니다. 기본적인 아이디어는 두 방향(왼쪽→오른쪽, 오른쪽→왼쪽)으로 배열을 순회하면서, 각 조건을 만족하도록 사탕 개수를 조정하는 것입니다. 자세한 접근 방법은 다음과 같습니다:

1. **왼쪽에서 오른쪽으로 순회**  
   - 각 아이가 최소 1개의 사탕을 받도록 초기값을 설정합니다.
   - 왼쪽 이웃과 비교하여, 만약 현재 아이의 등급이 왼쪽 아이보다 높다면, 현재 아이가 받는 사탕의 수는 왼쪽 아이의 사탕 수보다 1개 더 많아야 합니다.
   - 이를 통해 왼쪽 조건(왼쪽 이웃보다 높은 등급이면 더 많은 사탕)을 만족시킵니다.

2. **오른쪽에서 왼쪽으로 순회**  
   - 이번에는 오른쪽 이웃과 비교합니다.
   - 만약 현재 아이의 등급이 오른쪽 아이보다 높으면서, 현재까지 할당된 사탕의 수가 오른쪽 아이보다 많지 않다면, 오른쪽 아이의 사탕 수보다 1개 더 많도록 업데이트합니다.
   - 이 단계는 오른쪽 조건(오른쪽 이웃보다 높은 등급이면 더 많은 사탕)을 만족시킵니다.

3. **최종 결과 계산**  
   - 두 번의 순회를 통해 각 아이가 받을 사탕 수를 조정한 후, 모든 사탕 수를 더하면 최소로 필요한 사탕의 총 개수를 구할 수 있습니다.

이러한 두 번의 순회 방식은 각 조건을 모두 만족시키면서도 최소 사탕 수를 보장할 수 있는 효율적인 방법입니다.

### 💡 답변 (Assistant)
다음은 파이썬 코드로 구현한 예제입니다:

```python
def candy(ratings):
    n = len(ratings)
    candies = [1] * n  # 각 아이에게 최소 1개의 사탕을 할당

    # 왼쪽에서 오른쪽으로 순회하며 조건 만족 (왼쪽 이웃보다 높으면 사탕 개수 증가)
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1

    # 오른쪽에서 왼쪽으로 순회하며 조건 만족 (오른쪽 이웃보다 높으면 사탕 개수 조정)
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)

    return sum(candies)


# 테스트 예제
ratings1 = [1, 0, 2]
ratings2 = [1, 2, 2]

print(candy(ratings1))  # 출력: 5
print(candy(ratings2))  # 출력: 4
```

이 코드는 먼저 왼쪽→오른쪽, 그리고 오른쪽→왼쪽으로 배열을 순회하여 각 조건을 만족하도록 사탕 개수를 조정한 후, 모든 사탕의 총합을 반환합니다.
