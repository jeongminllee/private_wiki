---

### 🔍 문제 핵심

이항계수 \( \binom{N}{K} \) 는 다음과 같이 정의됩니다:

\[
\binom{N}{K} = \frac{N!}{K!(N-K)!}
\]

하지만 문제는 수가 **4,000,000까지 커지므로**, 직접 나눗셈을 하면 **오버플로우** 혹은 **정확도 손실**이 생깁니다.

---

### 🧠 핵심 아이디어

- 이 문제는 **모듈러 연산**과 **페르마의 소정리**를 활용한 **모듈러 역원** 계산이 핵심입니다.

---

### 🧩 필요한 구성 요소

1. **팩토리얼을 미리 계산**해놓는다.  
   시간복잡도: \( O(N) \)

2. **모듈러 역원 계산**  
   페르마의 소정리 사용:  
   \( a^{-1} \equiv a^{MOD - 2} \mod MOD \)  
   \( \Rightarrow \frac{1}{K!} \equiv (K!)^{MOD - 2} \mod MOD \)

3. **이항계수 계산식**  
   \[
   \binom{N}{K} \mod MOD = \frac{fact[N]}{fact[K] \cdot fact[N-K]} \mod MOD = fact[N] \cdot (fact[K]^{-1} \cdot fact[N-K]^{-1}) \mod MOD
   \]

---

### 🧮 사용해야 할 주요 값

- `MOD = 1_000_000_007` (소수이므로 페르마의 소정리 적용 가능)
- 팩토리얼 리스트: `fact[i] = i! % MOD`
- 역팩토리얼 리스트: `inv_fact[i] = (i!)^{-1} % MOD`

---

### ⛏ 힌트 요약

- 팩토리얼을 `N`까지 미리 계산한다.
- 모듈러 역원은 **거듭제곱**을 통해 구한다 (`pow(a, MOD-2, MOD)`).
- 시간 복잡도는 전처리 \( O(N) \), 계산은 \( O(1) \)

### ✅ 이항 계수 계산 코드 스켈레톤

```python
MOD = 1_000_000_007

def precompute_factorials(n):
    """팩토리얼과 역팩토리얼을 미리 계산"""
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)

    # 팩토리얼 계산
    for i in range(2, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    # 역팩토리얼 계산 (MOD - 2를 거듭제곱)
    inv_fact[n] = pow(fact[n], MOD - 2, MOD)  # 페르마의 소정리

    for i in range(n - 1, 0, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

    return fact, inv_fact

def binomial_coefficient(n, k, fact, inv_fact):
    """이항계수 계산"""
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

# 입력 처리
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

# 전처리
fact, inv_fact = precompute_factorials(n)

# 결과 출력
print(binomial_coefficient(n, k, fact, inv_fact))
```

---

### 🔍 요약

- `precompute_factorials(n)` : O(n)으로 팩토리얼과 역팩토리얼을 모두 구함
- `binomial_coefficient(n, k, fact, inv_fact)` : O(1)로 이항계수 구함
- 전체 시간 복잡도 : **O(n)** (입력 한 번, 계산 한 번)
