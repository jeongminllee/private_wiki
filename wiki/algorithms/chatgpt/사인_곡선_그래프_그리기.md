## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
다음은 한글이 깨지지 않도록 설정된 사인 곡선 그래프를 그리는 코드입니다. 아래 코드를 실행하면 `사인 함수`라는 레이블이 붙은 사인 곡선 그래프가 출력됩니다.

```python
# Install and import necessary libraries
!pip install /mnt/data/koreanize_matplotlib-0.1.1-py3-none-any.whl
import matplotlib.pyplot as plt
import numpy as np
import koreanize_matplotlib  # For Korean character support

# 데이터 준비
x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

# 그래프 그리기
plt.plot(x, y, label='사인 함수', color='blue')

# 그래프 꾸미기
plt.title('사인 곡선 그래프')
plt.xlabel('x 값')
plt.ylabel('사인 값')
plt.legend()
plt.grid(True)

# 그래프 출력
plt.show()
```

이 코드는:

- `koreanize_matplotlib`을 사용해 한글이 깨지지 않도록 설정하고,
- 0부터 \(2\pi\)까지의 x값에 대해 사인 곡선을 그립니다.

원하는 스타일이나 범위가 있다면 알려주세요.
