경사하강법(Gradient Descent)에서 말하는 **파라미터(parameter)**는 모델이 학습을 통해 조정하는 값들을 뜻합니다. 보통은 **가중치(weight)**와 **편향(bias)**을 통틀어 파라미터라고 부릅니다.

---

### 예시: 선형 함수 \( y = ax + b \)

- **\(a\)** → 가중치(Weight)  
  입력 \(x\)가 출력 \(y\)에 얼마나 영향을 미치는지를 결정하는 값입니다.  

- **\(b\)** → 편향(Bias)  
  \(x=0\)일 때 \(y\)가 얼마가 되는지를 정해주는 상수항입니다.  

---

### 결론
- \(a\)와 \(b\) **둘 다 파라미터(parameter)** 입니다.  
- 그중 \(a\)는 **웨이트(weight)**, \(b\)는 **편향(bias)** 이라고 부릅니다.  
- 경사하강법은 이 두 파라미터 \(a, b\)를 오차(손실 함수, loss)를 최소화하도록 계속 업데이트하는 과정입니다.

---

## 1. 오차역전파(Backpropagation)란?
- 인공신경망(Artificial Neural Network, ANN)을 학습시키는 핵심 알고리즘입니다.  
- **순전파(forward propagation)** 과정에서 입력 → 은닉층 → 출력층으로 신호가 전달되고, 예측값과 실제값의 차이를 손실(loss)로 계산합니다.  
- 이후 **오차역전파(backpropagation)** 과정에서는 **출력층에서부터 입력층 방향으로** 오차를 전달하면서, 각 파라미터(가중치와 편향)에 대해 손실이 얼마나 영향을 받았는지를 계산(미분)합니다.  
- 최종적으로 경사하강법(Gradient Descent)으로 파라미터를 업데이트합니다.

---

## 2. 핵심 개념
오차역전파는 **연쇄 법칙(Chain Rule)** 을 활용합니다.  
- 손실 \(L\)이 있을 때, 특정 가중치 \(w\)에 대한 기울기(gradient)는 다음처럼 계산합니다:

\[
\frac{\partial L}{\partial w}
= \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial z} \cdot \frac{\partial z}{\partial w}
\]

즉, **출력층에서부터 역으로 곱해가며 미분**합니다.

---

## 3. 간단한 예시
신경망 구조:
\[
x \xrightarrow{w} z \xrightarrow{\sigma} y \quad \Rightarrow \quad L = (y - t)^2
\]

- 입력: \(x\)  
- 가중치: \(w\)  
- 활성화 함수: \(\sigma(z)\)  
- 출력: \(y\)  
- 목표값: \(t\)  
- 손실: \(L = (y - t)^2\)

### 순전파
1. \(z = w \cdot x\)  
2. \(y = \sigma(z)\)  
3. \(L = (y - t)^2\)  

### 역전파
1. \(\frac{\partial L}{\partial y} = 2(y - t)\)  
2. \(\frac{\partial y}{\partial z} = \sigma'(z)\)  
3. \(\frac{\partial z}{\partial w} = x\)  
4. 따라서,

\[
\frac{\partial L}{\partial w} = 2(y - t) \cdot \sigma'(z) \cdot x
\]

이 기울기를 이용해 경사하강법으로 \(w\)를 업데이트합니다:

\[
w \leftarrow w - \eta \frac{\partial L}{\partial w}
\]

(\(\eta\): 학습률, learning rate)

---

## 4. 직관적으로 이해하기
- 순전파: 입력 데이터를 흘려보내 예측값을 계산  
- 손실 계산: 실제값과 비교해 “얼마나 틀렸는지” 확인  
- 역전파: 틀린 정도를 가중치/편향에게 “책임 분배”  
- 업데이트: 각 파라미터가 조금씩 수정됨 → 점점 더 정답에 가까워짐  

---

## 5. 핵심 포인트
- 오차역전파는 **체인룰을 이용해 기울기를 계산**하는 과정  
- 실제 학습은 경사하강법(또는 변형된 최적화 알고리즘, Adam 등)으로 파라미터를 업데이트하면서 진행  
- 덕분에 심층 신경망(Deep Neural Network) 같은 복잡한 구조도 학습 가능

## 1. MLP (Multilayer Perceptron, 다층 퍼셉트론)
- **구조**: 입력층(Input layer) – 은닉층(Hidden layers) – 출력층(Output layer)  
- 각 층은 **퍼셉트론(Perceptron, 노드)** 으로 구성됩니다.  
- 층과 층은 **완전연결(fully-connected, dense)** 되어 있어, 이전 층의 모든 뉴런이 다음 층의 모든 뉴런과 연결됩니다.  
- 활성화 함수(activation function, 예: ReLU, sigmoid, tanh)를 사용해 비선형성을 추가합니다.  

👉 특징:  
- 입력 데이터 → 선형변환(가중치·편향) → 활성화 함수 → 출력  
- 여러 은닉층을 쌓아올리면 더 복잡한 패턴을 학습 가능  
- 가장 기본적인 형태의 **피드포워드 신경망(feedforward neural network)**

---

## 2. DNN (Deep Neural Network, 심층 신경망)
- **정의**: 은닉층이 여러 개인 신경망을 총칭하는 용어입니다.  
- 즉, MLP 구조에서 **은닉층을 깊게 쌓아올린 형태**가 DNN입니다.  
- 보통 "Deep"이라고 하면 은닉층이 2~3개 이상인 경우를 가리킵니다.  

👉 예:  
- 1~2개의 은닉층 → MLP라고 부를 수도 있음  
- 은닉층이 많아지면 → DNN이라고 부르며, 사실상 DNN은 "깊은 MLP"라고 생각하면 됩니다.  

---

## 3. 관계
- **MLP ⊂ DNN**  
  - MLP는 특정 구조(완전연결 기반)의 신경망  
  - DNN은 깊은 신경망을 지칭하는 일반적인 표현  
- 따라서, “깊은 MLP = DNN”이라고 할 수 있습니다.  

---

## 4. 간단한 비교 예시
| 구분 | MLP | DNN |
|------|-----|-----|
| 의미 | 다층 퍼셉트론 (완전연결층 기반 신경망) | 은닉층이 여러 개인 신경망 (깊은 신경망) |
| 층 수 | 은닉층이 1~2개여도 MLP라 부름 | 은닉층이 많으면 보통 DNN이라 부름 |
| 관계 | 특정 구조 모델 | 더 포괄적인 개념 (MLP 포함) |

---

## 5. 직관적으로 요약
- MLP = **완전연결층 신경망의 구조적 이름**  
- DNN = **은닉층이 깊은 신경망의 통칭**  
- 즉, **MLP는 DNN의 한 종류**

# DNN이란?
- **정의**: 은닉층이 여러 개인 신경망의 총칭. 보통 **완전연결층(=Dense/Linear)** 을 여러 층 쌓은 모델을 말합니다.
- **수식(한 층)**:  
  \[
  \mathbf{h}^{(l)}=\phi\!\left(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)}+\mathbf{b}^{(l)}\right)
  \]
  - \(\mathbf{W}^{(l)}\): 가중치(파라미터), \(\mathbf{b}^{(l)}\): 편향(파라미터)  
  - \(\phi\): 활성화 함수(ReLU, GELU, SiLU 등)  
  - 입력 \(\mathbf{h}^{(0)}=\mathbf{x}\), 마지막 \(\mathbf{h}^{(L)}\)가 출력

# 왜 “깊이”가 중요한가?
- **표현력**: 깊이는 복잡한 비선형 함수를 **적은 파라미터로 효율적으로** 표현하게 해줍니다. (폭만 키우는 것보다 깊이가 더 효율적인 경우 다수)
- **보편근사정리**: 얕은 네트도 충분히 넓다면 임의의 연속함수를 근사할 수 있지만, **실무에서는 깊이가 학습 효율·일반화에 유리**한 경우가 많습니다.

# 학습(Training) 파이프라인
1. **순전파**: 입력 → 층 통과 → 예측 생성  
2. **손실 계산**: 예측 vs 정답 (예: 회귀=MSE, 이진 분류=BCE, 다중 분류=CrossEntropy)  
3. **역전파**: 체인룰로 각 파라미터의 기울기 계산  
4. **최적화**: SGD/AdamW 등으로 파라미터 업데이트

# 핵심 구성요소 & 베스트 프랙티스
## 1) 활성화 함수(Activation)
- **ReLU**: 빠르고 안정적. 단, 음수 영역에서 **죽은 ReLU** 가능  
- **LeakyReLU/ParametricReLU**: 죽은 ReLU 완화  
- **GELU/SiLU(Swish)**: 부드러움·성능이 좋은 편(요즘 자주 사용)

## 2) 가중치 초기화
- **Xavier(Glorot)**: \(\mathrm{Var}(W)=\frac{2}{\text{fan\_in}+\text{fan\_out}}\) — tanh/sigmoid 계열에 적합  
- **He(Kaiming)**: \(\mathrm{Var}(W)=\frac{2}{\text{fan\_in}}\) — ReLU 계열에 적합  
- 잘못된 초기화는 **폭주/소실**을 유발 → 학습 불안정

## 3) 정규화(Normalization)
- **BatchNorm**: 배치 통계로 정규화, 가속·안정화 효과. 완전연결에도 사용 가능  
- **LayerNorm**: 시퀀스/변동 배치 크기에 강함(트랜스포머에서 표준)
- 정규화는 **학습률을 더 크게** 가져가게 해주고, **기울기 흐름**을 안정화

## 4) 잔차 연결(Residual / Skip)
- \(\mathbf{y}=\mathbf{x}+F(\mathbf{x})\)  
- **기울기 소실 문제를 크게 완화**. 깊은 네트 안정화의 핵심 아이디어(ResNet 이후 표준)

## 5) 규제(Regularization)
- **Weight Decay(L2)**: 과적합 억제. AdamW(Decoupled) 권장  
- **Dropout**: 뉴런 무작위 끄기(훈련 시만). 과적합 완화  
- **Early Stopping**: 검증 손실 상승 시 중단  
- **데이터 증강/Label Smoothing**: 일반화 향상(특히 비전/언어 태스크)

## 6) 최적화(Optimization)
- **SGD + Momentum/Nesterov**: 튼튼한 기본기  
- **Adam/AdamW**: 빠른 수렴, 하이퍼파라미터 튜닝 쉬움(실무 기본값으로 흔함)  
- **학습률 스케줄**: Cosine, Step, Warmup 등  
- **Gradient Clipping**: 폭주 방지(특히 RNN/길이가 긴 그래프)

## 7) 하이퍼파라미터 감
- **은닉층 수**: 2~6부터 시작(탭/소규모 데이터), 과적합·시간 고려해 조절  
- **은닉 너비**: 입력 차원×(2~8) 정도로 시작, 검증 성능으로 조정  
- **배치크기**: 32~512 범위에서 리소스·일반화 균형  
- **학습률**: AdamW 기준 \(1\mathrm{e}{-3}\) 전후 시작, 스케줄로 조정

# 분류·회귀 실무 팁
- **손실함수 선택**  
  - 회귀: MSE, MAE(이상치 강건)  
  - 이진: BCEWithLogitsLoss (시그모이드+BCE 결합)  
  - 다중: CrossEntropyLoss (소프트맥스+NLL 결합)  
  - 클래스 불균형: 클래스 가중, Focal Loss 고려
- **출력층**  
  - 회귀: 활성화 없음(또는 목적에 맞는 제한)  
  - 이진: 로짓 출력(훈련 시 시그모이드 포함된 손실 사용)  
  - 다중: 로짓 출력(훈련 시 CrossEntropyLoss가 내부에서 소프트맥스 처리)

# 데이터/도메인 관점
- **탭(Tabular) 데이터**: 소규모·설명변수 위주면 **GBDT(XGBoost/LightGBM)** 가 DNN보다 강한 경우 많음. 대규모·교차특성 많으면 DNN이 경쟁력.  
- **고차원/비정형(이미지·오디오·텍스트)**: 보통 CNN/Transformer가 더 적합하지만, **DNN(MLP) 블록**은 여전히 핵심 구성요소로 사용(예: ViT의 MLP 헤드, Recommender의 MLP 타워 등).

# 흔한 실패/디버깅 포인트
- **기울기 소실/폭주**: 초기화·정규화·잔차 연결 도입  
- **과적합**: 더 많은 데이터, 규제 강화(Dropout/Weight Decay), Early Stopping  
- **학습 멈춤(plateau)**: 학습률 스케줄, 최적화기 변경, 배치크기 조정  
- **불안정한 손실**: 학습률 과대, 정규화 누락, 데이터 스케일링 문제 체크  
- **데이터 누수/분포변화**: 전처리 파이프라인의 훈련/검증 분리 철저

# 아주 간단한 PyTorch 예시 (다중분류)
```python
import torch
import torch.nn as nn
import torch.optim as optim

class DeepMLP(nn.Module):
    def __init__(self, in_dim, hidden=[256, 256], out_dim=10, p_drop=0.2):
        super().__init__()
        layers = []
        d = in_dim
        for h in hidden:
            layers += [
                nn.Linear(d, h),
                nn.ReLU(inplace=True),         # 활성화
                nn.Dropout(p_drop),            # 규제
                nn.LayerNorm(h),               # 정규화(배치 작은 경우에 유리)
            ]
            d = h
        self.backbone = nn.Sequential(*layers)
        self.head = nn.Linear(d, out_dim)      # 로짓 출력 (CrossEntropyLoss 사용)

        # Kaiming 초기화(ReLU용)
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.kaiming_normal_(m.weight, nonlinearity='relu')
                nn.init.zeros_(m.bias)

    def forward(self, x):
        x = self.backbone(x)
        return self.head(x)  # 로짓

# dummy training loop
model = DeepMLP(in_dim=100, hidden=[256,256,256], out_dim=5)
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

for epoch in range(10):
    model.train()
    # X: [batch, 100], y: [batch] with class ids 0..4
    X = torch.randn(64, 100)
    y = torch.randint(0, 5, (64,))
    logits = model(X)
    loss = criterion(logits, y)

    optimizer.zero_grad()
    loss.backward()                # 역전파
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 안정화(선택)
    optimizer.step()

    # 평가/스케줄 등은 생략
```

# 요약
- **DNN = 은닉층이 여러 개인 신경망의 총칭**(깊은 MLP라고 생각해도 무방).
- 좋은 DNN은 **적절한 활성화·초기화·정규화·잔차 연결·규제·최적화**가 조화롭게 세팅됩니다.
- 데이터 특성(크기·종류·불균형·잡음)에 맞는 **손실/아키텍처/하이퍼파라미터** 선택이 성능을 좌우합니다.

원하시면 **탭ular 분류/회귀** 또는 **특정 데이터셋** 기준으로, **구체 하이퍼파라미터 추천과 튜닝 절차(학습률 찾기, 스케줄, 배치크기 스윕, 규제 강도 스윕)** 도 바로 정리해 드릴게요.

**Word2Vec**은 자연어처리(NLP)에서 아주 유명한 단어 임베딩(embedding) 기법이에요. 단어를 벡터 공간에 매핑해서 **단어의 의미적 유사성**을 수치적으로 다루게 해줍니다.  

---

# 1. Word2Vec이란?
- 구글(2013, Mikolov et al.)에서 발표한 단어 임베딩 모델  
- **목표**: “비슷한 맥락에서 쓰이는 단어는 비슷한 벡터로 표현되도록 학습”  
- 결과: 단어 → 고차원 원-핫(one-hot) 벡터에서, **저차원 연속 벡터**로 변환  
- 이 벡터 공간에서 단어 간의 **의미적/문법적 관계**가 나타납니다.  

예:  
\[
\text{vector}("king") - \text{vector}("man") + \text{vector}("woman") \approx \text{vector}("queen")
\]

---

# 2. 학습 아이디어
Word2Vec은 **주변 단어(context)를 예측하는 방식**으로 학습합니다.  
- “단어 의미는 주변 단어에 의해 정의된다”(Distributional Hypothesis)라는 전제를 따름.

두 가지 주요 모델이 있습니다:

### (1) CBOW (Continuous Bag of Words)
- 주변 단어(윈도우 context) → 중앙 단어 예측  
- 예: `the cat ___ on the mat` → 빈칸 단어 `sits` 예측  

### (2) Skip-gram
- 중앙 단어 → 주변 단어 예측  
- 예: `sits` → 주변 단어(`the`, `cat`, `on`, `mat`) 예측  

👉 Skip-gram은 희소 데이터(rare words) 학습에 더 강력, CBOW는 학습 속도가 빠름.  

---

# 3. 구조 (Skip-gram 기준)
1. 입력 단어를 원-핫 벡터로 표현 (\(V\): 어휘 크기)  
2. 입력층 → **투사행렬(embedding matrix, W)** 곱 → 저차원 벡터(임베딩)  
3. 은닉층(embedding vector)을 출력층(softmax)로 연결  
4. 출력층에서 context word 확률 분포 예측  
5. 실제 주변 단어와 비교 → 오차 역전파 → 임베딩 벡터 갱신  

---

# 4. 효율 개선 기법
Word2Vec은 어휘 크기 \(V\)가 크면 softmax 계산이 너무 무겁기 때문에,  
효율화를 위해 다음 기법을 사용합니다:
- **Negative Sampling**: 진짜 주변 단어는 양성(positive), 랜덤 샘플 단어들은 음성(negative)으로 두고 이진 분류 학습  
- **Hierarchical Softmax**: 어휘를 트리 구조로 두어 확률 계산을 빠르게 함  

---

# 5. Word2Vec의 의미
- 학습 결과: 각 단어는 \(d\)차원 벡터(\(d \ll V\))로 표현됨  
- 유사한 의미의 단어들은 벡터 공간에서 가깝게 위치  
- 단어 간 연산이 가능해짐 → “king - man + woman ≈ queen” 같은 관계성 반영  

---

# 6. 한계
- **정적(Static) 임베딩**: 한 단어는 항상 같은 벡터로 표현됨  
  - 예: `bank` (강둑 vs 은행) → 같은 벡터  
- 문맥에 따라 의미가 변하는 단어를 잘 처리하지 못함  
- 이 한계 때문에 이후에 **ELMo, BERT, GPT** 같은 **문맥적(Contextual) 임베딩** 모델이 등장  

---

# 7. 요약
- Word2Vec = 단어를 저차원 벡터로 바꿔주는 신경망 모델  
- CBOW/Skip-gram 두 방식 존재  
- 의미 유사성 + 단어 간 관계를 벡터 공간에 반영  
- 지금은 **BERT류 모델**이 주로 쓰이지만, Word2Vec은 여전히 **빠르고 가벼운 임베딩** 방법으로 의미 있음
