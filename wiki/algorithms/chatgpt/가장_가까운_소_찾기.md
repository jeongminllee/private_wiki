# 가장 가까운 소 찾기

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
이 문제는 농부 존(Farmer John)이 가진 소들의 위치 좌표가 주어졌을 때, 가장 가까운 두 소를 찾는 문제입니다. 문제의 주요 포인트는 다음과 같습니다.

### 문제 개요
- **입력**
  - 첫 번째 줄에는 소의 수 \( N \) (2 ≤ \( N \) ≤ 2,000)이 주어집니다.
  - 그 다음 \( N \)개의 줄에는 각 소의 \( X \)와 \( Y \) 좌표 (각각 1 ≤ \( X \), \( Y \) ≤ 100,000)가 주어집니다.
  - 각 소는 1번부터 \( N \)번까지 번호가 매겨져 있습니다.
  
- **문제 요구사항**
  - 주어진 좌표를 바탕으로 모든 소들 중에서 두 소 사이의 유클리드 거리가 최소가 되는 소의 쌍을 찾아야 합니다.
  - 거리는 두 좌표 간의 \(\sqrt{(X_i - X_j)^2 + (Y_i - Y_j)^2}\)로 계산합니다.
  
- **출력**
  - 가장 가까운 두 소의 번호를 오름차순(숫자가 작은 것부터)으로 출력합니다.
  
### 예제 설명
예제 입력은 다음과 같습니다:
```
9
2 9
5 9
8 10
11 7
10 3
5 1
6 4
2 5
7 6
```
- 예제에서 소 7번과 9번의 좌표는 각각 (6, 4)와 (7, 6)입니다.
- 두 좌표 사이의 거리는 \(\sqrt{(7-6)^2 + (6-4)^2} = \sqrt{1+4} = \sqrt{5}\)로 계산됩니다.
- 이 두 소가 모든 소들 중에서 가장 가까운 거리를 가지므로, 출력은 `7 9`가 됩니다.

### 문제 해결 방법
이 문제는 소의 수 \( N \)이 최대 2,000이므로, \( O(N^2) \)의 시간복잡도로 모든 쌍에 대해 거리를 계산해도 충분히 풀 수 있습니다.  
하지만, 더 효율적인 알고리즘(예: 분할 정복법)을 사용하여 \( O(N \log N) \) 시간복잡도로 해결하는 방법도 존재합니다. 문제의 목적은 두 소 사이의 최소 거리를 찾고, 해당 소들의 번호를 출력하는 데 있습니다.

요약하면, 주어진 소들의 좌표에서 모든 가능한 쌍의 유클리드 거리를 계산하여 최소 거리를 갖는 두 소를 찾아, 그 소들의 번호를 오름차순으로 출력하는 문제입니다.

### 💡 답변 (Assistant)
문제의 접근 방식은 전체 소의 쌍을 모두 비교하는 브루트 포스 방식으로 올바른 아이디어지만, `distance` 함수에서 계산식의 우선순위 때문에 오류가 발생합니다.

현재 코드의  
```python
return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 1/2
```
는 의도한 대로 \(\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)를 계산하지 않습니다.  
파이썬에서는 `**` 연산자가 `/`보다 우선순위가 높기 때문에, 위 식은  
```python
(((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 1) / 2
```
로 해석됩니다. 즉, 결과값이 실제 거리의 1/2가 되어버립니다.

**해결 방법:**  
지수 연산 부분에 소괄호를 추가하여 올바른 연산 순서를 보장해야 합니다.
```python
return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** (1/2)
```
이렇게 수정하면 제곱근을 올바르게 계산할 수 있습니다.

또한, 실수 연산을 피하기 위해 제곱근 계산 없이 제곱값끼리 비교하는 방법도 고려할 수 있습니다. (즉, 두 점 사이의 거리의 제곱을 비교하면 같은 결과를 얻을 수 있습니다.)

def distance(x1, y1, x2, y2) :
    return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 1/2
def sol_6003() :
    N = int(input())    # The number of cows
    cows = [[0, 0]]

    for _ in range(N) :
        cows.append(list(map(int, input().split())))


    mn_dist = 200_001
    res = [0, 0]
    for i in range(1, N) :
        for j in range(i + 1, N + 1) :
            # 같은 길이는 존재하지 않는다고 했으니까.
            if distance(cows[i][0], cows[i][1], cows[j][0], cows[j][1]) < mn_dist :
                mn_dist = distance(cows[i][0], cows[i][1], cows[j][0], cows[j][1])
                res = [i, j]

    print(*res)
sol_6003()

### 💡 답변 (Assistant)
더 효율적인 접근 방법은 **분할 정복 알고리즘**을 사용하는 것입니다. 이 알고리즘은 일반적인 \( O(N^2) \)의 브루트 포스 방법보다 \( O(N \log N) \)의 시간복잡도를 가지므로, 입력 크기가 커질 때 훨씬 빠르게 동작합니다.

### 분할 정복 알고리즘의 기본 아이디어

1. **정렬:**  
   먼저 모든 점(소의 좌표)을 \( x \)좌표 기준으로 정렬합니다.

2. **분할:**  
   정렬된 리스트를 중간 인덱스를 기준으로 두 개의 부분으로 나눕니다. 왼쪽 부분과 오른쪽 부분에 대해 각각 재귀적으로 최단 거리를 계산합니다.

3. **정복(병합) 단계:**  
   왼쪽 부분과 오른쪽 부분에서 각각 구한 최단 거리 \( \delta \)를 이용해 전체에서의 최단 거리를 업데이트합니다.  
   특히, 경계 근처에 있는 점들 중에서 \( \delta \)보다 가까운 쌍이 존재할 수 있기 때문에, 경계 주변의 점들만 따로 모아서 \( y \)좌표 기준으로 정렬한 후, 인접한 점들만 비교합니다. 이 과정에서 최대 7개의 점만을 비교하면 되는 것이 중요한 최적화 포인트입니다.

### 구현 포인트

- **재귀 호출:**  
  각 부분 문제를 재귀적으로 해결한 뒤, 경계 영역에 있는 점들에 대해 별도의 검사를 합니다.
  
- **경계 영역 검사:**  
  \( x \)좌표가 경계에서 \( \delta \) 이하인 점들을 모아서 \( y \)좌표 기준으로 정렬합니다. 이 점들에 대해 인접한 몇 개의 점들만 비교하면 전체에서의 최소 거리를 찾을 수 있습니다.

- **거리 제곱 사용:**  
  실제 거리를 계산하는 대신 거리의 제곱 값을 비교하면, 제곱근 계산 비용을 줄일 수 있습니다.

### 왜 더 효율적인가?

- **시간복잡도:**  
  브루트 포스 방식은 \( O(N^2) \)의 시간복잡도를 가지지만, 분할 정복 방식은 \( O(N \log N) \)로 문제의 입력 크기가 커질 때 훨씬 더 빠른 성능을 보입니다.
  
- **최적화된 경계 검사:**  
  경계 검사 단계에서 인접한 최대 7개의 점만 확인함으로써 불필요한 비교를 줄입니다.

### 요약

분할 정복 알고리즘은 다음과 같이 진행됩니다:
1. \( x \)좌표 기준으로 점들을 정렬.
2. 중간에서 분할하여 왼쪽과 오른쪽 부분에서 최단 거리 구하기.
3. 경계 근처의 점들을 모아 \( y \)좌표 기준 정렬 후 추가 비교.
4. 전체 최단 거리를 반환.

이러한 방법을 사용하면 큰 입력에 대해서도 효율적으로 문제를 해결할 수 있습니다.

### 💡 답변 (Assistant)
아래는 분할 정복 알고리즘을 사용하여 가장 가까운 두 소의 좌표(및 소 번호)를 찾는 파이썬 코드입니다. 이 코드는 점들을 \(x\)좌표 기준으로 정렬한 후, 재귀적으로 문제를 해결하고 경계 영역에 대해 추가 비교를 수행합니다. 거리 비교는 제곱 값을 사용하여 제곱근 연산을 피합니다.

```python
import sys
import math

def closest_pair(points_x, points_y):
    n = len(points_x)
    if n <= 3:
        # 브루트 포스 방식: n이 작으면 모든 쌍 비교
        min_d = float('inf')
        best_pair = (-1, -1)
        for i in range(n):
            for j in range(i + 1, n):
                d = (points_x[i][0] - points_x[j][0])**2 + (points_x[i][1] - points_x[j][1])**2
                if d < min_d:
                    min_d = d
                    # 소의 번호는 points_x[i][2], points_x[j][2]
                    best_pair = tuple(sorted((points_x[i][2], points_x[j][2])))
        return min_d, best_pair

    # 중간 인덱스와 중간 x값 결정
    mid = n // 2
    mid_x = points_x[mid][0]

    # 왼쪽과 오른쪽 리스트 만들기
    left_x = points_x[:mid]
    right_x = points_x[mid:]
    
    # points_y를 x좌표 분할에 따라 분할하기 (안정정렬 사용)
    left_y = []
    right_y = []
    for p in points_y:
        if p[0] <= mid_x:
            left_y.append(p)
        else:
            right_y.append(p)
    
    # 재귀적으로 최단 거리 계산
    d_left, pair_left = closest_pair(left_x, left_y)
    d_right, pair_right = closest_pair(right_x, right_y)
    
    # 현재 최소 거리와 해당 쌍 결정
    if d_left < d_right:
        d = d_left
        best_pair = pair_left
    else:
        d = d_right
        best_pair = pair_right

    # 경계 영역에 속하는 점들만 모으기
    strip = []
    for p in points_y:
        if abs(p[0] - mid_x) ** 2 < d:
            strip.append(p)
    
    # strip 내에서 인접한 점들만 비교 (최대 7개)
    m = len(strip)
    for i in range(m):
        # j는 i+1부터 최대 7개 또는 조건에 따라
        for j in range(i + 1, m):
            if (strip[j][1] - strip[i][1])**2 >= d:
                break
            d_temp = (strip[i][0] - strip[j][0])**2 + (strip[i][1] - strip[j][1])**2
            if d_temp < d:
                d = d_temp
                best_pair = tuple(sorted((strip[i][2], strip[j][2])))
    return d, best_pair

def main():
    input = sys.stdin.readline
    N = int(input().strip())
    points = []
    for i in range(1, N+1):
        x, y = map(int, input().split())
        # 각 점: (x, y, id)
        points.append((x, y, i))
    
    # x, y 좌표 기준으로 정렬된 리스트 준비
    points_x = sorted(points, key=lambda p: p[0])
    points_y = sorted(points, key=lambda p: p[1])
    
    # 분할 정복 알고리즘 실행 (거리의 제곱 기준)
    _, result_pair = closest_pair(points_x, points_y)
    print(result_pair[0], result_pair[1])

if __name__ == '__main__':
    main()
```

### 코드 설명

- **데이터 준비**  
  각 소의 좌표와 번호를 튜플 `(x, y, id)`로 저장합니다.

- **정렬**  
  `points_x`는 \(x\)좌표 기준, `points_y`는 \(y\)좌표 기준으로 정렬합니다.

- **closest_pair 함수**  
  - 기저 사례: 점의 수가 3 이하인 경우 브루트 포스로 최소 거리를 계산합니다.
  - 재귀 단계: 점들을 중간 인덱스로 분할하고, 왼쪽과 오른쪽 부분에 대해 재귀 호출을 진행합니다.
  - 경계 영역: 중간 \(x\)값에서 거리 \(d\) (현재까지의 최소 거리 제곱) 이하에 있는 점들을 모아 추가 비교를 수행합니다.
  
- **출력**  
  최종적으로 가장 가까운 두 소의 번호를 오름차순으로 출력합니다.

이 방식은 \(O(N \log N)\)의 시간복잡도를 가지므로, 소의 수가 많아도 효율적으로 동작합니다.
