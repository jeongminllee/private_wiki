### 🔍 **문제 설명 (Problem Description)**

**문제:**  
어떤 도로 위에 `n`개의 주유소가 원형으로 존재합니다.  
각 주유소에는 `gas[i]`만큼의 연료가 있으며, 해당 주유소에서 다음 주유소까지 이동하려면 `cost[i]`만큼의 연료가 필요합니다.

**당신의 차는 빈 탱크로 출발하며**, 연료를 무제한으로 담을 수 있습니다.  
**한 주유소에서 출발하여 원형 루트를 한 바퀴 돌아 다시 같은 주유소로 돌아올 수 있는 출발 지점**이 존재하는지 확인하세요. 존재한다면 해당 인덱스를 반환하고, 존재하지 않는다면 -1을 반환합니다.

---

### 🧾 **입력**
- `gas`: 정수 배열 (주유소마다 얻을 수 있는 연료의 양)
- `cost`: 정수 배열 (해당 주유소에서 다음 주유소까지 가는 데 드는 연료)

---

### ✅ **출력**
- 가능한 출발 주유소의 인덱스 (0 ≤ 인덱스 < n), 불가능하면 `-1`

---

### 🧠 **핵심 아이디어**

1. **총 연료 ≥ 총 비용이 아니면 절대 불가능**  
   - 전체 gas의 합이 cost의 합보다 작으면 절대 한 바퀴 돌 수 없음.

2. **Greedy (탐욕법) 접근**
   - 어느 지점에서 출발했는데 중간에 연료가 부족해 멈췄다면, 그 전에 거쳤던 모든 지점도 출발점이 될 수 없음.
   - 따라서 멈췄을 때, 다음 지점부터 다시 시작하면 됨.

---

### 🧮 **알고리즘 구현 흐름**

```python
def canCompleteCircuit(gas, cost):
    total_tank = 0      # 전체 연료 잔량 (전체 gas - cost)
    curr_tank = 0       # 현재 경로 상 연료 잔량
    start_index = 0     # 시작 인덱스 후보

    for i in range(len(gas)):
        diff = gas[i] - cost[i]
        total_tank += diff
        curr_tank += diff

        # 현재까지의 잔량이 부족하면 다음 주유소부터 다시 시작
        if curr_tank < 0:
            start_index = i + 1
            curr_tank = 0

    return start_index if total_tank >= 0 else -1
```

---

### 📊 **예시**

```python
Input: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
Output: 3
```

- 각 지점에서 `(gas[i] - cost[i])` = `[-2, -2, -2, 3, 3]`
- 전체 합은 `0`보다 크므로 가능.
- 3번 인덱스에서 출발하면 연료가 부족하지 않고 한 바퀴 가능.

---

### ⏱️ **시간복잡도**
- **O(n)** — 배열을 한 번만 순회하므로 효율적입니다.

---

### 💡 **요약**

- 전체 연료가 부족하면 무조건 실패.
- 중간에 연료가 바닥나면 그 지점 이전은 절대 정답 아님.
- Greedy + 단순 반복으로 최적의 출발점을 찾을 수 있음.

## 🔧 문제의 본질
이 문제는 본질적으로 **원형 배열을 따라 이동하면서 에너지(연료)를 소비하고, 충전하면서 한 바퀴를 완주할 수 있는 출발점을 찾는 문제**입니다.

---

## 🔑 핵심 아이디어 상세 설명 (Greedy + 총합 조건)

### 1️⃣ 전체 연료(gas) - 전체 비용(cost)가 **음수면 절대 불가능**

- 왜냐하면:
  - 전체적으로 얻는 연료의 양이 이동에 필요한 연료보다 적다면 **어디서 출발해도 결국 연료가 부족**하게 됨.
- 수식으로 표현하면:
  \[
  \sum(gas[i] - cost[i]) < 0 \Rightarrow \text{불가능}
  \]

👉 이 조건은 **문제를 풀기 위한 전제조건**입니다.

---

### 2️⃣ 어느 지점에서 연료가 부족했다면, **그 앞의 어떤 지점에서도 출발할 수 없다**

#### 예시 상황:
- gas = [1, 2, 3, 4, 5]
- cost = [3, 4, 5, 1, 2]
- 차이가 되는 배열: gas - cost = [-2, -2, -2, 3, 3]

- 0번에서 출발 → tank = -2 → 연료 부족 → 실패  
- 1번에서 출발 → tank = -2 → 연료 부족 → 실패  
- 2번에서 출발 → tank = -2 → 연료 부족 → 실패  
- 3번에서 출발 → tank = 3 + 3 + (-2) + (-2) + (-2) = 0 → **성공**

#### 핵심 통찰:
- i번째에서 출발해서 **연료가 부족한 순간이 오면**, **i부터 그 지점까지의 모든 위치**는 출발점이 될 수 없음!
- 왜냐하면:
  - 그 지점까지의 누적 합이 **음수**이기 때문에, 그 어떤 앞 위치에서도 더 적은 연료로 더 먼 거리를 가야 함 → **더 불리함**

👉 따라서 실패한 시점 이후의 **다음 인덱스부터** 출발을 재시도하면 됨.

---

## 🔁 알고리즘 흐름 정리

1. `total_tank` ← 전체 여유 연료 저장용  
2. `curr_tank` ← 현재 시도 경로의 연료 저장용  
3. `start_index` ← 유망한 출발점 후보  

각 인덱스 i에서:
- gas[i] - cost[i] 값을 두 변수에 누적
- 만약 `curr_tank` < 0이라면:
  - 현재 출발점 후보에서 한 바퀴 돌 수 없으므로
  - 출발점 후보를 `i + 1`로 갱신하고 `curr_tank`는 초기화

반복 종료 후:
- total_tank ≥ 0 이면 → start_index가 정답
- total_tank < 0 이면 → -1 반환

1. **전체 연료가 전체 비용보다 적으면 불가능하다.**
2. **어느 시점에서 연료가 부족하면 그 앞의 어떤 지점도 출발점이 될 수 없으므로, 다음 지점부터 출발을 재시도한다.**
