# 그래프 Y 개수 구하기

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
흐즈로는 그래프 이론을 공부하다가 흥미로운 그래프를 발견했습니다. 다음의 특징을 가지는 단순 무향 그래프를 Y라고 부릅시다.

 
$4$개의 정점과 
$3$개의 간선을 가집니다.
하나의 정점을 루트라고 부르며, 나머지 
$3$개의 정점을 리프라고 부릅니다.
 
$3$개의 간선은 각각의 리프와 루트를 연결합니다.
흐즈로는 Y의 성질이 매우 특이하다고 생각하여, 어떤 그래프 안에 Y가 몇 개나 존재하는지 세어 보기로 했습니다. 단순 무향 그래프에서 Y의 개수를 다음과 같이 정의합시다.

그래프에서 
$3$개의 간선을 순서 없이 골랐을 때, 그 간선과 간선이 연결하는 정점들이 이루는 그래프가 Y가 되는 경우의 수를 그래프의 Y의 개수로 정의합니다.
단순 무향 그래프가 입력으로 주어질 때, 주어진 그래프의 Y의 개수를 출력하세요. 단, 개수가 너무 많을 수 있으니 개수를 소수 
$10^9+7$로 나눈 나머지를 출력하세요.

입력
첫 번째 줄에 정점의 개수 
$n$과 간선의 개수 
$m$이 공백으로 분리되어 주어집니다. (
$1 \le n \le 10^5$, 
 
$0 \le m \le \min(\frac{n(n-1)}{2},2\times 10^5)$)

두 번째 줄부터 
$m$개의 줄에 
$i$번째 간선이 연결하는 정점 
$u$와 
$v$가 공백으로 분리되어 주어집니다. (
$1 \le u,v \le n$, 
$u \neq v$)

주어진 그래프는 중복 간선이나 양 끝점이 같은 간선을 가지지 않음이 보장됩니다.

출력
주어진 그래프의 Y의 개수를 
$10^9 + 7$로 나눈 나머지를 출력하세요.

예제 입력 1 
4 6
1 2
1 3
1 4
2 3
2 4
3 4
예제 출력 1 
4
그래프에서 간선 
$3$개를 선택해 만들어진 부분 그래프가 Y가 되는 경우는 다음과 같습니다.

 
$(1,2)$, 
$(1,3)$, 
$(1,4)$를 선택합니다.
 
$(1,2)$, 
$(2,3)$, 
$(2,4)$를 선택합니다.
 
$(1,3)$, 
$(2,3)$, 
$(3,4)$를 선택합니다.
 
$(1,4)$, 
$(2,4)$, 
$(3,4)$를 선택합니다.
따라서 예제의 그래프의 Y의 개수는 
$4$입니다. 
$4 \equiv 4 \pmod{10^9+7}$이므로 
$4$를 출력해야 합니다.

### 💡 답변 (Assistant)
이 문제는 그래프 내에서 **Y 형태 (1개의 중심 노드 + 3개의 연결된 리프 노드)**가 될 수 있는 **서브그래프의 개수**를 세는 문제입니다.

---

### ✅ Y 그래프의 정의
Y는 총 4개의 정점과 3개의 간선으로 구성되며,  
**하나의 중심 정점(root)**과 **3개의 리프 노드**가 있고,  
**각 리프와 루트를 연결하는 3개의 간선**으로만 이루어진 구조입니다.

즉, 어떤 정점이 **세 개의 간선을 가지고 있고**,  
그 간선들이 연결된 **세 개의 서로 다른 정점**이 있다면,  
이 3개의 간선을 고르면 Y를 구성할 수 있습니다.

---

### ✅ 아이디어

- 어떤 정점 `u`가 있다고 할 때, `u`의 이웃 정점의 수를 `deg(u)`라고 하면,  
  `deg(u)` 중에서 **3개를 선택해서 조합을 만들 수 있는 경우의 수**는 `C(deg(u), 3)`입니다.
- 이것은 `u`가 **루트**이고, 그와 연결된 **세 개의 리프 노드**를 선택한 것과 같으며,  
  이 3개의 간선은 곧 Y의 하나의 구성입니다.
- 따라서 **모든 정점에 대해 `C(deg(u), 3)`의 합을 구하면 전체 Y의 개수**입니다.

---

### ✅ 수학 정리

- `C(k, 3) = k * (k - 1) * (k - 2) / 6` (단, k ≥ 3)
- 전체 Y 개수 = `∑ C(deg(u), 3)` for all u where deg(u) ≥ 3

---

### ✅ 구현 (Python)

```python
import sys
input = sys.stdin.read
MOD = 10**9 + 7

def comb3(k):
    if k < 3:
        return 0
    return (k * (k - 1) * (k - 2)) // 6

def main():
    data = input().split()
    n, m = int(data[0]), int(data[1])
    
    from collections import defaultdict
    degree = [0] * (n + 1)
    
    idx = 2
    for _ in range(m):
        u = int(data[idx])
        v = int(data[idx+1])
        degree[u] += 1
        degree[v] += 1
        idx += 2
    
    result = 0
    for d in degree:
        result = (result + comb3(d)) % MOD
        
    print(result)

main()
```

---

### ✅ 예제 확인

입력:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```

- 각 정점의 degree는 `[3, 3, 3, 3]`
- 각 정점마다 `C(3, 3) = 1` → 총 4개 Y 구조 가능

---

### ✅ 시간 복잡도

- 시간: O(m + n) — 입력 파싱과 degree 계산
- 공간: O(n) — degree 저장

---

### ✅ 결론

이 문제는 그래프 순회나 DFS/트리 구조를 사용할 필요 없이,  
**정점별 degree의 조합**만으로 간단하게 풀 수 있는 **조합 기반의 수학 문제**입니다.  
핵심은 Y의 정의를 조합적으로 해석하는 것이었습니다.
