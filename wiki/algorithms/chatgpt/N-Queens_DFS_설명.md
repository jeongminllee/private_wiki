```
# N-Queens 문제를 깊이 우선 탐색(DFS)으로 해결하는 함수
def dfs(n) :
    # 전역 변수를 사용하여 솔루션 개수 추적
    global ans
    
    # N개의 행에 모두 퀸을 배치했다면 유효한 해 발견
    if n == N :
        # 솔루션 개수 증가
        ans += 1
        return

    # 현재 행의 각 열에 퀸을 배치하는 시도
    for j in range(N) :
        # 현재 위치에 퀸을 배치할 수 있는지 확인
        # v1: 열 검사
        # v2: 대각선 검사 (오른쪽 위에서 왼쪽 아래)
        # v3: 대각선 검사 (왼쪽 위에서 오른쪽 아래)
        # 0은 이전 퀸들에 의해 공격받지 않는 위치를 의미
        if v1[j] == v2[n + j] == v3[n - j] == 0 :
            # 현재 위치를 점유된 것으로 표시
            v1[j] = v2[n + j] = v3[n - j] = 1
            
            # 다음 행에 퀸을 배치하기 위해 재귀 호출
            dfs(n + 1)
            
            # 백트래킹: 다른 가능성을 탐색하기 위해 위치 표시 해제
            v1[j] = v2[n + j] = v3[n - j] = 0

# 솔루션 개수 초기화
ans = 0

# 입력으로부터 체스판 크기(N) 읽기
N = int(input())

# 검사 배열 초기화:
# v1: 열 검사 (N개의 열)
# v2: 오른쪽 위에서 왼쪽 아래 대각선 검사 (2N-1개의 대각선)
# v3: 왼쪽 위에서 오른쪽 아래 대각선 검사 (2N-1개의 대각선)
v1 = [0] * N
v2 = [0] * (2 * N)
v3 = [0] * (2 * N)

# 첫 번째 행부터 DFS 시작
dfs(0)

# 유효한 N-Queens 배치 총 개수 출력
print(ans)
```

### N-Queens 문제란?

N-Queens 문제는 체스판 크기를 \( N \times N \)으로 설정했을 때, **N개의 퀸을 서로 공격하지 않도록 배치하는 방법의 개수**를 구하는 문제입니다.

퀸은 체스의 말 중 하나로, 다음과 같은 움직임이 가능합니다:
1. **가로**로 무제한 이동
2. **세로**로 무제한 이동
3. **대각선**으로 무제한 이동

따라서, 서로 다른 두 퀸이 가로, 세로, 대각선 중 어느 방향에서도 동일한 위치에 있으면 서로 공격할 수 있게 됩니다. N-Queens 문제의 목표는 이러한 공격 조건을 피하면서 모든 퀸을 배치하는 가능한 조합의 개수를 찾는 것입니다.

---

### 예시

#### \( N = 4 \)인 경우
체스판은 \( 4 \times 4 \) 크기이고, 4개의 퀸을 배치해야 합니다. 이 경우 가능한 배치 중 하나는:

```
. Q . .
. . . Q
Q . . .
. . Q .
```

여기서, \( Q \)는 퀸이 배치된 위치를, 점(.)은 빈 공간을 나타냅니다. 위와 같은 배치는 모든 퀸이 서로 공격하지 않는 조건을 만족합니다.

---

### 해결 방법: 깊이 우선 탐색 (DFS)

문제를 해결하기 위해 **재귀와 백트래킹**을 사용합니다.

1. **행 단위로 탐색**:
   - 체스판의 각 행(row)마다 퀸을 배치합니다.
   - 열(column)이나 대각선이 공격받지 않는다면 그 위치에 퀸을 배치하고 다음 행으로 넘어갑니다.

2. **유효성 검사**:
   - 특정 위치에 퀸을 배치할 때, 다음 조건을 확인합니다:
     - 같은 열에 다른 퀸이 없는가? (열 검사)
     - 대각선 방향에 다른 퀸이 없는가? (왼쪽 위에서 오른쪽 아래, 오른쪽 위에서 왼쪽 아래)

3. **백트래킹**:
   - 한 행에서 가능한 모든 열을 시도하고, 유효한 위치를 찾으면 다음 행으로 재귀 호출을 진행합니다.
   - 재귀가 끝나면 이전 상태로 돌아가 다른 가능성을 탐색합니다.

4. **재귀 종료 조건**:
   - \( N \)번째 행까지 퀸을 배치하면, 한 가지 유효한 배치를 찾은 것입니다. 이를 카운팅합니다.

---

### 코드 작동 원리

1. `dfs(n)` 함수는 \( n \)번째 행에 퀸을 배치하려고 시도합니다.
2. `v1`, `v2`, `v3` 배열은 각각 다음을 나타냅니다:
   - `v1[j]`: 열 검사 (열 \( j \)가 이미 사용되었는지)
   - `v2[n + j]`: 오른쪽 위에서 왼쪽 아래 대각선 검사
   - `v3[n - j]`: 왼쪽 위에서 오른쪽 아래 대각선 검사
3. 퀸을 배치 가능한 위치에 두고 재귀 호출을 진행합니다.
4. 재귀 호출이 완료되면 해당 위치를 초기 상태로 되돌려 백트래킹합니다.
