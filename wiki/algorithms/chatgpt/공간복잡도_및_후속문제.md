# 공간복잡도 및 후속문제

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-07-03

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root == p or root == q:
            return root
        
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if not right :
            return left
        if not left :
            return right
        if left and right :
            return root
```
이 코드의 공간복잡도 계산해줘. 그리고 이 문제의 Follow up인 
Follow up: Can you solve the problem in O(1) extra space complexity? (The output array does not count as extra space for space complexity analysis.)
에 대해서도 설명해주고, Follow up된 코드를 구현해줘.

### 💡 답변 (Assistant)
### ✅ 공간복잡도 분석 (Space Complexity)

주어진 `lowestCommonAncestor` 재귀 함수는 **이진 트리를 순회**하는 DFS(Depth-First Search) 방식입니다.  
- 이 함수는 **재귀 호출 스택**을 사용하므로, **공간복잡도는 트리의 높이**(`O(h)`)입니다.
- 최악의 경우 트리가 **한쪽으로 치우친 경우**(skewed tree) `h = O(n)`이 될 수 있고,  
  평균적으로는 **균형 이진 트리일 경우** `h = O(log n)`입니다.

즉,  
> **공간복잡도 = O(h), 최악의 경우 O(n), 평균적으로 O(log n)**

---

### 🔍 Follow-up: **O(1) extra space**로 해결할 수 있는가?

#### ❓질문의 의미
"Can you solve the problem in O(1) extra space complexity?"  
👉 이는 **재귀를 사용하지 않고**, **스택/큐도 사용하지 않고**, **추가적인 구조도 없이** 문제를 해결할 수 있느냐는 질문입니다.

#### 🧠 핵심 아이디어: **부모 포인터(parent pointer)**가 있는 경우

만약 각 노드가 부모에 대한 포인터를 가지고 있다면, 다음과 같이 해결할 수 있습니다:
1. 두 노드 `p`, `q`에서 각각 루트로 올라가며 경로를 구한다.
2. 두 경로를 비교하여 **가장 마지막으로 같은 노드**를 반환한다.

이 방법은 재귀나 추가 메모리를 사용하지 않고도 O(1) 추가 공간으로 해결 가능합니다.

### 📌 O(1) 공간 풀이 (부모 포인터가 주어진 경우)

LeetCode에서는 `TreeNode`에 `parent` 필드가 없지만, follow-up에서는 부모를 알 수 있다고 가정합니다. 아래는 부모 포인터를 활용한 풀이입니다:

```python
class TreeNode:
    def __init__(self, x):
        self.val = x
        self.left = None
        self.right = None
        self.parent = None  # 부모 노드 포인터

class Solution:
    def lowestCommonAncestor(self, p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # 두 노드의 깊이를 구한다
        def get_depth(node):
            depth = 0
            while node:
                node = node.parent
                depth += 1
            return depth

        depth_p = get_depth(p)
        depth_q = get_depth(q)

        # 깊이를 맞춘다
        while depth_p > depth_q:
            p = p.parent
            depth_p -= 1
        while depth_q > depth_p:
            q = q.parent
            depth_q -= 1

        # 공통 조상을 찾는다
        while p != q:
            p = p.parent
            q = q.parent

        return p
```

#### ✅ 특징
- 공간복잡도: **O(1)** (parent 포인터만 사용할 뿐 추가 구조 없음)
- 시간복잡도: **O(h)** (노드 깊이만큼 상향 이동)

|----------------------|------------------|-------------------|
| DFS 재귀             | O(h) (스택 사용) | 일반적인 방식     |
| 부모 포인터 이용     | **O(1)**         | 부모 포인터 필요 |

필요하다면 **부모 포인터 없이 O(1)로 해결할 수 있는 Morris Traversal 기반 방법**도 있지만, LCA 문제에는 적합하지 않습니다. 따라서 부모 포인터가 없을 경우 `O(h)` 공간을 사용하는 것이 최선입니다.
