# 슬라이딩 윈도우 알고리즘

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
### 직관적 이해 (Intuition)  
이 문제를 해결하기 위해서는 문자열 `s`에서 `words` 배열에 주어진 단어들을 연결하여 형성된 모든 가능한 부분 문자열의 시작 인덱스를 효율적으로 찾아야 합니다. 이를 위해 **슬라이딩 윈도우(sliding window)** 기법을 사용하여, 길이가 `len(words) * len(words[0])`인 부분 문자열을 확인하며, 해당 부분 문자열이 주어진 단어들의 조합과 일치하는지 검사합니다.  

---

### 접근 방법 (Approach)  
1. `words` 배열에 포함된 각 단어의 개수를 저장하는 **딕셔너리 `word_count`** 를 초기화합니다.  
2. 결과를 저장할 빈 리스트 **`result`** 를 초기화합니다.  
3. 연결된 부분 문자열의 길이를 계산하여 **`substr_len = len(words) * len(words[0])`** 로 설정합니다.  
4. 문자열 `s`를 **`len(s) - substr_len + 1`** 만큼 순회하며 검사합니다.  
5. 각 윈도우에 대해:  
   - **`seen` 딕셔너리** 를 초기화하여 현재 윈도우에서 발견한 단어들의 개수를 저장합니다.  
   - 길이 `len(words[0])` 만큼의 단어를 하나씩 추출하며 `word_count`에 존재하는지 확인하고, 존재하면 `seen`을 업데이트합니다.  
   - `seen`이 `word_count`와 일치하면, 해당 윈도우의 시작 인덱스를 `result`에 추가합니다.  
6. 최종적으로 `result`를 반환합니다.  

---

### 시간 복잡도 (Time Complexity)  
- **O((n−m⋅l)⋅m⋅l)**  
  - `n`: 문자열 `s`의 길이  
  - `m`: `words` 배열의 단어 개수  
  - `l`: 각 단어의 길이  
  - 외부 루프는 최대 `n−m⋅l+1` 번 실행되며, 내부에서 `m⋅l` 문자를 검사하므로 최악의 경우 위와 같은 시간 복잡도를 가집니다.  

### 공간 복잡도 (Space Complexity)  
- **O(m⋅l)**  
  - `word_count` 및 `seen` 딕셔너리의 크기는 최대 `m⋅l` 이므로, 이만큼의 추가 공간이 필요합니다.

### ❓ 질문 (User)
Intuition
To solve this problem, we need to efficiently find all starting indices of concatenated substrings in the given string s using the words provided in the array words. We'll employ a sliding window approach to check each possible substring of length len(words) * len(words[0]) and determine if it's a concatenated substring.

Approach
Initialize a dictionary word_count to store the count of each word in the words array.
Initialize an empty list result to store the starting indices of concatenated substrings.
Calculate the length of concatenated substrings, substr_len, as len(words) * len(words[0]).
Iterate through the string s up to len(s) - substr_len + 1.
Within each iteration, initialize a dictionary seen to store the words seen so far in the current window.
For each word of length len(words[0]) within the current window, check if it is in word_count and update seen.
If seen matches word_count, it means all words in words are found in the current window. Append the starting index of the window to result.
Return result.
Complexity
Time complexity:
O((n−m⋅l)⋅m⋅l), where n is the length of the string s, m is the number of words in words, and l is the length of each word. The outer loop runs n−m⋅l+1 times, and within each iteration, we iterate over m⋅l characters.

Space complexity:
O(m⋅l) for the word_count dictionary and seen dictionary.

## **풀이 방법** (Sliding Window + Hash Table)
이 문제를 해결하기 위해 **슬라이딩 윈도우(sliding window)** 와 **해시 테이블(Hash Table)** 을 활용합니다.  

### **접근 방법**
1. **단어 개수 카운트**  
   - `words`의 단어들이 몇 번씩 등장하는지 딕셔너리(`word_count`)에 저장합니다.  

2. **슬라이딩 윈도우로 문자열 검사**  
   - 전체 문자열 `s`를 탐색하면서, 길이가 `words_total_length = len(words) * len(words[0])`인 부분 문자열을 검사합니다.  
   - 시작 인덱스는 `0`부터 `len(s) - words_total_length + 1`까지입니다.  
   - 내부에서 **각 단어를 `word_count`와 비교**하면서 유효한 조합인지 확인합니다.  

3. **유효한 부분 문자열 판별**  
   - 현재 윈도우에서 단어를 `word_count`와 비교하여 `seen` 딕셔너리에 저장하고, `word_count`와 일치하는지 확인합니다.  
   - 일치하면 시작 인덱스를 결과 리스트에 추가합니다.  

---

## **시간 및 공간 복잡도 분석**
### **시간 복잡도**  
- **O((n−m⋅l)⋅m⋅l)**
  - `n`: 문자열 `s`의 길이  
  - `m`: `words` 배열의 길이  
  - `l`: 각 단어의 길이  
  - 바깥 루프는 최대 `n - m⋅l + 1`번 실행되고, 내부에서 `m⋅l`만큼 검사하므로 위와 같은 복잡도를 가짐.  

### **공간 복잡도**  
- **O(m⋅l)**  
  - `word_count` 및 `seen` 딕셔너리의 크기 때문에 최대 `O(m⋅l)`의 공간이 필요함.

## **파이썬 코드 구현**
```python
from collections import Counter

def findSubstring(s, words):
    if not s or not words:
        return []
    
    word_len = len(words[0])
    word_count = Counter(words)  # 단어 빈도수 저장
    substr_len = len(words) * word_len
    result = []
    
    for i in range(len(s) - substr_len + 1):
        seen = Counter()  # 현재 윈도우에서 본 단어 개수 저장
        j = 0
        while j < len(words):
            word = s[i + j * word_len: i + (j + 1) * word_len]
            if word in word_count:
                seen[word] += 1
                if seen[word] > word_count[word]:
                    break  # 같은 단어가 너무 많이 등장하면 중단
            else:
                break  # words에 없는 단어가 나오면 중단
            j += 1
        
        if seen == word_count:
            result.append(i)  # 유효한 시작 인덱스 추가
    
    return result
```

## **실행 예제**
```python
s = "barfoothefoobarman"
words = ["foo", "bar"]
print(findSubstring(s, words))  # 출력: [0, 9]
```

## **개선 가능성**
현재 구현은 **고정된 윈도우 크기**를 기준으로 **한 칸씩 이동**하며 검사하는 방식입니다.  
이를 **슬라이딩 윈도우 + 투 포인터** 방식으로 개선하면 일부 불필요한 연산을 줄일 수 있습니다.  
이러한 방법을 적용하면 **O(n)** 에 더 가까운 시간 복잡도로 개선할 수도 있습니다.
