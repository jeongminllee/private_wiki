# 피보나치 구현 방법

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
피보나치 수열을 파이썬으로 구현할 수 있는 방법이 여러가지 있어.
1. 일반적인 for문
2. 메모이제이션
3. 다이나믹 프로그래밍
3가지 코드를 구현해줘

### 💡 답변 (Assistant)
다음은 피보나치 수열을 구현하는 세 가지 방법입니다.  

### 1. **일반적인 for문을 사용한 반복문 구현**
```python
def fibonacci_iterative(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1

    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print(fibonacci_iterative(10))  # 출력: 55
```
- 반복문을 사용하여 피보나치 수를 계산합니다.
- 시간 복잡도: **O(n)**, 공간 복잡도: **O(1)**

---

### 2. **메모이제이션 (재귀 + 캐싱)**
```python
def fibonacci_memoization(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 0:
        return 0
    elif n == 1:
        return 1

    memo[n] = fibonacci_memoization(n - 1, memo) + fibonacci_memoization(n - 2, memo)
    return memo[n]

print(fibonacci_memoization(10))  # 출력: 55
```
- 이전에 계산한 값을 저장하여 중복 계산을 방지합니다.
- 시간 복잡도: **O(n)**, 공간 복잡도: **O(n)**

---

### 3. **다이나믹 프로그래밍 (Bottom-Up)**
```python
def fibonacci_dp(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1

    dp = [0] * (n + 1)
    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]

print(fibonacci_dp(10))  # 출력: 55
```
- 작은 문제를 먼저 해결하면서 배열에 값을 저장해가며 해결하는 방식입니다.
- 시간 복잡도: **O(n)**, 공간 복잡도: **O(n)** (배열 사용)  
- 공간을 더 줄이려면 `dp` 배열 없이 `a, b` 변수만 사용하면 됩니다.

---

세 가지 방법 모두 `O(n)`의 시간 복잡도를 가지지만,  
- **반복문 방식**이 가장 공간 효율적입니다. (`O(1)`)  
- **메모이제이션**은 재귀 방식이므로 **스택 메모리를 많이 사용**할 수 있습니다.  
- **다이나믹 프로그래밍**은 배열을 활용하는데, **추가 메모리를 사용할 수 있지만 직관적**입니다.
