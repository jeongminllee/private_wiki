# 재귀 반복문 변환

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
아래 재귀는 구간 \([s,e]\)가 남아있을 때의 “현재 날짜(cnt)”가 **구간 길이로부터 고정적으로 결정**된다는 점을 이용해 메모이제이션을 했어요.  
구간 길이 \(L=e-s+1\) 이면 지금까지 \(n-L\)개를 먹었으니,  
현재 날짜(곱해지는 값) \(cnt = (n-L)+1 = n-(e-s)\) 입니다.

그래서 반복문으로는 **구간 길이(len)를 1부터 n까지 늘려가며** DP를 채우면 됩니다.

```python
import sys
input = sys.stdin.readline

n = int(input())
rice = [int(input()) for _ in range(n)]

# dp[s][e] = 구간 [s,e]가 남았을 때 얻을 수 있는 최대 가치
dp = [[0]*n for _ in range(n)]

# 길이 1짜리 구간(마지막 날): cnt = n
for i in range(n):
    dp[i][i] = n * rice[i]

# 길이를 2 ~ n으로 늘려가며 채움
for length in range(2, n+1):
    cnt = n - length + 1  # 현재 날짜(곱해지는 값)
    for s in range(0, n - length + 1):
        e = s + length - 1
        dp[s][e] = max(
            dp[s+1][e] + cnt * rice[s],  # 왼쪽 선택
            dp[s][e-1] + cnt * rice[e]   # 오른쪽 선택
        )

print(dp[0][n-1])
```

### (선택) 메모리 O(n)으로 줄인 버전
같은 점화식에서 `dp[s][e]`는 바로 이전 length의 값만 쓰니 1차원으로도 가능해요.

```python
import sys
input = sys.stdin.readline

n = int(input())
rice = [int(input()) for _ in range(n)]

# dp[s] = 현재 length에서 구간 [s, s+length-1]의 최대 가치
dp = [0]*n

# length=1 초기화 (cnt=n)
for i in range(n):
    dp[i] = n * rice[i]

# length=2..n
for length in range(2, n+1):
    cnt = n - length + 1
    new_dp = [0]*n
    for s in range(0, n - length + 1):
        e = s + length - 1
        new_dp[s] = max(
            dp[s+1] + cnt * rice[s],  # dp[s+1]는 이전 length에서 [s+1, e]
            dp[s]   + cnt * rice[e]   # dp[s]   는 이전 length에서 [s, e-1]
        )
    dp = new_dp

print(dp[0])
```

원하는 스타일이 2D/1D 중 뭐든 골라 쓰면 되고, 결과는 재귀 버전과 동일하게 나옵니다.

### ❓ 질문 (User)
```
import sys
input = sys.stdin.readline
sys.setrecursionlimit(2000)

n = int(input())
rice = [int(input()) for i in range(n)]

dp =[[0 for i in range(n)] for i in range(n)]
def get_maxvalue(s, e, cnt):
    # base case
    if s==e : return cnt*rice[s]
    if dp[s][e] : return dp[s][e]
    # step
    dp[s][e] = max(get_maxvalue(s+1, e, cnt+1)+cnt*rice[s], get_maxvalue(s, e-1, cnt+1)+cnt*rice[e])
    return dp[s][e]

print(get_maxvalue(0, n-1, 1))
```

이 코드를 재귀가 아니라 반복문으로 구현해줘.
