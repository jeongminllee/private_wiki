### ❓ 질문 (User)
문제
Sogang ICPC Team에는 색상 이름과 닉네임의 순서로 이여서 팀명을 지으면 ICPC 리저널에서 수상할 수 있다는 전설이 있다. 색상 이름들과 닉네임들이 주어질 때, Q개의 팀에 대해 다음 리저널에서 수상할 수 있을지 전설에 기반해 알려주는 프로그램을 작성하자.

입력
첫째 줄에는 색상의 종류 C와 닉네임의 개수 N이 주어진다. (1 ≤ C, N ≤ 4,000)

다음 C개의 줄에는 색상 이름 C개가 한 줄에 하나씩 주어진다. 색상 이름은 중복되지 않는다.

다음 N개의 줄에는 Sogang ICPC Team 구성원들의 닉네임 N개가 한 줄에 하나씩 주어진다. 닉네임도 중복되지 않는다.

다음 줄에는 팀의 개수 Q가 주어진다. (1 ≤ Q ≤ 20,000)

다음 Q개의 줄에는 팀명 Q개가 한 줄에 하나씩 주어진다. 팀명은 중복되지 않는다.

모든 색상 이름의 길이와 닉네임의 길이는 1,000글자를 넘지 않는다. 모든 팀명은 2,000글자를 넘지 않는다. 모든 문자열은 알파벳 소문자로만 이루어져 있다.

출력
팀명이 입력된 순서대로, 전설에 따라 해당 팀이 다음 리저널에서 수상할 수 있다면 Yes, 아니라면 No를 출력한다.

### 💡 답변 (Assistant)
### 코드 설명:
1. **입력 처리**:
   - 첫 줄에서 `C`(색상의 개수)와 `N`(닉네임 개수)을 입력받습니다.
   - `C`개의 색상과 `N`개의 닉네임을 각각 `set`에 저장합니다.
   - `Q`(팀명 개수)를 입력받고, `Q`개의 팀명을 처리합니다.

2. **팀명 판별**:
   - 각 팀명을 1부터 `len(팀명)-1`까지 두 부분으로 나누어 검증합니다.
   - 앞부분이 `colors`에 있고, 뒷부분이 `nicknames`에 있으면 `Yes`를 기록하고 반복을 종료합니다.
   - 끝까지 조건을 만족하지 못하면 `No`를 기록합니다.

3. **출력 최적화**:
   - `sys.stdout.write()`를 사용하여 한 번에 출력하여 성능을 개선합니다.

이 코드는 `O(Q * M) (M: 평균 팀명 길이)`의 시간 복잡도를 가지며, 효율적으로 문제를 해결합니다. 🚀

## 🔹 **코드 분석**
### 1️⃣ **트라이(Trie) 구축 (색상 저장)**
```python
C, N = map(int, input().split())  
colors = {}  # 트라이의 루트 노드

for _ in range(C):  
    now = colors  # 트라이 탐색 시작 노드  
    for c in input().strip():  # 한 글자씩 트라이에 저장  
        if not now.get(c):  
            now[c] = {}  
        now = now[c]  
    now[0] = 1  # 종료 지점(해당 색상이 존재함을 표시)
```
- 색상 이름을 트라이(Trie) 자료구조에 저장해.
- `now[0] = 1`을 추가하여 **해당 노드가 완전한 색상 문자열의 끝**임을 표시해.
- 예를 들어, `"blue"`라는 색상이 입력되면, 트라이는 다음과 같이 만들어져:
  ```python
  colors = {
      'b': {
          'l': {
              'u': {
                  'e': { 0: 1 }  # 'blue'의 끝을 나타냄
              }
          }
      }
  }
  ```

---

### 2️⃣ **닉네임 저장 (해시셋 활용)**
```python
names = {input().strip() for i in range(N)}
```
- **닉네임을 `set`에 저장**해 빠르게 조회할 수 있도록 함.  
  `set`은 **O(1)** 시간 복잡도로 존재 여부를 확인할 수 있어.

---

### 3️⃣ **팀명 확인 (`check` 함수)**
```python
def check(word):
    now = colors  # 트라이의 루트에서 탐색 시작
    for i in range(len(word)):  # 팀명을 한 글자씩 확인
        if now.get(0) and word[i:] in names:  # 색상 부분이 완성됐고, 남은 부분이 닉네임에 있으면
            return 1  # 팀명 조건 만족 -> Yes
        if not now.get(word[i]):  # 현재 글자가 트라이에 없으면 종료
            return
        now = now[word[i]]  # 다음 노드로 이동
```
✔ **색상 부분이 트라이에 존재하는지 확인**  
✔ **남은 부분이 닉네임 `set`에 있는지 확인**  

- `if now.get(0) and word[i:] in names:`  
  - **현재까지 탐색한 색상이 완전한 색상(`0` 키가 있음)**  
  - **남은 부분이 닉네임 `set`에 존재하는지 확인**  
  - 만족하면 **바로 `1`을 반환** → `Yes` 출력  

이 방식은 **가능한 조합을 찾으면 즉시 탐색을 멈춰서** 불필요한 연산을 줄여줘.

---

### 4️⃣ **팀명 판별 실행**
```python
for _ in range(int(input())):
    print("Yes" if check(input().strip()) else "No")
```
- `check` 함수를 이용해 팀명이 조건을 만족하는지 확인
- `Yes` 또는 `No`를 출력

## 🔹 **시간 초과를 해결한 핵심 최적화**
### ✅ 1. **닉네임을 `set`에 저장하여 O(1) 조회**
  - 내가 준 코드는 `nickname_trie.exists(nickname_part)`를 호출하여 닉네임을 트라이에서 검색했어.  
  - 하지만 **트라이를 활용한 단어 탐색은 O(K) (K: 문자열 길이)** 라서 많은 닉네임이 있으면 성능이 떨어져.
  - 반면 **해시셋(`set`)은 평균 O(1)**이므로 **훨씬 빠르게 조회 가능**!

### ✅ 2. **색상 검색 중간에 즉시 반환 (`now.get(0)`)**
  - 내가 준 코드는 **문자열을 완전히 분할한 후 색상과 닉네임을 각각 검사**했어.
  - 하지만 이 코드는 **트라이에서 색상을 탐색하는 중간에 닉네임을 즉시 검사**해.  
  - 따라서 **가능한 팀명을 찾으면 빠르게 반환**하여 **불필요한 탐색을 줄임**!

### ✅ 3. **불필요한 트라이 탐색 방지**
  - 내가 준 코드는 **트라이에 색상과 닉네임을 모두 저장해서 검색**했어.
  - 하지만 이 코드는 **닉네임을 따로 `set`에 저장하고, 색상만 트라이에서 찾음**.
  - 즉, **닉네임을 찾기 위해 트라이를 추가로 탐색할 필요가 없음** → **성능 향상**.

### ❓ 질문 (User)
strip() 을 붙이고 안붙이고 차이가 있어?

### 💡 답변 (Assistant)
`strip()`을 붙이고 안 붙이고의 차이는 **문자열 앞뒤 공백(개행 포함) 제거 여부**야.  

### `strip()`을 사용하는 이유  
`sys.stdin.readline()`은 입력을 받을 때 **줄 끝에 개행 문자(`\n`)를 포함**해.  
이걸 그대로 사용하면 **문자열 비교할 때 문제가 생길 수 있어**.  

예를 들어,  
```python
names = set()
names.add("joker")  # "joker\n"이 아니라 "joker"를 저장

word = sys.stdin.readline()  # 예를 들어 "joker\n"을 입력받음
if word in names:
    print("Found")
else:
    print("Not Found")
```
이러면 `word`에는 `"joker\n"`이 들어가니까 `names`에 `"joker"`가 있어도 `word in names`가 `False`가 돼.

### 해결책  
`strip()`을 써서 개행 문자(`\n`)를 제거하면 `"joker"`로 정상 비교할 수 있어.  
```python
word = sys.stdin.readline().strip()  # "joker\n" -> "joker"
```

### 결론  
- **`strip()`을 붙이면 문자열 앞뒤 공백(특히 개행 문자)을 제거해서 비교가 정확해짐.**
- **`strip()`을 안 붙이면 `\n`이 포함된 채로 저장·비교될 가능성이 있음.**  
  (의도하지 않은 결과 발생 가능)  
- **파일에서 입력을 받을 때는 `strip()`을 쓰는 게 일반적으로 안전함.**
