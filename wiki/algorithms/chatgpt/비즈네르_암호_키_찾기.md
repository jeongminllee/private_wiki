# 비즈네르 암호 키 찾기

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
비즈네르 암호는 고전 암호의 일종으로, 대문자 알파벳으로만 이뤄진 평문에 키를 더하여 암호를 만드는 방법이다. 구체적인 과정은 다음과 같다.

평문과 동일한 길이가 될 때까지 키를 반복하여 문자열을 만든다. 이 문제에선 키를 단순 반복해 평문과 동일한 길이를 만들 수 있는 경우만 고려한다.
평문과 키의 각 알파벳을 1부터 26까지의 수에 순서대로 대응시켜 수열을 만든다. 즉, A=1, B=2, ..., Z=26가 된다.
평문과 키 수열에서 동일한 위치에 있는 수들을 더하여 암호문을 만든다. 단, 더했을 때 26이 넘는 수의 경우 26만큼 뺀 결과를 사용한다.
2와 마찬가지로, 암호문에서 수를 다시 알파벳에 대응시켜 문자열로 만들고 최종 결과로 반환한다.
예를 들어, 평문이 HELLOWORLD이고, 키가 SCUPC라고 하자. 1에서 키를 두 번 반복해 SCUPCSCUPC가 되며, 2에서 수에 대응시키면 키는 
$[19, 3, 21, 16, 3, 19, 3, 21, 16, 3]$, 평문인 HELLOWORLD는 
$[8, 5, 12, 12, 15, 23, 15, 18, 12, 4]$가 된다. 이후 3에서 동일한 위치에 있는 수를 더하면 
$[27, 8, 33, 28, 18, 42, 18, 39, 28, 7]$이며, 26 초과인 수에서 26을 빼면 
$[1, 8, 7, 2, 18, 16, 18, 13, 2, 7]$이 된다. 이를 다시 알파벳에 대응시키면, 최종 결과는 AHGBRPRMBG가 된다.

평문과 임의의 키를 사용해 만든 비즈네르 암호문이 주어질 때, 가능한 키 중 가장 짧은 키를 찾아보자.

입력
첫 번째 줄에 평문이 주어진다. 평문은 알파벳 대문자로만 구성되어 있으며, 평문의 길이는 
$200\,000$을 넘지 않는다.

두 번째 줄에 평문에 대한 비즈네르 암호문이 주어진다. 암호문은 알파벳 대문자로만 구성되어 있으며, 주어진 평문과 동일한 길이를 가진다. 올바른 비즈네르 암호문이 주어지며, 답이 항상 존재함이 보장된다.

출력
첫 번째 줄에 가능한 키 중 가장 짧은 키를 출력한다.

예제 입력 1 
BIGDATASECURITY
UNVYMMFHZONWXOK
예제 출력 1 
SEOUL
예제 입력 2 
HELLOWORLD
KHOORZRUOG
예제 출력 2 
C
예제 입력 3 
HELLOWORLD
AHGBRPRMBG
예제 출력 3 
SCUPC 

```
 # ord("A") = 65
```

### 💡 답변 (Assistant)
이 문제의 핵심은 평문과 암호문의 패턴을 분석하여 **가장 짧은 반복 키**를 찾아내는 것입니다. 현재 작성한 코드에서는 평문과 암호문을 기반으로 키를 만들어내는 부분은 처리되었지만, 가장 짧은 반복 키를 찾는 로직은 추가해야 합니다.

### 힌트
1. **반복 주기 확인**:
   - `res` 문자열에서 반복되는 가장 짧은 주기를 찾아내는 것이 핵심입니다.
   - 이 반복 주기는 키의 길이가 됩니다.

2. **반복 주기 찾기 방법**:
   - KMP 알고리즘에서 사용하는 **접두사-접미사 길이 배열(Prefix Function)**을 응용하여 문자열의 반복성을 찾을 수 있습니다.
   - 또는, 단순히 `res`를 슬라이싱하면서 모든 가능한 길이를 검사하여 반복 여부를 확인할 수도 있습니다.

3. **반복 여부 검증**:
   - 키 길이가 \( k \)일 때, `res[:k]`를 반복하여 전체 `res`를 구성할 수 있다면, \( k \)가 가능한 키 길이가 됩니다.
   - 반복 가능한 모든 \( k \) 중 가장 작은 값을 찾으면 됩니다.

4. **효율성 고려**:
   - 평문과 암호문의 길이가 최대 200,000이므로, 반복 주기를 찾는 과정은 효율적으로 수행되어야 합니다. 전체 길이를 \( n \)이라고 할 때, 시간 복잡도는 \( O(n) \) 또는 \( O(n \log n) \) 수준이어야 적합합니다.

2. 해당 반복 주기의 길이만큼 키를 슬라이싱하여 출력한다.

---

### 1. **Prefix Function을 활용한 방법**
KMP 알고리즘에서 사용하는 **접두사-접미사 길이 배열(Prefix Function)**을 활용하면, 문자열에서 반복되는 패턴을 효율적으로 찾을 수 있습니다.

#### 과정:
1. `res` 문자열에 대해 Prefix Function을 계산합니다.
   - Prefix Function의 정의: \( \text{pi}[i] \)는 \( res[0:i] \)의 접두사와 접미사가 일치하는 최대 길이.
2. `n`을 `len(res)`라고 할 때, 문자열의 가장 짧은 반복 주기 \( k \)는:
   \[
   k = n - \text{pi}[n-1]
   \]
   단, \( n \% k == 0 \)이어야 \( res[:k] \)가 반복 주기로 전체 문자열을 구성합니다.
3. \( res[:k] \)를 반환합니다.

---

### 2. **Brute Force 방법**
모든 가능한 키 길이를 직접 검사하는 방식입니다. \( n \)이 클 경우 비효율적일 수 있으므로, 가능한 한 빠르게 반복 여부를 확인해야 합니다.

#### 과정:
1. `res`의 가능한 키 길이 \( k \)를 \( 1 \)부터 \( n \)까지 검사합니다.
2. 각 \( k \)에 대해 \( res[:k] \)를 반복하여 전체 문자열과 일치하는지 확인합니다.
3. 일치하는 가장 짧은 \( k \)를 찾아 출력합니다.

---

### Prefix Function 코드 예시
다음은 Prefix Function을 사용해 가장 짧은 반복 주기를 찾는 Python 코드의 예입니다:

```python
def find_shortest_repeating_key(s):
    n = len(s)
    # Prefix function array
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    
    # Calculate the shortest period
    k = n - pi[-1]
    if n % k == 0:  # Check if it's a valid period
        return s[:k]
    return s
```

### Brute Force 코드 예시
다음은 가능한 모든 키 길이를 검사하는 코드입니다:

```python
def find_shortest_repeating_key(s):
    n = len(s)
    for k in range(1, n + 1):
        if n % k == 0:  # Only consider lengths that divide the string length
            if s[:k] * (n // k) == s:
                return s[:k]
    return s
```

---

### 효율성 비교
- **Prefix Function**: 시간 복잡도 \( O(n) \).
- **Brute Force**: 최악의 경우 \( O(n^2) \), 그러나 특정 조건에서는 간단하고 빠르게 구현할 수 있음.

### 💡 답변 (Assistant)
다음은 주어진 문제를 해결하는 Python 정답 코드입니다. 이 코드는 **Prefix Function**을 사용하여 가장 짧은 반복 키를 찾아냅니다:

```python
def find_shortest_repeating_key(plain, cipher):
    # Step 1: Calculate the intermediate key sequence from plain and cipher
    res = ''
    for i in range(len(plain)):
        diff = ord(cipher[i]) - ord(plain[i])
        if diff < 0:
            diff += 26
        res += chr(diff + 65)  # Convert to uppercase letter
    
    # Step 2: Find the shortest repeating key using Prefix Function
    n = len(res)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and res[i] != res[j]:
            j = pi[j - 1]
        if res[i] == res[j]:
            j += 1
        pi[i] = j
    
    # The shortest period
    k = n - pi[-1]
    if n % k == 0:  # Check if k is a valid period
        return res[:k]
    return res

# Input and output handling
plain = input()
cipher = input()
print(find_shortest_repeating_key(plain, cipher))
```

---

### 코드 설명
1. **Intermediate Key 생성**:
   - 평문과 암호문의 알파벳 차이를 계산하여 키를 복원합니다.
   - `diff`를 계산할 때 26을 더해 음수 방지를 하고, 다시 알파벳으로 변환합니다.

2. **Prefix Function 계산**:
   - \( \text{pi}[i] \): \( res[0:i] \)에서 접두사와 접미사가 일치하는 최대 길이.
   - 이를 통해 가장 짧은 반복 주기를 계산합니다.

3. **최단 반복 키 반환**:
   - 반복 주기 \( k = n - \text{pi}[n-1] \).
   - \( n \% k == 0 \) 조건을 확인하여, 유효한 반복 주기인지 검사합니다.
