# 전기톱 비용 최소화

> **카테고리**: `Algorithms (알고리즘 & 자료구조)`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
높이가 a1, a2, ..., an인 나무 n개를 전기톱을 이용해서 자르려고 한다.

i번 나무에 전기톱을 사용할 때 마다 그 나무의 높이는 1만큼 감소한다. 전기톱은 사용할 때 마다 충전해야 한다. 전기톱을 충전하는 비용은 완전히 자른 나무의 번호에 영향을 받는다. 즉, 높이가 0이 되어버린 나무의 번호에 영향을 받는다. 완전히 잘려진 나무의 번호 중 최댓값이 i이면, 전기톱을 충전하는 비용은 bi이다. 완전히 잘려진 나무가 없다면 전기톱은 충전할 수가 없다. 가장 처음에 전기톱은 충전되어져 있다.

나무의 높이 ai와 각각의 나무에 대한 충전 비용 bi가 주어졌을 때, 모든 나무를 완전히 자르는데 (높이를 0으로 만드는데) 필요한 충전 비용의 최솟값을 구하는 프로그램을 작성하시오. 

입력
첫째 줄에 n(1 ≤ n ≤ 100,000)이 주어진다. 둘째 줄에는 a1, a2, ..., an이, 셋째 줄에는 b1, b2, ..., bn이 주어진다. (1 ≤ ai ≤ 109, 0 ≤ bi ≤ 109)

a1 = 1이고, bn = 0이며, a1 < a2 < ... < an, b1 > b2 > ... > bn을 만족한다.

출력
나무를 완전히 자르는 충전 비용의 최솟값을 출력한다.

예제 입력 1 
5
1 2 3 4 5
5 4 3 2 0
예제 출력 1 
25
예제 입력 2 
6
1 2 3 10 20 30
6 5 4 3 2 0
예제 출력 2 
138

### 💡 답변 (Assistant)
이 문제는 그리디 알고리즘을 이용해서 해결할 수 있습니다. 문제에서 요구하는 것은 **모든 나무를 완전히 자르는 데 필요한 충전 비용의 최솟값**입니다. 문제의 조건을 바탕으로 풀이 전략을 세우겠습니다.

---

### 문제 분석 및 해결 전략

1. **나무의 높이 감소 과정**  
   전기톱을 사용할 때마다 나무의 높이가 1씩 감소합니다. 모든 나무의 높이를 0으로 만들기 위해 각 나무를 자르는 데 필요한 횟수는 높이 \(a_i\)입니다.

2. **충전 비용 계산**  
   - 나무를 완전히 자를 때마다 전기톱을 충전해야 합니다.
   - 나무가 완전히 잘려 높이가 0이 되었을 때, 그 나무의 번호 중 가장 큰 번호 \(i\)를 기준으로 충전 비용 \(b_i\)가 결정됩니다.
   - 충전 비용은 문제에서 \(b_1 > b_2 > \dots > b_n\) 조건이 주어졌기 때문에, **높은 번호의 나무를 완전히 자르는 일이 충전 비용을 최소화하는 데 중요합니다.**

3. **풀이 방법**
   - 가장 높은 번호의 나무부터 시작하여, 나무의 높이를 모두 자릅니다.
   - 나무를 자르는 과정에서 충전 비용을 최소화하려면, 각 나무를 자를 때마다 현재까지 완전히 자른 나무의 번호 중 최대값을 유지하면서 비용을 누적합니다.

---

### 구현 계획

1. 입력을 받아 나무의 높이 리스트 \(a\)와 충전 비용 리스트 \(b\)를 저장합니다.
2. \(a_i\) 값을 기준으로 모든 나무를 0으로 만들고, \(b\) 값을 기반으로 비용을 누적합니다.
3. 최종적으로 누적된 비용을 출력합니다.

---

### 구현 코드

```python
def min_cutting_cost(n, heights, costs):
    total_cost = 0
    max_cost_index = -1  # 현재까지 완전히 자른 나무의 최대 번호
    
    for i in range(n - 1, -1, -1):  # 높은 번호의 나무부터 처리
        # 나무 i를 자르기 위해 필요한 비용을 누적
        total_cost += heights[i] * (costs[max_cost_index] if max_cost_index != -1 else costs[i])
        max_cost_index = i  # 나무 i를 완전히 잘랐으므로 갱신
    
    return total_cost

# 입력 처리
n = int(input())
heights = list(map(int, input().split()))
costs = list(map(int, input().split()))

# 결과 출력
print(min_cutting_cost(n, heights, costs))
```

### 시간 복잡도

1. 입력 크기 \(n\)에 대해 단일 루프를 실행합니다.
2. 각 루프에서 최대 비용의 인덱스 갱신은 \(O(1)\)입니다.

따라서 시간 복잡도는 \(O(n)\)입니다.
