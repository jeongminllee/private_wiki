# Summary

[루틴 index](../routine/index.md)에 전체 문서를 월별로 연결했다. 기존 과목 원문과 체크 값은 보존하고, 10/7~10/13 체크리스트 7개의 들여쓰기만 복구했다. 작업 도중 사용자가 편집한 생성기는 사용자 선택에 따라 그대로 유지했다.

# Findings

## 1. OKF 형식

- 4개 과목의 316개 문서에는 YAML frontmatter와 `type`, `description`이 없다.
- 체크리스트 72개는 열 0의 frontmatter 구분자를 갖고 있었다. 10/7~10/13의 7개는 닫는 `---`, 제목과 체크 항목이 4칸 들여쓰기돼 있었다. 이 7개는 이번에 형식을 복구했고 체크 값·문구·링크는 유지했다.
- 기존 과목 문서의 메타데이터 일괄 보완은 후속 작업이다. 브리핑의 여러 항목을 하나의 Concept으로 취급하기보다 자료 성격을 표시하고, 재사용할 지식은 작은 문서로 분리한다.

## 2. AI 브리핑 중복과 날짜 충돌

[8/28 AI](../routine/ai_paper/2026-08-28/2026-08-28.md)와 [8/29 AI](../routine/ai_paper/2026-08-29/2026-08-29.md)는 파일 전체가 같다. 8/29 파일의 본문 날짜도 8/28로 명시돼 있다. 따라서 파일명은 채워져 있지만 실제 8/29 브리핑은 확인되지 않는다.

원본 날짜를 확인하기 전에는 제목만 8/29로 바꾸거나 한쪽을 삭제하지 않는다. 이는 단순 파일 중복을 넘어 날짜별 내용의 충돌이다.

## 3. 체크리스트 검토 후보

체크 항목은 총 316개이고 기존 `[x]`는 163개다. 9/10~10/13의 체크리스트 34개는 모두 미체크다. 이 기간에 본문이 있는 미체크 항목은 AI 34개·경제 34개·영어 24개·채용 29개로 합계 121개다.

[변경 기록](../../log.md)의 2026-09-16 및 2026-09-01 항목에는 주말 영어와 신규 공고 없음은 미체크로 유지하는 정책이 있다. 본문이 있다는 이유만으로 완료 표시를 자동 변경하지 않았다.

[8/1 체크리스트](../routine/checklist/2026-08-01.md)와 [8/2 체크리스트](../routine/checklist/2026-08-02.md)는 영어가 체크돼 있지만 대상 파일은 제목만 있다. 당시 완료 표시의 의미를 확인할 후보로 남긴다.

## 4. 대화 세션 인용과 다운로드 잔여

전체 84개 문서에 세션 전용 인용 또는 다운로드 링크가 남아 있다. 자동 집계는 다음과 같다.

| 잔여 형식 | 개수 |
| --- | ---: |
| `:chatgpt-content-reference{...}` | 1,246 |
| 내부 `cite` 토큰 | 473 |
| 내부 `url` 토큰 | 185 |
| `sandbox:` Markdown 링크 | 8 |

- AI 28개·경제 33개는 세션 전용 인용을 포함한다. AI 7개·경제 8개에는 HTTP URL 자체가 없다. 채용도 본문 67개 중 6개에 외부 URL이 없다.
- 특히 9/2~9/9 AI·경제 16개 중 15개는 HTTP URL 없이 내부 인용만 남아 있다. [경제 원문](../../raw/journal/us_economy_briefing_2026-09-02_to_2026-09-09_verbatim.md)에도 같은 내부 인용만 있어 이 원문만으로 URL을 복구할 수 없다.
- 대표: [9/10 AI](../routine/ai_paper/2026-09-10/2026-09-10.md), [9/10 경제](../routine/economy/2026-09-10/2026-09-10.md). 인용 토큰을 지우는 작업보다 출처 복구와 미복구 표시가 먼저다.
- [10/7 AI](../routine/ai_paper/2026-10-07/2026-10-07.md)의 앞 21행에는 9/30~10/6 ZIP·개별 파일 다운로드 안내가 섞여 있다. 그 뒤에는 10/7 브리핑 본문이 있다. 개별 Markdown 링크 7개는 해당 날짜의 로컬 문서와 대응하고, ZIP은 별도 확인이 필요하다.
- 경제 15개에는 검색 카드 부산물과 `images.openai.com/static-rsc` 링크 63개가 남아 있다. [10/13 경제](../routine/economy/2026-10-13/2026-10-13.md) 후반부가 대표다. 기사 URL을 유지하면서 카드 반복만 정리할 수 있다.

외부 사실의 정확성이나 링크의 현재 접근 가능성은 이번 점검에서 검증하지 않았다. 날짜별 원문을 근거가 확인된 영구 지식으로 승격할 때 확인한다.

# Changes and Validation

- 루트 index와 README의 루틴 진입점을 실제 `index.md`로 연결하고 사용법을 갱신했다.
- [생성기](../routine/days.py)는 작업 도중 당일 생성과 정상 체크리스트 들여쓰기로 다시 편집됐다. 사용자가 현재 편집 유지를 선택해 추가 변경하지 않았고, [배치 실행기](../routine/run_today.bat)의 이번 변경도 원래 상태로 되돌렸다. 현재 과목 노트는 제목만 생성되며 날짜/기간 CLI는 없다. Python `input()`과 배치 `pause`의 중복 대기는 후속 개선 후보다.
- [점검 스크립트](../../scripts/audit_routine.py)는 날짜·본문 유무·frontmatter 구분자/필드·중복·세션 잔여·index 누락·로컬 링크를 집계한다. YAML 전체 문법, 모든 Markdown 문법, 외부 링크나 의미적 주장 충돌까지 검증하는 범용 linter는 아니다.
- 체크리스트 79개의 YAML 파싱과 각 4개 체크 항목, 전체 395개 파일의 index 연결 및 점검 문서의 로컬 링크를 확인했다. 실제 날짜별 기록을 추가 생성하지 않았다.
- 체크리스트 7개는 줄별 텍스트를 비교해 들여쓰기 외 문구·체크 값·링크가 같음을 확인했다.
