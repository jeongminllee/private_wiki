# Day 32 — Explaining Why a Strong Average Can Hide Important Failure Cases

오늘 목표는 **평균 성능이 높더라도 특정 subgroup이나 edge case에서 심각하게 실패할 수 있다는 점을 설명하는 것**입니다. 오늘은 **overall metric → subgroup analysis → hidden failure → practical consequence → targeted evaluation** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A model achieves 94% overall accuracy, but its accuracy drops to 68% for one important subgroup of users. Would you still consider the model successful?

답변에는 **전체 평균 성능, subgroup 성능, 왜 평균만 보면 문제가 숨겨질 수 있는지, 실무적으로 어떤 위험이 있는지, 무엇을 추가로 평가해야 하는지**를 포함하세요.

시작은 이렇게 해보세요.

> The overall accuracy looks strong, but the subgroup result raises an important concern that the average metric may be hiding.

## 2. Reusable Speaking Templates — 3분

### Template 1: 평균과 세부 성능 분리

> The overall metric is **[strong/high]**, but it masks substantial variation across **[groups/conditions]**.

예:

> The overall accuracy is high, but it masks substantial variation across user groups.

### Template 2: 특정 실패가 중요한 이유 설명

> Poor performance on **[subgroup]** is particularly concerning because **[practical consequence]**.

예:

> Poor performance on this subgroup is particularly concerning because these users represent a critical deployment population.

### Template 3: 추가 평가 제안

> I would break down performance by **[dimension]** rather than relying on the aggregate score alone.

예:

> I would break down performance by user group, data source, and difficulty level rather than relying on the aggregate score alone.

---

## 3. Useful Words & Expressions — 4분

### 1. aggregate
**전체를 합친, 집계된**

> The aggregate accuracy is high, but subgroup performance varies considerably.

자주 쓰는 표현은 `aggregate metric`, `aggregate result`, `aggregate performance`입니다.

---

### 2. mask
**문제를 가리다, 숨기다**

> A strong average score can mask poor performance on minority groups.

일상 영어에서도 쓸 수 있습니다.

> The overall improvement masked several underlying problems.

---

### 3. subgroup
**하위 집단**

> We should evaluate the model separately for each subgroup.

논문에서는 다음과 같이 자주 나옵니다.

> subgroup analysis

---

### 4. disparity
**집단 간 성능 격차**

> There is a substantial performance disparity between the two groups.

`difference`보다 **문제가 될 수 있는 격차**라는 의미가 조금 더 강합니다.

> The study found disparities in error rates across user groups.

---

### 5. edge case
**일반적이지 않지만 실제로 발생할 수 있는 특수 상황**

> The model performs well on average but fails on several important edge cases.

실무에서 매우 자주 씁니다.

> We need more targeted tests for edge cases before deployment.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> The average score is high, so the model performs good.

정답:

> The average score is high, so the model performs well overall.

설명: `perform`은 동사이므로 형용사 `good`이 아니라 부사 `well`을 사용합니다.

- performs good ❌
- performs well ✅

그리고 `overall`을 넣으면 **전체 성능에 한정한 주장**이라는 점이 더 명확해집니다.

---

### 2

> But one group has very lower accuracy.

정답:

> However, one group has much lower accuracy.

설명:

- very lower ❌
- much lower ✅
- significantly lower ✅

비교급을 강조할 때는 `much`, `far`, `significantly` 등을 사용합니다.

---

### 3

> We should not only see average performance.

더 자연스럽게:

> We should not look only at average performance.

또는:

> We should not rely solely on aggregate performance.

설명: `see performance`보다 `look at`, `examine`, `rely on`이 자연스럽습니다.

---

### 4

> This problem can be hidden by average score.

정답:

> This problem can be hidden by the average score.

더 자연스럽게:

> The average score can mask this problem.

설명: 기술 영어에서는 `mask`를 쓰면 훨씬 간결하고 자연스럽습니다.

---

### 5

> We need to evaluate each groups separately.

정답:

> We need to evaluate each group separately.

설명:

`each` 뒤에는 단수명사가 옵니다.

- each groups ❌
- each group ✅

복수로 쓰고 싶다면:

> We need to evaluate different groups separately.

라고 하면 됩니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 말해보세요.

> The overall accuracy is …  
> However, this aggregate metric may mask …  
> One subgroup performs substantially worse, which is concerning because …  
> This suggests that the model’s errors are not distributed evenly across …  
> I would therefore examine …  
> Before deployment, I would want to determine whether …  
> Based on the current evidence, I would describe the model as …

오늘은 특히 **“overall performance가 높다”와 “모든 사용자에게 잘 작동한다”를 구분해서 말하는 것**에 집중하세요.

초급식 표현:

> The model is 94% accurate, so it is very good.

더 정확한 표현:

> The model achieves 94% overall accuracy, but performance is substantially lower for one subgroup.

C1에 가까운 표현:

> Although the aggregate accuracy is strong, the large subgroup disparity suggests that the overall metric may obscure an important failure mode.

## Compact Model Answer — 1분

> I would not consider the model fully successful based on the 94% overall accuracy alone. The aggregate result is strong, but it masks a substantial performance drop for one subgroup, where accuracy falls to 68%. This disparity is important because the model may behave reliably for most users while failing much more frequently for a specific population. I would therefore analyze precision, recall, and error types separately for each subgroup and investigate whether the gap is caused by data imbalance, distribution differences, or insufficient representation during training. Before deployment, I would want to reduce this disparity or at least understand its operational consequences. Based on the current evidence, I would describe the model as promising overall but insufficiently robust across user groups.

오늘 입에 붙일 세 문장은 이것입니다: **“The aggregate metric may mask important variation.” → “There is a substantial performance disparity across subgroups.” → “I would break down performance rather than relying on the average alone.”**
