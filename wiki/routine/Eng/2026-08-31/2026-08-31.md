# Day 26 — Explaining Calibration: When Confidence Scores Can Be Trusted

오늘 목표는 **모델의 accuracy와 confidence를 구분하고, 예측 확률이 실제 빈도와 얼마나 잘 맞는지 설명하는 것**입니다. 오늘은 단순히 “confidence가 높다”가 아니라 **prediction → confidence → calibration → practical decision** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A classifier predicts some cases with 90% confidence. Does that mean 90% of those predictions are actually correct? How would you verify whether the confidence scores are trustworthy?

답변에는 다음 내용을 포함하세요: confidence와 accuracy의 차이, calibration의 의미, 잘못 보정된 confidence가 왜 위험한지, 그리고 어떻게 확인할지.

시작은 이렇게 해보세요.

> A confidence score of 90% does not automatically mean that the prediction is correct 90% of the time.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **confidence와 실제 정확도를 구분**할 때 사용합니다.

> A predicted probability of **[X%]** should ideally correspond to an empirical accuracy of approximately **[X%]**.

예:

> Predictions assigned 80% confidence should ideally be correct about 80% of the time.

두 번째는 **calibration이 잘못된 상황을 설명**할 때 유용합니다.

> The model may be **[overconfident / underconfident]** if its predicted probabilities systematically **[overestimate / underestimate]** actual correctness.

예:

> The model may be overconfident if 90%-confidence predictions are correct only 70% of the time.

세 번째는 **검증 방법을 제안**할 때 씁니다.

> To assess calibration, I would compare **[predicted probabilities]** with **[observed frequencies]** across **[groups/bins]**.

예:

> To assess calibration, I would compare predicted confidence with observed accuracy across probability bins.

## 3. Useful Words & Expressions — 4분

**calibrated**는 모델이 내놓은 확률과 실제 빈도가 잘 맞는 상태를 뜻합니다.

> A well-calibrated model should make 70%-confidence predictions that are correct roughly 70% of the time.

**overconfident**는 실제 정확도보다 confidence를 지나치게 높게 주는 상태입니다.

> The model appears overconfident on out-of-distribution samples.

일반 영어에서도 가능합니다.

> He sounded overconfident despite having limited evidence.

**underconfident**는 실제 성능에 비해 confidence를 지나치게 낮게 주는 경우입니다.

> The classifier is accurate but slightly underconfident.

**reliability diagram**은 confidence 구간과 실제 정확도를 비교하는 시각화입니다.

> A reliability diagram can reveal whether predicted probabilities match observed frequencies.

**empirical**은 이론이나 추측이 아니라 실제 관측 데이터에 기반한다는 뜻입니다.

> The empirical accuracy was lower than the predicted confidence.

논문에서 매우 자주 등장하는 조합은 `empirical evidence`, `empirical results`, `empirical distribution`입니다.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

1. `The model has 90% confidence, so it is 90% correct.`
   → **A 90% confidence score does not necessarily mean that the prediction is correct 90% of the time.**
   한 개의 prediction에는 맞다/틀리다만 존재합니다. 90%라는 값은 **유사한 confidence를 가진 많은 예측 집단에서의 빈도적 의미**로 해석해야 합니다.

2. `The confidence is higher than real accuracy.`
   → **The predicted confidence is higher than the observed accuracy.**
   연구 영어에서는 `real accuracy`보다 `observed accuracy` 또는 `empirical accuracy`가 더 정확합니다.

3. `The model is too confidence.`
   → **The model is too confident.**
   `confidence`는 명사, `confident`는 형용사입니다.

   * high confidence ✅
   * highly confident ✅
   * too confidence ❌

4. `We need to check calibration by each probability ranges.`
   → **We need to check calibration across different probability ranges.**
   `each` 뒤에는 단수명사가 와야 합니다. 하지만 여기서는 여러 구간을 전체적으로 비교하므로 `across different probability ranges`가 자연스럽습니다.

5. `If confidence and accuracy are similar, calibration is good.`
   → **If predicted confidence closely matches observed accuracy, the model is well calibrated.**
   `similar`도 가능하지만 `closely matches`가 관계를 더 정확하게 표현합니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> The model predicts some cases with …
> However, confidence should not be interpreted as …
> For the model to be well calibrated, …
> If 90%-confidence predictions are correct only …, the model is …
> This matters because …
> To evaluate calibration, I would …
> If necessary, I would then …

오늘은 특히 **probability와 correctness를 분리해서 말하는 것**에 집중하세요.

초급식 표현:

> The model is 90% sure, so the answer is probably correct.

더 정확한 표현:

> The model assigns 90% confidence, but that score is meaningful only if the model is well calibrated.

C1에 가까운 표현:

> A confidence score is useful only to the extent that it corresponds to observed frequencies; otherwise, it may create a false sense of certainty.

## Compact Model Answer — 1분

> A 90% confidence score does not automatically mean that an individual prediction is 90% correct. Instead, if the model is well calibrated, predictions assigned around 90% confidence should be correct roughly 90% of the time across many examples. A model is overconfident when its predicted probabilities are systematically higher than its observed accuracy, and this can be risky in applications where confidence scores influence decisions or thresholds. To assess calibration, I would group predictions into confidence bins and compare the average predicted probability with the empirical accuracy in each bin. I would also examine a reliability diagram and calibration metrics. If the model is poorly calibrated, I would consider applying a calibration method before using its confidence scores for operational decisions.

오늘 입에 붙일 세 문장은 이것입니다: **“Confidence does not necessarily equal correctness.” → “A well-calibrated model should match predicted probabilities with observed frequencies.” → “Overconfidence can create a false sense of certainty.”**
