# Day 24 — Explaining Reproducibility and Why One Good Run Is Not Enough

오늘 목표는 **한 번 잘 나온 결과를 믿는 것과, 여러 조건에서 반복해서 같은 결론을 얻는 것을 구분해서 설명하는 것**입니다. 오늘은 **single result → reproducibility → sources of variation → stronger evidence** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> Your model achieves its best accuracy in one run, but the result drops noticeably when you repeat the experiment with different random seeds. Would you report the best score, the average score, or both? Why?

답변에는 다음 내용을 포함하세요: 가장 높은 점수만 보고하는 것이 왜 위험할 수 있는지, 여러 run이 왜 필요한지, 어떤 통계값을 함께 보고할지, 그리고 어떤 결과를 더 신뢰할 것인지.

시작은 이렇게 해보세요.

> I would not rely on the best run alone because it may not be representative of the model’s typical performance.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **한 번의 결과에 대한 경계**를 표현할 때 유용합니다.

> A single run may not be representative of **[typical behavior]**, especially when **[source of variation]**.

예:

> A single run may not be representative of the model’s typical behavior, especially when performance is sensitive to random initialization.

두 번째는 **무엇을 보고할지 설명**할 때 씁니다.

> I would report **[metric]** together with **[uncertainty measure]** to provide a more reliable picture of performance.

예:

> I would report the mean accuracy together with the standard deviation to provide a more reliable picture of performance.

세 번째는 **재현성이 주장에 어떤 영향을 주는지 설명**할 때 좋습니다.

> If the improvement can be reproduced across **[runs/settings]**, that would strengthen the claim that **[conclusion]**.

예:

> If the improvement can be reproduced across multiple seeds and datasets, that would strengthen the claim that the method is genuinely effective.

## 3. Useful Words & Expressions — 4분

**reproducible**은 비슷한 조건에서 같은 결과를 다시 얻을 수 있다는 뜻입니다.

> The improvement should be reproducible across independent runs.

논문에서 매우 중요합니다.

> The reported result was difficult to reproduce.

**representative**는 어떤 값이 전체적인 경향을 얼마나 잘 나타내는지 말할 때 씁니다.

> The best score may not be representative of typical model performance.

일상 영어에서도 가능합니다.

> This example is not representative of my usual work.

**variance**는 결과가 평균 주변에서 얼마나 흔들리는지를 나타냅니다.

> High variance across random seeds makes the result less reliable.

말하기에서는 굳이 수식을 설명하지 않아도 됩니다.

> The main issue is the large variance across runs.

**random initialization**은 학습 시작 시 모델 파라미터의 초기값이 무작위로 정해지는 것을 의미합니다.

> The model appears to be sensitive to random initialization.

`random seed`와 연결해서 자주 사용합니다.

**cherry-pick**은 자신에게 유리한 결과만 골라서 제시한다는 뜻입니다.

> Reporting only the best run could be seen as cherry-picking the results.

강한 표현이므로 상대 연구를 비판할 때는 신중하게 쓰는 것이 좋습니다.

좀 더 부드럽게는:

> Reporting only the best run may give an overly optimistic picture.

라고 할 수 있습니다.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

1. `We need to repeat the experiment several times for reliability.`
   → **We need to repeat the experiment several times to assess its reliability.**
   `for reliability`도 의미는 전달되지만 목적을 명확하게 하려면 `to assess`가 자연스럽습니다.

2. `The result changes depending on random seed.`
   → **The result varies depending on the random seed.**
   기술 영어에서는 `changes`보다 `varies`가 자연스럽고, 특정 조건으로서의 seed를 말할 때 `the random seed`가 좋습니다.

3. `We should report average and standard deviation together.`
   → **We should report the mean and standard deviation together.**
   통계 문맥에서는 `average`보다 `mean`이 더 정확합니다.

4. `The best score is not always showing the real performance.`
   → **The best score does not always reflect the model’s true performance.**
   `showing`보다 `reflect`가 자연스럽고, 일반적인 사실을 말하므로 현재진행형을 쓰지 않습니다.

5. `If we can reproduce same result, we can trust more.`
   → **If we can reproduce the same result, we can have greater confidence in the finding.**
   `same` 앞에는 보통 `the`가 필요합니다. 또한 `trust more`보다 `have greater confidence in`이 학술적으로 훨씬 자연스럽습니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> The best run achieved …
> However, a single run may not be representative of …
> The results varied across …
> This suggests that the method may be sensitive to …
> I would therefore report … together with …
> Reporting only the best score could …
> If the improvement is reproducible across …, I would be more confident that …

오늘은 특히 다음 차이를 의식하세요.

초급식 표현:

> The best score is 90%, so the model is good.

더 정확한 표현:

> The model reached 90% accuracy in its best run, but the average performance was lower.

C1에 가까운 표현:

> Although the model achieved 90% accuracy in its best run, the substantial variance across seeds suggests that this score may overstate its typical performance.

핵심은 **최고 점수와 기대 성능을 구분하는 것**입니다.

## Compact Model Answer — 1분

> I would report both the average performance and the best score, but I would place more emphasis on the mean and the variability across runs. A single strong run may not be representative of the model’s typical behavior, particularly if the method is sensitive to random initialization. Reporting only the best result could give an overly optimistic picture of performance. I would therefore include the mean accuracy, standard deviation, and the number of random seeds used in the experiment. If the improvement remains consistent across multiple runs and datasets, I would have greater confidence that the method is genuinely effective rather than benefiting from a favorable random seed.

오늘 입에 붙일 세 문장은 이것입니다: **“A single run may not be representative.” → “I would report the mean together with the standard deviation.” → “Reproducibility would strengthen the claim.”**
