# Day 41 — Explaining Whether a Model Improvement Comes from the New Method

오늘 목표는 **성능이 좋아졌을 때 그 원인이 정말 새롭게 제안한 방법 때문인지 설명하는 것**입니다. 오늘은 연구에서 자주 쓰이는 **ablation study → isolate variables → contribution → evidence strength** 구조를 연습합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A new model performs better than the baseline, but the authors changed the architecture, training data, and optimization method at the same time. Can we conclude that the new architecture caused the improvement?

답변에는 **왜 한 번에 여러 요소를 바꾸면 원인을 알기 어려운지, 어떤 실험이 필요한지, ablation study가 무엇을 보여주는지, 현재 어느 정도까지 결론 내릴 수 있는지**를 포함하세요.

시작은 이렇게 해보세요.

> The overall improvement is clear, but it is difficult to determine which change actually caused the performance gain.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **여러 변수가 동시에 바뀌었다고 설명**할 때 사용합니다.

> Because several factors changed simultaneously, it is difficult to isolate the effect of **[specific factor]**.

예:

> Because several factors changed simultaneously, it is difficult to isolate the effect of the new architecture.

두 번째는 **ablation study를 제안할 때** 유용합니다.

> An ablation study would help determine how much **[component]** contributes to **[result]**.

예:

> An ablation study would help determine how much the new attention mechanism contributes to the performance gain.

세 번째는 **강한 결론을 피할 때** 씁니다.

> Based on the current evidence, we can conclude that **[system]** works better overall, but not that **[single component]** is solely responsible.

예:

> Based on the current evidence, we can conclude that the full system performs better overall, but not that the new architecture is solely responsible.

## 3. Useful Words & Expressions — 4분

**ablation study**는 모델의 일부 요소를 제거하거나 하나씩 바꿔보면서 어떤 구성 요소가 성능 향상에 실제로 기여했는지 확인하는 실험입니다.

> The paper includes an ablation study to measure the contribution of each component.

**isolate**는 여러 요인 중 특정 요인의 효과를 분리해서 본다는 뜻입니다.

> We need to isolate the effect of the new training objective.

일반 영어에서도 쓸 수 있습니다.

> It is difficult to isolate the main cause of the problem.

**contribution**은 특정 요소가 전체 결과에 얼마나 기여했는지를 의미합니다.

> The experiment estimates the contribution of each module.

연구 영어에서 매우 자주 씁니다.

> individual contribution  
> relative contribution  
> contribution to performance

**simultaneously**는 여러 일이 동시에 일어난다는 뜻입니다.

> Several hyperparameters were changed simultaneously.

일상 영어에서는 `at the same time`이 더 쉽고 자연스럽습니다.

> We changed too many things at the same time.

**solely responsible for**는 어떤 결과의 유일한 원인이라는 뜻입니다.

> We cannot conclude that the new module is solely responsible for the improvement.

일반 영어에서도 사용 가능합니다.

> Lack of funding was not solely responsible for the delay.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> They changed many things in one time.

정답:

> They changed many things at the same time.

설명: 한국어의 “한 번에”를 직역해서 `in one time`이라고 하면 어색합니다.

- in one time ❌
- at the same time ✅
- simultaneously ✅

### 2

> So we don't know which one made the result better.

더 자연스럽게:

> So we do not know which change caused the improvement.

설명: `made the result better`도 이해는 되지만, 연구에서는 `caused the improvement`가 훨씬 정확합니다.

### 3

> We should remove each parts and test again.

정답:

> We should remove each component and test the model again.

설명: `each` 뒤에는 단수명사가 옵니다.

- each parts ❌
- each component ✅

또한 모델 구조에서는 `part`보다 `component`가 전문적으로 들립니다.

### 4

> This experiment can know which module is important.

정답:

> This experiment can show which module is important.

또는:

> This experiment can help us determine which module is important.

설명: `experiment can know`는 불가능합니다. 실험은 **알 수 있는 주체**가 아니라 **보여주는 수단**입니다.

- experiment can know ❌
- experiment can show ✅
- help us determine ✅

### 5

> The architecture may not be the only reason of improvement.

정답:

> The architecture may not be the only reason for the improvement.

더 학술적으로:

> The architecture may not be solely responsible for the improvement.

설명:

- reason of ❌
- reason for ✅

그리고 `solely responsible for`는 논문 Discussion에서 매우 자연스럽습니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 말해보세요.

> The new system clearly performs better than …  
> However, several factors were changed simultaneously, including …  
> Therefore, it is difficult to isolate …  
> An ablation study would help …  
> For example, the authors could …  
> If performance drops when … is removed, …  
> Based on the current evidence, I would conclude that …

초급식 표현:

> The new architecture is better because the score increased.

더 정확한 표현:

> The full system performs better, but we do not yet know whether the new architecture caused the improvement.

C1에 가까운 표현:

> Because the architecture, training data, and optimization strategy were modified simultaneously, the current experiment does not allow us to attribute the observed gain to any single component.

## Compact Model Answer — 1분

> The new model clearly outperforms the baseline, but I would not conclude that the architecture alone caused the improvement. The authors changed several factors at the same time, including the architecture, training data, and optimization method. As a result, it is difficult to isolate the contribution of each change. I would therefore want to see an ablation study in which the authors modify one component at a time while keeping the remaining conditions fixed. For example, they could compare the new architecture with the original training data and optimizer. If the performance gain remains under those conditions, the evidence for the architectural contribution would be much stronger. Based on the current results, we can say that the overall system is better, but not that the new architecture is solely responsible.

오늘 입에 붙일 세 문장은 이것입니다: **“It is difficult to isolate the effect of a single component.” → “An ablation study can measure the contribution of each component.” → “The full system performs better, but we cannot attribute the gain to one change alone.”**
