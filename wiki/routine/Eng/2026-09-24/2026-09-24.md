# Day 44 — Explaining Data Leakage and Fair Evaluation

오늘 목표는 **평가 성능이 높아도, 학습 과정에서 평가 데이터의 정보가 새어 들어갔다면 그 결과를 신뢰하기 어렵다는 점**을 영어로 설명하는 것입니다. 오늘은 **evaluation setup → data leakage → inflated performance → fair comparison → cautious conclusion** 구조를 연습합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A model achieves extremely high accuracy, but you later discover that some test examples were indirectly included during training. Can the reported performance still be trusted?

답변에는 **왜 문제가 되는지, 성능이 왜 과대평가될 수 있는지, 어떤 평가가 더 공정한지, 결과를 어떻게 다시 검증해야 하는지**를 포함하세요.

시작은 이렇게 해보세요.

> I would not fully trust the reported performance because the evaluation may have been affected by data leakage.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **평가 오염 문제를 설명할 때** 사용합니다.

> If information from **[test data]** is available during **[training/model selection]**, the evaluation may no longer be independent.

예:

> If information from the test set is available during model selection, the evaluation may no longer be independent.

두 번째는 **성능 과대평가를 설명할 때** 유용합니다.

> This can lead to an overestimate of **[model performance/generalization ability]**.

예:

> This can lead to an overestimate of the model’s real-world generalization ability.

세 번째는 **공정한 재평가를 제안할 때** 씁니다.

> To obtain a fair estimate, I would evaluate the model on **[a clean holdout set / unseen data]**.

예:

> To obtain a fair estimate, I would evaluate the model on a clean holdout set that was never used during training or model selection.

## 3. Useful Words & Expressions — 4분

**data leakage**는 학습에 사용되면 안 되는 정보가 학습이나 모델 선택 과정에 들어가는 현상입니다.

> The unusually high score may be caused by data leakage.

**holdout set**은 학습과 모델 선택에 사용하지 않고 마지막 평가를 위해 따로 보관하는 데이터입니다.

> We evaluated the final model on a separate holdout set.

**contamination**은 평가 데이터가 학습 데이터에 섞이거나 영향을 받은 상태를 뜻합니다.

> Benchmark contamination can make performance estimates unreliable.

논문에서는 `test-set contamination`, `benchmark contamination` 같은 표현이 자주 나옵니다.

**inflate**는 수치나 효과를 실제보다 크게 보이게 한다는 뜻입니다.

> Data leakage can artificially inflate the reported accuracy.

일반 영어에서도 쓸 수 있습니다.

> Temporary demand inflated the price.

**fair comparison**은 비교 대상들이 동일하거나 적절한 조건에서 평가되었다는 뜻입니다.

> A fair comparison requires the same evaluation protocol for all models.

연구에서는 `fair baseline comparison`, `consistent evaluation protocol`도 자주 사용합니다.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> The test data was used for training by mistake.

더 정확하게:

> Some test data were accidentally used during training.

설명: `data`는 연구 영어에서는 보통 복수 취급합니다.

- data was △
- data were ✅

다만 일상 영어에서는 `data is`도 자주 들을 수 있습니다.

### 2

> So the accuracy can be more higher than real.

정답:

> So the reported accuracy may be higher than the true performance.

설명:

- more higher ❌
- higher ✅

또한 `than real`보다는 `than the true performance`가 훨씬 자연스럽습니다.

### 3

> We cannot know the model generalize well.

정답:

> We cannot know whether the model generalizes well.

더 자연스럽게:

> We cannot determine whether the model generalizes well.

설명: `whether`가 필요하고, `model`이 3인칭 단수이므로 `generalizes`를 사용합니다.

### 4

> We should test again with never seen data.

정답:

> We should test the model again on previously unseen data.

설명:

- with never seen data △
- on previously unseen data ✅

머신러닝에서는 `unseen data`가 매우 자주 쓰이는 표현입니다.

### 5

> This result is not fair because test set leaked.

더 자연스럽게:

> The evaluation is not reliable because information from the test set leaked into the training process.

또는 더 간결하게:

> The evaluation is compromised by test-set leakage.

설명: `test set leaked`만으로는 무엇이 어디로 새어 들어갔는지 불분명합니다.

- information leaked into training ✅
- evaluation was compromised ✅

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> The reported accuracy is very high, but …  
> The main concern is that …  
> This means the test set may no longer be …  
> As a result, the reported score could be …  
> To obtain a fair estimate, I would …  
> I would also check whether …  
> Based on the current evidence, I would …

초급식 표현:

> The model saw the test data, so the score is not fair.

더 정확한 표현:

> The evaluation may be unreliable because information from the test set was available during training.

C1에 가까운 표현:

> Because the test set was not fully isolated from the training process, the reported accuracy may substantially overestimate the model’s true generalization performance.

## Compact Model Answer — 1분

> I would not fully trust the reported performance if some test examples were indirectly included during training. The purpose of a test set is to provide an independent estimate of how well the model generalizes to unseen data. If information from the test set leaks into the training or model-selection process, the reported score may be artificially inflated. I would therefore create a clean holdout set that has never been used during training, hyperparameter tuning, or model selection. I would also check for duplicate or near-duplicate examples across the data splits. If the model maintains strong performance on the clean evaluation set, I would have much greater confidence in the result. Otherwise, the original performance should be interpreted cautiously.

오늘 입에 붙일 세 문장은 이것입니다: **“The evaluation may have been affected by data leakage.” → “The reported score may overestimate true generalization performance.” → “A clean holdout set is necessary for a fair evaluation.”**
