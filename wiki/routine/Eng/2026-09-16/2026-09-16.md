# Day 38 — Explaining Trade-offs Between Accuracy, Latency, and Cost

오늘 목표는 **모델 성능이 가장 높은 선택이 항상 실무적으로 가장 좋은 선택은 아니라는 점을 설명하는 것**입니다. 오늘은 **accuracy → latency → computational cost → deployment constraints → balanced decision** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> Model A achieves 92% accuracy with 200 ms latency, while Model B achieves 93% accuracy but requires 1.5 seconds per request and twice as much GPU memory. Which model would you choose for deployment?

답변에는 **성능 차이, 응답 속도, GPU 비용, 실제 서비스 요구사항, 최종 선택 기준**을 포함하세요.

시작은 이렇게 해보세요.

> Model B is slightly more accurate, but the additional gain may come at a significant operational cost.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **성능과 비용의 trade-off를 설명**할 때 사용합니다.

> There is a trade-off between **[benefit]** and **[cost]**.

예:

> There is a trade-off between accuracy and inference latency.

두 번째는 **선택 기준이 상황에 따라 달라진다고 말할 때** 유용합니다.

> The better choice depends on whether **[requirement A]** is more important than **[requirement B]**.

예:

> The better choice depends on whether maximum accuracy is more important than fast response time.

세 번째는 **작은 성능 향상이 비용을 정당화하는지 평가**할 때 씁니다.

> I would choose **[option]** unless the additional **[performance gain]** clearly justifies **[extra cost]**.

예:

> I would choose Model A unless the additional one-percentage-point gain clearly justifies the higher latency and memory usage.

## 3. Useful Words & Expressions — 4분

**trade-off**는 하나를 얻기 위해 다른 것을 희생해야 하는 관계를 뜻합니다.

> There is a clear trade-off between model size and inference speed.

일상 영어에서도 자주 씁니다.

> Working remotely involves a trade-off between flexibility and face-to-face communication.

**latency**는 요청이 들어온 뒤 응답이 나오기까지 걸리는 시간입니다.

> The larger model has significantly higher inference latency.

실무에서는 `low latency`, `latency-sensitive`, `end-to-end latency` 같은 표현도 자주 사용합니다.

**throughput**은 일정 시간 동안 처리할 수 있는 요청량입니다.

> The smaller model provides higher throughput under heavy traffic.

예:

> We measured both latency and throughput under different concurrency levels.

**resource-intensive**는 많은 계산 자원이나 메모리를 필요로 한다는 뜻입니다.

> The larger model is more accurate but considerably more resource-intensive.

일반적으로 `computationally expensive`도 매우 자주 사용합니다.

> The method is computationally expensive to run at scale.

**worthwhile**은 들어가는 비용이나 노력을 고려해도 충분히 가치가 있다는 뜻입니다.

> The accuracy gain may not be worthwhile if inference costs double.

일상 영어에서도 유용합니다.

> The extra preparation was worthwhile.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> Model B has more high accuracy.

정답:

> Model B has higher accuracy.

또는 더 자연스럽게:

> Model B achieves higher accuracy.

설명: 비교급에서는 `more high`가 아니라 `higher`를 사용합니다.

- more high ❌
- higher ✅

### 2

> But it needs two times more GPU memory.

더 자연스럽게:

> But it requires twice as much GPU memory.

설명: 자원 요구량을 말할 때 `requires`가 자연스럽고, 두 배는 `twice as much`를 사용합니다.

- two times more △
- twice as much ✅

### 3

> Model A is faster five times.

정답:

> Model A is about five times faster.

설명: 배수 표현은 보통 숫자를 비교급 앞에 둡니다.

> twice as fast  
> three times faster  
> five times more expensive

### 4

> It depends on what is more important for service.

더 자연스럽게:

> It depends on what is more important for the service.

더 전문적으로:

> The decision depends on the deployment requirements.

설명: 실무·연구 문맥에서는 `deployment requirements`가 매우 자연스럽습니다.

### 5

> One percent accuracy is maybe not worth for this cost.

정답:

> A one-percentage-point accuracy improvement may not be worth the additional cost.

설명: `worth` 뒤에는 일반적으로 `for`를 쓰지 않습니다.

- worth for the cost ❌
- worth the cost ✅

그리고 92%에서 93%는 정확히는 **one percentage point** 차이입니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> Model B achieves slightly higher accuracy, but …  
> The main trade-off is between …  
> Model A provides …  
> whereas Model B requires …  
> For a latency-sensitive application, …  
> However, if the application is high-stakes, …  
> Therefore, I would choose … unless …

초급식 표현:

> Model B is better because accuracy is higher.

더 정확한 표현:

> Model B is more accurate, but it is also slower and more resource-intensive.

C1에 가까운 표현:

> The one-percentage-point accuracy gain must be evaluated against the substantial increase in latency and GPU memory consumption, particularly in a production environment with strict response-time constraints.

## Compact Model Answer — 1분

> I would probably choose Model A for most production environments. Model B achieves one percentage point higher accuracy, but it also has much higher latency and requires twice as much GPU memory. This creates a clear trade-off between predictive performance and operational efficiency. If the application is latency-sensitive or needs to handle a large number of concurrent requests, Model A would likely provide better overall system performance because it can respond faster and use fewer resources. However, if the application is high-stakes and even a small accuracy improvement has substantial value, Model B may be worthwhile. I would therefore make the decision based on deployment requirements rather than accuracy alone.

오늘 입에 붙일 세 문장은 이것입니다: **“There is a trade-off between accuracy and latency.” → “The better choice depends on the deployment requirements.” → “The additional performance gain may not justify the operational cost.”**
