# Day 64 — Defending a Technical Decision
### 기술적 선택의 이유를 논리적으로 설명하기
**15-Minute English Practice | TOEIC 500–600 → CEFR C1+**

오늘은 **“왜 이 방법을 선택했나요?”**에 답하는 연습입니다.

AI/ML 기술 면접에서 특히 중요합니다.

> “Why did you choose tensor parallelism?”
>
> “Why did you use this benchmark?”
>
> “Why didn't you choose the simpler approach?”

핵심 구조는:

**Decision → Reason → Alternative → Trade-off → Conclusion**

## 1. 🎤 Speaking Prompt — 2분

상황:

> You decided to use **Tensor Parallelism (TP)** rather than running separate model replicas.
>
> Your interviewer asks:
>
> **“Why did you choose tensor parallelism?”**

조건:

- TP allows a large model to be distributed across multiple GPUs.
- It introduces communication overhead.
- Replication is simpler but requires each GPU to hold the full model.
- Your goal is to serve a model that does not fit comfortably on a single GPU.

> I chose tensor parallelism because the model is too large for a single GPU.

그 다음 점점 확장하세요.

# 2. Reusable Speaking Templates — 3분

### Template 1 — 선택 + 핵심 이유

> **I chose A primarily because B.**

> I chose tensor parallelism primarily because the model's memory requirements exceed what a single GPU can comfortably provide.

**primarily because**  
= 주된 이유는 ~이기 때문에

`because`만 반복하는 것보다 훨씬 자연스럽습니다.

---

### Template 2 — 대안과 비교

> **Although A would be simpler, I chose B because...**

> Although model replication would be simpler, I chose tensor parallelism because it allows us to distribute the model across multiple GPUs.

이 구조는 **면접에서 굉장히 강력합니다.**

단순히:

> I chose B because B is better.

가 아니라,

> **A도 장점이 있지만, 특정 조건 때문에 B를 선택했다.**

라는 논리를 만듭니다.

---

### Template 3 — Trade-off 인정하기

> **The main trade-off is that A provides X at the expense of Y.**

> The main trade-off is that tensor parallelism provides better memory scalability at the expense of additional communication overhead.

`at the expense of ~`

= ~을 희생하면서 / ~을 대가로

학술·기술 영어에서 매우 유용합니다.

---

# 3. Five Useful Expressions — 4분

### ① Primarily because

> I chose this approach primarily because it reduces memory pressure.

주로 메모리 부담을 줄여주기 때문에 이 방법을 선택했습니다.

---

### ② At the expense of

> The approach improves scalability at the expense of communication overhead.

확장성을 높이는 대신 통신 오버헤드가 발생합니다.

일상 영어:

> The promotion gave me more responsibility at the expense of my free time.

---

### ③ Be better suited to

> Tensor parallelism is better suited to large models that cannot fit on a single GPU.

`be suited to`

= ~에 적합하다

자주 쓰는 조합:

- well-suited to
- poorly suited to
- better suited to

---

### ④ In contrast

> Replication is simpler. In contrast, tensor parallelism requires additional coordination between GPUs.

`however`보다 **두 가지 접근법을 명확하게 대비**할 때 좋습니다.

---

### ⑤ From a practical standpoint

> From a practical standpoint, reducing memory pressure was more important than minimizing communication overhead.

= 실질적인 관점에서 보면

면접에서 상당히 자연스럽습니다.

> From a practical standpoint, ...

라고 시작하면 뒤에 **현실적인 판단 기준**을 제시하기 좋습니다.

# 4. Correction Exercise — 3분

### ①

❌ I chose TP because it can make the model distributed.

✅ **I chose TP because it allows the model to be distributed across multiple GPUs.**

**왜?**

`make the model distributed`는 한국어식 표현에 가깝습니다.

> distribute a model across GPUs

또는

> allow a model to be distributed across GPUs

가 자연스럽습니다.

---

### ②

❌ TP is more better for large models.

✅ **TP is better suited to large models.**

**왜?**

`more better` ❌

`better` 자체가 비교급입니다.

그리고 기술적인 적합성을 말할 때:

> better suited to

가 매우 자연스럽습니다.

---

### ③

❌ The disadvantage is it has communication overhead.

✅ **One drawback is that it introduces additional communication overhead.**

**왜?**

`has communication overhead`도 의미는 전달되지만,

> introduce overhead

가 기술 문서에서 훨씬 자연스럽습니다.

---

### ④

❌ I chose TP instead replication.

✅ **I chose TP instead of replication.**

또는:

> **I chose TP rather than replication.**

**기억하세요.**

> instead **of** + noun

> rather **than** + noun

---

### ⑤

❌ TP is good, but it has a disadvantage that communication is increased.

✅ **TP has the advantage of reducing memory pressure, but it also introduces additional communication overhead.**

이 문장이 오늘의 핵심입니다.

**장점 + 단점**을 동시에 설명합니다.

## Level 2

## Level 3 — C1

> I chose tensor parallelism primarily because the model's memory requirements made single-GPU deployment impractical. Although model replication would be simpler from an implementation standpoint, it would require each GPU to maintain a full copy of the model, which would significantly increase memory requirements. The main trade-off is that tensor parallelism introduces additional inter-GPU communication overhead. However, given our primary constraint—model memory capacity—I considered this overhead an acceptable cost.

### 이 답변의 구조

> I chose TP...

↓

> **Reason**  
> memory requirements...

↓

> **Alternative**  
> replication would be simpler...

↓

> **Trade-off**  
> communication overhead...

↓

> **Judgment**  
> acceptable cost.

이게 바로 **C1 수준의 technical reasoning**입니다.

# 7. Compact Model Answer — 1분

> That's a valid concern. Tensor parallelism does introduce additional communication overhead, so it can negatively affect performance in some workloads. However, in our case, the primary constraint was GPU memory rather than raw compute performance. Model replication would have required each GPU to store a complete copy of the model, which was not practical. Therefore, from a practical standpoint, I considered the communication overhead an acceptable trade-off for being able to distribute the model across multiple GPUs.

### ⭐ 특히 기억할 문장

> **The primary constraint was X rather than Y.**

이건 면접에서 정말 강력합니다.

예:

> The primary constraint was memory rather than compute.

> The primary constraint was latency rather than throughput.

> The primary constraint was cost rather than performance.
