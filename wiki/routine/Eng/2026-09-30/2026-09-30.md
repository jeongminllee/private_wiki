# Day 48 — Explaining Reproducibility and Experimental Reliability

오늘 목표는 **한 번 좋은 결과가 나온 것과, 같은 조건에서 다시 실행했을 때 비슷한 결과가 반복되는 것은 다르다**는 점을 영어로 설명하는 것입니다. 오늘은 **single result → reproducibility → variance → controlled conditions → reliable conclusion** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A model achieves excellent performance in one training run, but the score changes noticeably when you train it again with a different random seed. Would you consider the result reliable?

답변에는 **왜 한 번의 결과만으로 충분하지 않은지, random seed가 왜 영향을 줄 수 있는지, 여러 번 반복 실험해야 하는 이유, 무엇을 보고 신뢰도를 판단할지**를 포함하세요.

시작은 이렇게 해보세요.

> I would be cautious about calling the result reliable because a single training run may not represent the model’s typical performance.

---

## 2. Reusable Speaking Templates — 3분

첫 번째는 **한 번의 실험 결과를 조심스럽게 해석할 때** 사용합니다.

> A single run may not be sufficient to determine whether **[result]** is stable.

예:

> A single run may not be sufficient to determine whether the performance improvement is stable.

두 번째는 **여러 번 반복한 결과를 설명할 때** 유용합니다.

> I would repeat the experiment across **[multiple seeds / multiple runs]** and report **[mean and variance]**.

예:

> I would repeat the experiment across multiple random seeds and report the mean and standard deviation.

세 번째는 **재현 가능성을 강조할 때** 씁니다.

> A result is more convincing if it can be reproduced under **[the same or similar conditions]**.

예:

> A result is more convincing if it can be reproduced under the same experimental conditions.

---

## 3. Useful Words & Expressions — 4분

**reproducibility**는 같은 방법과 조건을 사용했을 때 비슷한 결과를 다시 얻을 수 있는 성질입니다.

> Reproducibility is essential for reliable experimental results.

논문에서는 다음 표현이 자주 나옵니다.

> reproducibility study  
> reproducible results  
> reproducible experiment

**random seed**는 난수 생성의 시작값입니다.

> Different random seeds can lead to slightly different training outcomes.

머신러닝에서는 초기화, 데이터 셔플, dropout 등에 영향을 줄 수 있습니다.

**variance**는 반복 실험에서 결과가 얼마나 흔들리는지를 나타냅니다.

> The model has strong average performance but high variance across runs.

일반 영어에서도 `variation`이 더 쉬운 표현으로 자주 쓰입니다.

> There is considerable variation between experiments.

**robust**는 조건이 조금 바뀌어도 결과가 크게 흔들리지 않는다는 뜻입니다.

> A robust method should perform consistently across different runs.

일반 영어에서도 매우 유용합니다.

> We need a robust solution that works under different conditions.

**replicate**는 실험을 다시 수행해 비슷한 결과가 나오는지 확인한다는 뜻입니다.

> We were able to replicate the reported improvement.

논문 영어에서 자주 쓰입니다.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> We got good result only one time.

정답:

> We obtained a good result in only one run.

더 자연스럽게:

> The strong result was observed in only one run.

설명: 실험에서는 `one time`보다 `one run`이 훨씬 자연스럽습니다.

- one time △
- one run ✅

---

### 2

> The result changes depend on random seed.

정답:

> The result changes depending on the random seed.

또는:

> The result varies across random seeds.

설명:

- changes depend on ❌
- changes depending on ✅
- varies across ✅

`vary across`는 연구 영어에서 매우 유용합니다.

---

### 3

> We need repeat the experiment many times.

정답:

> We need to repeat the experiment multiple times.

설명:

- need repeat ❌
- need to repeat ✅

연구 문맥에서는 `many times`보다 `multiple times`가 더 자연스럽습니다.

---

### 4

> If result is similar, experiment is reliable.

더 자연스럽게:

> If the results are consistent across runs, the experiment is more reliable.

설명: 한 번의 결과가 아니라 반복 결과를 말하므로 `results`가 자연스럽고, `similar`보다 `consistent`가 연구 문맥에 더 적합합니다.

---

### 5

> We should show average and how much result changes.

정답:

> We should report the average and the variability across runs.

더 전문적으로:

> We should report the mean and standard deviation across multiple runs.

설명: `how much result changes`는 의미는 통하지만 연구에서는 `variability`, `variance`, `standard deviation` 같은 표현을 씁니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> The model performs very well in one run, but …  
> The score changes when …  
> This suggests that …  
> A single run is therefore …  
> I would repeat the experiment across …  
> I would report …  
> If the results remain consistent, then …

초급식 표현:

> The model got a good score once, so it is good.

더 정확한 표현:

> The model achieved a strong score in one run, but we need repeated experiments to determine whether the result is stable.

C1에 가까운 표현:

> Although the model achieves excellent performance in one run, substantial variation across random seeds would weaken the reliability of the reported improvement.

---

## Compact Model Answer — 1분

> I would not consider the result fully reliable based on a single training run. If performance changes noticeably across random seeds, this suggests that the method may have high variance. I would therefore repeat the experiment several times using different seeds while keeping the main training conditions fixed. Instead of reporting only the best score, I would report the mean performance together with a measure of variability, such as the standard deviation. I would also check whether the improvement over the baseline remains consistent across runs. If the same advantage appears repeatedly under similar conditions, I would have much greater confidence that the method is robust and reproducible.

오늘 입에 붙일 세 문장은 이것입니다: **“A single run may not be sufficient to establish reliability.” → “The result varies across random seeds.” → “A robust result should remain consistent across repeated experiments.”**
