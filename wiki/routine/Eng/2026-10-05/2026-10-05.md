# Day 51 — Explaining Model Calibration and Confidence

오늘 목표는 **모델이 높은 확률을 출력한다고 해서 실제로 그만큼 신뢰할 수 있는 것은 아니며, confidence calibration이 왜 중요한지** 설명하는 것입니다. 오늘은 **predicted confidence → calibration → overconfidence → reliability → deployment decision** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 답해보세요.

> A classifier often predicts “90% confident,” but among those predictions it is actually correct only about 70% of the time. Would you trust its confidence scores?

답변에는 **confidence와 correctness의 차이, calibration이 무엇인지, overconfidence가 왜 위험한지, 실제 시스템에서 어떻게 보정할지**를 포함하세요.

시작은 이렇게 해보세요.

> I would not fully trust the confidence scores because the model appears to be overconfident.

## 2. Reusable Speaking Templates — 3분

첫 번째는 **모델 confidence를 평가할 때** 사용합니다.

> A well-calibrated model should be correct about **[X]% of the time** when it predicts **[X]% confidence**.

예:

> A well-calibrated model should be correct about 90% of the time when it predicts 90% confidence.

두 번째는 **과신 문제를 설명할 때** 유용합니다.

> The model appears to be overconfident because **[predicted confidence]** is higher than **[observed accuracy]**.

예:

> The model appears to be overconfident because its predicted confidence is much higher than its observed accuracy.

세 번째는 **실제 적용 판단으로 연결할 때** 씁니다.

> Before deployment, I would evaluate whether the confidence scores are **[well calibrated / reliable enough for decision-making]**.

예:

> Before deployment, I would evaluate whether the confidence scores are reliable enough for high-risk decisions.

## 3. Useful Words & Expressions — 4분

**calibration**은 모델이 출력하는 확률과 실제 정답률이 얼마나 잘 맞는지를 뜻합니다.

> The model has high accuracy but poor calibration.

**overconfident**는 실제 성능보다 지나치게 높은 확률을 출력하는 상태입니다.

> The classifier is overconfident on difficult examples.

일반 영어에서도 쓸 수 있습니다.

> He sounded overconfident during the presentation.

**underconfident**는 반대로 실제 성능보다 지나치게 낮은 confidence를 출력하는 상태입니다.

> The model is slightly underconfident on easy examples.

**reliability**는 모델의 출력이 실제 의사결정에 사용할 만큼 일관되고 믿을 만한지를 뜻합니다.

> Calibration is important for the reliability of probabilistic predictions.

일반 영어에서도 매우 자주 쓰입니다.

> Reliability matters more than speed in this system.

**confidence score**는 모델이 자신의 예측에 부여하는 확률 또는 신뢰도 값입니다.

> The system uses the confidence score to decide whether human review is required.

실무에서는 다음 표현도 자주 나옵니다.

> low-confidence prediction  
> confidence threshold  
> confidence-based routing

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> The model confidence is too much high.

정답:

> The model’s confidence is too high.

설명:

- too much high ❌
- too high ✅

`too much`는 보통 명사와 함께 씁니다.

> too much noise  
> too much data

형용사에는 `too + adjective` 구조를 씁니다.

### 2

> It predicts 90% confidence, but actually correct only 70%.

정답:

> It predicts with 90% confidence, but it is actually correct only 70% of the time.

설명: 영어에서는 누가 맞는지 주어가 필요합니다.

- but actually correct ❌
- but it is actually correct ✅

그리고 반복 빈도는 `70% of the time`이 자연스럽습니다.

### 3

> The confidence score is not match with real accuracy.

정답:

> The confidence score does not match the actual accuracy.

설명:

- is not match ❌
- does not match ✅

`match`는 여기서 동사입니다.

또한 `match with`보다 그냥 `match`가 더 자연스럽습니다.

### 4

> We need calibrate the model before using in real service.

정답:

> We need to calibrate the model before using it in a real service.

더 자연스럽게:

> We need to calibrate the model before deploying it in a real system.

설명:

- need calibrate ❌
- need to calibrate ✅
- using in real service △
- deploying it in a real system ✅

### 5

> High confidence doesn't always means high accuracy.

정답:

> High confidence does not always mean high accuracy.

설명:

`does`가 이미 3인칭 단수 표시를 하기 때문에 뒤 동사는 원형을 씁니다.

- does not means ❌
- does not mean ✅

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> The model predicts with high confidence, but …  
> This suggests that …  
> A well-calibrated model should …  
> Overconfidence is risky because …  
> Before deployment, I would …  
> If necessary, I would …  
> Based on this, …

초급식 표현:

> The model says 90%, but it is wrong many times.

더 정확한 표현:

> The model frequently reports 90% confidence, but its actual accuracy is much lower.

C1에 가까운 표현:

> The discrepancy between predicted confidence and observed accuracy indicates that the model is poorly calibrated and systematically overconfident.

## Compact Model Answer — 1분

> I would not fully trust the model’s confidence scores. If the model predicts with 90% confidence but is correct only about 70% of the time, it is clearly overconfident. A well-calibrated model should have predicted probabilities that closely match observed outcomes. This matters because downstream systems may use confidence scores to decide whether to automate a decision or request human review. Overconfidence can therefore create unnecessary risk, especially in high-stakes applications. Before deployment, I would evaluate calibration using reliability analysis and, if necessary, apply a calibration method such as temperature scaling. The main goal is not only to make accurate predictions, but also to make confidence estimates that are trustworthy.

오늘 입에 붙일 세 문장은 이것입니다: **“A well-calibrated model should have confidence scores that match observed accuracy.” → “The model appears to be overconfident.” → “Accurate predictions are not enough if the confidence estimates are unreliable.”**
