# Day 25 — Explaining Why One Metric Is Not Enough

오늘 목표는 **하나의 평가 지표만 보고 모델을 판단하지 않고, metric의 한계와 실제 목적에 맞는 평가 기준을 설명하는 것**입니다. 오늘은 **metric → limitation → task requirement → better evaluation** 구조로 말하는 연습을 합니다.

## 1. Speaking Prompt — 2분

다음 질문에 60–90초 동안 영어로 답해보세요.

> A classification model has very high accuracy, but the positive class is rare and important. Is accuracy enough to evaluate the model? What else would you look at?

답변에는 다음 내용을 포함하세요.

1. accuracy가 왜 오해를 줄 수 있는지
2. 어떤 metric을 추가로 볼 것인지
3. 실제 업무 목표에 따라 어떤 metric을 우선할지
4. 최종적으로 모델을 어떻게 평가할지

시작은 이렇게 해보세요.

> Accuracy is useful, but it may be misleading when the class distribution is highly imbalanced.

## 2. Reusable Speaking Templates — 3분

### Template 1: 지표의 한계 설명

> **[Metric]** provides useful information about **[aspect]**, but it does not fully capture **[important aspect]**.

예:

> Accuracy provides useful information about overall correctness, but it does not fully capture performance on the minority class.

### Template 2: 목표에 따라 metric 선택

> The most appropriate metric depends on **[operational objective]**.

예:

> The most appropriate metric depends on whether missing positive cases is more costly than generating false alarms.

### Template 3: 여러 지표 종합

> Rather than relying on **[single metric]** alone, I would evaluate **[multiple metrics]** together.

예:

> Rather than relying on accuracy alone, I would evaluate precision, recall, and PR-AUC together.

## 3. Useful Words & Expressions — 4분

### 1. misleading

**오해를 불러일으킬 수 있는**

> Accuracy can be misleading when one class dominates the dataset.

일반 영어에서도 자주 씁니다.

> The headline is technically correct but somewhat misleading.

---

### 2. class imbalance

**클래스 불균형**

> Severe class imbalance can make accuracy an unreliable metric.

논문식 표현:

> The dataset exhibits substantial class imbalance.

---

### 3. false negative

**실제 양성을 음성으로 잘못 예측한 경우**

> In medical screening, false negatives can be particularly costly.

기술적 의사결정에서는 metric 자체보다 **error type의 비용**을 설명할 수 있어야 합니다.

---

### 4. trade-off

**상충 관계**

> There is often a trade-off between precision and recall.

예:

> Increasing recall may come at the cost of lower precision.

---

### 5. align with

**~와 부합하다**

> The evaluation metric should align with the actual business objective.

논문·실무 모두에서 매우 유용합니다.

> The loss function should align with the intended evaluation criterion.

## 4. Correction Exercise — 3분

먼저 직접 고쳐본 뒤 정답을 확인하세요.

### 1

> Accuracy is not enough for evaluate the model.

정답:

> Accuracy is not enough to evaluate the model.

설명: 목적 표현은 `to + 동사원형`을 사용합니다.

* for evaluate ❌
* to evaluate ✅

---

### 2

> The positive data is very less.

정답:

> There are very few positive examples.

설명:

* data는 일반적으로 불가산명사
* examples는 가산명사

따라서 개수를 말할 때는 `few examples`가 자연스럽습니다.

---

### 3

> Recall is important when we don't want to miss positives too much.

더 자연스럽게:

> Recall is important when missing positive cases is costly.

설명: `don't want to miss too much`는 의미는 통하지만 기술적으로는 **비용 구조**를 설명하는 표현이 더 자연스럽습니다.

---

### 4

> Precision and recall have trade-off each other.

정답:

> There is a trade-off between precision and recall.

설명: 고정 구조를 기억하세요.

> There is a trade-off between A and B.

---

### 5

> We should choose metric depending on purpose.

더 자연스럽게:

> We should choose the metric based on the objective.

또는:

> The metric should align with the operational objective.

설명: `depending on`도 가능하지만, 기술적 판단에서는 `based on the objective`, `align with the objective`가 더 명확합니다.

## 5. 60–90 Second Speaking Practice — 2분

다음 흐름으로 한 번에 말해보세요.

> Accuracy is useful, but …
> In an imbalanced dataset, …
> The main concern is that …
> If false negatives are costly, I would prioritize …
> On the other hand, if false positives are expensive, …
> Rather than relying on one metric alone, …
> The final evaluation should align with …

오늘은 특히 **metric 이름만 나열하지 말고, 왜 필요한지를 설명하는 것**에 집중하세요.

초급식 표현:

> Accuracy is high, so the model is good.

더 정확한 표현:

> Accuracy is high, but the model may still perform poorly on the minority class.

C1에 가까운 표현:

> Although the model achieves high overall accuracy, that metric may obscure poor performance on rare but operationally important cases.

## Compact Model Answer — 1분

> Accuracy alone is not sufficient in this case because the positive class is rare. A model could achieve high accuracy simply by predicting the majority class most of the time. I would therefore examine precision, recall, F1 score, and PR-AUC, depending on the operational objective. If missing positive cases is especially costly, I would place more emphasis on recall. If false alarms are expensive, precision would become more important. Rather than relying on a single metric, I would evaluate the trade-off between these measures and choose a threshold that aligns with the actual use case. In other words, the best metric is not necessarily the one with the highest value, but the one that best reflects the cost of the errors we care about.

오늘 입에 붙일 세 문장은 이것입니다: **“Accuracy may be misleading.” → “The most appropriate metric depends on the objective.” → “The evaluation should align with the actual use case.”**
