### 왜 특히 잘 맞는가

이 공고는 경력 전환 과정에서 오히려 기존 전공을 숨길 필요가 없는 드문 사례입니다. 목재물리 석사 과정에서 했던 **물리현상 분석·수치해석·실험 결과 해석**을 AI와 동떨어진 과거 경험으로 취급하는 대신, `physical simulation → numerical analysis → ML surrogate/PINN`이라는 방향으로 그대로 가져갈 수 있습니다. 공고 자체가 물리 기반 시뮬레이션과 수치해석 경험을 우대하기 때문에 이런 연결은 단순한 자기소개서 포장이 아니라 실제 JD와 맞닿아 있습니다. ([LinkedIn][2])

동시에 Python·PyTorch 기반 ML 실험, LLM과 Agent, Codex 활용, 모델 평가와 MLOps 쪽 경험도 그대로 활용할 수 있습니다. 특히 **“AI 모델을 공부했다”가 아니라 “물리 문제를 수치적으로 다뤄본 사람이 최신 ML/LLM 기술까지 확장했다”**라는 차별화가 가능하다는 점이 큽니다. 이 부분은 지금까지 발견했던 일반적인 LLM Engineer 공고보다 지원 서사를 만들기 훨씬 쉽습니다. ([LinkedIn][2])

### 부족할 수 있는 부분

가장 큰 간극은 **PINN이나 surrogate model을 실제로 구현한 결과물이 아직 명확하지 않다는 것**입니다. 공고의 핵심 우대사항이 물리 시뮬레이션과 ML의 결합인 만큼, 기존 수치해석 경험만 설명하는 것보다 작은 구현 하나라도 있으면 강도가 크게 달라집니다. 두 번째는 학습한 모델을 실제 서비스나 MLOps 파이프라인까지 연결한 경험입니다. 해당 회사가 LLM 애플리케이션뿐 아니라 데이터 파이프라인·모델 서빙·배포까지 우대하고 있기 때문입니다. ([LinkedIn][2])

### 지원 전에 무엇을 준비할까

이번 공고 때문에 큰 프로젝트를 새로 시작할 필요는 없습니다. 오히려 **기존 석사 연구 주제 또는 유사한 diffusion/transport 문제 하나를 작은 ML 문제로 다시 구현**하는 것이 가장 효과적입니다. 기존 numerical solution을 baseline으로 놓고, PyTorch MLP 또는 간단한 PINN으로 물리량을 예측한 다음 RMSE와 계산시간을 비교하면 됩니다. 여기에 `수치해석 → ML surrogate → 오차 분석`을 1개의 GitHub repository로 정리하면 이 공고의 핵심 우대조건을 직접 증명할 수 있습니다.

LLM 쪽에서는 별도 대형 프로젝트 대신 현재 해온 작업 중 하나를 붙이면 충분합니다. 예를 들어 실험 결과나 논문 데이터를 LLM이 분석하도록 하거나, Agent가 실험 결과를 읽고 다음 실험 후보를 생성하도록 구성해 **“Physics/Scientific ML + LLM Agent”**라는 흐름을 보여주면 좋습니다. 이 회사가 ML/DL뿐 아니라 LLM·Agent·RL까지 업무 범위에 포함시키고 있다는 점과도 잘 맞습니다. ([LinkedIn][2])
