특히 자격요건이 경력 연수를 강하게 요구하지 않습니다. **현대적인 ML/LLM을 직접 만들어본 경험을 coursework, research, internship 또는 보여줄 수 있는 프로젝트로 증명하면 인정**하며, LLM output의 품질을 엄격하게 평가하고 AI가 유발할 수 있는 위험을 판단하는 능력을 중요하게 봅니다. 특정 모델이나 프레임워크 자체보다 **실제 production에서 시스템이 제대로 동작하는가**를 더 중요하게 평가한다는 점도 특징입니다. :chatgpt-content-reference{index="2"}

현재 방향과 맞는 부분은 꽤 명확합니다. Python 기반 LLM 시스템 구현, 모델 benchmark/evaluation, Agent 구조, FastAPI 기반 파이프라인, GitHub에 결과를 재현 가능하게 남기는 경험을 하나의 지원 스토리로 묶기 좋습니다. 특히 현재 보안 분석 시스템에서 **정적 분석 → Local LLM → Agent/보고서 → 평가**로 이어지는 구조와 모델 성능을 수치로 검증하는 작업은 Nuvo가 말하는 `production-grade LLM + evals + guardrails`에 잘 대응합니다.
