## 신규 고적합 공고 — 2026년 8월 20일

이전에 안내한 공고를 제외하고 확인한 결과, 오늘은 **새롭게 확인할 가치가 충분한 국내 공고 2건**을 남겼습니다. 특히 1번은 `신입 + LLM/Agent + 평가 기준 설계 + 실제 운영`, 2번은 `Python/PyTorch + Agentic AI + AI for Science + 경력보다 문제 해결 능력 중시`라는 점이 눈에 띕니다.

### 1. DALPHA — AI Engineer

**적합도: 9.3/10 · 이번 회차 우선 지원 추천**

* **근무지:** 서울 관악구, 서울대입구 인근
* **원격:** 프로젝트에 따라 고객사 방문·온사이트 가능. 상시 원격 근무는 명시되지 않음
* **고용 형태:** 정규직 또는 **6개월 풀타임 인턴 지원 가능**
* **경력:** 원티드에서 **신입**으로 분류
* **인턴 자격:** 6개월 풀타임 출퇴근 가능 + AI 프로젝트 경험 또는 학부 AI 관련 과목 1개 이상
* **마감:** **상시채용**
* **지원:** DALPHA **AI Engineer 원티드 공고** ([원티드][1])

이번 DALPHA 포지션은 전형적인 “LLM API 붙이기”보다 범위가 넓습니다. 고객의 업무와 데이터를 직접 분석해 기술 문제로 재정의하고, **Agent 구조·데이터 파이프라인·기존 시스템 연동을 포함한 전체 AI 시스템**을 설계합니다. 실제 운영 환경에서 평가 기준을 직접 정의하고 성능을 측정·개선하며, 데이터·모델·파이프라인 중 어디에서 문제가 발생했는지 추적하는 것도 업무입니다. ([BeBee][2])

LLM 측면에서는 **AI Agent와 LLM을 이용한 실제 제품 운영**, RAG, Function Calling, Multi-Agent, Vector DB, Knowledge Graph 등이 직접 언급됩니다. 특히 “실무자의 정성적 판단을 어떤 평가셋으로 옮기고, 결과가 옳은지 어떻게 측정할 것인가”를 문제로 명시하고 있어 **benchmark/evaluation 성향도 꽤 강합니다.** 최신 AI 기술을 연구·구현하고 실험적으로 제품에 적용한 경험도 평가합니다. ([원티드][1])

사용자에게 잘 맞는 이유는 모델 연구 하나만 깊게 요구하기보다 **문제 정의 → 데이터 → 모델/Agent → 평가 → 운영**의 전체 사이클을 보는 포지션이기 때문입니다. Python 기반 ML 경험, 실험을 설계하고 결과를 분석해온 연구 배경, 최근 Agent·benchmark 쪽으로 확장해온 경험을 하나의 이야기로 묶기 좋습니다. 특히 비전산 전공 경력을 “도메인 문제를 구조화할 수 있는 능력”으로 전환해 설명하기에도 비교적 유리합니다.

가장 부족할 가능성이 높은 것은 **실제 사용자가 쓰는 Agent를 운영한 증거**입니다. JD는 PoC보다 `0→1 시스템 구축 → 실제 운영 → 성능 개선` 경험을 상당히 중요하게 봅니다. 대규모 비정형 데이터 처리나 온프레미스·폐쇄망 환경 경험도 있다면 우대됩니다. ([BeBee][2])

지원 전에는 새로운 모델을 학습하기보다 기존 Agent 프로젝트 하나를 **평가 가능한 제품**으로 마감하는 것이 효과적입니다. 예를 들어 `문서 입력 → RAG → 계획 수립 → Tool Calling → Action 생성` 구조를 만들고, 고정된 50~100개 평가 문제에서 `task success rate`, retrieval accuracy, tool-call accuracy, hallucination rate, p95 latency를 측정하세요. 실패 사례를 **데이터 / retrieval / reasoning / tool execution**으로 분류하고 개선 전후 수치를 남기면 DALPHA가 JD에서 요구하는 방식과 상당히 직접적으로 맞습니다.

### 2. NanoForge AI — Agentic AI Research Engineer

**적합도: 9.2/10 · 전공 배경까지 활용 가능한 독특한 후보**

* **근무지:** 서울 성수
* **근무 방식:** **On-site**
* **고용 형태:** **정규직 / 인턴 / 파트타임 모두 지원 가능**
* **경력:** 특정 연차 제한 없음. 회사가 명시적으로 **경력 요건보다 실제 문제 해결 능력과 학습 속도를 중시**
* **신규 게시/재노출:** LinkedIn 기준 **2026년 8월 17~18일 전후**
* **마감:** 별도 마감일 미표기, 현재 공식 Careers에서 모집 중
* **지원:** NanoForge AI **공식 Careers — Agentic AI Research Engineer** ([NanoForge AI][3])

NanoForge는 AI를 소재 연구에 적용하는 AI for Science 회사입니다. 현재 **materials foundation model**, 논문·특허·소재 DB·계산 도구·실험을 연결하는 **agentic scientific workflow**, 그리고 소재 screening/prediction/optimization/ranking pipeline을 개발하고 있습니다. Agentic AI Research Engineer가 공식 모집 포지션으로 별도로 열려 있습니다. ([LinkedIn][4])

요건이 흥미롭습니다. **Python과 PyTorch 등을 이용해 AI/ML 시스템을 직접 구현·실험한 사람**, 복잡하고 모호한 문제를 `data → target → architecture → evaluation`으로 구조화할 수 있는 사람을 찾으며, 소재 전공 자체는 필수가 아니라고 명시합니다. 더 나아가 회사는 학력·경력보다 실제 문제 해결 능력, 빠른 학습과 실행을 중시한다고 밝히고 있습니다. ([LinkedIn][4])

이 공고는 사용자의 기존 전공을 오히려 **강점으로 사용할 가능성이 있는 드문 경우**입니다. 물리 현상을 연구하고 MATLAB 기반 수치해석·실험 설계를 수행한 경험에 Python/PyTorch ML 역량을 붙이면, 일반적인 웹/CS 출신 지원자와는 다른 `scientific domain → numerical modeling → AI` 경로를 설명할 수 있습니다. Agent와 최신 AI 연구에 대한 관심도 scientific workflow 쪽으로 자연스럽게 연결됩니다.

다만 이 포지션은 일반적인 LLM Engineer보다 **AI for Science 비중이 더 높습니다.** Hugging Face Transformers, vLLM, LLM fine-tuning 등이 현재 공개된 JD의 핵심 요구사항으로 명시되지는 않았습니다. 따라서 목표가 순수 LLM Training/Inference라면 Scatter Lab·DEEPX 같은 이전 후보가 더 직접적이고, **AI Agent + Scientific ML 쪽까지 열어둔다면 NanoForge의 차별화 가치가 매우 높다**고 보는 것이 적절합니다. ([LinkedIn][4])

지원 전 가장 좋은 포트폴리오는 작은 **Scientific Agent**입니다. 논문 몇 편과 구조화된 실험 데이터를 입력해 `문헌 검색 → 가설 생성 → Python 분석 코드 실행 → 결과 검증 → 다음 실험 제안`까지 수행하게 만들고, 정답이 있는 태스크를 따로 만들어 citation accuracy, 계산 결과 정확도, tool-call success rate를 평가하면 좋습니다. 기존 연구 데이터 일부를 익명화하거나 공개된 diffusion/transport 데이터로 재현하면 **도메인 지식 + PyTorch + Agent + Evaluation**을 한 프로젝트에서 보여줄 수 있습니다.

**오늘 기준 지원 우선순위는 `DALPHA AI Engineer → NanoForge Agentic AI Research Engineer`입니다.** DALPHA는 신입·6개월 인턴 경로가 명확하고 LLM/Agent/evaluation이 직무의 중심이라 현재 목표와 더 직접적입니다. NanoForge는 LLM 순도는 조금 낮지만, 기존 과학 연구 경력을 버리지 않고 오히려 AI 엔지니어링의 차별점으로 사용할 수 있다는 점 때문에 별도로 지원할 가치가 큽니다. ([원티드][1])
