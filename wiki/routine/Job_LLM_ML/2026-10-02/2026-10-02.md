### 현재 경험과 가장 강하게 맞는 부분

이 공고에서는 악성코드 프로젝트보다 **B200/vLLM + fine-tuning 결과를 먼저 보여주는 게 좋습니다.** JD 핵심 키워드가 이미 `LLM serving / GPU server / LoRA·QLoRA / multi-GPU / evaluation`이기 때문입니다.

포트폴리오 첫 번째 사례를 다음 흐름으로 잡으면 상당히 강합니다.

`Base model → LoRA/QLoRA → fixed evaluation → failure analysis → vLLM serving → TP benchmark`

여기에 `TP1 vs TP2 × concurrency 1/8/32` 결과와 **TTFT, TPOT, throughput, P99, GPU utilization**을 넣고, 단순 수치보다 “왜 특정 workload에서 TP2의 효율이 떨어졌는가” 같은 해석을 붙이는 것이 좋습니다.

두 번째 사례로 악성코드 분석 시스템을 넣어 `Static Analysis → Evidence → Local LLM → Evaluation → Report` 구조와 **근거 기반 판단·FP/FN 평가**를 보여주면 됩니다.
