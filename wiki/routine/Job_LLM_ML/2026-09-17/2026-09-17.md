현재 목표와도 잘 연결됩니다. 특히 **PyTorch/Hugging Face 모델 개발 + LLM serving + benchmark + Linux/GPU 환경**을 모두 설명할 수 있고, 석사 과정에서 수행한 수치해석·회귀·정량적 실험 경험은 물류의 **예측/최적화 문제**와 연결하기 좋습니다.

여기서는 CJ올리브네트웍스와 포트폴리오 전략이 조금 달라야 합니다. Agent 기능을 많이 보여주는 것보다 **모델을 만들고 성능을 정량적으로 개선한 과정**을 앞에 두는 편이 좋습니다. `baseline → 모델/파라미터 변경 → 평가 지표 → error analysis → 성능 개선`이라는 연구형 흐름이 효과적입니다.

현재 부족한 부분은 **물류 도메인과 최적화 알고리즘 경험**입니다. 이번 공채에 `AI모델개발`과 `최적화`를 분리했다는 점도 중요합니다. LLM/ML 중심이면 **AI모델개발을 1순위**로 보고, 최적화는 보조 선택지로 두는 것이 현재 커리어 방향에 더 맞습니다. CJ대한통운이 최근 GPU 기반 배차 최적화와 Physical AI까지 기술 영역을 확대하고 있는 것도 확인됩니다. :chatgpt-content-reference{index="7"}

지원 전에는 **LoRA/QLoRA 실험 하나를 완성하는 것**이 가장 효과적입니다. 모델 전후 성능뿐 아니라 inference latency, GPU memory, error cases까지 기록하면 `모델 개발 + 시스템 이해`를 동시에 보여줄 수 있습니다. 여기에 기존 연구에서 사용했던 **가설 설정 → 변수 통제 → 정량 분석** 경험을 강조하면 비전산 전공이라는 약점도 상당 부분 상쇄할 수 있습니다.
