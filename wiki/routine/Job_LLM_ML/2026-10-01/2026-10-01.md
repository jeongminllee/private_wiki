업무 내용은 현재 준비 방향과 매우 가깝습니다. 더존비즈온은 자사 ERP·업무 데이터를 활용한 **AI Agent, AI Search, RAG pipeline**, 그리고 **MCP·A2A 기반 Agent 개발**을 맡깁니다. 여기에 데이터 chunking/indexing, synthetic data와 context augmentation뿐 아니라 **ontology·knowledge graph를 이용한 검색과 추론**까지 포함합니다. 자격요건에는 Python·Linux, Agent/RAG pipeline 구축·운영, LLM API 활용, ontology/knowledge graph 경험을 명시하고 있고, 우대사항에 NLP, FAISS/Milvus/pgvector와 **RAG 성능 평가·개선**이 들어갑니다. [직행](https://zighang.com/recruitment/5dcbf1c7-b2d8-4e27-a616-5fa2abcf3496?utm_source=chatgpt.com)

현재 강점 중에서는 **Python/Linux, FastAPI·MCP 계열 시스템 구현, Local LLM 기반 분석 Agent, 평가 pipeline**이 직접 연결됩니다. 특히 악성코드 분석 프로젝트를 `정적 분석 Tool → MCP/Agent → 근거 데이터 → LLM 판단 → 보고서` 형태로 보여주면 단순 RAG 데모보다 훨씬 설득력이 있습니다. B200/vLLM benchmark도 핵심 요구사항은 아니지만, latency와 inference 특성을 정량적으로 다뤄봤다는 보조 증거로 사용할 수 있습니다.

다만 **두 가지 걸림돌이 분명합니다.** 첫째, 공고가 명시적으로 `경력 1년 이상`을 요구하므로 현재 프로젝트·연구 경험을 회사가 실무 경력으로 어느 정도 인정할지는 불확실합니다. 따라서 “자격요건 완전 충족”으로 보기는 어렵습니다. 둘째, **ontology/knowledge graph가 단순 우대가 아니라 자격요건 쪽에 포함**되어 있습니다. RDF·OWL·SPARQL까지는 우대사항이지만, 최소한 entity–relation 구조를 직접 설계하고 검색·추론에 활용한 증거가 있으면 훨씬 유리합니다. [직행](https://zighang.com/recruitment/5dcbf1c7-b2d8-4e27-a616-5fa2abcf3496?utm_source=chatgpt.com)

지원 전에는 새로운 대형 프로젝트를 시작하기보다 현재 보안 LLM 프로젝트에 작은 **Knowledge Graph + RAG 평가 계층**을 붙이는 것이 효율적입니다. 예를 들어 `CWE → 취약 함수 → 공격 기법 → 정적 분석 evidence → remediation` 관계를 RDFLib나 Neo4j로 표현하고, Agent가 vector retrieval과 graph lookup을 함께 사용하도록 만든 뒤 `Recall@K/MRR`, 근거 일치율, unsupported claim rate, latency를 비교하면 됩니다. 이 결과를 GitHub README에 아키텍처·평가표·실패 사례와 함께 넣으면 이 JD의 `MCP + RAG + ontology + evaluation` 네 축을 한 프로젝트에서 보여줄 수 있습니다.

직무 성격은 **Core LLM Training/Research보다는 Enterprise Agent/RAG Engineering** 쪽입니다. 따라서 Upstage LLM Inference나 FuriosaAI처럼 장기 연구 방향의 최상위 카드를 대체할 공고는 아니지만, **현재 갖고 있는 프로젝트를 거의 그대로 활용하면서 국내에서 junior 수준으로 도전할 수 있는 Applied LLM 포지션**이라는 점에서 지원 가치가 있습니다.
