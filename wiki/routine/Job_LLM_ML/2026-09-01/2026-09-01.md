## 🎯 9월 하반기 AI/ML 채용 시장 핵심 트렌드

1. **"단순 프롬프트 엔지니어링 $\rightarrow$ 체계적인 평가(Evaluation Harness) 엔지니어링"**:
   - 기업들이 LLM 서비스를 상용화하면서 가장 절실히 필요로 하는 역량은 **"우리 비즈니스 도메인에서 모델이 무엇을 틀리고 왜 틀리는지 정량적으로 측정하고 지속 관리하는 체계"**입니다.
   - `lm-eval-harness`, RAG Triad 지표(Faithfulness, Answer Relevance, Context Recall), LLM-as-a-Judge 파이프라인 경험자가 최고 우대를 받습니다.

2. **"오픈소스 모델 경량화 및 고효율 서빙(vLLM / SGLang) 역량 요구 급증"**:
   - 클라우드 API 비용 부담으로 인해 7B~32B급 오픈소스 모델(Llama 3.3, Qwen 2.5 등)을 자체 인프라에 서빙하려는 수요가 폭증하고 있습니다.
   - LoRA/QLoRA 파인튜닝, FP8 양자화, vLLM/SGLang 기반의 High-Throughput 서빙 파이프라인 구축 능력이 핵심 차별화 요소입니다.

### 🌟 추천 포트폴리오 구성 예시:
> **프로젝트 제목**: *“도메인 특화 LLM 벤치마크 구축 및 합성 데이터를 활용한 성능 개선 파이프라인”*

1. **문제 정의**: 특정 태스크(예: 금융/법률 QA, 복합 SQL 생성)에서 Base 모델의 한계점과 취약한 실패 패턴 정의.
2. **벤치마크 설계**: 100~200개 규모의 엄격한 Gold-standard 평가 데이터셋 구축 및 평가 메트릭 정의.
3. **합성 데이터 생성 & 필터링**: 취약 케이스를 보완하는 합성 데이터를 생성하고, Rule Filter + LLM Judge로 고품질 데이터 선별.
4. **Fine-Tuning & 결과 검증**: LoRA 파인튜닝 전후 성능 비교 차트, 카테고리별 Accuracy 변화, Ablation Study 결과를 README에 시각화.
