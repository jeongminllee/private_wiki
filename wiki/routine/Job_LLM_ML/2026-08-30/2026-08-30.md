이전에 알린 공고는 제외했습니다. 이번 검색에서는 **국내 2건 + 글로벌 1건**이 새 알림 기준을 넘었습니다. 특히 **넷마블 AI 전략실 인턴은 이번 주기에서 가장 우선순위가 높습니다.** 경력·전공·학력 제한이 없으면서 로컬 GPU LLM 서빙, Hugging Face, 최신 LLM 논문 재현, GitHub까지 직접 우대합니다. ([지원아][1])

넷마블 AI 전략실에서 **LLM 및 음성 AI 연구·개발**을 담당합니다. LLM 쪽에서는 자연스러운 장기 대화를 위한 **기억 추출·정리·랭킹과 감정 인식**을 다루며, 별도 트랙에서는 STT/TTS 기반 Cascaded Conversation을 연구합니다. 우대사항이 상당히 직접적인데, **로컬 GPU에서의 LLM 서빙, Hugging Face, LangGraph·Agno, 딥러닝 모델 설계·학습·추론, 최신 LLM 논문 구현·재현, GitHub 공개 프로젝트 또는 오픈소스 기여**가 명시되어 있습니다. ([지원아][1])

현재의 Python·PyTorch·Hugging Face와 Linux/GitHub 기반 경험, GPU 환경에서 모델을 직접 실행·서빙하고 벤치마크하려는 방향을 거의 그대로 가져갈 수 있습니다. 특히 최근의 LLM Agent/Harness 관심까지 고려하면 **대화 Memory를 관리하고 평가하는 LLM 트랙**이 음성 트랙보다 훨씬 자연스럽게 연결됩니다.

부족할 수 있는 부분은 **장기 대화 memory architecture와 정량적인 conversational evaluation**입니다. 단순 RAG 경험보다 “어떤 정보를 장기 기억으로 남길지, 어떤 시점에 회수할지, 잘못된 기억을 어떻게 방지할지”를 설명할 수 있으면 좋습니다.

마감이 **내일인 8월 31일**이라 새 프로젝트를 만드는 것은 비효율적입니다. 지원서와 GitHub에서 `local LLM 실행/서빙`, `Hugging Face 모델 사용·튜닝`, `benchmark/error analysis`, `최신 기술·논문을 실제 코드로 검증한 경험`을 전면에 배치하는 것이 좋습니다. 프로젝트 설명은 **문제 → 실험 조건 → 수치 결과 → 실패 원인 → 개선** 순서로 정리하면 이 JD와 특히 잘 맞습니다. ([지원아][1])

주요 업무는 GenOS 테스트 페이지 구현·관리, **고객사 맞춤형 모델 학습용 데이터셋 생성·관리**, 그리고 AI 솔루션 프로젝트에서 **Agent 생성**을 지원하는 것입니다. 우대사항에는 Vector Search·RAG, 대규모 AI 모델 및 데이터 최적화, **LLM·Embedding·Multimodal 모델용 데이터셋 생성 → 학습 → 배포** 경험이 들어갑니다. ([유어잡 URJOB][2])

모델 연구에만 갇히지 않고 **데이터 → LLM/RAG → Agent → 배포** 사이클을 경험할 수 있다는 점이 좋습니다. Python/PyTorch 기반 ML 경험과 LLM/Agent 프로젝트를 실제 기업용 GenAI 시스템으로 확장하려는 경우에는 상당히 현실적인 진입 포지션입니다.

반면 넷마블에 비하면 **PyTorch/Hugging Face, benchmark, 논문 재현을 직접 요구하는 정도는 낮습니다.** 또한 Enterprise RAG, Vector Search, 고객사별 데이터 파이프라인 경험이 부족하다면 그 부분이 간극입니다.

지원 전에는 기존 프로젝트 하나를 `원본 데이터 → 정제/학습 데이터셋 → embedding/vector DB → RAG → Agent → evaluation`이라는 흐름으로 설명할 수 있도록 정리하세요. 특히 데이터셋을 “만들었다”에서 끝내지 말고 **품질 기준, retrieval accuracy, hallucination/error case**까지 붙이면 좋습니다.

마감일은 주의가 필요합니다. 최신 JobKorea 재게시에는 **8월 26일 시작·10월 10일 마감**으로 나오지만, Linkareer/URJOB 계열 공고에는 **8월 31일 마감**으로 표시됩니다. 회사가 재공고하면서 일정이 변경된 것으로 보이므로, 안전하게는 **8월 31일 이전 지원**을 권합니다. ([잡코리아][3])
