### 최우선: PyTorch vs Triton benchmark

아주 작은 실험이면 됩니다.

예:

```text
PyTorch implementation
        ↓
same operation
        ↓
Triton implementation
        ↓
Benchmark
        ↓
Latency / Throughput
        ↓
Memory access analysis
```

여기서 중요한 건 절대적인 성능 숫자가 아닙니다.

**왜 차이가 발생했는지를 설명하는 것**입니다.

예를 들어:

- memory-bound인가?
- compute-bound인가?
- coalesced access인가?
- tile size가 어떤 영향을 주는가?
- occupancy는?
- memory bandwidth를 얼마나 사용하는가?

정도까지 분석하면 좋습니다.
