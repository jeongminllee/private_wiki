# 캐시 파일 삭제 방법

> **카테고리**: `Infra - Linux & Remote`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2025-10-28

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
com.grammarly.GRLlamaOnboarding
com.grammarly.ProjectLlama
com.grammarly.ProjectLlama.UpdateService
```
이 세 파일은 Library/Caches 폴더 안에 있던 캐시 파일들이야. 삭제하는 터미널 명령어 알려줘

### 💡 답변 (Assistant)
아래 명령어를 그대로 터미널에 붙여 넣으면 됩니다. (macOS 기본 쉘 zsh 기준)

## 1) 사용자 캐시(~/Library/Caches) 지우기
```bash
# 존재 여부 확인(선택)
ls -ld ~/Library/Caches/{com.grammarly.GRLlamaOnboarding,com.grammarly.ProjectLlama,com.grammarly.ProjectLlama.UpdateService} 2>/dev/null

# 삭제
rm -rf -- ~/Library/Caches/{com.grammarly.GRLlamaOnboarding,com.grammarly.ProjectLlama,com.grammarly.ProjectLlama.UpdateService}
```

## 2) 시스템 캐시(/Library/Caches)에 있을 경우(있으면 아래도 실행)
```bash
# 존재 여부 확인(선택)
ls -ld /Library/Caches/{com.grammarly.GRLlamaOnboarding,com.grammarly.ProjectLlama,com.grammarly.ProjectLlama.UpdateService} 2>/dev/null

# 삭제(관리자 권한 필요)
sudo rm -rf -- /Library/Caches/{com.grammarly.GRLlamaOnboarding,com.grammarly.ProjectLlama,com.grammarly.ProjectLlama.UpdateService}
```

### 참고
- `rm -rf`는 되돌릴 수 없으니 경로를 꼭 확인하세요.  
- 삭제 전에 Grammarly 관련 앱이 실행 중이면 종료하고 진행하세요.  
- 휴지통으로 보내고 싶다면(완전 삭제 대신):
```bash
osascript -e 'tell application "Finder" to delete POSIX file (POSIX path of (system attribute "HOME") & "Library/Caches/com.grammarly.GRLlamaOnboarding")' \
          -e 'tell application "Finder" to delete POSIX file "/Users/$USER/Library/Caches/com.grammarly.ProjectLlama"' \
          -e 'tell application "Finder" to delete POSIX file "/Users/$USER/Library/Caches/com.grammarly.ProjectLlama.UpdateService"'
```
