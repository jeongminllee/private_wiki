# 인터넷 연결 문제 해결

> **카테고리**: `Errors - CUDA & GPU`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2026-03-24

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
Ubuntu 설치 직후 **인터넷이 안 되는 경우**는 대부분 다음 3가지 계층 중 하나에서 문제가 발생합니다:

1) **물리/드라이버 (NIC 인식 문제)**  
2) **네트워크 설정 (Netplan / NetworkManager)**  
3) **DNS / IP 할당 문제**

아래 순서대로 점검하면 빠르게 원인 좁힐 수 있습니다.

---

# 1️⃣ 가장 먼저: 인터페이스 인식 확인
```bash
ip a
```

### 정상
- `eth0`, `enp3s0`, `wlan0` 같은 인터페이스 존재
- `UP` 상태

### 문제 케이스
- 인터페이스 자체가 없음 → **드라이버 문제**
- `DOWN` 상태 → 활성화 필요

👉 인터페이스 활성화
```bash
sudo ip link set <인터페이스명> up
```

---

# 2️⃣ 유선 LAN vs Wi-Fi 먼저 구분

## ✔️ 유선 LAN이라면
```bash
sudo dhclient
```

→ IP 자동 할당 요청

그 다음:
```bash
ip a
```
→ `inet 192.168.x.x` 생겼는지 확인

---

## ✔️ Wi-Fi라면
```bash
nmcli device
```

### 상태 해석
- `wifi disconnected` → 연결 필요
- `unavailable` → 드라이버 문제 가능성 큼

👉 Wi-Fi 연결
```bash
nmcli device wifi list
nmcli device wifi connect "SSID" password "비밀번호"
```

---

# 3️⃣ 드라이버 문제 (가장 흔한 원인 🔥)

특히:
- Realtek
- Broadcom

👉 확인
```bash
lspci | grep -i network
```
또는
```bash
lsusb
```

👉 드라이버 로드 여부
```bash
lsmod | grep <드라이버명>
```

---

## ✔️ 해결 방법 (인터넷 없이)

### 방법 1: USB 테더링 (가장 빠름)
폰 연결 → 자동 네트워크 인식됨  
→ 이후:
```bash
sudo apt update
sudo ubuntu-drivers autoinstall
```

---

### 방법 2: 오프라인 드라이버 설치
다른 PC에서 다운로드 후 USB로 옮김

예:
- Broadcom:
```bash
sudo apt install bcmwl-kernel-source
```

---

# 4️⃣ NetworkManager / Netplan 확인

Ubuntu 24.04는 기본적으로 **NetworkManager 기반**

```bash
systemctl status NetworkManager
```

→ inactive면:
```bash
sudo systemctl restart NetworkManager
```

---

## Netplan 확인
```bash
cat /etc/netplan/*.yaml
```

예시 정상:
```yaml
network:
  version: 2
  renderer: NetworkManager
```

적용:
```bash
sudo netplan apply
```

---

# 5️⃣ IP는 있는데 인터넷 안될 때 (DNS 문제)

```bash
ping 8.8.8.8
```

### 결과
- 성공 → 인터넷은 됨 (DNS 문제)
- 실패 → 네트워크 자체 문제

👉 DNS 설정
```bash
sudo nano /etc/resolv.conf
```

추가:
```
nameserver 8.8.8.8
nameserver 1.1.1.1
```

---

# 6️⃣ 최종 점검 플로우 (실전 루틴)

```bash
ip a
nmcli device
ping 8.8.8.8
ping google.com
```

이 4개 결과로 거의 100% 원인 특정 가능

---

# 🚨 가장 흔한 원인 TOP 3

1. Wi-Fi 드라이버 없음 (특히 Broadcom/Realtek)
2. DHCP 미할당
3. NetworkManager 비활성

---

# 🔧 추천 해결 전략 (현실적인 순서)

1. 📱 **USB 테더링 연결 (강력 추천)**
2. → `ubuntu-drivers autoinstall`
3. → `apt update && upgrade`
4. → 재부팅

---
