### 💡 답변 (Assistant)
아래는 주어진 과제를 수행하기 위한 파이썬 코드의 일부분입니다. 시스템 정보 및 부하 정보를 수집하기 위해 `platform`, `psutil`, `json` 라이브러리를 사용하며, `setting.txt` 파일을 통해 출력 정보의 항목을 설정할 수 있도록 구현되어 있습니다.

```python
import platform
import psutil
import json

class MissionComputer:
    def __init__(self):
        self.load_setting()
    
    def load_setting(self):
        try:
            with open("setting.txt", "r") as f:
                self.settings = json.load(f)
        except FileNotFoundError:
            # 기본 설정
            self.settings = {
                "os": True,
                "os_version": True,
                "cpu_type": True,
                "cpu_cores": True,
                "memory_size": True,
                "cpu_usage": True,
                "memory_usage": True
            }

    def get_mission_computer_info(self):
        system_info = {}
        
        if self.settings.get("os"):
            system_info["운영체계"] = platform.system()
        if self.settings.get("os_version"):
            system_info["운영체계 버전"] = platform.version()
        if self.settings.get("cpu_type"):
            system_info["CPU의 타입"] = platform.processor()
        if self.settings.get("cpu_cores"):
            system_info["CPU의 코어 수"] = psutil.cpu_count(logical=False)
        if self.settings.get("memory_size"):
            memory = psutil.virtual_memory()
            system_info["메모리의 크기"] = memory.total

        return system_info

    def get_mission_computer_load(self):
        load_info = {}
        
        if self.settings.get("cpu_usage"):
            cpu_usage = psutil.cpu_percent(interval=1, percpu=True)
            load_info["CPU 실시간 사용량"] = [f"Core {i}: {usage}%" for i, usage in enumerate(cpu_usage)]
        if self.settings.get("memory_usage"):
            memory_usage = psutil.virtual_memory()
            load_info["메모리 실시간 사용량"] = f"{memory_usage.percent}%"

        return load_info

    def save_settings(self):
        with open("setting.txt", "w") as f:
            json.dump(self.settings, f)

if __name__ == "__main":
    mission_computer = MissionComputer()
    
    # 시스템 정보 출력
    system_info = mission_computer.get_mission_computer_info()
    print(json.dumps(system_info, indent=4))

    # 시스템 부하 정보 출력
    load_info = mission_computer.get_mission_computer_load()
    print(json.dumps(load_info, indent=4))

    # 설정을 변경하고 저장할 경우
    mission_computer.settings["cpu_usage"] = False
    mission_computer.settings["memory_usage"] = False
    mission_computer.save_settings()
```

이 코드는 `MissionComputer` 클래스를 정의하고, 설정 파일 `setting.txt`를 사용하여 출력 정보의 항목을 설정합니다. 클래스는 시스템 정보와 부하 정보를 수집하고, JSON 형식으로 출력합니다. 설정을 변경한 후 `save_settings` 메서드를 호출하여 변경 내용을 저장할 수 있습니다.

물론, 시스템에서 실행하기 전에 필요한 라이브러리를 설치해야 합니다. 이 코드의 실행 결과는 지정된 설정과 실제 시스템 상태에 따라 다를 수 있습니다.

### 💡 답변 (Assistant)
`self.settings` 딕셔너리의 초기값은 주로 코드 내에 하드 코딩된 기본 설정입니다. 이 설정은 코드 내에서 사용할 수 있도록 프로그램이 시작할 때 로드되며, 사용자가 직접 `setting.txt` 파일을 수정하여 사용자 지정 설정을 저장하거나 불러올 수 있도록 합니다.

사용자는 `setting.txt` 파일을 통해 이러한 설정을 변경할 수 있습니다. 예를 들어, `setting.txt` 파일은 다음과 같이 보일 수 있습니다:

```json
{
    "os": true,
    "os_version": true,
    "cpu_type": true,
    "cpu_cores": true,
    "memory_size": true,
    "cpu_usage": false,
    "memory_usage": true
}
```

이 파일에서 `cpu_usage` 설정을 `false`로 변경하면 CPU 사용량 정보가 출력되지 않습니다. 사용자가 원하는 대로 설정을 변경하고 저장한 후 코드를 실행하면 설정이 반영됩니다.

이렇게 하면 사용자가 설정을 커스터마이즈하고 더 편리하게 관리할 수 있습니다.
