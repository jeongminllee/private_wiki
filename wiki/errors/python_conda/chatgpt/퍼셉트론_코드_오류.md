# 퍼셉트론 코드 오류

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
# 퍼셉트론의 수학 모델 f(x*w + b)
def predict(input) :
    x = torch.matmul(input, w) + b
    x = torch.maximum(input=torch.tensor(0.), other=x)
    return x

inputs = torch.tensor([[0, 0], 
                       [0, 1], 
                       [1, 0], 
                       [1, 1]], dtype=torch.float32)

predict(inputs)
```

함수의 어떤 부분이 잘 못된걸까

### 💡 답변 (Assistant)
주어진 코드에서 발생한 오류는 `torch.matmul(input, w)` 부분에서 `input`과 `w`의 크기가 맞지 않아서 생깁니다. `torch.matmul`은 행렬 곱셈을 수행하며, 입력 텐서들의 차원과 크기가 적절히 맞아야 합니다.

오류 메시지를 보면, `input` 텐서의 크기는 `(4, 2)`이고, `w` 텐서의 크기가 잘못 지정되었거나 정의되지 않았음을 나타냅니다.

---

### 문제 원인
- `input` 텐서는 크기가 `(4, 2)`입니다.
  - 4개의 샘플, 각 샘플은 2개의 특징으로 구성되어 있습니다.
- `w`는 가중치 텐서로, 크기가 `(2, n)`이어야 합니다. 여기서 `n`은 출력 노드의 수입니다.
- 그러나 `w`가 제대로 정의되지 않았거나, 올바른 크기로 초기화되지 않았기 때문에 오류가 발생했습니다.

---

### 해결 방법
1. `w`와 `b`를 정의하고 올바른 크기로 초기화합니다.
    ```python
    w = torch.tensor([[1.0], [1.0]])  # 크기 (2, 1)
    b = torch.tensor([0.0])           # 크기 (1,)
    ```
    여기서 `w`의 크기는 `(2, 1)`로 설정했으며, 이는 출력 노드가 하나라는 의미입니다.

2. 수정된 코드:
    ```python
    import torch

    # 퍼셉트론의 수학 모델 f(x*w + b)
    def predict(input):
        x = torch.matmul(input, w) + b  # input (4, 2), w (2, 1) -> x (4, 1)
        x = torch.maximum(input=torch.tensor(0.0), other=x)  # ReLU 활성화 함수
        return x

    inputs = torch.tensor([[0, 0],
                           [0, 1],
                           [1, 0],
                           [1, 1]], dtype=torch.float32)

    # 가중치와 편향 정의
    w = torch.tensor([[1.0], [1.0]])  # 크기 (2, 1)
    b = torch.tensor([0.0])           # 크기 (1,)

    output = predict(inputs)
    print(output)
    ```

3. 출력 결과:
    ```
    tensor([[0.],
            [1.],
            [1.],
            [2.]])
    ```
   여기서 `(0, 0), (0, 1), (1, 0), (1, 1)`에 대한 출력은 입력의 합을 기반으로 계산됩니다.

---

### 요약
- 오류는 `torch.matmul(input, w)`에서 `input`과 `w`의 크기가 맞지 않아 발생했습니다.
- `w`와 `b`를 올바르게 정의하고 초기화하면 문제를 해결할 수 있습니다.
