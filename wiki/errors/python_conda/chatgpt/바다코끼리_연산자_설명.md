# 바다코끼리 연산자 설명

> **카테고리**: `Errors - Python & Conda`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
파이썬 바다코끼리(윌러스) : = 연산자는 어떤 건지 설명해줘

### 💡 답변 (Assistant)
파이썬의 **바다코끼리 연산자(Walrus Operator)**는 `:=`입니다.

```python
변수 := 표현식
```

일반 대입 연산자 `=`와 달리, **값을 변수에 저장하면서 그 값을 표현식 안에서 바로 사용할 수 있습니다.**

## 1. `=`와 `:=`의 차이

일반 대입문은 값을 저장만 합니다.

```python
n = len(data)

if n > 10:
    print(n)
```

바다코끼리 연산자를 사용하면 대입과 조건 검사를 한 번에 처리할 수 있습니다.

```python
if (n := len(data)) > 10:
    print(n)
```

위 코드는 다음 두 작업을 동시에 수행합니다.

1. `len(data)`를 계산한다.
2. 계산 결과를 `n`에 저장한 뒤 `n > 10`을 검사한다.

즉, `:=`는 정식 명칭으로 **대입 표현식(assignment expression)**입니다.

---

## 2. 왜 이름이 바다코끼리인가?

`:=`를 옆으로 보면 바다코끼리의 눈과 엄니처럼 보인다고 해서 붙은 별명입니다.

```text
:=
```

- `:` → 눈
- `=` → 엄니

---

## 3. 대표적인 사용 사례

### 반복해서 입력받기

바다코끼리 연산자가 없으면 다음처럼 작성합니다.

```python
command = input("명령어: ")

while command != "quit":
    print(f"실행: {command}")
    command = input("명령어: ")
```

`input()` 코드가 두 번 반복됩니다.

바다코끼리 연산자를 사용하면 다음과 같이 줄일 수 있습니다.

```python
while (command := input("명령어: ")) != "quit":
    print(f"실행: {command}")
```

동작 순서는 다음과 같습니다.

```python
command := input("명령어: ")
```

입력값을 `command`에 저장한 다음,

```python
command != "quit"
```

조건을 검사합니다.

---

### 계산 결과를 조건문에서 재사용하기

```python
numbers = [10, 20, 30, 40]

if (average := sum(numbers) / len(numbers)) >= 25:
    print(f"평균은 {average}입니다.")
```

출력:

```text
평균은 25.0입니다.
```

`sum(numbers) / len(numbers)`를 다시 계산하지 않아도 됩니다.

---

### 정규식 검색 결과 저장하기

바다코끼리 연산자가 특히 유용한 사례입니다.

```python
import re

text = "주문번호는 ORDER-1234입니다."

if match := re.search(r"ORDER-\d+", text):
    print(match.group())
```

출력:

```text
ORDER-1234
```

다음 두 작업을 동시에 수행합니다.

```python
match = re.search(...)
```

그리고:

```python
if match:
```

검색에 성공했는지 검사합니다.

---

### 파일을 일정 크기씩 읽기

```python
with open("data.bin", "rb") as file:
    while chunk := file.read(1024):
        process(chunk)
```

`file.read(1024)`가 빈 바이트 문자열 `b""`을 반환할 때까지 반복합니다.

바다코끼리 연산자가 없으면 다음과 같이 작성해야 합니다.

```python
with open("data.bin", "rb") as file:
    chunk = file.read(1024)

    while chunk:
        process(chunk)
        chunk = file.read(1024)
```

## 4. 괄호가 필요한 경우

바다코끼리 연산자는 문맥에 따라 괄호를 요구하거나, 괄호를 사용하는 편이 안전합니다.

```python
if (n := len(data)) > 10:
    print(n)
```

다음처럼 작성하면 의도가 불분명하거나 문법 오류가 발생할 수 있습니다.

```python
if n := len(data) > 10:
    print(n)
```

이 코드는 `len(data)`가 아니라 비교 결과인 `True` 또는 `False`가 `n`에 저장되는 것으로 해석될 여지가 있습니다.

실제로 의미는 대략 다음과 같습니다.

```python
n := (len(data) > 10)
```

따라서 계산 결과 자체를 저장하려면 반드시 의도를 분명히 표현해야 합니다.

```python
if (n := len(data)) > 10:
    print(n)
```

---

## 5. 리스트 컴프리헨션에서 사용하기

다음 코드는 각 문자열의 길이를 계산하고, 길이가 3보다 큰 문자열만 결과에 넣습니다.

```python
words = ["AI", "Python", "ML", "Transformer"]

result = [
    (word, length)
    for word in words
    if (length := len(word)) > 3
]

print(result)
```

출력:

```python
[('Python', 6), ('Transformer', 11)]
```

`len(word)`를 한 번만 계산하고, 그 결과를 조건 검사와 결과 생성에 모두 사용합니다.

다만 리스트 컴프리헨션에서 지나치게 복잡하게 사용하면 읽기 어려워질 수 있습니다.

---

## 6. `:=`는 아무 곳에서나 `=` 대신 쓸 수 없다

다음은 올바른 일반 대입입니다.

```python
x = 10
```

바다코끼리 연산자를 단독 대입문처럼 작성하면 오류가 발생합니다.

```python
x := 10
```

단독으로 사용하려면 괄호가 필요합니다.

```python
(x := 10)
```

하지만 이렇게 작성할 이유는 거의 없습니다. 단순 대입에는 그냥 `=`를 사용해야 합니다.

```python
x = 10
```

`:=`는 **조건문, 반복문, 컴프리헨션 등의 표현식 안에서 대입 결과를 바로 재사용할 때** 의미가 있습니다.

---

## 7. 자주 하는 실수

### 비교 결과를 저장하는 실수

```python
if n := len(data) > 10:
    print(n)
```

여기서 `n`에는 길이가 아니라 `True` 또는 `False`가 저장될 수 있습니다.

올바른 형태:

```python
if (n := len(data)) > 10:
    print(n)
```

---

### 너무 많은 작업을 한 줄에 넣기

```python
if (result := process(data)) and (score := evaluate(result)) > 0.8:
    save(result, score)
```

문법적으로는 가능하지만, 로직이 복잡해지면 분리하는 편이 좋습니다.

```python
result = process(data)

if result:
    score = evaluate(result)

    if score > 0.8:
        save(result, score)
```

바다코끼리 연산자는 코드를 무조건 짧게 만드는 도구가 아니라, **중복 계산을 줄이면서 가독성도 유지할 수 있을 때 사용하는 도구**입니다.

---

## 8. 언제 사용하면 좋은가?

다음 조건에 해당하면 유용합니다.

- 계산 비용이 있는 표현식의 결과를 조건문에서 바로 재사용할 때
- `while`문에서 입력이나 파일 읽기 결과를 즉시 검사할 때
- 정규식 검색 결과처럼 성공 여부와 결과 객체를 함께 사용할 때
- 같은 표현식을 반복해서 작성하는 것을 피할 때

반대로 단순한 대입이라면 `=`가 더 좋습니다.

```python
name = "Python"
```

이를 굳이 다음처럼 작성할 필요는 없습니다.

```python
(name := "Python")
```

## 핵심 정리

```python
if (n := len(data)) > 10:
    print(n)
```

여기서:

```python
n := len(data)
```

는 `len(data)`의 결과를 `n`에 저장하면서, 그 값 자체도 표현식의 결과로 반환합니다.

개념적으로는 다음 두 줄을 한 문맥 안에서 처리하는 것입니다.

```python
n = len(data)

if n > 10:
    print(n)
```

바다코끼리 연산자는 **Python 3.8부터 지원**하며, “대입하면서 바로 사용한다”가 핵심입니다.
