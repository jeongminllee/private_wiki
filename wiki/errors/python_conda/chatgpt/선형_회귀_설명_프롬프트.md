선형 회귀(Linear Regression)는 데이터 사이의 관계를 모델링하는 가장 기초적이면서도 강력한 도구입니다. 수학적 기반부터 확률적 해석, 그리고 실제 구현 시 마주하게 되는 한계까지 체계적으로 정리해 드리겠습니다.

---

### 1. 선형 회귀의 기본 개념

**"선형(Linear)"의 의미**
머신러닝에서 선형 회귀가 '선형'이라고 불리는 이유는 모델이 **파라미터(가중치 $w$)에 대해 선형**이기 때문입니다. 입력 변수 $x$ 자체가 제곱($x^2$)이나 로그($\log x$) 형태를 띠더라도, 우리가 찾아야 할 파라미터 $w$가 곱해지고 더해지는 구조라면 이는 선형 모델로 분류됩니다.

**기본 가정**
선형 회귀는 출력 변수 $y$가 입력 변수 $x$의 선형 결합에 **가우시안 노이즈($\epsilon$)**가 더해진 형태라고 가정합니다. 즉, 데이터가 특정 '직선' 또는 '평면'의 근처에 분포한다고 믿는 것입니다.

---

### 2. 수학적 모델링

**수식 표현**
*   **단순 선형 회귀:** 독립 변수가 하나인 경우입니다. $y = w_1x + w_0 + \epsilon$
*   **다중 선형 회귀:** 여러 변수가 영향을 미칩니다. $y = w_0 + w_1x_1 + w_2x_2 + \dots + w_Dx_D + \epsilon$

**행렬 표현 (Vectorization)**
계산을 효율적으로 하기 위해 데이터를 행렬로 표현합니다.
$$\mathbf{y} = \mathbf{X}\mathbf{w} + \mathbf{\epsilon}$$
*   $\mathbf{X}$ (**설계 행렬, Design Matrix**): $N \times (D+1)$ 크기로, 각 행은 하나의 데이터 샘플을 의미합니다. 첫 열은 편향($w_0$)을 위해 보통 1로 채웁니다.
*   $\mathbf{w}$ (**가중치 벡터**): 우리가 찾고자 하는 파라미터들입니다.
*   $\mathbf{y}$ (**타겟 벡터**): 실제 관측값들입니다.

**잔차(Residual)의 의미**
잔차는 **실제 값($y$)과 모델이 예측한 값($\hat{y}$)** 사이의 차이($y - \hat{y}$)를 의미합니다. 오차(Error)가 이론적인 모델과 실제의 차이라면, 잔차는 우리가 가진 표본 데이터에서 계산되는 구체적인 수치입니다.

---

### 3. 손실 함수와 최적화

**평균제곱오차(MSE)를 사용하는 이유**
가장 널리 쓰이는 손실 함수는 **평균제곱오차(Mean Squared Error)**입니다.
$$E(\mathbf{w}) = \frac{1}{2N} \sum_{n=1}^{N} \{y_n - \mathbf{w}^T\mathbf{x}_n\}^2$$
제곱을 하는 이유는 오차의 음수/양수 여부와 상관없이 거리를 측정하기 위함이며, 미분이 가능하여 수학적으로 최적화하기 매우 편리하기 때문입니다.

**최소제곱법(OLS)과 정규방정식(Normal Equation)**
MSE를 최소화하기 위해 손실 함수를 $\mathbf{w}$에 대해 미분하여 0이 되는 지점을 찾으면 다음과 같은 **정규방정식**이 유도됩니다.
$$\mathbf{w}_{ML} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$
*   **직관적 의미:** 이는 벡터 $\mathbf{y}$를 행렬 $\mathbf{X}$의 열들이 이루는 부분공간에 **직교 투영(Orthogonal Projection)**하는 가중치를 찾는 것과 같습니다.
*   **한계:** 데이터가 너무 많거나 변수 간 상관관계가 높으면 행렬의 역행렬을 구하는 비용이 커지거나 계산이 불가능(Singularity 문제)해질 수 있습니다.

**경사하강법(Gradient Descent)과의 차이**
정규방정식은 한 번에 해를 구하는 '해석적 방법'인 반면, 경사하강법은 반복적으로 기울기를 따라 내려가며 최적값을 찾는 '수치적 방법'입니다. 데이터가 매우 클 때는 메모리 문제로 인해 경사하강법이 훨씬 유리합니다.

---

### 4. 확률·통계적 해석

**가우시안 노이즈 가정**
관측값 $y$가 예측값 $\mathbf{w}^T\mathbf{x}$를 평균으로 하고 분산이 $\sigma^2$인 가우시안 분포를 따른다고 가정해 봅시다.
$$p(y|\mathbf{x}, \mathbf{w}, \sigma^2) = \mathcal{N}(y|\mathbf{w}^T\mathbf{x}, \sigma^2)$$

**최대우도추정(MLE)과의 연결**
이 확률 모델에서 전체 데이터의 발생 확률(Likelihood)을 최대화하는 가중치 $\mathbf{w}$를 찾으면, 신기하게도 **MSE를 최소화하는 과정과 정확히 일치**하게 됩니다. 즉, 선형 회귀의 최소제곱법은 "데이터의 오차가 가우시안 분포를 따른다"는 가정하에 가장 확률이 높은 모델을 찾는 것과 같습니다.

---

### 5. 주요 가정(Assumptions)과 위반 시 문제

1.  **선형성:** 입력과 출력의 관계가 선형적이어야 합니다. 비선형적이라면 모델의 예측력이 크게 떨어집니다.
2.  **독립성:** 데이터 샘플들이 서로 독립적이어야 합니다. 시계열 데이터처럼 앞뒤 데이터가 연관되면 오차가 편향될 수 있습니다.
3.  **등분산성:** 모든 입력값 범위에서 오차의 분산이 일정해야 합니다. 분산이 일정하지 않으면 특정 영역에서 예측 신뢰도가 낮아집니다.
4.  **정규성:** 잔차가 정규분포를 따라야 통계적 가설 검정(Z-score 등)이 유효해집니다.

---

### 6. 과적합(Overfitting)과 일반화

**파라미터 수와 데이터 수**
입력 변수(파라미터)의 개수가 데이터 수에 비해 너무 많으면 모델이 데이터의 '노이즈'까지 학습해 버리는 **과적합**이 발생합니다.
*   **훈련 오차(Training Error):** 데이터에 딱 맞게 복잡한 곡선을 그리므로 매우 낮아집니다.
*   **테스트 오차(Test Error):** 새로운 데이터가 들어오면 예측을 전혀 못 하므로 급격히 커집니다.

---

### 7. 정규화(Regularization)

과적합을 막기 위해 가중치 벡터 $\mathbf{w}$의 크기가 너무 커지지 않도록 패널티를 주는 기법입니다.

*   **Ridge (L2 정규화):** 손실 함수에 $\frac{\lambda}{2}\|\mathbf{w}\|^2$를 더합니다. 모든 가중치를 골고루 작게 만들어 모델을 부드럽게 만듭니다. (가우시안 사전 확률 분포를 가정한 MAP 추정과 같습니다.)
*   **Lasso (L1 정규화):** 손실 함수에 $\lambda\|\mathbf{w}\|_1$을 더합니다. 중요하지 않은 변수의 가중치를 **정확히 0**으로 만들어 변수 선택(Feature Selection) 효과를 줍니다.

---

### 8. 실제 구현 관점

**Scikit-learn의 LinearRegression**
내부적으로는 행렬의 **특이값 분해(SVD)** 등을 활용하여 정규방정식의 수치적 불안정성을 해결한 방식으로 해를 구합니다.

**Python 기초 구현 예시 (경사하강법)**
```python
import numpy as np

# 가중치 업데이트 식: w = w - learning_rate * gradient
# MSE의 기울기(gradient) = (1/N) * X.T @ (X @ w - y)

def train(X, y, lr=0.01, epochs=1000):
    n, d = X.shape
    w = np.zeros(d) # 가중치 초기화
    for _ in range(epochs):
        prediction = X @ w
        error = prediction - y
        gradient = (1/n) * X.T @ error
        w -= lr * gradient
    return w
```

---

### 9. 한계와 확장

*   **한계:** 이상치(Outlier)에 매우 민감합니다. 제곱 오차를 사용하기 때문에 멀리 떨어진 점 하나가 전체 직선의 방향을 크게 바꿀 수 있습니다.
*   **다항 회귀(Polynomial Regression):** 입력을 $x, x^2, x^3$ 등으로 변환하여 곡선 관계를 학습합니다. 여전히 $w$에 대해서는 선형이므로 선형 회귀의 틀 안에서 동작합니다.
*   **일반화 선형 모델(GLM):** 출력이 정규분포가 아닌 경우(예: 이진 분류의 베르누이 분포)에도 선형 모델의 아이디어를 적용한 확장판입니다. **로지스틱 회귀**가 대표적인 예입니다.

선형 회귀는 단순히 선을 긋는 것이 아니라, 데이터 이면의 확률적 구조를 파악하고 최적의 평면을 찾는 수학적 여정의 시작입니다.

# 선형 회귀(Linear Regression) 정리

선형 회귀(Linear Regression)는 데이터 간의 관계를 모델링하는 가장 기초적이면서도, 동시에 매우 강력한 도구입니다. 단순한 직선 모델로 보이지만, 그 이면에는 **선형대수, 최적화, 확률·통계**가 유기적으로 결합된 구조가 숨어 있습니다.  
아래에서는 수학적 기반부터 확률적 해석, 그리고 실제 구현 시 마주하게 되는 한계까지를 체계적으로 정리합니다.

---

## 1. 선형 회귀의 기본 개념

### “선형(Linear)”의 의미
선형 회귀가 ‘선형’이라고 불리는 이유는 **입력 변수에 대해 선형이기 때문이 아니라, 파라미터(가중치) $\mathbf{w}$에 대해 선형이기 때문**입니다.

예를 들어 입력이 $x^2$, $\log x$와 같은 비선형 형태이더라도,
\[
y = w_0 + w_1 x^2 + w_2 \log x
\]
처럼 파라미터가 선형 결합 형태로 등장한다면 이는 여전히 선형 모델입니다.

### 기본 가정
선형 회귀는 출력 변수 $y$가 입력 변수 $x$의 선형 결합에 **가우시안 노이즈 $\epsilon$**가 더해진 형태라고 가정합니다.
\[
y = \mathbf{w}^T \mathbf{x} + \epsilon
\]
즉, 데이터는 하나의 직선(또는 고차원에서는 평면) 주변에 확률적으로 분포한다고 가정합니다.

---

## 2. 수학적 모델링

### 수식 표현
- **단순 선형 회귀 (Simple Linear Regression)**  
  \[
  y = w_1 x + w_0 + \epsilon
  \]

- **다중 선형 회귀 (Multiple Linear Regression)**  
  \[
  y = w_0 + w_1 x_1 + \cdots + w_D x_D + \epsilon
  \]

### 행렬 표현 (Vectorization)
데이터를 행렬로 표현하면 계산과 이론 전개가 훨씬 간결해집니다.
\[
\mathbf{y} = \mathbf{X}\mathbf{w} + \boldsymbol{\epsilon}
\]

- $\mathbf{X}$ (**Design Matrix**): $N \times (D+1)$  
  각 행은 하나의 데이터 샘플이며, 첫 열은 편향항을 위해 1로 채웁니다.
- $\mathbf{w}$: 학습 대상인 가중치 벡터
- $\mathbf{y}$: 실제 관측값 벡터

### 잔차(Residual)
잔차는 실제값과 예측값의 차이입니다.
\[
r_n = y_n - \hat{y}_n
\]
- **오차(Error)**: 이론적 모델과 실제 세계의 차이
- **잔차(Residual)**: 표본 데이터에서 계산되는 구체적인 오차 값

---

## 3. 손실 함수와 최적화

### 평균제곱오차(MSE)
선형 회귀에서 가장 널리 쓰이는 손실 함수는 평균제곱오차입니다.
\[
E(\mathbf{w}) = \frac{1}{2N} \sum_{n=1}^{N} (y_n - \mathbf{w}^T \mathbf{x}_n)^2
\]

- 제곱을 통해 부호를 제거하고
- 미분 가능하므로 최적화가 용이합니다.

### 최소제곱법(OLS)과 정규방정식
손실 함수를 $\mathbf{w}$에 대해 미분해 0으로 두면 다음 해를 얻습니다.
\[
\mathbf{w}_{OLS} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}
\]

**직관적 의미**
- $\mathbf{y}$를 $\mathbf{X}$의 열공간(column space)에 **직교 투영**한 결과입니다.

**한계**
- $\mathbf{X}^T\mathbf{X}$가 역행렬을 가지지 않을 수 있음 (다중공선성)
- 데이터 규모가 커질수록 계산 비용과 메모리 부담 증가

### 경사하강법과의 차이
- **정규방정식**: 해석적(Closed-form) 해
- **경사하강법**: 반복적 수치 최적화  
대규모 데이터나 온라인 학습에서는 경사하강법이 실용적입니다.

---

## 4. 확률·통계적 해석

### 가우시안 노이즈 가정
관측값이 다음 분포를 따른다고 가정합니다.
\[
p(y|\mathbf{x},\mathbf{w},\sigma^2)
= \mathcal{N}(y \mid \mathbf{w}^T\mathbf{x}, \sigma^2)
\]

### 최대우도추정(MLE)
전체 데이터의 로그 우도를 최대화하면,
\[
\arg\max_{\mathbf{w}} \log p(\mathbf{y}|\mathbf{X},\mathbf{w})
\]
이는 **MSE 최소화 문제와 정확히 동일**해집니다.

👉 즉, 선형 회귀의 최소제곱해는  
“오차가 가우시안 분포를 따른다고 가정했을 때 가장 그럴듯한 모델”입니다.

## 5. 주요 가정과 위반 시 문제

1. **선형성**: 관계가 비선형이면 편향된 예측 발생  
2. **독립성**: 시계열·공간 데이터에서는 위반되기 쉬움  
3. **등분산성**: 분산이 달라지면 신뢰구간 해석이 왜곡됨  
4. **정규성**: 가설 검정과 신뢰구간의 타당성에 영향

---

## 6. 과적합과 일반화

- 파라미터 수 ≫ 데이터 수 → 과적합
- 훈련 오차 ↓, 테스트 오차 ↑

이는 모델이 **신호(signal)가 아닌 노이즈**까지 학습했기 때문입니다.

## 7. 정규화(Regularization)

### Ridge (L2)
\[
E(\mathbf{w}) + \frac{\lambda}{2}\|\mathbf{w}\|_2^2
\]
- 가중치를 전반적으로 작게 만듦
- 가우시안 사전분포를 가정한 MAP 추정과 동일

### Lasso (L1)
\[
E(\mathbf{w}) + \lambda\|\mathbf{w}\|_1
\]
- 일부 가중치를 정확히 0으로 만듦
- 변수 선택 효과 제공

## 8. 실제 구현 관점

### scikit-learn의 LinearRegression
- SVD 등 수치적으로 안정적인 방법 사용
- 명시적 역행렬 계산을 피함

### 경사하강법 기반 구현 예시
```python
import numpy as np

def train(X, y, lr=0.01, epochs=1000):
    n, d = X.shape
    w = np.zeros(d)
    for _ in range(epochs):
        prediction = X @ w
        error = prediction - y
        gradient = (1/n) * X.T @ error
        w -= lr * gradient
    return w
```

## 9. 한계와 확장

### 한계
- 이상치(outlier)에 매우 민감
- 복잡한 비선형 패턴 표현 불가

### 확장
- **다항 회귀**: 입력 변환을 통한 비선형 표현
- **일반화 선형 모델(GLM)**: 비정규 분포 출력 대응  
  (예: 로지스틱 회귀)
