# 파이썬 튜플 연산 오류

> **카테고리**: `Errors - Python & Conda`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
A=(1,2,3)
d=(2,4,6)
D+=a
D*=2
Print(len(d))

### 💡 답변 (Assistant)
지금 코드는 **파이썬 문법 + 자료형 동작**이 여러 군데 섞여 있어서 정확히 짚고 넘어가는 게 중요해. 하나씩 분해해보자.

---

## 1️⃣ 초기 상태
```python
A = (1, 2, 3)   # tuple (immutable)
d = (2, 4, 6)   # tuple (immutable)
```

- `A`, `d` 둘 다 **튜플(tuple)** → **immutable (불변 객체)**
- 즉, 내부 값 변경 ❌ (in-place 수정 불가)

---

## 2️⃣ `D += a`
문제 포인트가 여기야.

### ❗ 오류 1: 변수명
```python
D += a
```
- `D` → 정의 안 됨
- `a` → 정의 안 됨

👉 파이썬은 **대소문자 구분**
👉 `A`, `d`랑 완전히 다른 변수

➡️ 이 줄에서 바로 **NameError 발생**

---

## (가정) 의도한 코드라면?
아마 이거였을 가능성이 높아:

```python
d += A
```

### 이때 동작
```python
d = (2, 4, 6)
A = (1, 2, 3)

d += A
```

👉 tuple에서 `+=`는 **in-place가 아니라 새 객체 생성**

즉,
```python
d = d + A
```

결과:
```python
d = (2, 4, 6, 1, 2, 3)
```

---

## 3️⃣ `D *= 2`

또 동일 문제:
- `D` 정의 안 됨 → **NameError**

---

## (가정) 수정된 코드
```python
d *= 2
```

### 동작
```python
d = (2, 4, 6, 1, 2, 3)

d *= 2
```

👉 tuple 반복

결과:
```python
d = (2, 4, 6, 1, 2, 3, 2, 4, 6, 1, 2, 3)
```

---

## 4️⃣ `print(len(d))`

최종 길이:
```python
len(d) = 12
```

---

# ✅ 정리 (의도된 코드 기준)
```python
A = (1, 2, 3)
d = (2, 4, 6)

d += A
d *= 2

print(len(d))   # 12
```

---

# 🔥 핵심 개념 (중요)
### tuple에서 `+=`, `*=` 특징

| 연산 | 의미 | 실제 동작 |
|------|------|----------|
| `+=` | 연결 | 새 객체 생성 |
| `*=` | 반복 | 새 객체 생성 |

👉 **mutable처럼 보이지만 실제로는 immutable → 새 객체 할당**

---

# ⚠️ 시험에서 자주 나오는 함정
- tuple인데 `+=` → 수정처럼 보이지만 ❌
- 실제로는 → **새 객체 생성 후 재할당**
- 변수 이름 대소문자 → 엄격하게 구분
