## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
문제
이세계를 모험할 때는 무기가 필요한 법이기에 호반우는 현재 신에게 받은 소수소수검의 사용법을 익히고 있다.

소수소수검을 사용하기 위해서는 검이 제시하는 두 자릿수의 소수 
$A,\,B$와 양의 정수 
$N$을 이용해 소수소수를 만들어야 한다. 소수소수란 해당 수 자체가 소수일 필요는 없지만 모든 연속된 두 자릿수가 소수인 수를 말한다.

예를 들어 
$973$은 
$97$과 
$73$이 소수이므로 소수소수가 되지만, 
$937$은 
$93$이 소수가 아니기에 소수소수가 아니다.

이때 소수소수를 만들 때 한가지 제한사항이 있는데 처음 두 자릿수는 
$A$이고 마지막 두 자릿수는 
$B$인 
$N$ 자릿수의 소수소수를 만들어야 한다.

아직 검의 사용법에 익숙하지 않은 호반우를 도와 소수소수를 만들어 주자.

입력
첫 번째 줄에 소수 
$A,\,B$와 양의 정수 
$N$이 공백을 두고 주어진다. 
$(7 \le N \le 100,\,11 \le A,\,B \le 97)$ 

출력
주어진 수들로 소수소수를 만들 수 있다면 소수소수를 아무거나 하나 출력하고 만들 수 없다면 -1을 출력한다.

예제 입력 1 
47 37 7
예제 출력 1 
4719737
 
\(4719737\)은 모든 연속된 두 자릿수 
\(47,71,19,97,73,37\)이 소수이므로 소수소수이다.

예제 입력 2 
17 23 10
예제 출력 2 
-1
파이썬 코드 작성해줘

### 💡 답변 (Assistant)
주어진 조건에 따라 소수소수를 만드는 파이썬 코드를 작성해보겠습니다.

```python
def is_prime(num):
    if num <= 1:
        return False
    if num == 2:
        return True
    if num % 2 == 0:
        return False
    for i in range(3, int(num ** 0.5) + 1, 2):
        if num % i == 0:
            return False
    return True

def find_prime_pairs(A, B, N):
    result = []
    for num in range(10**(N-1), 10**N):
        str_num = str(num)
        if is_prime(num):
            for i in range(N - 1):
                if not is_prime(int(str_num[i:i+2])):
                    break
            else:
                if str_num.startswith(str(A)) and str_num.endswith(str(B)):
                    result.append(str_num)
    return result

A, B, N = map(int, input().split())
prime_pairs = find_prime_pairs(A, B, N)

if prime_pairs:
    print(prime_pairs[0])
else:
    print(-1)
```

이 코드는 먼저 주어진 수가 소수인지를 판별하는 `is_prime` 함수를 정의합니다. 그 후, 주어진 조건에 맞게 소수소수를 찾는 `find_prime_pairs` 함수를 구현합니다. 마지막으로 주어진 입력에 따라 결과를 출력합니다.

### 💡 답변 (Assistant)
주어진 입력에서 `split()` 함수를 사용하여 입력을 공백을 기준으로 나눈 후에 `map()` 함수를 사용하여 각 값을 정수로 변환하고자 했는데, 입력이 비어있는 경우에 대한 처리가 필요합니다. 아래 코드에서는 이를 처리하도록 수정하였습니다.

```python
def is_prime(num):
    if num <= 1:
        return False
    if num == 2:
        return True
    if num % 2 == 0:
        return False
    for i in range(3, int(num ** 0.5) + 1, 2):
        if num % i == 0:
            return False
    return True

def find_prime_pairs(A, B, N):
    result = []
    for num in range(10**(N-1), 10**N):
        str_num = str(num)
        if is_prime(num):
            for i in range(N - 1):
                if not is_prime(int(str_num[i:i+2])):
                    break
            else:
                if str_num.startswith(str(A)) and str_num.endswith(str(B)):
                    result.append(str_num)
    return result

try:
    A, B, N = map(int, input().split())
    prime_pairs = find_prime_pairs(A, B, N)

    if prime_pairs:
        print(prime_pairs[0])
    else:
        print(-1)
except ValueError:
    print("입력이 잘못되었습니다.")
```
