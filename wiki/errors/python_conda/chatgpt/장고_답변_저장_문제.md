# 장고 답변 저장 문제

> **카테고리**: `Errors - Python & Conda`

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
지금 파이썬 장고로 웹 페이지를 제작하고 질문 답변 게시판을 만들고 있어. 지금 마지막 단계로 답변을 다는 부분을 설정하고 이를 답변을 달 수 있는 컨텐트 까지 만들었어. 근데 이게 저장이 안되고 화면에 표시가 안되네. 너한테 어떤 정보를 주어야 하는지 알려줘.

### 💡 답변 (Assistant)
좋습니다. 저장/표시 문제를 정확히 보려면 아래 정보가 필요합니다.

1. **모델 코드**
   - `Question` 모델
   - `Answer` 모델  
   보통 `models.py` 전체 또는 관련 부분

2. **답변 저장 view 코드**
   - `views.py`에서 답변을 처리하는 함수  
   예: `answer_create`, `answer_write`, `answer_form` 같은 함수

3. **URL 매핑**
   - `urls.py`에서 답변 작성 URL 부분  
   예: `path('answer/create/<int:question_id>/', ...)`

4. **템플릿 코드**
   - 질문 상세 페이지 HTML
   - 답변 입력 `<form>` 부분
   - 답변 목록을 출력하는 부분

5. **form 태그 확인용 정보**
   특히 아래가 있는지 봐야 합니다.

```html
<form method="post">
    {% csrf_token %}
```

그리고 입력창에 `name` 속성이 있는지도 중요합니다.

```html
<textarea name="content"></textarea>
```

6. **브라우저/터미널 에러**
   - 저장 버튼 눌렀을 때 터미널에 뜨는 에러
   - 브라우저 화면 에러
   - 에러가 없다면 “에러는 없는데 새로고침돼도 안 보인다”라고 알려주세요.

7. **DB에 실제 저장되는지**
   관리자 페이지나 shell에서 확인했을 때 `Answer` 객체가 생기는지도 중요합니다.

우선 가장 빠르게 보려면 아래 4개를 보내주세요.

```text
models.py
views.py의 답변 저장 함수
urls.py의 답변 관련 path
질문 상세 템플릿의 form + 답변 출력 부분
```

### 💡 답변 (Assistant)
좋아요. 원인 잡으려면 아래 정보만 주면 됩니다.

1. **models.py**
   - Question 모델
   - Answer 모델

2. **views.py**
   - 질문 상세 페이지 view
   - 답변 저장 처리 view  
   예: `answer_create`, `detail` 같은 함수

3. **urls.py**
   - 답변 등록 URL 부분

4. **질문 상세 템플릿**
   - 보통 `question_detail.html`
   - 답변 입력 `<form>` 부분 포함

5. **현재 브라우저에서 나타나는 현상**
   - 저장 버튼 누르면 페이지가 새로고침 되는지
   - 에러 화면이 뜨는지
   - 아무 반응 없는지
   - URL이 바뀌는지

6. **터미널 에러 로그**
   - `python manage.py runserver` 실행 중 나오는 에러 메시지

특히 가장 중요한 건 이 4개입니다.

```text
models.py
views.py
urls.py
question_detail.html
```

추가로, 답변 입력 form에서 이 부분이 있는지도 같이 확인해 주세요.

```html
<form method="post">
    {% csrf_token %}
    ...
</form>
```

그리고 view에서 저장 후 보통 이런 흐름이 있어야 합니다.

```python
answer = Answer(question=question, content=request.POST.get('content'))
answer.save()
return redirect('질문상세페이지', question_id=question.id)
```

코드 올려주시면 어디에서 저장이 끊기는지 바로 잡아드릴게요.

### ❓ 질문 (User)
이제 답변 된다... 고마워 오타 찾아냈어. answer.save가 아니라 question.save로 되어있더라 복사 붙여넣기 하는 과정에서 내가 수정한다는걸 빼먹었나봐

### 💡 답변 (Assistant)
좋습니다. 이건 Django 입문할 때 정말 자주 나는 실수예요.

핵심은 이거였네요.

```python
answer.save()
```

여야 하는데,

```python
question.save()
```

가 되어 있어서 **답변 객체는 생성만 되고 DB에 저장되지 않았던 상황**입니다.

보통 흐름은 이렇게 이해하면 됩니다.

```python
question = Question.objects.get(id=question_id)

answer = Answer(
    question=question,
    content=request.POST.get('content')
)

answer.save()
```

여기서 저장해야 하는 대상은 `Question`이 아니라 **새로 만든 Answer 객체**입니다.

그리고 앞으로 비슷한 실수 줄이려면 변수명을 조금 더 명확히 쓰는 것도 좋아요.

```python
new_answer = Answer(
    question=question,
    content=request.POST.get('content')
)

new_answer.save()
```

이렇게 쓰면 `question.save()`와 헷갈릴 가능성이 확 줄어듭니다. 지금 오타 잡은 거 아주 잘하셨어요. Django 게시판 구현에서 답변 저장까지 됐으면 이제 꽤 중요한 구간 하나 넘긴 겁니다.
