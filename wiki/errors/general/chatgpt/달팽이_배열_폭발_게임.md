# 달팽이 배열 폭발 게임

> **카테고리**: `Errors - General Troubleshooting`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)  
> **작성일**: 2024-12-28

## 💬 대화 내용 및 Q&A

### ❓ 질문 (User)
```
T = int(input())
def main() :
    N, C = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(N)]
    M = N // 2

    # [0] pos[] : 1차원 리스트에서 pos참조하여 달팽이 읽기/쓰기
    # 왼쪽 방향부터 반시계방향
    di = [0, 1, 0, -1]
    dj = [-1, 0, 1, 0]
    cnt_mx, cnt, flag = 1, 0, 0
    ci, cj, dr = M, M, 0        # 중앙 위치로 초기화, 방향(방향은 상관없음 -> 어차피 인접 비교)
    pos = []

    for t in range(N*N-1) :
        cnt += 1
        ci, cj = ci+di[dr], cj+dj[dr]
        pos.append((ci, cj))
        if cnt == cnt_mx :              # 2차원(달팽이) <-> 1차원 lst
            cnt = 0                     # 방향 변경
            dr = (dr + 1) % 4
            if flag == 0 :
                flag = 1
            else :
                flag = 0                # 두 번에 한 번씩 길이 증가
                cnt_mx += 1

    def bomb(lst) :
        # global ans    # main() 에 아닐때
        nonlocal ans    # main() 함수 안에서 실행할 때

        nlst = []       # 리턴에 사용
        lst.append(-1)  # 패딩
        i = 0
        while i < (len(lst)-1) :
            j = i + 1
            while lst[i] == lst[j] :
                j += 1
            if 4 <= (j - i) :   # 폭발
                ans += lst[i] * (j - i) # 구슬 번호 * 폭발 개수
            else :
                nlst += [lst[i]] * (j - i)

            i = j

        lst.pop()
        return nlst

    di = [0, -1, 1, 0, 0]
    dj = [0, 0, 0, -1, 1]
    ans = 0
    for _ in range(C) :                 # 명령의 개수만큼 d, s
        d, s = map(int, input().split())

        # [1] d방향으로 s만큼 뻗어가면서 arr을 0으로 변경 후 1차원 lst에 저장
        for mul in range(1, s+1) :
            arr[M+di[d]*mul][M+dj[d]*mul] = 0

        lst = []        # 0이 아닌 실제 구슬만 담기
        for (i, j) in pos :
            if arr[i][j] > 0 :
                lst.append(arr[i][j])

        # [2] 연속 4개 이상 폭발시키고 (더 이상 폭발하지 않을때 까지 반복)
        while True :
            tlst = bomb(lst)        # 4개 이상 폭발(점수 추가), 나머지 반환
            if len(tlst) == len(lst):   # 더이상 폭발하지 않음
                break
            lst = tlst

        # [3-1] 구슬을 개수 + 번호로 변환
        lst = []
        tlst.append(-1)         # 마지막 데이터 처리를 위해 패딩 추가 => 나중에 제거 필요
        i = 0
        while i < (len(tlst) - 1) :
            j = i + 1
            while tlst[i] == tlst[j] :  # 같은 동안 증가
                j += 1
            lst += [(j-i), tlst[i]] # 개수 + 번호를 추가
            i = j

        # [3-2] 1차원 -> 2차원 배열에 복사
        arr = [[0] * N for _ in range(N)]
        for i in range(0, min(len(lst), len(pos))) :
            arr[pos[i][0]][pos[i][1]] = lst[i]

    print(ans)

if __name__ == "__main__" :
    for _ in range(T) :
        main()
    # main()
```

### 💡 답변 (Assistant)
이 코드는 달팽이 배열을 활용한 퍼즐 문제를 해결하는 프로그램입니다. 문제의 핵심은 2차원 배열에서 여러 규칙에 따라 데이터를 폭발시키고, 이를 1차원 배열로 변환하거나 다시 2차원 배열로 복원하며 점수를 계산하는 것입니다. 

---

## **코드 구성**

### 1. **입력**
- `T` : 테스트 케이스 수
- 각 테스트 케이스에서:
  - `N, C` : 배열 크기(`N x N`)와 명령의 개수(`C`)
  - `arr` : `N x N` 크기의 2차원 배열, 초기 상태
  - 명령 `d, s` : 방향 `d`와 거리 `s`

---

### 2. **핵심 구조**
#### **[0] 달팽이 배열 생성 (`pos` 리스트)**
- **목적**: 2차원 배열의 좌표를 달팽이 순서(중앙부터 반시계 방향)로 변환
- `pos` 리스트:
  - 2차원 좌표를 달팽이 형태로 순서대로 나열한 리스트
  - 예를 들어 `N=5`일 때 `(2,2)`를 시작으로 순서대로 `(2,1)`, `(3,1)` 등이 저장됨
- 방향은 `di`와 `dj`를 사용하여 반시계 방향으로 이동
- `cnt_mx`: 현재 방향으로 이동 가능한 최대 길이
- `flag`: 두 번에 한 번씩 이동 길이를 증가시키기 위한 변수

---

#### **[1] 명령 처리**
- 주어진 방향 `d`와 거리 `s`에 따라:
  - 중앙에서 시작하여 방향 `d`로 `s`만큼 이동하며, 해당 위치를 `0`으로 만듦 (구슬 제거)

---

#### **[2] 1차원 리스트 생성 (`lst`)**
- `arr`의 좌표 순서(`pos`)에 따라 구슬(값이 0이 아닌 요소)을 1차원 리스트로 변환

---

#### **[3] 구슬 폭발 (`bomb` 함수)**
- **목적**: 1차원 리스트에서 4개 이상의 연속된 구슬 폭발
- **구현**:
  - 같은 숫자가 4개 이상 연속되면 점수에 추가 (`ans += 구슬 번호 * 개수`)
  - 폭발하지 않은 구슬만 남긴 새로운 리스트 반환
- **반복**: 폭발이 더 이상 발생하지 않을 때까지 반복

---

#### **[4] 구슬 변환**
- 연속된 구슬을 개수와 번호로 변환
  - 예: `[1, 1, 2, 2, 2]` → `[2, 1, 3, 2]` (1이 2개, 2가 3개)

---

#### **[5] 1차원 리스트 → 2차원 배열 복원**
- 변환된 구슬 리스트를 다시 2차원 배열(`arr`)로 복원
  - 달팽이 순서(`pos`)를 이용해 복사

---

### 3. **출력**
- 각 테스트 케이스에 대해 폭발로 얻은 점수(`ans`)를 출력

---

## **코드의 주요 함수 및 변수 설명**
### **`bomb(lst)`**
- **목적**: 연속된 구슬을 폭발시키고 점수를 계산
- **파라미터**: 
  - `lst`: 현재 1차원 리스트
- **반환값**: 폭발 후 남은 구슬 리스트 (`nlst`)
- **로직**:
  - 연속된 숫자의 범위를 찾고, 4개 이상이면 점수 추가 후 제외

---

### **`main()`**
- **입력 처리**: 배열 및 명령 읽기
- **달팽이 변환**: 2차원 배열을 1차원 리스트로 변환 (`pos` 이용)
- **명령 처리**: 폭발 및 변환 반복
- **출력**: 테스트 케이스별 점수 출력
