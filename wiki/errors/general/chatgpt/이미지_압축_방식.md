# 이미지 압축 방식

> **카테고리**: `Errors - General Troubleshooting`  
> **원천**: ChatGPT 대화 아카이브 (`raw/notes/Chatgpt_2026-08-02-23-14-23`)

## 💬 대화 내용 및 Q&A

### 💡 답변 (Assistant)
### 문제 요약  
이미지를 압축하는 방법을 다루는 문제야. **이미지를 4등분하며 재귀적으로 분할하고**, 한 영역이 특정 비율(T%) 이상 같은 색이면 그 영역을 하나의 색으로 압축해.  

이 과정을 적용한 후, 압축된 데이터를 기반으로 다시 이미지를 복원하는 게 목표야.

---

### 압축 방식 설명  
1. **입력 이미지가 흑백(0과 1)으로 주어짐**  
   - `0`: 흰색  
   - `1`: 검은색  
   - 크기는 항상 `W × W` (`W`는 2의 거듭제곱, 최대 64)  

2. **이미지를 4개 구역으로 나눔** (중앙 기준)  
   - **순서**: **오른쪽 위 → 왼쪽 위 → 왼쪽 아래 → 오른쪽 아래**  
   - 예를 들어 4×4 이미지라면 이렇게 나눠  
     ```
     a | b
     -----
     c | d
     ```

3. **각 영역을 검사하여 압축**  
   - 한 영역이 특정 비율 `T%` 이상 같은 색이면 **더 나누지 않고** 하나의 색으로 처리  
   - 그렇지 않으면 **계속 4등분해서 압축 진행**  

---

### 예제 설명  
#### 입력 1  
```
4 80
0000
1000
0011
0011
```
- 4×4 크기의 이미지  
- **80% 이상 같은 색이면 압축**  

##### 4등분하면 이렇게 됨  
```
00 | 00
-------
10 | 00
```
- `00` → 흰색 (0)  
- `10` → 다른 색 섞임 (1개 이상 80% X) → **계속 나눔**  
- `00` → 흰색 (0)  
- `00` → 흰색 (0)  

결과:  
```
0000
1000
0011
0011
```
압축 전과 동일한 이미지.

---

#### 입력 2  
```
8 75
11111000
11110000
11000011
11000011
11000100
00000100
00010011
00010011
```
- 8×8 크기  
- **75% 이상 같은 색이면 압축**  

##### 4등분하면  
```
1111 | 1000
---------------
1111 | 0000
---------------
1100 | 0011
---------------
1100 | 0011
```
- `1111` → 검은색(1) (100% 검은색)  
- `1000` → 75% 이상 검은색 (압축됨) → **전체 검은색 처리**  
- `0000` → 흰색(0)  
- `1100` → 75%가 안됨 (계속 나눠야 함)  

결과 이미지:  
```
11110000
11110000
11110011
11110011
00000100
00000100
00000011
00000011
```

---

### 핵심 정리  
1. 이미지를 4등분하면서 재귀적으로 나눈다.  
2. 각 구역이 특정 비율(T%) 이상 같은 색이면 하나의 색으로 처리한다.  
3. 압축된 데이터를 기반으로 이미지를 다시 복원해서 출력한다.
