# 세션 시작 문구

아래 내용을 실제 작업과 함께 전달한다. 팀 공용 진입 파일에 추가할 필요는 없다.

```text
이번 작업에서는 references/이정민/index.md를 개인 하네스 진입점으로 사용해라.
팀의 기존 규칙을 먼저 따르고, 현재 작업에 필요한 Markdown 문서만 읽어라.

프로젝트 경로와 정본 위치는 references/이정민/config/project.md에서 확인해라.
작업 목표·현재 상태·실행 한도는 최신 사용자 요청과 해당 작업 문서에서 확인해라.
이전 작업의 목표와 조건을 새 작업의 고정 제약으로 사용하지 마라.

모델 배정과 추론 강도는 references/이정민/config/models.md를 기준으로 한다.
Sol은 조율·통합, Terra는 구현/독립 리뷰, Luna는 조사/검증,
Astra는 고난도 판단/독립 감사를 담당한다.
실제 지원하는 모델·위임 기능만 사용하고, 미지원·미확인은 그대로 보고해라.
단일 모델의 역할 연기를 독립된 여러 모델의 검증이라고 기록하지 마라.

먼저 이번 작업의 범위·위험·필요한 검증을 짧게 정리한 뒤 진행해라.
불필요한 모든 모델 호출, 전체 폴더 읽기, 작업 로그 파일 생성은 하지 마라.

이번 작업:
<여기에 실제 요청을 적는다>
```

반복 사용 시에는 "references/이정민/index.md를 따라 다음 작업을 진행해라"처럼 시작하고 실제 요청을 붙여도 된다.
현재 도구에서 문서를 읽을 수 있는지와 실제 역할 수행 가능 여부는 결과에서 구분한다.
