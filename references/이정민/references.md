# 이정민 · 선택한 팀원 참고자료

아직 등록된 활성 자료는 없다. 실제 팀원 파일이 제공되지 않았으므로 임의의 링크를 활성화하지 않았다.
이 문서 하나에서 목록·적용 조건·검토 기준을 관리한다. 원본은 팀원 폴더에 그대로 둔다.

## 자료 목록

| ID / 제목 | 원본 링크·경로 기준 | 사용할 때 / 제외할 때 | 적용 역할 | 상태 | 확인한 버전·날짜 | 내 적용 메모 |
|---|---|---|---|---|---|---|

경로는 이 파일 기준 상대 링크 또는 '저장소 루트 기준'을 명시한 경로로 쓴다.
한 자료를 추가할 때 [참조 규칙](harness/team-references.md)에 따라 원본과 현재 적용 전제를 확인한다.
자료 내용을 자세히 정리할 때만 [reference 양식](templates/reference.md)을 사용한다.

## 등록 메모 양식 — 실제 자료로 바꾸어 사용

- 자료 ID / 제목:
- 원본 경로와 경로 기준:
- 소유자 / 정본 또는 수정본:
- 상태: candidate
- 사용할 때 / 사용하지 않을 때:
- 적용할 역할: BUILDER / REVIEWER 등
- 검토한 버전·commit 또는 확인한 구절 / 확인 날짜:
- 이번 프로젝트에 적용할 부분 / 적용하지 않을 부분:
- 필수 여부 / 읽을 수 없거나 변경됐을 때의 처리:

다른 팀원의 전체 하네스를 읽을 필요는 없다. 현재 작업에 맞는 특정 공식·절차·검토 기준만 선택한다.
