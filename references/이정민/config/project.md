# 프로젝트 참고표 · AegisLM

이 문서는 프로젝트 경로와 정본 위치를 안내한다. 작업 목표·현재 단계·대상 모델·
실행 횟수·예산·진행 상태는 최신 사용자 요청과 해당 작업 문서에서 관리한다.
이미 합의한 작업 범위와 권한은 이어받고, 이전 작업의 조건을 다음 작업에 자동 적용하지 않는다.

## 사용 원칙

하네스는 역할·작업 배분·인수인계·검증 방법을 제공한다.
작업별 목표·완료 조건·실행 한도는 필요한 작업 패킷에 전달하며 이 참고표에 복제하지 않는다.
경로가 바뀌면 확인 후 갱신한다. 문서에 경로가 있다는 사실은 도구 실행 권한을 뜻하지 않는다.
비밀정보와 인증 정보는 기록하지 않는다.
