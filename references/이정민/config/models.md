# 모델 운영표

이 문서는 사용자가 선택한 **모델 배정·추론 강도에 대한 운영 요청값**이다.
실행 환경의 설정 파일이 아니며, 읽는 것만으로 모델·추론 강도·권한·병렬 수가 자동 변경되지 않는다.
모델명은 사용자가 제공한 식별자 그대로 보존했다. 계정/도구의 지원이나 실제 호출 성공을 보증하지 않는다.

## 기본 배정 — 이 표가 개인 하네스의 기준

| 슬롯 | 역할 | 요청 model ID | 요청 추론 강도 | 사용 가능 여부 | 마지막 실제 확인 |
|---|---|---|---|---|---|
| Sol | Director / Architect / Integrator | `gpt-5.6-sol` | `high` | unverified | 미확인 |
| Terra | Builder / 독립 Reviewer | `gpt-5.6-terra` | `high` | unverified | 미확인 |
| Luna | Scout / Verifier | `gpt-5.6-luna` | `low` | unverified | 미확인 |
| Astra | Principal Specialist / Independent Auditor | `gpt-6-astra` | `high` | unverified | 미확인 |

Terra의 구현과 리뷰는 모두 `high`다. Builder와 Reviewer는 서로 다른 작업·새 검토 세션으로 분리한다.
Astra도 기본 `high`를 유지한다. 어려운 작업이라는 이유만으로 요청값을 임의로 `xhigh`로 바꾸지 않는다.
값 변경이 필요하면 이유를 제안하고 사용자 또는 이미 승인된 팀 절차에 따라 적용한다.

## 실행 환경

| 항목 | 운영 기준 |
|---|---|
| 사용하는 도구 | Codex를 우선하되 기존 실행 환경을 그대로 사용 |
| 도구 버전 | 현재 세션에서 확인 가능할 때 기록. 미확인 상태를 임의로 채우지 않음 |
| 실행 모드 | 실제 지원 시 native 위임. 아니면 수동 다중 세션 또는 제한된 단일 세션 |
| 동시 하위 에이전트 | 기본 최대 2개. 실제 환경의 더 낮은 제한을 우선 |
| 같은 작업 사본의 동시 소스 작성자 | 최대 1개. Sol의 직접 수정도 작성자 수에 포함 |
| 조용한 모델 대체 | 금지. 대체 사실·이유·실제 모델을 명시 |
| 모델/권한 자동 설정 | 하지 않음. 이 문서는 실행 환경을 수정하지 않음 |

## 실제 사용 확인

현재 도구의 상태 표시나 실행 메타데이터로 실제 모델과 추론 강도를 확인할 수 있으면 결과에 기록한다.
확인할 수 없으면 `MODEL_ACTUAL: unknown`으로 남긴다. 모델의 자기소개를 확인 근거로 삼지 않는다.
모델명 확인과 해당 작업에서의 호출 성공은 별개다. 작업 성공 여부는 실제 결과로 판단한다.
모든 모델을 시험하기 위해 불필요한 호출을 실행하지 않는다. 실제 필요한 역할부터 확인한다.

부모 세션의 모델과 하위 역할의 모델을 별도로 확인한다. Sol 역할 지시를 읽었다고 부모 모델이 Sol로 바뀐 것은 아니다.
사용 불가능하거나 확인할 수 없는 모델은 그렇다고 알리고 [세션 운영](../harness/runtime.md)을 따른다.
필수 감사의 대체/보류는 [승격 규칙](../harness/escalation.md)을 따른다.

모델 접근성 확인을 이유로 비밀정보를 수집하거나 기존 전역·팀 설정을 변경하지 않는다.
실제 확인 뒤 표를 갱신할 수 있으나, 이 Markdown을 읽거나 수정한 것만으로 확인 완료가 되지는 않는다.
