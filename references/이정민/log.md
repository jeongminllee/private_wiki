# 하네스 변경 기록

## 2026-09-18 · V3.1.1-MD

- 개별 작업의 목표·단계·모델·실행 횟수를 하네스에 고정한 V3.1의 오류를 정정했다.
- 운영 문서·시작 프롬프트·역할·검토 절차에서 작업별 조건을 제거했다. 해당 조건은 개별 작업 기록에서 관리한다.
- 프로젝트 참고표는 경로·정본 위치만 안내하며, 작업 패킷은 비어 있는 양식으로 유지한다.
- 아래 항목은 변경 이력이며 현재 작업에 적용할 지시가 아니다.

## 2026-09-18 · V3.1-MD

- 사용자 요청으로 프로젝트 상태에 대한 배포 직전 가정을 제거했다.
- AegisLM 단일 프로젝트와 GPT-OSS-20B 첫 파일럿 1회 계약을 반영했다.
- 실제 모델 배정·검증과 문서 요청값을 구분하고 B200 부모 데이터 전체 학습 gate를 유지한다.
- AegisLM 프로젝트 안의 `references/이정민/`에 같은 버전 snapshot을 배치한다.

## 2026-09-09 · V3-MD

개인 경로를 `references/이정민/`으로 통일했다.
역할·작업 배분·승격·인수인계·검증·참고자료·작업 절차·양식 구조를 유지했다.
설치/관리 도구, 실행 설정 파일, 자동 등록·생성 단계, 도구 테스트를 제외했다.
모델 설정과 팀원 참고자료 등록은 Markdown 표로 옮겼다.
요청 추론 강도는 Sol high / Terra high / Luna low / Astra high다.
배포 직전 프로젝트의 기존 구조 보존·최소 변경·회귀 확인을 기본 작업 원칙으로 명시했다.

이 기록은 문서 구성의 변경 기록이다. 실제 모델 실행, 프로젝트 테스트, 비용/품질 개선이 검증됐다는 뜻은 아니다.
